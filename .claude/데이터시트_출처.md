# 데이터시트 출처

저장소 6개 실험이 쓰는 IC 의 **제조사 1차 데이터시트** 목록이다. 전부 벤더
사이트에서 직접 내려받아 `PINNING`/`Pin description`/`Pin Configuration` 절을
열어 확인했다 — `alldatasheet` 같은 2차 미러나 블로그 경유가 아니다.

확인일: 2026-09-07 (`74HC11` 은 2026-09-27 — 실험04 저작 중 §5.2 Pin description 확인)

## 인용 형식

보고서 참고문헌에는 **제조사 · 문서번호 · 개정 · 발행일 · URL** 을 모두 적는다.
개정 번호가 빠지면 어느 판을 봤는지 특정되지 않는다 — 74HC 계열은 개정마다
전기적 특성이 바뀐다.

```
Nexperia. 74HC04; 74HCT04 — Hex inverter. Rev. 10, 2024-02-16.
https://assets.nexperia.com/documents/data-sheet/74HC_HCT04.pdf
```

## 아직 열려 있는 것

- **실험03 M5 — 교안 표기가 `7404`/`7408`/`7432`/`7486`(TTL) 인데 실물 지급품이
  TTL 인지 74HC 인지 모른다.** 핀 배치는 두 계열이 같아서 결선도는 영향을 받지
  않지만, **전기적 특성이 다르다** — TTL 은 미사용 입력을 개방하면 HIGH 로 뜨고,
  74HC 는 뜨지 않는다. 실물 칩 각인을 보고 인용할 데이터시트를 고른다.

- **실험10 은 이 표를 근거로 쓰지 않는다.** 그 주차 교안 p9 가 `7490`·`7404`·
  `7405`·`741` 핀아웃 도해를 문서 안에 직접 싣고 있어, 교안이 최상위 근거다.
  위 TI 항목은 교차 검증용이다.

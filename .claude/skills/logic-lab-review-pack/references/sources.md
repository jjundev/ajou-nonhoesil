# 자료와 문항 감사

현재 수행 범위는 현재 공지·교안과 config.scope_tokens로 확인한다. 수행 제외를 시험 제외로 바꾸지 않는다.
manual_candidates가 고른 판본을 기록하고 과거 판본이면 모든 화면에 현재 학기 미확인을 표시한다.
IC 핀·출력 극성·전기적 정격은 정확한 부품·패키지의 데이터시트와 교안을 대조한다.
보고서·기존 학습 노트·과거 제출본은 학생이 이해해야 할 주장을 찾는 재료다. 그것만으로 정답을 확정하지 않는다.
미사용 입력에 관한 단일 실험 관찰을 모든 CMOS의 일반 규칙으로 가져오지 않는다.
예상 결과, 실제 측정 결과, 이상 모델을 분명히 구분한다.

퀴즈 폴더와 원본_docx를 포함해 모든 자료를 목록화한다. PDF와 DOCX가 같은 문제인지 내용으로 대조한다.
문항 단위로 past/unknown/predicted/practice, included/duplicate/held/other_experiment을 기록한다.
실제 기출 여부는 제목만으로 확정하지 않는다. 연도·분반·배점 등 원문 증거를 확인한다.
중복은 조건·회로·입출력 극성·정답을 확인한 뒤 대표 ID에 연결한다. 문구만 유사한 다른 회로는 별도 문항이다.
답안지가 다른 경우 양쪽 제공 답안을 따로 남기고 독립 풀이로 대조한다.
모든 고유 기출을 수록하며 예상문제는 개념 공백만 보충한다. 판독 불가 문항은 원문 페이지와 보류 이유를 남긴다.

PDF 텍스트 추출은 탐색 보조다. 회로도·오버바·클록 엣지·아래첨자·표는 페이지를 PNG로 렌더해 눈으로 읽는다.
PDF page는 1부터, 인쇄 페이지는 별도 문자열이다. 원문 그림은 문제와 풀이의 답 노출 여부를 살핀다.
해설에만 있는 정답 표시를 원문 문제 그림으로 가져오지 않는다.
원본은 수정하지 않고 임시 판독 자료는 run/work, 산출 그림은 run/figures에 저장한다.

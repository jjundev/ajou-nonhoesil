### LED 숫자 순서를 고정하는 탐색

새 숫자 순서 배치는 LED 태그를 의미상 순서로 선언하고, 승인된 `LAYOUT['leds']` 좌표를 고정한 채
`python -m scripts.lab.place_search <배치.py> --mode fixed --budget 256 --length-slack 1.10 --out <별도폴더>`로
탐색한다. 현재 어댑터는 실험07이다. LED를 칩 핀 순서에 맞춰 다시 정렬하지 않는다. 칩 배치·허용된 등가
할당·배선 순서·λ를 바꾸고, 실제 준비/걷기/결선/완성본을 같은 후보 경로로 검증한다.
검증된 최단 신호선 길이의 110% 안에서 밀도·실제 교차·단계 최대 밀도·꺾임·길이 순으로 선택한다.
λ는 후보 생성 설정이며 최종 평가 기준이 아니다. 승인본은 fallback으로 보존하고 결과는 별도 폴더에 낸다.
R10의 칩→LED 연결 규칙은 유지한다. `led_order_policy='fixed'`일 때만 출력 핀 순서 역전 검사를 제외하며,
홀·넷·전원·겹침·가독성 검사는 완화하지 않는다. 기존 주차의 기본 `pin` 정책은 유지한다.
보고서는 탐색 예산·실패 원인·비교 지표를 남기며, 전역 최적해라고 부르지 않는다.

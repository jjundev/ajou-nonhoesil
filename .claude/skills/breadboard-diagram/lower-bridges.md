# 새 결선도의 긴 5V·GND 레일 연결선

앞으로 생성하는 v2 결선도에 적용한다. 대상은 좌 바깥 레일과 가운데 레일을 잇는 긴 두 가닥이다.
칩 전원핀의 짧은 점퍼, LED 전원선, 입력 점퍼, 전원 잭 선은 아래로 우회시키지 않는다.
기존 승인본은 재생성하지 않는다.

## 배치와 검증

- 마지막 칩 아래에서 실제 홀이 있는 연속 행 쌍을 위에서 아래로 비교한다. 보드 맨 아래로 고정하지 않는다.
- 브리지를 먼저 예약하고 신호선을 배선한다. 긴 두 가닥과 다른 모든 배선 사이에 한 홀 간격 이상의 여유를
  둔다. 교차·포개짐·가까운 평행선·사선 접근을 검사한다. 두 브리지끼리는 별도 연속 행을 사용한다.
- 준비·걷기·단계·완성본에서 확정 홀이 같은지, 임시선이 브리지에 접근하는지 검증한다.
  기존 홀·넷·전원·부품·번호 원·가독성 검사를 유지한다.
- 조건을 만족하는 같은 칩/LED 배치의 후보 중 가장 가까운 아래쪽 행 쌍을 사용한다.
  충분히 떨어졌으면 더 내리지 않는다. 공간이 없으면 실패를 보고하고 칩·신호선 배치를 조정한다.
  혼잡한 기준 배치로 되돌아가거나 검사를 완화하지 않는다.

## 저작과 탐색

새 빌더의 고정물 함수는 다음을 사용한다. 회로별 모든 단계가 같은 `layout`을 읽어야 한다.

```python
bb.connect_jacks()
bb.connect_rail_bridges(layout)
```

고정 LED 탐색은 기존 명령에 `--lower-bridges`를 추가한다.

```bash
python -m scripts.lab.place_search <배치.py> --mode fixed --budget 256 --length-slack 1.10 --lower-bridges --out <별도폴더>
```

채택한 `LAYOUT`에는 `bridge: [GND행, VCC행]`과 `bridge_policy: 'lower-clearance-v1'`을 함께 저장한다.
`connect_rail_bridges`는 두 가닥의 홀을 먼저 검사하고 확정 행에서만 그린다. 빈 홀이 없을 때 가까운
위쪽 행으로 옮기는 `free_rail_row`로 되돌아가지 않는다. 번호·순서표·넷은 기존 브리지와 동일하다.

LED 없는 회로의 기존 배치 절차에서는 배치를 정한 뒤
`place_lower_bridges(circuits, layout, verify=...)`를 호출한다.
`verify`는 실제 단계·완성본을 `place_verify(module, candidate, 임시폴더)`로 검증해 오류 문자열 또는
`None`을 돌려준다. 반환된 배치로 다시 생성한 PNG/JSON을 눈으로 대조한 뒤 채택한다.

탐색 보고서에는 브리지 행 쌍과 정책을 남긴다. 신호선의 기존 `density` 지표는 전원선을 제외하므로
그 수치만으로 브리지 여유를 판단하지 않는다. 별도 간격 검사와 실제 그림으로 확인한다.

# 7-Segment 표시기 (`display_chain`)

표시기는 칩이 아니다. `bb.chips` 에 안 들어 R9 를 타지 않고 우 블록에 선다. 모델 표는 엔진 `DISPLAYS` 다.

```python
bb.display_chain('FND 507', 윗행)     # 표시기 + 묶음 전원선 + 세그먼트마다 330Ω
wires += [(첫단계, None, 'sig', ('U2', 13), ('SEG', 'a'), 'a: U2 pin 13 -> 330Ω (U3 pin 7)')]
```

- **핀.** DIP 처럼 왼쪽 위 pin 1, 왼쪽을 내려가 오른쪽 아래 pin 6, 오른쪽 위 pin 10 이다. 교안 실험8 p16 핀 그림과 돌림 방향이 같다.
- **다리 가정.** 교안에 간격이 없다. 지난 학기 사진에서 몸통이 c~h 를 덮고 a·b·i·j 만 남아, 숨은 다리를 d·h 열로 두고
  배선은 그 밖에만 꽂는다. 다리가 c~e·f~h 어디든 스트립이 같아 결선은 그대로다. 실물이 다르면 `DISPLAYS` 를 고친다.
- **저항.** 세그먼트 핀 스트립에서 표시기 위아래 행으로 낸다. 빈 끝 스트립이 `SEG` 끝점이고 R10 은 이것을 LED 사슬 신호
  스트립처럼 본다. 경로는 골 차선(`_GAP_LANES`)으로 e·f 열에 가로로 들어갈 수 있다.
- **몸통.** 표시기·저항 몸통 위로는 선이 못 지난다(R15). 배선기도 번호 원도 피한다. f쪽 묶음선은 표시기 밑을 돌아 간다.
- **신호 표시.** 저항 옆 `signal_tag` 배지가 세그먼트 이름이다. 몸통은 LED 쪽 330Ω 과 똑같이 둔다. 배지 상한(`MAX_ON_BOARD_LABELS`)에 걸리면 안 세는 경로를 만들지 말고 예외표에 근거를 적는다.
- **새 부품.** 첫 렌더를 확대해 기존 부품과 나란히 본다. 자동 검사는 꽂을 수 있는지만 보고, 다른 소자로 보이는지는 못 잡는다.
- **도장.** 도장에는 `displays` 키로 든다(없는 주차는 키가 없어 옛 도장이 그대로다).

## `TAP` — LED 사슬 신호 스트립 중계

칩 사이가 R8 에 걸리고 n.c. 핀이 모자라면 LED 사슬 신호 스트립을 쓴다. 그 스트립은 앞 칩 출력과 같은 넷이다. 끝점
`('TAP', 'A')` 는 그 스트립의 빈 홀(c~e)이고 R10 의 칩 핀 → LED 스트립 선이다. 실물 `보고서/실험08/결선도/배치.py`.
그 LED 를 빼도 스트립이 남아 다음 칩은 끊기지 않지만, LED 급전선을 뽑으면 끊긴다.

준비 그림에는 입력 점퍼의 0 자리(임시 고정)를 둘 수 있다. `build_all` 은 입력 점퍼를 준비의 신호선으로 세지 않는다.

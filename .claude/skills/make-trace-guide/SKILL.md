# make-trace-guide

완성본 결선도(`배치.py` 의 `FINALS`)를 **번호 구간 층**으로 나눠, 한 쪽에 한 층씩
싣는 PDF 를 `<실험NN>/결선도/팀원전달용/실험NN_따라그리기.pdf` 에 낸다. 그림·표·쪽 검사는
전부 코드(`scripts/lab/trace_guide.py`, 엔진 `layer=(lo, hi)`)가 한다. 이 스킬이 판단하는
것은 **층을 어디서 끊고 뭐라고 부르나** 하나다. 쪽 순서는 완성본마다 `완성본 쪽 → 그 층들`
이고, 쪽 수 = 완성본 수 + 층 수다.

## 인자 — 실험 하나로 정한다

`<실험번호|N주차>`. 번호 토큰이 없으면 한 줄로 되묻고 멈춘다.
- "실험N"·"N" → 실험 N.
- "N주차" → `.venv/bin/python -c "from scripts.lab import config; print(config.experiments_in_week(N))"`.
  결과가 **정확히 하나**이고, 사용자가 회로 이름을 말했다면 그 이름이 그 실험 `FINALS` 에 있을
  때만 진행한다. 비었거나, 둘 이상이거나, 회로 이름이 안 맞으면 후보를 들어 한 줄로 되묻고
  멈춘다 — 같은 번호의 실험 폴더(`실험0N`)가 있으면 첫 후보로 든다.
- 회로 이름을 말하지 않았으면 그 실험 `FINALS` 전부를 싣는다.

## 고치는 파일 — 이 둘뿐이다

1. 그 주차 `보고서/실험NN/결선도/배치.py` — `FINALS` 빌더의 `layer` 인자, `LAYERS` 표
2. 그 주차 `결선도/팀원전달용/실험NN_따라그리기.pdf`

엔진·생성기·공용 테스트가 실패하면 그 파일을 고치지 않는다. 실패한 명령과 출력 끝부분을
보고에 싣고 멈춘다 — 도구 결함은 도구 커밋으로 따로 고친다(`breadboard-diagram` 규칙).
주차 전용 테스트도 더하지 않는다: `tests/test_trace_guide_layers.py` 가 `LAYERS` 있는
주차를 전부 자동으로 잰다. 커밋하지 않는다 — 사용자가 한다.

## 절차

1. **전제.** `.venv/bin/python -m pytest tests/test_breadboard_boards.py -q` 가 초록이어야
   한다. 빨강이면 완성본 PNG 가 낡은 것이다 — `breadboard-diagram` 으로 넘기고 멈춘다.
2. **빌더.** `FINALS` 의 빌더마다 시그니처에 `layer=None` 이 있고
   `BreadboardRenderer(template_path, baseline=baseline, layer=layer)` 로 넘기는지 본다.
   v2 주차(`BOARD = 'v2'`)는 `board=BOARD` 도 넘긴다 —
   `BreadboardRenderer(template_path, baseline=baseline, layer=layer, board=BOARD)`.
   없으면 `보고서/실험04/결선도/배치.py` 의 `build_e4_mux` 처럼 더한다 — `stage` 와 함께
   주면 `ValueError` 로 거절하는 두 줄 포함. `FINALS` 에 없는 회로는 손대지 않는다.
3. **층.** `LAYERS` 가 `FINALS` 의 완성본 전부를 덮고 있으면 건너뛴다. 빠진 완성본이 있으면
   그 몫만 쓴다. 없으면 `결선도/<완성본>.json` 의 `steps`
   (번호·kind·from·to·desc)를 읽고 아래 **층 규칙**대로 `FINALS` 바로 뒤에 쓴다.
4. **재기.** `.venv/bin/python -m pytest tests/test_trace_guide_layers.py tests/test_breadboard_boards.py -q`
5. **뽑기.** 기존 PDF 가 있으면 먼저 스크래치 폴더에 복사해 둔다. 그다음
   `.venv/bin/python -m scripts.lab.trace_guide N`. 생성기가 쪽 넘침을 스스로 막는다 —
   `"…" 쪽이 넘쳤다` 가 나오면 그 층을 둘로 쪼개고 4 로 돌아간다. 실패하면 기존 PDF 는 그대로
   남는다. `LAYERS 에 층 목록이 없다` · `…번에서 시작해야 하는데` · `완성본 배선은 N개다` 는 도구
   결함이 아니라 **`LAYERS` 가 낡은 것**이다 — 완성본 사이드카를 다시 읽고 3 에서 고친다.
6. **보기.** `pymupdf` 로 60dpi PNG 를 스크래치 폴더에 뽑아 Read 로 본다: 표 행이 가장 많은
   층 쪽 하나 + 완성본마다 마지막 층 쪽(완성본 PNG 와 선 모양 대조). 겹치면 겹친 대로 둔다.
7. **다시 뽑은 경우.** 5 의 사본과 새 PDF 를 쪽별로 잰다:
   ```python
   import pymupdf, hashlib
   def sig(f):
       d = pymupdf.open(f)
       return [(p.get_text(), [hashlib.md5(d.extract_image(x[0])['image']).hexdigest()
                               for x in p.get_images()]) for p in d]
   ```
   같으면 5 의 사본을 제자리로 복사해(`cp <사본> <PDF>`) 파일을 그대로 두고 "바뀐 것 없음" 으로
   보고한다. `git checkout` 은 쓰지 않는다 — 커밋 안 된 최신본 대신 옛 커밋본이 돌아온다.

## 층 규칙

층은 완성본 번호 1..N 을 **번호 순서대로 이어 자른 구간**이다. 빌더 배선 순서는 바꾸지
않는다 — 번호와 도장이 바뀌어 이미 받은 손그림과 어긋난다. 번호를 1 부터 훑으며 **하는 일이
바뀌는 자리**에서 끊는다:

- 전원 잭·레일 브리지가 끝나는 자리 → 1층
- **처음 이어진** 칩 전원(pin 14·7) 묶음이 끝나는 자리 → 2층. 그 사이 LED 사슬이 이어
  나오면 2층에 넣는다. 뒤에 따로 나오는 칩 전원은 그 자리의 층에 둔다.
- 그다음은 게이트·관측 노드가 바뀌는 자리마다. 두 게이트의 배선 번호가 엇갈리면
  `입력 갈래` / `출력 → 다음 칩` 처럼 역할로 끊는다.
- 게이트 배선이 없는 회로(계측 회로 등)는 남은 배선의 종류로 끊는다(예: `미사용 입력 pull`).

이름은 그 구간에 **실제로 든 것**을 적는다: `<게이트·노드> (<칩 라벨>)`. 칩 라벨(U1…)은
`결선도/netlist.md` 의 `- U1 = 74HC86 …` 줄에서 읽는다. 늦게 번호를 받은 칩 전원·LED 사슬이
신호 층에 섞이면 이름에 `+ U3 전원` · `→ Co LED` 처럼 붙인다. 한 층 14행 이하를 목표로
하고, 판정은 5 의 생성기가 한다. 이름은 20자 안팎으로 — 쪽 제목이 두 줄로 접혀도 결함은
아니다.

## 보고

1. PDF 경로·쪽 수 (또는 "바뀐 것 없음")
2. 층 표 — 완성본마다 `번호 구간 · 이름 · 행 수`
3. 고친 것 — `배치.py` 의 빌더 이름, `LAYERS` 새로 씀/그대로
4. 본 쪽 — 쪽 번호와 확인한 것
5. 걸린 것 — 멈춘 명령과 출력 끝, 요청했지만 `FINALS` 에 없어 빠진 회로

요청한 회로가 빠졌으면 답의 **첫 줄**에 그 사실을 쓴다. 팀원이 그려 오면
`review-hand-diagram` 으로 검토한다고 한 줄 붙인다.

## 흔한 실수

| 실수 | 대신 |
|---|---|
| 층 테스트가 빨개서 공용 테스트를 고친다 | 보고하고 멈춘다 — 도구 결함은 따로 고친다 |
| 주차 전용 테스트를 새로 쓴다 | 안 쓴다 — 공용 테스트가 이미 잰다 |
| 요청받은 회로가 `FINALS` 에 없어 목록에 더한다 | 더하지 않는다 — 첫 줄과 "걸린 것" 에 적는다 |
| 층을 예쁘게 하려고 빌더에서 배선 순서를 옮긴다 | 순서는 그대로, 이름으로 설명한다 |
| 주차가 비었는데 비슷한 번호 실험으로 진행한다 | 후보를 들어 되묻는다 |
| 다시 뽑은 같은 PDF 를 새 파일로 남긴다 | 사본과 해시가 같으면 사본을 제자리로 복사한다 |
| `LAYERS` 번호 오류를 도구 결함으로 보고 멈춘다 | `LAYERS` 가 낡은 것 — 3 에서 고친다 |

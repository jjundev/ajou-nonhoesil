# export-hand-diagram

학생이 배포본 실체도 판형 위에 손으로 그린 결선도 PDF 로부터 300 DPI PNG 로 일괄 추출하고, `보고서/실험NN/결선도/손그림/` 에 정본으로 아카이빙한다.

## 절대 규칙

1. **표준 파일명은 국문 규격으로 고정한다.** `실험NN_{소단원}_손그림_{회로명}.png` (예: `실험01_1-1_손그림_3입력_AND.png`, `실험01_3_손그림_복합논리회로.png`).
2. **단일 소스 원칙.** 회로 목록 및 소단원 정보는 `보고서/실험NN/결선도/netlist.md` 에서만 읽어 동적으로 결정한다. 스크립트 내에 실험별 회로 이름을 하드코딩하지 않는다.
3. **크롭 옵션 (기본값: 크롭 안 함).** 기본 동작은 원본 전체 페이지를 보존하여 저장한다. 사용자가 크롭을 원하거나 `--crop` 플래그를 지정한 경우에만 템플릿 좌표계 기준 `ix in [20, 565]`, `iy in [30, 740]` 영역을 크롭하여 브레드보드 본체만 정밀 추출한다.
4. **고해상도 유지.** 기본 해상도는 300 DPI 로 렌더링하여 마크다운 및 노션 문서 삽입 시 핀 번호와 전선 결선이 선명하게 보이도록 한다.

## 인자

`<실험번호|주차> [PDF 경로] [--out DIR] [--dpi DPI] [--crop]`

- 번호 토큰이 없으면 한 줄로 되묻고 중단한다.
- `PDF 경로` 가 없으면 `output/손그림검토/round<max>/hand.pdf` 를 우선 탐색하고, 없으면 `output/실험NN_손그림결선도_최종통합본.pdf` 를 쓴다.
- `--out` 생략 시 `보고서/실험NN/결선도/손그림/` 에 저장된다.
- 기본 DPI 는 300 이다.
- **기본값은 크롭하지 않는다.** 브레드보드 본체만 정밀 크롭하려면 `--crop` 옵션을 지정한다.

## 실행 절차

0. **실험 번호를 폴더 이름으로 옮긴다.**
   ```bash
   python3 -c "
   from scripts.lab import config
   print(config.experiment_dir(<실험번호>))
   "
   ```

1. **대상 손그림 PDF 확인.**
   - 사용자가 경로를 직접 지정했으면 그 파일을 쓴다.
   - 없으면 최신 검토본을 자동 탐색한다:
     ```bash
     python3 -c "
     from scripts.lab.export_hand_diagrams import find_default_pdf
     print(find_default_pdf(<실험번호>))
     "
     ```

2. **추출 실행.**
   ```bash
   python3 -m scripts.lab.export_hand_diagrams <실험번호> [PDF경로] [--crop]
   ```
   - 기본값은 원본 전체 페이지를 저장하며, 브레드보드 본체 영역만 잘라내려면 `--crop` 옵션을 붙인다.
   - `netlist.md` 및 최신 검토 라운드의 `전사/p*.json` 과 교차 검증하여 페이지 순서가 뒤섞여 있어도 올바른 회로명으로 매핑된다.

3. **결과 검증 및 보고.**
   - `보고서/실험NN/결선도/손그림/` 내 파일 목록과 해상도(기본 전체 페이지 약 5042x3476 px @ 300DPI, 크롭 시 약 1817x2368 px), 용량을 확인하고 표로 정리하여 사용자에게 보고한다.
   - 보고서 마크다운 또는 노션에 첨부할 수 있는 상대 경로(`![회로명](../결선도/손그림/파일명.png)`)를 함께 안내한다.

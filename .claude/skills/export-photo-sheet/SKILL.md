# export-photo-sheet

`<실험NN>/실험사진/` 의 낱장 사진을 항목마다 한 장의 시트로 합성해
`<실험NN>/실험사진/시트/` 에 둔다. 시트의 타일마다 입력 조합과 LED 상태가
캡션으로 구워져 있어, 노션에 손으로 끼울 때 사진과 캡션이 어긋날 수 없다.

이 스킬이 하는 일은 전부 **대조**다 — 파일명을 기록과 대조하고, 캡션을 기록과
대조하고, 사진을 캡션과 대조한다. 대조에 실패한 항목은 만들지 않는다.

## 규칙

- 캡션의 LED 상태는 `기록.md` 확인 칸에서만 온다. `✓` 는 예상값, 값은 관찰값,
  공란은 시험하지 않은 행이라 거부한다.
- 파일명은 `<항목> <입력비트>.jpg` 다 — `1-1 000.jpg`, `3-1 11.jpg`. 항목 토큰은
  명세 제목의 `실험 N)` 번호이고(`3-1` 처럼 뒤에 붙은 것은 앞자리로 대응),
  비트열은 그 표의 입력 열 순서다. 규칙 밖 파일의 이름을 대신 짓지 않는다.
- 원본 사진을 손대지 않는다. 회전·축소는 별도 요청이고, 하기 전에 백업이 먼저다.

## 절차

1. **번호를 폴더로 옮긴다.**

   ```bash
   python3 -c "from scripts.lab import config; print(config.experiment_dir(<실험번호>))"
   ```

   완료: 폴더 경로가 나온다.

2. **파일명·기록을 대조한다.**

   ```bash
   python3 -m scripts.lab.contact_sheet <실험번호> --check
   ```

   완료: `문제 0건`. 아니면 표를 그대로 보여 주고 멈춘다 — 규칙 밖 파일명,
   기록에 없는 조합, 확인 칸이 빈 조합은 전부 사용자가 정할 일이다.

3. **캡션 표를 만든다.**

   ```bash
   python3 -m scripts.lab.contact_sheet <실험번호> --dry-run
   ```

   완료: 사진 수와 캡션 수가 같다.

4. **사진 전부를 열어 대조표를 쓴다.** 사진마다 LED 를 보고 아래 표의 한 행을
   채운다. 어둡게 켜진 LED 가 꺼진 것처럼 보이는 일이 흔하므로, 사진 판독은
   묻는 근거일 뿐 기록을 뒤집는 근거가 아니다.

   ```
   | 항목 | 입력 | 캡션(기록) | 사진에서 본 것 | 판정 |
   |---|---|---|---|---|
   | 2-1 | 110 | L1 켜짐 · L2 켜짐 | L1 흐림 · L2 켜짐 | 애매 → 확인 요청 |
   ```

   완료: 대조표 행 수가 사진 수와 같고, 모든 행의 "사진에서 본 것" 칸이 차
   있다. 판정이 `어긋남` 이나 `애매` 인 행이 있으면 그 항목은 사용자가 확정할
   때까지 만들지 않는다. 사용자가 기록을 고치면 2단계부터 다시 한다.

5. **합성한다.**

   ```bash
   python3 -m scripts.lab.contact_sheet <실험번호>            # 전부
   python3 -m scripts.lab.contact_sheet <실험번호> --only 2-1 # 한 항목만 다시
   ```

   완료: 시트 수가 사진이 있는 항목 수와 같고, 장마다 5 MB 아래다(스크립트가
   품질을 낮춰 맞춘다). 시트를 더 줄여야 하면 `--tile-width 800` 을 쓴다.

   **항목당 사진이 8장이면 `--per-sheet 4` 로 4장씩 두 장에 나눈다**(파일명에
   `_1`·`_2` 가 붙는다 — 2026-09-18 실험03에서 사용자가 정했다). 타일 사이
   여백은 없고, 타일 높이는 그 항목 사진의 비율에서 정해져 위아래 흰 띠가 남지
   않는다. 결과보고서에는 시트마다 그림 한 줄씩 넣고 캡션에 조합 범위를 적는다
   (`000부터 011까지`).

6. **결과를 안내한다.** 파일·크기 표, 결과보고서에 넣을 상대경로 스니펫
   `![<회로명>의 네 입력 조합](../실험사진/시트/<파일명>)`, 그리고 노션에는
   상대경로 그림이 깨지므로 시트를 손으로 끼워야 한다는 한 줄.

## 비-목표

- 사진을 자동으로 회전하거나 축소하지 않는다. 방향과 화질 손실은 사용자 결정이다.
- `기록.md` 를 고치지 않는다.
- 노션에 올리지 않는다 — sync-report-to-notion 의 영역이다.

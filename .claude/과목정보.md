이 파일은 하네스 전체의 단일 메타데이터 소스다. 표지·보고서·체크리스트가
학부·과목·교수·분반·학번·성명을 전부 여기서 읽는다. **스킬에 하드코딩하지 말 것.**

## PDF 변환

macOS 의 Chrome 헤드리스를 쓴다. 위 `chrome` 경로가 이 머신의 실제 위치다.

    "$CHROME" --headless --disable-gpu --no-pdf-header-footer \
      --print-to-pdf="출력.pdf" "file:///절대경로/입력.html"

Chrome 은 정상 동작 중에도 macOS 에서 `task_policy_set ... invalid argument`
를 stderr 로 뱉는다. **종료 코드가 아니라 PDF 파일 생성 여부로 성공을 판정한다.**

## 노션 업로드

예비·결과보고서는 md 를 그대로 노션에 올리고(⑦ `sync-report-to-notion`), 사용자가
노션에서 PDF 로 내보낸 뒤 ⑥ 이 만든 표지 PDF 를 앞에 손으로 붙여 제출한다.

**토큰은 이 파일에 두지 않는다.** 환경변수 `NOTION_TOKEN` 에서만 읽는다 —
`.claude/` 는 git 에 추적되므로 여기 두면 저장소에 비밀이 들어간다.

`~/.zshrc` 가 아니라 **`~/.zshenv`** 에 넣는다. zsh 는 `~/.zshrc` 를 **대화형
셸에서만** 읽어서, 스킬이 돌리는 비대화형 `python3` 는 토큰을 못 본다.

    grep -q NOTION_TOKEN ~/.zshenv || echo "export NOTION_TOKEN='ntn_...'" >> ~/.zshenv

위 `notion_parent_page_id` 페이지에 노션에서 integration 을 **Connect** 해 두어야
한다. 안 하면 API 가 404 `object_not_found` 를 돌려준다.

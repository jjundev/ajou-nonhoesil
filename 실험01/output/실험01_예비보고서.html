1. 실험 목적

교안(실험1.pdf) p.2 "1. 목적" 에 따르면 이번 실험의 목적은 다음 두 가지다.

  1. Logic gates(논리 게이트)의 이해
  2. Logic 회로 구성 법칙의 이해 — Boolean equation(부울대수)과 De Morgan(드모르간)의 법칙 이해를 포함한다.

이를 이번 주차의 세 실험 항목에 구체적으로 적용하면 다음과 같다.

  1. 2-input 게이트 IC(74HC08, 74HC32, 74HC00, 74HC02)를 두 단으로 캐스케이드 연결해 3-input AND·OR·NAND·NOR 게이트를 구성하고, LED 로 읽은 출력을 진리표와 대조해 검증한다 (E1.P1-1, E1.P1-2).
  2. 인버터(74HC04)·AND(74HC08)·OR(74HC32)를 조합한 복합 논리회로를 구성하여, 여러 게이트가 만드는 부울식을 실제 회로로 확인하고 드모르간 정리가 회로 수준에서 어떻게 성립하는지 관찰한다 (E1.P2).

2. 실험 이론

2.1 논리 레벨 — H/L 과 0/1

교안 p.3 은 논리값을 두 단계로 정의한다: L(Low) = 논리값 0 = 물리적으로 0V, H(High) = 논리값 1 = 물리적으로 3~5V. 이 보고서의 §2.2 이론표(T6~T9)는 교안 원문 그대로 H/L 인코딩을 쓰고, §4 의 3-input 진리표(T1~T5)는 실험실에서 LED 점등 여부로 직접 읽는 0/1 인코딩을 쓴다. 두 표기는 같은 논리값을 가리키는 서로 다른 표기일 뿐이며, 교안과 대조할 때 혼동하지 않도록 이 보고서에서도 서로 바꿔 쓰지 않는다.

2.2 기본 게이트 — 2-input 이론표

교안 p.4~p.8 은 AND·OR·NOT·NAND·NOR 각 게이트의 기호와 부울식, 2-input 진리표를 차례로 제시한다. 아래 T6~T9 는 명세(실험01/체크리스트/명세.md)에 role: reference 로 등록된 참조표로, 학생이 배선·기록하는 대상이 아니라 교안 원문을 그대로 옮긴 이론 자료다. H/L 인코딩을 0/1 로 바꾸지 않고 교안 그대로 둔다.

2.3 2-input 게이트로 3-input 을 만드는 법

이번 실험의 세 항목 중 둘(E1.P1-1, E1.P1-2)은 2-input IC 만으로 3-input 게이트를 구성하는 것이다. 근거는 AND·OR 의 결합법칙이다.

  • A·B·C = (A·B)·C — 게이트1 이 A·B 를 만들고, 게이트2 가 그 결과와 C 를 다시 AND 한다.
  • A+B+C = (A+B)+C — 같은 방식으로 OR 두 단.

NAND·NOR 는 결합법칙이 성립하지 않는다 ((A↑B)↑C ≠ A↑(B↑C)). 그래서 교안 p.12 는 3-input NAND 를 NAND 두 단으로 만들지 않고, AND 로 A·B 를 만든 뒤 NAND 로 C 와 합치는 구조를 쓴다: A·B·C = (A·B)↑C. NOR 도 같은 이유로 OR + NOR 조합이다: A+B+C = (A+B)↓C.

2.4 드모르간 정리와 복합회로(E1.P2)의 부울대수 해석

드모르간 정리는 A·B = A + B, A+B = A·B 다 (교안 p.2 가 명시한 학습 목표).

교안 p.13 복합회로의 세 출력을 부울대수로 정리하면 다음과 같다. 배선은 §5.4 에 있다.

  • Z = A·B — 드모르간을 적용하면 Z = A + B = A + B
  • X = A + Z = A + (A + B) = A + B (멱등법칙 A + A = A)
  • Y = A + B

따라서 X 와 Z 는 대수적으로 항등이다(X = Z = A + B). 브레드보드에서 X LED 와 Z LED 가 서로 다르게 켜지면 그것만으로 배선 오류를 알 수 있다 — 계측기 없이 얻는 자체 검산이다.

출처: 부울식 전개는 위 드모르간 정리를 배선 판독 결과(실험01/결선도/netlist.md)에 적용해 이 보고서가 직접 도출했다.

3.3 LED 와 전류 제한 저항

교안 p.11·p.12·p.13 은 모두 "※ 다이오드 연결 시, 330Ω 저항 필수" 박스를 달고 있다. LED 는 애노드 쪽에 330Ω 을 직렬로 넣고 캐소드를 GND 로 내린다.

74HC 출력이 약 4.5V 를 내고 LED 순방향 전압을 약 2V 로 보면 330Ω 에 걸리는 전류는 약 (4.5 − 2) / 330 ≈ 7.6 mA 이다. 74HC 시리즈의 권장 출력 전류를 넘는 값이므로, 교안 지시대로 따르되 LED 가 예상보다 어두우면 이것을 먼저 의심한다 (§5.5 M3).

3.4 미사용 핀 처리

  • 미사용 입력핀은 전부 GND 로 내린다. 띄워두면(플로팅) CMOS 입력이 잡음을 주워 출력이 불안정해진다. 이 실험에서 결과가 안 맞는 가장 흔한 원인이다.
  • 미사용 출력핀은 개방한다. 출력끼리 묶거나 GND 로 내리면 칩이 손상된다.
  • 입력 A·B·C 도 점퍼선으로 +5V(=1) 또는 GND(=0)에 직접 물린다. 띄워두지 않는다.

4. 실험 과정 및 예상 결과

4.1 E1.P1-1 · 3-input AND / OR gate 구성

교안 p.11. 2입력 게이트 2개를 캐스케이드해 3입력을 만든다. 교안 회로도에는 LED 가 2개 달려 있다 — 게이트1 출력(A·B)에 L1, 게이트2 출력(A·B·C)에 L2 가 붙는다. 진리표의 검증 대상은 최종 출력 L2 이고, L1 은 중간단이 살아 있는지 눈으로 보는 용도다.

OR 는 같은 회로를 74HC32 로 바꿔 반복한다. 교안이 IC 를 지정하지 않고 "OR gate에 대한 IC 찾아서 수행" 이라고만 쓰므로, 준비물 중 quad 2-input OR 인 74HC32 를 선택했다.

과정. ① §5.2 대로 배선한다. ② 입력 A·B·C 를 000 부터 111 까지 8가지 조합으로 순서대로 인가한다. ③ 각 조합에서 L2 의 점등 여부를 기록하고 아래 예상표와 대조한다.

4.2 E1.P1-2 · 3-input NAND / NOR gate 구성

교안 p.12. §2.3 에서 밝힌 대로 NAND 는 결합법칙이 성립하지 않으므로 NAND 두 단이 아니라 74HC08 + 74HC00 조합이다. 게이트1(74HC08)이 A·B 를 만들고, 게이트2(74HC00)가 그 결과와 C 를 받아 A·B·C 를 낸다. p.11 과 마찬가지로 중간단 L1, 최종단 L2 두 개의 LED 가 붙는다.

5. 회로 결선도

5.1 공통 규칙

  • 모든 IC: pin 14 → VCC(+5V), pin 7 → GND
  • 미사용 입력핀은 전부 GND 로 내린다. 플로팅 금지. 미사용 출력핀은 개방한다
  • 입력 A·B·C 는 점퍼선으로 +5V(=1) 또는 GND(=0)에 직접 물린다
  • LED 는 애노드 쪽에 330Ω 직렬, 캐소드 → GND
  • 물리 칩 재사용: 아래 U1·U3·U8 은 같은 74HC08 한 개를, U2·U5·U9 는 같은 74HC32 한 개를 항목마다 재배선해 쓰는 것이다

출처: 실험01/결선도/netlist.md "공통 규칙" 절.

## 📌 핵심 요약

FPGA Kit 설계 프로젝트를 **3주간** 진행한다. 1~2주차에 설계·구현, **3주차에 동작 확인과 평가**를 한다.

- **Kit**: 조별 1개. 실험실 밖 반출 금지, 본인 분반 시간에만 사용.
- **조교 답변 범위**: 설치·드라이버·프로그램 실행·보드 연결 같은 환경 문제만. "어떻게 구현하나"는 답하지 않는다 — 설계 방향을 찾는 과정도 평가에 들어간다.
- **이름 맞추기**: 프로젝트명 = Verilog 파일명(.v) = module명. 다르면 top module 인식·pin map 적용이 실패할 수 있다. 프로젝트마다 새 폴더.
- **경로**: 한글·공백·OneDrive 경로 금지. 예: `C:\FPGA_Project\project1`
- **Pin map**: 코드의 input/output 변수명이 pin map 파일에 그대로 있어야 하고, 파일에 빈칸이 없어야 한다.
- **7-segment**: 숫자가 아니라 a~g + h(dp) 8bit 패턴을 넣는다(예: `b0110_1101`). 보드가 active-high 인지 active-low 인지 확인.
- **Switch**: 16개 스위치가 bit 하나씩으로 들어온다(`h0800` = bit 11). 조건문 쓸 때 bit 위치를 확인.
- **3주차 평가 때 설명할 것**: 구현 기능, 입출력 구성, switch/button 처리, 7-segment/LED 출력 방식, 주요 module 구조, pin map 연결, 디버깅하며 겪은 문제와 해결.

## 본문 전문

안녕하세요.
논리회로실험 조교 주우진입니다.

FPGA Kit 프로젝트 진행과 관련하여 안내드립니다.
이번 프로젝트는 총 3주간 진행되며, 단순히 예제 코드를 실행하는 것이 아니라 각 조가 직접 설계, 구현, 디버깅, 검증까지 수행하는 방식으로 진행됩니다. 아래 내용을 반드시 확인해주시기 바랍니다.

1. FPGA Kit 사용 관련 안내

FPGA Kit는 조별로 1개씩 제공됩니다.
Kit는 실험실 외부로 반출할 수 없으며, 반드시 수업 및 실험 진행 시간 내에만 사용해야 합니다.

또한 본인이 속한 분반이 아닌 다른 요일/시간대의 강의에 참여하거나, 다른 분반 시간에 Kit를 사용하는 것은 불가합니다.
Kit 수량과 실험실 운영 문제로 인해 반드시 본인 분반 시간에만 프로젝트를 진행해주시기 바랍니다.

2. 프로젝트 진행 기간 및 평가 안내

프로젝트는 총 3주간 유동적으로 진행됩니다.
수업 시작 시간은 반드시 지켜주시고, 종료 시간은 진행 상황에 따라 조정될 수 있습니다.

3주차에는 설계 결과 확인과 평가가 함께 진행될 예정입니다.
따라서 1~2주차에는 설계 및 구현을 최대한 진행하고, 3주차에는 동작 확인, 오류 수정, 최종 설명 준비까지 마무리할 수 있도록 계획해주시기 바랍니다.

평가와 관련하여, 조교는 설계 해결책에 대해 직접적인 답변을 제공하지 않습니다.
즉, “이 기능을 어떻게 구현해야 하는지”, “이 코드를 어떻게 짜야 하는지”와 같은 설계 자체에 대한 답변은 제공하기 어렵습니다.
각 조에서 설계 방향을 논의하고, 문제를 분석하여 해결하는 과정까지 평가에 포함된다고 생각해주시기 바랍니다.

다만, 설치 오류, 드라이버 인식 문제, 프로그램 실행 문제, 보드 연결 문제 등 실험 환경과 관련된 문제는 확인 후 안내드릴 수 있습니다.

3. 프로젝트 생성 및 파일명 관련 주의사항

프로젝트를 생성할 때는 프로젝트명, Verilog 파일명(.v), module명이 서로 일치하도록 설정해주시기 바랍니다.

예를 들어 프로젝트명이 project1이라면, Verilog 파일명과 module명도 다음과 같이 맞추는 것을 권장합니다.

프로젝트명: project1
파일명: project1.v
module명: module project1(…);

이 세 가지가 서로 다를 경우, 컴파일 과정에서 top module을 제대로 인식하지 못하거나, pin map이 정상적으로 적용되지 않는 문제가 발생할 수 있습니다.
또한 기존 파일이 있는 폴더에 새 프로젝트를 생성하면 이전 파일들과 충돌하여 오류가 발생할 수 있으므로, 프로젝트마다 새로운 폴더를 생성하여 진행해주시기 바랍니다.

4. 프로젝트 경로 관련 주의사항

프로젝트 경로에 한글, 공백, OneDrive 경로가 포함될 경우 오류가 발생할 수 있습니다.
특히 OneDrive 폴더 안에서 프로젝트를 생성하면 access error가 발생할 수 있으며, 한글 폴더명이나 파일명이 포함된 경우에도 컴파일 또는 실행 과정에서 문제가 생길 수 있습니다.
따라서 프로젝트는 가급적 아래와 같이 영문 경로에 생성해주시기 바랍니다.

예시: C:\FPGA_Project\project1

반대로 아래와 같은 경로는 오류가 발생할 가능성이 있으므로 피하는 것을 권장합니다.

예시: C:\Users\사용자\OneDrive\바탕 화면\논리회로실험\프로젝트

5. Pin map 관련 안내

FPGA 보드의 switch, button, LED, 7-segment 등은 Verilog 코드의 변수명과 실제 보드의 핀이 서로 연결되어야 정상적으로 동작합니다.

따라서 제공된 pin map 파일을 반드시 확인하고, 코드에서 사용하는 입출력 변수명이 pin map에 정의된 이름과 일치하는지 확인해주시기 바랍니다.

특히 pin map 파일에 빈칸이 있거나, 변수명이 코드와 다르거나, 프로젝트의 top module 이름과 맞지 않으면 보드에 업로드하더라도 원하는 동작이 나오지 않을 수 있습니다.

Pin map 관련해서는 다음 사항을 꼭 확인해주시기 바랍니다.

* 코드의 input/output 변수명이 pin map 파일에 존재하는지 확인
* pin map 파일에 비어 있는 항목이 없는지 확인
* 프로젝트명, Verilog 파일명, module명이 일치하는지 확인
* 사용하는 switch, LED, 7-segment가 실제 보드 핀과 제대로 연결되어 있는지 확인

6. 7-segment 출력 관련 안내

7-segment는 숫자 하나를 표시하기 위해 여러 개의 segment를 조합해서 켜고 끄는 구조입니다.
각 segment는 보통 a, b, c, d, e, f, g와 dot에 해당하는 h 또는 dp로 구성됩니다.

따라서 숫자를 출력할 때는 단순히 숫자 5를 대입하는 것이 아니라, 숫자 5를 표시하기 위해 어떤 segment를 켜야 하는지를 8bit 값으로 지정해야 합니다.

예를 들어 특정 숫자를 표시하기 위한 값이 다음과 같이 표현될 수 있습니다.

b0110_1101

이때 각 bit는 7-segment의 특정 부분에 대응됩니다.
또한 h는 dot, 즉 소수점 표시 부분을 의미합니다.

주의할 점은 보드에 따라 segment가 active-high 방식인지 active-low 방식인지 다를 수 있다는 점입니다.
즉, 1을 넣었을 때 켜지는 보드가 있고, 0을 넣었을 때 켜지는 보드가 있을 수 있으므로, 반드시 실습 자료와 보드 동작을 확인하면서 진행해주시기 바랍니다.

7. Switch 입력 관련 안내

Switch 입력은 보통 여러 개의 스위치 상태가 하나의 bit 묶음으로 들어오는 방식입니다.

h0800은 16진수 값이며, 이를 2진수로 표현하면 다음과 같습니다.

h0800 = 0000 1000 0000 0000

즉, 여러 switch 중 특정 위치의 switch 하나가 켜져 있는 상태를 의미합니다.

Switch를 사용할 때는 단순히 “몇 번째 스위치를 켰다”라고 생각하기보다, 해당 스위치가 Verilog 코드에서 몇 번째 bit로 들어오는지 확인해야 합니다.

예를 들어 스위치 위치에 따라 다음과 같은 값으로 들어올 수 있습니다.

0001, 0002, 0004, 0008
0010, 0020, 0040, 0080
0100, 0200, 0400, 0800
1000, 2000, 4000, 8000

따라서 switch 입력을 조건문에서 사용할 때는 실제 입력값과 bit 위치를 정확히 확인한 후 작성해야 합니다.

8. 자주 발생하는 오류 및 해결 안내

프로젝트 진행 중 자주 발생하는 오류는 다음과 같습니다.

첫째, 설치 오류가 발생하는 경우입니다.
설치가 정상적으로 되지 않았거나 실행 파일이 제대로 동작하지 않는 경우에는 재설치를 진행해야 할 수 있습니다.

둘째, 드라이버가 인식되지 않는 경우입니다.
FPGA Kit를 연결했는데도 보드가 인식되지 않는 경우, 보드 연결 상태와 드라이버 설치 여부를 다시 확인해야 합니다.
케이블 연결 문제인지, 드라이버 설치 문제인지, 프로그램 설정 문제인지 순서대로 확인해주시기 바랍니다.

셋째, 프로젝트가 생성되지 않는 경우입니다.
이 경우 OneDrive 경로에서 access error가 발생했거나, 한글 경로 때문에 실행이 불가하거나, 기존 파일들과 충돌하여 오류가 발생했을 가능성이 있습니다.
이 경우에는 영문 경로에 새 폴더를 만들고 다시 프로젝트를 생성하는 것을 권장합니다.

넷째, pin map이 정상적으로 적용되지 않는 경우입니다.
이 경우 pin map 파일에 오류가 있는지, 코드의 변수명과 pin map의 변수명이 일치하는지, top module명이 올바르게 설정되어 있는지 확인해야 합니다.

9. 프로젝트 진행 시 권장 순서

프로젝트를 시작하기 전에 각 조는 먼저 구현할 기능을 명확히 정리해주시기 바랍니다.
이후 입력으로 사용할 switch/button과 출력으로 사용할 LED/7-segment를 결정하고, 해당 입출력들이 pin map에서 어떻게 연결되는지 확인해야 합니다.

권장 진행 순서는 다음과 같습니다.

1. 구현할 기능 정리
2. 사용할 입력 장치 결정
3. 사용할 출력 장치 결정
4. Verilog module의 input/output 정의
5. pin map 파일과 변수명 일치 여부 확인
6. 7-segment 출력값 및 switch 입력값 확인
7. 간단한 기능부터 테스트
8. 전체 기능 통합
9. 보드 업로드 후 실제 동작 확인
10. 3주차 평가를 위한 설계 설명 준비

10. 평가 준비 관련 안내

3주차 평가 시에는 단순히 결과가 동작하는지만 보는 것이 아니라, 각 조가 어떤 방식으로 설계했는지 설명할 수 있어야 합니다.

따라서 다음 내용을 미리 정리해두는 것을 권장합니다.

* 프로젝트에서 구현한 기능
* 입력과 출력의 구성
* switch/button 입력값 처리 방식
* 7-segment 또는 LED 출력 방식
* 주요 Verilog module 구조
* pin map 연결 방식
* 디버깅 과정에서 발생한 문제와 해결 방법

프로젝트 진행 중 환경 문제나 보드 인식 문제는 조교에게 문의해주시기 바랍니다.
다만, 설계 해결책 자체에 대한 직접적인 답변은 제공하지 않는 점 참고 부탁드립니다.

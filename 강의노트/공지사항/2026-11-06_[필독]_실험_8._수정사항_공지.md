## 📌 핵심 요약

실험 8 강의노트 **p13 회로도**(실험 3. 7-Segment 표시기를 갖는 BCD 카운터)의 **74HC47 ↔ FND507** 결선 일부가 잘못되어 정정합니다. 실험은 아래 결선을 기준으로 합니다.

**잘못된 부분 (p13 회로도)**
- VCC가 FND507의 1번(Segment E), 5번(DP)에 연결되어 있음
- 7447의 d 출력이 3번(Common Anode)에, e 출력이 2번(Segment D)에 연결되어 있음
- 8번(Common Anode)이 연결되어 있지 않음

**올바른 결선 (p16 pin map, FND507 데이터시트 기준)**

| 74HC47 출력 | FND507 핀 | 비고 |
|---|---|---|
| a (13번) | 7번 | |
| b (12번) | 6번 | |
| c (11번) | 4번 | |
| d (10번) | 2번 | **정정** |
| e (9번) | 1번 | **정정** |
| f (15번) | 9번 | |
| g (14번) | 10번 | |
| VCC | 3번, 8번 (Common Anode) | **정정** |
| — | 5번 (DP) | 사용하지 않음 |

- a, b, c, f, g는 p13 회로도와 같다.
- 각 세그먼트 선에는 회로도와 같이 330Ω 저항을 직렬로 연결한다.
- 74HC47의 3, 4, 5번(/LT, /BI, /RBI)은 회로도대로 VCC에 연결한다.
- 강의노트에 FND205로 적힌 부분은 FND507을 뜻한다.

> [!IMPORTANT]
> **실험 전 확인**: 받은 FND가 Common Anode인지 먼저 확인한다. 3번(또는 8번)에 VCC, 세그먼트 핀 하나를 330Ω 저항을 거쳐 GND에 연결했을 때 켜지면 Common Anode다. Common Cathode 소자는 이 회로에서 동작하지 않으니 조교에게 교체를 요청한다.

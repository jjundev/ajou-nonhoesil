## 검증 방법과 한계

1. inventory 의 path 집합 10개를 파일시스템 목록과 대조했다. 원문 10개 SHA256 을 추출 전·후 비교해 변경 없음을 확인했다.
2. PDF 8개(20쪽)를 PyMuPDF 120dpi 로 렌더해 모두 보았다. 작은 회로(DAC 회로, 저항망)와 v1 Online 캡처는 300~500dpi 확대 렌더로 부품값·라벨을 대조했다. 텍스트 추출은 탐색 보조로만 썼다.
3. DOCX 2개는 설치된 Word 를 COM 으로 매크로 비활성(AutomationSecurity=3)·읽기 전용으로 열어 작업 폴더에만 PDF 로 내보냈고, 각 3쪽을 렌더해 보았다. OOXML 문단 번호·그림 위치(6번 수식은 P23/P33 의 둘째 그림)도 대조했다. HWP·DOC 파일은 없었다.
4. 이미지·개인 식별 정보: 채점본은 없었고 기출 시험지의 반/조/이름/학번 칸은 비어 있다.
5. 구조/관계/파일 검증 CLI 가 통과했다. 기계 검사는 원문 해석과 정답의 옳고 그름을 보증하지 않는다. 다른 판독자의 독립 검토는 없다.
6. 원문 간 모순과 부분 판독 메모가 남아 source_visual=partial, status=complete_with_holds 로 두었다.

python -m scripts.lab.review_pack.question_bank_cli check --root . --bank 문제은행/실험10/question-bank.json

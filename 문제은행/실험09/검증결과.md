## 보류와 불일치

- **파일명과 실제 내용이 다른 자료**
  - `종합_기출문제 (2p).pdf`의 헤더는 “실험 9 RAM 예상문제”다. 문항마다 근거를 따로 정했다.
  - `기출_채점본_2.jpg`와 `_3.jpg`에는 점수와 응시자 칸이 없다. 아주대학교 로고와 쪽 번호 12가 있는 인쇄 페이지이고, 9·10번 수기 답이 붉은 원으로 둘러져 있다. 파일명의 “채점본”만으로 기출 판정을 하지 않았다.
  - 그래서 B part 1 쓰기(q-bpart1)는 unknown이다. 같은 페이지의 10번은 2016-2 시험지 3번과 조건이 같아 q-bpart0(기출)으로 묶었다.
- **Read/Write 답안의 표기 모호**: 단답형 PDF와 HWP의 3·4번 답안은 “Read = 1, Write =0”과 “Read = 1, Write =1”이다. 입력값을 뜻하는지 극성 규약을 뜻하는지 원문만으로 정할 수 없어 그대로 두었다. Quiz 예상문제 인쇄물의 수기 답은 각각 0과 1이다.
- **SRAM 저장 회로 이름에 대한 제공 답안 세 가지**
  - 예상 자료: “플립플롭 , 인버터”
  - 단답형·HWP: “플립플롭이 사용되며, F/F과 레지스터, Ram의 순이며 …”
  - 수기: “R-S F/F”
  - 세 가지를 모두 보존했고 정답을 고르지 않았다.
- **수기메모 5번 답의 input 값**: 1을 쓰는 문항인데 input 값이 0으로 읽힌다. 다른 제공 답안들의 Input = 1과 다르다. Selection 값도 덧칠돼 있어 확정하지 않았다.
- **덧쓴 수기 값**: 채점본_2·3의 WR0·WR1 값과 수기메모 6~8번의 일부 값은 0과 1이 덧쓰여 있다. 후보만 남겼다.
- **채점본_1의 판독 한계**: 1·3번 수기 답안은 연필이 흐려 일부만 판독했다. 3번의 74670 그림은 수기에 가려진 라벨이 있다.
- **v1에 삽입된 Online 개별과제 슬라이드**: 축소 이미지라 수기 서술 일부를 읽지 못했다. 퀴즈 시행 근거가 없어 unknown으로 두었다.
- **수기메모 이미지 가장자리의 다른 퀴즈**: 왼쪽 가장자리에 카운터 주제 퀴즈 채점지 일부가 겹쳐 있다. 잘려서 판독할 수 없고 실험9 문항도 아니어서 source 미해결로만 기록했다.

## 검증 방법과 한계

1. inventory의 path 집합을 파일시스템 전체 목록 13개와 대조했다. 원문 13개의 SHA256을 추출 전·후 비교해 변경이 없음을 확인했다(`sha_before.txt`).
2. PDF 7개 14쪽은 PyMuPDF로 120dpi 렌더해 모두 직접 봤다. 수기 메모, 삽입 슬라이드, 표, 답안 줄은 300~600dpi로 확대해 다시 봤다.
3. HWP는 원본을 작업 폴더에 복사한 뒤 로컬에 설치된 한컴오피스 2020(HWPFrame.HwpObject COM)으로 열었다. PDF 저장은 COM 예외로 실패했다. 대신 CreatePageImage로 3쪽을 작업 폴더에 이미지로 렌더해 봤다. 외부 웹 변환은 쓰지 않았다.
4. DOC는 설치된 Word를 COM으로 매크로 강제 비활성·읽기 전용으로 열었다. 작업 폴더에만 PDF를 내보내 2쪽을 렌더해 봤고, 본문 32개 문단 위치를 대조했다.
5. 원본 이미지 4장을 직접 봤다. 회전 촬영(채점본_2)은 돌려서 봤고 수기 영역은 확대했다. 흐릿한 원본을 생성형 보정으로 바꾸지 않았다. 회로를 새로 그리거나 원문의 답을 지우지 않았다.
6. 구조·관계·파일 검증 CLI가 통과했다. 기계 검사는 원문 해석이나 정답의 옳고 그름을 보증하지 않는다. 다른 판독자의 독립 검토는 없고, 이번 세션의 직접 판독과 자체 대조 결과다.
7. 부분 판독과 분류 보류가 남아 있어 source_visual=partial, status=complete_with_holds를 유지했다.

## 보류와 불일치

- 파일명 2016-1과 시험지 헤더 2017-1이 다르다. 두 값을 그대로 저장했다.
- 예상문제 v2·종합본·DOCX의 6번은 번호만 있고 본문이 없다. 3개의 partial 등장으로 남겼으며 다른 버전의 6번과 합치지 않았다.
- 1×2 DEMUX 문제 뒤에 붙은 그림은 2×1 MUX 표·식·회로를 제시한다. 문서 위치에 따른 후보 답안 연결만 했다.
- 비교 해설의 입력선·출력선 개수 설명은 같은 페이지의 도해와 불일치한다. 원문 설명을 고쳐 쓰지 않았다.
- 디코더/DEMUX 비교 해설의 선 종류 및 데이터 선택기 역할 설명은 후속 독립 풀이 검토 대상으로 남겼다.
- 문제에 주어진 74HC125/nOE 표는 Low에서 입력을 통과시키지만, 뒤에 붙은 제공 그림은 active high enables라는 캡션을 갖는다. 확정 답안으로 승격하지 않았다.
- 1×4 DEMUX 제공 표의 D=0 행은 출력 네 칸이 X다. 0 또는 Z로 교정하지 않았다.
- 미확인 Quiz 문항 3개의 시행 근거는 아직 없다.

## 검증 방법과 한계

1. 파일시스템 전체 목록과 inventory의 path 집합을 대조했다. 원문 11개 SHA256을 추출 전·후 비교해 변경 없음을 확인했다.
2. PDF는 PyMuPDF로 렌더해 17쪽 모두 확인했다. DOCX는 bundled render_docx.py가 LibreOffice 부재로 실패한 로그를 확인한 뒤, 설치된 Word에서 매크로를 비활성화하고 읽기 전용으로 열어 작업 폴더에만 PDF를 출력했다. 해당 4쪽은 Poppler로 렌더해 확인했고 OOXML 문단 위치도 대조했다. DOCX 원문 해시는 동일하다.

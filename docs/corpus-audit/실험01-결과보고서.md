# 실험01 결과보고서 코퍼스 감사 — 과거 제출본 1편

대상: `from_the_past/정리/결과보고서/실험1/실험1 결과보고서 160314.pdf`
(2016-03-14, 홍선표, 15쪽). 아카이브 교안 기준(항목 3개).

## 1. 판정 요약

**예상표·회로도·사용 소자·배선 사진은 전부 교안 회로와 맞다.** 3-input
AND(74HC08)·OR(74HC32)·NAND(74HC08+74HC00)·NOR(74HC32+74HC02)·복합(74HC04+
74HC08+74HC32). `74HC32`·`74HC02` 핀 그림도 데이터시트와 같다(p10). 틀린
것은 **고찰 산문의 부울식 1종**이다.

## 2. 틀린 자리

### F5 (하) — p9·p12 고찰, `L1` 을 앞단 NAND/NOR 로 적었다

> "3-input NAND gate를 구성해보면 L1 = (A·B)`, L2 = ((A·B)`·C)`"
> "3-input NOR gate를 구성해보면 L1 = (A+B)', L2 = ((A+B)'+C)'"

같은 쪽의 예상표는 `L1 = A·B` / `L1 = A+B` 로 맞게 채워져 있고, 회로도와
사진도 앞단이 AND/OR 다. 산문만 틀렸다. 이 식으로 드모르간을 전개한 뒷
문장(`L1 = A'+B'` 등)도 따라서 틀렸다.

## 3. 관측

- 측정표가 `H`/`0` 을 섞어 쓴다(p2 `H H H H H`, p4 `0 0 1 0 1`). 표기
  일관성이 없을 뿐 값은 예상표와 일치한다.
- p13 고찰: "회로가 복잡해질수록 확실한 결과값을 확인하기 위해서 저항을
  꽂아야 한다는 조교님의 조언" — 2016 에는 LED 직렬 저항이 교안 지시가
  아니었다는 방증이다. 배포본은 모든 쪽 머리에 "다이오드 연결 시, 330Ω
  저항 필수" 를 박아 두었다.

디지털-아날로그 변환기(DAC)의 기본 원리

📌 가중 저항형 DAC (Binary-Weighted)
b3(MSB) ───[ R ]───┐ b2 ───[ 2R ]───┼───(-) ┌───────┐ b1 ───[ 4R ]───┤ │ LM741 │──► Vout b0(LSB) ───[ 8R ]───┤ ┌───(+) │ │ │ └───────┘ Rf └───┴───[ Rf ]──┘ GND (가상 접지)
$$V_{out} = -V_{ref} \frac{R_f}{R} \left( \frac{b_3}{1} + \frac{b_2}{2} + \frac{b_1}{4} + \frac{b_0}{8} ight)$$
⚠️ 가중 저항형 DAC의 극단적 한계
• 비트 수가 증가할수록 저항비가 지수적($2^n$)으로 증가:
- 8비트 DAC: $R \sim 128R$
- 16비트 DAC: $R \sim 32,768R$ ($10\text{k}\Omega \sim 327.68\text{M}\Omega$)
• 문제점: 반도체 집적회로 내부에서 수백 배 이상의 정밀 저항비를 공정 오차 없이 제작하는 것은 물리적으로 불가능 ➔ **R-2R 사다리형 DAC의 탄생!**

[가중 저항형의 한계와 실무]

가중 저항형은 비트 수가 4비트만 넘어가도 MSB 저항의 미세한 오차가 LSB 저항값 전체를 집어삼켜 전압 출력이 역전되는 비단조성(Non-monotonicity)이 발생합니다.

Modern DAC Standard R-2R Ladder Network

R-2R 사다리형 DAC와 테브난 등가 해석

오직 $R$과 $2R$ 두 종류 저항만으로 구현하는 정밀 $1/2$ 전류 분배 사다리망

R R R ┌─────────/\/\/\─────/\/\/\─────/\/\/\─────┐ │ │ │ │ │ [2R] [2R] [2R] [2R] [Rf=2R] │ │ │ │ │ GND b0(LSB) b1 b2(MSB) OP-Amp(-)
• 각 노드에서 왼쪽을 바라본 테브난 등가 저항은 항상 **정확히 $R$**로 일정!
• 각 비트 스위치가 주입하는 전류는 상위 노드로 갈 때마다 정확히 **$1/2$씩 감쇄**되어 가산기로 유입.
📌 LM741 출력 아날로그 전압 공식 (4비트)
$$V_{out} = -V_{ref} \cdot \frac{R_f}{2R} \cdot \sum_{i=0}^{3} \frac{b_i}{2^{3-i}} = -V_{ref} \left( \frac{b_3}{2} + \frac{b_2}{4} + \frac{b_1}{8} + \frac{b_0}{16} ight)$$
• 1 LSB 계단 전압 (Step Size): $\Delta V = \frac{V_{FS}}{2^n - 1} \approx \frac{V_{ref}}{16}$
• 4비트 카운터(7493)를 물리면 $0\text{V}$부터 $V_{FS}$까지 완벽한 16단계 계단형 톱니파(Staircase Waveform) 출력!

[R-2R 사다리형의 반도체 공학적 승리]

R-2R 구조는 오직 $R$과 $2R$ (즉, $R$ 2개 직렬)만 사용하므로 반도체 레이아웃에서 동일한 단위 저항 셀을 반복 배치하여 공정 변동에 대한 저항비 매칭 정밀도를 0.01% 이내로 극대화할 수 있습니다.

Performance Metrics Resolution, DNL, INL & Settling

DAC 성능 평가 4대 핵심 지표

해상도, 정착 시간, 선형성 오차(DNL/INL) 및 단조성(Monotonicity)

📌 1. 해상도 & 정착 시간

해상도 (Resolution): 비트 수 $n$ 또는 1 LSB 전압

$$V_{\text{LSB}} = \frac{V_{\text{FS}}}{2^n - 1} \quad (\text{예: 8비트 5V 시 } \approx 19.6\text{mV})$$

정착 시간 (Settling Time): 디지털 입력 변화 후 출력이 최종값의 $\pm 0.5\text{LSB}$ 이내로 안정화되기까지 걸리는 시간 (OP-Amp 슬루레이트가 지배).

📌 2. 선형성 오차 (DNL / INL) & 단조성

• DNL (차등 비선형성): 실제 인접 계단 높이와 이상적 $1\text{LSB}$ 간의 차이 ($|DNL| < 1\text{LSB}$ 이어야 단조성 보장).
• INL (적분 비선형성): 이상적 직선과 실제 변환 곡선 간의 최대 편차.
• 단조성 (Monotonicity): 디지털 코드가 증가할 때 출력 아날로그 전압이 절대 감소하지 않고 계속 증가하는 특성.

[단조성 깨짐(Non-Monotonicity)의 위험성]

만약 DNL 오차가 커서 디지털 코드가 0111에서 1000으로 올라갔는데 전압이 오히려 떨어지면 모터 제어나 로봇 제어 루프에서 발산 진동이 발생하여 기계가 폭주합니다.

A/D Conversion Sampling & Quantization

아날로그-디지털 변환(ADC)과 표본화 정리

나이퀴스트-섀넌 표본화 정리, 앨리어싱(Aliasing) 및 양자화 잡음 공식

📌 나이퀴스트 표본화 정리 & 앨리어싱
$$f_s \ge 2 f_{\max} \quad (f_s: \text{Sampling Rate})$$
• 신호의 최고 주파수 $f_{\max}$의 2배 이상으로 샘플링해야 원래 신호를 왜곡 없이 완벽 복원 가능.
• 앨리어싱 (Aliasing): $f_s < 2 f_{\max}$일 때 고주파 성분이 저주파 잡음으로 왜곡 복원되는 현상.
• 안티앨리어싱 필터 (AA Filter): ADC 입력단 직전에 $f_s/2$ 이상의 고주파를 차단하는 LPF 필수 장착!
📌 양자화 오차와 신호 대 잡음비 (SNR)
• 연속적인 전압을 이산적 디지털 값으로 반올림할 때 필연적으로 발생하는 오차:
$$\text{최대 양자화 오차} = \pm \frac{1}{2} \text{LSB} = \pm \frac{V_{\text{FS}}}{2(2^n - 1)}$$
• 이론적 최대 신호 대 양자화 잡음비 (SQNR):
$$\text{SNR} = 6.02 imes N + 1.76\text{ dB}$$
➔ 비트 수($N$)가 1비트 늘어날 때마다 음질/정밀도가 약 **$6\text{dB}$ (2배)**씩 향상!

[디지털 오디오 16비트 44.1kHz의 비밀]

인간 가청 주파수 상한이 $20\text{kHz}$이므로 나이퀴스트 정리에 따라 $f_s > 40\text{kHz}$가 필요하여 CD 표준이 $44.1\text{kHz}$로 정해졌습니다.

16비트 해상도는 $\text{SNR} = 6.02 imes 16 + 1.76 \approx 98\text{dB}$의 경이로운 다이내믹 레인지를 제공합니다.

Architecture Comparison Flash vs Successive Approx

Flash ADC vs SAR ADC 아키텍처 비교

병렬 비교기를 이용한 1클록 최고속 변환과 이진 탐색(Binary Search) 기반 고효율 변환

📌 Flash ADC (병렬 비교형: 초고속)

$(2^n - 1)$개의 아날로그 비교기(LM339)와 우선순위 인코더 결합

$$\text{변환 속도: 단 1 클록 (수백 MHz } \sim \text{GHz)}$$
  • 장점: 현존하는 가장 빠른 ADC 구조 (오실로스코프, 레이더)
  • 단점: 8비트만 되어도 255개 비교기 필요 ➔ 면적/전력 소모 지수적($2^n$) 급증
📌 SAR ADC (축차 비교형: 고효율 범용)

비교기 1개 + SAR 로직 + 내부 DAC를 이용한 이진 탐색(Binary Search)

$$\text{변환 시간: 정확히 } N \text{ 클록 소요}$$
  • MSB(절반 전압)부터 1을 넣어보고 비교 ➔ 크면 1 유지, 작으면 0 리셋을 반복하여 LSB까지 결정
  • 장점: 비교기 1개로 $8 \sim 18$비트 고해상도 구현, 저전력·저비용 (MCU/ADC0804 표준)

[스무고개 게임과 SAR ADC]

SAR ADC는 마치 1부터 100까지 숫자 맞추기(스무고개)에서 "50보다 큽니까? $ o$ 75보다 큽니까?" 하며 범위를 절반씩 좁혀나가는 이진 탐색 알고리즘을 하드웨어로 구현한 것입니다.

📌 ADC0804 제어 타이밍 시퀀스
• Step 1: 변환 시작
$\overline{CS}=0$ 상태에서 $\overline{WR}$에 음의 펄스(LOW $ o$ HIGH)를 인가하면 SAR 내부 레지스터 리셋 및 변환 개시.
• Step 2: SAR 이진 탐색 진행 (약 $100\mu\text{s}$ 소요)
• Step 3: 변환 완료 인터럽트
변환이 끝나면 $\overline{INTR}$ 핀이 자동으로 **LOW(0V)**로 떨어짐.
• Step 4: 데이터 버스 읽기
$\overline{RD}$를 LOW로 당겨 3상태 버퍼를 열고 $DB_0 \sim DB_7$ 데이터 읽기.

[ADC0804 자가 연속 변환(Free-Running) 모드]

실험실에서 마이크로컨트롤러 없이 빵판에서 계속 변환하려면 $\overline{INTR}$ 출력을 $\overline{WR}$ 입력에 직결하면 됩니다.

변환이 끝나는 즉시($\overline{INTR}=0$) 다음 변환 시작 펄스($\overline{WR}=0$)를 스스로 넣어 무한 연속 샘플링이 가능합니다.

Lab Secrets & Exam Mixed-Signal Q&A

기억소자·신호변환 트러블슈팅 & 퀴즈 3선

아날로그/디지털 접지 분리 원칙 및 시험/면접 단골 문제

Q1 AGND vs DGND 분리

질문: ADC에서 아날로그 접지(AGND)와 디지털 접지(DGND)를 분리하는 이유는?

디지털 스위칭 시 접지선에 흐르는 급격한 스파이크 노이즈가 미세한 아날로그 입력 전압에 유입되어 변환 정밀도를 파괴하는 것을 방지하기 위함입니다.
Q2 8비트 Flash ADC 비교기 수

질문: 8비트 Flash ADC를 만들려면 비교기가 몇 개 필요한가?

$2^8 - 1 = \mathbf{255\text{개}}$의 비교기가 필요합니다. 고해상도로 갈수록 면적과 전력 소모가 극단적으로 커집니다.
Q3 7489 오픈컬렉터 풀업

질문: 7489 RAM 출력에 풀업 저항을 달지 않으면 무슨 일이 생기는가?

내부 풀업 트랜지스터가 없으므로 HIGH 출력 시 핀이 공중에 떠(High-Z) 항상 0V만 측정되어 데이터를 읽을 수 없습니다.

[혼성 신호(Mixed-Signal) 실험 총평]

ADC와 DAC 실험은 미세 전압을 다루므로 빵판 전원선의 노이즈를 잡는 것이 최우선입니다.

AGND와 DGND는 칩 바로 아래에서 단일 접점(Star Ground)으로만 만나도록 결선해야 깨끗한 변환 파형을 얻을 수 있습니다.

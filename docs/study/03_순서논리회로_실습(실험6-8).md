## 📌 1. 30초 핵심 요약: 상태(State)를 기억하는 회로의 본질

```
[조합논리회로] : 현재 입력(X) ───────────────> 현재 출력(Y)     (과거 기억 불가, No Memory)
[순서논리회로] : 현재 입력(X) + 현재 상태(Q) ──> 차기 상태(Q*) + 출력(Y) (양의 피드백 루프로 과거 기억)
```

1. **순서논리회로의 핵심 메커니즘**:
   - 출력의 일부가 다시 입력으로 되돌아오는 **양의 피드백(Positive Feedback)** 루프를 형성하여, 외부 입력이 사라져도 이전의 논리 상태(0 또는 1)를 영구히 보존(쌍안정, Bistable)합니다.
2. **소자의 계층적 발전 흐름**:
   - **SR 래치 (Latch)**: 교차 결합된 게이트로 1비트 기억 $\to$ 금지 입력($S=R=1$ or $\bar{S}=\bar{R}=0$) 존재.
   - **게이트 D 래치**: 인에이블($C$)이 1인 동안 입력이 출력에 그대로 통과하는 **레벨 감응(Level-sensitive / Transparent)** 소자.
   - **플립플롭 (Flip-Flop)**: 클록의 순간적인 상승/하강 전이 시점에만 데이터를 캡처하는 **에지 트리거(Edge-triggered)** 소자로, 레이스 어라운드(Race-around) 문제를 원천 차단.
   - **시프트 레지스터 (Shift Register)**: 플립플롭을 직렬로 연결하여 클록 펄스마다 데이터를 좌/우로 이동 (직병렬 데이터 변환기).
   - **카운터 (Counter)**: 클록 펄스를 계수하여 정해진 순서대로 상태를 순환 (비동기 리플 카운터 vs 동기식 카운터).
   - **유한 상태 기계 (FSM)**: 상태 레지스터 + 차기 상태/출력 조합논리로 구성된 순차 제어 시스템의 궁극체 (Mealy vs Moore).

## 📖 2. 순서논리회로 핵심 이론 완벽 리마인드

### 2.1 기억 소자의 본질: Latch vs Flip-Flop

| 구분 | 래치 (Latch) | 플립플롭 (Flip-Flop) |
| :--- | :--- | :--- |
| **트리거 방식** | **레벨 감응 (Level-Sensitive)**<br>Enable($C$) 신호가 HIGH(또는 LOW)인 구간 전체 | **에지 감응 (Edge-Triggered)**<br>Clock($CP$) 신호가 $0 \to 1$ (상승) 또는 $1 \to 0$ (하강) 전이하는 순간 |
| **투과성 (Transparency)** | **투과적 (Transparent)**: 활성 구간 동안 입력 $D$의 변화가 출력 $Q$에 실시간 전달됨 | **비투과적 (Non-Transparent)**: 클록 에지 순간의 입력만 샘플링되며, 나머지 구간에서는 입력이 변해도 출력 차단 |
| **피드백 회로 적용 시** | 클록 활성 구간 동안 출력이 다시 입력으로 돌아와 상태가 요동치는 **Race-Around 현상 발생 위험** | 에지 시점에만 1회 갱신되므로 피드백 루프를 안전하게 구성 가능 |
| **대표 소자** | 74HC00/02 게이트 래치, 74HC373 (Octal D Latch) | **74HC74** (Dual D-FF), **74HC76** (Dual JK-FF) |

### 2.2 SR 래치: NOR 기반 vs NAND 기반 비교

```
[Active-High NOR SR Latch]                [Active-Low NAND S'R' Latch]
       S ───┤NOR 1├─── Q                        /S ───┤NAND 1├─── Q
            │   ┌─┘                                   │    ┌─┘
            └───┼─┐                                   └────┼─┐
            ┌───┘ │                                   ┌────┘ │
            │   ┌─┘                                   │    ┌─┘
       R ───┤NOR 2├─── Q'                       /R ───┤NAND 2├─── Q'
```

#### (1) NOR 게이트 기반 SR 래치 (Active-High)
- **특성방정식**: $Q^* = S + R'Q \quad (\text{단, } S \cdot R = 0)$
- **동작**:
  - $S=1, R=0 \implies Q=1$ (**Set**)
  - $S=0, R=1 \implies Q=0$ (**Reset**)
  - $S=0, R=0 \implies Q^* = Q$ (**Hold / 불변**)
  - $S=1, R=1 \implies Q=0, Q'=0$ (**금지 입력 / Invalid State**): $Q$와 $Q'$가 서로 반전 관계를 깨뜨림. 이후 $S, R$이 동시에 $0$으로 바뀌면 전파 지연 차이에 의해 최종 상태가 무작위로 결정되는 **Race Condition** 발생.

#### (2) NAND 게이트 기반 $\bar{S}\bar{R}$ 래치 (Active-Low)
- **특성방정식**: $Q^* = S + \bar{R}Q \quad (\text{단, } \bar{S}' \cdot \bar{R}' = 0)$
- **동작**:
  - $\bar{S}=0, \bar{R}=1 \implies Q=1$ (**Set**)
  - $\bar{S}=1, \bar{R}=0 \implies Q=0$ (**Reset**)
  - $\bar{S}=1, \bar{R}=1 \implies Q^* = Q$ (**Hold / 불변**)
  - $\bar{S}=0, \bar{R}=0 \implies Q=1, Q'=1$ (**금지 입력 / Invalid State**)
- *실무 포인트*: TTL 및 CMOS 공정에서는 전자 이동도($\mu_n > \mu_p$) 특성상 NAND 게이트의 면적과 속도가 우수하므로, 대부분의 상용 IC 비동기 제어 핀은 **Active-Low ($\overline{PR}, \overline{CLR}$)** 구조를 채택합니다.

### 2.3 플립플롭 4대 기종 (SR, D, JK, T) 완벽 정리

```
[SR Flip-Flop]       [D Flip-Flop]        [JK Flip-Flop]       [T Flip-Flop]
  ┌─────────┐          ┌─────────┐          ┌─────────┐          ┌─────────┐
S─┤         ├─Q      D─┤         ├─Q      J─┤         ├─Q      T─┤         ├─Q
  │  SR-FF  │          │  D-FF   │          │  JK-FF  │          │  T-FF   │
R─┤         ├─Q'       │         ├─Q'     K─┤         ├─Q'       │         ├─Q'
  │ >CLK    │          │ >CLK    │          │ >CLK    │          │ >CLK    │
  └─────────┘          └─────────┘          └─────────┘          └─────────┘
```

#### (1) 특성표 (Characteristic Table) & 특성방정식 (Characteristic Equation)

| 플립플롭 | 입력 ($t$) | 차기상태 $Q^*$ ($t+1$) | 설명 | 특성방정식 |
| :--- | :--- | :--- | :--- | :--- |
| **SR-FF** | $S=0, R=0$<br>$S=0, R=1$<br>$S=1, R=0$<br>$S=1, R=1$ | $Q$<br>$0$<br>$1$<br>금지(Invalid) | 유지 (No Change)<br>리셋 (Reset)<br>셋 (Set)<br>동시 1 입력 금지 | $Q^* = S + R'Q \quad (SR = 0)$ |
| **D-FF** | $D=0$<br>$D=1$ | $0$<br>$1$ | 리셋 (0 저장)<br>셋 (1 저장) | $Q^* = D$ |
| **JK-FF** | $J=0, K=0$<br>$J=0, K=1$<br>$J=1, K=0$<br>$J=1, K=1$ | $Q$<br>$0$<br>$1$<br>$Q'$ | 유지 (No Change)<br>리셋 (Reset)<br>셋 (Set)<br>**토글 (Toggle / 반전)** | $Q^* = J Q' + K' Q$ |
| **T-FF** | $T=0$<br>$T=1$ | $Q$<br>$Q'$ | 유지 (No Change)<br>**토글 (Toggle / 반전)** | $Q^* = T \oplus Q = T Q' + T' Q$ |

#### (2) 여기표 (Excitation Table: 순서회로 설계 시 필수 암기)
> **여기표의 의미**: 현재 상태($Q$)에서 목표 차기 상태($Q^*$)로 전이시키기 위해 **플립플롭 입력에 무엇을 인가해야 하는가?**

$$\begin{array}{|c|c|c|c|c|c|c|c|}
\hline
\text{현재 상태 } Q & \text{차기 상태 } Q^* & S & R & J & K & D & T \\
\hline
0 & 0 & 0 & X & 0 & X & 0 & 0 \\
0 & 1 & 1 & 0 & 1 & X & 1 & 1 \\
1 & 0 & 0 & 1 & X & 1 & 0 & 1 \\
1 & 1 & X & 0 & X & 0 & 1 & 0 \\
\hline
\end{array}$$

- *암기 팁*:
  - **D-FF**: $D = Q^*$ (무조건 차기 상태값 그대로 복사).
  - **T-FF**: $Q \ne Q^*$ 이면 $T=1$, $Q = Q^*$ 이면 $T=0$ ($T = Q \oplus Q^*$).
  - **JK-FF**: $0 \to 0$은 $0X$, $0 \to 1$은 $1X$, $1 \to 0$은 $X1$, $1 \to 1$은 $X0$. ($J$는 $0\to 1$ 활성화, $K$는 $1\to 0$ 활성화).

### 2.4 주종형(Master-Slave) 플립플롭과 1's Catching 현상

```
                  ┌───────────────┐         ┌───────────────┐
     J/S/D ───────┤               ├──── Y ──┤               ├────── Q
                  │ Master Latch  │         │  Slave Latch  │
     K/R ─────────┤ (Active C=1)  │         │ (Active C=0)  │
                  └───────┬───────┘         └───────┬───────┘
                          │                         │
       CLK ───────────────┴───────────[NOT]─────────┘
```

1. **동작 원리 (2단 래치 직렬 결선)**:
   - $\text{CLK} = 1$ (High): 마스터 래치가 활성화되어 외부 입력($J, K$)을 읽어 중간 노드 $Y$를 결정. 슬레이브 래치는 비활성화 ($Q$는 이전 값 유지).
   - $\text{CLK} = 0$ (Low): 마스터 래치가 비활성화되어 외부 입력을 차단. 슬레이브 래치가 활성화되어 중간 노드 $Y$의 값을 최종 출력 $Q$로 전달.
2. **1's Catching (일 포획) 현상과 치명적 결함**:
   - 펄스 트리거형(Pulse-triggered) 주종 JK-FF의 마스터 래치는 $\text{CLK}=1$인 구간 **전체**에 걸쳐 입력을 받아들입니다.
   - 만약 $\text{CLK}=1$인 동안 $J$ 입력 선에 아주 짧은 노이즈 펄스(Glitch) '1'이 유입되면, 마스터 래치의 피드백 특성상 즉시 1을 포획(Latch)하여 노이즈가 사라진 후에도 $Y=1$로 유지됩니다.
   - 결국 클록 하강 에지에서 원치 않는 '1'이 슬레이브 출력 $Q$에 반영되어 데이터가 오염됩니다.
3. **현대 디지털 회로의 해결책**:
   - 주종형 대신 에지 시점($\approx 1\sim 2\text{ ns}$)에만 입력 창이 열리는 **완전 에지 트리거(Edge-Triggered with Pulse Transition Detector)** 소자를 표준으로 사용합니다.

### 2.5 비동기 입력 ($\overline{PR}, \overline{CLR}$)의 최우선 동작 원리

플립플롭에는 동기 입력($D, J, K, T$) 외에 비동기 제어 핀인 **Active-Low Preset ($\overline{PR}$)** 및 **Clear ($\overline{CLR}$)**가 제공됩니다.

$$\begin{array}{|cc|c|c|c|l|}
\hline
\overline{PR} & \overline{CLR} & \text{CLK} & \text{동기 입력}(D / J,K) & Q^* & \text{동작 모드} \\
\hline
\mathbf{0} & \mathbf{1} & X & X & \mathbf{1} & \textbf{비동기 프리셋 (Asynchronous Set, 즉시 Q=1)} \\
\mathbf{1} & \mathbf{0} & X & X & \mathbf{0} & \textbf{비동기 클리어 (Asynchronous Reset, 즉시 Q=0)} \\
0 & 0 & X & X & 1 & \text{불안정/금지 상태 (동시 해제 시 레이스 발생)} \\
\mathbf{1} & \mathbf{1} & \uparrow & \text{적용} & \text{동기 동작} & \textbf{정상 클록 동작 모드 (Normal Operation)} \\
\hline
\end{array}$$

> [!IMPORTANT]
> **실험 시 필수 주의사항**:
> 비동기 핀은 내부 래치 게이트에 직접 연결되므로 **클록($\text{CLK}$) 및 동기 입력보다 항상 절대적인 최우선권(Dominant)**을 가집니다. 따라서 정상적인 플립플롭/카운터 실습을 진행하려면 **$\overline{PR}$과 $\overline{CLR}$ 핀을 반드시 $+5\text{V}$ (VCC)에 연결(Pull-Up)**해야 합니다. 플로팅 상태로 두면 공기 중 노이즈로 인해 수시로 원치 않는 리셋이 발생합니다.

### 2.6 디지털 타이밍 파라미터와 준안정성 (Metastability)

```
        ◄─────────── Setup / Hold Time Window ───────────►
                              │
                    ┌─────────┼─────────┐
   D Input: ────────┤  STABLE │  STABLE ├──────── (변경 금지 구역)
                    └─────────┼─────────┘
                              │
   Clock (CLK): ──────────────┼───▲───────────────────────────────
                              │   │ (Active Clock Edge)
                              ◄t_su►
                                  ◄t_h►
                                  │
                                  │◄─── t_co ───►
   Q Output: ─────────────────────┴─────────────┌────────────────
                                                │ STABLE NEW VALUE
```

#### (1) 핵심 타이밍 정의
1. **셋업 시간 ($t_{su}$, Setup Time)**: 클록 유효 에지가 발생하기 **직전**까지 데이터 입력이 안정적으로 유지되어야 하는 최소 시간.
2. **홀드 시간 ($t_h$, Hold Time)**: 클록 유효 에지가 발생한 **직후**까지 데이터 입력이 변하지 않고 유지되어야 하는 최소 시간.
3. **클록-투-출력 지연 ($t_{co}$, Clock-to-Output Delay)**: 유효 클록 에지 발생 순간부터 플립플롭 출력 $Q$에 새로운 유효 논리값이 나타날 때까지 걸리는 전파 지연.

#### (2) 최대 동작 주파수 ($f_{\max}$) 및 타이밍 마진 수식
- **셋업 시간 제약 (Setup Constraint / Max-Delay)**:
  데이터가 다음 클록 에지 전까지 조합논리($t_{comb}$)를 거쳐 도착해야 함.

$$T_{clk} \ge t_{co(\max)} + t_{comb(\max)} + t_{su}$$

$$f_{\max} = \frac{1}{T_{clk,\min}} = \frac{1}{t_{co(\max)} + t_{comb(\max)} + t_{su}}$$

- **홀드 시간 제약 (Hold Constraint / Min-Delay)**:
  현재 클록에 의해 변경된 새로운 데이터가 너무 빨리 다음 플립플롭으로 전파되어 현재 플립플롭의 홀드 윈도우를 파괴해서는 안 됨.

$$t_{co(\min)} + t_{comb(\min)} \ge t_h$$

> [!WARNING]
> **홀드 시간 제약의 특수성**:
> 홀드 시간 공식에는 클록 주기 $T_{clk}$ 항이 전혀 없습니다! 즉, 회로에 홀드 타임 위반(Hold Violation)이 발생하면 **클록 주파수를 아무리 낮추어도(Slow Clock) 에러가 해결되지 않습니다.** 반드시 데이터 경로에 지연 버퍼(Buffer)를 물리적으로 추가해야만 해결됩니다.

#### (3) 준안정성 (Metastability)
- 셋업/홀드 윈도우 내부에서 입력 신호가 전이되면 내부 래치가 $0$도 $1$도 아닌 중간 전압($V_{DD}/2$)에 머무르는 준안정 상태에 빠집니다.
- 준안정 상태에서 정상 논리 레벨로 복귀하는 데 걸리는 시간($t_{res}$)은 확률적이므로 시스템 다운을 초래합니다.
- **해결책**: 외부 비동기 신호는 반드시 **2단 플립플롭 동기화기(2-stage Synchronizer)**를 거쳐 시스템 클록에 정렬시킵니다.

### 2.7 시프트 레지스터 4대 분류 및 양방향 동작

```
(a) SISO (Serial-In Serial-Out)   : [D_in] ──> [FF0] ──> [FF1] ──> [FF2] ──> [FF3] ──> [D_out]
(b) SIPO (Serial-In Parallel-Out)  : [D_in] ──> [FF0] ──> [FF1] ──> [FF2] ──> [FF3]
                                                  │         │         │         │
                                                  ▼         ▼         ▼         ▼
                                                 [Q0]      [Q1]      [Q2]      [Q3]
(c) PISO (Parallel-In Serial-Out)  : [D0..D3] ─> (Mux Load) ─> [FF 체인] ─> [D_out]
(d) PIPO (Parallel-In Parallel-Out): [D0..D3] ─> [FF0..FF3] ─> [Q0..Q3] (데이터 레지스터 버퍼)
```

1. **SISO**: $N$비트 데이터를 1개 핀으로 송수신 (데이터 지연선, 버퍼). $N$비트 입출력에 $2N$ 클록 소요.
2. **SIPO**: 직렬 통신 데이터를 병렬 버스 데이터로 변환 (UART 수신기 구조, `실험 7`).
3. **PISO**: 병렬 버스 데이터를 직렬 통신 라인으로 변환 (UART 송신기 구조).
4. **PIPO**: 1클록에 병렬 로드 및 동시 병렬 출력 (CPU 범용 레지스터).

#### 양방향 범용 시프트 레지스터 (74194) 제어 모드

$$\begin{array}{|cc|l|l|}
\hline
S_1 & S_0 & \text{동작 모드} & \text{상세 설명} \\
\hline
0 & 0 & \text{유지 (Hold)} & \text{클록이 인가되어도 } Q_0 \sim Q_3 \text{ 상태 불변} \\
0 & 1 & \text{우측 시프트 (Shift Right)} & D_{SR} \to Q_0 \to Q_1 \to Q_2 \to Q_3 \\
1 & 0 & \text{좌측 시프트 (Shift Left)} & D_{SL} \to Q_3 \to Q_2 \to Q_1 \to Q_0 \\
1 & 1 & \text{병렬 로드 (Parallel Load)} & \text{병렬 입력 } A, B, C, D \text{가 } Q_0 \sim Q_3\text{로 동시 로드} \\
\hline
\end{array}$$

### 2.8 링 카운터 vs 존슨 카운터 비교

```
[4-bit Ring Counter: 4 States]
   ┌────────────────────────────────────────────────────────┐
   │                                                        │
   └── [FF0 (Q0)] ───> [FF1 (Q1)] ───> [FF2 (Q2)] ───> [FF3 (Q3)]
   상태 전이: 1000 ──> 0100 ──> 0010 ──> 0001 ──> 1000 ...

[4-bit Johnson (Twisted-Ring) Counter: 8 States]
   ┌────────────────────────────────────────────────────────┐ (Inverted Feedback)
   │  ┌──────────────────────────────────────────────────┐  │
   └──┼── [FF0 (Q0)] ───> [FF1 (Q1)] ───> [FF2 (Q2)] ───> [FF3 (Q3)]
      └───────────────────────────────────────────────────── Q3' ───┘
   상태 전이: 0000 ─> 1000 ─> 1100 ─> 1110 ─> 1111 ─> 0111 ─> 0011 ─> 0001 ─> 0000 ...
```

| 비교 항목 | 링 카운터 (Ring Counter) | 존슨 카운터 (Johnson Counter) |
| :--- | :--- | :--- |
| **피드백 결선** | 최종단 정출력 $Q_{N-1}$을 첫단 $D_0$에 연결 ($D_0 = Q_{N-1}$) | 최종단 반전출력 $\bar{Q}_{N-1}$을 첫단 $D_0$에 연결 ($D_0 = \bar{Q}_{N-1}$) |
| **유효 상태 수** | **$N$ 개** (Modulo-$N$) | **$2N$ 개** (Modulo-$2N$) |
| **상태 인코딩** | 1-Hot 인코딩 ($1000 \to 0100 \to \dots$) | 특수 Gray 코드 (인접 비트가 1개씩 순차 반전) |
| **디코딩 회로** | **완전 불필요** (출력 핀 $Q_i$ 자체가 상태 신호) | **2입력 AND 게이트 $2N$개**로 글리치 없이 완전 디코딩 |
| **미사용 상태 수** | $2^N - N$ 개 (매우 많음) | $2^N - 2N$ 개 |
| **자기 기동성 (Self-Starting)** | ❌ 노이즈로 $0000, 1100$ 등 진입 시 영구 락업(Lockup) | ❌ 미사용 루프에 갇힐 경우 영구 락업 위험 |
| **자가 복구 회로 (Self-Correction)** | $D_0 = (Q_1 + Q_2 + \dots + Q_{N-1})'$ (NOR 게이트 피드백) | $D_0 = \bar{Q}_{N-1} \cdot (\text{미사용 상태 검출 논리})$ |

---

### 2.9 비동기(Ripple) 카운터 vs 동기식(Synchronous) 카운터

```
[비동기 3-bit Ripple Counter]
   Clock ──> [CLK0]        Q0 ──> [CLK1]        Q1 ──> [CLK2]
             [FF0 (T=1)]          [FF1 (T=1)]          [FF2 (T=1)]
             [Q0 (LSB) ]          [Q1       ]          [Q2 (MSB) ]
   (전파지연 누적: t_total = 3 * t_pd)

[동기식 3-bit Synchronous Counter]
   Clock ────┬────────────────────┬────────────────────┐
             ▼                    ▼                    ▼
          [CLK0]               [CLK1]               [CLK2]
          [FF0 (T=1)]          [FF1 (T=Q0)]         [FF2 (T=Q0·Q1)]
          [Q0 (LSB) ]          [Q1        ]         [Q2 (MSB)     ]
                                  │                    ▲
                                  └────────[AND]───────┘
   (전파지연 단일화: t_total = t_pd + t_and)
```

1. **비동기식 (Ripple) 카운터**:
   - 첫 번째 플립플롭에만 시스템 클록이 연결되고, 다음 단 플립플롭들은 이전 단의 출력($Q$ 또는 $Q'$)을 자신의 클록으로 사용합니다.
   - **문제점 1 (전파 지연 누적)**: $N$단 카운터의 총 지연은 $N \cdot t_{pd}$. 비트 수가 커지면 고속 클록에서 카운팅 에러 발생.
   - **문제점 2 (디코딩 글리치, Glitch)**: $011_2 (3) \to 100_2 (4)$ 전이 시, $Q_0 \to 0$ ($010$), $Q_1 \to 0$ ($000$), $Q_2 \to 1$ ($100$) 순서로 비트가 순차적으로 바뀌면서 과도 상태 동안 원치 않는 스파이크 펄스가 발생하여 다운스트림 회로를 오작동시킴.
2. **동기식 (Synchronous) 카운터**:
   - 모든 플립플롭이 **동일한 시스템 클록을 병렬로 공유**하여 동시에 상태가 전이됩니다.
   - 각 플립플롭의 입력($T_i$ 또는 $J_i, K_i$)은 이전 모든 비트가 1일 때만 1이 되도록 AND 캐리 체인을 구성합니다 ($T_i = Q_0 \cdot Q_1 \cdots Q_{i-1}$).
   - 총 전파 지연이 1단 플립플롭 지연 + 게이트 지연으로 일정하여 고속 동작에 적합합니다.

### 2.10 7490 10진 카운터, 7447 디코더 & FND 507 7-Segment 아키텍처

```
       ┌──────────────────────── 7490 Decade Counter ────────────────────────┐
       │                                                                      │
CLK ───┤> CK_A (Pin 14) ──> [Mod-2 Counter] ──> Q_A (Pin 12)                  │
       │                                           │ (외부 점퍼선 결선)       │
       │                                           ▼                          │
       │                    [Mod-5 Counter] <── CK_B (Pin 1)                  │
       │                           │                                          │
       │                           ├──> Q_B (Pin 9)                           │
       │                           ├──> Q_C (Pin 8)                           │
       │                           └──> Q_D (Pin 11)                          │
       │                                                                      │
       │  Reset Pins: MR1, MR2 (Pins 2, 3) ──> GND 인가 (정상 카운팅)          │
       │  Set Pins  : MS1, MS2 (Pins 6, 7) ──> GND 인가 (정상 카운팅)          │
       └──────────────────────────────────────────────────────────────────────┘
                                   │
                           BCD Bus (QA..QD)
                                   ▼
       ┌──────────────────────── 7447 Decoder ───────────────────────────────┐
       │  Inputs: A, B, C, D (Active-High BCD)                                │
       │  Control: BI/RBO, RBI, LT (Active-Low, 정상표시 시 VCC에 풀업)        │
       │  Outputs: a, b, c, d, e, f, g (Active-Low Open-Collector)            │
       └──────────────────────────────────────────────────────────────────────┘
                                   │
                         Active-Low Segment Bus (a~g)
                                   ▼ 330Ω 저항 7개 직렬
       ┌────────────────────── FND 507 Display ───────────────────────────────┐
       │  Common Anode (공통 양극: Pin 3, 8 ──> +5V VCC 연결)                 │
       │  7447 출력이 LOW가 될 때 전류 싱크(Sink)가 발생하여 LED 점등           │
       └──────────────────────────────────────────────────────────────────────┘
```

1. **7490 Decade Counter 구성 원리**:
   - 내부가 **Mod-2 카운터 (A)**와 **Mod-5 카운터 (B, C, D)**의 독립된 2블록으로 분리되어 있습니다.
   - 외부 클록을 $\text{CK}_A$ (Pin 14)에 넣고, $Q_A$ (Pin 12)의 출력을 $\text{CK}_B$ (Pin 1)에 점퍼선으로 연결하면 **$2 \times 5 = 10\text{진 (BCD 카운터)}$**로 동작합니다.
   - 리셋 단자 $MR_1, MR_2$ (Pins 2, 3)와 셋 단자 $MS_1, MS_2$ (Pins 6, 7)를 모두 **GND**에 연결해야 $0 \sim 9$ 순차 계수가 진행됩니다.
2. **7447 디코더 & FND 507 매칭**:
   - **7447**: BCD 입력을 받아 7세그먼트 구동 신호($a \sim g$)를 출력하며, **Active-Low Open-Collector** 구조입니다.
   - **FND 507**: **Common Anode (공통 양극)** 타입으로 공통 핀(3, 8번)에 $+5\text{V}$를 연결하고 각 세그먼트 단자에 7447 출력을 저항($330\ \Omega$)을 거쳐 연결합니다. 7447이 0(LOW)을 출력하면 LED에 전류가 흘러 불이 켜집니다.

### 2.11 유한 상태 기계 (FSM: Mealy vs Moore) & 8단계 설계 방법론

```
[Mealy Machine]
   Inputs (X) ──┬─────────────────> [Combinational Logic] ───────────────> Outputs (Z)
                │                         ▲          ▲                            ▲
                ▼                         │          │                            │
             [Next State Logic] ──────────┘          └────── (Direct Feedthrough) ┘
                    │
                    ▼
             [State Registers] ──── (Present State Q)
             
[Moore Machine]
   Inputs (X) ──> [Next State Logic] ──> [State Registers] ──> [Output Logic] ──> Outputs (Z)
                                                 │
                                                 └─────────────── (State Only)
```

| 비교 항목 | 밀리 머신 (Mealy Machine) | 무어 머신 (Moore Machine) |
| :--- | :--- | :--- |
| **출력 결정 수식** | $Z(t) = G(S(t), X(t))$ (현재 상태와 현재 입력 모두에 의존) | $Z(t) = G(S(t))$ (오직 현재 상태에만 의존) |
| **타이밍 및 글리치** | 입력 신호의 노이즈/글리치가 즉시 출력에 전달됨 (빠른 반응) | 출력이 클록 에지에 동기화된 상태 변수에서만 유도되므로 **Glitch-free (안정적)** |
| **필요 상태 수** | 무어 머신보다 **상태 수가 적거나 같음** | 밀리 머신보다 **상태 수가 1개 이상 많을 수 있음** |

#### FSM 8단계 표준 설계 절차
1. **[단계 1] 사양 정의 및 상태도(State Diagram) 작성**: 문제 요구조건을 원(상태)과 화살표(전이 조건/출력)로 도시.
2. **[단계 2] 상태표(State Table) 작성**: 현재 상태($Q$), 입력($X$), 차기 상태($Q^*$), 출력($Z$)을 정형화.
3. **[단계 3] 상태 축소 (State Minimization)**: Implication Table(상태 축소 삼각표)을 사용하여 중복 등가 상태 합병.
4. **[단계 4] 상태 할당 (State Assignment)**: 기호 상태($A, B, C \dots$)에 2진 비트 코드 할당 ($m = \lceil \log_2 N \rceil$).
5. **[단계 5] 플립플롭 기종 선정 및 여기표 매핑**: D, JK, T 플립플롭의 여기표에 따라 플립플롭 입력 조건 열 작성.
6. **[단계 6] 카르노 맵 간략화**: 플립플롭 입력식 및 회로 출력식을 최소 SOP 형태로 간소화.
7. **[단계 7] 회로도(Schematic) 결선**: 게이트와 플립플롭 결선도 완성.
8. **[단계 8] 미사용 상태 분석 (Unused State & Self-Starting 검증)**: $2^m - N$개의 잉여 상태에 빠졌을 때 정상 루프로 자동 복귀하는지 검증.

### 3.2 필수 보조 회로: SR 래치 스위치 디바운서 (Debouncer)

기계식 푸시버튼이나 토글스위치는 접점이 닫힐 때 수 밀리초($\text{ms}$) 동안 수십 번 튀는 **채터링(Bouncing)** 노이즈를 발생시킵니다. 이를 플립플롭의 클록 신호에 직접 인가하면 버튼을 한 번 눌렀을 때 수십 번 카운팅되는 오작동이 일어납니다.

```
       +5V ────────[ 10kΩ 저항 ]─────┬────────── 1번 핀 (/S)
                                     │
                 [ SPDT Switch ] ────┘      ┌──┤NAND 1├─── Q (Debounced Clean Clock)
                   (A단자: Set)             │  │   ┌─┘
                                            └──┼───┼─┐
                                            ┌──┼───┘ │
                   (B단자: Reset)           │  │   ┌─┘
                 [ SPDT Switch ] ────┐      └──┤NAND 2├─── Q'
                                     │
       +5V ────────[ 10kΩ 저항 ]─────┴────────── 2번 핀 (/R)
```

- **원리**: 스위치가 A 접점에 처음 닿는 순간 즉시 래치가 Set($Q=1$)되며, 이후 스위치가 공중에서 튀며 접촉이 끊어져도 Hold 모드($\bar{S}=\bar{R}=1$)가 되어 $Q=1$을 유지합니다. 반대편 B 접점에 완전히 닿기 전까지는 출력이 절대 반전되지 않으므로 완벽한 단일 펄스(Clean Clock)를 얻을 수 있습니다.

## 🎯 4. 예비보고서 & 퀴즈 단골 질문 Q&A (족보 적중)

### Q1. Latch와 Flip-Flop의 차이점을 클록 트리거 방식과 투과성(Transparency) 관점에서 설명하라.
- **모범 답안**:
  1. **트리거 방식**: 래치(Latch)는 인에이블($C$) 신호가 활성화되어 있는 전 구간 동안 동작하는 **레벨 감응(Level-sensitive)** 소자이고, 플립플롭(Flip-Flop)은 클록 신호가 LOW에서 HIGH로 바뀌는 상승 에지 또는 HIGH에서 LOW로 바뀌는 하강 에지 순간에만 동작하는 **에지 감응(Edge-triggered)** 소자이다.
  2. **투과성 (Transparency)**: 래치는 활성 레벨 구간 동안 입력 $D$의 모든 변화가 출력 $Q$에 실시간으로 통과(Transparent)하여 반영되므로 피드백 루프 구성 시 한 클록 주기 내에 상태가 여러 번 바뀌는 Race-around 현상이 발생할 수 있다. 반면 플립플롭은 클록 에지 순간에만 입력을 샘플링하고 나머지 구간에서는 입력이 완전히 차단되는 비투과적(Non-transparent) 특성을 가지므로 피드백 순서논리회로를 안정적으로 구성할 수 있다.

### Q2. 비동기 리플 카운터(Ripple Counter)를 글리치(Glitch) 없이 고속으로 동작시키기 어려운 이유와, 동기식 카운터의 해결책을 설명하라.
- **모범 답안**:
  1. **이유**: 비동기 리플 카운터는 각 플립플롭의 클록이 이전 단 플립플롭의 출력에 연결되어 전파 지연($t_{pd}$)이 $N$개 플립플롭에 걸쳐 **$N \cdot t_{pd}$로 누적**된다. 이로 인해 상태 전이 시(예: $011_2 \to 100_2$) 각 비트가 동시에 변하지 않고 $011 \to 010 \to 000 \to 100$과 같은 과도 상태를 거치면서 디코딩 출력에 원치 않는 스파이크 펄스인 **디코딩 글리치(Glitch)**가 발생하며, 클록 주파수가 높아지면 카운팅 오류가 발생한다.
  2. **동기식 카운터의 해결책**: 모든 플립플롭의 클록 핀을 단일 시스템 클록 라인에 병렬로 공통 연결하여 모든 비트가 **동일한 에지에서 동시에 천이**하도록 설계한다. 각 플립플롭의 입력은 이전 모든 하위 비트들이 1일 때만 1이 되도록 AND 게이트 캐리 체인을 구성하므로 전파 지연이 누적되지 않고 글리치가 제거된다.

### Q3. 7490 IC로 0~9 BCD 10진 카운터를 구성할 때 12번 핀($Q_A$)과 1번 핀($CK_B$)을 점퍼선으로 연결하는 이유를 설명하라.
- **모범 답안**:
  - 7490 IC는 내부에 1개의 **Mod-2 카운터 (Clock A $\to Q_A$)**와 1개의 **Mod-5 카운터 (Clock B $\to Q_B, Q_C, Q_D$)**가 완전히 분리되어 집적되어 있다.
  - 10진(Decade / BCD) 카운터는 $2 \times 5 = 10$진수로 동작해야 하므로, 외부 시스템 클록을 14번 핀($CK_A$)에 인가하고, Mod-2의 최종 출력인 **12번 핀($Q_A$, LSB)**을 Mod-5 카운터의 클록 입력인 **1번 핀($CK_B$)**에 직렬 연결함으로써 전체 회로가 $0000_2(0) \sim 1001_2(9)$의 10가지 상태를 순차적으로 카운팅하는 BCD 카운터로 완성된다.

### Q4. 주종형(Master-Slave) 플립플롭에서 발생하는 1's Catching 현상의 원인과 이를 방지하기 위한 현대 디지털 회로의 설계 방식을 서술하라.
- **모범 답안**:
  - **원인**: 마스터 래치가 활성화되는 $\text{CLK}=1$ 구간 동안 $J$ 입력에 일시적인 노이즈 글리치('1')가 유입되면 마스터 래치가 이를 즉시 캡처하여 노이즈가 사라진 후에도 내부 상태를 '1'로 유지(Catch)하게 되고, 이후 하강 에지에서 슬레이브 출력으로 전달되어 잘못된 값이 출력된다.
  - **방지책**: 레벨 기반의 주종 구조 대신, 상승/하강 에지 시점($1\sim 2\text{ ns}$)의 극히 짧은 윈도우에서만 입력을 샘플링하고 나머지 구간은 완전히 격리시키는 **에지 트리거(Edge-Triggered) 플립플롭**을 사용한다.

### Q5. 링 카운터와 존슨(트위스트 링) 카운터의 유효 상태 수, 디코딩 복잡도, 자기 기동성(Self-Starting) 문제를 비교하라.
- **모범 답안**:
  1. **유효 상태 수**: $N$개의 플립플롭을 사용할 때 링 카운터는 **$N$개**, 존슨 카운터는 **$2N$개**의 상태를 가진다.
  2. **디코딩 복잡도**: 링 카운터는 1-Hot 출력이므로 디코더가 **전혀 필요 없고**, 존슨 카운터는 간단한 **2입력 AND 게이트 $2N$개**로 글리치 없이 디코딩할 수 있다.
  3. **자기 기동성**: 두 카운터 모두 전원 인가 시 또는 노이즈로 인해 유효하지 않은 미사용 상태(Unused States)에 진입하면 정상 시퀀스로 돌아오지 못하고 갇히는 **락업(Lockup)** 문제가 발생한다. 이를 방지하기 위해 링 카운터는 첫단 입력에 $D_0 = (Q_1 + Q_2 + \dots + Q_{N-1})'$ 피드백 논리를 추가하여 비정상 상태에서 자동으로 $100\dots 0$으로 복구되도록 자가 복구 회로를 설계해야 한다.

### Q6. 7447 BCD-to-7Segment 디코더와 FND 507을 연결할 때 Common Anode(공통 양극) 타입을 사용해야 하는 전기적 이유를 서술하라.
- **모범 답안**:
  - 7447 디코더 IC의 출력단은 **Active-Low Open-Collector (오픈 컬렉터)** 트랜지스터 구조로 설계되어 있다.
  - 오픈 컬렉터 출력은 출력이 활성화될 때 트랜지스터가 턴온되어 전류를 외부에서 IC 내부로 끌어당기는 **전류 싱크(Current Sink)** 능력은 우수하지만, 자체적으로 HIGH 전압을 밀어내는 전류 소싱(Current Source) 능력은 없다.
  - 따라서 모든 LED 양극이 $+5\text{V}$에 묶여 있는 **Common Anode (공통 양극)** FND 507을 사용해야 7447 출력이 LOW가 될 때 $+5\text{V} \to \text{FND LED} \to 330\ \Omega \text{ 저항} \to 7447\text{ 출력(GND)}$ 경로로 정상적인 점등 전류가 흐르게 된다.

### Q7. 플립플롭 기반 순서회로에서 홀드 시간 위반(Hold Time Violation)이 발생했을 때 클록 주파수를 낮추어도 문제가 해결되지 않는 이유를 수식으로 증명하라.
- **모범 답안**:
  - 플립플롭의 홀드 시간 만족 조건식은 다음과 같다:
    $$t_{co(\min)} + t_{comb(\min)} \ge t_h$$
  - 위 수식에서 확인할 수 있듯이, 홀드 시간 마진은 오직 플립플롭의 최소 전파 지연($t_{co(\min)}$), 조합논리의 최소 지연($t_{comb(\min)}$), 플립플롭 자체의 홀드 시간 요구조건($t_h$)에 의해서만 결정되며 **클록 주기($T_{clk}$)나 클록 주파수($f_{clk}$)와 관련된 항이 전혀 포함되어 있지 않다.**
  - 따라서 클록을 아무리 느리게 동작시켜도 동일한 클록 에지에서 발생한 데이터 전파 속도가 홀드 요구시간보다 빠르면 홀드 위반이 지속되므로, 반드시 데이터 선로에 의도적인 버퍼 지연($t_{comb}$)을 삽입해야만 해결된다.

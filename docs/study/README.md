## ⚡ 실험실 5대 생존 수칙 (실험 전 필독!)

> [!IMPORTANT]
> 1. **VCC와 GND를 먼저 꽂고 시작하라**: 모든 디지털 IC는 핀 14(또는 16)에 $+5\text{V}$, 핀 7(또는 8)에 $\text{GND}$가 연결되어야 동작합니다. 가장 흔한 실수는 전원 핀을 빼먹는 것입니다.
> 2. **CMOS 입력 핀을 절대 허공에 띄우지 마라 (No Floating Inputs)**: CMOS 게이트의 미사용 입력 핀을 오픈(Open) 상태로 두면 공기 중 정전기/노이즈를 흡수하여 $V_{DD}/2$ 부근에 머물게 되고, 내부 NMOS/PMOS가 동시 턴온되어 과전류와 발열이 발생합니다. 반드시 $V_{CC}$나 $\text{GND}$에 묶거나 풀업/풀다운 저항을 연결하세요.
> 3. **LED에는 반드시 $330\,\Omega \sim 1\,\text{k}\Omega$ 전류 제한 저항을 직렬 연결하라**: 저항 없이 게이트 출력을 LED 다이렉트로 연결하면 과전류로 IC 또는 LED가 소손됩니다.
> 4. **신호 결선은 전원을 끈(Power OFF) 상태에서 진행하라**: 전원이 켜진 채로 와이어를 꽂거나 뽑으면 쇼트(Short)로 인해 전원 공급기(Power Supply)가 트립되거나 IC 내부 게이트가 파괴될 수 있습니다.
> 5. **Active-Low 신호(버블/Bar 표기)를 주의하라**: $\overline{CLR}$, $\overline{PR}$, $\overline{G}$ 등 상단에 바($\overline{\ \ }$)가 붙어있거나 버블($\circ$)이 달린 핀은 $0\text{V}(\text{LOW})$일 때 활성화됩니다. 정상 동작을 시키려면 이 핀들에 $+5\text{V}(\text{HIGH})$를 걸어두어야 합니다.

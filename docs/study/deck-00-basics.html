💡 게이트별 실전 직관

AND: 깐깐한 직렬 스위치 (둘 다 1이어야 1)

OR: 관대한 병렬 스위치 (하나라도 1이면 1)

NAND/NOR: 반전 출력 범용 게이트

XOR ($A \oplus B$): 가산기 합($S$) 생성

XNOR ($A \odot B$): 디지털 비교기(Comparator)

[7대 게이트 실전 포인트]

XOR ($A \oplus B = \bar{A}B + A\bar{B}$): 가산기(Adder)의 Sum 비트이자 비트 반전 제어기($B \oplus 0 = B$, $B \oplus 1 = \bar{B}$)로 4비트 가감산기(74HC283)에서 핵심 역할을 합니다.

XNOR ($A \odot B = AB + \bar{A}\bar{B}$): 두 신호가 완벽히 같을 때만 1을 출력하므로 주소 디코더나 데이터 일치 검사기에 사용됩니다.

Universal Logic NAND / NOR Synthesis

범용 게이트(Universal Gate)의 원리와 구현

NAND 또는 NOR 게이트 단 한 종류만으로 모든 논리 회로를 완전 합성하는 방법

1 NOT 게이트 구현

두 입력을 하나로 묶어 입력

$$\overline{A \cdot A} = \bar{A}$$
A ──┬──\ └───)o── Y = A' 74HC00
2 AND 게이트 구현

NAND 출력 뒤에 NOT(NAND) 직결

$$\overline{\overline{AB}} = AB$$
A ──\ )o──┬──\ B ──/ └───)o── Y = AB
3 OR 게이트 구현

입력을 반전시켜 NAND에 입력 (드모르간)

$$\overline{\bar{A} \cdot \bar{B}} = A + B$$
A ──▷o─\ )o── Y = A + B B ──▷o─/
★ NAND 게이트 4개로 XOR ($A \oplus B$) 구현하기 (시험 단골)
$$A \oplus B = \overline{ \overline{A \cdot \overline{AB}} \cdot \overline{B \cdot \overline{AB}} }$$

74HC00 IC(Quad 2-input NAND) 1개에 들어있는 4개의 NAND 게이트를 모두 결선하면 별도의 74HC86(XOR) IC 없이 XOR 연산기를 완성할 수 있습니다.

[범용 게이트의 반도체 공학적 중요성]

CMOS 공정에서 NAND 게이트는 NMOS 풀다운이 직렬이고 PMOS 풀업이 병렬이므로, 전자 이동도가 높은 NMOS의 장점을 살려 NOR 게이트보다 면적이 작고 속도가 빠릅니다.

따라서 플래시 메모리(NAND Flash) 및 대다수 ASIC 라이브러리는 기본 셀을 NAND 기반으로 합성합니다.

Boolean Axioms Algebraic Rules

부울 대수 기본 공리 & 필수 연산 규칙

수식 전개의 뼈대: 항등원, 영원, 멱등, 보원, 이중부정과 부울 고유의 분배법칙

📌 5대 기본 공리 (Axioms)
법칙 명칭AND 연산 ($\cdot$)OR 연산 ($+$)
항등원 (Identity)$A \cdot 1 = A$$A + 0 = A$
영원 (Null)$A \cdot 0 = 0$$A + 1 = 1$
멱등 (Idempotent)$A \cdot A = A$$A + A = A$
보원 (Complement)$A \cdot \bar{A} = 0$$A + \bar{A} = 1$
이중부정 (Involution)$\overline{\overline{A}} = A$
★ 주의: 부울 대수 특이 분배법칙

일반 대수에서는 성립하지 않지만 부울 대수에서는 반드시 성립하는 핵심 정리입니다.

$$A + BC = (A + B)(A + C)$$
[증명 전개]:
$(A + B)(A + C) = AA + AC + BA + BC$
$= A + A(C + B) + BC = A(1 + C + B) + BC$
$= A \cdot 1 + BC = \mathbf{A + BC}$ (Q.E.D)

[부울 대수 공리 강의 팁]

$A + BC = (A+B)(A+C)$는 논리식을 POS(최대항 곱) 형태로 변환하거나 복잡한 곱의 합 형태를 인수분해할 때 필수적으로 쓰입니다. 퀴즈에서 많은 학생들이 일반 수학 공식과 혼동하여 틀리므로 강조해 주십시오.

Essential Theorems De Morgan & Bubble Pushing

4대 필수 정리 & 버블 푸싱(Bubble Pushing)

흡수 법칙, 합의 정리(Consensus), 드모르간 정리와 회로도 시각적 변환 테크닉

1 흡수 법칙 & 합의 정리

흡수 법칙 (Absorption): 잉여 항을 흡수하여 제거

$$A + AB = A \quad \Big| \quad A + \bar{A}B = A + B$$

합의 정리 (Consensus Theorem):

$$AB + \bar{A}C + BC = AB + \bar{A}C$$

* $BC$항은 $A=1$일 땐 $AB$가, $A=0$일 땐 $\bar{A}C$가 커버하므로 삭제 가능.

2 드모르간 정리 & 버블 푸싱
$$\overline{AB} = \bar{A} + \bar{B} \quad \Big| \quad \overline{A+B} = \bar{A} \cdot \bar{B}$$
[버블 푸싱 황금률] 1. 게이트 출구의 버블(NAND)을 입구로 밀면 AND ➔ OR로 변환! 2. 신호선 상의 마주보는 버블 2개는 서로 상쇄 (Bubble Cancellation) 3. Active-Low 신호 흐름을 직관적으로 추적 가능

[버블 푸싱(Bubble Pushing)의 실전 위력]

실제 칩 레벨 도면(Schematic)을 볼 때 버블 푸싱을 적용하면 수식을 적지 않고도 "어떤 신호가 LOW로 활성화되어 다음 단을 구동하는지"를 직관적으로 파악할 수 있습니다.

Consensus Theorem은 추후 조합논리 회로에서 타이밍 글리치(Hazard)를 제거하기 위해 일부러 추가하는 항으로 다시 등장합니다.

Arithmetic Logic 2's Complement & Overflow

2진 수체계와 2의 보수(2's Complement) 가감산

부호-절대값 및 1의 보수 한계 극복, 덧셈기 기반 뺄셈 구현 및 오버플로우 판별

📌 2의 보수 변환 및 범위

변환 공식: $N$비트 데이터의 비트를 전부 반전(1의 보수) 후 $+1$

$$-X = \bar{X} + 1$$
  • $N$비트 표현 범위: $-2^{N-1} \sim +(2^{N-1}-1)$
  • 4비트 예: $-8 \sim +7$ ($+0$과 $-0$의 중복 문제 완전 해결)
  • 뺄셈 연산: $A - B = A + (-B) = A + \bar{B} + 1$
★ 오버플로우(Overflow) 판별식

부호 있는 연산에서 결과값이 $N$비트 표현 범위를 초과하여 부호가 왜곡되는 현상입니다.

$$V = C_n \oplus C_{n-1}$$
• $C_n$: 최상위 부호비트(MSB)에서 발생한 최종 캐리
• $C_{n-1}$: 직전 비트에서 MSB로 넘어온 캐리
• 판별: $(+) + (+) = (-)$ 또는 $(-) + (-) = (+)$ 발생 시 $V=1$

[2의 보수 및 오버플로우 강의 팁]

많은 학생들이 캐리 발생($C_{out}=1$)과 오버플로우($V=1$)를 혼동합니다.

구분법: 부호 없는(Unsigned) 연산에서는 $C_{out}=1$이 오버플로우이고, 부호 있는(Signed) 연산에서는 $V = C_n \oplus C_{n-1} = 1$이 오버플로우입니다. 74HC283 가산기 실험에서 반드시 검증하는 항목입니다.

Visual Optimization Karnaugh Map

카르노맵(K-Map) 시각적 간소화 4대 황금률

수식 전개 없이 1과 Don't Care를 $2^n$개 직사각형으로 묶어 최적 간소화식 도출

1 그레이 코드

인접 행/열 간에 단 1비트만 변경되도록 배치:

00 ➔ 01 ➔ 11 ➔ 10

* 01에서 11로 건너뛰는 순서 절대 엄수!

2 $2^n$ 크기 묶기

반드시 1, 2, 4, 8, 16개의 직사각형/정사각형으로 묶음.

❌ 3개, 6개 묶기 절대 금지!

✔ 크게 묶을수록 항이 소거됨.

3 토러스 인접성

맵의 양 끝(좌-우, 상-하)과 4개의 모서리는 서로 맞닿아 있는 인접 셀입니다.

4 모서리 = 1개의 4-묶음
4 Don't Care ($d$)

입력될 수 없는 무효 상태는 $X(d)$로 표기.

• 묶음을 크게 만들 수 있으면 1로 취급
• 아니면 0으로 버림

[K-Map 실전 오류 방지]

1. 반드시 Prime Implicant(주항) 중 Essential Prime Implicant(필수 주항)을 먼저 식별하여 묶습니다.

2. Don't Care는 굳이 다 묶을 필요가 없으며, 1을 묶을 때 크기를 2배로 불려 변수를 날릴 수 있을 때만 포함시킵니다.

Synthesis SOP vs POS Forms

SOP(최소항 합) vs POS(최대항 곱) 합성

출력 1 중심(AND-OR)과 출력 0 중심(OR-AND)의 2단 논리 회로 등가 변환

📌 SOP (Sum of Products)

동작 원리: 출력 $Y=1$인 최소항(Minterm)들을 묶어 OR 결합

$$F(A,B,C) = \sum m(1, 3, 5, 7) = C$$
  • 표준 형태: AND-OR 2단 회로
  • 드모르간 변환: NAND-NAND 회로와 완벽 등가
  • 대부분의 디지털 설계에서 기본 표준으로 채택
📌 POS (Product of Sums)

동작 원리: 출력 $Y=0$인 최대항(Maxterm)들을 묶어 AND 결합

$$F(A,B,C) = \prod M(0, 2, 4, 6) = C$$
  • 표준 형태: OR-AND 2단 회로
  • 드모르간 변환: NOR-NOR 회로와 완벽 등가
  • 진리표에 0이 1보다 현저히 적을 때 훨씬 유리

[SOP와 POS 선택 기준]

진리표에서 1의 개수와 0의 개수를 센 뒤, 1이 많으면 0을 묶어 POS로 전개하거나 $\bar{F}$를 구한 뒤 인버터를 붙이는 것이 게이트 수를 아끼는 비결입니다.

Self Diagnostic 10-Minute Quiz

실험실 투입 전 10분 자가진단 퀴즈 3선

조교 단골 구두 퀴즈 & 시험 대비 필수 실전 문제

Q1 드모르간 변환

문제: $Y = \overline{(A+B)C}$를 NAND 게이트만으로 구현하시오.

정답: Y = \overline{A+B} + \bar{C} = \bar{A}\bar{B} + \bar{C} = \overline{ \overline{\bar{A}\bar{B}} \cdot C }
Q2 2의 보수 오버플로우

문제: 4비트 2의 보수 연산 $(+5) + (+4)$ 수행 시 $C_4$와 $C_3$, $V$는?

0101 + 0100 = 1001 (-7)
C3 = 1, C4 = 0
V = 0 ⊕ 1 = 1 (오버플로우 발생!)
Q3 K-Map 간소화

문제: $F(A,B,C) = \sum m(1,3,5) + d(7)$의 최적 간소화식은?

d(7)을 1로 포함하여
m(1,3,5,7)을 4개 묶음
➔ 정답: F = C

[퀴즈 풀이 및 피드백]

Q1은 드모르간 법칙을 연쇄 적용하여 NAND 구조로 만드는 전형적인 시험 문제입니다.

Q2는 양수 5와 4를 더했는데 결과가 음수 1001(-7)이 나오는 2의 보수 오버플로우의 대표 사례입니다.

Q3은 Don't Care를 1로 포함시켜 2-묶음 2개 대신 4-묶음 1개로 변수 2개를 단숨에 날리는 최적화 문제입니다.

Latch Fundamentals Bistable Memory Cells

SR 래치 vs 게이트 D 래치 (레벨 감응)

교차 결합 양의 피드백 루프, 금지 상태 및 투명성(Transparency) 특성

📌 NOR 기반 Active-High SR 래치
S ──┤NOR 1├─── Q │ ┌─┘ └───┼─┐ ┌───┘ │ R ──┤NOR 2├─── /Q
SRQ*/Q*동작 상태
00Q/Q유지 (Hold)
0101리셋 (Reset)
1010셋 (Set)
1100금지 (Invalid / Race)
📌 게이트 D 래치와 투명성(Transparency)

SR의 금지 상태를 없애기 위해 $S=D, R=\bar{D}$로 묶은 회로

$$\text{Enable } C=1: Q = D \text{ (Transparent)} \quad \Big| \quad C=0: Q \text{ 유지 (Latch)}$$
⚠️ 한계: $C=1$인 동안 입력이 변하면 출력이 즉시 바뀌므로, 피드백 루프 구성 시 출력이 입력을 다시 흔드는 Race-Around 문제 발생 ➔ 플립플롭의 등장 배경!

[SR 래치 $S=R=1$이 금지인 진짜 이유]

$S=R=1$일 때는 $Q=0, \bar{Q}=0$이 되어 상보 관계($Q e \bar{Q}$)가 깨집니다.

더 치명적인 문제는 $S, R$이 동시에 0으로 바뀔 때 두 게이트의 미세한 지연 시간 차이에 의해 최종 상태가 무작위(0 또는 1)로 튀는 Race Condition이 발생하기 때문입니다.

[실습실 74HC74 최다 질문: "불이 안 꺼져요!"]

학생들이 $\overline{PRE}$나 $\overline{CLR}$ 핀을 안 쓰고 비워두면(Floating) 플로팅 노이즈로 인해 비동기 리셋이 걸려 클록을 아무리 줘도 출력이 변하지 않습니다.

반드시 사용하지 않는 $\overline{PRE}, \overline{CLR}$은 VCC에 직결해야 정상 클록 동작을 합니다.

Timing Integrity Setup/Hold & Metastability

타이밍 제약 조건과 메타스테이빌리티(Metastability)

셋업 타임($t_{su}$)·홀드 타임($t_h$) 위반 시의 비정상 전압 진동 및 2-FF 동기화기

📌 Setup Time ($t_{su}$) vs Hold Time ($t_h$)
Data ───────XXXXX┌─────────────────────┐XXXXX──── │◄─ t_su ─►│◄── t_h ──►│ Clock ───────────────────────▲──────────────────── (Edge)
• Setup Time ($t_{su}$): 클록 에지 발생 전에 데이터가 안정적으로 유지되어야 하는 최소 시간.
• Hold Time ($t_h$): 클록 에지 발생 후에 데이터가 변하지 않고 유지되어야 하는 최소 시간.
• 최대 동작 주파수: $f_{\max} = \frac{1}{t_{c-q} + t_{comb} + t_{su}}$
⚠️ 메타스테이빌리티와 2-FF 동기화기
• 비동기 신호가 $t_{su}/t_h$ 윈도우 내부에서 변하면 출력이 중간 전압($V_{DD}/2$)에서 오랜 시간 방황(진동)함.
• 2-Stage 플립플롭 동기화기 (2-FF Synchronizer):
Async In ──►[ D-FF 1 ]── Metastable Node ──►[ D-FF 2 ]──► Sync Out CLK ───────────────────────────┘
➔ 1번째 FF의 메타스테이블이 1클록 주기 동안 안정화되도록 대기하여 MTBF(평균 고장 간격)를 수백 년 단위로 연장!

[반도체/FPGA 면접 1순위 단골 질문]

"메타스테이빌리티가 무엇이며 어떻게 해결합니까?"는 모든 디지털 하드웨어 기업의 필수 질문입니다.

Sequence Generators Ring vs Johnson Counters

링 카운터(Ring) vs 존슨 카운터(Johnson)

출력 피드백을 이용한 시퀀스 발생기: 상태 수, 디코딩 복잡도 및 비정상 상태 탈출

📌 링 카운터 (Ring Counter: $Q_N o D_0$)

최종단 출력 $Q$를 첫 단 입력 $D$로 단순 순환

$N$개 FF ➔ $N$개 유효 상태 (4비트: 4상태)
  • 상태 순환: 1000 ➔ 0100 ➔ 0010 ➔ 0001 ➔ 1000
  • 장점: 각 비트가 원-핫(One-Hot)이므로 **디코더 게이트 전혀 불필요**!
  • 단점: 초기 1 주입 필수, 무효 상태(12개) 진입 시 고립 위험.
📌 존슨 카운터 (Twisted Ring: $\bar{Q}_N o D_0$)

최종단 반전 출력 $\bar{Q}$를 첫 단 입력 $D$로 교차 피드백

$N$개 FF ➔ $2N$개 유효 상태 (4비트: 8상태)
  • 상태 순환: 0000 ➔ 1000 ➔ 1100 ➔ 1110 ➔ 1111 ➔ 0111 ➔ 0011 ➔ 0001
  • 장점: 플립플롭 효율 2배, 인접 상태 간 1비트만 변하여 글리치 없음!
  • 디코딩: 2-입력 AND 게이트 1개만으로 각 상태 디코딩 가능.

[존슨 카운터의 산업계 응용]

존슨 카운터는 8상태를 만드는 데 2입력 AND 게이트만 있으면 되므로, 고속 다상 클록 발생기(Multi-phase Clock Generator)나 3상 모터 제어 신호 생성에 필수적으로 쓰입니다.

Asynchronous Counting 74HC93 & 7490 Decade Counter

비동기식(Ripple) 카운터와 누적 지연

앞 단의 출력이 뒷 단의 클록을 구동하는 구조와 과도기 글리치(Glitch) 한계

📌 74HC93 4비트 2진 리플 카운터
CLK In ──►[ >CLK QA ]──┬─► QA (LSB: f/2) [ T=1 /QA ] │ └──►[ >CLK QB ]──┬─► QB (f/4) [ T=1 /QB ] │ └──►[ >CLK QC ]── ...

* 하강 에지 트리거 토글 FF 체인: $Q_0$ 출력이 $Q_1$의 클록으로 전달되어 마치 물결(Ripple)처럼 전파.

⚠️ 리플 카운터의 치명적 결함: 누적 지연
• $N$번째 비트가 바뀌기까지 총 지연시간: $t_{\text{total}} = N imes t_{pd}$
• 과도기 글리치 예시 ($0111_2 o 1000_2$ 전이 시):
$0111 o 0110 o 0100 o \mathbf{0000} o 1000$
➔ 순간적으로 0000 등의 잘못된 상태가 출력선에 나타나 후속 조합회로에 심각한 오작동 유발!

[동기식 카운터로 넘어가야 하는 이유]

리플 카운터는 회로가 단순하여 빵판에서 만들기 쉽지만, 4비트만 되어도 40ns 이상의 지연이 쌓여 고속 CPU나 정밀 타이머에는 절대 쓸 수 없습니다.

Synchronous Counting 74HC163 & Modulo-N

동기식 카운터(74HC163) & Modulo-N 설계

모든 플립플롭이 동일 클록으로 동시 갱신되며, 병렬 룩어헤드 캐리로 누적 지연 제거

📌 동기식 카운터의 핵심 장점
  • 공통 클록(Common CLK): 모든 FF가 한 클록 에지에서 동시 전환
  • 동기식 전파 지연: 비트 수 $N$에 상관없이 $t_{total} = t_{c-q}$ 단 1회 지연
  • 글리치 없음: 중간 과도기 상태가 발생하지 않아 완벽한 안정성 보장
  • Ripple Carry Output (RCO): 15 카운트 시 HIGH 출력되어 다음 칩으로 즉시 캐리 전달
★ Modulo-10 (10진 카운터: 0~9) 설계법
• 방식 1: 동기식 클리어 ($\overline{\text{SCLR}}$) 활용 (추천)
출력이 9($1001_2$)일 때 감지하여 $\overline{\text{SCLR}}$을 LOW로 만들어 다음 클록 에지에서 0으로 초기화.
• 방식 2: 병렬 로드 ($\overline{\text{LOAD}}$) 활용
$RCO$를 $\overline{\text{LOAD}}$에 피드백하고 입력 $D_0 \sim D_3$에 시작값을 인가하여 임의 범위(예: 6~15) 카운팅 구현.

[동기식 리셋 vs 비동기식 리셋 차이]

74HC163은 동기식 리셋(Synchronous Reset)을 채택하여 리셋 핀이 0이어도 다음 클록 에지가 와야 비로소 0으로 초기화됩니다. 이로 인해 리셋 펄스에 노이즈가 타도 오작동하지 않는 강력한 장점이 있습니다.

Signal Conditioning Switch Debouncing

기계식 스위치 채터링(Chattering)과 디바운서

스위치 접점 바운싱($1 \sim 10\text{ms}$)으로 인한 다중 펄스 계수 오류 및 완벽 해결 회로

⚠️ 채터링(Bouncing) 현상
스위치 누름 ──► │ 수 ms 동안 접점이 수십 번 튀면서 펄스 발생 │ └───/\/\/\/\/\┌───────────────────────────── │◄──── 1 ~ 10 ms ────►│

* 카운터 클록에 스위치를 직결하면 버튼을 한 번 눌렀는데 숫자가 1이 아니라 5, 12씩 마구 올라가는 원인!

✔ 2대 완벽 디바운서 (Debouncer) 회로
• 1. SPDT 스위치 + SR 래치 디바운서:
스위치가 처음 접점에 닿는 순간 래치가 Set/Reset되어 이후의 미세한 바운싱을 완전히 무시 (가장 확실한 하드웨어 디바운스).
• 2. RC 저역통과필터 + 74HC14 슈미트 트리거:
$R=10\text{k}\Omega, C=0.1\mu\text{F}$로 고주파 튐을 뭉개고, 슈미트 트리거의 히스테리시스($\Delta V_T$)로 칼 같은 1회 구형파 생성.

[실습실 팁: 스위치 입력 시 필수 조치]

실험 6, 7, 8에서 수동으로 클록을 줄 때는 절대로 빵판 푸시버튼을 클록 핀에 직결하면 안 됩니다.

클록 노이즈 방지법 및 플립플롭 vs 래치 기술 면접 단골 질문

Q1 래치 vs 플립플롭

질문: 래치와 플립플롭의 결정적 차이는?

래치는 Enable 레벨(구간) 동안 입력이 출력에 투과되는 레벨 감응이고, 플립플롭은 클록 에지(순간)에만 샘플링되는 에지 감응 소자입니다.
Q2 존슨 vs 링 카운터

질문: 4비트 존슨 카운터의 상태 수와 장점은?

링 카운터(4개)보다 2배 많은 8개 상태를 가지며, 인접 상태 간 1비트만 변경되어 과도기 글리치 없이 2입력 AND 게이트로 디코딩됩니다.
Q3 셋업/홀드 타임 위반

질문: 셋업 타임을 위반하면 무슨 일이 일어나는가?

플립플롭 내부 마스터 래치가 정상 안정화되지 못하고 중간 전압에서 방황하는 메타스테이빌리티가 발생하여 데이터가 깨집니다.

[순서논리회로 실험 총평 가이드]

순서논리회로의 디버깅 핵심은 "클록 신호의 품질"입니다. 접촉 불량이나 긴 점퍼선으로 인한 인덕턴스 때문에 클록에 링잉(Ringing) 노이즈가 생기면 플립플롭이 1클록에 2번 트리거됩니다.

클록 배선은 최대한 짧게 연결하고 반드시 GND 접지를 강화해야 합니다.

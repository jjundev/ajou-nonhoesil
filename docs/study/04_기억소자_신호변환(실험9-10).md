```

      • SRAM : 6T 교차 인버터 래치 구조 → 초고속(1~10ns), 리프레시 불필요, 캐시 메모리 사용.

   2. D/A 변환기 (DAC)

      • LM741 반전 가산기 : 가상 접지(V- = 0V)를 활용해 V_out = -V_ref (Rf/R) Σ (b_i / 2^k) 계단 전압 출력.

   3. A/D 변환기 (ADC)
      • Flash ADC : (2^n - 1)개 비교기 + 우선순위 인코더 → 피드백 없는 1클록 초고속 변환 (면적/전력 O(2^n)).
      • SAR ADC : 축차 비교 레지스터 + 내부 DAC 이진 탐색(Binary Search) → 정확히 n 클록 소요 (가장 널리 쓰임).
      • 변환 지표 : 1 LSB Step Size = V_FS / (2^n - 1), 양자화 오차 = ±1/2 LSB, 나이퀴스트 표본화 fs >= 2*f_max.
```

## 📖 2. 이론 핵심 리마인드

### 2.1 반도체 메모리 분류 및 핵심 동작 원리

반도체 메모리는 전원 차단 시 데이터 보존 여부에 따라 **휘발성(Volatile)**과 **비휘발성(Non-Volatile)**으로 대별된다.

```
                       ┌─────────────────────────────────────────┐
                       │          Semiconductor Memory           │
                       └────────────────────┬────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    ▼                                               ▼
         ┌─────────────────────┐                         ┌─────────────────────┐
         │   RAM (Volatile)    │                         │  ROM (Non-Volatile) │
         └──────────┬──────────┘                         └──────────┬──────────┘
                    │                                               │
           ┌────────┴────────┐                   ┌──────────┬───────┴───┬──────────┐
           ▼                 ▼                   ▼          ▼           ▼          ▼
       ┌───────┐         ┌───────┐           ┌───────┐  ┌───────┐   ┌────────┐ ┌───────┐
       │ SRAM  │         │ DRAM  │           │ Mask  │  │ PROM  │   │ EPROM  │ │ Flash │
       │ (6T)  │         │(1T-1C)│           │  ROM  │  │(Fuse) │   │/EEPROM │ │Memory │
       └───────┘         └───────┘           └───────┘  └───────┘   └────────┘ └───────┘
```

#### (1) SRAM vs DRAM 상세 비교

| 비교 항목 | SRAM (Static RAM) | DRAM (Dynamic RAM) |
| :--- | :--- | :--- |
| **기본 단위 셀 구조** | **6-MOSFET (6T)**<br>(2개 인버터 교차 래치 + 2개 접근 NMOS) | **1-MOSFET + 1-Capacitor (1T-1C)**<br>($C_s \approx 20 \sim 30\text{ fF}$) |
| **데이터 저장 방식** | 쌍안정 래치의 양의 피드백 상태로 정적 유지 | 커패시터($C_s$)의 미세 전하 축적/방전 |
| **동작 속도 (접근 시간)** | **초고속 ($1 \sim 10\text{ ns}$)** | 상대적 저속 ($30 \sim 60\text{ ns}$) |
| **읽기 동작 특성** | **비파괴 읽기 (Non-Destructive Read)** | **파괴적 읽기 (Destructive Read)**<br>$\to$ 읽기 직후 **재저장(Restore)** 사이클 필수 |
| **리프레시 (Refresh)** | **불필요** (전원 공급 중 데이터 무한 유지) | **필수** (누설 전류 보상을 위해 수십 ms 주기 재충전) |
| **집적도 및 단가** | 낮음 (셀 면적이 큼), 고가 | **초고집적도 (단일 칩 수십 GB)**, 저단가 |
| **주요 응용 분야** | CPU L1/L2/L3 캐시 메모리, 고속 레지스터 | PC/스마트폰 주기억장치 (Main Memory, DDR4/DDR5) |

#### (2) 비휘발성 메모리(ROM) 및 PLD 아키텍처

- **Mask ROM**: 반도체 제조 시 마스크 배선으로 '0'/'1'을 하드와이어링. 수정 불가, 대량생산 시 최저 단가.
- **PROM (Programmable ROM)**: 퓨즈(Fuse)/안티퓨즈를 전기적으로 끊어 1회만 프로그래밍(OTP).
- **EPROM**: 플로팅 게이트에 전자 트랩. 자외선(UV Light, $254\text{ nm}$)을 석영창에 $20 \sim 30$분 조사하여 일괄 소거.
- **EEPROM**: 전기적 터널링(Fowler-Nordheim)을 통해 바이트 단위로 전기적 소거 및 재기록.
- **Flash Memory**: 블록/섹터 단위로 고속 일괄 소거.
  - **NOR Flash**: 바이트 단위 랜덤 읽기 가능(XIP 코드 실행), BIOS/임베디드 펌웨어용.
  - **NAND Flash**: 직렬 스트링 구조로 집적도 극대화, 페이지 읽기/쓰기 + 블록 소거, SSD/스마트폰 스토리지.

```
    [ ROM / PROM ]           [ PLA (Prog. Logic Array) ]        [ PAL (Prog. Array Logic) ]
   Inputs                    Inputs                           Inputs
     │                         │                                │
 ┌───▼───────────┐         ┌───▼───────────┐                ┌───▼───────────┐
 │ Fixed AND     │         │ Programmable  │                │ Programmable  │
 │ (Full Decoder)│         │ AND Array     │                │ AND Array     │
 └───┬───────────┘         └───┬───────────┘                └───┬───────────┘
     │ All 2^n Minterms        │ k Product Terms (Shared)       │ Fixed Product Terms/OR
 ┌───▼───────────┐         ┌───▼───────────┐                ┌───▼───────────┐
 │ Programmable  │         │ Programmable  │                │ Fixed         │
 │ OR Array      │         │ OR Array      │                │ OR Array      │
 └───┬───────────┘         └───┬───────────┘                └───┬───────────┘
     ▼ Outputs                 ▼ Outputs                        ▼ Outputs
```

- **ROM**: 고정 AND (완전 디코더) + 프로그래머블 OR. 모든 최소항 생성, 진리표 직접 매핑.
- **PLA**: 프로그래머블 AND + 프로그래머블 OR. 곱항 공유(Product Term Sharing)로 최적화 극대화.
- **PAL**: 프로그래머블 AND + 고정 OR. 고정 OR 구조로 배선 용량 최소화, 속도 최고($t_{pd}$ 최단), 저비용.

### 2.2 2D 메모리 어레이 주소 디코딩 (Coincident Selection)

메모리 용량이 $N$비트 주소선($2^N$ 워드)으로 증가할 때, 1차원 디코더는 $2^N$개의 출력선이 필요하여 비효율적이다. 이를 해결하기 위해 행(Row)과 열(Column) 디코더로 분할하는 **2차원 매트릭스 디코딩(Coincident Selection)**을 사용한다.

```
                  Column Address (CA, N/2 bits)
                               │
                        ┌──────▼──────┐
                        │ Column Dec. │ (2^(N/2) Select Lines)
                        └──────┬──────┘
                               │
Row Address (RA, N/2 bits)     ▼
      │                  ┌───────────┐
┌─────▼─────┐            │ ┌─┬─┬─┬─┐ │
│ Row Dec.  ├────────────┼─┼─┼─┼─┼─┼─┤ Word Line (WL)
│ (2^(N/2)) ├────────────┼─┼─┼─┼─┼─┼─┤
└───────────┘            │ └─┴─┴─┴─┘ │ Memory Cell Matrix (2^(N/2) x 2^(N/2))
                         └─────┬─────┘
                               │ Bit Lines & Sense Amps
                               ▼
                          Data Output
```

- **디코더 게이트 수 절감 효과**:
  - $1\text{ Mb}$ ($N=20$) 메모리 기준:
    - 1D 디코딩: $2^{20} = 1,048,576$개의 디코더 출력선 및 방대한 팬아웃 필요.
    - 2D 디코딩: Row 디코더 $2^{10} = 1,024$개 + Column 디코더 $2^{10} = 1,024$개 $\to$ 총 $2,048$개 게이트로 약 **512배 축소**.

### 2.3 16-bit IC RAM (7489 / 74189 & 74670 Register File) 및 타이밍

#### (1) IC 핀 배치 및 구조 비교

```
       74670 (4x4 Register File)                    7489 / 74189 (16x4 RAM)
          ┌───────∪───────┐                            ┌───────∪───────┐
      D1 ─┤ 1          16 ├─ VCC                   A0 ─┤ 1          16 ├─ VCC
      D2 ─┤ 2          15 ├─ D4                    A1 ─┤ 2          15 ├─ A3
     /GR ─┤ 3          14 ├─ D3                   /ME ─┤ 3          14 ├─ A2
      RB ─┤ 4  74670   13 ├─ /GW                   /WE ─┤ 4   7489   13 ├─ /Q4 (7489: OC /
      RA ─┤ 5  (4x4    12 ├─ WB                    D1 ─┤ 5  74189  12 ├─ /Q3  74189: 3S)
      Q1 ─┤ 6  RegFile)11 ├─ WA                   /Q1 ─┤ 6  (16x4) 11 ├─ D4
      Q2 ─┤ 7          10 ├─ Q4                    D2 ─┤ 7          10 ├─ /Q2
     GND ─┤ 8           9 ├─ Q3                   GND ─┤ 8           9 ├─ D3
          └───────────────┘                            └───────────────┘
```

1. **74670 (4-Word × 4-Bit Dual-Port Register File)**:
   - **독립 듀얼 포트(Dual-Port)**: 쓰기 포트($W_A, W_B, \overline{\text{GW}}, D_1 \sim D_4$)와 읽기 포트($R_A, R_B, \overline{\text{GR}}, Q_1 \sim Q_4$)가 분리되어 **동시 읽기/쓰기(Simultaneous Read/Write)** 가능.
   - 출력단: 3-State 비반전 출력 ($Q_n$).
2. **7489 / 74189 (16-Word × 4-Bit RAM)**:
   - 단일 주소 버스($A_0 \sim A_3$): 16개 주소($0000_2 \sim 1111_2$) 공유.
   - 메모리 인에이블($\overline{\text{ME}}$ 또는 $\overline{\text{CS}}$, Pin 3, Active-Low) & 쓰기 인에이블($\overline{\text{WE}}$, Pin 4, Active-Low).
   - **출력 반전 특성 (핵심 주의)**:
     - 7489: **오픈 컬렉터(Open-Collector) 반전 출력 ($\overline{Q}_1 \sim \overline{Q}_4$)** $\to$ 외장 풀업 저항 필수.
     - 74189: **3-상태(3-State) 반전 출력 ($\overline{Q}_1 \sim \overline{Q}_4$)**.
     - 입력으로 $D_n = 1$을 쓰면 읽을 때 출력 핀에는 $\overline{Q}_n = 0$ ($0\text{ V}$, Low)가 나타남.

#### (2) 메모리 동작 모드 진리표

| $\overline{\text{ME}}$ ($\overline{\text{CS}}$) | $\overline{\text{WE}}$ ($\overline{\text{GW}}$) | 동작 모드 (Operation Mode) | 데이터 출력 ($Q_n$) 상태 |
| :---: | :---: | :--- | :--- |
| **0 (Low)** | **0 (Low)** | **쓰기 (Write)** | 출력 디스에이블 (7489: High-Z / 74189: 3-State High-Z) |
| **0 (Low)** | **1 (High)** | **읽기 (Read)** | 선택된 번지의 저장 데이터 출력 ($\overline{D}_n$ 반전 출력) |
| **1 (High)** | **X** | **비선택 (Inhibit / Standby)** | 고임피던스(High-Z) 상태 유지 |

#### (3) 쓰기/읽기 사이클 타이밍 요구조건

```
              ┌─────────────────────────────┐
Address/Data ─┤          VALID              ├──────────────────────
              └──────────────┬──────────────┘
                             │  t_s (Setup >= 15ns)
                       ┌─────▼──────┐
/WE (/GW)    ──────────┤            ├──────────────────────────────
                       │  t_w >=25ns│  t_h (Hold >= 10ns)
                       └────────────┘
```

- **셋업 시간 ($t_s$, Setup Time)**: $\overline{\text{WE}}$ 펄스가 Low로 내려가기 전 주소 및 데이터가 안정화되어 유지되어야 하는 최소 시간 ($\ge 15\text{ ns}$).
- **쓰기 펄스 폭 ($t_w$, Write Pulse Width)**: $\overline{\text{WE}}$ 신호가 Low로 유지되는 최소 지속 시간 ($\ge 25\text{ ns}$).
- **홀드 시간 ($t_h$, Hold Time)**: $\overline{\text{WE}}$가 High로 복귀한 후에도 주소 및 데이터가 유지되어야 하는 최소 시간 ($\ge 10\text{ ns}$).

### 2.4 D/A 변환기 (Digital-to-Analog Converter, DAC)

$n$-비트 디지털 2진 입력 $B = b_{n-1} b_{n-2} \dots b_1 b_0$을 비례하는 아날로그 전압 $V_{\text{out}}$으로 변환하는 회로.

#### (1) 가중 저항형 DAC (Binary-Weighted Resistor DAC)

```
                  R_1 = R       (MSB: b3)
       V_ref ───o/ o──/\/\/\/\───┐
                  b3             │
                  R_2 = 2R      (b2)
       V_ref ───o/ o──/\/\/\/\───┤
                  b2             │
                  R_3 = 4R      (b1)
       V_ref ───o/ o──/\/\/\/\───┼──────────┐  R_f
                  b1             │          │ ┌──/\/\/\/\──┐
                  R_4 = 8R      (LSB: b0)   │ │            │
       V_ref ───o/ o──/\/\/\/\───┘          ▼ │            │
                  b0                      ┌───┴──┐         │
                                          │ 2 (-)│         │
                           GND ───────────┤ 3 (+)├──6──────┴─── V_out
                                          │LM741 │ (Virtual Ground: V- = 0V)
                                          └──────┘
```

- **출력 전압 수식 완벽 유도**:
  1. 이상적인 OP-Amp는 $R_{in} = \infty$이므로 반전 단자(-)로 유입되는 전류는 $I_- = 0$.
  2. 비반전 단자(+)가 접지($0\text{ V}$)되어 있으므로, 음귀환(Negative Feedback) 루프에 의해 반전 단자의 전압은 **가상 접지(Virtual Ground)** 전위 $V_- = 0\text{ V}$를 형성함.
  3. KCL(키르히호프 전류 법칙)에 의해 각 비트 분로를 통해 흘러 들어오는 전류의 총합 $I_{\text{sum}}$은 모두 피드백 저항 $R_f$로 흐름:
     $$I_{\text{sum}} = \frac{V_{\text{ref}}}{R} b_{n-1} + \frac{V_{\text{ref}}}{2R} b_{n-2} + \frac{V_{\text{ref}}}{4R} b_{n-3} + \dots + \frac{V_{\text{ref}}}{2^{n-1}R} b_0 = \frac{V_{\text{ref}}}{R} \sum_{i=1}^n \frac{b_{n-i}}{2^{i-1}}$$
  4. 옴의 법칙에 의해 출력 전압 $V_{\text{out}}$은:
     $$V_{\text{out}} = V_- - I_{\text{sum}} \cdot R_f = 0 - I_{\text{sum}} R_f = - V_{\text{ref}} \frac{R_f}{R} \left( \frac{b_{n-1}}{2^0} + \frac{b_{n-2}}{2^1} + \dots + \frac{b_0}{2^{n-1}} \right)$$

- **가중 저항형의 한계점**:
  - $n$비트가 커질수록 저항 범위($2^{n-1}$)가 기하급수적으로 벌어짐 ($12\text{ bit}$ 시 $R \sim 2048R$).
  - IC 공정 내에서 $1\text{ k}\Omega$과 $2\text{ M}\Omega$의 정밀한 저항비 매칭, 온도 계수 일치, 기생 커패시턴스 밸런싱이 불가능함.

#### (2) R-2R 사다리형 DAC (R-2R Ladder DAC)

```
                    R              R              R
         ┌──────/\/\/\/\──┬─────/\/\/\/\──┬─────/\/\/\/\──┬──────┐
         │                │               │               │      │
        ┌┴┐ 2R           ┌┴┐ 2R          ┌┴┐ 2R          ┌┴┐ 2R  │ (Virtual GND: V- = 0V)
        │ │              │ │             │ │             │ │     ▼
        └┬┘              └┬┘             └┬┘             └┬┘   ┌───┐
         │                │               │               │    │ - │  R_f
        GND              b0              b1              b2  ──┤   ├─/\/\/\─┐
                       (LSB)                                   │ + │        │
                                                        (MSB:b3)└──┬┘        │
                                                                   ▼        │
                                                                 V_out ─────┘
```

- **테브난(Thevenin) 등가 해석 및 동작 원리**:
  - 사다리의 어느 수직 노드에서 좌측을 바라보아도 등가 저항은 항상 $R$로 일정함 ($2R \parallel 2R = R$).
  - 각 비트 스위치($b_i$)에서 주입된 전류는 다음 노드로 진행할 때마다 정확히 **$\mathbf{1/2}$씩 이진 감쇠(Binary Attenuation)**되어 가상 접지 노드로 합산됨.
- **출력 전압 공식**:
  $$V_{\text{out}} = - V_{\text{ref}} \frac{R_f}{R} \sum_{i=1}^n b_{n-i} 2^{-i} = - V_{\text{ref}} \frac{R_f}{R} \left( \frac{b_{n-1}}{2^1} + \frac{b_{n-2}}{2^2} + \dots + \frac{b_0}{2^n} \right)$$
- **장점**:
  - 오직 **$R$과 $2R$ 두 가지 값의 저항비(Ratio)**만 정밀하게 맞추면 되므로, 박막 레이저 트리밍 공정으로 $16 \sim 24\text{ bit}$의 초고정밀 DAC 구현 가능 (현대 상용 DAC의 표준).

### 2.5 A/D 변환기 (Analog-to-Digital Converter, ADC)

연속 아날로그 전압 $V_{\text{in}}$을 표본화(Sampling) 및 양자화(Quantization)하여 $n$-비트 디지털 2진수로 변환하는 장치.

```
       ┌─────────────────────────────────────────────────────────────┐
       │                  ADC Architecture Families                  │
       └─────────────────────────────────────────────────────────────┘

    [ Flash ADC (Simultaneous) ]        [ Successive Approximation (SAR) ADC ]
          V_in                                V_in ──┐
           │                                         │  +
        ┌──┴────────┬─────────┐                  ┌───▼──┐
        │           │         │                  │ Comp │──┐
      ┌─▼──┐      ┌─▼──┐    ┌─▼──┐               └───▲──┘  │
  Vref┤Comp│  Vref┤Comp│Vref┤Comp│                   │ -   │
      └──┬─┘      └──┬─┘    └──┬─┘               ┌───┴──┐  ▼
         │           │         │                 │ DAC  │◄─ SAR Logic
         └─────┬─────┴─────────┘                 └───┬──┘  (Binary Search)
               ▼                                     │
       Priority Encoder                          ┌───▼──────────────┐
               │                                 │ Digital Output   │
               ▼                                 └──────────────────┘
        Digital Output (1-Cycle)
```

#### (1) Flash ADC (동시형 / 병렬 비교기형)
- **구조**: $2^n$개의 정밀 분압 저항으로 분할된 $2^n - 1$개의 기준 전압과 $2^n - 1$개의 전압 비교기를 병렬 연결 $\to$ 비교기 출력(온도계 코드, Thermometer Code)을 우선순위 인코더(Priority Encoder)로 변환.
- **특징**:
  - **변환 속도 최상 ($1\text{ Cycle}$)**: 피드백 루프 없이 비교기 전파 지연만 소요 ($10 \sim 100\text{ GSPS}$).
  - **하드웨어 비용 폭증**: 8비트 시 255개, 10비트 시 1,023개의 비교기 필요 $\to$ 면적/전력 소모가 $O(2^n)$으로 급증.

#### (2) Feedback형 ADC 비교

| ADC 아키텍처 | 동작 원리 | 변환 소요 시간 | 분해능 & 정밀도 | 주요 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **계수형 / 램프형<br>(Counting Ramp)** | 카운터 클록마다 1 LSB씩 $V_{\text{DAC}}$ 상승 $\to$ $V_{\text{in}} \le V_{\text{DAC}}$일 때 카운터 정지 | 최대 $2^n$ 클록<br>(가장 느림) | 낮음 ($6 \sim 8\text{ bit}$) | 단순 센서 모니터링 |
| **축차 비교형<br>(SAR ADC)** | **이진 탐색(Binary Search)** 알고리즘:<br>MSB부터 1로 두고 $V_{\text{in}}$과 비교하여 1 유지 또는 0 리셋 | **정확히 $\mathbf{n}$ 클록** | **중고속 & 고분해능**<br>($10 \sim 18\text{ bit}$) | **MCU 내장 ADC 표준**,<br>산업용 DAQ, 오디오 |
| **이중 슬로프 적분형<br>(Dual-Slope)** | 고정 시간 $T_1$ 동안 $V_{\text{in}}$ 적분 $\to$ 기준 전압 $-V_{\text{ref}}$로 $0\text{ V}$까지 역적분 시간 $T_2$ 측정 | 수천~수만 클록<br>(매우 느림) | **초고정밀도** ($18 \sim 24\text{ bit}$)<br>($R, C$, 클록 주파수 오차 완전 상쇄) | **디지털 멀티미터(DMM)**,<br>정밀 전자저울 |

### 2.6 신호 변환 지표 및 샘플링 이론

```
   Output Voltage
        ▲
        │                                  Ideal Transfer Curve
   V_FS ┼───────────────────────────────/-- Actual Curve
        │                             /
        │                           ┌─o (Step k: DNL_k = Actual Width - 1 LSB)
        │                         ┌─┘
        │                     ┌───┘ ◄─── INL_k (Total Deviation from Ideal)
        │                   ┌─┘
        │               ┌───┘
        │           ┌───┘
        │       ┌───┘
        │   ┌───┘
      0 ┼───┴───────────────────────────────► Digital Code
            0   1   2   3   4   5   6   7
```

1. **분해능 (Resolution, $n$)**:
   - 아날로그 신호를 분할하여 구분할 수 있는 비트 수 $n$ 또는 스텝 단계 수 ($2^n$).
2. **1 LSB 스텝 크기 (Step Size, $\Delta V$)**:
   $$\Delta V_{\text{LSB}} = \frac{V_{\text{FS}}}{2^n - 1} \quad \left(\text{DAC 전체 스케일 기준}\right) \quad \text{혹은} \quad \frac{V_{\text{ref}}}{2^n} \quad \left(\text{ADC 기준}\right)$$
3. **양자화 오차 (Quantization Error, $e_q$)**:
   - 연속 아날로그 값을 이산 값으로 반올림/버림할 때 생기는 본질적 오차:
     $$-\frac{1}{2}\text{ LSB} \le e_q \le +\frac{1}{2}\text{ LSB}$$
   - **이상적 신호 대 양자화 잡음비 (SQNR)**:
     $$\text{SQNR (dB)} = 6.02 \cdot n + 1.76\text{ dB}$$
     *(분해능이 1비트 증가할 때마다 신호 품질 약 $6\text{ dB}$ 향상)*
4. **나이퀴스트-섀넌 표본화 정리 (Nyquist-Shannon Sampling Theorem)**:
   - 신호의 최고 주파수가 $f_{\max}$일 때, 에일리어싱(Aliasing) 왜곡 없이 원신호를 완벽 복원하기 위한 최소 샘플링 주파수 $f_s$:
     $$f_s \ge 2 f_{\max} \quad (f_{\text{Nyquist}} = 2 f_{\max})$$
   - 이를 만족하기 위해 ADC 전단에 **안티 에일리어싱 저역통과 필터(Anti-Aliasing LPF)** 배치 필수.
5. **선형성 지표: DNL vs INL**:
   - **DNL (Differential Non-Linearity)**: 실제 스텝 폭과 이상적인 1 LSB 간의 편차.
     - **단조성(Monotonicity) 조건**: 모든 코드에 대해 $\text{DNL} > -1\text{ LSB}$ (전압 역전 방지).
     - $\text{DNL} \le -1\text{ LSB}$이면 ADC에서 특정 코드가 건너뛰는 **Missing Code** 발생.
   - **INL (Integral Non-Linearity)**: 실제 전달 특성 곡선과 이상적 직선 사이의 최대 누적 편차.

### Q1. A/D Converter를 Feedback 경로의 유무에 따라 두 가지 유형으로 분류하고 각각의 동작 특성과 장단점을 비교하시오. (실험 10 퀴즈 1번)
> **모범 답안:**
> 1. **Simultaneous Type (동시형 / Flash ADC)**:
>    - **특징**: 내부 피드백 경로(Feedback path)가 없음.
>    - **동작**: $2^n - 1$개의 전압 비교기를 병렬로 배치하여 입력 전압과 기준 전압을 단 1회의 클록으로 동시에 비교 판정하고 우선순위 인코더로 출력.
>    - **장단점**: 변환 속도가 극도로 빠르나, 비트 수 $n$ 증가 시 비교기 수가 지수함수($O(2^n)$)로 급증하여 전력 소모와 하드웨어 면적이 매우 큼.
> 2. **Feedback Path Type (피드백형 ADC: Counter형, SAR형, Dual-Slope형)**:
>    - **특징**: 내부에 DAC, 전압 비교기, 제어 로직으로 구성된 닫힌 루프 피드백을 포함.
>    - **동작**: DAC가 생성한 아날로그 전압과 입력 전압을 비교하면서 피드백 신호에 따라 디지털 값을 단계적으로 수정하여 근사값을 찾음.
>    - **장단점**: 단 1개의 비교기만 사용하므로 회로가 단순하고 저비용으로 고분해능을 구현할 수 있으나, $n$회 이상의 클록 사이클이 소요되어 Flash 타입 대비 변환 속도가 느림.

### Q2. 연산 증폭기(OP-Amp) 반전 가산 증폭기에서 입력 전압 $V_1, V_2, V_3$과 저항 $R_1, R_2, R_3$, 피드백 저항 $R_f$에 대한 출력 전압 $V_o$의 관계식을 유도하시오. (실험 10 퀴즈 2번)
> **모범 답안:**
> 1. 이상적인 OP-Amp는 입력 임피던스가 무한대이므로 반전 단자로 유입되는 전류는 0이다 ($I_- = 0$).
> 2. 비반전 단자(+)가 접지($0\text{ V}$)되어 있으므로 음귀환에 의해 반전 단자(-)는 가상 접지(Virtual Ground) $V_- = 0\text{ V}$를 만족한다.
> 3. 반전 단자 노드에서 KCL을 적용하면, 입력 전류들의 합은 피드백 전류 $I_f$와 같다:
>    $$I_1 + I_2 + I_3 = I_f \implies \frac{V_1 - 0}{R_1} + \frac{V_2 - 0}{R_2} + \frac{V_3 - 0}{R_3} = \frac{0 - V_o}{R_f}$$
> 4. 양변에 $-R_f$를 곱하여 정리하면:
>    $$V_o = - R_f \left( \frac{V_1}{R_1} + \frac{V_2}{R_2} + \frac{V_3}{R_3} \right) = - \left( \frac{R_f}{R_1} V_1 + \frac{R_f}{R_2} V_2 + \frac{R_f}{R_3} V_3 \right)$$

### Q3. D/A Converter의 가중 저항형(Binary-Weighted)과 사다리형(R-2R Ladder) 방식의 구조적 차이점과 장단점을 비교하시오. (실험 10 퀴즈 4번)
> **모범 답안:**
> - **가중 저항형(Binary-Weighted Resistor)**:
>   - **구조**: 비트 자리수 가중치에 비례하여 $R, 2R, 4R, \dots, 2^{n-1}R$ 저항을 병렬 연결.
>   - **장점**: 회로 구조가 직관적이고 소자 수가 적음.
>   - **단점**: 고비트(8비트 이상)로 갈수록 최대-최소 저항값의 비율이 $2^{n-1}$로 극단화되어 집적 회로 내 저항 매칭 정밀도 확보 및 온도 드리프트 보상이 불가능함.
> - **사다리형(R-2R Ladder)**:
>   - **구조**: 오직 $R$과 $2R$ 두 종류의 저항만을 사다리 형태로 반복 연결.
>   - **장점**: 두 종류의 저항비(Ratio)만 유지하면 되므로 박막 레이저 트리밍 집적화가 매우 용이하며 고분해능($16 \sim 24\text{ bit}$) 및 고속 스위칭 구현 가능 (현대 상용 DAC의 표준).
>   - **단점**: 가중 저항형에 비해 필요한 총 저항 소자의 개수가 더 많음.

### Q4. SRAM과 DRAM의 셀 구조, 동작 원리, 장단점 및 주요 용도를 비교 설명하시오. (이론 시험 빈출)
> **모범 답안:**
> - **SRAM**: 6개의 MOSFET(교차 결합 인버터 래치)으로 구성되며, 전원이 유지되는 한 쌍안정 상태를 정적으로 유지함. 비파괴 읽기를 수행하며 리프레시가 필요 없어 초고속($1 \sim 10\text{ ns}$)이나, 셀 면적이 커서 고가임 (CPU 캐시 메모리용).
> - **DRAM**: 1개의 NMOS와 1개의 미세 커패시터($C_s$)로 구성되며 전하 축적 유무로 데이터를 저장함. 셀 면적이 극히 작아 초고집적화 및 저단가가 가능하나, 읽기 시 전하가 소실되는 파괴적 읽기(Restore 필요)가 발생하고 누설 전류 보상을 위해 수십 ms 주기의 Refresh가 필수임 (메인 메모리용).

### Q5. 7489 / 74189 RAM 소자에서 데이터를 읽을 때 주의해야 할 출력 신호의 전기적/논리적 특성은? (실험 9 예비)
> **모범 답안:**
> 1. **출력 반전 특성**: 7489와 74189는 모두 반전 출력($\overline{Q}_1 \sim \overline{Q}_4$) 구조를 가지므로, 메모리 내부에 $D_n = 1$을 쓰면 읽을 때 출력 핀에는 $0\text{ V}$ (Low)가 출력된다. 따라서 원래 논리값을 보려면 후단에 7404 인버터를 결합하거나 반전 로직을 감안해야 한다.
> 2. **오픈 컬렉터(7489)**: 7489의 출력단은 Open-Collector이므로 외장 풀업 저항($10\text{ k}\Omega$)을 $+5\text{ V}$에 연결해야 정상적인 High 전압 레벨이 형성된다.

### Q6. Flash ADC에서 8비트 및 10비트 해상도를 구현하기 위해 필요한 아날로그 전압 비교기의 개수를 구하시오.
> **모범 답안:**
> Flash ADC에서 $n$비트 변환 시 필요한 비교기 개수는 $N = 2^n - 1$개이다.
> - **8비트 Flash ADC**: $2^8 - 1 = 256 - 1 = \mathbf{255\text{개}}$
> - **10비트 Flash ADC**: $2^{10} - 1 = 1024 - 1 = \mathbf{1023\text{개}}$

### Q7. SAR(축차 비교형) ADC가 아날로그 전압을 디지털 코드로 변환할 때 사용하는 알고리즘과 4비트 변환 소요 클록 수를 기술하시오.
> **모범 답안:**
> SAR ADC는 **이진 탐색(Binary Search)** 알고리즘을 사용한다.
> 1. MSB($b_3$)를 '1'로 설정하여 $V_{\text{DAC}} = \frac{1}{2} V_{\text{ref}}$를 생성하고 $V_{\text{in}}$과 비교. $V_{\text{in}} < V_{\text{DAC}}$이면 '0'으로 리셋, $V_{\text{in}} \ge V_{\text{DAC}}$이면 '1' 유지.
> 2. 다음 비트($b_2, b_1, b_0$)에 대해 순차적으로 위 과정을 반복.
> 3. 따라서 $n$비트 변환에는 입력 전압 크기와 무관하게 **정확히 $\mathbf{n}$ 클록 사이클**이 소요되며, 4비트 SAR ADC는 항상 **4 클록 사이클**이 소요된다.

### Q8. 나이퀴스트 표본화 정리(Nyquist Sampling Theorem)를 정의하고, 이를 위반했을 때 발생하는 현상과 방지 대책을 설명하시오.
> **모범 답안:**
> - **정의**: 대역 제한된 신호의 최대 주파수가 $f_{\max}$일 때, 원신호를 왜곡 없이 완벽히 복원하기 위해서는 샘플링 주파수 $f_s$가 최소 $2 f_{\max}$ 이상이어야 한다 ($f_s \ge 2 f_{\max}$).
> - **위반 시 현상**: $f_s < 2 f_{\max}$인 경우 고주파 성분이 저주파 대역으로 접혀 들어가 원래 신호와 겹쳐 왜곡되는 **에일리어싱(Aliasing)** 현상이 발생한다.
> - **방지 대책**: ADC 전단에 $f_{\max}$ 이상의 고주파 노이즈를 차단하는 **안티 에일리어싱 저역통과 필터(Anti-Aliasing LPF)**를 배치한다.

### 5.2 오차 원인 분석 (Error Source Analysis)

1. **가중 저항 오차율 ($\pm 5\%$)에 따른 출력 전압 비선형성**:
   - 실습에 사용되는 탄소피막 저항은 통상 $\pm 5\%$의 공차를 가짐.
   - 특히 LSB 측 저항($22.6\text{ k}\Omega$)이나 MSB 측 저항($1.5\text{ k}\Omega$)의 미세 오차는 계단파 스텝 높이의 불균일(DNL 에러)을 유발함.
2. **7405 오픈 컬렉터 인버터의 포화 전압 ($V_{OL} \approx 0.1 \sim 0.2\text{ V}$)**:
   - 논리 '0' 출력 시 완전한 $0\text{ V}$가 아닌 트랜지스터 포화 전압 $V_{CE,\text{sat}}$가 잔류하여 $0\text{ V}$ 오프셋 오차(Offset Error) 발생.
3. **OP-Amp의 입력 오프셋 전압 ($V_{os}$) 및 슬루율 (Slew Rate)**:
   - LM741의 내부 불평형으로 인해 $1 \sim 5\text{ mV}$의 입력 오프셋 전압이 피드백 루프를 통해 증폭됨.
   - 고주파 클록 인가 시 OP-Amp 슬루율 한계($0.5\text{ V}/\mu\text{s}$)로 인해 계단파 모서리가 둥글게 왜곡(Rounding)됨.

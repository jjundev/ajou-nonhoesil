📌 전가산기 (Full Adder: 2-HA + 1-OR)
$$S = A \oplus B \oplus C_i \quad \Big| \quad C_o = AB + C_i(A \oplus B)$$
A ──┬───────[XOR 1]── S1 ──┬───────[XOR 2]──► S (Sum) B ──┼───┐ │ │ ┌───┘ │ │ │ Ci ─┴───┼───[AND 2]── C2 ──┐ └───┼───[AND 1]── C1 ──────┼─────────────────[OR]──► Co (Carry) │ │

* $C_1$과 $C_2$는 동시 1이 불가능한 상호 배타적이므로 OR 게이트로 결합 가능!

[전가산기 캐리 결합의 수학적 증명]

$C_1 = AB$가 1이면 $A=1, B=1$이므로 $S_1 = A \oplus B = 0$이 되어 $C_2 = S_1 \cdot C_i = 0$입니다.

따라서 $C_1 \cdot C_2 = 0$이 항상 성립하므로 $C_1 + C_2 = C_1 \oplus C_2$가 되어 단순 OR 게이트 1개로 완벽하게 합성됩니다.

Hardware Integration 74HC283 Adder/Subtractor

4비트 2진 가감산기 (74HC283 + XOR 제어)

제어 신호 $M$에 따라 덧셈($A+B$)과 2의 보수 뺄셈($A+\bar{B}+1$)을 단일 회로로 수행

┌───────────────────────────────────┐ M ─────────┤ C0 (초기 캐리 입력) │ │ │ │ ├───[XOR]──┤ B0 (A0 + B0 ⊕ M) │ B0 ────┘ │ │ ├───[XOR]──┤ B1 (A1 + B1 ⊕ M) 74HC283 │──► S0~S3 (결과) B1 ────┘ │ (4-bit │ ├───[XOR]──┤ B2 (A2 + B2 ⊕ M) Adder) │──► C4 (최종 캐리) B2 ────┘ │ │ ├───[XOR]──┤ B3 (A3 + B3 ⊕ M) │ B3 ────┘ │ │ A0~A3 ────────┤ A0~A3 (피가수 직결) │ └───────────────────────────────────┘
📌 제어선 $M$의 동작 매커니즘

1. $M = 0$ (덧셈 모드):

  • $B_k \oplus 0 = B_k$ (입력 $B$ 그대로 전달)
  • $C_0 = 0$ (캐리 입력 없음)
  • 결과: $\mathbf{\text{Sum} = A + B}$

2. $M = 1$ (뺄셈 모드):

  • $B_k \oplus 1 = \bar{B}_k$ (입력 $B$의 모든 비트 반전: 1의 보수)
  • $C_0 = 1$ (최하위 비트에 $+1$ 주입: 2의 보수 완성!)
  • 결과: $\mathbf{\text{Sum} = A + \bar{B} + 1 = A - B}$

[가감산기 1-Chip 제어의 우아함]

별도의 감산기 칩을 쓰지 않고 74HC86(XOR) 1개와 74HC283(가산기) 1개만으로 가산과 감산을 완벽히 통합합니다.

이것이 현대 CPU의 ALU(Arithmetic Logic Unit) 내부 덧셈/뺄셈기 하드웨어의 실제 동작 구조입니다.

Error Detection Signed Overflow Flag

부호 연산 오버플로우(Overflow) 판별 회로

최상위 부호비트 캐리($C_4$)와 차상위 캐리($C_3$)의 XOR 비교를 통한 오류 검출

📌 오버플로우 공식 & 회로
$$V = C_4 \oplus C_3$$
74HC283 C4 (최종 캐리) ────\ ))──► V (Overflow LED) 74HC283 C3 (MSB 입력 캐리) ─/ 74HC86

* 74HC283은 내부 $C_3$ 핀이 외부로 노출되지 않으므로, 전가산기 $FA_3$의 캐리 생성식을 별도 게이트로 추출하여 구현합니다.

📌 오버플로우 발생 2대 조건 (4비트 기준: $-8 \sim +7$)

1. 양수 + 양수 = 음수 오류:
$(+5) + (+4) = 0101_2 + 0100_2 = 1001_2 (-7)$
➔ $C_3 = 1, C_4 = 0 \implies V = 1 \oplus 0 = \mathbf{1}$ (발생!)

2. 음수 + 음수 = 양수 오류:
$(-6) + (-5) = 1010_2 + 1011_2 = 10101_2 (+5)$
➔ $C_3 = 0, C_4 = 1 \implies V = 0 \oplus 1 = \mathbf{1}$ (발생!)

[Unsigned Carry vs Signed Overflow 구분]

• 부호 없는 연산 (Unsigned): $C_4=1$ 자체가 표현 범위를 벗어난 자리올림 오류입니다.

• 부호 있는 연산 (Signed): $C_4=1$이 발생해도 정상적인 연산일 수 있으며(예: $(-1)+(-1)$), 반드시 $V = C_4 \oplus C_3$가 1이어야만 오버플로우 오류입니다.

Universal Synthesis Shannon's Expansion

샤논 전개(Shannon's Expansion)와 MUX 함수 합성

4변수 부울 함수 $F(A,B,C,D)$를 게이트 없이 8:1 MUX 1개로 완전 구현하는 비법

📌 샤논 전개 정리 공식
$$F(A,B,C,D) = \bar{A} \cdot F(0,B,C,D) + A \cdot F(1,B,C,D)$$
• 선택선 $S_2, S_1, S_0$에 상위 변수 $A, B, C$를 연결.
• 데이터 입력선 $D_0 \sim D_7$에는 마지막 변수 $D$에 대한 4가지 조건 ($0, 1, D, \bar{D}$) 중 하나를 결선.
➔ 게이트 1개도 없이 MUX 1개로 복잡한 4변수 회로 완성!
★ 실전 예제: $F(A,B,C,D) = \sum m(1,3,4,11,12,13,14,15)$
ABC (선택선)해당 최소항$D=0$일 때$D=1$일 때입력단 $D_k$ 결선
000 ($D_0$)$m_0, m_1$01$D$
001 ($D_1$)$m_2, m_3$01$D$
010 ($D_2$)$m_4, m_5$10$\bar{D}$
110 ($D_6$)$m_{12}, m_{13}$111 (VCC)
111 ($D_7$)$m_{14}, m_{15}$111 (VCC)

[샤논 전개 합성 실습 팁]

시험이나 퀴즈에서 "8:1 MUX로 4변수 함수를 구현하라"는 문제가 나오면, 진리표를 2줄씩 묶어 $D$의 값에 따라 $0, 1, D, \bar{D}$를 도출하는 표를 그리면 1분 만에 풀 수 있습니다.

[Active-Low 디코더의 실무 가치]

SRAM, ROM, 주변장치 IC들의 칩 선택 핀은 대부분 Active-Low($\overline{CS}$)입니다.

74HC138은 출력이 바로 Active-Low이므로 인버터를 거치지 않고 메모리들의 $\overline{CS}$ 핀에 직결할 수 있습니다.

Code Conversion DEMUX & 74HC148 Priority Enc

DEMUX(분배기) & 우선순위 인코더(74HC148)

1:N 데이터 역다중화 분배 및 다중 인터럽트 우선순위 판별 인코딩

📌 디코더 기반 DEMUX (1:N 분배기)

74HC138의 Enable 핀($\bar{G}_{2A}$)에 단일 데이터를 입력하고, 선택선($A,B,C$)으로 목적지 지정:

선택된 라인으로만 데이터 통과, 나머지는 1(비활성)

* MUX가 여러 입력을 하나로 모은다면, DEMUX는 하나를 여러 목적지 중 하나로 라우팅.

📌 74HC148 8:3 우선순위 인코더
• 여러 입력이 동시에 0(Active)으로 들어올 때, 가장 높은 번호(7번 우선)의 2진 코드($A_2, A_1, A_0$)를 출력.
• $\overline{\text{GS}}$ (Group Select): 하나라도 입력이 들어왔음을 알림 (인터럽트 요청선).

CPU에 여러 하드웨어(키보드, 마우스, 타이머, SSD)가 동시에 인터럽트를 요청했을 때, 우선순위 인코더가 가장 긴급한 장치의 번호를 CPU 버스에 실어줍니다.

반드시 $a \sim g$ 7개 신호선에 저항을 각각 독립적으로 달아야 합니다.

Hardware Reliability Static 1-Hazard Elimination

타이밍 해저드(Hazard)와 글리치 제거

게이트 전파 지연차로 인한 순간 오동작 펄스와 K-Map 컨센서스 항(Consensus) 보강

⚠️ 정적 1-해저드 (Static 1-Hazard) 발생 원인
• 식: $F = A\bar{B} + BC$ 에서 $A=1, C=1$일 때 $B$가 $1 \to 0$으로 전이.
• 이론상 $F = 1\cdot 0 + 1\cdot 1 = 1$로 계속 유지되어야 함.
• 그러나 $B$가 NOT 게이트를 통과하는 전파 지연($t_{pd}$) 동안 잠시 $B=0, \bar{B}=0$인 순간이 발생!
• 결과: 출력이 $1 \to 0 \to 1$로 순간 튀는 음의 글리치(Spike Noise) 발생.
✔ K-Map 컨센서스 묶음으로 완벽 해결
• K-Map에서 인접한 두 묶음 사이의 경계를 감싸주는 중복 항(Consensus Term $AC$)을 수식에 추가:
$$F_{\text{safe}} = A\bar{B} + BC + \mathbf{AC}$$
• $B$가 요동쳐도 $AC=1$이 출력을 단단히 받쳐주어 글리치가 원천 차단됨!

[이론적 최소화 vs 하드웨어 신뢰성의 딜레마]

수학적으로는 $AC$항이 불필요한 잉여 항이지만, 하드웨어에서는 글리치로 인한 오동작(특히 카운터의 오카운팅)을 방지하기 위해 필수적으로 추가합니다.

이것이 수학과 전자공학의 가장 큰 시각 차이입니다.

Q1 가산기 오버플로우

질문: 4비트 덧셈에서 $C_4=1$인데 왜 오버플로우가 아닐 수 있는가?

부호 있는 연산에서는 $(-1)+(-1) = 1111_2+1111_2 = 11110_2(-2)$처럼 $C_4=1, C_3=1$이어도 $V = 1 \oplus 1 = 0$으로 정상 연산이기 때문입니다.
Q2 MUX 함수 구현

질문: 4:1 MUX로 3변수 다수결 함수 $F = AB+BC+CA$를 구현하는 법은?

선택선에 $A, B$를 넣고, 샤논 전개에 따라 $D_0=0, D_1=C, D_2=C, D_3=1$을 데이터 핀에 결선합니다.

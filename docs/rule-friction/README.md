# 생성 마찰 로그

격리 에이전트가 스킬 규칙만 보고 보고서를 쓰다가 **규칙이 안 맞아 막히거나
판단으로 메운 자리**를 주차별로 남기는 곳이다.

## `docs/notion-feedback/` 와 무엇이 다른가

출처가 다르다. `notion-feedback` 은 **사용자가 노션에서 고친 것**을 분류한
로그이고, 여기는 **에이전트가 규칙을 실행하다 부딪친 것**이다. 섞으면 나중에
"어느 규칙이 어디서 왔는가" 를 되짚을 때 두 종류가 뒤엉킨다.

## 왜 남기는가

스킬 문서는 컴파일도 실행도 되지 않아서, 결함이 문서를 읽어서는 거의 안
나오고 격리 실행에서만 나온다. 그 실행은 한 번뿐이고 에이전트의 컨텍스트는
사라진다 — 그 자리에서 적지 않으면 영영 없어진다.

**규칙으로 반영하지 않기로 한 것도 남긴다.** 나중에 같은 마찰이 다른 주차에서
또 나오면 그때가 규칙으로 박을 때다. 한 번은 그 주 사정이고 두 번은 규칙이다.

## 파일 이름

`<실험NN>-<종류>.md` — 예: `실험02-예비보고서.md`

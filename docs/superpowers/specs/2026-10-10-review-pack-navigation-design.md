# 복습노트 내부 목차 정리

## 최종 결정 — 2026-10-10 후속 요청

사용자가 자료 이동 영역을 제거하도록 요청했다. 실험01~05의 실험설명 전체와 공통 note/legacy review 템플릿에서 자료 이동 제목·문서 링크·구분선을 삭제한다. 왼쪽 패널은 현재 문서의 내부 목차만 표시한다. 기출 HTML은 별도 워크북이므로 이 패널을 추가하지 않는다.

## 표시와 동작

패널 제목은 목차다. 추가 소제목인 이 페이지 목차와 읽은 토픽/푼 문제 진행 숫자·막대를 제거한다. 목차 제목 바로 아래에 토픽/문항 목록만 둔다. 실험 이해/문제와 풀이 섹션 링크를 제거하고 들여쓰기는 0으로 한다. 개별 읽음/풂 체크는 유지한다. `<nav class="toc" aria-label="이 페이지 목차">` 안에 `<ol class="toc-list">`와 전체 토픽 hash 링크를 정적으로 생성한다. JS는 이 링크를 화면·읽음 체크에 연결한다. pack-nav나 자료 이동 제목·문서 링크·구분선을 생성하지 않는다. 현재 토픽 강조와 읽음 체크를 유지한다.

모바일에서 목차 선택 후 drawer를 닫고 기존 hash/history·키보드 포커스·요약·위젯을 유지한다. 잘못된 hash 인코딩은 예외를 처리하여 빈 화면을 만들지 않는다. JS 비활성에서도 전체 토픽 링크가 보인다. 인쇄에서는 패널을 숨긴다.

## 보존과 재발 방지

토픽/문항 ID·순서·본문·수식·그림·원문 증거·MD·payload·읽음 저장 키를 보존한다. 다른 저장소 upstream을 수정하지 않는다. 생성기와 검사기는 내부 목차만 허용하고 자료 이동 영역 재삽입을 검출한다. 갱신기는 혼합 legacy 목차·자료 이동 분리형·최신 내부 목차형을 읽고 최종 내부 목차형으로 갱신한다. 전체 사전 검사와 백업 후 쓰고, 알 수 없는 구조는 쓰기 전에 실패한다. 반복 갱신은 무변경이어야 한다.

## 검증

15개 학습 HTML 조사, 실험설명 5개와 동봉 템플릿 10개 반영, 5개 팩 검사, 본문과 나머지 파일 바이트 보존, 375px/1280px light/dark 동작, standalone 참조 0, 반복 갱신 무변경을 확인한다. 스킬 저작·검증·갱신 문서에도 자료 이동 영역을 추가하지 않는 규칙을 적는다.

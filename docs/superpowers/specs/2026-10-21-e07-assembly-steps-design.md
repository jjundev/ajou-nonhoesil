# 실험07 체크리스트 조립 순서 설계

상태: 2026-10-21 사용자의 `모두 추천대로`로 결정 0~7 확정. 구현은 별도 실행 요청 후 시작한다.

## 목적과 범위

기존 기능 확인 12단계와 V1~V12는 유지하고, 실험07 단계1 앞에 준비 6묶음을 추가한다. 공통 저작 규칙·데이터·생성기를 함께 수정하고 실험07을 첫 적용 사례로 삼는다. 실제 작업 블록은 기능 12개 + 준비 6개 = 18개이며, 기존 걷기 11개는 별도다. 모든 블록을 합치면 29개다. 준비 페이지는 6개 추가하며, 이름을 바꿔 작업량 증가를 감추지 않는다.

## 분할 원칙

- 조립 묶음은 목적·대조 범위·완료 조건이 명확해야 한다.
- 전원·임시 고정선·LED·칩 배치도 작업량에 포함한다. 기반 작업을 무조건 첫 단계에 몰지 않는다.
- 다른 칩이나 작업 목적으로 넘어갈 때 우선 분할한다. 같은 칩의 반복 접속은 세부 목록으로 묶을 수 있다.
- 기존 기능 단계의 새 신호선 예산은 유지한다. 총 접속 수에 대한 근거 없는 새 숫자 제한은 도입하지 않는다.
- 모든 준비 묶음은 전원 및 발생기 출력이 꺼진 상태다. 준비 완료 확인은 육안 배선 대조이며 통전·정상 동작의 증명이 아니다.

## 실험07 순서

| 소속 단계 | 순서 | 제목 | 범위와 완료 확인 |
|---|---|---|---|
| 1 | 1 | 보드·U1 전원 준비 | 칩 네 개 위치·노치, 전원 잭·레일, U1 전원핀·극성 대조 |
| 1 | 2 | U2 입력 고정 | U2 전원, CLK/CLR, PR, J/K를 네 항목으로 나누어 핀별 대조 |
| 1 | 3 | U3 입력 고정 | U3 전원, CLK/CLR, 고정 PR, J/K를 네 항목으로 나누어 핀별 대조 |
| 1 | 4 | U4 입력 고정 | U4 전원, CLK/CLR, 고정 PR, J/K를 네 항목으로 나누어 핀별 대조 |
| 1 | 5 | 위쪽 LED 준비 | 위쪽 BIT2·BIT1·BIT4의 LED·330Ω·GND, 극성 대조. 출력 급전은 연결하지 않음 |
| 1 | 6 | 아래쪽 LED 준비 | 아래쪽 BIT3·BIT6·BIT5의 같은 항목 대조. 출력 급전은 연결하지 않음 |

준비6 이후 기존 단계1에서 D 입력 점퍼와 NAND 입력 묶음을 연결한다. 전원 투입 전의 기존 전체 준비 조건을 대조하고 V1의 D=0→1→0을 수행한다. 단계1 설명에서 이미 끝낸 준비 작업을 다시 지시하지 않는다. 단계2~12, 걷기 주소, V1~V12의 내용·식별자와 T1~T3는 유지한다.

## 데이터 계약

`lab-netlist/v3` 회로 절에 선택 표 `## 조립 순서`를 추가한다. v2는 기존 문법 그대로이며 이 새 표를 쓰면 명시적으로 거절한다. 버전명을 바꾸지 않는 v3의 선택적 확장임을 스키마에 기록한다.

열은 정확히 `소속 단계 | 순서 | 제목 | 그림 | 이번 작업 | 완료 확인`이다. 소속 단계·순서는 양의 정수이며 원문 순서를 보존한다. 소속 단계는 같은 회로의 일반 단계 하나를 참조한다. 그룹별 순서는 1부터 연속이며, 소속 단계 순서도 기존 단계 등장 순서를 따른다. 중복 표, 중복 키, 빈 표·셀, 잘못된 열·정수는 파싱 오류다. 존재하지 않거나 중복된 부모 단계 참조, 빠진 순서는 검증 error다. 정렬해서 오류를 숨기지 않는다.

기존 `## 단계` 네 열·숫자/걷기 문법과 관측 절차 참조는 변경하지 않는다. 조립 표는 파싱 후 산문 본문에서 제거해 중복 인쇄하지 않는다. 새 필드는 빈 목록을 기본값으로 두어 표 없는 기존 입력의 동작을 보존한다.

## 그림과 출력

주차 배치 모듈의 선택적 `ASSEMBLY_BOARDS`는 부모 단계 PNG 파일명을 키로, `(준비 PNG 파일명, builder)`의 순서 있는 목록을 값으로 가진다. 기존 BOARDS·FINALS 튜플은 바꾸지 않는다. 일괄 렌더는 BOARDS의 해당 부모 직전에 준비 빌더를 삽입하고 snapshot을 다음 준비·부모에 전달한다. FINALS에는 준비 기준선을 전달하지 않는다.

준비는 추가 조립만 허용한다. 제거 작업은 기존 걷기에 남긴다. sig/mid 신호선·출력 급전은 준비에 옮겨 기존 신호선 예산을 우회하지 않는다. 전원·임시 고정·수동 LED 사슬만 분할한다. 기존 배치와 최종 레일 예약을 기준으로 좌표를 한 번 결정하고 준비 단계에서 다시 할당하지 않는다.

마지막 준비 그림은 기존 단계1에서 D 입력과 NAND 입력 묶음을 제외한 상태다. 새 단계1의 절대 연결·위치는 원래 단계1과 같다. 강조색·회색 및 작업 설명 변화는 허용한다. 완성본 위치·넷·콘텐츠 도장은 보존하며, PNG 바이트 차이는 같은 환경의 전후 렌더로 판별한다.

준비는 `단계 1 준비 ① · <제목>`으로 출력한다. 그림·핀/홀 작업 목록·완료 확인·`전원과 신호발생기 출력을 꺼요.`를 한 페이지에 싣는다. 정상 동작을 뜻하는 체크 문구나 관측표는 붙이지 않는다. 고정 인쇄 문구는 기존 스킬의 해요체를 따른다. 기존 fit 래퍼로 한 묶음 한 페이지를 구현하며 fit_pages의 측정 방식을 바꾸지 않는다.

표와 registry의 파일명·순서·부모 연결을 검증한다. 준비 그림이나 JSON 사이드카가 없으면 error로 정식 PDF 출력을 막는다. 생성 전 구조 검증과 생성 후 파일 검증을 구분해 그림이 없는 최초 저작을 막는 순환을 피한다. 기존 표 없는 실험의 누락 그림 처리 정책은 바꾸지 않는다.

## 보존·검증

- 기존 기록.md·명세 측정표·V1~V12·완성본·팀원전달용 파일·실험07 output 및 무관한 변경은 보존한다.
- 준비 중 전원이 꺼졌다는 이유로 물리 충돌·잘못된 레일 접속·배선 제거를 허용하지 않는다. 다만 미완성 준비에 통전된 모든 F/F 입력 구동 검사를 적용하지 않는다.
- 파서/의미 검사, 그림 사슬/물리 검증, HTML/페이지 검사, 실제 PDF 화면 검토를 수행한다.
- 초기 측정한 기록 해시와 단계별 넷·좌표를 작업 후 대조한다. static 검사만으로 화면 검토 완료라 하지 않는다.
- 다른 실험의 저장 산출물을 일괄 재생성하거나 커밋·푸시하지 않는다.

## 확정 결정

0=B 조립 순서 분리, 1=목적·범위·완료 조건, 2=준비 중 전원/발생기 끄기, 3=누적 그림, 4=기존 신호선 제한 유지 및 총량 제한 미도입, 5=묶음당 한 페이지, 6=공통 규칙+실험07, 7=준비6묶음.

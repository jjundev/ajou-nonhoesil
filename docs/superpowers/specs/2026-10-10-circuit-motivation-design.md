# 실험설명 도입부의 회로 사용 동기

## 확정된 의도와 범위

2026-10-10 사용자 선택: 기존 실험01~05 전체와 앞으로 생성할 실험설명에 적용한다. 기존 학습팩의 도입부를 개선하는 bounded 작업이다. 이후 사용자가 계획대로 직접 구현을 승인했다.

도입부만 읽어도 ‘어떤 문제를 해결하려고 이 회로를 쓰는지’와 이번 실험의 관찰 목적을 연결할 수 있게 한다. 첫 토픽 ID `t-start`를 유지하고 제목은 `왜 이 회로를 쓰는지 먼저 알아봐요`로 통일한다.

## 내용 계약

- 설명 순서: 해결할 문제 → 회로가 필요한 이유 → 작은 입력·출력 예 → 이번 실험과 연결.
- 새 동기 설명은 약 2~4개 짧은 문단, 다정한 ‘~해요’체로 쓴다. 정의·성립 조건·인과는 줄이지 않는다.
- 용어는 등장할 때 설명한다. 상세 식·진리표·기초 원리는 뒤의 기존 토픽에서 배운다.
- 이해를 위한 상황은 `이해를 위한 예시`로 표시하고 교안의 실제 수행 조건과 구분한다. 교안 밖 설명은 `보충`으로 표시한다. 활용 사례를 교안의 주장으로 꾸미지 않는다.
- 실험01: 여러 입력 조건을 만족하는지 판단하는 게이트의 필요성.
- 실험02: 현실의 전압을 안정적으로 0·1로 판정해야 하는 이유, Schmitt-trigger의 역할, 전환 속도를 살피는 이유. 이번 학기 수행하지 않는 AC 항목의 구분을 유지한다.
- 실험03: 이진수 계산에서 올림·내림을 다른 자리로 전달해야 하는 이유.
- 실험04: 여러 입력 중 하나를 선택하거나 한 입력의 목적지를 선택하는 이유. 데이터와 선택선의 역할을 구분한다.
- 실험05: 이진 코드와 개별 선택선 사이의 변환이 필요한 이유. 이상적인 활성 High 예와 74HC42·74HC148의 실제 극성, 일반 인코더의 one-hot 조건을 구분한다. Excess-3를 모든 인코더의 필수 출력으로 설명하지 않는다.

## 보존 계약

- 적용 대상은 `복습노트/실험01~05/`의 실험설명 HTML·MD와 해당 저작 원본, 앞으로 사용할 저작·검증 규칙이다.
- 기존 첫 토픽의 수행 범위·판본·예상과 측정 구분을 보존한다. 새 요약에는 ‘해결하는 문제’를 포함한다.
- `t-start` 이외 토픽의 본문·IDs, 읽음 저장 키, 기출문제·풀이·문제은행·그림·원문 증거를 보존한다.
- HTML과 MD는 같은 내용으로 만들고 출처는 manifest 기반으로 MD에 생성한다. HTML에 출처나 연결 문제 메타데이터를 넣지 않는다.
- 보고서·원자료·영상·새 위젯·화면 디자인 변경은 범위 밖이다.

## 현재 저장소에서 확인한 사항

- `.claude/skills/logic-lab-review-pack/references/authoring.md:5`는 이미 동기를 요구하지만 네 단계의 구체적 작성 기준이 없다.
- 실험01~05 모두 note/review presentation version 2이며 첫 fragment 경로는 `sections/t-start.html`이다.
- 보존된 저작 원본은 `docs/learning-pack-source/실험04`와 `실험05`에 있다. 실험01~03에는 같은 위치의 저작 원본이 없다.
- 실험04 `refresh_note.py:24`와 `:96`는 도입 본문·제목을 재생성한다. 실험05 `sections.py`의 `S['t-start']`와 `TOPICS`는 `build_run.py`에서 사용한다. fragment만 바꾸면 재생성 때 옛 내용으로 돌아간다.
- 공통 조립기 `scripts/lab/review_pack/render.py:48`는 저작 fragment를 조립한다. 동기 문장을 자동 생성하는 기능은 필요하지 않다.

## 검증과 완료 조건

입출력 예와 인과를 현재 교안·필요한 일반 이론에 대조하고 직접 검산한다. 기계 검사는 내용 정확성의 증명이 아니다. 5개 팩 모두 `check`를 통과하고, 375px·1280px 및 밝은/어두운 테마에서 첫 화면·목차·우측 요약·이전/다음·수식·그림을 확인한다. 기존 자료 보존을 비교하고 변경 후 검증 상태를 새로 기록한다. 실제 수행한 독립 리뷰 없이 `independent=pass`를 유지하거나 새로 기록하지 않는다.

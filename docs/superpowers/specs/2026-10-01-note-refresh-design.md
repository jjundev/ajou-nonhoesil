# 실험설명 문체·정보·그림 수정 설계

## 목표와 확정 범위
논리회로를 오래전에 배운 학생이 실험설명을 편하게 읽고 원리를 이해하도록 수정한다. 사용자 요청은 (1) 생명과학 정리노트의 TOSS 말투 적용, (2) ‘이 개념으로 풀 문제’와 출처는 MD에만 작성, (3) 강의노트를 포함한 오래된 설명 그림을 직접 다시 제작하는 것이다.

grill-yourself의 결정 #1은 사용자 후속 writing-plans 요청으로 권장안 확정: 실험설명의 모든 설명 그림을 교체한다. 기출풀이의 원문 이미지·문제은행·증거 파일은 보존한다. 실행 방식은 기존 native 선택을 유지한다.

## 동작
- 본문·요약·힌트·그림 설명은 짧고 다정한 ‘~해요’체로 쓴다. 수식·신호 이름·직접 인용은 유지한다.
- HTML에는 ‘이 개념으로 풀 문제’와 출처가 나타나지 않는다. DOM·요약 패널·인쇄에도 포함하지 않는다.
- MD에는 토픽별 출처와 연결 문제를 보존한다.
- 설명용 회로·블록도는 SVG, 진리표는 텍스트 표로 만든다. HTML과 MD에서 같은 그림을 사용한다.
- 목차, 페이지 이동, 요약 패널과 MUX 조작 기능은 유지한다.
- 생명과학의 레이아웃·조작을 유지한다. 생명과학 원본 템플릿을 그대로 보존하고 조립 시 슬롯 값만 수정한다.
- 원자료·측정값·도출값의 차이와 논리 조건은 유지한다. 원문의 모순은 새 그림으로 조용히 덮지 않는다.

## 구현 방향
공통 설명 본문과 MD 전용 메타데이터를 분리한다. 출처는 manifest.topics[].sources, 문제 연결은 status=included인 manifest.problems[].topics에서 생성한다. CSS로 숨기거나 완성 HTML에서 문자열을 지워 MD를 잃는 방식은 사용하지 않는다.

기존 팩은 이전 방식으로 검사할 수 있어야 한다. 새 manifest에는 note_presentation_version=2를 기록한다. 이 값은 HTML/MD 분리 출력과 메타데이터 보존 검사를 활성화한다. 새로운 외부 의존성이나 그림 생성 서비스는 필요 없다.

## 검증
HTML의 숨김 영역과 footer까지 제외 항목 부재를 검사한다. MD의 토픽별 메타데이터와 링크를 독립 검증한다. SVG의 접속·반전·주소 순서·극성을 식/진리표 및 원문과 대조한다. 375px 모바일, 데스크톱, 밝은/어두운 테마, 인쇄에서 확인한다.

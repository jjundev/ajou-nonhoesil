# 실험07 숫자 순서 최적화 후보 정식 반영

사용자가 승인한 전체 최적화 완성본(길이305.3158, 꺾임69, 밀집도3.4737)을 기준으로 삼는다.

1. `결선도/배치.py`의 NAND 9·10→8, 칩6/16/27/38행, LED14/18/26/30/36/40행과 승인 경로를 반영한다. R10 순서 예외는 주차 전용 렌더러로 한정하며 다른 규칙을 유지한다. 임시 입력선은 승인 완성 경로를 피해 예약하고 모든 통전 단계 입력 구동을 검증한다. 기존 넷 시험의 핀 변경과 숫자 순서/승인 지표 회귀를 먼저 실패시킨 뒤 구현한다.
2. netlist의 핀·슬롯·LED 순서·걷기 홀 주소와 배치탐색 기록을 동기화한다. 관측 기대값·명세 측정칸·작성된 기록은 보존한다. 준비6·기능12·걷기11·완성1을 재생성하고 구조·넷·도장·단계 예산을 검증한다.
3. 체크리스트 HTML/PDF를 fit_pages로 재생성한다. 팀원 손그림모사/부품그리기와 따라그리기 PDF를 재생성한다. 관련 시험과 PDF 이미지/페이지 크기·직접 시각 검사를 완료한다. 기존 자료는 /tmp/e07-adoption-backup에 보관했다. 커밋·푸시는 요청 범위가 아니다.

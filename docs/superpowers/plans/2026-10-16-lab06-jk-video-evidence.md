### 사건·사진 선정

후보 구간은 1편 `[11,16]` 비동기 Set, `[23,27]` 비동기 Reset, `[28,41]` CLK=0 유지, `[42,60]` JK 유지 조건에서 클럭 조작, `[61,94]` J=0/K=1, `[95,116]` J=1/K=0, `[117,134.242433]` J=K=1 실패 시도와 2편 전체다. 이는 최종 절단점이나 저장 프레임 시각이 아니다.

각 사건을 `id, source_id, start_s, end_s, t3_row, transcript_evidence, visible_observation, uncertainties`로 기록한다. 입력값과 에지는 화면에서 보인 것만 visible_observation에 넣는다. 전사로 알려진 값은 transcript_evidence에 둔다. 기존 사례에서 ‘JK 유지’ 발언만으로 J=K=0을 확정할 수 없다.

후보 구간을 먼저 1초 간격으로 보고 조작·출력 변화 부근은 0.1초 간격, 경계는 원본 프레임 간격까지 좁힌다. 시간 표시는 실제 원본 프레임 PTS다. 손 가림·초점·회로와 LED 식별성으로 안정 프레임을 골라 불필요한 중복을 줄인다.

Set/Reset은 안정 상태 대표 사진, 유지/동적 동작은 의미 있는 전후 사진을 만든다. 2편에서 조작 전후가 보이지 않으면 ‘배선 수정 후 최종 상태’로만 분류한다. 전후 패널에 원본 편 번호·시각·입력 근거 종류를 표시한다. 무주석 PNG는 자르지 않은 표시 방향 전체 프레임이다.

### 편집 규칙

1편의 전원 미인가 도입부는 제외하되 첫 유효 조건 설명이 시작되는 문맥을 보존한다. 약 117초 이전의 관찰 구간은 보존하고 마지막 실패 시도는 제외한다. 117초 이후 조건 설명만 온전히 남길 수 있으면 실패한 조작 전에 자르고, 문장이 잘리거나 실패 동작과 분리할 수 없으면 마지막 정상 항목 설명이 끝나는 지점에서 자른다. 실패로 귀결되는 시도를 성공 과정으로 제시하지 않는다.

연결 사이 2초 동안 `배선 조정 후 재촬영`을 표시하고 중단 구간임을 명시한다. 설명 음성을 재합성하지 않는다. 2편의 유효 시작부터 실제 전원 차단 직전까지 연결한다. 소등 시점은 전사의 약 6초가 아니라 영상으로 정한다. 원본 음성이 필요한 설명에서 절단되지 않도록 전사와 대조하되, 직접 청취하지 못한 경계의 청감 자연스러움은 미확인으로 보고한다.

사진은 PNG, 최종 영상은 1080×1920, H.264/yuv420p, 30fps CFR, AAC 48kHz stereo, MP4 faststart로 출력한다. 두 원본의 평균 프레임률이 약 30인 것을 재확인한 뒤 원래 시간축으로 변환한다. CRF 18, preset medium으로 한 번 인코딩하고 회전 메타데이터를 중복 적용하지 않는다. 최종 실험 음성 구간은 영상과 같은 원본 절단점을 사용한다. 간단한 커트·연결·중단 표시는 로컬 FFmpeg로 처리한다.

- [x] **Step 3:** `ffmpeg -v error -i <최종 MP4> -f null -` 전체 디코딩이 exit 0인지 확인한다. ffprobe로 표시 방향 1080×1920, 비디오/오디오 존재, H.264/AAC, 약 30fps, 회전 중복 없음, A/V 종료 시각 차이 0.1초 이내를 검사한다. 출력 길이는 원본 보존 구간 길이 합+2초와 0.1초 이내로 일치해야 한다.
- [x] **Step 4:** 최종본 시작·모든 절단점 전후·중단 표시·2편의 끝을 직접 보고, 실패 장면·전원 차단이 제거되고 정상 상태와 자막이 보존됐는지 확인한다. 생성본과 입력의 해당 시각을 대조한다. 직접 청취할 도구가 없는 조건에서는 수치상 동기 검증과 청감 미확인을 구별한다.
- [x] **Step 5:** 입력 4개의 SHA-256을 다시 계산해 시작값과 모두 일치하는지 확인한다. 검사 결과와 실제 수치·오류를 검증결과에 남긴다. 실패가 있으면 완료라고 보고하지 않고 해당 산출물만 수정·재검증한다.
- [x] **Step 6:** 사진 폴더·비교 시트·최종 MP4·미확인사항에 대한 절대 경로 링크와 사진 장수·최종 길이를 전달한다. 원본 보존 해시 일치와 미확인 항목을 별도로 알린다. 커밋하지 않는다.

## 계획 자체 검토

- 사진 추출과 영상 연결은 같은 시간선의 두 산출물로 묶었으며 별도 기능 개발을 추가하지 않았다.
- 승인된 설계의 원본 보존·JK 항목 수정·전사 사용·전후 사진·실패 제거·재촬영 표시·미확인 보고를 Task 1~3에 대응했다.
- 인터페이스의 source_id·시각·사건/사진/편집 필드 이름을 작업 간 일치시켰다.
- Review Focus 5개를 각 작업의 실제 파일 검증과 직접 판독으로 확인한다.
- 프레임 시각·절단 시각은 관찰 작업의 결과다. 임의의 확정값을 넣지 않고 선택·검증 기준을 명시했다.
- 실행은 계획 검토 후 시작한다. 작업 간 시각 판단이 밀접하므로 Native 실행을 추천한다.

# 체크리스트 입력·LED 위치 안내 구현 계획

> 실행: 이 대화에서 직접 구현한다. 사용자 승인: 공통 기능 추가 + 실험06 체크리스트만 재생성.

**목표:** 표를 보는 자리에서 조작할 입력 점퍼와 관측 LED의 실제 위치를 확인한다.
**설계:** 2026-10-16 대화에서 승인된 grill-yourself 설계. 결선 엔진 입력 좌표를 선택적 사이드카 필드로 내보내고, 체크리스트 표 앞에 위치도를 만든다.
**기술:** Python, HTML/CSS, Chrome PDF, unittest.

## 제약

- 진리표 열·행·값·사진명·LED 번호와 기록.md를 유지한다.
- 입력은 조작하는 레일 끝 기준으로 그룹별 위→아래 정렬한다.
- 단계는 단계 JSON, 기록표는 완성본 JSON을 쓴다. 누락은 표시하고 검사에서 경고한다.
- 기존 v1 사이드카 계약을 유지한다. 실험06 이외의 산출물은 재생성하지 않는다.

- [x] engine/renderer.py: v2 sidecar inputs(name, at, rail, x, row) 파생. 도장 밖 메타데이터로 추가.
- [x] scripts/lab/io_locations.py: 읽기·검증·물리 그룹 정렬·위치도 HTML.
- [x] render.py 및 template.html: 기록·단계·중간 노드 표 앞에 위치도 연결. 표와 안내를 같은 쪽에 유지.
- [x] validate.py와 두 스킬: 누락 검사·생성 계약 문서화.
- [x] 실험06 사이드카·HTML·PDF 재생성. 기존 기록 해시와 표 셀 회귀 확인.
- [x] 관련 테스트, HTML 검사, PDF 쪽 크기·시각 검수, diff 검토.

## 실행 기록

- 신규 위치 기능 테스트 실패를 확인한 뒤 구현했다. 관련 테스트 546개 통과.
- 리뷰에서 누적 관측 LED의 입력 합집합 검사 누락을 발견했다. 실험05 C2 단계2(D5·D0) 회귀 테스트의 실패를 확인하고 수정했다. 재리뷰에서 해결 확인.
- 실험06 기존 HTML의 표 13개가 바이트 단위로 동일하고 기록.md SHA256은 `6b54d58eddf5da2a751191550d1e57f87c05efd93884f329be2ada39025dca36`으로 유지된다.
- Ruling: 엔진이 내보내는 그림의 글꼴이 기존 PNG와 달라졌으나 결선 도장이 같았다. 기존 그림 바이트를 보존하고 입력 JSON만 갱신했다.
- 위치 안내 6개(기록 3·단계 1·노드 2)를 PDF로 렌더해 시각 확인했다. 프로브용 표에서는 LED를 흐리게 표시한다.

## 검토 초점

가운데 레일, 같은 신호의 복수 점퍼, 입력 부분집합의 순위 보존, 걷기·이름 변경, 기존 위치 없는 JSON.

- Produces:
  - `SUMMARY_FILE = 'sections/note-summaries.json'`
  - `load_note_summaries(root: Path) -> dict[str, dict] | None` — `root/SUMMARY_FILE` 이 없으면 `None`. 파일 형식은 `{"schema_version": 1, "topics": {"<topic-id>": {"rules": [["조건", "결과"], ...], "why": "…", "traps": ["…", ...]}}}`. `why`·`traps` 는 생략 가능하다. 반환값은 `topics` dict. 형식이 틀리면 `ValueError(f'{path}: {topic_id}: …')`.
  - `render_summary(parts: dict) -> str` — `<div class="sum" hidden>…</div>` 전체를 돌려준다.
  - `replace_summary(topic_id: str, fragment: str, parts: dict) -> str` — 조각 안의 `<div class="sum" hidden>…</div>` 정확히 하나를 `render_summary(parts)` 로 바꾼다. 0개나 2개 이상이면, 또는 그 div 안에 `<div` 가 있으면 `ValueError(topic_id + ': …')`.
  - `summary_text(fragment: str) -> str` — 조각의 div.sum 안 텍스트(태그 제거, `html.unescape`).
  - `lost_tokens(old_html: str, new_html: str) -> list[str]` — `re.findall(r"[A-Za-z0-9][A-Za-z0-9′'̄⊕]*", …)` 로 뽑은 토큰 중 old 에 있고 new 에 없는 것을 처음 나온 순서대로, 중복 없이.
  - `check_topic_ids(summaries: dict, topic_ids: list[str]) -> None` — 빠진 id 는 `ValueError('<id>: missing summary')`, 남는 id 는 `ValueError('<id>: unknown topic')`.

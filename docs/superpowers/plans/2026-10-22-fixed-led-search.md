# LED 고정 배치 탐색 구현

사용자 승인 설계: LED 숫자 순서와 현재 좌표를 고정한다. 최단 검증 길이의 +10% 안에서 밀도 우선으로 선택한다. 경로 계산 예산은 256회다.

## 범위와 제약

- 실험07 LED: BIT1~6 = 14/18/26/30/36/40행.
- 기존 승인 경로·그림·체크리스트·측정 기록은 유지하고 별도 탐색 결과를 낸다.
- 과거 실험의 기본 배치기 및 도장 호환성을 유지한다.
- 전역 최적성 보장은 하지 않는다. 경로 탐색 실패와 배치 불가능성을 구분한다.
- 커밋·푸시는 하지 않는다.

## 작업

1. LED 고정, +10% 선택, 실제 교차, 계산 예산, 배선 ID의 실패 테스트를 먼저 실행한다.
2. R10 연결 규칙/순서 정책을 분리하고, 기존 경로 생성기에 고정 LED 탐색을 연결한다.
3. 다양한 배치·등가 할당, 배선 순서/λ 변형, 주변 개선과 결정적 예산 제어를 구현한다.
4. 실험07의 후보 컨텍스트·임시선·모든 실제 단계 검증과 승인본 논리 넷 대조를 연결한다.
5. 기존 회귀 검사, 프로세스 수에 따른 재현성, 256회 실험07 탐색을 실행한다.
6. 별도 경로에 결과 JSON/보고서/선택 후보 30장과 좌우 비교 그림을 남긴다.

## 구현 판단

- Ruling: 고정 LED 모드는 명시적으로 선택한다. 기존 주차의 승인본에 새 정책을 소급하지 않는다.
- Ruling: 256회는 영구 신호선 전체의 경로 생성 시도 수다. 승인 경로의 재검증은 새 경로 생성으로 세지 않는다. 임시 전원/접지선은 실제 신호선과 공존하는 구간을 기준으로 별도 예약한다.
- Ruling: 단계의 선 합집합을 최종 순위로 사용하지 않는다. 실제 30개 보드를 검사하며, 논리 넷을 물리 행/등가 핀 할당과 무관한 단자 ID로 정규화해 승인본과 비교한다.
- Ruling: 전체 예산의 절반은 다양한 배치, 1/4은 배선 정책/λ 변형, 나머지는 주변 개선에 사용한다. 중복을 건너뛰고 남는 예산은 전역 후보로 채운다.

## 확인된 개발 중 검증

- 새 모듈 부재로 테스트 수집 실패 확인 후 구현.
- 후보 순회가 첫 128개에서 8개 배치에만 치우치는 회귀 테스트 실패 확인 후, 배치/할당을 분산하도록 수정.
- 논리 넷 동등성 검사 부재로 실패 확인 후 구현. LED 이름을 교환한 오류를 검출한다.
- 강화 전 관련 회귀 688 passed, 58 subtests passed.
- 강화 후 최종 결과는 별도 검증 보고서에 기록한다.
- Ruling: 독립 검토로 원래 게이트의 가운데 레일 점유를 기준으로 모든 할당을 가지치기하는 문제가 확인됐다. NAND3 pin9과 NAND4 pin12의 실제 행이 다르며 LED의 레일 점퍼는 LED를 옮기지 않고 다른 레일 홀을 쓸 수 있다. 해당 조건으로 가능한 후보를 제외하는 실패 테스트를 확인한 뒤 조건을 제거하고 최종 256회를 재실행했다.
- Ruling: 기존 `slot_candidates()`는 pin1/반대쪽 끝 행을 전원 레일 홀에 맞추는 모서리 전원 가정을 포함했다. HC76의 실제 VCC/GND는 pin5/pin13이므로 새 탐색은 이 가정을 물려받지 않고, 칩 순서·3~6행 간격·보드 경계로 후보를 생성한 뒤 실제 전원/홀 연결을 검증한다. 비모서리 전원 칩의 가능한 후보가 빠지는 실패 테스트를 확인한 뒤 수정했다.
- Ruling: 배선 정책 비교 단계에서 후보 8개의 Cartesian product를 예산으로 자르면 높은 λ/뒤쪽 순서가 누락될 수 있었다. 회귀 테스트로 이 위험을 고정하고, 최대 4개의 서로 다른 후보에 λ 4종 × 순서 4종의 완전한 프로파일을 배정하도록 바꿨다. 부족한/중복 예산은 주변/전역 탐색으로 채우며 전체 예산 256회는 유지한다.

## 완료 증거

- 최종 경로 계산 256회 완료: 통과 65회, 실패 191회. 현재 승인본을 별도로 검증 후 최종 선택했다.
- 최단 후보 302.6842칸, 선택 길이 띠 332.9526칸. 선택된 승인본은 길이 305.3158칸·밀도 3.4737·교차18·꺾임69다.
- 관련 회귀 검사 822 passed, 449 subtests passed. 1/2프로세스 소규모 실행의 결과 전체가 같다.
- 출력된 선택 후보 30개 PNG/JSON과 실제 LED 위치를 대조했고, 기존 자료 69개 SHA-256이 유지됐다.
- 독립 리뷰와 `git diff --check`를 마쳤다. 결과와 비교 이미지는 `docs/verification/2026-10-22-e07-fixed-led-search.md`가 가리킨다.

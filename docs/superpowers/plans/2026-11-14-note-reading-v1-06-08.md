# 실험06~실험08 실험설명 읽기 방식 v1(`note_reading_version=1`) 재작성 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `실험06`·`실험07`·`실험08` 복습 팩의 `실험설명` HTML/MD 본문만 읽기 방식 v1(`note_reading_version=1`) 계약에 맞춰 재작성하고 검증해 발행한다.

**Architecture:** `docs/learning-pack-source/실험06~08/`의 `h.py`·본문 원고(`sections.py`/`content.py`)·`build_run.py`를 `실험09` 선례와 동일하게 결론 우선 구조(`p.gist`, 내용 소제목, 추적표 ‘왜 이 값인가요’ 열, `data-row="compare|avoid"`, `pull_layouts`)로 갱신한다. 각 실험의 발행본 `.pack/`을 임시 `RUN`으로 복제해 `review_pack build`로 `note_reading.py`와 `check_pack`을 통과시키고, 기출·문제설명·그림·요약·PDF가 동일함을 확인한 뒤 `실험설명` HTML/MD·`table-layout.json`·`manifest.json`(`note_reading_version`)·`검증결과.md`만 반영한다.

**Tech Stack:** Python 3, `scripts/lab/review_pack` (`render.py`, `note_reading.py`, `html2md.py`, `table_layout.py`, `checks.py`), `pytest`, Chromium(로컬 HTTP 시각 검증)

**Spec:** 본 대화의 `/grill-yourself` 확정 설계(2026-11-14) 및 [authoring.md](../../../.claude/skills/logic-lab-review-pack/references/authoring.md#L11-L36)

## Global Constraints

- `실험09`는 `af2dc1ec`에서 이미 `note_reading_version=1` 적용·검증 완료 상태이므로 수정하지 않는다.
- `manifest.json`에 `note_presentation_version=2`, `note_summary_version=2`, `note_reading_version=1`이 함께 지정되어야 한다(`scripts/lab/review_pack/manifest.py:115-116`).
- 모든 토픽(`t-start` 포함) 첫 `div.layer`는 결론/질문 소제목 바로 다음에 `<strong>`이 포함된 `<p class="gist">`를 두어야 한다(`scripts/lab/review_pack/note_reading.py:186-193`).
- 절차형 범용 제목(`'새 이름부터 알아봐요'`, `'한눈에 보기'`, `'작은 예부터 살펴봐요'`, `'조건과 작동 원리를 확인해요'`, `'헷갈리기 쉬운 것'`, `'헷갈리기 쉬운 말'`)과 군말 문장(`'줄로 기억하면 충분해요'`, `'외울 필요 없고'`)을 쓰지 않는다(`note_reading.py:158-166`). 연습 제목 `'한 단계만 풀어 봐요'`는 유지한다.
- 본문에 「한눈에 보기」 조건|결과 규칙표를 두지 않고, 추적표 마지막 열(‘왜 이 값인가요’ 또는 ‘동작 · 이유’, 열 코드 `t`)과 `tr[data-row="compare"]`(한 표에 2개 이상)·`tr[data-row="avoid"]`만 사용한다(`note_reading.py:167,202-207`, `authoring.md:20-23`).
- 본문에 `'교안 p7'` 같은 출처 표식을 쓰지 않고(교안 오류를 다루는 `warn` 문장 안 쪽수 제외), 출처·범위 고지·근거는 `topics[].sources`, `md_notes`, `div.sum`에 둔다(`authoring.md:27`).
- `div.sum`(및 `실험06`의 `note-summaries.json`), `supp` 연습 문항, 추적표 계산 값, `md_notes`, 설명 SVG, `기출문제`/`기출풀이`/`문제설명`은 변경하지 않는다.
- 기존 `problems.py`·`explanations.py`·`quiz.py`·`build_run.py`가 호출하는 `h.table(headers, rows, cls='table-wrap')`의 2~3인자 호환성을 깨뜨리지 않는다.

## Review Focus

- `실험06`/`실험07`에서 `table(headers, rows)`를 2~3인자로 부르는 문제·해설·작도 코드가 `cols` 추가 때문에 `TypeError`로 깨지는 실패 → `ltable(headers, rows, cols, marks=None, cls='table-wrap')`로 분리하고 기존 `table()` 시그니처를 유지해 `build_run.py`와 `review_pack build` 통과로 검증한다.
- `실험06` 재빌드 시 `sections.py`의 구버전 한 문단 `sumd`가 발행본 `.pack/sections/note-summaries.json`을 덮어써 `note_summary_version=2`와 `summary-audit.md` 정합성이 깨지는 실패 → `RUN/sections/note-summaries.json`을 보존해 `assemble`이 `replace_summary`로 정본 요약을 유지하게 하고 `check_pack`으로 검증한다.
- `실험07/build_run.py`의 비레이어 토픽 자동 래퍼가 `'작은 상태부터 살펴봐요'` 등 금지 제목을 생성하거나, 전체 `publish` 실행으로 `generated_files` 안의 `실험07_기출문제.pdf`·`실험07_기출풀이.pdf`가 유실되는 실패 → 모든 토픽을 명시적 `layer(...)`로 작성해 자동 래퍼 분기를 없애고, `실험09` 선례처럼 실험설명 관련 파일만 선택 반영한 뒤 PDF 존재 및 `check_pack`을 확인한다.
- 「한눈에 보기」 규칙표 제거와 ‘왜 이 값인가요’ 열 추가 후 `sections/table-layout.json`의 표 순번·열 수 불일치로 `TableLayoutError`가 나는 실패 → `실험06`/`07`/`08` 모두 `pull_layouts`로 `table-layout.json`을 재생성해 `assemble`을 통과시킨다.
- 토픽 ID(`t-*`) 변경·누락이나 추적표 값 변조로 `기출풀이`/`문제설명`의 `#t-...` 앵커가 깨지거나 기존 논리 검산이 어긋나는 실패 → 토픽 ID와 추적표 수치를 원고대로 고정하고 `check_pack`의 앵커 검사와 기존 계산 스크립트(`problems.py`, `check_values.py`)를 실행해 확인한다.

# 결선도 렌더러 — 엔진과 주차 결선 분리 설계

- 날짜: 2026-09-15
- 기준 커밋: `85a7a14` (실험03 GND 브리지 한 가닥 합치기 직후)
- 계기: 실험03 GND 브리지를 고치면서 "실험이 진행될 때마다 스킬 폴더의 py 를 수정해야
  하는가" 라는 질문이 나왔다. 답은 "지금 구조에서는 그렇다" 였고, 그 구조를 바꾼다.

## 문제

`.claude/skills/breadboard-diagram/scripts/render_breadboard.py`(2593줄) 한 파일에 공용
엔진과 주차별 결선이 함께 산다.

| 구간 | 줄 | 내용 |
|---|---|---|
| 엔진 | 1–1580 | `BreadboardRenderer`·배선 도구·`verify()`·`_input_jumper` 등 |
| 실험01 | 1581–1935 | `E1_SLOTS`·`_e1_*`·`build_e1_*`·`E1_BOARDS`·`E1_FINALS`·`build_e1_all` |
| 실험02 | 1936–2183 | 같은 꼴 (`E2_*`·`_e2_*`·`build_e2_*`) |
| 실험03 | 2184–2546 | 같은 꼴 (`E3_*`·`_e3_*`·`build_e3_*`) |
| CLI | 2547– | `main()` — `--circuit` 분기표가 모든 주차 이름을 안다 |

`SKILL.md` §6 이 "주차마다 `build_eN_*` 를 이 파일에 쓴다" 고 지시한다. 그래서:

1. **스킬 수정과 결선 수정이 구분되지 않는다.** git 이력으로 "도구가 바뀌었나" 를 볼 수 없다.
2. **격리 검증이 파일 일부를 잘라낸다.** 답안(그 주 결선)이 도구 파일 안에 있어
   `scripts/lab/breadboard_isolate.py` 가 `# 실험 1 ·` 주석을 찾아 구간을 걷어낸다. 주석
   규약 하나가 어긋나면 답안이 든 트리로 시험한다.
3. **파일이 주당 약 300줄씩 는다.**
4. 커밋된 PNG 가 코드 출력과 어긋나도 아무도 모른다 — 실험01 PNG 13장이 지금 그 상태다
   (아래 §사실 4).

## 사실 (코드로 확인한 것 — 결정의 전제)

1. **주차 구간은 서로를 부르지 않는다.** AST 로 셌다: 각 구간이 쓰는 엔진 이름은
   `BreadboardRenderer`·`_input_jumper`(실험01·03)·`os`·`tempfile` 뿐이고, 다른 주차의
   이름은 0개다. 엔진 본체도 주차 이름을 부르지 않는다(`main()` 분기표만 예외).
2. **세 주차의 `build_eN_all` 은 이름만 다르고 몸체가 같다** — 보드 사슬을 기준선으로
   이어 뽑고 완성본을 뽑는다.
3. **렌더는 같은 기계에서 바이트까지 결정적이다.** `e3_all` 을 두 번 뽑아 5장 모두 같다.
4. **글꼴은 기계의 시스템 글꼴이다**(`FONT_CANDIDATES`: Apple SD Gothic Neo → 맑은 고딕 →
   나눔고딕). 커밋된 실험01 PNG 13장은 지금 코드 출력과 전부 다르지만, PNG 를 커밋한
   시점(`992ad74`)의 렌더러를 이 기계에서 돌리면 지금 코드와 13장 모두 바이트가 같다.
   차이는 **커밋 당시 기계의 글꼴**뿐이다(배선 동일, 높이 28~32px 차이). 실험02·03 은
   코드 출력과 바이트가 같다.
5. **회로 ID 가 저장돼 있다.** `보고서/실험01/output/손그림검토/round*/전사/*.json` 에
   `"circuit": "e1_nand"` 등 20건. `hand_compare.reference_diagram` 은 `build_{회로 ID}` 를
   찾는다. 그래서 결선 함수 이름은 바꾸지 않는다.
6. **격리 트리는 `git archive HEAD` 로 만든다**(`scripts/lab/isolate.py`). git 이 추적하지
   않는 `__pycache__/*.pyc` 는 트리에 들어가지 않는다. `tests/` 는 통째로 답안지다.
7. **고아 PNG 는 없다.** 세 주차 모두 결선도 폴더 PNG 목록 = 코드가 만드는 목록.
8. 커밋된 결선도 PNG 의 픽셀을 읽는 코드는 없다(`test_breadboard_coords` 는 템플릿을 연다).
   격리 판정(`breadboard_compare.judge`)은 승인본을 코드로 새로 뽑고, 재생성 PNG 는
   파일명만 본다.

## 엔진 인터페이스

| 이름 | 하는 일 |
|---|---|
| `BOARD_FILE = '배치.py'` | 주차 결선 파일 이름 |
| `board_path(n) -> str` | `REPO_ROOT/<config.experiment_dir(n)>/결선도/배치.py`. 경로 규칙은 `scripts.lab.config` 에만 있다 |
| `board_numbers() -> list[int]` | `<EXPERIMENT_BASE>/실험*/결선도/배치.py` 글롭 → 실험 번호. `experiment_folder_name(n)` 으로 되돌려 같을 때만 센다 |
| `load_board_file(path, name=None)` | 주차 파일 하나를 모듈로 불러온다 |
| `load_board(n)` | `load_board_file(board_path(n), f'board_e{n}')` |
| `build_all(board, output_dir, template_path=None) -> dict` | `board.BOARDS` 를 기준선으로 이어 뽑고 `board.FINALS` 를 뽑는다. `{파일명: 도장}` |
| `BreadboardRenderer.content()` / `.stamp()` | 도장에 드는 내용 / `'v1:' + sha256` |
| `STAMP_KEY = 'breadboard-stamp'` · `read_stamp(path)` | PNG 텍스트 청크 키 / 읽기 (없으면 `None`) |

**로더가 엔진 사본을 섞지 않는 법.** 테스트·대조기는 엔진을 `importlib` 로 여러 번
로드한다(모듈 이름 `render_breadboard`, `rb_test_*` 등 — `sys.modules` 에 등록하지 않는다).
`load_board_file` 은 실행하는 동안만 `sys.modules['render_breadboard']` 에 **자기를 부른
엔진의 전역 이름을 담은 모듈**을 끼우고, 끝나면 원래대로 되돌린다. 그래서 `배치.py` 의
`BreadboardRenderer` 는 그 엔진의 클래스와 같은 객체다 — 테스트가 클래스 메서드에 거는
스파이(`BreadboardRenderer.export = spy`)가 그대로 먹는다. 모듈 속성을 통째로 바꿔치는
스파이(`mod.BreadboardRenderer = Spy`)는 주차 모듈 쪽에 걸어야 한다. 불러오는 동안
`sys.dont_write_bytecode` 를 켜 보고서 폴더에 `__pycache__` 를 만들지 않는다.

## 도장

- 키 `breadboard-stamp`, 값 `v1:<sha256 hex>`.
- 해시 대상: `json.dumps(content(), ensure_ascii=False, sort_keys=True, default=…)` 의 UTF-8.
- `content()` = `title`·`subtitle`·`submit`·`notes`·`steps`·`probes`·`kept`(기준선이
  있으면 개수, 없으면 `None`)·`removed()`·`wiring()`. 전부 주차 파일이 넘긴 문자열·홀
  주소·템플릿 좌표라 글꼴과 무관하다. 줄바꿈된 줄은 넣지 않는다(글꼴 폭에 따라 갈린다).
- `export()` 가 `verify()` 뒤에 계산해 `PngInfo` 로 찍는다.
- 검사(`tests/test_breadboard_boards.py`):
  - `board_numbers()` 마다 임시 폴더에 `build_all` → 결선도 폴더 PNG 집합 = 결과 키 집합,
    파일마다 `read_stamp(PNG) == 결과 도장`. 실패 문구가 `--experiment N` 으로 다시 뽑으라고 말한다.
  - 엔진 `_font` 를 `ImageFont.load_default(size)` 로 바꿔 뽑아도 도장이 같다(Pillow ≥ 10.1).

## 이행 증명

1. **옮기기**: 옮기기 전 코드(`--circuit eN_all`)와 옮긴 뒤 코드(`--experiment N`)를 같은
   기계에서 임시 폴더에 뽑아 21장 모두 바이트가 같다. 커밋된 PNG 는 이 단계에서 건드리지 않는다.
2. **도장**: 21장을 다시 뽑는다. 실험02·03 은 픽셀이 같고(도장만 더해진다), 실험01 은
   글꼴만 바뀐다. 체크리스트 PDF 는 다시 내지 않는다 — 실험02·03 은 픽셀이 같고, 실험01 은
   제출이 끝났다.
3. **배관**: 격리 트리를 만들어 실험01 `배치.py`·PNG 가 없고, 누출 토큰이 구조적 누출
   외에 0건이고, 승인본 `배치.py` 자기 대조가 치명·기능 0건이다.

## 범위 밖

- 칩 자리가 `netlist.md` `kind: layout` 표와 `배치.py` 슬롯 상수에 두 번 적힌 중복.
- 결선을 데이터(YAML 등)로 바꾸는 것 — 선을 어느 행으로 돌리는가 같은 판단이 코드다.
- 격리 재생성(에이전트가 결선을 다시 짜는 단계) 실행.
- 노션·제출본의 그림 교체.

# 체크리스트 회로 단위 재설계 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `prep-lab-checklist` 가 내는 인쇄본을 "회로 하나 = 결선도 + 배선 + 유의사항 + 측정표" 단위로 재편해, 실험실에서 쪽을 왕복하지 않고 쓸 수 있게 만든다.

**Architecture:** `netlist.md` 의 `# ` 절마다 속성 리스트(`kind`, 그리고 회로면 `id`/`item`/`tables`/`diagram`)를 요구하는 `lab-netlist/v1` 계약을 신설한다. 새 파서 `netlist_parser.py` 가 이것을 읽고, `kind` 가 인쇄 목적지를 정하는 **라우터**가 된다(공통면 / 참조표 / 확인목록 / 인쇄제외 / 회로 페이지). `render.py` 는 하나의 연속 번호 목록 대신 공통면 1장 + 회로마다 강제 개쪽 + 종료면을 낸다. 기존 `check_netlist` 와 `record.py` 는 건드리지 않는다.

**Tech Stack:** Python 3.14 표준 라이브러리만 (PyYAML 없음, `md.py` 의 미니 YAML 파서 사용). 테스트는 `unittest`. PDF 는 Chrome 헤드리스.

## Global Constraints

- **테스트 실행기는 `unittest` 다.** 이 머신에 `pytest` 가 설치돼 있지 않다. 명령은 항상 `python3 -m unittest ...` 형태다.
- **표준 라이브러리만 쓴다.** `md.py` 헤더가 "PyYAML 이 이 환경에 없으므로"라고 명시한다. 새 의존성을 추가하지 않는다.
- **저장소 언어는 한국어다.** 주석·docstring·오류 메시지·테스트 이름 모두 한국어로 쓴다. 코드 식별자와 경로만 원문.
- **경로 상수를 문자열로 베끼지 않는다.** 실험 폴더 경로는 `config.experiment_dir(n)`, 루트까지의 `../` 사슬은 `config.root_relative_prefix()` 를 쓴다 (`config.py:EXPERIMENT_BASE` 주석이 이 규칙의 근거와 과거 사고를 적고 있다).
- **인쇄본 본문에 마크다운 표기가 남으면 안 된다.** 백틱과 `**` 는 `render._plain()` 으로 벗긴다. `tests/test_lab_render.py:test_markdown_syntax_does_not_reach_print` 가 이것을 잠그고 있다.
- **`class="check"` 는 명세의 기록 대상 표 행에만 쓴다.** 개수를 `test_check_cells_exist_for_every_truth_table_row` 가 명세에서 계산해 대조한다. 그 외의 체크박스는 `class="box"` 를 쓴다.
- **`role: reference` 표(실험1 의 T6~T9)는 인쇄본에 넣지 않는다.** 기존 규칙이고 테스트가 잠그고 있다.
- **기존 `check_netlist(path, spec)` 의 동작을 바꾸지 않는다.** 다섯 SKILL.md(`draft-lab-spec`·`write-pre-report`·`write-result-report`·`review-lab-report`·`prep-lab-checklist`)가 그것을 부르고, 실험02·03·05·06·10 은 아직 회로 메타가 없다. 거기서 거절하면 네 스킬이 다섯 주차에서 동시에 멈춘다.

```python
결선도가 없는 것보다 **틀린 결선도가 나오는 것**이 훨씬 나쁘다 — 그 지점이
netlist 스스로 "가장 흔한 배선 실수"라고 표시한 곳이기 때문이다.

임포트하지 않고 소스를 `ast` 로 읽는다. 이 스크립트는 패키지가 아니고 PIL 을
끌어온다.
"""

import ast
import unittest
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
SRC = ROOT / ".agents/skills/breadboard-diagram/scripts/render_breadboard.py"
SKILL = ROOT / ".agents/skills/breadboard-diagram/SKILL.md"


def _tree():
    return ast.parse(SRC.read_text(encoding="utf-8"))


def _dispatch_pairs():
    """`dispatch = {...}` 의 (회로 ID, 빌더 함수 이름) 목록."""
    for node in ast.walk(_tree()):
        if isinstance(node, ast.Assign) and any(
                isinstance(t, ast.Name) and t.id == "dispatch" for t in node.targets):
            return [(ast.literal_eval(k), v.id)
                    for k, v in zip(node.value.keys, node.value.values)]
    raise AssertionError("dispatch 딕셔너리를 못 찾았다")


def _choices():
    """`--circuit` 인자의 choices 리스트."""
    for node in ast.walk(_tree()):
        if (isinstance(node, ast.Call)
                and isinstance(node.func, ast.Attribute)
                and node.func.attr == "add_argument"
                and node.args and getattr(node.args[0], "value", "") == "--circuit"):
            for kw in node.keywords:
                if kw.arg == "choices":
                    return ast.literal_eval(kw.value)
    raise AssertionError("--circuit 의 choices 를 못 찾았다")


class BreadboardDispatch(unittest.TestCase):
    def test_회로_ID_가_빌더를_공유하지_않는다(self):
        """두 회로가 한 빌더를 쓰면 둘 중 하나는 반드시 틀린 그림이다."""
        pairs = _dispatch_pairs()
        seen = {}
        shared = []
        for circuit, builder in pairs:
            if builder in seen:
                shared.append(f"{seen[builder]} 와 {circuit} 가 {builder} 를 공유한다")
            seen[builder] = circuit
        self.assertEqual(shared, [], "\n".join(shared))

    def test_choices_와_dispatch_가_같은_집합이다(self):
        self.assertEqual(sorted(_choices()),
                         sorted(c for c, _ in _dispatch_pairs()))

    def test_지원하지_않는_회로를_SKILL_문서가_광고하지_않는다(self):
        doc = SKILL.read_text(encoding="utf-8")
        supported = {c for c, _ in _dispatch_pairs()}
        for gone in ("e1_or", "e1_nor"):
            if gone not in supported:
                with self.subTest(circuit=gone):
                    self.assertNotIn(f"`{gone}`", doc)


if __name__ == "__main__":
    unittest.main()
```

`tests/test_lab_netlist_parser.py`:

```python
"""`lab-netlist/v1` 파서 계약. 정본은 `docs/schema/lab-netlist-v1.md` 다.

`spec_parser` 와 같은 분업을 지킨다 — 여기서는 **표현할 수 없는 것**만 예외로
던지고(알 수 없는 kind, 회로인데 id 가 없음), 의미 결함(없는 항목을 가리킴,
그림 파일 부재)은 `validate.check_netlist_circuits` 가 findings 로 보고한다.
"""

import tempfile
import unittest
from pathlib import Path

from scripts.lab import config
from scripts.lab.netlist_parser import NetlistError, parse_netlist

ROOT = Path(__file__).resolve().parents[1]

MINIMAL = """---
schema: lab-netlist/v1
week: 2
experiment: 1
spec: ../체크리스트/명세.md
---

# 공통 규칙

- kind: common
- 모든 IC: pin 14 → VCC, pin 7 → GND
- 미사용 입력핀은 전부 GND

# C1 · 3-input AND

- kind: circuit
- id: C1
- item: E1.P1-1
- tables: [T1]
- diagram: 그림.png

- U1 = 74HC08 (quad 2-input AND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 1  ← 입력 A
  - 미사용 입력핀: pin 9, 10 → GND
"""


def _write(text):
    path = Path(tempfile.mkdtemp()) / "netlist.md"
    path.write_text(text, encoding="utf-8")
    return path


class ParseMinimal(unittest.TestCase):
    def setUp(self):
        self.netlist = parse_netlist(_write(MINIMAL))

    def test_프론트매터를_읽는다(self):
        self.assertEqual(self.netlist.week, 2)
        self.assertEqual(self.netlist.experiment, 1)
        self.assertEqual(self.netlist.spec, "../체크리스트/명세.md")

    def test_절을_kind_로_가른다(self):
        self.assertEqual([s.kind for s in self.netlist.sections],
                         ["common", "circuit"])
        self.assertEqual(len(self.netlist.circuits), 1)
        self.assertEqual(len(self.netlist.of_kind("common")), 1)

    def test_회로_메타를_읽는다(self):
        c = self.netlist.circuits[0]
        self.assertEqual(c.id, "C1")
        self.assertEqual(c.item, "E1.P1-1")
        self.assertEqual(c.tables, ["T1"])
        self.assertEqual(c.diagram, "그림.png")

    def test_속성_리스트를_본문에서_걷어낸다(self):
        """속성 줄이 본문에 남으면 인쇄본에 `kind: circuit` 이 배선 단계로 찍힌다."""
        c = self.netlist.circuits[0]
        self.assertNotIn("kind:", c.body)
        self.assertNotIn("tables:", c.body)
```

```python
출처(참고문헌)가 배선 단계 7~11번으로 찍히고, 참조 핀아웃 표는 표 줄이라는
이유로 통째로 사라지고, 미확정 절은 제목만 남아 문장이 끊겼다. 목적지를
데이터로 적으면 그 세 결함이 구조적으로 불가능해진다.
"""

import re
from dataclasses import dataclass, field
from pathlib import Path
from typing import Optional

from . import md

KINDS = ("common", "lookup", "sources", "open-issues", "circuit")

_H1 = re.compile(r"^#[ \t]+(?!#)(.+?)[ \t]*$", re.M)
_ATTR = re.compile(r"^-[ \t]+([a-z_]+)[ \t]*:[ \t]*(.*)$")

# `- U1 = 74HC08 (quad ...)` 또는 `## U1 = \`7490\` (decade counter)`.
# 칩 이름은 공백·괄호·쉼표·백틱 앞까지다.
IC_DECL = re.compile(r"(U\d+)[ \t]*=[ \t]*`?([^\s(,`]+)")

_BACKFILL = (
    "`# ` 절마다 `- kind:` 를 적고, 회로 절에는 `- id:`·`- item:`·`- tables:` 를 "
    "채운다. 계약은 docs/schema/lab-netlist-v1.md 다"
)


class NetlistError(ValueError):
    """결선도를 구조적으로 읽을 수 없을 때."""


@dataclass
class NetlistSection:
    kind: str
    title: str
    body: str                 # 속성 리스트를 걷어낸 나머지
    line: int
    id: Optional[str] = None
    item: Optional[str] = None
    tables: list = field(default_factory=list)
    diagram: Optional[str] = None

    @property
    def ics(self) -> list:
        """이 절이 선언한 칩 이름. 등장 순서를 지키고 중복을 지운다.

        `- ics:` 필드를 따로 두지 않는다 — 배선 본문의 `U<n> = <칩>` 선언이 이미
        정답이고, 필드를 늘리면 둘이 표류한다. 인쇄본의 칩 교체 배너가 이것을
        쓴다 (netlist M10: 칩이 종류당 하나라 회로를 순차로 배선해야 한다).
        """
        out = []
        for _, chip in IC_DECL.findall(self.body):
            if chip not in out:
                out.append(chip)
        return out


@dataclass
class LabNetlist:
    week: int
    experiment: int
    spec: str
    sections: list
    path: Path
    text: str

    @property
    def circuits(self) -> list:
        return [s for s in self.sections if s.kind == "circuit"]

    def of_kind(self, kind: str) -> list:
        return [s for s in self.sections if s.kind == kind]


def _leading_attrs(block: str):
    """절 첫머리의 **연속된** `- key: value` 줄만 속성으로 읽는다. (dict, 나머지 본문).

    `spec_parser._attrs` 는 블록 전체를 훑고 표 줄에서 멈춘다. 여기서는 더
    좁힌다 — 회로 절의 본문은 `- U1 = 74HC08` 불릿과 `- 미사용 입력핀: pin 9 →
    GND` 처럼 콜론이 든 한글 불릿으로 이어지고, 그 뒤에 표가 없어 멈출 곳이
    없다. 지금은 키 패턴(`[a-z_]+`)이 한글 불릿을 걸러주지만 그건 우연이다.
    첫 비-속성 줄에서 멈추면 키 패턴이 넓어져도 안전하다.
    """
    attrs, lines, i = {}, block.split("\n"), 0
    while i < len(lines) and not lines[i].strip():
        i += 1
    while i < len(lines):
        m = _ATTR.match(lines[i])
        if not m:
            break
        attrs[m.group(1)] = m.group(2).strip()
        i += 1
    return attrs, "\n".join(lines[i:])


def _parse_section(title, block, line, path) -> NetlistSection:
    attrs, body = _leading_attrs(block)
    kind = attrs.get("kind")
    if kind not in KINDS:
        raise NetlistError(
            f"{path}:{line} 절 {title!r} 의 kind 가 {kind!r} 입니다. "
            f"허용: {', '.join(KINDS)}. kind 가 인쇄 목적지를 정한다 — {_BACKFILL}"
        )
    if kind != "circuit":
        return NetlistSection(kind=kind, title=title, body=body, line=line)
    for required in ("id", "item", "tables"):
        if not attrs.get(required):
            raise NetlistError(
                f"{path}:{line} 회로 절 {title!r} 에 {required} 가 없습니다. {_BACKFILL}"
            )
    tables = md.parse_value(attrs["tables"])
    if not isinstance(tables, list):
        tables = [tables]
    return NetlistSection(
        kind=kind, title=title, body=body, line=line,
        id=attrs["id"], item=attrs["item"], tables=[str(t) for t in tables],
        diagram=attrs.get("diagram") or None,
    )


def parse_netlist(path) -> LabNetlist:
    path = Path(path)
    text = path.read_text(encoding="utf-8")
    front, body = md.split_frontmatter(text)
    if front.get("schema") != "lab-netlist/v1":
        raise NetlistError(
            f"{path}: schema 가 lab-netlist/v1 이 아닙니다 ({front.get('schema')!r})"
        )
    for required in ("week", "experiment", "spec"):
        if front.get(required) is None:
            raise NetlistError(f"{path}: 프론트매터에 {required} 가 없습니다")

    heads = list(_H1.finditer(body))
    if not heads:
        raise NetlistError(f"{path}: `# ` 절이 하나도 없습니다. {_BACKFILL}")

    sections = []
    for n, m in enumerate(heads):
        end = heads[n + 1].start() if n + 1 < len(heads) else len(body)
        line = body[: m.start()].count("\n") + 1
        sections.append(_parse_section(m.group(1), body[m.end():end], line, path))

    seen = set()
    for c in [s for s in sections if s.kind == "circuit"]:
        if c.id in seen:
            raise NetlistError(
                f"{path}: 회로 ID {c.id} 가 두 번 정의됐다. ID 는 문서 전체에서 "
                "유일해야 한다 — 인쇄 순서이자 오류 메시지의 지시 대상이다"
            )
        seen.add(c.id)
    if not seen:
        raise NetlistError(
            f"{path}: `kind: circuit` 절이 하나도 없습니다. 인쇄본은 회로마다 "
            f"한 쪽을 낸다. {_BACKFILL}"
        )

    return LabNetlist(week=front["week"], experiment=front["experiment"],
                      spec=front["spec"], sections=sections, path=path, text=text)
```

```python
def check_netlist_circuits(netlist, spec) -> list:
    """회로 메타의 **의미** 결함. 구조 결함은 `netlist_parser` 가 예외로 던진다.

    `check_netlist` 는 건드리지 않는다 — 다섯 스킬이 그것을 부르고, 회로 메타를
    요구하는 것은 인쇄본을 내는 ① `prep-lab-checklist` 뿐이다. 요구를 필요한
    자리에만 둔다. 그것에 요구를 넣으면 아직 백필하지 않은 다섯 주차에서
    ③④⑤⑧ 이 동시에 멈춘다.

    결선도 부재는 **warn 이지 error 가 아니다.** 그림 없이도 배선 목록과 빈
    브레드보드로 실험은 된다. 다만 조용히 빈칸으로 나가면 인쇄 후에야 눈으로
    발견하므로 시끄럽게 알린다.
    """
    out = []
    known_items = {i.id for i in spec.items}
    known_tables = {t.id for t in spec.tables}
    covered = set()

    for circuit in netlist.circuits:
        where = f"{netlist.path.name}:{circuit.id}"
        if circuit.item not in known_items:
            out.append(Finding("error", where,
                f"item {circuit.item!r} 이 명세에 없다. "
                f"정의된 항목: {sorted(known_items)}"))
        for table_id in circuit.tables:
            if table_id not in known_tables:
                out.append(Finding("error", where,
                    f"없는 표 {table_id} 를 가리킨다. "
                    f"정의된 표: {sorted(known_tables)}"))
            else:
                covered.add(table_id)
        if not circuit.diagram:
            out.append(Finding("warn", where,
                "diagram 이 없다 — 인쇄본에 빈 브레드보드가 대신 들어간다. "
                "breadboard-diagram 스킬로 결선도를 먼저 렌더한다"))
        elif not (netlist.path.parent / circuit.diagram).exists():
            out.append(Finding("warn", where,
                f"diagram 파일이 없다: {circuit.diagram}. breadboard-diagram "
                "스킬로 렌더하거나 diagram 줄을 지운다"))

    for table_id in sorted({t.id for t in spec.tables if t.role != "reference"}
                           - covered):
        out.append(Finding("warn", netlist.path.name,
            f"기록 대상 표 {table_id} 를 가리키는 회로가 없다 — "
            "인쇄본은 회로를 통해서만 표를 싣는다. 그대로 두면 조용히 빠진다"))
    return out
```

```python
_BULLET = re.compile(r"^([ \t]*)-[ \t]+(.*)$")


def _blocks(body: str) -> str:
    """`- ` 불릿·열 0 산문·`##` 헤딩을 HTML 로. 표 줄(`|`)은 건너뛴다.

    들여쓴 이어지는 줄을 앞 항목에 붙인다 — 버리면 여러 줄로 쓴 경고가 중간에서
    잘린다. 74HC02 핀 순서 경고가 실제로 세 줄짜리 불릿이고, 그 경고를 netlist
    스스로 "이 실험에서 가장 흔한 배선 실수"라고 표시한다.

    빈 줄 없이 이어지는 열 0 산문 줄은 한 문단으로 합친다 — netlist 의
    "다르면 배선 오류다" 경고가 실제로 두 줄이다.
    """
    out, items, para = [], [], []

    def flush_items():
        if items:
            out.append("<ul>" + "".join(f"<li>{_esc(i)}</li>" for i in items)
                       + "</ul>")
            items.clear()

    def flush_para():
        if para:
            out.append(f"<p>{_esc(' '.join(para))}</p>")
            para.clear()

    for raw in body.split("\n"):
        line = raw.rstrip()
        stripped = line.strip()
        if not stripped:
            flush_para()
            continue
        if stripped.startswith("|"):
            continue                      # 표는 부르는 쪽이 따로 렌더한다
        if stripped.startswith("#"):
            flush_items()
            flush_para()
            out.append(f"<h4>{_esc(_plain(stripped.lstrip('# ')))}</h4>")
            continue
        m = _BULLET.match(line)
        if m and not m.group(1):
            flush_para()
            items.append(_plain(m.group(2)))
            continue
        if line.startswith((" ", "\t")) and items:
            items[-1] += " " + _plain(stripped)
            continue
        flush_items()
        para.append(_plain(stripped))
    flush_items()
    flush_para()
    return "\n".join(out)


def _md_table_html(table, lead_checkbox: bool = False) -> str:
    """마크다운 표를 인쇄용 HTML 로. 체크박스 열은 `.box` 다 — `.check` 는
    명세의 기록 대상 표 행 전용이고 개수를 테스트가 명세에서 세어 대조한다."""
    out = ["<table><thead><tr>"]
    if lead_checkbox:
        out.append("<th>확인</th>")
    out += [f"<th>{_esc(_plain(h))}</th>" for h in table.header]
    out.append("</tr></thead><tbody>")
    for row in table.rows:
        out.append("<tr>")
        if lead_checkbox:
            out.append('<td class="box"></td>')
        out += [f"<td>{_esc(_plain(c))}</td>" for c in row]
        out.append("</tr>")
    out.append("</tbody></table>")
    return "".join(out)


LEGEND = ("확인 칸: ✓ 일치 / 값 = 불일치 시 실제로 관찰한 값 / 공란 = 미확인. "
          "표를 통째로 진행하지 않았으면 그 표 아래에 진행하지 않았음 이라고 적는다.")


def _flow_table(spec, netlist) -> str:
    """오늘의 흐름. 도착 직후 오늘 뭘 몇 개 하는지 한눈에 본다.

    쪽번호는 렌더 시점에 알 수 없다(Chrome 이 조판한다). 회로 번호로 대신한다 —
    회로마다 강제 개쪽이므로 회로 번호가 곧 순서다.
    """
    total = len(netlist.circuits)
    rows = ["<table class='flow'><thead><tr><th>순서</th><th>회로</th>"
            "<th>쓰는 IC</th><th>기록할 표</th></tr></thead><tbody>"]
    for n, circuit in enumerate(netlist.circuits, start=1):
        tables = ", ".join(
            f"{t} {spec.table(t).title}" if spec.table(t) else t
            for t in circuit.tables)
        rows.append(
            f"<tr><td>{n}/{total}</td><td>{_esc(_plain(circuit.title))}</td>"
            f"<td>{_esc(' · '.join(circuit.ics))}</td><td>{_esc(tables)}</td></tr>")
    rows.append("</tbody></table>")
    return "".join(rows)


def common_page(spec, netlist) -> str:
    """회로 페이지들 앞에 한 번만 오는 면.

    `kind` 가 목적지를 정한다 — `sources`(핀아웃 출처)는 여기 없다. 그것은
    ③ 예비보고서의 참고문헌 재료지 실험실에서 근거의 등급을 읽을 일은 없다.
    옛 렌더러는 그것을 배선 단계 7~11번으로 찍었다.
    """
    power = " · ".join(f"{k} = {v}" for k, v in spec.power.items())
    out = [f'<div class="power">전원: {_esc(power)} · '
           "미사용 입력핀은 전부 GND (플로팅 금지)</div>",
           f'<p class="legend">{_esc(LEGEND)}</p>',
           "<h2>오늘의 흐름</h2>", _flow_table(spec, netlist)]

    for section in netlist.of_kind("common"):
        out.append(f"<h2>{_esc(_plain(section.title))}</h2>")
        out.append(_blocks(section.body))

    for section in netlist.of_kind("lookup"):
        out.append(f'<div class="tblock"><h2>{_esc(_plain(section.title))}</h2>')
        out.append(_blocks(section.body))
        for table in md.parse_tables(section.body):
            out.append(_md_table_html(table))
        out.append("</div>")

    for section in netlist.of_kind("open-issues"):
        out.append(f"<h2>{_esc(_plain(section.title))} — 실험실에서 확인할 것</h2>")
        out.append(_blocks(section.body))
        for table in md.parse_tables(section.body):
            out.append(_md_table_html(table, lead_checkbox=True))

    return "\n".join(out)
```

```python
_CHIP_LINE = re.compile(r"^-[ \t]+(U\d+[ \t]*=[ \t]*.+)$")

_PHOTO = {
    "truth-table": "사진: 완성 회로 1장 + 불일치 행마다 1장. 파일명 {tid} row3.jpg 형식",
    "stepped": "사진: 스텝마다 1장. 파일명 {tid} row3.jpg 형식",
    "capture": "사진: 파형 자체가 결과물이다. 파일명 {tid} row1.jpg 형식",
}


def _split_circuit_body(section):
    """회로 본문을 (칩 상자, 미사용핀 줄, 산문) 으로 가른다.

    `- U<n> = <칩>` 이 상자의 제목이고 그 아래 들여쓴 `- ` 가 배선이다. 옛
    렌더러는 들여쓰기를 무시하고 전부 형제 번호로 만들어 **칩의 경계가 사라졌다**.

    미사용핀 줄은 상자에서 빼내 별도 강조 박스로 보낸다 — 플로팅 입력이 이
    과목의 대표 실패 원인인데 긴 목록의 마지막 두 줄로 묻혀 있었다.

    `- U<n> =` 형태의 칩 선언이 하나도 없으면(실험10 처럼 `## U1 = ...` 헤딩을
    쓰는 결선도) 상자를 만들지 않고 본문 전체를 산문으로 흘린다. 조용히 버리는
    것보다 낫다.
    """
    chips, unused, prose = [], [], []
    current = None
    for raw in section.body.split("\n"):
        line = raw.rstrip()
        stripped = line.strip()
        if not stripped or stripped.startswith("|"):
            continue
        m = _CHIP_LINE.match(line)
        if m:
            current = {"head": _plain(m.group(1)), "wires": []}
            chips.append(current)
            continue
        if stripped.startswith("- ") and line.startswith((" ", "\t")) and current:
            text = _plain(stripped[2:])
            (unused if text.startswith("미사용") else current["wires"]).append(text)
            continue
        if line.startswith((" ", "\t")) and current and current["wires"]:
            current["wires"][-1] += " " + _plain(stripped)
            continue
        prose.append(line)
    return chips, unused, "\n".join(prose)


def _chip_swap(previous, current) -> str:
    """칩 교체 배너. 준비물이 종류당 하나라 순차 배선이 강제된다 (netlist M10)."""
    if previous is None:
        return "준비: " + ", ".join(current.ics) + " 를 꽂는다"
    remove = [c for c in previous.ics if c not in current.ics]
    add = [c for c in current.ics if c not in previous.ics]
    keep = [c for c in current.ics if c in previous.ics]
    parts = []
    if remove:
        parts.append("뺀다: " + ", ".join(remove))
    if add:
        parts.append("꽂는다: " + ", ".join(add))
    if keep:
        parts.append("그대로 둔다: " + ", ".join(keep))
    return " · ".join(parts) or "칩 교체 없음"


def _diagram_html(section, netlist) -> str:
    """결선도가 있으면 싣고, 없으면 그 자리에 빈 브레드보드를 넣는다.

    **렌더러를 호출하지 않는다.** 인쇄가 PIL·시스템 폰트·미추적 스크립트에
    묶이면 안 된다. 부재는 `validate.check_netlist_circuits` 가 warn 으로 알린다.

    그림은 전체 폭을 요구한다 — 998px 를 절반(95mm)으로 줄이면 12px 핀 라벨이
    약 3.2pt 가 되어 읽을 수 없다.
    """
    if section.diagram:
        png = netlist.path.parent / section.diagram
        if png.exists():
            src = f"../{netlist.path.parent.name}/{section.diagram}"
            return (f'<img src="{_esc(src)}" style="width:100%">'
                    f'<p class="src">결선도: {_esc(section.diagram)}</p>')
    rows = crop_rows(section.body)
    visible_mm = _BREADBOARD_HEADER_MM + rows * 6
    return (f"<h3>브레드보드 작도 ({rows}행)</h3>"
            "<p class='src'>이 회로의 결선도가 아직 없다 — 격자에 직접 그린다</p>"
            f'<img src="{config.root_relative_prefix()}.claude/assets/Breadboard.jpg" '
            f'style="width:100%;max-height:{visible_mm:.1f}mm;object-fit:cover;'
            'object-position:top">')


def _mismatch_html() -> str:
    """결과보고서의 `예상과의 비교`가 여기서 나온다. 확인 칸 하나로는 좁다."""
    head = ("<table class='mismatch'><thead><tr><th>불일치 행</th><th>예상</th>"
            "<th>실제</th><th>사진 파일</th><th>짐작된 원인</th></tr></thead><tbody>")
    body = "".join("<tr>" + "<td></td>" * 5 + "</tr>" for _ in range(3))
    return head + body + "</tbody></table>"


def _circuit_tables(spec, section) -> str:
    out = []
    for table_id in section.tables:
        table = spec.table(table_id)
        if table is None or table.role == "reference":
            continue
        out.append('<div class="tblock">')
        out.append(f"<h3>{_esc(table.id)} · {_esc(table.title)}</h3>")
        # `_plain` 을 씌운다 — 옛 `_tables()` 는 안 씌웠다. 지금 어느 명세의
        # `source` 에도 마크다운이 없지만, 들어오는 순간 백틱이 인쇄본에 찍히고
        # 그것을 잡는 검사는 본문만 본다.
        out.append(f"<p class='src'>출처: {_esc(_plain(table.source or ''))}</p>")
        out.append(_capture_html(table) if table.kind == "capture"
                   else _truth_or_stepped_html(table))
        out.append(f"<p class='photo'>"
                   f"{_esc(_PHOTO[table.kind].format(tid=table.id))}</p>")
        out.append(_mismatch_html())
        out.append("</div>")
    return "\n".join(out)


def circuit_pages(spec, netlist) -> str:
    """회로마다 한 면. 강제 개쪽이라 회로 둘이 한 쪽을 나눠 쓰지 않는다.

    면 안의 순서는 작업 순서다 — 칩 교체 → 결선도 → 배선 → 미사용핀 → 유의사항
    → 측정표. `[결선도+배선]` 과 `[표]` 만 통짜로 유지하므로, 넘칠 때 갈리는
    지점이 "다 꽂았다"는 순간과 일치한다.
    """
    out, previous = [], None
    total = len(netlist.circuits)
    for n, section in enumerate(netlist.circuits, start=1):
        chips, unused, prose = _split_circuit_body(section)
        tables = ", ".join(section.tables)
        out.append('<section class="circuit">')
        out.append(f"<h2>회로 {n}/{total} · {_esc(_plain(section.title))} "
                   f"· 기록: {_esc(tables)}</h2>")
        out.append(f'<div class="banner">{_esc(_chip_swap(previous, section))}</div>')
        out.append('<div class="wirebox">')
        out.append(_diagram_html(section, netlist))
        for chip in chips:
            out.append(f'<div class="chip"><h4>{_esc(chip["head"])}</h4><ol start="1">')
            out += [f'<li><span class="box"></span>{_esc(w)}</li>'
                    for w in chip["wires"]]
            out.append("</ol></div>")
        out.append("</div>")
        if unused:
            out.append('<div class="unused"><b>배선을 끝내고 반드시 확인한다</b><ul>')
            out += [f'<li><span class="box"></span>{_esc(u)}</li>' for u in unused]
            out.append("</ul></div>")
        if prose.strip():
            out.append(_blocks(prose))
        out.append(_circuit_tables(spec, section))
        out.append("</section>")
        previous = section
    return "\n".join(out)
```

```python
def crop_rows(netlist_text: str) -> int:
    """netlist 가 실제로 쓰는 행 수. 브레드보드 템플릿을 여기에 맞춰 자른다.

    회로 본문을 넘긴다 — 결선도가 없는 회로의 fallback 격자 크기를 정한다.
    """
    ic_count = len(IC_DECL.findall(netlist_text))
    rows = max(6, ic_count * 8)
    return min(rows, MAX_BREADBOARD_ROWS)
```

## 남는 위험

- **결선도 해상도.** 998px 를 190mm 로 인쇄하면 약 133 DPI 이고 12px 핀 라벨이 6~6.5pt 다. 읽히지만 여유가 없다. `breadboard-diagram` 을 2배 해상도로 내는 것은 별건이다.
- **실험02·03·05·06·10 은 백필 전이다.** 그 주차에서 `prep-lab-checklist` 를 돌리면 `NetlistError` 로 멈춘다 — 의도된 동작이고 메시지가 백필 방법을 담는다. 실험02 는 결선도 PNG 5장이 이미 있어 백필 1순위다.
- **실험03·05·06·10 은 결선도가 0장**이고 `breadboard-diagram` 에 회로 ID 도 없다. 백필해도 당분간 빈 브레드보드 fallback 으로 나간다.
- **`_split_circuit_body` 는 `- U<n> = <칩>` 형태를 가정한다.** 실험10 결선도는 `## U1 = 7490` 헤딩을 쓴다. 그 경우 칩 상자 없이 산문으로 흘러 내용은 보존되지만 배선 체크박스가 없다. 실험10 을 백필할 때 결선도 쪽을 불릿 형태로 맞추거나 파서를 넓힌다.

## 회신 원문 요약

- 실험 1-2: input 으로 bit(0~3), output 으로 `Y(0~9)` 까지 확인한다.

- 회로도와 같이 결선하고, 실험 방법 하단의 주의사항(p9 Negative Logic)은 반영한다.

            self.assertEqual(len(ys), 10)
            self.assertEqual([i for i, v in enumerate(ys) if v == "0"], [n], row)

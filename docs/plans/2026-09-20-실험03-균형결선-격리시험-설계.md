# 실험03 균형 결선 격리 시험 (설계)

2026-09-20. `2026-09-20-결선도-칩한쪽-밀집-R7-설계.md` 가 넣은 규칙(게이트 좌우 배정 · R7 ·
`_input_jumper(side='f')`)을 **실제 회로로 한 번 돌려 본다.** 실험03 전가산기·전감산기를
게이트 1·4(hex 1·6)로 다시 짜서 뽑고, 승인본과 나란히 잰다.

## 의도

실험03 승인본은 게이트 1·2 만 써서 74HC86 왼쪽에 11리드가 몰렸다. 같은 회로를 규칙대로
좌·우로 나눠 그리면 (a) R7 을 통과하는가, (b) 설계가 예상한 좌 7·우 5 가 맞는가, (c) f쪽
입력·중앙 레일 브리지·칩 위/아래 행으로 건너는 사슬·걷기 보드의 유령 점퍼가 실제 그림에서
문제없이 도는가를 본다. 결과는 **제출물이 아니라 검증 표본**이다.

## 하지 않는 것

- `보고서/실험03/` 은 한 파일도 건드리지 않는다 — 승인본 PNG·도장·손그림·보고서가 그 그림을 인용한다.
- 실험03 `배치.py` 에 빌더를 더하지 않는다 — 테스트가 실험 1·2·3 빌더는 전부 `legacy` 여야 한다고 못 박았다.
- netlist·명세·체크리스트를 다시 쓰지 않는다.
- 시험에서 규칙 결함이 드러나도 이 계획 안에서 엔진·SKILL 을 고치지 않는다 — 결과 표에 적고 따로 다룬다.

## 시험 회로 (게이트 배정)

슬롯은 실험03 과 같다(S1 좌 7행 74HC86 · S2 좌 18행 74HC04 · S3 우 10행 74HC08 · S4 우 21행 74HC32).

| 칩 | 승인본 | 시험 |
|---|---|---|
| 74HC86 | XOR1 = 게이트1(1,2→3), XOR2 = 게이트2(4,5→6) | XOR1 = 게이트1, **XOR2 = 게이트4(12,13→11)** — Ci/Bi 는 f쪽 pin 13 에 `side='f'` 로, A⊕B 는 pin 3 → pin 12 로 칩 아래 14행을 돌아 건넌다, S 는 pin 11 |
| 74HC08 | AND1 = 게이트1, AND2 = 게이트2 | AND1 = 게이트1, **AND2 = 게이트4** — A⊕B(또는 (A⊕B)')는 pin 12, Ci/Bi 갈래는 pin 13, 출력 pin 11 |
| 74HC32 | OR = 게이트1 | 그대로 |
| 74HC04 | NOT1 = 1→2, NOT2 = 3→4 | NOT1 = 1→2, **NOT2 = 게이트6(13→12)** |

레일: Ci/Bi 가 좌 중앙 GND(468)에 꽂히므로 좌 GND↔좌 중앙 GND 브리지 한 가닥이 **새로** 필요하다(승인본 프레임엔 없다). 이것이 R5 연결성 검사와 이번에 넣은 `touch_rail` 이 실제로 요구하는지 보는 지점이다.

## 통과 기준

1. `build_all` 이 6장(절차 4 + 완성본 2)을 R1~R7 위반 없이 뽑는다.
2. 완성본 두 장의 `side_leads()` 가 모든 칩·모든 쪽에서 ≤ 8 이다.
3. 걷기 보드의 걷는 가닥이 정확히 둘(A 갈래, A⊕B→AND2)이다.
4. 가닥 수(`len(steps)`)가 승인본 대비 +3 이내다(새 브리지 1 + 우회 사슬 구간은 가닥 수가 아니라 꺾임이다).
5. 나란히 그림에서 74HC86 좌우 밀도가 눈으로 갈라진다.

기준 2 가 깨지면 `SIDE_LEAD_MAX` 가, 기준 4 가 깨지면 "게이트 나누기가 가닥을 늘리지 않는다"는 전제가 틀린 것이다 — 결과 표에 적는다.

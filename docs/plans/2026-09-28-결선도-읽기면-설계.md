# 결선도·체크리스트 읽기면 개편 — 설계

2026-09-28. grill-yourself 로 낸 설계를 사용자가 전부 추천값으로 확정했다(#8~#11).

## 의도

학생이 실험실에서 태블릿으로 읽는 면(체크리스트 HTML→PDF)을 다시 짠다. 결선도 PNG 는
**보드와 보드 위 표기만** 남기고, 제목·결선 순서·걷기·계측 목록은 렌더러가 사이드카 JSON
으로 내보내 체크리스트 HTML 이 조립한다. 주의사항 산문·공통 규칙·미확정 표는 학생 면에서
뺀다 — netlist.md·배치.py 에 저작용으로 그대로 남는다.

근거: 실험04 체크리스트 28쪽 중 공통면이 420mm 4쪽이고 그 대부분이 공통 규칙과 미확정
M1~M15 다. 사용자 진술: "공통 규칙 및 미확정 사항들은 사실상 읽지 않는다". 결선도 PNG 는
보드 아래 주의사항 9줄·범례·결선 순서가 픽셀로 구워져 태블릿에서 작고, 체크할 수 없다.

분류: architectural — 렌더러→체크리스트 사이에 사이드카 JSON 인터페이스가 새로 생기고
netlist 에 새 절 종류(`must-read`)가 생긴다.

## 끝나면

- 공통면(1쪽)은 전원 박스 · **꼭 읽을 것(불릿 ≤5)** · 손으로 할 때 주의 3줄 · 선 색 범례 ·
  기록 범례 · 오늘의 흐름 · 참조 핀아웃 · 칩 자리표뿐이다.
- 단계 쪽: 보드 그림 + 이 단계에서 + 결선 순서 체크박스 목록(① 우 a12 → 좌 a18 · S0') +
  걷기·계측 목록 + 회색 개수 + 확인 노드 + 단계 진리표.
- 결선도 PNG 에는 보드만 있다(제목·주의사항·범례·순서표 없음). 보고서·노션에도 이 PNG 가 간다.
- `must-read` 가 불릿 5개를 넘거나 불릿·표가 아닌 줄을 가지면 파서가 멈춘다. PNG 는 있는데
  사이드카 JSON 이 없으면 체크리스트 렌더가 멈춘다.

## 이번에 안 하는 것

- 시각 디자인(색·서체·보드 옆 배치) — 별도 디자인 세션. 이번은 데이터와 클래스 이름 계약까지.
- 보드를 SVG/HTML 로 다시 그리기 — 좌표·`verify()`·손그림 대조·도장이 PNG 격자에 묶여 있다.
- 실험05~ — 폴더가 없다. 저작 규칙만 스킬 문서에 적는다.

## 접근

| 안 | 방식 | 채택 |
|---|---|---|
| A | 보드만 PNG + 사이드카 JSON, 체크리스트 HTML 이 조립 | ✔ |
| B | 렌더러가 보드 위 배선까지 SVG/HTML 로 | — (렌더러·검증 재작성) |
| C | PNG 그대로, 글자만 줄이고 공통면 절만 뺌 | — (디자인 목표 미달) |

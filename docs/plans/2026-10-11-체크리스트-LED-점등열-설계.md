# 체크리스트 단계 진리표의 LED 점등 열과 배치 순서 번호 — 설계

2026-10-11 사용자 요청(grill-yourself 로 확정). 구현 계획: `2026-10-11-체크리스트-LED-점등열-구현계획.md`.

## 의도

v2 판형 주차(실험05~)의 체크리스트 단계 진리표에 LED 마다 **켜짐/꺼짐**을 적는다. 출력 0 에서 켜지는
LED(Negative Logic, 실험05 C1)를 표만 보고 읽게 한다. LED 가 여럿이면 보드 **위→아래 순서로 ①②③…**
번호를 매기고 열도 그 순서로 둔다 — 실험05 C1 은 보드 순서가 `Y0~Y5, Y9, Y6, Y8, Y7`(netlist M17)인데 표는
`Y0~Y9` 라 헷갈렸다.

분류: bounded — 단계 진리표(`render._stage_table_html` → `nodes.stage_table`)와 결선도 사이드카를 넓힌다.

## 완료 시 동작

- 단계 블록 표에 그 시점까지 급전된 LED 가 **누적으로** 전부 열로 나온다. 열 머리 `LED③ Y2`, 둘째 줄
  `0이면 켜짐 · U4 pin 3`. 셀은 `켜짐`/`꺼짐` 굵게 + 논리값 작게.
- 임시 급전은 `LED② A2 = D0'`. 걷기 뒤 단계에서는 그 열이 빠진다.
- **마지막 관측 단계에도 LED 점등 표를 싣는다**(기록표와 일부 겹친다).
- 회로 완성본 아래에 `LED 순서(위→아래): ①Y0 ②Y1 … ⑦Y9 ⑧Y6 ⑨Y8 ⑩Y7`.
- 기록표 출력 열 머리에 `LED⑦` 배지. 열 순서는 명세 그대로.
- v1 주차(실험01~04) 인쇄본은 바뀌지 않는다.
- 급전 표기를 못 풀면 검증이 warn 을 내고 그 단계는 옛 표로 물러선다.

## 이번에 안 하는 것

- LED 를 번호순으로 재배치(배치기 R10 변경) — 사용자가 위치순 번호를 골랐다.
- PNG 위 ①② 번호 — 도장이 바뀐다. 보드엔 이미 태그가 있다.
- 기록표 열 순서 변경 — 명세·`기록.md`·`.check` 불변식.
- stepped·capture 표.

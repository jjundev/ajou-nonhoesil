# verify-draft-lab-spec 설계 — 격리 재생성 검증을 스킬로 만든다

2026-09-08. 실험01 격리 재생성 회차(`docs/verify/draft-lab-spec.md` 의
2026-09-08 절)를 마친 뒤 "이 작업을 스킬로 만들까" 를 스스로 캐물어
정한 것이다. 사용자 결정 둘(역할 분담·실전 실행)을 포함한다.

## 왜 만드나

- 런북(`docs/verify/draft-lab-spec.md`)은 있지만 아무도 안 돌린다 — 기록
  표의 2026-09-07 행이 **미실행**이다. 문서는 사람이 읽고 손으로 따라 해야
  하고, 스킬이면 `/` 한 번에 돈다.
- 2026-09-08 회차가 런북에 없던 절차를 여럿 만들었다: 답안지 목록이
  `tests/` 전체와 다른 스킬 여덟까지 넓어진 것, `git archive` 뒤 `git init`
  단일 커밋으로 `git status` 누출을 닫은 것, 핀 배정 대조와 문장 교집합
  도구, "규칙이 막았나 / 검사가 잡았나" 판정. 전부 컨트롤러의 스크래치패드와
  대화에만 있다.
- 이 저장소의 전제가 "스킬 문서는 실행해 봐야 결함이 나온다" 인데, 그것을
  재는 절차만 문서로 남아 있으면 그 전제를 스스로 어기는 것이다.

# 체크리스트에 강의노트 회로도 싣기 — 설계

작성 2026-09-19. 2026-09-18 핸드오프의 B 항목이다(A 걷기 보드는 `f15fdc2` 로 병합).
C(사진 파일명)·D(물리 주의사항)·E(종료 메모)·A 유보 1~4 는 이 라운드 밖이다.
`/grill-yourself` 로 설계하고 Needs-you 세 줄을 사용자가 권장안대로 확정했다.

## Intent

체크리스트 PDF 의 회로 페이지마다 그 항목의 **강의노트 게이트 기호 회로도**를 칩 교체
배너 바로 뒤(단계 그림·브레드보드 작도면 앞)에 싣는다. 실험실에서 결선도를 보다가
"원래 회로가 뭐였지" 를 교안을 따로 열지 않고 확인하게 한다. 회로도 PNG 는 교안을
300dpi 로 렌더해 크롭하고, 명세 항목의 새 필드 `schematic:` 이 그 경로를 가리킨다.
완료 조건: ① 실험05 부터 `draft-lab-spec` → `prep-lab-checklist` 흐름에서 회로도가
실린다. ② 실험03(p5·p7)으로 한 번 검증하고 테스트 기준선(9 failed / 1284 passed)을 지킨다.

Classification: bounded — 명세 → 파서 → validate → render 의 기존 흐름에 선택 필드
하나를 더한다. 선례는 표 속성 `figure`(`spec_parser.py:44`, `render.py:158`,
`figure.set_spec_figure`).

## Behavior when done

- 회로 페이지 머리글·배너 바로 아래에 "강의노트 p5 · 회로 구성" 캡션과 회로도가 실린다.
  한 항목을 가리키는 회로가 여럿이면 **첫 회로에만** 싣는다.
- `schematic:` 이 없는 명세(실험01·02)의 렌더 결과는 지금과 같다.
- `schematic:` 이 가리키는 파일이 없으면 `<img>` 대신 안내 한 줄을 낸다. validate 가 warn 을 낸다.
- 필드 형태가 틀리면(스칼라·빈 리스트·문자열 아닌 원소) 파서가 `SpecError` 로 거절한다.
- `python -m scripts.lab.schematic <실험번호> <항목id>` 가 `pages` 첫 쪽에서 로고를 뺀
  가장 큰 래스터 이미지 영역을 300dpi 로 크롭해 `체크리스트/실험NN_<소실험>_회로도.png`
  로 저장하고 명세에 `schematic:` 을 적는다. `--page`·`--box x0,y0,x1,y1`(pt) 로 덮어쓴다.

## Not in this round

- C·D·E, A 유보 1~4 — 서로 독립, 다음 라운드
- 실험01·02 명세 소급 — 핸드오프 결정
- 실험03 `체크리스트.html/pdf`·`output/` 재생성 — 완성본. 검증 렌더는 임시 파일로 하고 지운다
- 예비·결과보고서에 회로도 싣기 — 요청 범위 밖
- `specdiff` 대조 — `figure` 와 같은 이유(파생 자산이지 판독 결과가 아니다)

## Implementation spec

1. **파서** `scripts/lab/spec_parser.py` — `SpecItem.schematic: Optional[list] = None`.
   `pages` 검사 바로 뒤에서 비지 않은 문자열 리스트가 아니면 `SpecError`.
2. **검증** `scripts/lab/validate.py` — `check_schematics(spec)`: 선언한 파일이
   `spec.path.parent / p` 에 없으면 warn. 필드 없음은 finding 없음. `validate_spec` 에서
   `check_diagnostic_claims` 앞에 부른다. `docs/schema/lab-spec-v2.md` 항목 표·검사 강도
   표·"정본은 코드다" 문단·`SpecError` 표를 갱신한다(`tests/test_schema_doc_sync.py`).
3. **크롭 도구** 새 `scripts/lab/schematic.py` — pymupdf(지연 import).
   `default_box`(여러 쪽에 반복되는 로고 xref 를 빼고 가장 큰 이미지 영역 + 4pt 여백,
   쪽 경계로 자름. 여백 4pt 는 이미지 바로 아래 "회로 구성" 캡션(top 507pt)을 넣지 않기
   위해서다 — 실측 p5 이미지 `[21,278,476,502]`, p7 `[50,287,450,502]`),
   `crop`(`get_pixmap(dpi=300, clip=box)`), `schematic_name`(`figure.sub_id` 재사용),
   `set_spec_schematic`, CLI `main`. 게이트 라벨이 텍스트 오버레이라 임베드 이미지를 그냥
   뽑으면 IC 이름이 빠진다 — 렌더 후 크롭한다.
4. **렌더러** `scripts/lab/render.py` — `_schematic_html(item, spec_dir)` 를 `circuit_pages`
   의 배너 직후에, 항목당 한 번. `src` 는 명세 기준 상대경로 그대로(HTML 이 명세와 같은
   `체크리스트/` 에 놓인다). template CSS `.schematic` 폭 80%·최대 높이 70mm.
5. **스킬 문서** — `draft-lab-spec` 4단계 끝에 크롭·눈 확인 불릿, `prep-lab-checklist`
   인쇄물 구성·비-목표에 한 줄씩.
6. **실험03 검증** — PNG 2장 + 명세 두 줄을 커밋. `체크리스트/_검증.html/pdf` 로 렌더해
   눈으로 확인한 뒤 지운다. 전체 테스트 기준선 유지.

## Decisions

### Confident

| # | Decision | Answer | Rationale |
|---|---|---|---|
| 1 | 필드 자리 | 명세 **항목** frontmatter `schematic: [경로]` | 회로도는 항목(교안 쪽) 단위, `pages` 와 나란히(`spec_parser.py:54`) |
| 2 | PNG 저장 폴더 | `<실험NN>/체크리스트/` | `결선도/*.png` 는 `배치.py` 출력과 정확히 같아야 한다(`tests/test_breadboard_boards.py:222`) |
| 3 | 크롭 방식 | 300dpi 렌더 + clip, 기본 영역 = 로고 뺀 최대 이미지 bbox | 라벨이 텍스트 오버레이. bbox 실측이 회로 영역과 맞는다 |
| 4 | 크롭 엔진 | pymupdf `get_pixmap(clip=)`, 지연 import | requirements-dev 에 이미 있다. bbox 와 렌더를 한 라이브러리로 |
| 5 | 누가 만드나 | `draft-lab-spec` 마지막 단계 + `schematic.py` | `pages` 를 정하는 곳. `prep-lab-checklist` 는 명세를 짓지 않는다 |
| 6 | specdiff | 대조 안 함 | `figure` 선례 |
| 7 | 파일 부재 | 렌더는 안내 한 줄, validate warn | `diagram` 부재와 같은 급. `check_embedded_images` 가 깨진 `<img>` 를 error 로 잡는다(`validate.py:823`) |
| 8 | 필드 없음 | finding 없음 | 소급하지 않으므로 warn 은 잡음 |
| 9 | 자리·횟수 | 배너 뒤, 단계 블록 앞, 항목의 첫 회로에만 | 핸드오프 "브레드보드 작도면 앞" |

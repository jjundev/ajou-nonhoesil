# 중간 노드 기대값 표 — 설계

2026-09-20 `/grill-yourself` 결과. 결정 #9·#10·#11 은 사용자가 가정값 그대로 확정했다.

## 배경

실험01·02·03 을 거치며 가장 시간이 많이 든 것은 디버깅이었다. 다 꽂고 전원을 켰을 때
예상과 다르면 어느 선이 잘못됐는지 찾을 수 없었다 — 용의자가 선 전부였다. 실험01 은
74HC08 불량을 마지막 회로에서야 찾았고(기록.md 2026-09-11), 실험03 은 걷지 않은 두
가닥 때문에 인버터를 꽂은 뒤 LED 가 어긋났다(2026-09-18).

원리는 하나다. **마지막으로 통과한 검사 이후에 손댄 선만 용의자가 되게 한다.** 이를
위해 네 하위 시스템이 필요하고, 이 문서는 첫째만 다룬다.

1. **중간 노드 기대값 표** (이 문서). 나머지 셋이 전부 이것을 전제한다.
2. 공통면 디버깅 절차 상자 (전원 전 정적 검사 · 실패 시 탐색 순서 · 칩 사전 시험).
3. 단계 세분화 규약 변경 ("칩 하나 = 단계 하나" → "관측 노드 하나 = 단계 하나") 과
   주차 `배치.py` 재작성.
4. 결선도 net 부류별 선 색 규칙.

## Intent

결선도(`netlist.md`)의 회로 절에 `## 노드` 표를 두어, 회로 안의 모든 관측점(게이트
출력 핀)에 대해 "이 입력 행에서 이 핀은 0 이어야 한다"를 기계적으로 계산하고
체크리스트 회로 페이지에 인쇄한다. 실험실에서 출력이 틀린 행을 잡으면 이 표를 보고
입력 쪽 핀부터 프로브로 찍어 처음 갈라지는 노드를 찾는다. 검증기는 노드 식이 명세의
출력 식과 모든 행에서 일치하는지, 핀이 그 회로에 선언된 칩의 것인지 확인한다.

끝난 모습: 실험03 두 회로에 노드 표가 있고, 인쇄본 회로 페이지의 기록표 바로 위에
입력 열 + 노드 열(핀 병기) 표가 찍히며, 틀린 식·없는 칩·빠진 출력 노드는 인쇄 전에
error 로 막힌다.

Classification: **bounded** — `## 단계` 표가 이미 같은 경로(파서가 본문에서 떼어냄 →
`NetlistSection` 필드 → `check_netlist_circuits` → `circuit_pages`)를 낸다.

## Behavior when done

- 결선도 저자는 회로 절 안에 `## 노드` 헤딩과 `| 노드 | 식 | 핀 |` 표를 쓴다. 식은
  그 회로 기록 진리표의 입력 변수만 쓰고(`boolexpr` 문법), 핀은 `U1 pin 3` 형식이다.
- 체크리스트 회로 페이지에서 기록표 바로 위에 "중간 노드 기대값 — 프로브로 찍을 핀"
  표가 나온다. 열 머리는 노드 이름과 핀 두 줄, 셀은 그 표의 `encoding` 그대로 `0/1`
  또는 `H/L`, 입력에 don't-care 가 있는 행은 `—`.
- 표 위 한 줄: "틀린 행에서 입력 쪽 노드부터 프로브로 찍는다. 기대값과 처음 갈라지는
  노드가 고장 자리다 — 그 게이트의 입력 핀이 틀리면 선, 맞으면 게이트".
- 검증 실패는 인쇄 전에 잡힌다: 식 평가 불가, 핀 형식 위반, 회로에 없는 칩, 노드 이름
  중복, 출력 노드 누락, 출력 노드 값이 명세 식과 불일치, 기록 진리표가 없는 회로의
  노드 표 → 전부 error. 단계는 있는데 노드 표가 없으면 warn.
- 파서 수준 결함(헤딩 아래 표 없음, 열 이름 다름, 행 없음)은 `NetlistError` 로 즉시
  거절한다. 단계 표와 같은 강도다.

## Not in this round

- 공통면 절차 상자 — 노드 표 없이도 인쇄되는 독립 렌더 변경이라 다음 라운드.
- 단계 세분화와 배치.py 재작성 — 규약 변경이고 주차마다 그림을 다시 뽑는 저작 작업.
- `기록.md` 에 노드 측정 칸 — 기대값 표는 채우는 표가 아니다(#9 확정: 두지 않는다.
  실패 시 측정값은 "막혔던 것" 메모에 산문으로).
- 실험01·02 백필 — 지난 실험이고 재인쇄 계획이 없다(#10 확정: 실험03 두 회로만).
- 노드가 다른 노드를 식에서 참조하는 문법 — 실험03 의 일곱 노드가 전부 입력 변수만으로
  적히고, 노드 이름에 `⊕`·`'` 가 들어가 식별자가 아니다.
- 노드가 많을 때 표를 눕히거나 나누기 — #11 확정: 입력 행 × 노드 열 하나로 간다.

## Decisions

### Confident

| # | Decision | Answer | Rationale |
|---|---|---|---|
| 1 | 노드 데이터의 자리 | netlist 회로 절의 `## 노드` 마크다운 표 | 핀 번호는 배선 사실이라 명세가 아니라 결선도 소유다. `## 단계` 와 같은 메커니즘이 이미 있다 (`netlist_parser.py` `_split_stages`) |
| 2 | 식 문법 | `boolexpr` 문법, 기록 진리표의 입력 변수만 참조 | 평가기를 새로 만들지 않는다 (`boolexpr.eval_boolean`). 실험03 노드 일곱 개가 전부 입력 변수로 적힌다 |
| 3 | 핀 형식 | `U<n> pin <m>` 하나로 고정, `U<n>` 은 회로 본문의 `IC_DECL` 선언에 있어야 함 | 칩 교체 배너가 이미 이 선언을 정본으로 쓴다 (`NetlistSection.ics`) |
| 4 | 출력 노드 의무 | `derived_parts` 의 출력마다 같은 이름의 노드가 있고 값이 전 행 일치해야 error 없음 | 결선도와 명세의 표류를 잡는 유일한 자리. `check_boolean` 은 명세 셀만 본다 |
| 5 | 기대값 계산 모듈 | 새 `scripts/lab/nodes.py`, `validate._bit` 은 `notation.bit_of` 로 이동 | validate 가 render 를 import 하므로 둘이 공유할 함수는 제3의 모듈에 둬야 순환이 없다 |
| 6 | 인쇄 위치 | 회로 페이지에서 기록표(`_circuit_tables`) 바로 위 | 실패는 기록표에서 발견된다 |
| 7 | 노드 표 부재 처리 | 단계가 있으면 warn, 없으면 아무것도 안 함. 실험01·02 는 백필하지 않음 | 지난 실험 재인쇄 계획이 없고, 코퍼스 warn 허용목록은 `validate_spec` 만 본다 |
| 8 | 기준 진리표 | 회로 `tables` 의 첫 기록 진리표. 둘 이상이면 입력 열이 같아야 함 | 실험03 은 회로당 기록표 하나. 다른 입력 집합을 한 표에 섞을 수 없다 |
| 9 | `기록.md` 측정 칸 | 두지 않는다 | 사용자 확정(가정값) |
| 10 | 백필 대상 | 실험03 두 회로 + 체크리스트 재생성 | 사용자 확정(가정값) |
| 11 | 표 방향 | 입력 행 × 노드 열 | 사용자 확정(가정값) |

## 실험03 백필 내용

C2 전가산기 (T3: A, B, Ci → S, Co):

| 노드 | 식 | 핀 |
|---|---|---|
| A⊕B | A⊕B | U1 pin 3 |
| S | A⊕B⊕Ci | U1 pin 6 |
| A·B | A·B | U2 pin 3 |
| (A⊕B)·Ci | (A⊕B)·Ci | U2 pin 6 |
| Co | A·B + (A⊕B)·Ci | U3 pin 3 |

C4 전감산기 (T7: A, B, Bi → D, Bo):

| 노드 | 식 | 핀 |
|---|---|---|
| A' | A' | U4 pin 2 |
| A⊕B | A⊕B | U1 pin 3 |
| (A⊕B)' | (A⊕B)' | U4 pin 4 |
| D | A⊕B⊕Bi | U1 pin 6 |
| A'·B | A'·B | U2 pin 3 |
| (A⊕B)'·Bi | (A⊕B)'·Bi | U2 pin 6 |
| Bo | A'·B + (A⊕B)'·Bi | U3 pin 3 |

핀은 netlist 배선 본문(`U4 pin 2 → U2.pin1`, `U4 pin 4 → U2.pin4`, `U1 pin 3`,
`U2 pin 3·6`, `U3 pin 3`)과 대조한 값이다.

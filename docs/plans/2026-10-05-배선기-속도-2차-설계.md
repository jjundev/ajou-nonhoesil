## 구현

1. **`_seg_boxes(segs)`** — 기존 선마다 범위 상자 `(x0, y0, x1, y1)`, `segs` 순서. `_routes` 가 `segs`
   를 만든 뒤 한 번 계산해 `_valid` 에 넘긴다. 생성기가 사는 동안 `segs`·`others` 는 생성기 시작 때 만든
   목록이라 고정이다.
2. **`_valid(bb, path, others_pts, segs, seg_boxes)`** — 경로 상자 ±3 을 `px0, px1, py0, py1` 로 잡고
   `near` = 상자가 그 안과 겹치는 기존 선. 끝점-기존 선, 꺾임점-남의 선, 남의 꺾임점-새 선, R4 검사는
   `segs` 대신 `near` 를 훑는다. 기존 끝점·부품 다리 검사는 `px0 < q[0] < px1 and py0 < q[1] < py1` 인
   점만. R6·R14·꺾임점-리드·번호 원 검사와 검사 순서는 그대로.
   - 동치 근거: 걸러지는 선·점에 대해 원래 식은 반드시 False 다. `_on_seg` 는 점이 구간 상자 ±2 안이어야
     참(1차 선검사), 꺾임점 근접은 1.5px, R4 는 같은 좌표 1.5px + 겹침 2px 초과 — 모두 ±2 안의 겹침을
     요구한다. 여유 3 은 그 위 1px 를 더해 ±2 경계의 부동소수 반올림을 덮는다. `_valid` 는 bool 만
     돌려주고 아무것도 안 바꾼다.
3. **`_clean`** — `_axis(out[-2], out[-1])` 를 한 번만 계산(`ax = …; if ax and ax == _axis(out[-1], p)`).
   원래 `len(out) >= 2 and X and X == Y` 와 참·거짓이 같다.

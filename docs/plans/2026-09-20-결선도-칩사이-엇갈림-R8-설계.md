# 칩 사이 배선의 쪽 맞추기 — 게이트 배정 방향 규칙 + 검사 R8 (설계)

2026-09-20. `/grill-yourself` 결과. 결정 #8·#9 는 사용자가 추천안대로 확정했다.
선행: `2026-09-20-결선도-칩한쪽-밀집-R7-설계.md`, 격리 시험 `docs/verify/2026-09-20-실험03-균형결선/`.

## 의도

격리 시험판(게이트를 무조건 1·4 로 나눈 판)에서 같은 블록에 위아래로 앉은 두 칩을 잇는 배선이
반대쪽으로 건너는 X자가 생겼다(전가산기 1건 `우 g13→b21`, 전감산기 2건 `+ 좌 a9→h19`).
승인본 실험01~03 완성본 7장에는 0건이다. 같은 블록 두 칩 사이 배선은 **출발 핀과 같은 쪽**
(a~d 끼리, g~j 끼리)에서 끝나게 한다. 그러려면 게이트를 "무조건 1·4" 가 아니라 **신호가 오는
쪽을 향한 게이트**로 고르고, **R7 에 걸리는 칩만** 나눈다. 렌더러는 반대쪽으로 건너는 칩 간
배선을 R8 로 막는다.

시험판을 이 규칙으로 다시 짜면 74HC08(좌 7)·74HC04(좌 5)는 나눌 필요가 없어 승인본 배정(게이트
1·2)으로 돌아가고 74HC86 만 나뉜다 — 엇갈림 0건, 리드 최댓값 7.

분류: **bounded** — R7 과 같은 자리(`verify()`·`density_policy`·SKILL §4a/§5·draft-lab-spec)에 규칙
하나를 더하고 시험 빌더를 고쳐 다시 잰다.

## 완료 시 동작

- `verify()` 가 같은 블록의 서로 다른 두 칩 핀 스트립을 잇는 배선의 양 끝 쪽이 다르면
  `R8 칩 사이 엇갈림: 좌 a9 → 좌 h19 · <desc> — 74HC86 a쪽 → 74HC04 f쪽` 로 막는다. 같은 칩
  안(XOR1→XOR2), 다른 블록 사이, LED·레일 끝점은 보지 않는다.
- draft-lab-spec 의 게이트 규칙이 "쿼드 둘 = 1·4" 에서 "R7 에 걸리는 칩만 나누고, 게이트는 신호가
  오는 쪽으로" 로 바뀐다.
- 시험판 v2: 74HC86 게이트 1·4, 74HC08 1·2, 74HC04 1·2. 엇갈림 0, 가닥 수 승인본 +1.
- 실험01~03 승인본은 R8 도 legacy 로 면제되지만 실측 0건이라 테스트는 legacy 포함 전 빌더에
  `cross_side_wires() == []` 를 건다.

## 이번에 안 하는 것

- 같은 칩 안에서 건너는 사슬 금지 — 나누기의 대가. 막으면 R7 과 모순.
- 다른 블록 사이 배선의 "가까운 쪽" 강제 — 문서 규칙으로만(결정 #8).
- "한 행을 가로지르는 배선 수" 지표 — 별건.

## 게이트 배정 규칙 (문서에 들어갈 문장)

1. **R7 에 걸리는 칩만 나눈다.** 한쪽 리드가 8 이하면 게이트 1·2 로 둔다 — 승인본 실험03 의
   74HC08(좌 7)·74HC04(좌 5)가 그렇다.
2. **게이트 자리는 신호가 오는 쪽이다.** 같은 블록 위/아래 칩에서 오면 그 출력 핀과 같은 쪽,
   다른 블록에서 오면 그 블록을 향한 쪽(우 블록은 a쪽, 좌 블록은 f쪽), 레일 입력은 바깥 레일 쪽.
3. **나눈 칩 안의 사슬만** 칩 위/아래 행으로 건넌다 — 두 칩 사이에서 건너지 않는다(R8).

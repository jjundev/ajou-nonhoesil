**Goal:** 노션 v3 결과보고서의 논리 결함(칩 불량 원인 서사의 자기모순, LED 전류의 전원 전압 불일치, 과한 단정)과 AI 티(같은 문장 반복, 백틱 수식, 장식 결론문)를 원본 md 에서 고쳐 노션 **v4** 로 올리고, 사용자가 사진 5장을 끼운 뒤 되읽어 "제출 가능" 판정으로 닫는다.

**Tech Stack:** Python 3.11 (`scripts/lab/*`), Notion API (`NOTION_TOKEN` 환경변수), Git Bash on Windows. **이 PC 에서 `python3` 는 Microsoft Store 스텁이라 실행되지 않는다 — 항상 `PYTHONPATH=. python` 을 쓴다.** 스킬 문서의 `python3 -c` 는 그대로 옮기지 말고 `python` 으로 바꾼다.

**Spec:** 이 대화의 `/grill-yourself` 설계(2026-09-12). 요약은 아래 §설계 요약. 실행자는 이 파일만 보고도 작업할 수 있어야 하므로 필요한 사실을 전부 여기 옮겼다.

## 설계 요약 (spec)

**사용자 확인 결과(2026-09-12):** 실험 3 의 배선은 예비보고서 결선표와 동일 — 74HC08 은 1번 게이트(핀 1·2 → 3), **A' 가 1번 핀, B 가 2번 핀**. 1-1·2-1 의 앞단도 같은 게이트(핀 1·2 → 3, A 가 1번, B 가 2번). 나머지 결정은 추천대로: 74HC32 표준 핀 배치 문장 유지, 백틱 전부 제거, 하네스 규칙 이번에 같이 반영.

**핵심 논증(결과 분석에 들어갈 내용의 근거):**
- 실험 3 증상: A=B=1 에서만 Z LED 꺼짐. 이때 74HC08 입력은 (핀1 = A' = 0, 핀2 = B = 1), 정상 출력 0, Z = 1 이어야 함.
- 신호선 하나가 고정되는 단일 고착 고장 중 이 증상(11 만 틀리고 00·01·10 은 맞음)에 맞는 것은 **핀 1 고착-1** 하나뿐. (출력 고착-1 이면 A=B=0 에서도 Z 가 꺼져 틀린다. 핀 2 고착-1, 핀 1·2 고착-0 은 A=B=1 에서 증상을 내지 못한다.)
- 그런데 실험 2-1 에서 011 (A=0, B=1, C=1) 을 넣었고 중간단 LED 는 예상대로 꺼져 있었다(`기록.md` T3 ✓). 핀 1 고착-1 이었다면 그때 중간단이 켜졌어야 한다.
- 따라서 이 불량은 단일 고착 모델 밖(조건에 따라 달라지는 불량). 보고서 v3 의 "모델을 벗어난 경우였다" 는 결론은 옳고, **근거가 빠져 있던 것**이 문제다.
- 실험 1-1 의 {000,100,110,111} 은 A 고착-1 만 못 잡고, 실험 2-1 의 {000,001,011,110} 은 B 고착-1 만 못 잡는다(A=핀1, B=핀2).

**고칠 것과 안 고칠 것:**
- 원인 서사 상세는 **결과 분석 "A=B=1 에서만 어긋났던 원인" 한 곳**에만. 실험 3 표 아래·고찰·추가 공부는 가리키기만.
- LED 전류: 실험은 5 V 전원(명세 `power: VCC +5V`, 예비보고서 "5 V 단일 전원", 예비보고서 어림 "대략 9 mA"). (5.0 − 1.9)/330 ≈ 9.4 mA 로 맞춘다. "적색" 은 사진 `1-1 111.jpg` 로 확인됐으므로 유지.
- 추가 공부 두 소절은 **유지**(라운드1 사용자 지시 "3학년 수준, 매주", ④ §섹션별 재료 "소절 둘로 고정").
- 참고문헌 형식 유지, 노션 v3 삭제 안 함, 예비보고서 수정 안 함.
- 이번 라운드에서 안 하는 것: 본문 백틱을 잡는 `validate` 검사 신설(규칙을 먼저 두고, 다음 실험에서 같은 수정이 또 나오면 그때 검사로 승격).

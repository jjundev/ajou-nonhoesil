# 결선도 단계화 · 슬롯 고정 · 미사용핀 생략 — 설계

실험01(2026-09-11) 실험실 기록 `보고서/실험01/실험중있었던일.md` 에서 얻은 세 교훈을
netlist 스키마, 브레드보드 렌더러, 체크리스트 인쇄본에 반영한다. 결정은
2026-09-12 grill-yourself 로 확정했다.

## 무엇이 문제였나

1. 결선도의 미사용 게이트 입력 접지선이 순서표의 절반(NAND 20줄 중 12줄)이었고,
   빼도 결과가 달라지지 않았다. 학교 규정이 아니다 — 운영계획서 3.2 6) 은
   "직접 손으로 작성한 회로 결선도, 학번·이름·날짜" 만 요구한다.
2. 1-1(AND) → 1-2(OR) 는 칩만 갈아끼우면 되는데, AND 는 칩을 10행에, NAND 는
   같은 74HC08 을 7행에 두어 회로마다 전부 걷어야 했다. 복합회로의 기존
   1·2·3단계는 전원→신호→LED 라는 **그리는** 순서라 2단계까지 꽂아도 아무것도
   확인할 수 없었다.
3. 전부 꽂고 불이 안 들어오면 어디가 틀렸는지 알 수 없었다. 74HC08 결함은
   11 조합을 건너뛰어 마지막 회로에서야 드러났다.

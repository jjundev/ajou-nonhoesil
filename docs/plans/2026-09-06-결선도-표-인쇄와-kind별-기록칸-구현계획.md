# 결선도 표 인쇄와 kind 별 기록 칸 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 회로·공통 절의 마크다운 표를 인쇄본에 순서를 지켜 싣고, `_circuit_tables` 가 표 kind(`truth-table`·`stepped`·`capture`) 마다 다른 기록 칸을 내게 해서 실험02~10 여섯 주차의 백필을 메타 편집만으로 끝낼 수 있게 만든다.

**Architecture:** `render._blocks` 와 `_split_circuit_body` 가 `|` 로 시작하는 줄을 버리는 것을 **저작 규칙이 아니라 렌더러 결함으로** 취급해 고친다. `md.parse_table_at` 을 뽑아 두 렌더 경로가 같은 표 파서를 쓰게 하고, `_split_circuit_body` 를 순서 보존형 `_circuit_body` 로 대체한다. `## U<n> = <칩>` 헤딩을 `- U<n> = <칩>` 불릿과 동등한 배선 표기로 승격해 실험02·10 의 핀 표가 그대로 체크박스 배선표가 되게 한다. 기록 칸은 `truth-table`(현행 유지)·`stepped`(확인 열 없음, 빈 셀이 기록 칸)·`capture`(예상 상자 + 스케치 + 판독 조건)로 갈린다.

**Tech Stack:** Python 3 표준 라이브러리만 (PyYAML 없음). `unittest`. 인쇄는 Chrome headless → PDF (`scripts/lab/html2pdf.py`).

```python
def parse_table_at(lines: list, i: int):
    """`lines[i]` 가 표의 헤더면 `(MdTable, 표가 끝난 다음 인덱스)`, 아니면 `(None, i)`.

    구분선은 **위치로만** 판정한다 — 헤더 바로 다음 줄이어야 한다. 내용으로
    판정하면 `| - | - |` 같은 don't-care 행이 구분선과 구별되지 않아 데이터가
    조용히 사라진다 (`-` 는 이 프로젝트의 don't-care 표기 중 하나다).

    렌더러가 본문을 한 줄씩 훑으며 이것을 부른다 — 산문·칩 상자와 표의 **순서**를
    지키려면 표가 어디서 시작해 어디서 끝나는지를 알아야 한다.
    """
    if not (_ROW.match(lines[i]) and not _SEP.match(lines[i])
            and i + 1 < len(lines) and _SEP.match(lines[i + 1])):
        return None, i
    header = _cells(lines[i])
    sep_line = i + 2                          # 구분선의 1-based 줄 번호
    j, rows = i + 2, []
    while j < len(lines) and _ROW.match(lines[j]):
        if j + 1 < len(lines) and _SEP.match(lines[j + 1]):
            break                             # 이 줄은 다음 표의 헤더다
        rows.append(_cells(lines[j]))
        j += 1
    return MdTable(header=header, rows=rows, line=sep_line), j


def parse_tables(body: str) -> list:
    """본문에서 마크다운 표를 전부 찾는다."""
    lines = body.split("\n")
    tables, i = [], 0
    while i < len(lines):
        table, nxt = parse_table_at(lines, i)
        if table is None:
            i += 1
            continue
        tables.append(table)
        i = nxt
    return tables
```

```python
    """회로·공통 절의 마크다운 표가 인쇄본에서 통째로 사라지던 자리다.

    def test_표를_원문_위치에_인쇄한다(self):
        html = _blocks("앞 산문이다.\n\n"
                       "| 레일 | 값 |\n|---|---|\n| VCC | +5V |\n\n"
                       "뒤 산문이다.\n")
```

```python
def _blocks(body: str) -> str:
    """`- ` 불릿·열 0 산문·`##` 헤딩·**마크다운 표**를 HTML 로.

    들여쓴 이어지는 줄을 앞 항목에 붙인다 — 버리면 여러 줄로 쓴 경고가 중간에서
    잘린다. 74HC02 핀 순서 경고가 실제로 세 줄짜리 불릿이고, 그 경고를 netlist
    스스로 "이 실험에서 가장 흔한 배선 실수"라고 표시한다.

    빈 줄 없이 이어지는 열 0 산문 줄은 한 문단으로 합친다 — netlist 의
    "다르면 배선 오류다" 경고가 실제로 두 줄이다.

    표는 **원문 위치에** 인쇄한다. 옛 렌더러는 `|` 로 시작하는 줄을 전부 버렸고,
    그래서 실험10 공통 규칙의 전원 레일 표(그 주차 최대 사고 지점)와 실험02·03·05
    회로 절의 소자 배치·팬아웃 표가 인쇄본에서 통째로 사라졌다. 여섯 주차에서
    169줄이다. 여기 실린 표는 참조용이라 체크박스를 받지 않는다 — 체크박스는
    칩 상자 안의 배선표만 받는다.
    """
    out, items, para = [], [], []

    def flush_items():
        if items:
            out.append("<ul>" + "".join(f"<li>{_esc(i)}</li>" for i in items)
                       + "</ul>")
            items.clear()

    def flush_para():
        if para:
            out.append(f"<p>{_esc(' '.join(para))}</p>")
            para.clear()

    lines = body.split("\n")
    i = 0
    while i < len(lines):
        line = lines[i].rstrip()
        stripped = line.strip()
        if not stripped:
            flush_para()
            i += 1
            continue
        if stripped.startswith("|"):
            table, nxt = md.parse_table_at(lines, i)
            if table is None:
                i += 1                    # 구분선 없는 `|` 줄 — 표가 아니다
                continue
            flush_items()
            flush_para()
            out.append(_md_table_html(table))
            i = nxt
            continue
        if stripped.startswith("#"):
            flush_items()
            flush_para()
            out.append(f"<h4>{_esc(_plain(stripped.lstrip('# ')))}</h4>")
            i += 1
            continue
        m = _BULLET.match(line)
        if m and not m.group(1):
            flush_para()
            items.append(_plain(m.group(2)))
            i += 1
            continue
        if line.startswith((" ", "\t")) and items:
            items[-1] += " " + _plain(stripped)
            i += 1
            continue
        flush_items()
        para.append(_plain(stripped))
        i += 1
    flush_items()
    flush_para()
    return "\n".join(out)
```

```python
def _new_chip(head: str) -> dict:
    return {"type": "chip", "head": _plain(head), "wires": [], "unused": [],
            "notes": [], "tables": []}


def _chip_boxes(nodes) -> list:
    """노드 목록에서 칩 상자만. 미사용핀 상자와 테스트가 쓴다."""
    return [n for n in nodes if n["type"] == "chip"]


def _circuit_body(section):
    """회로 본문을 `(노드 목록, 첫 칩 앞 산문, 마지막 칩 뒤 산문)` 으로 가른다.

    `- U<n> = <칩>` 이 상자의 제목이고 그 아래 들여쓴 `- ` 가 배선이다. 옛
    렌더러는 들여쓰기를 무시하고 전부 형제 번호로 만들어 **칩의 경계가 사라졌다**.

    미사용핀 줄은 배선 목록에서 빼내되 **칩 안에 남긴다**. 회로 단위로 한데
    모으면 다칩 회로에서 같은 핀 번호가 정반대 지시를 동시에 받는다 — C4 의
    pin 4 는 U5 기준 GND, U6 기준 개방이다. 어느 칩 것인지 인쇄본에 단서가
    없으면 "출력을 GND 로 내려 칩을 죽이는" 바로 그 사고가 된다.

    칩과 칩 **사이**의 산문·표는 노드로 남겨 원문 순서를 지킨다 — 옛 3버킷
    분해로는 실험10 P1 의 `U3 → 가중 저항망 표 → U4` 를 표현할 수 없어 표가
    마지막 칩 뒤로 밀렸다.

    앞뒤 산문을 따로 돌려주는 이유는 원문이 그렇게 쓰여 있기 때문이다 — 앞은
    회로 소개와 배선 경고(`74HC02 의 핀 순서에 주의`)이고, 뒤는 배선을 마친 뒤
    하는 검산(`LED_X 와 LED_Z 가 같이 켜져야 한다`)이다. 한 덩어리로 합치면
    검산 지시가 배선 앞에 놓여 preamble 로 읽힌다.

    칩 선언이 하나도 없으면 상자를 만들지 않고 본문 전체를 앞쪽 산문으로
    흘린다. 조용히 버리는 것보다 낫다.
    """
    lines = section.body.split("\n")
    nodes, prose = [], []
    chip, last_key = None, None

    def close_chip():
        nonlocal chip, last_key
        if chip is not None:
            nodes.append(chip)
            chip, last_key = None, None

    def flush_prose():
        if any(p.strip() for p in prose):
            nodes.append({"type": "prose", "text": "\n".join(prose)})
        prose.clear()

    i = 0
    while i < len(lines):
        line = lines[i].rstrip()
        stripped = line.strip()

        m = _CHIP_LINE.match(line)
        if m:
            close_chip()
            flush_prose()
            chip = _new_chip(m.group(1))
            i += 1
            continue

        if chip is not None:
            if stripped.startswith("- ") and line.startswith((" ", "\t")):
                text = _plain(stripped[2:])
                last_key = "unused" if text.startswith("미사용") else "wires"
                chip[last_key].append(text)
                i += 1
                continue
            if line.startswith((" ", "\t")) and stripped and last_key:
                # **마지막으로 담은 목록**에 잇는다. `wires` 로 고정하면 미사용
                # 줄을 잇는 줄이 엉뚱한 배선 줄에 붙는다 — 플로팅 핀 지시를
                # 다른 항목에 조용히 재부착하는 것이라, 칩 라벨을 잃던 결함과
                # 같은 부류다.
                chip[last_key][-1] += " " + _plain(stripped)
                i += 1
                continue
            if stripped:
                close_chip()          # 열 0 줄이 불릿형 칩 상자를 닫는다

        prose.append(line)
        i += 1

    close_chip()
    flush_prose()

    chip_at = [n for n, x in enumerate(nodes) if x["type"] == "chip"]
    if not chip_at:
        return [], "\n".join(x["text"] for x in nodes), ""
    first, last = chip_at[0], chip_at[-1]
    before = "\n".join(x["text"] for x in nodes[:first])
    after = "\n".join(x["text"] for x in nodes[last + 1:])
    return nodes[first:last + 1], before, after
```

### Task 4: `## U<n> = <칩>` 헤딩형 칩 상자와 배선표

실험02·10 은 배선을 `## U1 = \`7490\` (decade counter)` 헤딩 + `핀 | 연결 | 왜` 표로 적는다. `netlist_parser.IC_DECL`(`netlist_parser.py:29`)은 이미 이 형식을 파싱한다 — 그 주석이 실험10 을 이름으로 인용한다. 렌더러만 못 읽는다.

**Files:**
- Modify: `scripts/lab/render.py` (`_circuit_body`, `circuit_pages`)
- Create: `tests/fixtures/netlist_heading_chips.md`
- Test: `tests/test_lab_render.py`

**Interfaces:**
- Consumes: `_circuit_body` (Task 3), `md.parse_table_at` (Task 1), `_md_table_html(table, lead_checkbox=True)` (기존)
- Produces: 칩 노드의 `tables: [MdTable]` 이 채워진다. 헤딩형 칩의 배선표는 행마다 선행 `<td class="box">` 를 받는다.

**규칙 (두 형식의 차이는 의도한 것이다):**

| | 불릿형 (`- U1 = ...`) | 헤딩형 (`## U1 = ...`) |
|---|---|---|
| 상자 범위 | 들여쓴 줄만. 열 0 줄이 닫는다 | 다음 헤딩(어느 레벨이든) 또는 다음 칩 선언까지 |
| 배선 | 들여쓴 `- ` 불릿 → `<ol>` 체크박스 | 상자 안의 마크다운 표 → 표 행마다 `.box` |
| 미사용핀 | `미사용` 으로 **시작하는** 불릿 | 어느 셀에든 `미사용` 이 든 표 행 |
| 그 밖의 줄 | (없음 — 열 0 이면 상자를 닫는다) | `notes` 로 상자 안에 산문 인쇄, 체크박스 없음 |

미사용 판정이 형식마다 다른 이유: 실험10 U2 표는 `| 미사용 입력핀 11, 13 | GND | 플로팅 금지 |` 로 1열에 있고, 실험02 P4 U2 표는 `| 3 (2A) | **GND** | 미사용 입력 |` 로 3열에 있다. 열 위치를 못 박을 수 없다.

```python
_CHIP_LINE = re.compile(r"^-[ \t]+(U\d+[ \t]*=[ \t]*.+)$")
# ``## U1 = `7490` (decade counter)`` — 실험02·10 의 배선 표기. `IC_DECL` 은

# 배선 80줄이 통째로 사라졌다.
_CHIP_HEAD = re.compile(r"^#{2,}[ \t]+(U\d+[ \t]*=[ \t]*.+?)[ \t]*$")
_ANY_HEAD = re.compile(r"^#{1,}[ \t]+\S")
```

```python
def _absorb_wiring(chip, table) -> None:
    """헤딩형 칩 상자 아래의 마크다운 표를 배선표로 흡수한다.

    표를 **표인 채로** 남긴다 — 불릿으로 펴면 실험10 의 `핀 | 연결 | 왜` 가
    정렬을 잃고, 정렬이야말로 표로 적은 이유다. 행마다 앞에 체크박스 열이 붙는다.

    어느 셀에든 `미사용` 이 있으면 미사용 목록으로 뺀다. 열 위치를 못 박을 수
    없다 — 실험10 U2 표는 1열(`미사용 입력핀 11, 13`)이고 실험02 P4 U2 표는
    3열(`미사용 입력`)이다. 미사용은 배선 순서와 무관하게 **배선을 끝낸 뒤**
    칩마다 따로 확인하는 물건이라 목록이 갈려야 한다.
    """
    kept = []
    for row in table.rows:
        cells = [_plain(c).strip() for c in row]
        if not any(cells):
            continue
        if any("미사용" in c for c in cells):
            chip["unused"].append(" · ".join(c for c in cells if c))
        else:
            kept.append(row)
    if kept:
        chip["tables"].append(md.MdTable(header=table.header, rows=kept,
                                         line=table.line))
```

```python
def _truth_table_html(table) -> str:
    """진리표 — 입력은 주어지고, 출력에 `예상` 을 병기한 뒤 확인 칸을 붙인다."""
    inputs, outputs = split_columns(table)
    at = {c: i for i, c in enumerate(table.header)}
    head = list(inputs) + [f"{c}예상" for c in outputs]
    body = [[normalize_cell(row[at[c]]) for c in inputs]
            + [normalize_cell(row[at[c]]) for c in outputs]
            for row in table.rows]

    # thead/tbody 로 나눈다 — 표가 쪽을 넘어가도 헤더가 따라가야 한다.
    # 헤더 없는 진리표 조각은 실험실에서 읽을 수 없다.
    out = ["<table>", "<thead>", "<tr>"]
    out += [f"<th>{_esc(h)}</th>" for h in head]
    out.append('<th>확인</th></tr>')
    out += ["</thead>", "<tbody>"]
    for row in body:
        out.append("<tr>" + "".join(f"<td>{_esc(c)}</td>" for c in row)
                   + '<td class="check"></td></tr>')
    out += ["</tbody>", "</table>"]
    return "\n".join(out)


def _stepped_html(table) -> str:
    """스텝표 — **명세가 저작해 둔 빈 셀**이 실험실에서 채울 칸이다.

    `확인` 열을 붙이지 않는다. `확인` 은 "✓ 일치 / 값 = 불일치" 규약이라
    **예상값이 있어야** 뜻이 있는데 스텝표에는 없다. 붙이면 비교 대상 없는 빈
    칸이 하나 더 생기고, 실험02 T3~T5·T7 처럼 이미 `기록` 열을 저작한 표에서는
    같은 뜻의 칸이 둘이 된다.

    빈 셀이 하나도 없는 표에만 `기록` 열을 만든다 — 그런 표는 채울 곳이 없다.

    `.check` 가 아니라 `.fill` 을 쓴다. `.check` 개수는 명세의 `truth-table`
    행 수와 대조되는 불변식이라 다른 뜻의 칸을 섞으면 그 검사가 죽는다.
    """
    header = list(table.header)
    rows = [[normalize_cell(c) for c in row] for row in table.rows]
    if not any(not c.strip() for row in rows for c in row):
        header.append("기록")
        rows = [row + [""] for row in rows]

    out = ["<table>", "<thead>", "<tr>"]
    out += [f"<th>{_esc(h)}</th>" for h in header]
    out += ["</tr>", "</thead>", "<tbody>"]
    for row in rows:
        out.append("<tr>" + "".join(
            '<td class="fill"></td>' if not c.strip() else f"<td>{_esc(c)}</td>"
            for c in row) + "</tr>")
    out += ["</tbody>", "</table>"]
    return "\n".join(out)
```

```python
def _stepped(table) -> str:
    """명세에서 비어 있는 열이 실험실에서 채울 칸이다.

    `예상` 도 `확인` 도 붙이지 않는다. `확인` 은 "✓ 일치 / 값 = 불일치" 규약이라
    **예상값이 있어야** 뜻이 있는데 스텝표에는 없다. 인쇄본(`render._stepped_html`)
    이 같은 이유로 뺐다 — 두 문서는 쌍이라 규약이 갈리면 전사에서 어긋난다.

    빈 열이 하나도 없는 표에만 `기록` 열을 만든다.
    """
    header = list(table.header)
    rows = [list(row) for row in table.rows]
    if not any(not c.strip() for row in rows for c in row):
        header.append("기록")
        rows = [row + [""] for row in rows]
    return _grid(header, rows)
```

```python
def _chip_swap(previous, current) -> str:
    """칩 교체 배너. 준비물이 종류당 하나라 순차 배선이 강제된다 (netlist M10).

    같은 칩이 다음 회로에도 쓰이면 패키지는 남지만 **점퍼선은 다르다** —
    netlist 가 "항목마다 재배선해 쓰는 것"이라고 적는다. `그대로 둔다` 로만
    적으면 배선까지 그대로 둬도 되는 것으로 읽힌다.

    `continues` 가 있는 회로는 예외다. 실험10 E10.P2 는 다 만든 DAC 에 `741`
    비교기를 하나 더 붙이는 회로라, 기본 문구(`점퍼선을 모두 걷는다`)를 그대로
    따르면 직전 회로를 뜯는다.
    """
    if previous is None:
        return "준비 — 꽂는다: " + ", ".join(current.ics)
    if current.continues:
        add = [c for c in current.ics if c not in previous.ics]
        tail = " · 추가로 꽂는다: " + ", ".join(add) if add else ""
        return (f"{current.continues} 를 그대로 두고 이어 붙인다 — "
                f"점퍼선을 걷지 않는다{tail}")
    remove = [c for c in previous.ics if c not in current.ics]
    add = [c for c in current.ics if c not in previous.ics]
    keep = [c for c in current.ics if c in previous.ics]
    parts = ["앞 회로의 점퍼선을 모두 걷는다"]
    if remove:
        parts.append("뺀다: " + ", ".join(remove))
    if add:
        parts.append("꽂는다: " + ", ".join(add))
    if keep:
        parts.append("패키지는 두고 재배선한다: " + ", ".join(keep))
    return " · ".join(parts)
```

```python
    WIRE_ROWS = 51
    UNUSED_ROWS = 4
    CHIPS = 5

    def setUp(self):
        d = ROOT / config.experiment_dir(10)
        self.spec = parse_spec(d / "체크리스트/명세.md")
        self.netlist = parse_netlist(d / "결선도/netlist.md")

        self.assertEqual(self.html.count('class="chip"'), self.CHIPS)

    def test_원문_배선표의_모든_행이_인쇄본에_온다(self):
        rows = [row for circuit in self.netlist.circuits
                for chip in _chip_boxes(_circuit_body(circuit)[0])
                for table in _chip_tables(chip) for row in table.rows]
        self.assertEqual(len(rows), self.WIRE_ROWS)
        for row in rows:
            for cell in row:
                text = _esc(_plain(cell)).strip()
                if len(text) < 3:
                    continue          # `7`·`14` 같은 핀 번호는 우연히 겹친다
                with self.subTest(cell=text[:40]):
                    self.assertIn(text, self.html)

    def test_배선_체크박스_수가_원문_배선행_수와_같다(self):

                         self.WIRE_ROWS)

    def test_미사용_행이_배선표에서_빠져_미사용_상자로_간다(self):
        """미사용 판정을 지우면 체크박스가 4개 늘고 미사용 상자가 빈다."""

            if 'class="unused"' not in page:

            boxes += page[page.index('class="unused"'):].count('<span class="box">')
        self.assertEqual(boxes, self.UNUSED_ROWS)

    def test_미사용핀_지시가_어느_칩_것인지_밝힌다(self):
        """U2·U3 둘 다 `pin 11, 13 → GND` 다. 라벨이 없으면 구별되지 않는다."""
```

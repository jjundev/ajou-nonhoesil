# v2 배선기가 신호 이름 배지를 피한다 — 설계

2026-10-05 `grill-yourself` 결과. 결정 #6 은 사용자 확정, 나머지는 기본값 확정.

## Intent

v2 배선기(`route_plan`)가 보드 위 신호 이름 배지(입력 점퍼 이름 · LED 꼬리표)를 장애물로 보게 해, 선도
번호 원도 배지 위로 지나가지 않게 한다. 끝나면 실험05 두 회로(`build_e5_bcd`·`build_e5_xs3`)가 가독성 시험
`test_신호_이름_배지가_번호_원_배선_홀을_가리지_않는다` 를 통과하고, 실험01~04(v1) 그림과 실험04 v2
시험판 경로는 그대로다.

분류: bounded — 배선기의 판정 함수 둘과 입력 점퍼 헬퍼 하나를 고친다.

## 원인 (실측 2026-10-05)

v2 그림 전부의 배지 겹침: 실험04 시험판 0 · 실험05 시험판 3 · 실험05 C1 4 · C2 1.

| 원인 | 겹침 | 어디서 |
|---|---|---|
| ① 배선기가 배지 위로 선을 깐다 | C1 `Bit0`~`Bit2` ← `Y0` 급전 | `engine/router.py` `_valid` 는 번호 원 상자는 보고 `bb.tag_boxes` 는 안 본다 |
| ② 배선 번호 원이 배지 위에 앉는다 | C1 `Bit1`~`Bit3` | `engine/renderer.py` `_marker_clear`(경로 번호 원·`_auto_marker` 가 쓴다)가 배지를 안 본다. `_marker_fits` 는 본다 |
| ③ 입력 점퍼가 자기 배지 위에 번호를 찍는다 | C2 `D1` | `engine/helpers.py` `_input_jumper` 가 가운데 레일 번호 원을 **핀 행** −18px 에 두는데 배지는 **레일 착지 행**에 붙는다. 핀 행이 레일 빈 행이면 착지가 한 행 밀려 둘이 포개진다. 배지를 번호 원 뒤에 그려 `_settle_marker` 도 모른다 |

## 바꾸는 것

1. `_valid` — 경로 구간이 `bb.tag_boxes` 상자(여유 1px)에 닿으면 거절. 번호 원 상자 검사와 같은 꼴.
2. `_marker_clear` — `tag_boxes` 와 `_boxes_touch` 하면 거절. `_marker_fits` 와 같은 식.
3. `_input_jumper` — v2(`spec.readability`)의 가운데 레일 **기본** 번호 원 기준을 `y_rail` 로. v1 은 그대로.
4. SKILL §4a 한 줄: 고정 빌더는 입력 점퍼·LED 사슬을 경로보다 먼저 그린다(배선기는 그때까지 그려진
   배지만 피한다).

세 호출 자리는 전부 v2 경로다 — `_marker_clear` 는 `step_wire` 의 `spec.readability` 갈래·`_settle_marker`·
배선기에서만 불린다. v1 도장은 안 바뀐다.

## 시험

- 단위(`tests/test_breadboard_route.py`): 배지를 지나는 경로는 `_valid` 거절 · 배지 위 자리는 `_marker_clear`
  거절 · 빈 행 핀의 가운데 레일 입력은 번호 원이 자기 배지와 안 겹친다. 셋 다 고치기 전 실패를 본다.
- 회귀: `LambdaZero`(실험04 시험판 `plans_lambda0.json`), v1 도장(`test_breadboard_boards`), 배선기·배치기·
  가독성 시험 전체.
- 실험05: 다시 그린 뒤 가독성 두 시험 통과, `verify()`·단계 예산 5 그대로.

## 실패하면

C1 에서 장애물이 늘어 `경로 없음` 이 나면 배선기 수리(직전 4가닥)가 먼저 돈다. 그래도 막히면 C1 배치
(K1 행·LED 윗행)를 다시 고른다 — 배치기는 74HC04 때문에 후보를 못 낸다(#6). 고정 사슬 선(LED 애노드 →
+5V)이 배지에 닿는 배치는 배치로만 피한다 — 지금 기준 배치에는 없다.

## 이번에 안 하는 것

- 배치기의 "입력 핀이 레일 빈 행이면 버림" 규칙(`place_proxy`) — 74HC04 배치를 전부 버린다. 배치 지문과
  실험04 시험판 `배치탐색.md` 가 다시 돈다.
- `verify()` 에 배지 규칙(R15) — 지금은 가독성 시험이 막는다. v1 소급 범위를 먼저 정해야 한다.

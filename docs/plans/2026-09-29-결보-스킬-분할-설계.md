# 결보 스킬 조건부 본문 분할 설계

## 의도

`write-result-report/SKILL.md`(721줄)에서 **조건이 참일 때만 실행되는 본문**을 같은
스킬 폴더의 형제 파일로 옮긴다. SKILL.md 에는 번호·굵은 첫 문장·발동 조건·포인터만
남긴다. 보통 실행(기록.md 에 전사할 필기·사진이 없고, 퀴즈 `generate: false`,
`repeat: per-item` 없음)은 옮긴 본문을 읽지 않고, 조건이 참인 실행은 그 단계에서
해당 파일을 읽는다.

분류: bounded — 이미 있는 "그루터기 + 포인터" 패턴(`.claude/보고서서식.md`,
`tests/test_skill_docs.py` 의 `SHARED_*`)을 스킬 폴더 안으로 넓힌다.

## 배경 정정

대화 초반 진단의 "③·④ 서식 규칙 두 벌" 은 이미 같은 날 `보고서서식.md` 로 합쳐져
있었다. 실제로 남은 중복은 **실행 절차 0단계**(43줄)가 ③·④·⑤·② 에 글자 그대로,
draft-lab-spec 에 87% 로 있는 것이다 — 이번 범위 밖(다음 라운드).

# 결선도 엔진 나누기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3846줄 `render_breadboard.py` 를 역할별 조각 여섯(`scripts/engine/*.py`)과 약 300줄 진입점으로 나누고, 주석·docstring 을 절반 안팎으로 줄인다 — 바깥 동작(도장·PNG 바이트·import 이름)은 하나도 바꾸지 않는다.

**Architecture:** 진입점이 조각을 `_PARTS` 순서대로 **자기 `globals()` 에서** `exec(compile(src, path, 'exec'))` 한다. 그래서 엔진은 여전히 한 모듈 이름공간이고, 로드마다 독립 사본·모듈 전역 바꿔 끼우기·사본별 캐시라는 기존 계약이 그대로 선다. 나누기는 줄을 그대로 옮기는 스크립트 한 번으로 하고(줄 다중집합으로 증명), 주석 정리는 그 뒤 별도 커밋으로 한다(docstring 뺀 ast 대조로 증명).

**Tech Stack:** Python 3.14 표준 라이브러리 + Pillow(엔진 기존), unittest/pytest(xdist `-n auto --dist loadgroup`, 한 파일만 볼 때 `-n0`), git worktree.

**Spec:** `docs/plans/2026-10-05-결선도-엔진-나누기-설계.md`

```python
"""엔진 나누기 회귀 — 모든 주차·시험판 결선도를 뽑아 파일마다 sha256 을 적거나(save) 맞댄다(check).

python tmp/engine-split/golden.py save  tmp/engine-split/golden.json
python tmp/engine-split/golden.py check tmp/engine-split/golden.json
"""
import hashlib
import importlib.util
import json
import sys
import tempfile
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]
ENGINE = ROOT / '.claude/skills/breadboard-diagram/scripts/render_breadboard.py'
FIXTURES = ('board_min', 'board_layers', 'board_v2', 'board_v2_e4', 'board_v2_e5')


def load():
    spec = importlib.util.spec_from_file_location('render_breadboard', ENGINE)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def snapshot():
    mod = load()
    boards = [(f'실험{n:02d}', mod.load_board(n)) for n in mod.board_numbers()]
    boards += [(f, mod.load_board_file(ROOT / 'tests/fixtures' / f / '배치.py', f)) for f in FIXTURES]
    out = {}
    with tempfile.TemporaryDirectory(ignore_cleanup_errors=True) as d:
        for label, board in boards:
            od = Path(d) / label
            od.mkdir()
            if hasattr(board, 'LAYOUT'):          # v2 시험판 — RESTART 를 아는 쪽으로 그린다
                err = mod.place_verify(board, board.LAYOUT, str(od))
                assert err is None, f'{label}: {err}'
            else:
                mod.build_all(board, str(od))
            for p in sorted(od.iterdir()):
                out[f'{label}/{p.name}'] = hashlib.sha256(p.read_bytes()).hexdigest()
    return out


def main(cmd, path):
    now = snapshot()
    if cmd == 'save':
        Path(path).write_text(json.dumps(now, ensure_ascii=False, indent=1, sort_keys=True), encoding='utf-8')
        print(f'{len(now)}개 파일 기록')
        return 0
    want = json.loads(Path(path).read_text(encoding='utf-8'))
    bad = sorted(k for k in want.keys() | now.keys() if want.get(k) != now.get(k))
    print('같다' if not bad else '다르다:\n  ' + '\n  '.join(bad))
    print(f'{len(now)}개 파일')
    return 1 if bad else 0


if __name__ == '__main__':
    raise SystemExit(main(*sys.argv[1:3]))
```

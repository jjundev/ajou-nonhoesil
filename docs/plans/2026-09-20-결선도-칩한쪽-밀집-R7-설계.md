# 결선도 칩 한쪽 밀집 해소 — 게이트 좌우 배정 + 밀도 검사 R7 (설계)

2026-09-20. `/grill-yourself` 로 낸 설계. 결정 #9·#10·#11 은 사용자가 추천안대로 확정했다.

## 의도

실험03 결선도는 네 칩 모두 게이트 1·2(핀 1~6)만 써서 배선이 칩 **왼쪽 a~d 열 7행**에
몰렸고, 오른쪽에는 pin 14 전원선 하나뿐이었다(2026-09-18 실험실: 전감산기 74HC86 왼쪽
11리드 vs 오른쪽 1리드 — 꽂기도, 꽂았는지 확인하기도 힘들었다). 실험04부터는 netlist
저작 단계에서 게이트를 칩 **좌·우로 나눠** 배정하고, 렌더러가 칩 한쪽에 꽂히는 리드 수를
세어 한도를 넘으면 그림을 내지 않게 한다. 실험01~03 승인본은 손대지 않는다.

"완료" = 새 주차 빌더가 한쪽 밀집이면 `verify()` 가 어느 칩·어느 쪽·몇 리드인지 이름을
대며 멈추고, 오른쪽 게이트 입력을 중앙 레일에서 꽂는 그림이 기존 R1~R6·넷 검사를 그대로
통과한다.

분류: **architectural** — 새 규칙(R7)·입력 헬퍼 분기·저작 관례가 들어가고, 지금은 이를
잡는 검사가 없다.

## 완료 시 동작

- `render_breadboard.py --experiment N` 이 칩 한쪽(핀 행 7개 × 자유 열 4개) 리드가 8 을
  넘으면 파일을 쓰지 않고 `R7 칩 한쪽 밀집: 74HC86(좌 7행) 왼쪽 11리드 > 8: 좌 b7, …` 로
  멈춘다.
- 새 주차 netlist 는 quad 칩에서 게이트 둘을 쓰면 **1·4**(핀 1,2→3 / 12,13→11), hex
  인버터 둘이면 **1·6**(1→2 / 13→12)으로 적는다. 체크리스트·핀 점검 상자는 netlist 에서
  파생되므로 따라온다.
- 오른쪽 게이트의 입력 점퍼는 그쪽에 붙은 GND 레일(좌 블록이면 중앙 GND 468)에서 **i 열**로
  들어가고, 신호 이름 배지는 그 레일 바깥 여백에 찍힌다. 1 을 줄 때 옮기는 규칙은 같다.
- 실험01·02·03 의 PNG·도장·손그림 검토 결과는 바뀌지 않는다. 실험03 전감산기 74HC86 의
  11리드는 R7 회귀 사례로 테스트에 숫자로 남는다.

## 이번에 안 하는 것

- 실험03 재렌더 — 결과보고서·손그림이 제출됐고 도장 테스트가 PNG 를 고정한다.
- 입력을 칩 밖 스트립에 먼저 꽂고 갈래를 거기서 뽑는 "버스 행" — 입력마다 점퍼 +1 이라
  실험01 교훈(가닥 수)과 충돌한다.
- `validate.py` 의 netlist 게이트 균형 검사 — 결과는 R7 이 잡는다.
- 배선이 칩 몸통 위를 지나는지 검사 — 관례로만 둔다.

### 확정 (근거)

| # | 결정 | 답 | 근거 |
|---|---|---|---|
| 0 | 접근 | A | 밀집은 스트립 배정 문제 — 게이트를 옮겨야 스트립이 바뀐다 |
| 1 | 밀도 지표 | 칩 핀 행 7개 × 한쪽 자유 열 4개(a~d / g~j)에 꽂힌 **끝점** 수. 지나가는 선(`_passed`) 제외, 칩 핀(e·f) 제외 | `_leads` 가 홀 단위 점유표(`render_breadboard.py` `lead()`). 지나감은 R3·R4 가 이미 제한 |
| 2 | 집행 위치 | `verify()` R7, 기본 `strict` | SKILL §5 "문서를 읽어선 안 나온다 → 검사에 넣는다". `overlap_policy` 와 같은 꼴 |
| 3 | 지난 주차 | 실험01~03 기본 빌더에 `bb.density_policy = 'legacy'` 한 줄. 테스트 allowlist 는 실험 번호 {1, 2, 3} | 승인본 재작성 금지. 정책은 `content()` 밖이라 도장 불변 |
| 4 | 지표 노출 | `side_leads()` 별도 메서드. `wiring()` 불변 | `content()` 가 `wiring()` 을 통째로 해시 — 필드 하나만 더해도 실험01~03 도장 전부 깨짐 |
| 5 | 오른쪽 게이트 입력 | `_input_jumper(..., side='f')`: 그쪽 GND 레일 → i 열, 배지는 레일 바깥 여백 | 기존 assert 가 "우 블록 입력이면 자리를 새로 정한다" 고 예약해 둔 자리 |
| 6 | 게이트 짝 | quad 둘 = 1·4, 셋 = 1·4·2 / hex 둘 = 1·6, 셋 = 1·6·2 | 게이트4(핀 12,13→11)는 행 +1~+3 로 게이트1 의 거울 — 사슬(pin 3 → pin 12)이 같은 행대에 머물고 칩 위 행 한 번만 건넌다 |
| 7 | 사슬 건너기 | 칩 위 행(pin1_row−1)으로, 몸통 위 금지(관례) | 실험03 "칩 위 4·5·6행" 관례 그대로. 검사는 안 넣는다 |
| 8 | 파생물 | 체크리스트·손그림 검토·validate 무변경 | 핀은 netlist, 정답은 `wiring()` 에서 파생 |
| 9 | `SIDE_LEAD_MAX` | **8** | 실험03 좌 11 은 실패, 게이트를 나눈 전가산기(좌 7·우 5)는 통과. 6 이면 갈래 둘 있는 입력 스트립이 걸려 버스 행이 필요해진다 |
| 10 | 실험03 소급 | **안 한다**(legacy 고정) | 도장·손그림 참조가 흔들린다 |
| 11 | 적용 시점 | **실험04 netlist 저작부터** (draft-lab-spec 규칙 + R7 strict) | 실험04 칩이 16핀 MSI 면 게이트 짝 규칙은 안 걸리고 R7 만 산다 |

## 실험03 실측 (설계 근거 숫자, `side_leads()` 로 회귀에 남긴다)

전감산기 완성본(`build_e3_fs`), 한쪽 = 핀 행 7 × 자유 열 4:

| 칩 | 자리 | 왼쪽(a~d) | 오른쪽(g~j) |
|---|---|---|---|
| 74HC86 | 좌 7행 | 11 (b7 d7 b8 c8 a9 c9 c10 b11 c11 b12 b13) | 1 (g7) |
| 74HC04 | 좌 18행 | 5 | 1 |
| 74HC08 | 우 10행 | 7 (실측 2026-09-20 — 설계 초안의 8 은 그림에서 센 어림값) | 1 |
| 74HC32 | 우 21행 | 4 | 1 |

## 격리 시험 (2026-09-20)

실험03 전가산기·전감산기를 게이트 1·4 / 1·6 으로 다시 짜서 strict 로 뽑았다 —
`docs/verify/2026-09-20-실험03-균형결선/README.md`. 승인본은 R7 에 `74HC86(좌 7행) 왼쪽 11리드 > 8` 로
걸렸고, 나눈 판은 74HC86 좌 7·우 5, 74HC08 좌 4·우 4, 74HC04 좌 3·우 3, 74HC32 좌 4·우 1 로 통과했다.
가닥 수는 전가산기 27→28, 전감산기 31→32 로 각각 +1(새 GND 브리지)뿐이다. 통과 기준 5개 중 5개 통과.
규칙 변경 필요 여부: 필요 없다 — `SIDE_LEAD_MAX = 8` 은 게이트를 좌우로 나누라는 방향만 강제하는
느슨한 한도로 의도대로 작동했고, 남은 칩 사이 행 밀집은 R7 이 재는 대상이 아니라 별개 지표가 다룰 문제다.

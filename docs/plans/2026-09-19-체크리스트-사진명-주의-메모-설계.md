# 설계: 체크리스트 C~E — 사진 파일명 통일 · 물리 주의 상자 · 종료 메모 경로

작성 2026-09-19. `/grill-yourself` 결과이고, Needs-you 세 줄은 사용자가 권장값으로 확정했다.
출처는 2026-09-19 핸드오프("체크리스트 강의노트 회로도(B) 병합 이후 — C~E 와 유보 사항")다.

## Intent

실험04 부터 들고 갈 체크리스트 인쇄본과 결과보고서 스킬을 실제 실험 방식에 맞춘다.

- **C.** 사진 파일명을 `scripts/lab/contact_sheet.py` 규칙(`<항목> <입력비트>.jpg`) 하나로 통일한다. 진리표 행마다 찍을 파일명을 인쇄본에 미리 찍는다.
- **D.** 공통면에 물리 주의 상자 3줄을 넣는다.
- **E.** 실험 뒤에 쓴 자유 메모 파일을 고찰의 정식 재료로 받는다.

완료 기준:
- 스킬 문서·코드 어디에도 `T<n> row<m>` 이 남지 않는다(`docs/plans` 이력은 제외).
- 실험03 검증 렌더(`_검증.*`)에서 파일명 열·주의 상자·새 종료 목록이 보인다.
- 테스트 결과가 기준선 `9 failed` 그대로다.

분류: **bounded** — 이미 있는 `render.py`·`contact_sheet.py`·스킬 문서 세 개의 흐름을 고친다.

## 완료 후 동작

- **진리표 · 사진 파일명 열:** 진리표 오른쪽 끝, `확인` 열 옆에 `사진 파일명` 열이 붙는다. 행마다 `1-2 000.jpg` 처럼 그대로 쓸 이름이 인쇄된다.
  - 항목 제목에서 토큰(`실험 1-2)` → `1-2`)을 못 뽑으면 열을 내지 않는다.
  - 입력 셀에 0/1 이 아닌 값이 있는 행은 `—` 다.
- **사진 지시 줄:**
  - 진리표: "시험한 행마다 1장(불일치 행 필수), 표의 파일명 그대로, 앞에 실험 번호(예: 실험03)를 붙이지 않는다".
  - 스텝표·파형: `<항목> <표ID> <설명>.jpg` 를 안내한다.
- **공통면 · 물리 주의 상자:** 전원 박스 바로 아래에 3줄이 붙는다.
  - 클립 깊이까지만 꽂는다(실험03 GND).
  - 칩을 꽂고 뽑을 때 전원을 끈다.
  - 회로를 바꿀 때는 걷을 선부터 먼저 뽑는다. 이 셋째 줄은 걷기 보드(`0` 행)가 있는 주차에만 "0단계 걷기 그림의 선부터"라고 말한다.
- **종료면:** 7항목을 유지한다.
  - 빠지는 것: "완성 회로 사진", "T1 row3 형식".
  - 들어가는 것: "사진 파일명이 표에 인쇄된 이름 그대로인가", "종료 메모 거리를 적어 두었는가(자유 메모 파일도 된다)".
- **결과보고서 · 사진 전사:** 확인 칸이 비고 필기 PDF 가 없어도 행 사진이 있으면 사진에서 `기록.md` 를 전사한다.
  - 입력은 파일명에서, LED 만 판독한다.
  - 사용자 확정 후 반영한다.
  - 사진이 없는 행은 공란이다.
- **결과보고서 · 자유 메모:** 종료 메모가 비어 있고 실험 폴더 최상위에 자유 메모 `.md` 가 있으면 후보로 제시한다.
  - 4문항 대응표를 보여 주고 확정받는다.
  - 확정되면 `기록.md` 종료 메모를 먼저 채우고 고찰은 거기서 파생한다.
- **사진 시트:** 스텝표·파형 사진(`1-1 T1 xy.jpg`)은 `contact_sheet --check` 의 "규칙 밖" 문제로 잡히지 않고 시트 대상에서만 빠진다.

## Global Constraints

- 규칙 번호를 바꾸지 않는다. ③ 1~22, ④ 1~19(`5b` 포함) 가 그대로 남는다 — `test_rule_and_step_numbering_is_contiguous` 가 본다.
- 굵은 첫 문장(`N. **…**` 의 `**…**` 부분)을 글자 하나 바꾸지 않는다 — `test_particle_spacing_rule_lives_in_both_report_skills` 가 ③21·④18 의 굵은 문장에서 `조사와 숫자 뒤 단위는 붙여 쓴다` 를 찾는다.
- 내용을 지우지 않는다. 옮기거나 아래 치환표대로 바꾸기만 한다 — Task 1 Step 9 의 문장 보존 검사가 증명한다.
- ③18(문단 한 줄)·③19(11열)는 ③ 에 그대로 둔다(결정 #11).
- 공용 파일 안에서는 원문자 없는 `§절대 규칙 N`·`§실행 절차 N`·`N단계`·`N번대로` 를 쓰지 않는다. 절끼리는 `§<절 이름>` 으로 가리킨다.
- 스킬 문서와 공용 파일에 `Task <숫자>` 를 쓰지 않는다(`test_skill_docs.py` 의 작업 번호 금지 검사).
- 문서 산문은 저장소 관례대로 76열 안팎에서 접는다. 인코딩 UTF-8, 줄바꿈은 git `core.autocrlf=true` 에 맡긴다.
- 공용 파일에서 줄 맨 앞에 `# `·`## ` 로 시작하는 줄은 절 제목뿐이다. 예시 코드 블록(펜스와 그 안)은 4칸 들여쓴다 — `sections()` 가 줄 맨 앞 `## ` 를 절 경계로 읽는다.
- 격리 검증은 **커밋된 HEAD** 로만 돈다(`git archive HEAD`). 커밋 전에 돌리지 않는다.
- 테스트 합격 기준: 전체 스위트에서 **알려진 11건 밖의 실패 0**. 알려진 11건 = `test_lab_config` 5 · `test_lab_html2pdf` 2 · `test_merge_report` 2 · `test_lab_figure_export` 1 · `test_trace_guide::Pdf::test_실험04_는_층마다_한_쪽` 1. `test_lab_isolate` 실패는 그 파일만 단독으로 한 번 더 돌려 판정한다.

```python
def rule_blocks(section_body):
    """번호 항목마다 본문을 돌려준다(`5b.` 는 5 에 붙는다). 다음 번호 줄 앞까지다."""
    out, cur = {}, None
    for line in section_body.splitlines():
        m = re.match(r"^(\d+)[a-z]?\. ", line)
        if m:
            cur = int(m.group(1))
            out.setdefault(cur, [])
        if cur is not None:
            out[cur].append(line)
    return {n: "\n".join(v) for n, v in out.items()}


def shared_pointer_targets(text):
    """`SHARED_POINTER` 바로 뒤의 글 40자씩을 돌려준다.

    절 이름에 공백이 있어(`여백 블록`) 정규식으로 이름을 자르지 않는다 — 받은 쪽이
    알려진 이름으로 시작하는지 본다.
    """
    flat = _flat(text)
    out, i = [], flat.find(SHARED_POINTER)
    while i != -1:
        j = i + len(SHARED_POINTER)
        out.append(flat[j:j + 40])
        i = flat.find(SHARED_POINTER, j)
    return out
```

# 실험01 OR·NOR 결선도 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 실험01 의 다섯 회로 중 결선도가 없던 C2(3입력 OR)·C4(3입력 NOR)를 렌더러 빌더로 채우고, 체크리스트 인쇄본의 빈 브레드보드 2장을 실제 결선도로 바꾼다.

**Architecture:** `breadboard-diagram` 스킬의 정본을 `.claude/skills/` 로 일원화한 뒤, 기존 `build_e1_and`·`build_e1_nand` 와 같은 헬퍼 위에 `build_e1_or`(74HC32)·`build_e1_nor`(74HC32+74HC02)를 추가한다. 렌더러 계약은 소스를 `ast` 로 읽는 테스트로 고정한다 — 이 스크립트는 패키지가 아니고 임포트하면 PIL 을 끌어오기 때문이다. 마지막에 netlist 에 `diagram:` 줄을 채우고 체크리스트를 다시 렌더한다.

**Tech Stack:** Python 3 + Pillow(PIL), 표준 라이브러리 `unittest`·`ast`, Chrome 헤드리스(HTML→PDF), 저장소 자체 모듈 `scripts/lab/{spec_parser,netlist_parser,render,html2pdf,config,validate}`

**왜 필요한가:** 브리지 누락은 그림을 열어봐야 보인다. 미사용 입력이 아무 데도 안 닿는 죽은 레일에서 끝나는데, 배선표는 멀쩡해 보인다. `validate.py` 는 결선도 **파일 존재**만 검사하므로 이 결함을 다섯 커밋 동안 통과시켰다. 다음 빌더에서 같은 일이 조용히 반복되지 않게 계약으로 박는다.

- [ ] **Step 1: 실패하는 테스트를 쓴다**

`tests/test_breadboard_diagram_cli.py` 의 `_choices()` 정의 **아래**, `class BreadboardDispatch` **위**에 헬퍼를 넣는다:

```python
# 레일에 홀이 없는 행. `Breadboard.jpg` 의 레일 홀 컬럼을 픽셀로 훑어 얻었다 —
# 이 행을 `bridge_row` 로 쓰면 점퍼를 꽂을 구멍이 없다.
NO_HOLE_ROWS = {2, 3, 4, 9, 15, 21, 32}


def _builder_names():
    """파일 안 `build_*` 함수 이름."""
    return [n.name for n in _tree().body
            if isinstance(n, ast.FunctionDef) and n.name.startswith("build_")]


def _calls_in(fn_name, method):
    """`build_*` 함수 안의 `bb.<method>(...)` 호출 노드."""
    for node in _tree().body:
        if isinstance(node, ast.FunctionDef) and node.name == fn_name:
            return [c for c in ast.walk(node)
                    if isinstance(c, ast.Call)
                    and isinstance(c.func, ast.Attribute)
                    and c.func.attr == method]
    raise AssertionError(f"{fn_name} 를 못 찾았다")


def _bridge_rows(fn_name):
    """그 빌더가 브리지를 그리는 행 번호."""
    rows = []
    for call in _calls_in(fn_name, "connect_unused_inputs"):
        for kw in call.keywords:
            if kw.arg == "bridge_row":
                rows.append(ast.literal_eval(kw.value))
    for call in _calls_in(fn_name, "bridge_rails"):
        if len(call.args) >= 3:
            rows.append(ast.literal_eval(call.args[2]))
    return rows
```

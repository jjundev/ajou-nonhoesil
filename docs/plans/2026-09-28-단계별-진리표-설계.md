# 단계별 진리표 설계

2026-09-28. 사용자 요청: "중간단계 결선도마다 중간 진리표를 첨부해서 순서대로 확인하고
넘어가게. 현재는 진리표가 마지막에 하나만 나와서 중간단계 결선 후 뒤로 넘어가서 진리표를
확인하고 다시 돌아와야 함."

## Intent

체크리스트 회로 페이지에서 관측 노드가 있는 **단계 블록마다**, 그 단계에서 돌려 볼 입력
조합과 노드 기대값을 담은 작은 진리표(**단계 진리표**)를 단계 그림 바로 아래에 싣는다.
독자는 실험실에서 인쇄본을 보는 학생이다. 완료되면 단계를 밟는 동안 뒤쪽 기록표로 넘길
일이 없고, 마지막 단계 바로 아래에 기록표(T3 등)가 온다.

Classification: **bounded** — 기존 `render._stage_html`·`nodes.compute` 흐름의 변경이다.
새 저작 데이터는 없다(`## 단계`·`## 노드` 표와 명세 기록표만 쓴다).

같은 날 나온 다른 요청(인쇄본의 저작용 근거 문장 정리)은 이 설계 밖이다.

## Behavior when done

- 관측 노드가 있는 단계에 `A | B | A⊕B예상 (U1 pin 3) | ☐` 표가 붙는다. 입력 열은
  **그 노드 식에 나오는 입력만**, 기록표 헤더 순서다 (실험03 1단계 A·B, 실험04 1단계 E).
- 행은 **기록표 행을 그 입력으로 줄여 겹치는 것을 합친 것**이다 (처음 나온 순서 유지).
  2^k 전개가 아니다 — 실험04 MUX 는 입력이 7개다.
- 줄인 입력에 don't-care(X)가 남아도 노드 값이 정해지면 X 째 싣는다(MUX NAND0 의
  `E=1 · X · X · X` 행은 `E'=0` 이라 출력이 1 로 정해진다). 안 정해지면(예: `S0'` 에 대한 `S0=X`) 그 행을 뺀다. 0/1(H/L)도
  X 도 아닌 셀이 있는 행도 뺀다.
- 행마다 ☐ 칸이 있다. 클래스는 `td.box` 다 — `.check` 는 기록표 행 수 불변식 전용이다.
- **마지막 관측 단계에는 단계 진리표가 없다** — 바로 뒤에 기록표가 오고 그것이 그 단계의 표다.
- 걷기 단계, 노드를 안 가리키는 옛 단계 표(실험01·02), 단계 없는 회로는 단계 진리표가 없다.
- 계산 실패(노드 이름 없음·식 오류·기록표 없음)는 그 단계에 안내 한 줄
  (`단계 진리표를 계산할 수 없다: …`)만 내고 렌더는 죽지 않는다.
- 회로 페이지 순서: 배너 → 강의노트 회로도 → 앞 산문 → **완성본·칩별 배선 → 핀 점검 → 뒤 산문
  → 단계 1…n → 기록표**. 단계 없는 회로는 단계 자리만 빈다.
- 회로 끝의 "중간 노드 기대값" 표를 없앤다. `nodes.compute` 는 `validate` 가 계속 쓴다.

실측 기대값(현재 승인본 기준): 실험03 단계 진리표 5개(C2 4 · C4 1), 실험04 10개
(C1 7 · C2 3). 실험04 C1 4~7단계는 9행, C2 1~3단계는 5행(`D=0 · X · X` 행 포함).

## Not in this round

- 인쇄본 근거 문장 걸러내기 — 규칙 정의가 필요한 별개 작업.
- LED 기준 열(그 단계에 켜진 다른 LED 값) — 단계별 LED 배정이 데이터로 없다.
- 실험03 인쇄본 재생성 — 지난 주차이고 커밋된 PDF 를 바꾼다.
- 그림·표 좌우 배치 — 결선도 폭이 줄면 홀 번호를 못 읽는다.

## Decisions

### Confident
| # | 결정 | 답 | 근거 |
|---|---|---|---|
| 1 | 행 출처 | 기록표 행을 노드 입력으로 투영·중복 제거 | 2^k 는 MUX Y 가 128행. 기록표가 저작자가 고른 시험 행이다(실험04 명세 T1 9행) |
| 2 | 입력 열 | 노드 식 변수만, 기록표 헤더 순서 | 1단계에 Ci 는 아직 꽂지 않았다. `boolexpr._TOKEN` 으로 뽑는다 |
| 3 | X 행 | X 에 0·1 다 넣어 값이 하나면 X 째, 아니면 제외 | `nodes.compute` 는 X 행을 `None` 으로 버려 MUX `E=1` 행을 잃는다 |
| 4 | 확인 칸 | `td.box` (template.html 의 "그 외 체크박스는 `.box`" 규약) | `.check` 개수 = 기록표 행 수 (`test_lab_render.py:89`) |
| 5 | 기록.md | 옮기지 않는다 | `record.derive_record` 는 명세에서만 나온다 |
| 6 | 마지막 단계 | 표 없음, 기록표가 바로 뒤 | 마지막 노드 전 행 확인 = 기록표 |
| 7 | LED 열 | 이번엔 안 한다 | `netlist_parser.STAGE_COLUMNS` 4열에 LED 배정이 없다 |
| 8 | 적용 주차 | 실험04 부터 | 실험03 은 지났다 |
| 9 | 이름 | "단계 진리표", CSS `stage-table` | kind 표의 "미니표"(불일치 기록)와 이름이 겹치지 않게 |

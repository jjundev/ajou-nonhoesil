# 입력 점퍼선 보라 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 결선도의 입력 점퍼선(레일 → 칩 입력 행)을 검정 대신 입력 배지와 같은 보라 `INPUT` 으로 그린다.

**Architecture:** 배선 종류(`kind`)는 `'sig'` 그대로 둔다. 검사·라우터·걷기 판정이 `'sig'` 를 키로 쓰기 때문이다. `step_wire` 에 `color=` 덮어쓰기 인자를 하나 추가하고, `_input_jumper` 만 그 인자에 `INPUT` 을 넘긴다. 회색(`KEEP`, faded)은 지금처럼 우선한다.

**Tech Stack:** Python 3, Pillow, `unittest`(pytest 로 실행).

**Spec:** 이 대화의 grill-yourself 설계 「입력 점퍼선을 보라로」(2026-10-06). 결정 #1~#4 는 Confident로 확정했고, #5(실험05부터만 적용)와 #6(보라 펜을 다섯 번째로)은 [confirmed by default]다.

## Global Constraints

- 보라 값은 기존 `INPUT = (110, 40, 160, 255)`(`base.py:221`)이다. 새 색 상수는 만들지 않는다.
- `WIRE` dict 와 `KIND_KR` 에 키를 추가하지 않는다. 입력선의 kind 는 `'sig'` 다.
- 앞 단계 회색 `KEEP` 과 faded 층은 보라보다 우선한다.
- 다시 굽는 것은 실험05 결선도뿐이다. 실험01~04 의 PNG·JSON 은 건드리지 않는다(#5).
- 손그림 펜은 다섯 자루(빨강·파랑·검정·초록·보라)다(#6).

## Review Focus

1. 기준선(baseline) 보드에 이미 있는 입력 점퍼는 보라가 아니라 회색이어야 한다. Task 1 의 `test_기준선의_입력_점퍼는_회색이다` 가 맡는다.
2. 따라 그리기 층에서 faded 인 입력 점퍼도 회색이어야 한다. 1과 같은 분기(`kept or view == 'faded'`)를 타므로 1의 시험이 그 분기를 고정한다.
3. 입력 점퍼의 번호 원 테두리도 보라여야 한다. 번호 원은 `color` 변수를 쓰므로(`renderer.py:625`) 선 색 시험이 함께 지킨다. 실험05 PNG 를 눈으로 보고 확인한다(Task 3).
4. 입력이 아닌 `'sig'` 선(출력·LED 로 가는 선)은 검정으로 남아야 한다. Task 1 의 `test_다른_신호선은_검정_그대로다` 가 맡는다.
5. `color` 를 넘겨도 결선 순서표·`wiring()` JSON 의 `kind` 는 `'sig'` 로 남아야 한다. Task 1 의 `test_입력_점퍼의_kind_는_sig_다` 가 맡는다.

```python
"""입력 점퍼선은 입력 배지와 같은 보라(`INPUT`)로 그린다. kind 는 'sig' 그대로다(2026-10-06)."""
import importlib.util
import os
import unittest

REPO_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
SCRIPT = os.path.join(REPO_ROOT, '.claude', 'skills', 'breadboard-diagram',
                      'scripts', 'render_breadboard.py')

INPUT = (110, 40, 160, 255)
BLACK = (25, 25, 25, 255)


def _load():
    spec = importlib.util.spec_from_file_location('render_breadboard', SCRIPT)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def _pixel_on(bb, seg_index, t=0.75):
    """구간 `seg_index` 의 첫 두 점 사이 t 지점의 overlay 픽셀. 좌표는 템플릿 기준이라 배율을 곱한다."""
    _kind, pts, _d = bb._segments[seg_index]
    (x0, y0), (x1, y1) = pts[0], pts[1]
    k = bb.overlay.size[0] / bb.base_im.size[0]
    x, y = x0 + (x1 - x0) * t, y0 + (y1 - y0) * t
    return bb.overlay.getpixel((round(x * k), round(y * k)))


class InputWireColor(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.mod = _load()

    def board(self, **kw):
        bb = self.mod.BreadboardRenderer(board='v1', **kw)
        bb.enable_steps()
        return bb

    def test_입력_점퍼는_보라다(self):
        bb = self.board()
        bb.draw_chip('74HC08', 10)
        self.mod._input_jumper(bb, bb.cols['left'], 10, 'A', '74HC08 pin 1')
        i = next(i for i, s in enumerate(bb._segments) if '입력 A' in s[2])
        self.assertEqual(_pixel_on(bb, i), INPUT)

    def test_다른_신호선은_검정_그대로다(self):
        bb = self.board()
        c = bb.cols['left']
        bb.step_wire([(c['a'], bb.r_y(20)), (c['a'], bb.r_y(25))], 'sig', '출력 시험')
        self.assertEqual(_pixel_on(bb, len(bb._segments) - 1), BLACK)

    def test_입력_점퍼의_kind_는_sig_다(self):
        bb = self.board()
        bb.draw_chip('74HC08', 10)
        self.mod._input_jumper(bb, bb.cols['left'], 10, 'A', '74HC08 pin 1')
        seg = next(s for s in bb._segments if '입력 A' in s[2])
        self.assertEqual(seg[0], 'sig')
        step = next(s for s in bb.steps if '입력 A' in s['desc'])
        self.assertEqual(step['kind'], 'sig')

    def test_기준선의_입력_점퍼는_회색이다(self):
        first = self.board()
        first.draw_chip('74HC08', 10)
        self.mod._input_jumper(first, first.cols['left'], 10, 'A', '74HC08 pin 1')
        base = first.snapshot()
        bb = self.board(baseline=base)
        bb.draw_chip('74HC08', 10)
        self.mod._input_jumper(bb, bb.cols['left'], 10, 'A', '74HC08 pin 1')
        i = next(i for i, s in enumerate(bb._segments) if '입력 A' in s[2])
        self.assertEqual(_pixel_on(bb, i), self.mod.KEEP)


if __name__ == '__main__':
    unittest.main()
```

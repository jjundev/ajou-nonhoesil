# 결선도 엔진에 DIP-16 칩과 Negative Logic LED 넣기 — 설계 (실험05 1-2 대비)

작성 2026-10-05 (`/grill-yourself`). 기준 커밋 main `1c025ca`(설계는 `da08208` 에서 했고, 그 뒤 main 에 든 `PlaceLayoutTable` 은 이 설계와 겹치지 않는다). 구현계획:
`docs/plans/2026-10-05-실험05-DIP16-negative-LED-구현계획.md`.

## 의도

실험05 1-2(BCD → 10진 디코더, 74HC42)를 v2 판형으로 그릴 수 있게 엔진을 넓힌다. 능력 둘:
**DIP-16 칩**(그리기·배선기·배치기), **출력 0 에서 켜지는 LED 사슬**(신호 → 330Ω → LED → +5V).

끝났다는 것: 74HC42 하나 + Negative LED 10벌 시험판(`tests/fixtures/board_v2_e5/배치.py`)이
`place_search` → `route_plan` → `verify()` 를 통과하고, 진리표 시뮬레이터로 BCD 0~15 가 교안 함수와
맞으며, v1 승인본 도장과 e4 시험판 λ=0 스냅숏이 바이트 단위로 그대로다.

범위: 이번 학기 실험05 는 `scripts/lab/config.py` `EXPERIMENT_SCOPE[5] = ("1-2", "2-2")` — **2-1
(74HC148)·1-1(74HC08) 은 하지 않는다.** 실험일은 2026-10-09.

분류: bounded — 그리기·배선기·배치기·시뮬레이터의 기존 흐름에서 7행·pin 14/7·GND 사슬 가정을 넓힌다.

## 다 되면

- `bb.draw_chip('74HC42', k)` 가 8행 몸통·핀 번호 1~8 / 16~9 를 그린다. `connect_power(k)` 가
  pin 16 → +5V, pin 8(k+7) → GND.
- `bb.led_chain(R['a'], top, 'Y0', desc, block='right', active_low=True)` 가 신호 우 a top → 330Ω
  b top~top+2 → LED c(캐소드 top+2, 애노드 top+3) → a top+3 에서 가운데 VCC 점퍼를 그린다. 순서표에
  "0 이면 켜짐".
- 배치기가 `models` 에 74HC42 가 있어도 받는다. 슬롯 높이는 그 슬롯에 앉는 가장 큰 칩. 모르는 칩은
  `ValueError`(지금처럼). 그리기는 모르는 이름을 14핀으로 본다(v1 호환).
- `tests/_gate_sim.py` 가 74HC42 를 돌리고 `led_on(...)` 이 극성대로 켜짐을 판정한다.

## a쪽 출력 배선 순서 (#5·#10 의 귀결)

DIP-16 이름 상자가 반 행 k+3.5 만 막으면 a쪽 7가닥이 건널 반 행은 꼭 7개(k−0.5…k+2.5, k+4.5…
k+6.5)다 — 핀마다 하나로 정해진다(pin p ≤ 4 는 위 반 행, p ≥ 5 는 아래 반 행). 탐욕 배선은 막힌 선
앞 한 가닥만 바꿔 보므로(`_REPAIR_BACK`) 위에서부터 깔면 pin 4 가 막힌다. 그래서 배선표에 **이름
상자에 가까운 핀부터**(pin 4, 3, 2, 1, 5, 6, 7) 적는다. f쪽 Y7~Y9 는 끝 행(d1 = 0, j 열에서 정행
가로)으로 빠져 a쪽 반 행과 안 겹친다.

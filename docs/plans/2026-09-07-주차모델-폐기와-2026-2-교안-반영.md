# 주차 모델 폐기와 2026-2 교안 반영 구현계획

> **For agentic workers:** REQUIRED SUB-SKILL: `subagent-driven-development`(권장) 또는 `executing-plans` 로 과제 단위로 실행한다. 단계는 체크박스(`- [ ]`)로 추적한다.

**Goal:** 주차(week)를 열쇠로 쓰던 모델을 폐기하고 실험 번호를 열쇠로 삼아, 2026-2 운영계획의 실제 일정·교안을 하네스 전체에 반영한다.

**Architecture:** `config.py` 의 `WEEK_TO_EXPERIMENT` 를 `EXPERIMENT_DATES`(실험 번호 → 날짜)로 뒤집는다. 주차가 열쇠였을 때 표현할 수 없던 두 가지 — 한 날에 실험이 둘(9/18), 실험이 없는 주(추석·중간고사) — 가 구조적으로 사라진다. 스키마는 v2 로 올려 `week:` 필드를 걷어낸다. 그 위에서 교안 탐색을 재귀로 고치고, `review-lab-report` 에 판본 확인을 넣은 뒤, 실험01 산출물의 메타를 신판 기준으로 갱신한다.

**Tech Stack:** Python 3 (표준 라이브러리 + `pypdf`), pytest, Chrome 헤드리스(PDF), 저장소 내부 모듈 `scripts/lab/*`.

## Global Constraints

- **응답·주석·문서는 한국어.** 코드 식별자와 경로만 원문.
- **테스트 러너는 `.venv/bin/python -m pytest`.** 시스템 `python3` 에 pytest 가 없다. `tests/` 전체 discover 는 파일을 실제로 옮기는 모듈이 섞여 있어 피하고, 파일을 지정해 돌린다.
- **푸시하지 않는다.** `main` 이 `origin/main` 보다 75커밋 앞서 있고 사용자가 명시적으로 정했다.
- **경로를 손으로 짓지 않는다.** `config.experiment_dir()` · `config.manual_candidates()` · `config.experiment_folder_name()` 이 유일한 입구다.
- **주차표를 스킬 문서에 베끼지 않는다.** 이 계획은 그 사본 11곳을 지우는 일이다. 새 일정표도 같은 이유로 `config.py` 한 곳에만 둔다.
- **A4 실측 기대값은 `209.9 297.0`.** Chrome 헤드리스 고정 출력이다. `210.0` 을 맞추려고 CSS 를 건드리지 않는다.
- **Chrome 은 정상 동작 중에도 stderr 에 `task_policy_set ... invalid argument` 를 뱉는다.** 종료 코드가 아니라 PDF 파일 생성 여부로 판정한다.
- **인쇄본을 낸 뒤 반드시 `validate.check_rendered_html` 을 돌린다.** 이 검사를 빠뜨려 마크다운이 든 인쇄본이 커밋된 적이 있다.
- **명세·결선도의 본문(배선·진리표)을 고치지 않는다.** 두 세션이 독립적으로 대조해 신판과 전부 일치함을 확인했다. 고칠 것은 메타뿐이다.

## 스키마 결정 — `week:` 를 없애고 `date:` 를 넣지 않는다

```python
def _distributed_manual(experiment: int, root: Path) -> Optional[Path]:
    """배포 폴더에서 그 주차 교안을 찾는다. 없으면 `None`.

    **하위 폴더까지 훑는다.** 조교가 배포 폴더 안을 재편하면(2026-09-07 에
    실제로 파일 다섯이 `공지사항/` 으로 내려갔다) 비재귀 탐색은 조용히 실패해
    아카이브의 과거 학기 판으로 떨어진다. 아카이브에 늘 같은 번호 파일이
    있으므로 "교안을 못 찾았다"로 드러나지도 않는다.

    번호 뒤가 **숫자가 아니어야** 한다. `실험1` 로 앞자리만 맞추면
    `실험10`·`실험11`·`실험12` 를 집어삼킨다 — 이 과목은 실험이 10 개라
    한 자리와 두 자리가 실제로 섞인다.

    같은 번호가 여럿이면 경로순 첫 개를 쓴다. 얕은 것이 먼저 오도록
    (깊이, 경로) 로 정렬한다 — 최상위 배포본이 하위 사본을 이긴다.
    """
    folder = root / MANUAL_DISTRIBUTION
    if not folder.is_dir():
        return None
    pattern = re.compile(rf"^실험{experiment}(?!\d)")
    hits = sorted(
        (f for f in folder.rglob("*")
         if f.is_file() and f.suffix.lower() == ".pdf"
         and pattern.match(f.name)),
        key=lambda f: (len(f.relative_to(folder).parts), str(f)),
    )
    if not hits:
        return None
    return Path(MANUAL_DISTRIBUTION) / hits[0].relative_to(folder)
```

# v2 배선기 — 길이와 밀도를 함께 줄이기 (설계)

2026-10-04 · 근거: `docs/plans/2026-10-03-실험04-v2-시험판-결과.md` 제안 3(배선기 엔진 이전) · 시험판
`tests/fixtures/board_v2_e4/배치.py`. 결정은 사용자 확인(2026-10-04, 아래 #9~#12 전부 추천안).

## 의도

v2 결선도의 신호선 경로를 고르는 배선기에 **선 길이**와 **선 밀도** 두 기준을 함께 넣는다. 상충은
가중치 하나(λ)로 다루고, λ 는 실험04 v2 시험판으로 정한다. 다 되면 시험판에만 있던 배선기가 엔진
(`render_breadboard.py`)에 들어가고, 같은 회로를 지금보다 덜 빽빽하게 그리되 길이는 정한 한도 안에서만
는다. R1~R14 는 그대로 통과한다.

**방법은 선형회귀가 아니다.** 회귀는 데이터로 값을 *예측*하는 도구다. 이건 후보 경로 중 하나를
*고르는* 최적화 문제다. 두 목표의 상충은 가중합 `비용 = 길이 + λ·밀도` 로 다루고, λ 를 바꿔 가며
그려 파레토 전선(길이를 얼마 늘리면 밀도가 얼마 주는가)을 얻는다. 회귀가 맞는 자리는 사람의 쌍 비교
판단을 모아 λ 를 거꾸로 맞추는 선호 학습뿐이다 — 표본이 없어 이번 범위 밖이다.

지금 측정(2026-10-04, 1칸×1칸 셀을 신호선 3가닥 이상 지나는 셀 수): MUX v1 0 → v2 12, DMUX 9 → 11.
총길이는 MUX 528 → 348칸, DMUX 493 → 303칸. 지금 비용(`배치.py` `_coster`)은
`길이 + 40·꺾임 + 400·몸통횡단` 이고 밀도 항이 없다.

## 다 되면

- 엔진 `route_plan(build_fixed, chips, wires, board='v2', density_weight=None)` 이 v2 신호선 경로와
  번호 원 자리를 정한다. v1 판형이면 `ValueError`. 시험판 `배치.py` 는 자체 배선기 사본을 지우고 이것을 쓴다.
- 엔진 `wire_metrics(bb)` → `{'length': 칸, 'bends': 정수, 'density': 칸}`.
- `python -m scripts.lab.route_sweep` 이 λ 별 지표 표와 MUX·DMUX PNG 를 `tmp/route_sweep/` 에 낸다.
- 고른 λ 는 엔진 상수 `DENSITY_WEIGHT` 다. 경로 없음은 지금처럼 `AssertionError: 경로 없음`.
- v1 승인본(실험01~04)은 한 픽셀도 안 바뀐다.

## 구현 사양

- **밀도(#10).** 두 신호선(`sig`·`mid`)의 같은 축 구간이 수직 간격 g (0.5px < g < 1칸) 로 나란할 때
  `겹친 길이 × (1 − g/칸)` 을 더한다. 같은 선 안의 구간끼리는 안 센다. 간격 0 은 R4(포개짐) 몫이다.
- **비용.** `정적비용 + λ·밀도증분`. 정적비용은 지금 그대로(`길이 + 40·꺾임 + 400·몸통횡단`, px).
  밀도증분은 새 경로와 이미 깔린 신호선 구간 사이의 밀도(px).
- **순서.** `_ordered` 의 정적 정렬과 캐시는 그대로 두고, 앞 400개만 `정적 + λ·밀도` 로 다시 매긴 뒤
  그 순서로 합법성을 본다. 나머지는 정적 순서로 이어 본다. 수리(`_plan`)는 그대로.
- **λ 고르기(#11).** λ ∈ {0, 0.5, 1, 2, 4, 8}. MUX·DMUX 둘 다 길이 ≤ λ=0 길이 × 1.15 인 λ 중 두 회로
  밀도 합이 가장 작은 것. 어느 λ 도 밀도를 못 줄이면 0 으로 두고 B 를 다음 라운드로 올린다.
- **범위.** v2 만(`spec.readability`). 표준 라이브러리만. 기준 데이터는 실험04 v2 시험판.

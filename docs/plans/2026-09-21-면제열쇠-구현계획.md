# 면제 열쇠와 걷기 주소 계약 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 실험 3부터 단계 회로의 노드 표를 필수화하고, 걷기 단계·주소를 파서 데이터로 만들어 netlist 문구와 실제 브레드보드 제거선이 자동으로 함께 검증되게 한다.

**Architecture:** 단계 셀과 홀 주소의 문자열 판정은 `netlist_parser` 한 곳에 둔다. `validate`는 파서가 낸 `stage_no`·`walk_of`·`walk_addresses`·`check_holes`만 읽어 실험 번호별 검사 강도와 의미 계약을 집행하고, 브레드보드 회귀는 diagram 파일명으로 netlist 주소와 `removals()`를 연결한다. `STAGE_COLUMNS`와 브레드보드 엔진 실행 경로는 바꾸지 않는다.

**Tech Stack:** Python 표준 라이브러리(`re`, `pathlib`, `dataclasses`) + Pillow 브레드보드 렌더러. 테스트는 `unittest` 스타일을 `.venv/bin/python -m pytest`로 실행한다. 체크리스트 PDF는 헤드리스 Chrome과 `pypdf`를 쓴다.

**Spec:** `docs/plans/2026-09-21-면제열쇠-설계.md`

```python
    for row in rows:

        number = _STAGE_NUMBER.match(row["n"])
        walk = _STAGE_WALK.match(row["n"])
        row["stage_no"] = int(number.group(0)) if number and not walk else None
```

```python
_HOLE_PATTERN = r"(?:좌|우)\s*[a-j]\s*[1-9][0-9]*"
_HOLE = re.compile(_HOLE_PATTERN)
_WALK_ADDRESS = re.compile(rf"({_HOLE_PATTERN})\s*→\s*({_HOLE_PATTERN})")


def _normalise_hole(token: str) -> str:
    match = re.fullmatch(r"(좌|우)\s*([a-j])\s*([1-9][0-9]*)", token)
    assert match is not None
    return f"{match.group(1)} {match.group(2)}{match.group(3)}"


def _walk_addresses(text: str) -> list[str]:
    return [f"{_normalise_hole(start)} → {_normalise_hole(end)}"
            for start, end in _WALK_ADDRESS.findall(text)]


def _holes(text: str) -> list[str]:
    return [_normalise_hole(match.group(0)) for match in _HOLE.finditer(text)]
```

**Goal:** 손그림 전사 파서가 16핀 칩(74HC42·74HC138·74HC148)의 핀 자리를 실제대로 잡아, `review-hand-diagram` 을 문서 절차 그대로 돌려도 가짜 H3·H6 가 나지 않게 한다. 덤으로 격자 그림 행 번호를 63행까지 찍고 `crop_rows` 가 소수 배율을 받게 한다.

## Global Constraints

- 핀 수는 `load_renderer().dip_pins(label)` 에서만 얻는다. 숫자 16 을 파서에 박지 않는다.
- 모르는 칩 이름은 14핀(`dip_pins` 의 strict 끔 기본값) — 렌더러 그리기와 같다.
- 전사 JSON 형식은 바꾸지 않는다(`pins` 필드 추가 없음). 기존 전사가 그대로 읽혀야 한다.

- 커밋 메시지는 한국어 conventional(`fix(hand-compare): ...`) + 끝줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- 작업 브랜치 `fix/hand-dip16`, 끝나면 main 에 `--no-ff` 병합.

```python
def chip_pins(block, pin1_row, pin1_col='e', n=14):
    """DIP-n 이 꽂히는 홀. pin 1~n/2 는 pin 1 열, n/2+1~n 은 건너편 열을 거꾸로 올라온다.

    `pin1_col='e'` 가 렌더러 `draw_chip()` 이 꽂는 자리와 같아야 한다 —
    `test_핀_배치가_렌더러와_같다`(14핀)·`test_16핀_핀_배치가_참조_빌더와_같다` 가 그것을
    묶어 둔다. `'f'` 는 노치가 아래를 보게 그린 칩이다. 채널을 걸치지 않는 열은 핀 모델이
    없어 거절한다. `n` 은 핀 수 — 호출자가 칩 모델 표(`dip_pins`)에서 얻어 넘긴다.
    """
    across = {'e': 'f', 'f': 'e'}
    if pin1_col not in across:
        raise ValueError(
            f"pin 1 열은 e 또는 f 다 — DIP 칩은 채널을 걸친다: {pin1_col!r}")
    pins = {}
    for i in range(n // 2):
        pins[i + 1] = (block, pin1_col, pin1_row + i)
        pins[n - i] = (block, across[pin1_col], pin1_row + i)
    return pins
```

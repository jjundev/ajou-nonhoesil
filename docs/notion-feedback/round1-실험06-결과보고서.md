## 적용 경계

- 사용자 확인이나 기록으로 확보한 결과는 서술한다. 사진에 전 과정이 없다는 이유만으로 증명 한계를 반복하지 않는다.
- 캡션에는 보이는 상태·전후 변화와 필요한 촬영 맥락을 쓴다. 최종 상태 사진을 연속 토글 장면이라고 부르지 않는다.
- 실제 미확인 행은 `(미확인)`으로 남긴다. 미진행·불일치·원인 추정도 기존 규칙대로 구분한다. 사진만 있고 사용자 확인도 없으면 사진 밖 에지·토글을 확인했다고 쓰지 않는다.
- X 행의 결과를 모든 입력 조합과 양쪽 초기 상태를 시험했다는 주장으로 확대하지 않는다.
- 원본 보고서·노션 페이지·기록·사진은 이번 스킬 반영에서 수정하지 않았다. 노션 수정본과 업로드 직후 baseline도 각각 유지한다.
- `.agents/skills/write-result-report`는 `.claude/skills/write-result-report`의 심볼릭 링크라 같은 수정이 적용된다.

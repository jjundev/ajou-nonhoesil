## 배치 문제를 푼 방식

교안에서 BIT1·2는 한 패키지의 첫째·둘째 F/F다. 그대로면 패키지 경계 Q11(f쪽)→다음 J4(a쪽)가 R8에 걸린다. 각 패키지 안의 역할을 교환해 BIT1·3·5를 둘째 F/F(J9 K12 Q11 Q'10), BIT2·4·6을 첫째 F/F(J4 K16 Q15 Q'14)에 배정했다. 따라서 패키지 경계는 Q15→J9, Q'14→K12로 같은 f쪽이다. 두 F/F 사이의 쪽 바뀜은 같은 칩 안에서만 일어난다.

이 재배정은 교안 원문이 아니다. 논리 넷은 유지하며 PR1은 U2 pin7, PR2는 U2 pin2로 바뀐다. NAND는 f쪽 12·13→11을 쓴다. 물리 LED 위→아래 순서는 BIT2·BIT1·BIT4·BIT3·BIT6·BIT5다. 기록표 BIT1~BIT6 순서는 바꾸지 않았다.

R7 기본 한도 8은 그대로 만족할 수 없다. 모든 16핀을 쓰는 패키지는 각 핀 연결 16끝에 LED 급전 2끝만 더해도 합 18끝 이상으로, 양쪽 8의 합 16을 넘는다. CLK·CLR 분배를 포함한 중간 HC76은 a쪽 12(CLK4+CLR4+PR2+VCC1+J1), f쪽 10이다. 기존 이유 필수 주차 예외로 `SIDE_LEAD_MAX=12`를 선언했다. R7 자체를 끄거나 엔진 기본 한도를 바꾸지 않았으며 R1~R6·R8~R14는 그대로다.

배치 탐색 결과: U1 pin1행 7, U2 17, U3 28, U4 39. 가운데 GND/VCC 브리지 51/52행. LED 윗행: BIT2=18, BIT1=22, BIT4=28, BIT3=33, BIT6=40, BIT5=44. 최종 탐색 superset 길이 296.1칸·밀도 17.2칸, 기준 후보가 선택됐다. `배치탐색.md`의 기계 생성 결과를 사용했다.

## 부분 배선과 안전한 관측 준비

처음 작성한 단계는 뒤 단계 입력을 비워 두는 결함이 있었다. fresh 문서 리뷰가 이를 찾아 사용 입력을 임시 고정하는 방식으로 고쳤다.

- 미배선 J/K·CLK·CLR은 임시 GND, U2 PR은 임시 +5V. U3·U4 PR은 완성본에서도 +5V다. 미사용 입력으로 등록해 검사를 피하지 않았다.
- 해당 입력을 연결하기 직전 전원을 끄고 임시선을 걷는다. 걷기 행의 주소는 생성된 사이드카에서 가져왔고 파서의 주소쌍·확인 홀 검사를 통과했다.
- 매 통전 전 D/CLK/CLR=0, PR1=PR2=1로 초기화한다. 전원을 끈 보드에는 발생기로 역급전하지 않도록 출력도 정지·분리한다.
- 모든 통전 단계의 사용 FF 입력이 전원 레일·외부 입력·실제 출력 중 하나로 구동되는지 실제 넷으로 검사했다. 걷기 상태는 전원을 끄므로 그 검사에서 구분한다.
- 신호선은 1단계 2가닥, 6단계 2가닥, 나머지 각 3가닥이다. 걷기 그림은 새 신호선 0가닥이며 다음 단계 그림은 걷는 선 0가닥이다. 임시 0/1 고정선은 GND/VCC 기반 배선으로 분류한다.

## 내용 검토와 남은 미확정

기존 교안 p8 회로도는 이번에도 직접 열어 핀 연결을 대조했고 p9~11 텍스트를 다시 확인했다. 새 원문 표를 전사하지 않았고 T1~T3의 원래 저작 셀을 보존했다. 회로도 신호핀은 텍스트 층에 없으므로 기존 vision 판독 근거를 유지했다. 칩 내부 역할 교환을 원문 전사로 가장하지 않았다.

저작 기대값은 공통 CLR 초기화, 에지 직전 Q를 다음 J/K가 받는 원리, PR 강제 SET으로 손검토했다. 초기 1은 하강 에지마다 100000→010000→001000→000100→000010→000001로 이동한다. 상승 에지·준비 행은 유지한다. 실패 원인을 단정하는 새 진단 문장은 넣지 않았다.

교안을 보지 않는 별도 fresh 리뷰의 지적 2개를 모두 수용했다. 통전 중 입력 플로팅은 위 임시 고정·걷기로 해결했고, BIT1이 이미 1인 채 PR1을 검사하던 V7은 재초기화→CLR 해제→PR1로 0→1을 구별하게 고쳤다. 같은 두 문서를 재검토해 두 수정과 새 문서 모순 없음이 확인됐다. 이 리뷰는 원문 전사·그림·실물 동작의 독립 증명이 아니다.

대장의 상태:

- M1 해결: v3 노드/절차 지원.
- M2 미확정: 교안 본문 5s 이상과 그림 1Hz 차이. 본문 권장값 우선, 장비/담당자 확인 필요.
- M3 미확정: 발생기·스위치 제공 및 실제 출력 레벨·공통 접지·조작 수단.
- M4 미확정: LED 극성·HC 출력의 LED와 다음 J 동시 부하. 구현은 출력→LED→330Ω→GND, 출력 1에 점등이다.
- M5 미확정: 수령 IC 제조사·DIP 각인. HC76 전원5·13의 문서 근거와 구별한다.
- M6 설계 확정: 기능 보존 핀 재배정과 LED 순서.
- M7 배치 해결: 탐색·24개 그림 검증 및 R7 예외 근거. 실물 동작 측정은 하지 않았다.

구조 검증이 통과했다는 것은 파서가 읽을 수 있다는 뜻이고, 내용이 맞다는 뜻이 아니다.

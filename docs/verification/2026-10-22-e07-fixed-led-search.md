# LED 고정 배치 탐색 검증

경로 계산 256회 / 예산 256회. 지정한 탐색 범위에서 검증된 최선이며 전역 최적성은 보장하지 않는다.

최단 검증 길이 × 1.1 = 332.9526칸 이내에서 밀도 → 교차 → 단계 최대 밀도 → 꺾임 → 길이 순으로 선택.

| 후보 | 길이 | 밀도 | 교차 | 꺾임 | 단계 최대 밀도 | 전체 배선 길이 |
|---|---:|---:|---:|---:|---:|---:|
| 기존 승인본 | 305.3158 | 3.4737 | 18 | 69 | 3.4737 | 494.5752 |
| 최단 후보 | 302.6842 | 18.0263 | 20 | 68 | 18.0263 | 491.9437 |
| 선택 후보 | 305.3158 | 3.4737 | 18 | 69 | 3.4737 | 494.5752 |

고정 LED: `{"shift":{"BIT1":14,"BIT2":18,"BIT3":26,"BIT4":30,"BIT5":36,"BIT6":40}}`

지문: `501bccbea6eeabc292337ace2c84f4ba83143bbcf2bb7578c021da997a77d6d3`

실패는 해당 경로 탐색/검증의 실패이며 배치의 불가능성 증명이 아니다.
승인 배치·결선도·측정 기록은 자동으로 교체하지 않는다.

## 검증

- 최종 실행: 경로 계산 256회, 검증 통과 65회, 실패 191회. 승인본은 별도로 재검증했다.
- 선택 후보의 준비 6 + 결선 12 + 걷기 11 + 완성본 1 = 30개 보드를 PNG/JSON 쌍으로 출력했다.
- 모든 단계에서 물리 규칙, 입력 구동, 승인본과의 논리 넷 동등성을 검사했다. 마지막 단계와 완성본의 물리 배선·넷이 같다.
- 256개 시도 모두 LED 좌표 입력이 동일하다. 선택 후보의 30개 사이드카에서도 실제 LED 위치·태그가 승인본과 같다.
- 기존 그림·체크리스트·기록·팀원 자료 69개 파일은 탐색 전후 SHA-256이 같다.
- 관련 회귀 검사: `822 passed, 449 subtests passed in 92.92s (0:01:32)`. 전체 저장소 테스트 실행을 의미하지 않는다.
- 실제 2회 탐색을 1개/2개 프로세스로 각각 실행하여 결과 전체가 동일함을 확인했다.
- 독립 리뷰: 원래 입력 핀의 레일 점유로 다른 할당까지 배제하는 가지치기를 제거했다. 이 회귀 테스트가 실패한 뒤 통과했다.

## 선택 후보

```json
{
  "layout": {
    "slots": {
      "S1": 6,
      "S2": 16,
      "S3": 27,
      "S4": 38
    },
    "leds": {
      "shift": {
        "BIT1": 14,
        "BIT2": 18,
        "BIT3": 26,
        "BIT4": 30,
        "BIT5": 36,
        "BIT6": 40
      }
    },
    "bridge": [
      48,
      49
    ]
  },
  "variant": {
    "nand": 3,
    "ff": [
      false,
      false,
      false
    ]
  }
}
```

## 실패 집계

- 그림대로 꽂을 수 없다: 83회
- Temporary route not found: 58회
- 경로 없음: 37회
- 따라 그릴 수 없다: 13회

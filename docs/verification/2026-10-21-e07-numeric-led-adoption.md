# 실험07 숫자 순서 최적화 정식 반영 검증 (2026-10-21)

사용자가 승인한 전체 최적화 후보를 정식 완성본으로 채택하고 준비·걷기·단계·체크리스트·팀원 전달용 자료를 재생성했다. 커밋·푸시는 하지 않았다.

## 원본과 구현

- 칩 pin1 행 U1=6,U2=16,U3=27,U4=38, LED 윗행 BIT1~6=14,18,26,30,36,40, 브리지48/49행.
- NAND9·10→8. HC76 F/F 역할·PR1/PR2·클럭/초기화·각 BIT의 논리 연결은 유지한다.
- 승인 신호 경로를 `보고서/실험07/결선도/설계/승인경로.json`에 보존한다. 배치/배선표가 파일과 다르면 빌더가 거절한다.
- 실험07 전용 `ShiftRenderer`에서 R10 순서 역전 메시지만 예외 처리한다. 다른 블록 건너기 검사는 유지하며 공통 엔진/도구 코드는 변경하지 않았다. R7 한도12도 기존대로다.
- 임시선은 연결 직전까지 공존하는 신호선과 기존 임시선을 피해 별도 예약했다. 직접 대각선 또는 꺾인 전원/GND 경로이며 통전 단계·준비·걷기 모두 원래 엔진의 물리·읽기 검사로 검증했다. 완성본 경로는 바꾸지 않았다.
- netlist의 핀 표·참조 핀아웃의 사용 NAND 표시·LED 번호·슬롯·11개 걷기 주소를 새 사이드카와 맞췄다. 로컬 예비보고서의 결선표와 연결 설명도 새 핀/LED 순서와 맞췄다. Notion 원본/기준 스냅샷은 건드리지 않았다.

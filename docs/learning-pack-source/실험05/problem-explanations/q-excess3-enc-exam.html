이 문제를 보면 떠올려요

켜진 스위치 번호+3을 4비트로

문제에 “Excess 3코드 Encoder”와 SW 문자열이 보이면 켜진 스위치 번호에 3을 더해 4비트로 쓰는 것을 떠올려요. SW 문자열은 이진수 값이 아니라 어느 스위치가 켜졌는지를 나타내기 때문이에요.

이 문제에서 할 일

스위치 상태에서 켜진 십진수 한 자리를 찾고 +3한 4비트를 써요. 회로로도 같은 값을 확인해요.

첫 줄을 이렇게 시작해요

첫 SW 문자열 000001은 SW0만 켜짐이므로 0+3=3=0011을 써요.

필요한 개념: Excess-3 코드와 인코더를 배워요

왜 이렇게 푸는지 함께 따라가요

입력 여섯 비트는 이진수 1·4·16·32라는 숫자가 아니라 SW5…SW0의 on/off예요. 각 NAND는 반전된 스위치들을 받고 전체 출력을 다시 반전해 연결된 원래 스위치의 OR가 돼요. 남는 NAND 입력을 1에 묶으면 곱의 값이 바뀌지 않아요.

회로 읽기

Bit3 NAND에는 SW5의 반전이, Bit2에는 SW4·SW3·SW2·SW1의 반전이, Bit1에는 SW4·SW3·SW0의 반전이, Bit0에는 SW4·SW2·SW0의 반전이 들어가요(남는 입력은 VCC). NAND(X′, Y′, …)=X+Y+…이므로 각 Bit는 연결된 스위치들의 OR예요.

식

$$\mathrm{Bit3}=SW5,\ \mathrm{Bit2}=SW1+SW2+SW3+SW4,\ \mathrm{Bit1}=SW0+SW3+SW4,\ \mathrm{Bit0}=SW0+SW2+SW4$$

완성한 표

SWBit3Bit2Bit1Bit0
0000010011
0001000101
0100000111
1000001000

검산·주의

검산: 각 행이 십진수+3의 4비트와 같아요(SW5만 켜면 5+3=8=1000). 흔한 실수: SW 열을 오른쪽부터 SW5로 읽으면 행이 뒤바뀌어요. 표 열은 왼쪽이 SW5예요.

완성 답과 검산

000001 → 0011; 000100 → 0101; 010000 → 0111; 100000 → 1000

네 지정 행의 스위치 번호 0·2·4·5에 3을 더해 0011·0101·0111·1000인지 확인해요.

여기서 헷갈리기 쉬워요

출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

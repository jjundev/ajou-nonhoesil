이 문제에서 할 일

디코더의 주소 판별 항에 데이터 D를 곱하면 선택한 출력만 D를 따라가요.

첫 줄을 이렇게 시작해요

원래 Y0=S1′S0′에 D를 붙여 Y0=S1′S0′D라고 써요.

필요한 개념: 디코더로 디멀티플렉서를 만들어요

왜 이렇게 푸는지 함께 따라가요

네 2입력 AND를 모두 3입력으로 바꾸고 D를 추가해요. NOT은 선택선을 반전하는 데만 쓰고 데이터 D는 그대로 네 AND에 분기해요. 주소가 선택되지 않은 항은 이미 0이므로 D와 AND해도 0이고 선택 항에서는 D가 남아요.

풀이

디코더의 AND 네 개는 위에서부터 S1S0=00, 01, 10, 11을 골라내요. 각 AND에 데이터 D를 입력으로 하나 더 넣으면 선택된 AND만 D를 통과시켜요. AND를 3입력으로 바꾸고 D를 네 AND 모두에 연결해요.

완성 회로

논리식

$$Y_0=\overline{S_1}\,\overline{S_0}D,\ Y_1=\overline{S_1}S_0D,\ Y_2=S_1\overline{S_0}D,\ Y_3=S_1S_0D$$

검산·주의

검산: S1S0=10, D=1이면 Y2만 1이고 D=0이면 모두 0이에요. 흔한 실수: D를 일부 AND에만 연결하거나 NOT에 넣지 않아요.

완성 답과 검산

AND를 3입력으로 바꾸고 D를 모두에 연결해요. Y0=S1′S0′D, Y1=S1′S0D, Y2=S1S0′D, Y3=S1S0D

주소 10,D=1이면 Y2만 1, 같은 주소에서 D=0이면 모두 0인지 확인해요.

이 문제에서 할 일

코드 출력 세 핀과 상태 출력 두 핀을 구별해서 각각의 역할을 설명해요. 원문 칩 이름은 교안의 74HC148로 해석해요.

이 문제를 봤을 때 떠올릴 개념과 공식

A2A1A0는 번호 코드, GS는 입력 있음, EO는 다음 단 허용

문제에 “A0, A1, A2, GS, EO”가 보이면 출력 핀을 번호 코드·입력 있음 표시·다음 칩 허용의 세 그룹으로 나누는 것을 떠올려요. IN0만 L일 때와 입력이 없을 때 코드가 둘 다 HHH라 GS가 있어야 구별되기 때문이에요.

원문 p2에는 “74HC143”과 A0·A1·A2·GS·EO가 적혀 있어요. 핀을 코드 출력과 상태/연결 출력으로 구분하라는 단서지만 그 페이지에 칩 그림은 없어요.

같은 실험 교안 p10의 칩 그림은 명시적으로 74HC148이고 A0…A2·GS·EO가 보여요. 원문은 A0…A2=Data Output, GS=Priority Flag Output, EO=Enable Output이라고 설명해요.

이 핀 역할 대조는 원문 표현을 설명하는 근거예요. 143을 148로 고쳐 쓰거나 실제 143의 기능을 확인했다고 하지 않아요. 기존 풀이의 EI·GS·EO 상세 상태는 148 해석에 따른 조건부 설명이며 제공 원문의 기능표로 검증된 사실로 확장하지 않아요.

첫 줄을 이렇게 시작해요

A2A1A0는 번호 코드, GS는 활성 입력 존재, EO는 다음 단 활성 제어라고 먼저 세 그룹으로 나눠요.

필요한 개념: 우선순위 인코더와 74HC148을 배워요

왜 이렇게 푸는지 함께 따라가요

EI=L일 때 입력이 하나라도 L이면 GS=L,EO=H가 돼요. 모두 H이면 GS=H,EO=L이고 다음 칩을 허용할 수 있어요. IN0만 L인 경우와 입력이 없는 경우의 코드가 둘 다 HHH라 GS 같은 상태 핀이 있어야 둘을 구별할 수 있어요. EI=H로 비활성인 경우에는 GS·EO도 H예요.

풀이

  • A0, A1, A2: 우선순위가 가장 높은 활성 입력의 번호를 나타내는 3비트 데이터 출력이에요. Active Low라서 이진수를 비트마다 뒤집은 값이 나와요.
  • GS: Priority Flag 출력이에요. EI가 Low이고 하나 이상의 입력이 활성(Low)일 때 Low가 되어 “입력이 있다”를 알려요.
  • EO: Enable 출력이에요. EI가 Low이고 모든 입력이 High일 때 Low가 되어 다음 칩의 EI에 연결해 칩을 이어 붙일 때 써요.
완성 답과 검산

A0~A2는 데이터 출력, GS는 Priority Flag 출력, EO는 Enable 출력이에요.

다섯 핀을 빠짐없이 쓰고 IN0 활성/입력 없음의 A출력 HHH,GS L/H,EO H/L 차이를 확인해요.

검산: IN0만 Low일 때와 모두 High일 때 A2A1A0는 같은 HHH예요. 두 경우는 GS(Low/High)로 구분할 수 있어요.

여기서 헷갈리기 쉬워요

흔한 실수: GS를 번호를 나타내는 네 번째 비트로 쓰면 안 돼요. 코드는 A2A1A0 세 핀이에요.

이제 설명을 닫고 다시 풀어요
  1. A2A1A0는 번호 코드, GS는 활성 입력 존재, EO는 다음 단 활성 제어라고 먼저 세 그룹으로 나눠요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 다섯 핀을 빠짐없이 쓰고 IN0 활성/입력 없음의 A출력 HHH,GS L/H,EO H/L 차이를 확인해요.

떠올릴 것: A2A1A0는 번호 코드, GS는 입력 있음, EO는 다음 단 허용

원문 74HC143 표기는 유지해요. 교안 그림은 74HC148이며 원문 핀 역할 설명과 대조하되 두 IC가 같다고 확정하지 않아요.

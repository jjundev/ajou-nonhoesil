이 문제에서 할 일

입력 코드가 뜻하는 번호 하나를 여러 출력 중 선택하는 회로라고 정의해요.

첫 줄을 이렇게 시작해요

2비트 주소 10을 예로 “십진수 2번 출력만 활성”이라고 써요.

필요한 개념: 디코더는 코드에 맞는 한 줄만 켜요

왜 이렇게 푸는지 함께 따라가요

n비트가 표현하는 번호는 0~2ⁿ−1이므로 최대 2ⁿ개의 출력 중 하나를 고를 수 있어요. 모든 코드가 쓰이지 않는 BCD→decimal 같은 경우에는 출력이 최대보다 적을 수 있어요. 활성 극성이 Low인 실제 칩이면 선택한 출력이 0으로 표시돼요.

풀이

디코더는 n비트 이진 코드를 입력받아 2ⁿ개의 서로 다른 출력 중 그 코드에 해당하는 하나만 활성화하는 조합 논리회로예요. 입력 n개, 출력 m개이면 n×m 디코더라고 불러요.

예

2×4 디코더는 A1A0=10이면 D2만 1이에요. 메모리나 I/O 장치 중 하나를 고르는 데 써요.

완성 답과 검산

n비트 이진 코드를 2ⁿ개의 서로 다른 정보(한 줄 활성화)로 바꾸는 조합 논리회로예요.

3비트→최대 8출력인지 계산하고 “선택=반드시 전압 1”이라고 일반화하지 않았는지 확인해요.

검산: 3비트 입력이면 출력은 2³=8개이고 한 번에 하나만 활성화돼요.

여기서 헷갈리기 쉬워요

흔한 실수: 출력이 여러 개 동시에 켜진다고 쓰면 안 돼요. 일반 디코더는 입력 코드 하나에 출력 한 줄이에요.

이제 설명을 닫고 다시 풀어요
  1. 2비트 주소 10을 예로 “십진수 2번 출력만 활성”이라고 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 3비트→최대 8출력인지 계산하고 “선택=반드시 전압 1”이라고 일반화하지 않았는지 확인해요.

이 문제에서 할 일

입력 코드를 번호로 읽고 그 번호의 출력 하나만 1로 써요. 이미 채워진 000행은 기준으로 남겨요.

첫 줄을 이렇게 시작해요

다음 행 001은 십진수 1이므로 D1 칸에 1을 쓰고 나머지 일곱 칸에 0을 써요.

필요한 개념: 디코더는 코드에 맞는 한 줄만 켜요

왜 이렇게 푸는지 함께 따라가요

A2A1A0의 가중치는 4,2,1이에요. 예를 들어 101은 4+0+1=5이므로 D5를 켜요. 표는 D7부터 D0 순서라 D1은 오른쪽에서 두 번째, D5는 왼쪽에서 세 번째예요. 번호와 실제 칸을 함께 확인해요.

풀이

3×8 디코더는 입력 A2A1A0가 가리키는 번호의 출력 Dk만 1이고 나머지는 0이에요. 001은 1이라서 D1, 010은 2라서 D2, … 111은 7이라서 D7만 1이에요.

완성한 표

AD7D6D5D4D3D2D1D0
00000000001
00100000010
01000000100
01100001000
10000010000
10100100000
11001000000
11110000000
완성 답과 검산

A=k(십진수)이면 Dk만 1이에요. 000→D0, 001→D1, …, 111→D7.

각 행에서 1이 정확히 하나이고 그 출력 번호가 입력의 십진수 값인지 확인해요.

검산: 각 행에서 1이 정확히 하나이고, 그 자리 번호가 A의 십진수와 같아요. 예: 101=5 → D5.

여기서 헷갈리기 쉬워요

흔한 실수: 출력의 열 순서(D7이 왼쪽)를 잘못 읽어 1이 반대쪽에 오는 경우예요. 000 행의 1이 D0(맨 오른쪽)인 것을 기준으로 맞춰요.

이제 설명을 닫고 다시 풀어요
  1. 다음 행 001은 십진수 1이므로 D1 칸에 1을 쓰고 나머지 일곱 칸에 0을 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 각 행에서 1이 정확히 하나이고 그 출력 번호가 입력의 십진수 값인지 확인해요.

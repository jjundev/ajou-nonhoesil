이 문제에서 할 일

여러 입력선 중 켜진 선의 위치를 짧은 이진 코드로 표현하는 회로예요.

첫 줄을 이렇게 시작해요

D5만 활성인 예를 적고 선 번호 5=101이 출력 코드라고 써요.

필요한 개념: 인코더는 켜진 줄의 번호를 코드로 바꿔요

왜 이렇게 푸는지 함께 따라가요

8개 위치를 구별하려면 3비트면 충분해요. 디코더와 입력/출력 역할이 반대이며 일반 인코더는 한 선만 활성이라는 조건이 필요해요. 여러 선이 동시에 활성일 수 있다면 우선순위 규칙 같은 추가 처리가 필요해요.

풀이

인코더는 2ⁿ개의 입력 중 하나가 활성화되면 그 위치 정보를 n비트 이진 코드로 바꾸는 조합 논리회로예요. 입력 m개, 출력 n개이면 m×n 인코더라고 불러요.

예

8×3 인코더는 D5만 1이면 A2A1A0=101을 출력해요. 키보드 입력 처리나 인터럽트 식별에 써요.

완성 답과 검산

2ⁿ개 입력 중 활성화된 하나의 위치를 n비트 이진 코드로 바꾸는 조합 논리회로예요.

D0의 코드 000부터 D7의 코드 111까지가 3비트로 표현되는지 확인해요.

검산: 8개 입력이면 출력은 3비트(2³=8)예요.

여기서 헷갈리기 쉬워요

흔한 실수: 여러 입력이 동시에 켜지는 경우를 처리하지 못한다는 한계도 함께 알아 둬요. 그때는 우선순위 인코더가 필요해요.

이제 설명을 닫고 다시 풀어요
  1. D5만 활성인 예를 적고 선 번호 5=101이 출력 코드라고 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. D0의 코드 000부터 D7의 코드 111까지가 3비트로 표현되는지 확인해요.

시작: D5만 활성인 예를 적고 선 번호 5=101이 출력 코드라고 써요.

검산: D0의 코드 000부터 D7의 코드 111까지가 3비트로 표현되는지 확인해요.

이 문제에서 할 일

회로 변경과 기능 차이라는 두 요구를 각각 답해요.

이 문제를 봤을 때 떠올릴 개념과 공식

디코더 각 AND에 D 추가, 차이는 데이터 입력 D

문제에 “1 to 4 Demultiplexer”와 “두 회로 간에 어떠한 차이”가 보이면 네 AND에 D를 더하고 그 D가 곧 차이라는 것을 떠올려요. 디코더는 선택 출력이 늘 1이지만 DMUX는 선택 출력에 D 값을 전달하기 때문이에요.

회로 변경과 기능 차이라는 두 요구에서 주소 해독과 데이터 분배를 각각 떠올려요. 주소 S1S0는 목적지, D는 보낼 값이에요.

C0=S1′S0′부터 C3=S1S0까지 네 minterm에 Yk=D·Ck를 적용해요. 곱은 AND이고 ′는 NOT이에요.

활성 High AND형에서 D를 네 게이트에 추가하면 선택 출력만 D를 따라가요. D를 Enable처럼 곱하는 관계가 회로 변경과 D=0/1 동작 차이를 함께 설명해요.

첫 줄을 이렇게 시작해요

(1) 네 AND에 D를 추가한다고 쓰고, (2) 데이터선 유무와 선택 출력의 값을 별도 줄로 나눠요.

필요한 개념: 디코더로 디멀티플렉서를 만들어요

왜 이렇게 푸는지 함께 따라가요

디코더는 주소만으로 해당 출력이 1이지만 DMUX는 해당 출력에 D를 전달해요. 따라서 D=1에서는 같고 D=0에서는 DMUX의 출력이 전부 0이에요. 회로에서는 AND 입력 하나가 늘어난 것이 이 동작 차이를 만들어요.

풀이

디코더의 AND 네 개는 위에서부터 S1S0=00, 01, 10, 11을 골라내요. 각 AND에 데이터 D를 입력으로 하나 더 넣으면 선택된 AND만 D를 통과시켜요. AND를 3입력으로 바꾸고 D를 네 AND 모두에 연결해요.

완성 회로

논리식

$$Y_0=\overline{S_1}\,\overline{S_0}D,\ Y_1=\overline{S_1}S_0D,\ Y_2=S_1\overline{S_0}D,\ Y_3=S_1S_0D$$

두 회로의 차이

  • 디멀티플렉서에는 데이터 입력 D가 하나 더 있고 AND가 2입력에서 3입력이 돼요.
  • 디코더는 코드만으로 항상 한 출력이 1이지만, 디멀티플렉서의 선택된 출력은 D를 따라가서 D=0이면 모두 0이에요. D=1이면 디코더와 같아요.
완성 답과 검산

(1) AND를 3입력으로 바꾸고 D를 연결: Yk=(S1S0가 k인 조건)·D. (2) 디멀티플렉서에는 데이터 입력 D가 있고 선택된 출력이 D를 따르며, D=1이면 디코더와 같아요.

완성 회로의 모든 AND에 D가 연결됐고 두 회로의 차이를 입력 개수와 출력 동작 둘 다 설명했는지 확인해요.

여기서 헷갈리기 쉬워요

흔한 실수: 입력 개수만 비교하면 부족해요. 선택선과 데이터선의 역할 차이를 함께 써요.

이제 설명을 닫고 다시 풀어요
  1. (1) 네 AND에 D를 추가한다고 쓰고, (2) 데이터선 유무와 선택 출력의 값을 별도 줄로 나눠요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 완성 회로의 모든 AND에 D가 연결됐고 두 회로의 차이를 입력 개수와 출력 동작 둘 다 설명했는지 확인해요.

이 문제에서 할 일

출력 번호를 외우지 말고 각 AND에 연결된 원래/반전 입력을 읽어 표를 채워요.

첫 줄을 이렇게 시작해요

bit0=0,bit1=0에서 D4=(bit0)′(bit1)′=1이라고 첫 행을 계산해요.

필요한 개념: 디코더는 코드에 맞는 한 줄만 켜요

왜 이렇게 푸는지 함께 따라가요

D1은 두 원래 입력, D2는 bit0만 반전, D3는 bit1만 반전, D4는 둘 다 반전이에요. 따라서 이 회로의 D1은 주소 11, D4는 00에 해당해요. 일반적인 D0부터 시작하는 디코더 출력명과 다르므로 그림의 연결을 기준으로 해요.

식 세우기

$$D_1=b_0b_1,\ D_2=\overline{b_0}\,b_1,\ D_3=b_0\overline{b_1},\ D_4=\overline{b_0}\,\overline{b_1}$$

완성한 표

bit0bit1D1D2D3D4
000001
100010
010100
111000
완성 답과 검산

00 → D4만 1, 10 → D3만 1, 01 → D2만 1, 11 → D1만 1 (bit0 bit1 순서)

표의 bit0,bit1 순서 00·10·01·11에서 D4·D3·D2·D1만 각각 1인지 확인해요.

검산: 각 행에서 1이 정확히 하나이고, 그 출력은 입력 조합과 맞는 AND예요. 예: bit0=1, bit1=0이면 D3만 켜져요.

여기서 헷갈리기 쉬워요

흔한 실수: D1~D4의 번호를 입력 번호와 같다고 읽으면 안 돼요. 이 회로에서 D1이 입력 11, D4가 입력 00에 대응해요. bit0와 bit1이 표에서 bit0가 먼저 나오는 점도 확인해요.

이제 설명을 닫고 다시 풀어요
  1. bit0=0,bit1=0에서 D4=(bit0)′(bit1)′=1이라고 첫 행을 계산해요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 표의 bit0,bit1 순서 00·10·01·11에서 D4·D3·D2·D1만 각각 1인지 확인해요.

시작: bit0=0,bit1=0에서 D4=(bit0)′(bit1)′=1이라고 첫 행을 계산해요.

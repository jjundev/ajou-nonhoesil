이 문제에서 할 일

유도식뿐 아니라 입력 High/Low에서 전류가 흐르는 길까지 설명해야 해요.

이 문제를 봤을 때 떠올릴 개념과 공식

입력 Low에서 Rp on, VCC→Rp→부하로 흐르는 sourcing 전류

문제에 “입력 level에 따른 전류의 흐름”과 “Rp”가 보이면 입력 Low에서 Rp가 켜지는 경로를 떠올려요. 이 경로에서 Rp에 걸리는 VDD−VOH와 전류로 Rp를 유도하기 때문이에요.

입력 level에 따른 전류 흐름으로 Rp를 유도하라는 단서에서는 입력 Low와 출력 High를 먼저 연결해요. 이때 켜진 PMOS가 전원에서 출력 부하로 전류를 공급해요.

Rp의 위쪽은 VDD, 아래쪽은 VOH예요. 따라서 양단 전압 VDD−VOH를 출력 전류 크기 |IOH|로 나누어 Rp를 구해요. 출력에서 밖으로 흐르는 IOH가 음수로 표기돼도 저항은 양수예요.

정격 High 출력의 VOHmin과 |IOHmax| 조건에서 Rp(on)=(VDD−VOHmin)/|IOHmax|예요. V/A=Ω를 확인하고 꺼진 Rn으로 전류를 흘리지 않아요. 이 조건을 밝혀야 입력 level·전류 방향·식 유도를 모두 설명할 수 있어요.

첫 줄을 이렇게 시작해요

입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.

필요한 개념: Rp와 Rn은 전류가 흐르는 길을 정해요

왜 이렇게 푸는지 함께 따라가요

이 경로의 Rp에서 잃는 전압이 VDD−VOH예요. 입력 High에서는 Rp가 꺼지고 Low 출력을 위한 Rn 경로가 작동하므로 이때 Rp on 식을 유도하지 않아요. 입력 두 상태를 구별한 뒤 High 출력 조건에 옴의 법칙을 적용해요.

입력 High일 때

$R_n$이 켜지고 $R_p$는 꺼져요. 전류는 부하에서 $R_n$을 거쳐 GND로 흘러요. 이 경우는 $R_p$ 식과 상관없어요.

입력 Low일 때

$R_p$가 켜지고 $R_n$은 꺼져요. 전류는 VCC에서 $R_p$를 거쳐 부하로 흘러요(sourcing). 출력은 High예요.

식 세우기

$R_p$ 양단 전압은 $V_{DD}-V_{OH}$예요. 한계 조건에서 $V_{OH}=V_{OHmin}$, 전류는 $|I_{OHmax}|$예요. $V_{DD}-V_{OHmin} = |I_{OHmax}|\cdot R_{p(on)}$이에요.

완성 그림

완성 답과 검산

입력 Low: $R_p$ on, 전류는 VCC → $R_p$ → 부하. $R_{p(on)} = \dfrac{V_{DD}-V_{OHmin}}{|I_{OHmax}|}$

그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/|IOHmax|인지 확인해요.

채점 기준본의 그림과 식이 같아요. 그림에는 sourcing current, $R_p$, $V_{OHmin}$, $I_{OHmax}$가 표시돼요.

여기서 헷갈리기 쉬워요

식만 외워서 쓰는 거예요. 채점 메모는 그림에 어디가 $V_{OHmin}$이고 $I_{OHmax}$인지 표시하라고 했어요.

이제 설명을 닫고 다시 풀어요
  1. 입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/|IOHmax|인지 확인해요.

떠올릴 것: 입력 Low에서 Rp on, VCC→Rp→부하로 흐르는 sourcing 전류

입력 Low→PMOS on→전류 공급을 표시하고 Rp 양단 전압 VDD−VOH를 |IOH|로 나눠요.

시작: 입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.

판단: 이 경로의 Rp에서 잃는 전압이 VDD−VOH예요. 입력 High에서는 Rp가 꺼지고 Low 출력을 위한 Rn 경로가 작동하므로 이때 Rp on 식을 유도하지 않아요. 입력 두 상태를 구별한 뒤 High 출력 조건에 옴의 법칙을 적용해요.

검산: 그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/|IOHmax|인지 확인해요.

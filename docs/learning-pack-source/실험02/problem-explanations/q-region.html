이 문제를 보면 떠올려요

1.5 V·3.5 V로 입력 구간을 나누고 출력은 반대로, 입력·출력 레벨 함께 적기

문제에 “VIHmin= 3.5V, VILmax=1.5V”와 “CMOS inverter의 출력”이 보이면 두 값으로 입력을 세 구간으로 나눈 뒤 인버터라 출력은 반대로 읽는 걸 떠올려요. 두 기준 사이는 0/1을 보장하지 못하는 Abnormal이고, 묻는 건 출력 상태이기 때문이에요.

이 문제에서 할 일

그래프는 입력 전압이지만 물은 것은 인버터의 출력 상태예요. 먼저 입력 구간을 나눈 뒤 반대로 읽어요.

첫 줄을 이렇게 시작해요

세로축의 1.5 V와 3.5 V에 가로선을 긋고 입력선과 만나는 시각을 t1,t2로 표시해요.

필요한 개념: 논리 레벨의 기준 전압 네 개를 읽어요

왜 이렇게 푸는지 함께 따라가요

입력이 1.5 V 이하면 Low로 보장되므로 인버터 출력은 High예요. 3.5 V 이상이면 입력 High라 출력 Low예요. 사이에서는 0/1을 보장하지 못하므로 Abnormal로 표시해요. t1과 t2의 실제 시간 수치는 주어지지 않았으므로 숫자로 꾸며 쓰지 않아요.

기준선과 구간

$V_{ILmax}=1.5\,\mathrm{V}$, $V_{IHmin}=3.5\,\mathrm{V}$에 가로선을 긋고 입력선이 지나는 시각을 $t_1$, $t_2$라 해요. $t_1$ 이전은 입력 Low, $t_1$~$t_2$는 Abnormal, $t_2$ 이후는 입력 High예요.

인버터 출력으로 바꾸기

인버터는 입력과 반대로 내보내요. 입력 Low 구간은 출력 High, 입력 High 구간은 출력 Low, 가운데는 출력이 보장되지 않는 Abnormal이에요.

완성 그림

검산과 흔한 실수

입력 0 V는 Low 구간이고 출력은 5 V 근처예요. 흔한 실수는 출력을 입력과 같은 방향으로 표기하는 거예요. 채점 기준본은 전압 구역을 입력 기준으로 적었으니, 입력·출력 레벨을 함께 적으면 안전해요.

완성 답과 검산

$t_1$ 이전: 입력 Low → 출력 High, $t_1$~$t_2$: Abnormal, $t_2$ 이후: 입력 High → 출력 Low. ($t_1$, $t_2$는 입력이 1.5 V, 3.5 V를 지나는 시각이에요.)

입력이 0 V인 시작 부분의 출력이 High, 5 V인 마지막 부분의 출력이 Low인지 확인해요.

여기서 헷갈리기 쉬워요

답안 충돌: 원문·제공 답안의 조건이나 표기가 도출 결과와 달라요. 아래 풀이의 조건을 명시하고, 제공 답안을 그대로 정답으로 외우지 않아요.

출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
  1. 세로축의 1.5 V와 3.5 V에 가로선을 긋고 입력선과 만나는 시각을 t1,t2로 표시해요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 입력이 0 V인 시작 부분의 출력이 High, 5 V인 마지막 부분의 출력이 Low인지 확인해요.

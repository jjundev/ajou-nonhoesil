이 문제에서 할 일

VOHmin과 VILmax는 입력/출력도 다르고 High/Low도 달라요. 두 기호를 별도로 읽어요.

첫 줄을 이렇게 시작해요

VOHmin의 O를 찾아 출력임을 쓰고 H·min을 붙여 High 출력의 최솟값이라고 써요.

필요한 개념: 논리 레벨의 기준 전압 네 개를 읽어요

왜 이렇게 푸는지 함께 따라가요

VILmax는 I라서 입력, L이라서 Low, max라서 최댓값이에요. 입력 전압이 VILmax 이하면 Low로 보장돼요. VOHmin은 입력을 판정하는 수치가 아니라 High 출력을 내보내는 소자의 보장값이에요.

$V_{OHmin}$

HIGH를 출력할 때 최소 허용 전압이에요. 출력이 이 값 이상이어야 High로 인정돼요.

$V_{ILmax}$

LOW를 입력 받을 때 최대 입력 전압이에요. 입력이 이 값 이하면 Low로 알아들어요.

그림으로 위치 확인

완성 답과 검산

$V_{OHmin}$: HIGH를 출력할 때 최소 허용 전압이에요. 출력이 이 값 이상이어야 High로 인정돼요. / $V_{ILmax}$: LOW를 입력 받을 때 최대 입력 전압이에요. 입력이 이 값 이하면 Low로 알아들어요.

VOHmin에는 “출력·High·최소”, VILmax에는 “입력·Low·최대”가 들어갔는지 확인해요.

연결되는 소자의 조건에서 $V_{OLmax}\le V_{ILmax}$, $V_{OHmin}\ge V_{IHmin}$이면 출력이 다음 입력에 안전하게 전달돼요. 모든 소자에 엄격한 전압 순서가 성립하는 것은 아니에요. 입력 기준 사이가 Abnormal이에요.

여기서 헷갈리기 쉬워요

입력 기준과 출력 기준을 서로 바꿔 쓰는 거예요. 입력은 I, 출력은 O로 구분해요.

이제 설명을 닫고 다시 풀어요
  1. VOHmin의 O를 찾아 출력임을 쓰고 H·min을 붙여 High 출력의 최솟값이라고 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. VOHmin에는 “출력·High·최소”, VILmax에는 “입력·Low·최대”가 들어갔는지 확인해요.

시작: VOHmin의 O를 찾아 출력임을 쓰고 H·min을 붙여 High 출력의 최솟값이라고 써요.

판단: VILmax는 I라서 입력, L이라서 Low, max라서 최댓값이에요. 입력 전압이 VILmax 이하면 Low로 보장돼요. VOHmin은 입력을 판정하는 수치가 아니라 High 출력을 내보내는 소자의 보장값이에요.

검산: VOHmin에는 “출력·High·최소”, VILmax에는 “입력·Low·최대”가 들어갔는지 확인해요.

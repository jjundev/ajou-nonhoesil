2026-11-27. 워크북 v2의 24문항을 같은 번호와 순서로 대조했어요. 대표 문제은행 원문 14건을 시각 대조하고 자체 출제 10문항은 각 출처 쪽과 대조했어요. 회로정정본 p4~7·9~12·14~16에서 엣지, 비동기 제어, 핀맵, 자리 순서와 세그먼트 극성을 확인했어요. 배포 보드와 작도 문제의 핀·넷 표도 확인했어요. manifest 출처 해시는 모두 현재 파일과 일치해요.

이 문제에서 할 일

래치가 무엇을 저장하고, 어떻게 기억하며, 언제 입력을 받는지를 설명하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

되먹임으로 1비트 기억, Enable 동안 입력 반영

문제에 “Latch”가 보이면 무엇을·어떻게·언제 세 가지를 떠올려요. 저장 대상(1비트), 기억 방법(되먹임), 반영 시점(Enable 동안)이 설명의 뼈대이기 때문이에요.

“Latch를 설명”할 때는 되먹임과 Enable을 함께 떠올려요. 출력이 입력 쪽으로 돌아오는 루프가 두 안정 상태 중 하나를 붙잡아 1비트를 기억해요. Q(t−1)은 이미 저장한 값이고, Q(t)은 현재 값이에요.

교안의 Enable 래치는 E=1일 때 입력에 반응하는 레벨 감응 소자예요. D 래치에서는 이 구간에 Q=D라서 투명하다고 불러요. E=0이면 Q(t)=Q(t−1)로 유지해요. 초기 값은 Set/Reset 등으로 정하기 전에는 임의로 0이라 둘 수 없고, SR 금지 입력은 정상적인 보수 상태에 포함하지 않아요. 이 조건을 붙여야 저장과 입력 반영을 모두 설명할 수 있어요.

첫 줄을 이렇게 시작해요

“Latch는 2진 정보 1비트를 저장하는 기억소자예요.”라고 첫 문장을 써요.

필요한 개념: 출력을 되먹이는 회로와 NAND를 다시 읽어요, 실험 1: Enable이 있는 SR 래치

왜 이렇게 푸는지 함께 따라가요
  • 저장: 1비트. Q와 Q′은 서로 반대인 두 안정 상태 중 하나를 지켜요.
  • 기억 방법: 출력을 입력 쪽으로 되먹여 입력이 사라져도 마지막 상태를 유지해요.
  • 입력 반영: Enable이 1인 동안 입력이 바뀌면 출력이 바로 따라 바뀌는 레벨 트리거예요. Enable=0이면 유지해요. 교안은 비동기 기억소자로 분류해요.
  • 예: SR 래치, D 래치, JK 래치
완성 답과 검산

Latch는 되먹임으로 1비트를 기억하는 레벨 트리거(비동기) 기억소자예요. Enable이 활성인 동안 입력에 따라 출력이 바로 바뀌고, 비활성이면 마지막 상태를 유지해요.

검산: D 래치에서 E=1, D=1이면 Q=1이 되고, 이어서 E=0, D=0으로 바꿔도 Q=1이 남는지 따라가 봐요. 저장과 레벨 반영이 모두 보여요.

여기서 헷갈리기 쉬워요

“입력이 변할 때마다 출력이 바뀐다”만 쓰면 Enable=0일 때 유지된다는 점을 빠뜨려요.

이제 설명을 닫고 다시 풀어요
  1. 1비트 저장이라는 정의를 써요.
  2. 되먹임으로 유지한다는 점을 써요.
  3. Enable 동안 반영되는 레벨 트리거라고 마무리해요.

떠올릴 것: 되먹임으로 1비트 기억, Enable 동안 입력 반영

되먹임이 1비트를 기억해요. 교안의 래치는 E=1 동안 반응하고 E=0에서 이전 Q를 유지해요.

시작: “Latch는 2진 정보 1비트를 저장하는 기억소자예요.”라고 첫 문장을 써요.

판단: 저장(1비트), 기억 방법(되먹임), 반영 시점(Enable 동안)을 차례로 써요.

검산: D 래치에서 E=1, D=1이면 Q=1이 되고, 이어서 E=0, D=0으로 바꿔도 Q=1이 남는지 따라가 봐요. 저장과 레벨 반영이 모두 보여요.

초기 Q는 Set/Reset으로 정하기 전 0으로 가정하지 않으며, SR 금지 입력에서는 정상 보수 관계를 적용하지 않아요.

이 문제를 보면 떠올려요

PR·CLR 먼저, 그다음 하강 엣지에서만 J·K

문제에 단계별 PR·CLR·클록·J·K 표가 보이면 매 단계 적용 순서를 떠올려요. 비동기 PR·CLR이 클록보다 우선하고, 74HC76은 하강 엣지에서만 J·K를 보기 때문이에요.

이 문제에서 할 일

74HC76 하나에 PR·CLR·클록·J·K를 단계별로 넣고, 매 단계 뒤의 Q를 따라가는 새 연습이에요.

첫 줄을 이렇게 시작해요

“1단계는 PR=0이라 클록과 상관없이 Q=1이에요.”라고 첫 행을 채워요.

필요한 개념: 실험 3-2: 74HC76 JK 플립플롭

왜 이렇게 푸는지 함께 따라가요

매 단계 순서는 같아요. ① PR·CLR 중 0이 있으면 그것을 바로 적용해요. ② 둘 다 1이면 클록이 ↓인지 봐요. ③ ↓일 때만 J·K 표를 적용해요.

  • 1단계: PR=0 → Q=1(처음 Q는 몰라도 여기서 정해져요).
  • 2단계: ↓, J=K=0 → 유지 1.
  • 3단계: ↑ → 74HC76은 반응하지 않아 1.
  • 4단계: ↓, J=0, K=1 → Reset 0.
  • 5단계: ↓, J=K=1 → Toggle 1.
  • 6단계: ↓, J=K=1 → Toggle 0.
  • 7단계: ↓, J=1, K=0 → Set 1.
  • 8단계: CLR=0 → 즉시 0(J=K=1이어도 무관).

완성 답과 검산

Q = 1, 1, 1, 0, 1, 0, 1, 0 (단계 1~8)

검산: 하강 엣지는 2·4·5·6·7단계의 다섯 번뿐이에요. Q가 바뀐 곳은 1(Preset)·4·5·6·7·8(Clear)이고, 3단계(↑)는 바뀌지 않았는지 세어 봐요.

여기서 헷갈리기 쉬워요

3단계의 상승 엣지에서 K=1을 적용하거나, 8단계에서 J=K=1을 보고 Toggle하면 틀려요. 74HC76은 하강 엣지에서만, PR·CLR은 클록보다 먼저예요.

이제 설명을 닫고 다시 풀어요
  1. 각 단계에서 PR·CLR을 먼저 확인해요.
  2. 클록이 ↓인 단계만 J·K를 적용해요.
  3. 바뀐 단계 수와 하강 엣지 수를 세어 확인해요.

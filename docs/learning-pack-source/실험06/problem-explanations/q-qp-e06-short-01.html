이 문제에서 할 일

출력 Q의 변화, 입력 명령이 사라진 뒤 값을 유지하는 원리와 E=0의 역할을 3~4문장으로 설명하세요.

입력의 이름만 외우지 않고 활성 조건에서 출력이 왜 그렇게 되는지 확인해요.

이 문제를 봤을 때 떠올릴 개념과 공식

Set으로 만든 상태를 유지 식에 그대로 넣어요

“Set한 다음 S=R=0”은 처음 값을 회로가 정해 준다는 단서예요. 유지 구간의 앞단 출력은 둘 다 1이라 뒤쪽 교차 NAND에서 Q=(1·Q′)′, Q′=(1·Q)′이 돼요. 이전 출력 쌍을 대입해 같은 쌍이 나오면 안정 상태예요. E=0은 이후 입력 변화까지 차단해요.

첫 줄을 이렇게 시작해요

E=1, S=1, R=0을 대입해 위 앞단 출력 0과 아래 앞단 출력 1을 얻어요. 위 교차 NAND의 출력은 Q=1이에요.

개념으로 돌아가기: 해당 동작 원리

이유를 따라 완성해요

채점 핵심

앞단은 명령을 전달하거나 차단하고, 뒤의 교차 NAND는 출력을 서로 입력으로 돌려보내요. 유지 명령에서 두 NAND가 서로의 현재 값을 지지하므로 새 명령 전까지 기억해요.

채점 요소: Set으로 Q=1이 돼요. S=R=0으로 돌아와도 교차 되먹임이 Q=1,Q′=0을 유지해요. E=0이면 S·R의 변화가 저장부에 전달되지 않아 직전 상태를 지켜요.

허용 표현

되먹임/피드백, 유지/저장, High/1, 하강 엣지/1→0처럼 의미가 같은 표현을 인정해요. “전기가 남아 있어서”만으로는 되먹임 원리를 설명하지 못해요. 전원이 차단되어도 영구 보존된다고 쓰지 않아요.

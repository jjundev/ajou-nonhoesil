## 원문 시각 판독

PDF 스킬을 읽고 PyMuPDF로 15개 페이지를 렌더링한 후 실제 view_image로 모두 판독했어요. 출력은 output/validation/problem-recall/source-06/예요. 강의노트/실험6. Latch & Flip-Flop.pdf pp3–5,7–11; from_the_past/정리/퀴즈/실험6/의 2017-1 p1, 기출_단답형 pp1–2, 예상문제_v1 pp1–2, 예상문제_v3 p1, 해설 p1을 대조했어요.

앞단 NAND가 있는 SR의 바깥 입력은 active-high, 직접 NAND의 입력은 active-low였어요. D 회로의 NOT·Enable과 JK 회로의 Q′/Q 피드백을 실제 배선으로 확인했어요. 표의 C=1은 레벨 조건이며 이름 F/F만으로 엣지형이라고 판정하지 않았어요. 교안 p11과 from_the_past/정리/소자_데이터시트_및_미디어/1_데이터시트_및_핀아웃/74-76-diagram.jpg의 하강 엣지 버블·비동기 active-low를 실제 확인했어요. 이미지의 동시 Set/Reset=0 행은 출력 L*/L*이지만 금지 및 동시 해제 뒤 예측 불가이므로 새 설명은 출력값을 일반화하지 않았어요.

74HC574 보충 사양은 [Nexperia 공식 Rev10 데이터시트](https://assets.nexperia.com/documents/data-sheet/74HC_HCT574.pdf) pp1–4의 CP 상승 엣지·8비트·OE active-low·OE는 내부 상태에 영향 없음으로 확인했어요. 기존 로컬 원문이 아닌 보충 근거이고 manifest sources는 변경하지 않았어요. 기존 일반 사양/답안 충돌 경고도 줄이지 않았어요.

## 재계산 (동일 에이전트의 검산)

output/validation/problem-recall/calculation-06.json: 초기 Q=0/1 각각의 모든 Enable SR 입력 16조합을 NAND 반복 계산하여 확인했어요. C=0 및 C=1,SR=00은 이전 값, 01은 0/1, 10은 1/0, 11은 1/1이에요. 직접 NAND S=R=0은 초기값 무관 1/1이에요. D는 S=D,R=NOT D를 대입하여 활성 때 두 정상 행만 남고 C=0은 유지예요. JK는 J,K,Q 8경우를 Qnext=J·NOT Q+NOT K·Q로 별도 계산했고 T는 T,Q 4경우를 XOR로 확인했어요. 레벨 JK의 식은 단일 갱신이며 긴 펄스의 최종 상태를 보장하지 않아요.

파형 추적은 Q=None에서 시작하여 비동기 우선·하강 엣지만 따로 계산했어요. 결과 1,1,1,0,1,0,1,0이고, 3행 ↑은 유지, 8행 CLR은 Toggle보다 우선해요. 이는 독립 리뷰어 검토와 다른 동일 저작자의 재계산이에요.

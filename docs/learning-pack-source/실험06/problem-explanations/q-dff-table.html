이 문제에서 할 일

입력 이름이 S·C로 적힌 D 회로를 읽고 Q와 Q′을 채우는 문제예요. NOT 하나 때문에 SR 래치와 달리 입력 조합이 두 가지뿐이에요.

이 문제를 봤을 때 떠올릴 개념과 공식

NOT 하나로 R 자리가 S′, 그래서 C=1이면 Q=S

문제 회로에서 한 입력선에만 NOT이 붙어 있으면 래치의 두 입력이 늘 반대라는 걸 떠올려요. S·R 자리가 동시에 1이 될 수 없어서 C=1일 때 Set·Reset 두 행만 남기 때문이에요.

그림의 NOT과 S·C 두 입력을 보면 SR의 두 요청을 한 데이터와 그 보수로 묶은 D 래치를 떠올려요. 여기서 S라는 입력 이름이 데이터 D 역할을 하고, 아래 앞단에는 S′이 들어가요.

C=1이면 Q=S, Q′=S′이고 C=0이면 이전 상태를 유지해요. NOT 덕분에 바깥 Set·Reset 요청이 동시에 1일 수 없어 SR 금지 입력을 막아요. 이 그림에는 엣지 검출이나 마스터·슬레이브 단계가 없으므로 제목의 F/F보다 실제 레벨 회로를 기준으로 표를 채워요. 입력 S=0/1 두 행과 C=0 유지 행을 분리하는 이유예요.

첫 줄을 이렇게 시작해요

“NOT 때문에 아래 앞단 NAND에는 항상 S의 반대가 들어가요.”라고 회로부터 읽어요.

필요한 개념: 실험 2-1: D 래치는 부정 상태를 막아요

왜 이렇게 푸는지 함께 따라가요

위 앞단 NAND는 S·C, 아래 앞단 NAND는 S′·C를 받아요. SR 래치의 S 자리에 S, R 자리에 S′이 들어간 D 래치예요.

  • C=1, S=0: 아래 앞단만 0 → Q′=1, Q=0 (Reset).
  • C=1, S=1: 위 앞단만 0 → Q=1, Q′=0 (Set).
  • C=0: 앞단 출력이 모두 1 → 유지.

완성 답과 검산

S=0, C=1 → Q=0, Q′=1; S=1, C=1 → Q=1, Q′=0; C=0 → Q(t−1), Q′(t−1) 유지

검산: C=1에서 Q가 항상 S와 같고 Q′은 그 반대예요. S와 R 자리 값이 늘 반대라 금지 상태가 없어요.

여기서 헷갈리기 쉬워요

입력 이름이 S라서 SR 래치 네 행 표를 쓰면 안 돼요. 기출_단답형 답안의 둘째 행 “0 1 1”은 첫 행과 입력이 같아 오기로 보이고, 회로 계산으로는 S=1일 때 Q=1이에요.

이제 설명을 닫고 다시 풀어요
  1. NOT이 어느 선에 붙었는지 찾아요.
  2. C=1에서 S=0, S=1 두 경우를 따라가요.
  3. C=0 유지 행을 채워요.

떠올릴 것: NOT 하나로 R 자리가 S′, 그래서 C=1이면 Q=S

S가 데이터이고 S′이 Reset 쪽으로 가요. 이 레벨 회로는 C=1에서 Q=S, C=0에서 유지해요.

시작: “NOT 때문에 아래 앞단 NAND에는 항상 S의 반대가 들어가요.”라고 회로부터 읽어요.

판단: NOT 때문에 S와 R 자리가 늘 반대라서 C=1이면 Q=S예요.

검산: C=1에서 Q가 항상 S와 같고 Q′은 그 반대예요. S와 R 자리 값이 늘 반대라 금지 상태가 없어요.

제목은 F/F지만 엣지 검출 없는 D 래치로 읽어요. 기출 답안 둘째 행의 “0 1 1”은 오기로 보이며 회로 계산은 S=1일 때 Q=1이에요.

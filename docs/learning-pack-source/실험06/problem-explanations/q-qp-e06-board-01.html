이 문제에서 할 일

주어진 논리 회로와 핀 명세를 보고 v1 양식에 칩 방향, 전원, S·E·R, 게이트 사이 배선과 Q·Q′ 관측점을 작도하세요. 칩 위치는 자유예요.

입력의 이름만 외우지 않고 활성 조건에서 출력이 왜 그렇게 되는지 확인해요.

이 문제를 봤을 때 떠올릴 개념과 공식

핀 번호를 정한 뒤 각 전기적 연결을 홀로 옮겨요

“74HC00(DIP-14) 한 개”와 핀 명세로 NAND 네 쌍의 입력과 출력을 찾아요. E는 두 앞단의 공통 입력이고, Q·Q′은 관측점인 동시에 반대쪽 저장부 NAND의 되먹임이에요. 같은 연결에 속한 핀과 홀을 한 넷으로 표시해요. 전원을 끈 상태에서 칩을 중앙 홈에 걸치고 노치로 1번 핀 쪽을 정해요.

첫 줄을 이렇게 시작해요

노치 기준 1번을 먼저 표시하고 전원 14→+5V, 7→GND를 적어요. 이어서 (1,2)→3, (4,5)→6, (9,10)→8, (12,13)→11로 게이트를 나눠요.

개념으로 돌아가기: 해당 동작 원리

이유를 따라 완성해요

연결 기준

먼저 NOT bubble이 있는 NAND 네 개를 찾아요. S·E를 첫 게이트, R·E를 둘째 게이트에 넣고, 두 출력을 교차 NAND 입력으로 보내요. Q와 Q′은 반대쪽 게이트 입력으로 되먹여요.

넷연결
전원14: +5V / 7: GND
입력S:1 / E:2·4 / R:5
앞단3–9 / 6–13
되먹임8–12 / 11–10
관측Q:8 / Q′:11

완성 결선도

예시는 초기 입력을 0으로 그렸어요. 점퍼의 레일 쪽 끝만 옮겨 입력을 바꿔요. 위치가 달라도 동일 넷이면 인정해요.

완성 답과 검산

14→+5V, 7→GND; S→1, E→2·4, R→5; 3→9, 6→13, 8→12, 11→10; Q=8, Q′=11

E=0 유지, E=1에서 (S,R)=10 Set·01 Reset·00 유지·11 부정을 확인해요. 핀 넷은 완성 연결표와 같아야 해요.

이 실수를 피하세요

같은 행의 a~e와 f~j는 각각 연결되지만 중앙 홈을 건너서는 연결되지 않아요. 선이 그림에서 교차해도 연결점이 없으면 도통하지 않아요. 출력끼리 묶거나 전원 레일을 단락하지 않아요.

설명을 닫고 다시 풀어요
  1. 문제의 활성 조건을 표시해요.
  2. 첫 판단에서 정답까지 이유를 써요.
  3. 반대 상태나 경계 조건으로 검산해요.

떠올릴 것: 핀 번호를 정한 뒤 각 전기적 연결을 홀로 옮겨요

먼저 NOT bubble이 있는 NAND 네 개를 찾아요. S·E를 첫 게이트, R·E를 둘째 게이트에 넣고, 두 출력을 교차 NAND 입력으로 보내요. Q와 Q′은 반대쪽 게이트 입력으로 되먹여요.

답: 14→+5V, 7→GND; S→1, E→2·4, R→5; 3→9, 6→13, 8→12, 11→10; Q=8, Q′=11

검산: E=0 유지, E=1에서 (S,R)=10 Set·01 Reset·00 유지·11 부정을 확인해요. 핀 넷은 완성 연결표와 같아야 해요.

전원을 끄고 결선하고 입력은 0V/+5V에 고정해 띄우지 않아요. 출력은 고입력 임피던스 계측기로 관찰하며 LED·저항은 추가하지 않아요. 중앙 홈 양쪽은 분리되고 교차선은 접속점 없으면 연결되지 않아요. 출력끼리 결합·전원 레일 단락을 피해요.

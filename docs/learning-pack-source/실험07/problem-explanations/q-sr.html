필요한 개념으로 돌아가요

이유를 따라 완성해요

정상 이동 모드에서 입력 시간 조건을 만족하면 Qi다음=Q(i−1)이전이에요. 저장한 비트를 한 칸씩 옮겨 직렬·병렬 변환이나 지연에 써요.

답과 검산을 확인해요

0000에서 1, 0을 차례로 넣으면 1000→0100이에요.

헷갈리기 쉬운 조건을 확인해요

한 엣지는 한 칸 이동이에요.

  1. 입력 1이 두 엣지 동안 지나가는 칸을 표시해요.

떠올릴 것: 공통 클록의 유효 엣지

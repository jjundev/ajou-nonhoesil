이해를 위한 예시 · 회로가 해결하는 문제

이해를 위한 예시로, 회로가 두 이진수를 더하거나 빼야 한다고 해 봐요. 0과 1을 저장하는 것만으로는 계산이 되지 않아서, 입력 숫자를 합이나 차로 바꾸는 회로가 필요해요. 이 일을 가산기와 감산기가 맡아요.

한 자리의 결과만 내보내면 여러 자리 계산에 필요한 정보가 빠질 수 있어요. 가산기는 합과 윗자리로 보낼 올림을 함께 내보내고, 감산기는 차와 윗자리에서 빌렸다는 표시인 내림을 함께 내보내요.

1+1은 이진수로 10이에요. 현재 자리의 합은 0이고 윗자리로 보내는 올림은 1이에요. 0−1은 윗자리에서 2(이진수 10)를 빌렸다고 보면 현재 자리의 차가 1, 빌렸다는 표시도 1이에요. 여러 자리 계산에서는 이런 올림·내림을 다음 자리에 전달해야 해요.

이번 실험에서는 게이트로 반가산기·전가산기와 반감산기·전감산기를 만들고 입력 조합별 출력을 확인해요. 아래 자리에서 오는 올림·내림 입력이 있는 전가산기·전감산기를 보면, 한 자리 회로들을 연결해 여러 자리 계산을 만드는 이유를 이해할 수 있어요.

무엇을 만들고 무엇이 나오나요

가산기는 합과 올림 수(carry)를 내보내요. 감산기는 차와 내림 수(borrow)를 내보내요. 교안은 이런 회로가 CPU 안에서 계산을 맡는 ALU(산술 논리 장치)의 핵심 기능이라고 설명해요.

이진수 한 자리끼리 계산하면 결과가 한 자리에 안 들어갈 때가 있어요. 그래서 출력이 두 개 필요해요.

계산결과한 자리로 쓴 값넘어가는 값
0 + 000올림 0
0 + 111올림 0
1 + 110 (이진수 둘, 십진수 2)0올림 1
0 − 1빼지 못해서 윗자리에서 빌려요. 10 − 1 = 11내림 1

첫 줄부터 읽어 봐요. 1 + 1은 이진수로 10이에요. 오른쪽 자리에는 0을 쓰고 왼쪽 자리로 1을 올려요. 0 − 1은 0에서 1을 뺄 수 없어서 윗자리에서 2(이진수 10)를 빌려 와요. 그러면 10 − 1 = 1이에요. 그래서 차는 1이고 윗자리에게 빌렸다는 표시(내림)도 1이에요.

회로입력출력무엇으로 만드나요 (교안)
반가산기A, B합 S, 올림 CXOR 1개 + AND 1개
전가산기A, B, 올림 입력 Ci합 S, 올림 Co반가산기 2개 + OR 1개
반감산기A, B차 D, 내림 BXOR 1개 + NOT 1개 + AND 1개
전감산기A, B, 내림 입력 Bi차 D, 내림 Bo반감산기 2개 + OR 1개
이름이 헷갈리는 곳을 미리 정리해요

교안은 반감산기의 출력 내림 수도 글자 B로 적어요. 입력 B와 같은 글자예요. 이 노트에서는 출력 내림을 Bo라고 불러서 입력 B와 구분해요. 기출 표에는 출력 열이 그냥 B로 적혀 있기도 해요. 그 열은 출력 내림이에요.

Ci는 아래 자리에서 올라온 올림 입력이고, Bi는 아래 자리에서 빌려 간 내림 입력이에요. Co와 Bo는 윗자리로 내보내는 값이에요.

한 단계만 풀어 봐요

이진수 한 자리끼리 1 + 0을 계산하면 합과 올림은 얼마일까요?

힌트

결과를 이진수로 쓴 뒤 한 자리에 들어가는지 봐요.

연습 답

1 + 0 = 1이에요. 한 자리에 들어가니까 합은 1이고 올림은 0이에요.

여러 자리 계산을 하려면 현재 자리의 합 S·차 D뿐 아니라 윗자리 올림 Co·내림 Bo도 전달해야 해요. 1+1=10이면 합 0·올림 1, 0−1이면 차 1·빌림 1이에요. 반·전은 아래 자리에서 오는 Ci·Bi 입력이 없느냐 있느냐의 차이이고 Co·Bo는 윗자리 출력이에요. 교안의 감산기 출력 B는 입력 B와 다른 내림이므로 이 노트에서는 Bo로 구별해요.

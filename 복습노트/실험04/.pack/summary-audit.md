# 본문–핵심 요약 수동 대조

실험04 실험설명·문제설명의 실제 전체 본문과 요약을 읽고 서로 다른 주장으로 나누어 대조했다. 수정 후 발행 요약을 실제로 재독했다. 표·문제·답·그림·일반 본문은 보존했다.

수정 전 상태는 최초 Task8 before 스냅샷 기준이다. unresolved는 부족했던 조건·주의·보충을 보완한 뒤 최종 요약 인용과 다시 대조하여 pass로 판정했다. 키워드·행 수를 의미 검증으로 사용하지 않았다. 브라우저 검증은 Task8c 대기이다.

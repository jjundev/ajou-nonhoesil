### 문제 1 · 입력 전압 구간 표시하기

문제 읽기
#### 문제

다음 그림은 CMOS의 입력 전압 값의 변화를 나타낸 것이다. 아래 그림에 CMOS inverter의 출력이 High, Low, Abnormal 상태가 되는 구간을 표시하여라.(단, VCC= 5V, VIHmin= 3.5V, VILmax=1.5V, GND=0V이다)

#### 주어진 조건

$V_{CC}=5\,\mathrm{V}$, $V_{IHmin}=3.5\,\mathrm{V}$, $V_{ILmax}=1.5\,\mathrm{V}$, $GND=0\,\mathrm{V}$이에요. 입력은 GND에 머물다가 직선으로 VCC까지 오른 뒤 VCC로 유지돼요.

#### 구할 것

그림의 시간축 위에 High, Low, Abnormal 상태가 되는 구간을 표시하세요.

![입력 전압 구간 표시하기 · 주어진 그림](%EC%9E%90%EB%A3%8C/figures/questions/q-region-given-01.png)

이 문제에서 할 일
그래프는 입력 전압이지만 물은 것은 인버터의 출력 상태예요. 먼저 입력 구간을 나눈 뒤 반대로 읽어요.

이 문제를 봤을 때 떠올릴 개념과 공식
입력 전압이 올라가는 그림과 High·Low·Abnormal 구간이라는 말에서 입력 판정 경계를 떠올려요. VILmax는 Low 입력의 최대 전압, VIHmin은 High 입력의 최소 전압이에요.

Vin≤VILmax이면 입력 Low, Vin≥VIHmin이면 입력 High로 보장돼요. 그 사이는 논리값이 보장되지 않는 구간이에요. 인버터의 출력은 보장된 입력과 반대이므로 낮은 입력 구간에서는 High, 높은 입력 구간에서는 Low예요.

VOLmax와 VOHmin은 각각 출력 Low의 최대값과 출력 High의 최소값이에요. 입력 문턱과 역할이 달라요. 원문의 5 V 전원·1.5/3.5 V 입력 경계를 적용하되, 기존 답안 충돌을 이 구분만으로 확정하지 않아요.

첫 줄을 이렇게 시작해요
세로축의 1.5 V와 3.5 V에 가로선을 긋고 입력선과 만나는 시각을 t1,t2로 표시해요.

필요한 개념: [논리 레벨의 기준 전압 네 개를 읽어요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-levels)

왜 이렇게 푸는지 함께 따라가요
입력이 1.5 V 이하면 Low로 보장되므로 인버터 출력은 High예요. 3.5 V 이상이면 입력 High라 출력 Low예요. 사이에서는 0/1을 보장하지 못하므로 Abnormal로 표시해요. t1과 t2의 실제 시간 수치는 주어지지 않았으므로 숫자로 꾸며 쓰지 않아요.

#### 기준선과 구간

$V_{ILmax}=1.5\,\mathrm{V}$, $V_{IHmin}=3.5\,\mathrm{V}$에 가로선을 긋고 입력선이 지나는 시각을 $t_1$, $t_2$라 해요. $t_1$ 이전은 입력 Low, $t_1$~$t_2$는 Abnormal, $t_2$ 이후는 입력 High예요.

#### 인버터 출력으로 바꾸기

인버터는 입력과 반대로 내보내요. 입력 Low 구간은 출력 High, 입력 High 구간은 출력 Low, 가운데는 출력이 보장되지 않는 Abnormal이에요.

#### 완성 그림

![입력 상승 직선과 1.5 V, 3.5 V 기준선, 시간축 위 세 구간 표시](%EC%9E%90%EB%A3%8C/figures/solutions/q-region-solution-01.svg)

#### 검산과 흔한 실수

입력 0 V는 Low 구간이고 출력은 5 V 근처예요. 흔한 실수는 출력을 입력과 같은 방향으로 표기하는 거예요. 채점 기준본은 전압 구역을 입력 기준으로 적었으니, 입력·출력 레벨을 함께 적으면 안전해요.

완성 답과 검산
$t_1$ 이전: 입력 Low → 출력 High, $t_1$~$t_2$: Abnormal, $t_2$ 이후: 입력 High → 출력 Low. ($t_1$, $t_2$는 입력이 1.5 V, 3.5 V를 지나는 시각이에요.)

입력이 0 V인 시작 부분의 출력이 High, 5 V인 마지막 부분의 출력이 Low인지 확인해요.

여기서 헷갈리기 쉬워요
답안 충돌: 원문·제공 답안의 조건이나 표기가 도출 결과와 달라요. 아래 풀이의 조건을 명시하고, 제공 답안을 그대로 정답으로 외우지 않아요.

출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
- 세로축의 1.5 V와 3.5 V에 가로선을 긋고 입력선과 만나는 시각을 t1,t2로 표시해요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 입력이 0 V인 시작 부분의 출력이 High, 5 V인 마지막 부분의 출력이 Low인지 확인해요.

입력 경계 VILmax/VIHmin으로 구간을 나누고 인버터 출력을 반대로 읽어요. 출력 보증값과 답안 충돌은 별도로 확인해요.

**시작:** 세로축의 1.5 V와 3.5 V에 가로선을 긋고 입력선과 만나는 시각을 t1,t2로 표시해요.

**판단:** 입력이 1.5 V 이하면 Low로 보장되므로 인버터 출력은 High예요. 3.5 V 이상이면 입력 High라 출력 Low예요. 사이에서는 0/1을 보장하지 못하므로 Abnormal로 표시해요. t1과 t2의 실제 시간 수치는 주어지지 않았으므로 숫자로 꾸며 쓰지 않아요.

**검산:** 입력이 0 V인 시작 부분의 출력이 High, 5 V인 마지막 부분의 출력이 Low인지 확인해요.

### 문제 2 · CMOS 주요 파라미터 네 가지

문제 읽기
#### 문제

CMOS의 주요 parameters에 대해 설명하여라.

$V_{OHmin}$ : / $V_{IHmin}$ : / $V_{ILmax}$ : / $V_{OLmax}$ :

#### 구할 것

네 기호가 무엇을 뜻하는지 각각 설명하세요. (원문은 답 칸이 비어 있어요.)

이 문제에서 할 일
긴 기호를 네 부분으로 나누면 외우기보다 뜻을 읽을 수 있어요. V는 전압, I/O는 입력/출력, H/L은 High/Low예요.

이 문제를 봤을 때 떠올릴 개념과 공식
네 parameters의 뜻을 묻는 단서에서는 숫자를 계산하기보다 기호의 I/O와 H/L을 먼저 구분해요. V는 전압(V), I는 입력, O는 출력이에요.

VOHmin은 출력 High 최소값, VIHmin은 입력 High 최소값, VILmax는 입력 Low 최대값, VOLmax는 출력 Low 최대값이에요. min은 그 이상, max는 그 이하가 보장되는 경계예요.

출력 보증은 정해진 전원·부하 조건에서 적용해요. 입력 기준은 다음 소자가 받아들이는 범위예요. 따라서 네 정의 모두에 입력/출력과 최소/최대를 넣어야 서로 바뀌지 않아요.

첫 줄을 이렇게 시작해요
VOHmin을 V·O·H·min으로 나누고 “High 출력 전압의 최솟값”이라고 첫 답을 써요.

필요한 개념: [논리 레벨의 기준 전압 네 개를 읽어요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-levels)

왜 이렇게 푸는지 함께 따라가요
min은 그 이상, max는 그 이하라는 경계예요. VIHmin은 입력이 High라고 보장되는 최소값, VILmax는 입력이 Low라고 보장되는 최대값이에요. 출력 규격은 부하 조건을 만족할 때 소자가 보장하는 레벨이며 입력 판정 기준과 역할이 달라요.

#### $V_{OHmin}$

HIGH를 출력할 때 최소 허용 전압이에요. 출력이 이 값 이상이어야 High로 인정돼요.

#### $V_{IHmin}$

HIGH를 입력 받을 때 최소 입력 전압이에요. 입력이 이 값 이상이면 High로 알아들어요.

#### $V_{ILmax}$

LOW를 입력 받을 때 최대 입력 전압이에요. 입력이 이 값 이하면 Low로 알아들어요.

#### $V_{OLmax}$

LOW를 출력할 때 최대 허용 전압이에요. 출력이 이 값 이하여야 Low로 인정돼요.

#### 그림으로 위치 확인

![VCC에서 GND까지 V_OHmin, V_IHmin, V_ILmax, V_OLmax의 위치와 ABNORMAL 구간을 보여 주는 전압 사다리](%EC%9E%90%EB%A3%8C/figures/solutions/q-params-4-solution-01.svg)

완성 답과 검산
$V_{OHmin}$: HIGH를 출력할 때 최소 허용 전압이에요. 출력이 이 값 이상이어야 High로 인정돼요. / $V_{IHmin}$: HIGH를 입력 받을 때 최소 입력 전압이에요. 입력이 이 값 이상이면 High로 알아들어요. / $V_{ILmax}$: LOW를 입력 받을 때 최대 입력 전압이에요. 입력이 이 값 이하면 Low로 알아들어요. / $V_{OLmax}$: LOW를 출력할 때 최대 허용 전압이에요. 출력이 이 값 이하여야 Low로 인정돼요.

네 답에 입력/출력·High/Low·최소/최대가 모두 있는지 확인해요. 예를 들어 VIHmin 이상은 High 입력이에요.

연결되는 소자의 조건에서 $V_{OLmax}\le V_{ILmax}$, $V_{OHmin}\ge V_{IHmin}$이면 출력이 다음 입력에 안전하게 전달돼요. 모든 소자에 엄격한 전압 순서가 성립하는 것은 아니에요. 입력 기준 사이가 Abnormal이에요.

여기서 헷갈리기 쉬워요
입력 기준과 출력 기준을 서로 바꿔 쓰는 거예요. 입력은 I, 출력은 O로 구분해요.

이제 설명을 닫고 다시 풀어요
- VOHmin을 V·O·H·min으로 나누고 “High 출력 전압의 최솟값”이라고 첫 답을 써요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 네 답에 입력/출력·High/Low·최소/최대가 모두 있는지 확인해요. 예를 들어 VIHmin 이상은 High 입력이에요.

I/O로 입력·출력을 구분하고 H/L과 min/max를 붙여 네 전압 보증 경계를 읽어요.

**시작:** VOHmin을 V·O·H·min으로 나누고 “High 출력 전압의 최솟값”이라고 첫 답을 써요.

**판단:** min은 그 이상, max는 그 이하라는 경계예요. VIHmin은 입력이 High라고 보장되는 최소값, VILmax는 입력이 Low라고 보장되는 최대값이에요. 출력 규격은 부하 조건을 만족할 때 소자가 보장하는 레벨이며 입력 판정 기준과 역할이 달라요.

**검산:** 네 답에 입력/출력·High/Low·최소/최대가 모두 있는지 확인해요. 예를 들어 VIHmin 이상은 High 입력이에요.

### 문제 3 · CMOS 주요 파라미터 (VOHmin, VILmax)

문제 읽기
#### 문제

CMOS의 주요 parameter에 대해 설명하여라.

$V_{OHmin}$ : / $V_{ILmax}$ :

#### 구할 것

두 기호를 각각 설명하세요. (원문은 답 칸이 비어 있어요.)

이 문제에서 할 일
VOHmin과 VILmax는 입력/출력도 다르고 High/Low도 달라요. 두 기호를 별도로 읽어요.

이 문제를 봤을 때 떠올릴 개념과 공식
VOHmin과 VILmax 두 기호를 설명하라는 말에서 출력 보증과 입력 판정의 차이를 떠올려요. V의 단위는 볼트(V)예요.

VOHmin의 O·H·min은 High 출력의 최소 보증 전압이에요. 지정된 부하 조건에서 VOH≥VOHmin이어야 해요. VILmax의 I·L·max는 Low 입력의 최대 허용 전압으로 Vin≤VILmax일 때 Low로 판정돼요.

### 문제 5 · Schmitt-trigger가 잡음에 덜 민감한 이유

문제 읽기
#### 문제

Schmitt-trigger inverter의 출력이 입력 잡음에 영향을 덜 받게 되는 이유를 입출력 특성을 이용하여 설명하여라.

#### 구할 것

입출력 특성(히스테리시스 곡선)을 이용해 이유를 설명하세요.

이 문제에서 할 일
입력이 흔들릴 때 출력이 왜 자꾸 바뀌는지, 두 문턱을 쓰면 무엇이 달라지는지 설명해요.

이 문제를 봤을 때 떠올릴 개념과 공식
입력 잡음에 영향을 덜 받는 이유와 입출력 특성이라는 말에서 히스테리시스를 떠올려요. 같은 입력 전압이어도 이전 출력 상태에 따라 결과가 달라지는 특성이에요.

상승 입력의 문턱 VT+와 하강 입력의 문턱 VT−가 다르고 VT+>VT−예요. 폭 VH=VT+−VT−의 단위는 V예요. 인버터는 상승 문턱 돌파에서 Low, 하강 문턱 아래에서 High로 바뀌어요.

두 문턱 사이에서는 이전 상태를 유지하므로 한 문턱 주위의 작은 흔들림에 반복 반전되지 않아요. 다만 잡음이 해당 반전 문턱을 넘으면 바뀔 수 있어요. 모든 잡음을 제거한다고 쓰지 않고 상태 기억으로 이유를 설명해요.

첫 줄을 이렇게 시작해요
상승할 때의 문턱 VT+와 하강할 때의 문턱 VT−를 적고 VT+>VT−라고 표시해요.

필요한 개념: [Schmitt-trigger의 히스테리시스를 배워요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-schmitt)

왜 이렇게 푸는지 함께 따라가요
인버터는 입력이 올라가 VT+를 넘으면 출력 Low가 돼요. 그 뒤 입력이 조금 내려와도 VT− 아래로 내려가지 않으면 Low를 유지해요. 즉 같은 중간 전압이어도 지나온 방향과 직전 상태에 따라 출력이 달라져요. 이 기억 효과가 히스테리시스예요.

#### 일반 인버터의 문제

문턱이 하나라서 입력이 그 문턱 근처에서 조금만 흔들려도 출력이 계속 뒤집혀요.

#### Schmitt의 입출력 특성

올라갈 때는 $V_{T+}$, 내려올 때는 $V_{T-}$에서 출력이 바뀌는 히스테리시스 곡선이에요. 두 문턱 사이(폭 $V_H = V_{T+} - V_{T-}$)에서는 출력이 직전 값을 유지해요.

#### 잡음이 들어올 때

잡음 때문에 입력이 두 문턱 사이에서만 흔들리면 출력은 바뀌지 않아요. 잡음이 $V_{T+}$를 넘거나 $V_{T-}$ 아래로 내려갈 만큼 클 때만 출력이 바뀌어요.

#### 그림으로 확인

![문턱 근처에서 흔들리는 입력에 대해 인버터 출력은 5번 뒤집히고 Schmitt 출력은 한 번만 바뀌는 비교](%EC%9E%90%EB%A3%8C/figures/solutions/q-schmitt-noise-solution-01.svg)

#### 정리

Schmitt-trigger는 기준치(두 문턱)에 의해 Low, High가 정해지면, 잡음이 Abnormal에 해당하는 두 문턱 사이에서 흔들려도 출력이 유지돼서 영향을 덜 받아요.

완성 답과 검산
상승 문턱 $V_{T+}$와 하강 문턱 $V_{T-}$가 달라서 두 문턱 사이(히스테리시스 폭 $V_H$)의 잡음에는 출력이 바뀌지 않기 때문이에요.

출력이 Low가 된 뒤 입력이 두 문턱 사이에서만 움직일 때 계속 Low인지 확인해요. 큰 잡음은 문턱을 넘어 출력이 바뀔 수도 있어요.

그림에서 입력이 2.3~2.75 V 사이를 오갈 때 인버터 출력은 2.5 V를 지날 때마다 뒤집혀 모두 5번 바뀌지만, Schmitt 출력은 입력이 2.9 V를 넘는 순간 한 번만 바뀌어요.

여기서 헷갈리기 쉬워요
“문턱이 높아서” 또는 “문턱이 낮아서”라고만 쓰는 거예요. 문턱이 두 개이고 그 사이에서 출력이 유지된다는 점을 써야 해요.

이제 설명을 닫고 다시 풀어요
- 상승할 때의 문턱 VT+와 하강할 때의 문턱 VT−를 적고 VT+>VT−라고 표시해요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 출력이 Low가 된 뒤 입력이 두 문턱 사이에서만 움직일 때 계속 Low인지 확인해요. 큰 잡음은 문턱을 넘어 출력이 바뀔 수도 있어요.

두 문턱 VT+/VT− 사이에서 이전 출력 상태를 유지하는 히스테리시스가 반복 반전을 줄여요.

**시작:** 상승할 때의 문턱 VT+와 하강할 때의 문턱 VT−를 적고 VT+>VT−라고 표시해요.

**판단:** 인버터는 입력이 올라가 VT+를 넘으면 출력 Low가 돼요. 그 뒤 입력이 조금 내려와도 VT− 아래로 내려가지 않으면 Low를 유지해요. 즉 같은 중간 전압이어도 지나온 방향과 직전 상태에 따라 출력이 달라져요. 이 기억 효과가 히스테리시스예요.

**검산:** 출력이 Low가 된 뒤 입력이 두 문턱 사이에서만 움직일 때 계속 Low인지 확인해요. 큰 잡음은 문턱을 넘어 출력이 바뀔 수도 있어요.

### 문제 6 · 같은 입력에 대한 인버터와 Schmitt 출력

문제 읽기
#### 문제

아래 그림과 같은 입력이 인버터와 Schmitt-trigger inverter에 입력될 경우 각각의 출력을 그리시오.

#### 주어진 조건

기준선은 $V_{T+}=2.9$, $V_T=2.5$, $V_{T-}=2.1$이에요. 입력은 0 근처에서 출발해 기준선 주변을 여러 번 오르내린 뒤 5.0 근처 최고점을 지나 0 근처로 내려가요. 인버터는 $V_T$에서, Schmitt는 $V_{T+}$와 $V_{T-}$에서 바뀌어요.

#### 구할 것

인버터와 Schmitt-trigger inverter의 출력 파형을 각각 그리세요.

![같은 입력에 대한 인버터와 Schmitt 출력 · 주어진 그림](%EC%9E%90%EB%A3%8C/figures/questions/q-schmitt-waveform-given-01.png)

이 문제에서 할 일
같은 입력 그래프를 두 가지 판정 규칙으로 읽어 출력 파형 두 개를 그려요.

이 문제를 봤을 때 떠올릴 개념과 공식
같은 입력으로 인버터와 Schmitt 출력 두 개를 그리는 단서에서는 문턱 판정 규칙을 따로 적용해요. 그림의 일반 문턱은 2.5 V, 상승 문턱은 2.9 V, 하강 문턱은 2.1 V예요.

일반 인버터는 2.5 V를 지날 때마다 반전돼요. Schmitt 인버터는 출력 High일 때 2.9 V 상향 돌파, 출력 Low일 때 2.1 V 하향 돌파만 찾아요. 두 문턱 사이에서는 직전 출력을 기억해요.

그림의 시작 입력이 낮아 출력 High로 시작할 수 있어요. 다른 파형에서 초기 상태가 주어지지 않으면 임의로 정하지 않아요. 이 문항에서는 시간순으로 상태를 갱신해야 작은 흔들림과 실제 반전 시각을 구분할 수 있어요.

첫 줄을 이렇게 시작해요
입력이 낮은 시작점에서 두 인버터의 출력은 High라고 표시해요. 일반형은 2.5 V, Schmitt형은 2.9/2.1 V 기준선을 표시해요.

필요한 개념: [Schmitt-trigger의 히스테리시스를 배워요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-schmitt)

왜 이렇게 푸는지 함께 따라가요
일반형은 2.5 V를 지나는 모든 시각에 수직선을 내려 출력을 바꿔요. Schmitt형은 현재 High일 때 2.9 V 상향 돌파만, 현재 Low일 때 2.1 V 하향 돌파만 찾고 나머지 흔들림은 무시해요. 매번 현재 출력 상태를 적어 두면 기준선을 혼동하지 않아요.

#### 두 출력 따라가기

인버터는 $V_T=2.5$를 지날 때마다 뒤집혀서 12번 바뀌어요. Schmitt는 High에서 시작해 처음으로 $V_{T+}=2.9$ 위로 올라갈 때 Low가 되고, $V_{T-}=2.1$ 아래로 내려가기 전까지 Low를 유지해요. 맨 끝에서 $V_{T-}$ 아래로 내려갈 때 High로 돌아와 모두 2번 바뀌어요.

#### 완성 그림

![같은 입력에서 인버터 출력은 12번 뒤집히고 Schmitt 출력은 두 번만 바뀌는 파형](%EC%9E%90%EB%A3%8C/figures/solutions/q-schmitt-waveform-solution-01.svg)

#### 검산과 흔한 실수

Schmitt가 Low인 동안 입력의 골은 $V_{T-}$보다 높아요. 흔한 실수는 Schmitt도 $V_T$에서 바뀐다고 그리는 거예요.

완성 답과 검산
인버터: $V_T$를 지날 때마다 High↔Low로 바뀌어 모두 12번 바뀌어요. Schmitt: High에서 시작해 첫 번째 $V_{T+}$ 돌파에서 Low로, 마지막 $V_{T-}$ 하향 돌파에서 High로 단 두 번만 바뀌어요.

주어진 입력에서 일반형은 12회, Schmitt형은 2회 바뀌고 최종 출력이 High로 돌아오는지 그래프와 대조해요.

여기서 헷갈리기 쉬워요
출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
- 입력이 낮은 시작점에서 두 인버터의 출력은 High라고 표시해요. 일반형은 2.5 V, Schmitt형은 2.9/2.1 V 기준선을 표시해요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 주어진 입력에서 일반형은 12회, Schmitt형은 2회 바뀌고 최종 출력이 High로 돌아오는지 그래프와 대조해요.

일반형은 2.5 V 교차, Schmitt형은 현재 상태에 따라 2.9 V 상승/2.1 V 하강 돌파를 찾아요.

**시작:** 입력이 낮은 시작점에서 두 인버터의 출력은 High라고 표시해요. 일반형은 2.5 V, Schmitt형은 2.9/2.1 V 기준선을 표시해요.

**판단:** 일반형은 2.5 V를 지나는 모든 시각에 수직선을 내려 출력을 바꿔요. Schmitt형은 현재 High일 때 2.9 V 상향 돌파만, 현재 Low일 때 2.1 V 하향 돌파만 찾고 나머지 흔들림은 무시해요. 매번 현재 출력 상태를 적어 두면 기준선을 혼동하지 않아요.

**검산:** 주어진 입력에서 일반형은 12회, Schmitt형은 2회 바뀌고 최종 출력이 High로 돌아오는지 그래프와 대조해요.

### 문제 7 · Rp와 Rn이 출력에 미치는 영향

문제 읽기
#### 문제

CMOS의 내부 저항 Rp와 Rn이 CMOS의 출력에 미치는 영향에 대해 설명하여라.

#### 주어진 조건

CMOS 내부 회로는 VCC와 GND 사이에 $R_p$, $R_n$이 직렬로 있고, 가운데 출력 노드가 resistive load에 이어져 있어요. 입력은 Vin이에요.

#### 구할 것

$R_p$와 $R_n$이 출력에 어떤 영향을 주는지 설명하세요.

![Rp와 Rn이 출력에 미치는 영향 · 주어진 그림](%EC%9E%90%EB%A3%8C/figures/questions/q-rprn-effect-given-01.png)

이 문제에서 할 일
켜진 트랜지스터에도 저항이 있어서 부하 전류가 흐르면 이상적인 5 V/0 V와 달라지는 이유를 설명해요.

이 문제를 봤을 때 떠올릴 개념과 공식
내부 저항이 출력에 미치는 영향이라는 단서에서 켜진 트랜지스터의 등가 on 저항과 옴의 법칙을 떠올려요. Rp는 PMOS 경로, Rn은 NMOS 경로의 저항(Ω)이에요.

입력 Low이면 Rp로 전류를 공급해 VOH=VDD−\|IOH\|Rp, 입력 High이면 Rn으로 전류를 흡수해 VOL=IOLRn이에요. I는 A, IR은 V이므로 부하 전류가 흐를 때 출력이 전원 레일에서 벗어나요.

정상 상태의 저항성 부하 등가 모델에 적용해요. 꺼진 경로의 전류를 무시하고 두 저항을 동시에 on으로 놓지 않아요. 두 출력 상태를 따로 설명해야 출력 High의 감소와 출력 Low의 증가를 함께 설명할 수 있어요.

첫 줄을 이렇게 시작해요
입력 Low→Rp on→출력 High와 입력 High→Rn on→출력 Low 두 경우를 나누어 써요.

필요한 개념: [Rp와 Rn은 전류가 흐르는 길을 정해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-rprn)

왜 이렇게 푸는지 함께 따라가요
출력 High에서는 전원에서 출력까지 Rp를 지나며 전압이 떨어져 VDD보다 출력이 낮아져요. 출력 Low에서는 출력에서 GND까지 Rn을 지나며 전압이 생겨 출력이 0 V보다 높아져요. 어느 부하가 연결됐는지에 따라 전류 경로가 달라지므로 두 경우의 부하 연결을 구별해요.

#### 입력 Low (출력 High)

$R_p$가 켜지고 $R_n$은 꺼져요. 전류가 $R_p$를 거쳐 부하로 흘러서(sourcing) $V_{OH} = V_{DD} - \|I_{OH}\|R_p$예요.

#### 입력 High (출력 Low)

$R_n$이 켜지고 $R_p$는 꺼져요. 부하 쪽 전류가 $R_n$을 거쳐 GND로 흘러서(sinking) $V_{OL} = I_{OL}R_n$이에요. 꺼진 쪽은 1 MΩ 이상이라 전류가 거의 없어요.

#### 그림

![입력 High일 때 R_n으로 sinking, 입력 Low일 때 R_p로 sourcing 전류가 흐르는 두 경우의 회로](%EC%9E%90%EB%A3%8C/figures/solutions/q-rprn-effect-solution-01.svg)

#### 정리와 검산

저항이 작을수록 출력이 VCC, GND에 가까워 $V_{OHmin}$, $V_{OLmax}$를 지키기 쉬워요. 부하 전류가 0이면 $V_{OH}=V_{DD}$, $V_{OL}=0$이에요. 흔한 실수는 두 저항이 동시에 켜진다고 쓰는 거예요.

완성 답과 검산
켜진 저항(입력 Low면 $R_p$, 입력 High면 $R_n$)에서 전압이 떨어져 출력은 $V_{OH}=V_{DD}-\|I_{OH}\|R_p$, $V_{OL}=I_{OL}R_n$이 돼요. 그래서 저항이 작을수록 출력 레벨이 좋아요.

전류를 0으로 놓으면 저항에서의 전압강하도 0이 되어 VOH=VDD, VOL=0으로 돌아오는지 확인해요.

여기서 헷갈리기 쉬워요
출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
- 입력 Low→Rp on→출력 High와 입력 High→Rn on→출력 Low 두 경우를 나누어 써요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 전류를 0으로 놓으면 저항에서의 전압강하도 0이 되어 VOH=VDD, VOL=0으로 돌아오는지 확인해요.

켜진 Rp/Rn의 IR 전압강하 때문에 VOH는 VDD보다 낮고 VOL은 GND보다 높아져요.

**시작:** 입력 Low→Rp on→출력 High와 입력 High→Rn on→출력 Low 두 경우를 나누어 써요.

**판단:** 출력 High에서는 전원에서 출력까지 Rp를 지나며 전압이 떨어져 VDD보다 출력이 낮아져요. 출력 Low에서는 출력에서 GND까지 Rn을 지나며 전압이 생겨 출력이 0 V보다 높아져요. 어느 부하가 연결됐는지에 따라 전류 경로가 달라지므로 두 경우의 부하 연결을 구별해요.

**검산:** 전류를 0으로 놓으면 저항에서의 전압강하도 0이 되어 VOH=VDD, VOL=0으로 돌아오는지 확인해요.

### 문제 8 · Rp 값 유도

문제 읽기
#### 문제

CMOS의 내부 회로도를 이용하여 내부저항 Rp의 값을 유도하여라.

#### 주어진 조건

$R_p$는 VCC와 출력 노드 사이의 저항이에요. 출력이 High일 때의 전압 기준은 $V_{OHmin}$, 허용 전류는 $I_{OHmax}$예요.

#### 구할 것

$R_p$를 구하는 식을 유도하세요.

![Rp 값 유도 · 주어진 그림](%EC%9E%90%EB%A3%8C/figures/questions/q-rp-derive-given-01.png)

이 문제에서 할 일
Rp에 걸리는 전압과 Rp를 지나는 전류를 찾아 옴의 법칙을 적용하는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식
내부 회로도로 Rp를 유도하라는 말에서 High 출력의 PMOS 도통 경로를 떠올려요. 입력 Low일 때 전원에서 Rp를 지나 부하로 전류가 나가요.

Rp 양단 전압은 VDD−VOH이고 흐르는 전류의 크기는 \|IOH\|예요. 옴의 법칙 ΔV=\|I\|R에서 Rp=(VDD−VOH)/\|IOH\|를 얻어요. 전류 부호 규약과 저항의 양의 크기를 구분해요.

교안의 정격 경계 VOHmin·\|IOHmax\|를 대입하는 등가 on 저항이에요. 단위는 V/A=Ω이며 전류가 0인 조건에서는 이 나눗셈으로 저항을 정할 수 없어요. 숫자 없이 전압 차와 경로를 유도하는 문항이라 식과 조건을 제시해요.

첫 줄을 이렇게 시작해요
출력 High 상태를 그리고 Rp 위쪽 VDD, 아래쪽 VOH를 표시해요. 두 전압 차이는 VDD−VOH예요.

필요한 개념: [Rp와 Rn은 전류가 흐르는 길을 정해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-rprn)

왜 이렇게 푸는지 함께 따라가요
전류의 크기를 \|IOH\|로 두면 Rp=(VDD−VOH)/\|IOH\|예요. 문제의 한계 조건 VOHmin과 \|IOHmax\|를 넣어 등가 on 저항을 추정해요. 정격 경계에서의 등가값이지 모든 동작점에서 일정한 저항이라는 뜻은 아니에요.

#### 조건과 전류 길

$R_p$가 켜지는 때는 입력 Low, 출력 High예요. 전류(sourcing)는 VCC → $R_p$ → 출력 노드 → 부하 → GND로 흘러요.

#### 식 세우기

$R_p$ 양단 전압은 $V_{DD}-V_{OH}$, 전류는 $\|I_{OH}\|$예요. 옴의 법칙으로 $V_{DD}-V_{OH}=\|I_{OH}\|R_p$이고, 한계 $V_{OH}=V_{OHmin}$, $\|I_{OH}\|=\|I_{OHmax}\|$에서 $R_{p(on)}$이 정해져요.

#### 완성 그림

![입력 Low일 때 VCC에서 R_p를 거쳐 부하로 흐르는 I_OHmax와 출력 노드의 V_OHmin이 표시된 회로](%EC%9E%90%EB%A3%8C/figures/solutions/q-rp-derive-solution-01.svg)

#### 검산과 흔한 실수

단위는 V/A = Ω예요. 흔한 실수는 그림에 $V_{OHmin}$, $I_{OHmax}$ 위치를 표시하지 않거나 부호를 거꾸로 쓰는 거예요.

완성 답과 검산
$R_{p(on)} = \dfrac{V_{DD}-V_{OHmin}}{\|I_{OHmax}\|}$

분자는 Rp 양단의 전압 차이이고 단위는 V/A=Ω인지 확인해요. IOH 부호는 크기로 처리해요.

여기서 헷갈리기 쉬워요
출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
- 출력 High 상태를 그리고 Rp 위쪽 VDD, 아래쪽 VOH를 표시해요. 두 전압 차이는 VDD−VOH예요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 분자는 Rp 양단의 전압 차이이고 단위는 V/A=Ω인지 확인해요. IOH 부호는 크기로 처리해요.

입력 Low의 PMOS 경로에서 Rp=(VDD−VOHmin)/\|IOHmax\|예요. 전류는 크기로, 단위는 Ω로 확인해요.

**시작:** 출력 High 상태를 그리고 Rp 위쪽 VDD, 아래쪽 VOH를 표시해요. 두 전압 차이는 VDD−VOH예요.

**판단:** 전류의 크기를 \|IOH\|로 두면 Rp=(VDD−VOH)/\|IOH\|예요. 문제의 한계 조건 VOHmin과 \|IOHmax\|를 넣어 등가 on 저항을 추정해요. 정격 경계에서의 등가값이지 모든 동작점에서 일정한 저항이라는 뜻은 아니에요.

**검산:** 분자는 Rp 양단의 전압 차이이고 단위는 V/A=Ω인지 확인해요. IOH 부호는 크기로 처리해요.

### 문제 9 · Rp 유도: 입력 level별 전류 흐름

문제 읽기
#### 문제

CMOS의 내부 회로도를 이용하여 내부저항 Rp의 값을 유도하여라.(입력 level에 따른 전류의 흐름을 이용하여 설명하시오)

#### 주어진 조건

같은 내부 회로(VCC–$R_p$–출력 노드–$R_n$–GND, 출력 노드에 resistive load)를 써요. 입력 레벨에 따라 전류가 흐르는 길을 설명에 포함해요.

#### 구할 것

입력 level에 따른 전류의 흐름을 이용해 $R_p$를 유도하세요.

이 문제에서 할 일
유도식뿐 아니라 입력 High/Low에서 전류가 흐르는 길까지 설명해야 해요.

이 문제를 봤을 때 떠올릴 개념과 공식
입력 level에 따른 전류 흐름으로 Rp를 유도하라는 단서에서는 입력 Low와 출력 High를 먼저 연결해요. 이때 켜진 PMOS가 전원에서 출력 부하로 전류를 공급해요.

Rp의 위쪽은 VDD, 아래쪽은 VOH예요. 따라서 양단 전압 VDD−VOH를 출력 전류 크기 \|IOH\|로 나누어 Rp를 구해요. 출력에서 밖으로 흐르는 IOH가 음수로 표기돼도 저항은 양수예요.

정격 High 출력의 VOHmin과 \|IOHmax\| 조건에서 Rp(on)=(VDD−VOHmin)/\|IOHmax\|예요. V/A=Ω를 확인하고 꺼진 Rn으로 전류를 흘리지 않아요. 이 조건을 밝혀야 입력 level·전류 방향·식 유도를 모두 설명할 수 있어요.

첫 줄을 이렇게 시작해요
입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.

필요한 개념: [Rp와 Rn은 전류가 흐르는 길을 정해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-rprn)

왜 이렇게 푸는지 함께 따라가요
이 경로의 Rp에서 잃는 전압이 VDD−VOH예요. 입력 High에서는 Rp가 꺼지고 Low 출력을 위한 Rn 경로가 작동하므로 이때 Rp on 식을 유도하지 않아요. 입력 두 상태를 구별한 뒤 High 출력 조건에 옴의 법칙을 적용해요.

#### 입력 High일 때

$R_n$이 켜지고 $R_p$는 꺼져요. 전류는 부하에서 $R_n$을 거쳐 GND로 흘러요. 이 경우는 $R_p$ 식과 상관없어요.

#### 입력 Low일 때

$R_p$가 켜지고 $R_n$은 꺼져요. 전류는 VCC에서 $R_p$를 거쳐 부하로 흘러요(sourcing). 출력은 High예요.

#### 식 세우기

$R_p$ 양단 전압은 $V_{DD}-V_{OH}$예요. 한계 조건에서 $V_{OH}=V_{OHmin}$, 전류는 $\|I_{OHmax}\|$예요. $V_{DD}-V_{OHmin} = \|I_{OHmax}\|\cdot R_{p(on)}$이에요.

#### 완성 그림

![입력 Low일 때 VCC에서 R_p를 거쳐 부하로 흐르는 전류 I_OHmax와 V_OHmin이 표시된 회로](%EC%9E%90%EB%A3%8C/figures/solutions/q-rp-derive-current-solution-01.svg)

완성 답과 검산
입력 Low: $R_p$ on, 전류는 VCC → $R_p$ → 부하. $R_{p(on)} = \dfrac{V_{DD}-V_{OHmin}}{\|I_{OHmax}\|}$

그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/\|IOHmax\|인지 확인해요.

채점 기준본의 그림과 식이 같아요. 그림에는 sourcing current, $R_p$, $V_{OHmin}$, $I_{OHmax}$가 표시돼요.

여기서 헷갈리기 쉬워요
식만 외워서 쓰는 거예요. 채점 메모는 그림에 어디가 $V_{OHmin}$이고 $I_{OHmax}$인지 표시하라고 했어요.

이제 설명을 닫고 다시 풀어요
- 입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/\|IOHmax\|인지 확인해요.

입력 Low→PMOS on→전류 공급을 표시하고 Rp 양단 전압 VDD−VOH를 \|IOH\|로 나눠요.

**시작:** 입력 Low에서 PMOS 쪽 Rp가 켜지고 VCC→Rp→출력→부하로 전류가 흐른다고 먼저 써요.

**판단:** 이 경로의 Rp에서 잃는 전압이 VDD−VOH예요. 입력 High에서는 Rp가 꺼지고 Low 출력을 위한 Rn 경로가 작동하므로 이때 Rp on 식을 유도하지 않아요. 입력 두 상태를 구별한 뒤 High 출력 조건에 옴의 법칙을 적용해요.

**검산:** 그림에 전류 화살표·Rp 양단 전압·출력 High를 표시했고 Rp=(VDD−VOHmin)/\|IOHmax\|인지 확인해요.

CMOS의 내부 회로도를 이용하여 내부저항 Rn의 값을 유도하여라.(입력 level에 따른 전류의 흐름을 이용하여 설명하시오)

이 문제에서 할 일
Low 출력을 만드는 아래쪽 저항 Rn에 옴의 법칙을 적용해요.

이 문제를 봤을 때 떠올릴 개념과 공식
입력 level에 따른 전류 흐름으로 Rn을 유도하라는 단서에서는 입력 High의 NMOS 도통을 떠올려요. 출력 Low일 때 부하 전류가 출력에서 Rn을 거쳐 GND로 흘러요.

Rn 위쪽은 VOL, 아래쪽은 0 V이므로 전압 차는 VOL이에요. 전류 IOL을 흡수하는 경로에 옴의 법칙을 적용하면 Rn=VOL/IOL이에요.

교안의 Low 출력 정격 경계에서는 Rn(on)=VOLmax/IOLmax예요. IOL이 0이 아닌 조건과 V/A=Ω를 확인해요. 출력 Low의 전압 차는 VOL 자체이므로 Rp의 VDD−VOH 식을 옮겨 쓰지 않아요.

첫 줄을 이렇게 시작해요
입력 High에서 Rn on, Rp off를 적고 부하→출력→Rn→GND의 전류 길을 그려요.

필요한 개념: [Rp와 Rn은 전류가 흐르는 길을 정해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-rprn)

왜 이렇게 푸는지 함께 따라가요
Rn 아래쪽은 0 V이고 위쪽은 VOL이므로 양단 전압은 VOL−0이에요. 따라서 Rn=VOL/IOL예요. 문제의 한계 조건을 대입하면 VOLmax/IOLmax가 돼요. 전원과 출력 사이의 Rp 식과 분자가 달라지는 이유가 여기 있어요.

#### 입력 High일 때

$R_n$이 켜지고 $R_p$는 꺼져요(1 MΩ 이상). 출력은 Low예요.

#### 전류 길

VCC → 부하 → 출력 노드 → $R_n$ → GND로 전류(sinking)가 흘러요.

#### 식 세우기

$R_n$ 양단 전압이 출력 전압 $V_{OL}$이고 전류는 $I_{OL}$이에요. $V_{OL}=I_{OL}R_n$이에요. 한계에서 $V_{OL}=V_{OLmax}$, $I_{OL}=I_{OLmax}$예요.

#### 완성 그림

![입력 High일 때 부하에서 R_n을 거쳐 GND로 흐르는 전류 I_OLmax와 V_OLmax가 표시된 회로](%EC%9E%90%EB%A3%8C/figures/solutions/q-rn-derive-solution-01.svg)

완성 답과 검산
$R_{n(on)} = \dfrac{V_{OLmax}}{I_{OLmax}}$

분자에 VDD−VOL을 쓰지 않았는지, Rn 아래쪽 기준이 GND인지 확인해요.

단위는 V/A = Ω예요. 교안 6쪽 (a) 그림의 $R_{n(on)}=V_{OLmax}/I_{OLmax}$와 같아요. $R_n$은 GND 쪽이라서 분자에 $V_{DD}$가 들어가지 않아요.

여기서 헷갈리기 쉬워요
$R_p$ 식처럼 $V_{DD}-V$를 쓰는 거예요. $R_n$은 GND 기준이라서 $V_{OLmax}$만 써요.

이제 설명을 닫고 다시 풀어요
- 입력 High에서 Rn on, Rp off를 적고 부하→출력→Rn→GND의 전류 길을 그려요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 분자에 VDD−VOL을 쓰지 않았는지, Rn 아래쪽 기준이 GND인지 확인해요.

입력 High의 NMOS 흡수 경로에서 Rn(on)=VOLmax/IOLmax예요. GND 기준 전압과 Ω 단위를 확인해요.

**시작:** 입력 High에서 Rn on, Rp off를 적고 부하→출력→Rn→GND의 전류 길을 그려요.

**판단:** Rn 아래쪽은 0 V이고 위쪽은 VOL이므로 양단 전압은 VOL−0이에요. 따라서 Rn=VOL/IOL예요. 문제의 한계 조건을 대입하면 VOLmax/IOLmax가 돼요. 전원과 출력 사이의 Rp 식과 분자가 달라지는 이유가 여기 있어요.

**검산:** 분자에 VDD−VOL을 쓰지 않았는지, Rn 아래쪽 기준이 GND인지 확인해요.

### 문제 11 · 전달 지연이 나타나는 이유

문제 읽기
#### 문제

CMOS의 출력 특성 중 전달지연(Propagation delay)가 나타나는 이유를 설명하여라.

#### 구할 것

전달 지연이 나타나는 이유를 설명하세요.

이 문제에서 할 일
입력 변화와 출력 변화 사이에 왜 시간이 필요한지 실제 회로의 충전·방전으로 설명해요.

이 문제를 봤을 때 떠올릴 개념과 공식
전달 지연이 나타나는 이유라는 단서에서 출력 부하 용량 CL의 충·방전을 떠올려요. 용량의 전압을 바꾸려면 전하가 이동해야 하고 실제 경로의 전류는 유한해요.

tPLH는 출력 Low→High, tPHL은 출력 High→Low 방향의 전달 지연이에요. 교안에서는 대응하는 입력 50%와 출력 50% 시각 사이를 재요. 두 글자의 방향은 입력이 아니라 출력이에요.

켜진 저항 R과 같은 부하 CL의 단순 모델에서 시간 상수 τ=RCL이며 Ω·F=s예요. 실제 지연은 입력 에지와 부하에도 의존해요. 출력이 서서히 변하는 이유와 입력 뒤에 늦게 응답하는 이유를 이 경로로 연결해요.

첫 줄을 이렇게 시작해요
출력에 부하 용량 CL, 전류 경로에 켜진 저항 R을 그려 RC 회로라고 적어요.

필요한 개념: [전달 지연과 천이 시간을 구분해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-delay)

왜 이렇게 푸는지 함께 따라가요
용량 전압을 바꾸려면 전하를 넣거나 빼야 해요. 저항을 지나는 전류에는 한계가 있으므로 필요한 전하가 순간에 이동하지 못해요. 입력과 출력의 50% 지점을 찾고 그 시각 차이를 전달 지연이라고 부르면 원인과 측정 정의가 연결돼요.

#### 이상과 현실

이상적인 인버터는 입력이 바뀌는 순간 출력도 바뀌어서 지연이 없어요. 실제 회로에는 다음 단의 입력 용량 같은 capacitive load $C_L$과 켜진 트랜지스터의 저항 $R$이 있어요.

#### 왜 시간이 걸리나

용량의 전압은 순간적으로 바뀌지 못해요. 저항을 거쳐 서서히 충전·방전돼서 출력이 입력을 따라 바뀌는 데 시간이 걸려요.

#### 전달 지연의 정의

입력이 Vcc의 50%를 지나는 때부터 출력이 50%를 지나는 때까지가 전달 지연($t_{PHL}$, $t_{PLH}$)이에요.

#### 그림

![입력이 바뀐 뒤 실제 출력이 지수 곡선으로 서서히 변하고 이상적 출력은 점선으로 바로 뒤집히는 비교](%EC%9E%90%EB%A3%8C/figures/solutions/q-prop-delay-solution-01.svg)

완성 답과 검산
이론상 지연은 없지만 실제로는 capacitive load와 저항이 있어서 용량을 충전·방전하는 데 시간이 걸리기 때문이에요.

입력 50%→출력 50%를 재고, 출력의 10%→90%를 재는 천이 시간과 혼동하지 않았는지 확인해요.

간단한 RC 모델에서 50% 지연은 $0.69\,RC$예요. $R$이나 $C_L$이 0이면 지연도 0이 되어 이상적인 경우와 같아요.

여기서 헷갈리기 쉬워요
“스위치가 느려서”처럼 소자 이름만 쓰는 거예요. 용량과 저항 때문에 충전·방전에 시간이 걸린다는 이유를 적어야 해요.

이제 설명을 닫고 다시 풀어요
- 출력에 부하 용량 CL, 전류 경로에 켜진 저항 R을 그려 RC 회로라고 적어요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 입력 50%→출력 50%를 재고, 출력의 10%→90%를 재는 천이 시간과 혼동하지 않았는지 확인해요.

CL의 유한한 충·방전 때문에 지연이 생겨요. tPLH/tPHL은 입력·출력 50% 시각 차이를 재요.

**시작:** 출력에 부하 용량 CL, 전류 경로에 켜진 저항 R을 그려 RC 회로라고 적어요.

**판단:** 용량 전압을 바꾸려면 전하를 넣거나 빼야 해요. 저항을 지나는 전류에는 한계가 있으므로 필요한 전하가 순간에 이동하지 못해요. 입력과 출력의 50% 지점을 찾고 그 시각 차이를 전달 지연이라고 부르면 원인과 측정 정의가 연결돼요.

**검산:** 입력 50%→출력 50%를 재고, 출력의 10%→90%를 재는 천이 시간과 혼동하지 않았는지 확인해요.

### 문제 12 · 전달 지연과 천이 시간 (묶음)

문제 읽기
#### 문제

CMOS의 전달 지연과 천이 시간에 대해 설명하시오.

(1) 전달 지연(Propagation delay)가 나타나는 이유

(2) 천이 시간(Transition time)이 H->L 일때와 L->H일때 다른 이유

#### 구할 것

(1)과 (2)를 각각 설명하세요.

이 문제에서 할 일
두 소문항은 “왜 늦는가”와 “왜 두 방향 시간이 다른가”를 각각 물어요.

이 문제를 봤을 때 떠올릴 개념과 공식
(1) 전달 지연의 이유와 (2) H→L·L→H 천이 시간 차이라는 두 단서를 각각 읽어요. 지연은 입력과 출력 사이, 천이는 출력 자체의 변화 구간이라는 차이를 떠올려요.

tPLH/tPHL은 입력 50%에서 출력 50%까지예요. tr은 출력 10→90%, tf는 출력 90→10%까지예요. 출력 상승은 Rp로 충전, 하강은 Rn으로 방전해요.

같은 CL와 일정 R의 모델에서는 τp=RpCL, τn=RnCL이 달라 천이 시간도 달라져요. (1)에는 유한한 충·방전, (2)에는 두 경로의 차이를 적용해요. 수치가 없는 정성 설명이며 기존 정답 미확정을 유지해요.

첫 줄을 이렇게 시작해요
(1) 실제 출력에는 R과 CL이 있어 충·방전에 시간이 걸린다고 먼저 쓰고, (2)는 별도 줄로 나눠요.

필요한 개념: [전달 지연과 천이 시간을 구분해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-delay)

왜 이렇게 푸는지 함께 따라가요
H→L 출력은 Rn을 통해 방전하고 L→H는 Rp를 통해 충전해요. 같은 CL이라도 Rn과 Rp가 다르면 RC가 달라져 시간이 달라져요. 이상적인 일정 R·C 모델의 설명이며 실제 소자의 전류·입력 에지·부하 조건도 시간에 영향을 줘요. 이 문제에는 특정 수치가 주어지지 않았어요.

#### (1) 전달 지연

실제 출력에는 용량 $C_L$과 저항 $R$이 있어서 충전·방전에 시간이 걸려요. 입력 50%에서 출력 50%까지가 전달 지연이에요.

#### 두 방향의 길

출력이 H→L로 가면 부하 용량이 $R_n$을 통해 방전돼요. L→H로 가면 $R_p$를 통해 충전돼요.

#### 시간 상수

$R_{n(on)}$과 $R_{p(on)}$이 같지 않으면 시간 상수 $R\cdot C_L$이 달라서 10%에서 90%까지 걸리는 시간이 달라요.

#### 그림

![출력의 하강과 상승 곡선, 50% 지점 사이의 t_PHL, t_PLH 표시](%EC%9E%90%EB%A3%8C/figures/solutions/q-delay-transition-solution-01.svg)

완성 답과 검산
(1) capacitive load와 저항 때문에 충·방전에 시간이 걸려서예요. (2) H→L은 $R_n$으로 방전, L→H는 $R_p$로 충전하고 두 저항이 달라 시간 상수가 다르기 때문이에요.

(1)에 입력/출력 50% 전달 지연, (2)에 출력 10~90% 천이와 서로 다른 R 경로가 들어갔는지 확인해요.

$R_n=R_p$이면 두 시간이 같아야 해요. 이 일정 R·C 모델에서는 저항 차이로 두 시간의 차이를 설명해요.

여기서 헷갈리기 쉬워요
정답 미확정: 제공 자료만으로 채점 의도나 답안 연결을 확정하지 못했어요. 아래는 명시한 이론·해석에 따른 설명이며 확정된 원문 정답이라는 뜻은 아니에요.

(2)에 전달 지연의 이유를 반복해서 쓰는 거예요. (2)는 H→L과 L→H의 “차이”가 이유예요.

이제 설명을 닫고 다시 풀어요
- (1) 실제 출력에는 R과 CL이 있어 충·방전에 시간이 걸린다고 먼저 쓰고, (2)는 별도 줄로 나눠요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- (1)에 입력/출력 50% 전달 지연, (2)에 출력 10~90% 천이와 서로 다른 R 경로가 들어갔는지 확인해요.

(1)은 50% 전달 지연, (2)는 10–90% 천이와 Rp/Rn 경로 차이를 구분해요. 정답 미확정은 유지해요.

**시작:** (1) 실제 출력에는 R과 CL이 있어 충·방전에 시간이 걸린다고 먼저 쓰고, (2)는 별도 줄로 나눠요.

**판단:** H→L 출력은 Rn을 통해 방전하고 L→H는 Rp를 통해 충전해요. 같은 CL이라도 Rn과 Rp가 다르면 RC가 달라져 시간이 달라져요. 이상적인 일정 R·C 모델의 설명이며 실제 소자의 전류·입력 에지·부하 조건도 시간에 영향을 줘요. 이 문제에는 특정 수치가 주어지지 않았어요.

**검산:** (1)에 입력/출력 50% 전달 지연, (2)에 출력 10~90% 천이와 서로 다른 R 경로가 들어갔는지 확인해요.

### 문제 13 · 천이 시간이 H→L과 L→H에서 다른 이유

문제 읽기
#### 문제

CMOS에서 천이시간(Transition time)이 H->L일 때와, L->H일 때 timing 특성이 달라지는 이유를 설명하여라.

#### 구할 것

H→L과 L→H에서 timing 특성이 다른 이유를 설명하세요.

이 문제에서 할 일
같은 출력 용량이 두 방향에서 서로 다른 경로로 충·방전되는 이유를 비교해요.

이 문제를 봤을 때 떠올릴 개념과 공식
H→L과 L→H의 timing 차이라는 말에서 서로 다른 출력 충·방전 경로를 떠올려요. 하강은 Rn, 상승은 Rp가 주된 경로예요.

tf는 출력 90→10%, tr은 10→90% 사이 시간이에요. 같은 CL와 일정 저항의 단순 모델에서 τn=RnCL, τp=RpCL이며 천이는 약 2.2τ에 비례해요.

두 경로의 등가 저항이 다르면 시간이 다르지만 모든 실제 소자에서 같은 비율이 된다는 뜻은 아니에요. 입력 에지·부하 조건도 맞춰야 해요. 이 비교로 방향 차이를 설명하며 채점 답의 미확정 상태는 그대로 두어요.

첫 줄을 이렇게 시작해요
H→L: Rn으로 방전, L→H: Rp로 충전이라고 두 줄을 먼저 써요.

필요한 개념: [전달 지연과 천이 시간을 구분해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-delay)

왜 이렇게 푸는지 함께 따라가요
일정 저항·같은 CL의 단순 모델이면 천이 시간은 약 2.2RC예요. 그러므로 Rp와 Rn이 다르면 시간이 달라져요. 시간을 보고 저항만 역추론할 수 있다는 뜻은 아니에요. 실제 측정에서는 부하 용량·소자 특성·입력 조건도 확인해야 해요.

#### 두 방향의 길

출력이 H→L로 가면 부하 용량이 $R_n$을 통해 방전돼요. L→H로 가면 $R_p$를 통해 충전돼요.

#### 시간 상수

$R_{n(on)}$과 $R_{p(on)}$이 같지 않으면 시간 상수 $R\cdot C_L$이 달라서 10%에서 90%까지 걸리는 시간이 달라요.

#### 그림

![출력의 하강과 상승 곡선, 50% 지점 사이의 t_PHL, t_PLH 표시](%EC%9E%90%EB%A3%8C/figures/solutions/q-transition-solution-01.svg)

완성 답과 검산
H→L은 $R_n$을 거쳐 방전, L→H는 $R_p$를 거쳐 충전하는데 두 저항이 같지 않아서 시간 상수가 다르기 때문이에요.

같은 CL와 동일한 모델에서 Rp=Rn이라고 가정하면 두 천이 시간이 같아지는지 확인해요.

두 저항이 같다고 놓으면 두 시간이 같아져요. 같은 CL의 일정 R·C 모델에서는 저항 차이가 시간 차이를 만들어요.

여기서 헷갈리기 쉬워요
정답 미확정: 제공 자료만으로 채점 의도나 답안 연결을 확정하지 못했어요. 아래는 명시한 이론·해석에 따른 설명이며 확정된 원문 정답이라는 뜻은 아니에요.

입력 파형이 달라서라고 쓰는 거예요. 같은 입력 에지 기울기여도 출력 쪽 저항이 달라서 생기는 차이예요.

이제 설명을 닫고 다시 풀어요
- H→L: Rn으로 방전, L→H: Rp로 충전이라고 두 줄을 먼저 써요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- 같은 CL와 동일한 모델에서 Rp=Rn이라고 가정하면 두 천이 시간이 같아지는지 확인해요.

하강 Rn·상승 Rp의 충·방전 경로와 같은 CL 조건을 비교해요. 천이는 출력 10–90% 기준이에요.

**시작:** H→L: Rn으로 방전, L→H: Rp로 충전이라고 두 줄을 먼저 써요.

**판단:** 일정 저항·같은 CL의 단순 모델이면 천이 시간은 약 2.2RC예요. 그러므로 Rp와 Rn이 다르면 시간이 달라져요. 시간을 보고 저항만 역추론할 수 있다는 뜻은 아니에요. 실제 측정에서는 부하 용량·소자 특성·입력 조건도 확인해야 해요.

**검산:** 같은 CL와 동일한 모델에서 Rp=Rn이라고 가정하면 두 천이 시간이 같아지는지 확인해요.

### 문제 14 · 동작속도를 정하는 두 요소

문제 읽기
#### 문제

COMS의 동작속도를 결정짓는 2가지 요소와 각 요소에 따른 동작속도에 미치는 영향을 timing diagram을 그려 설명하여라.

#### 구할 것

두 요소와 각각의 영향을 timing diagram으로 설명하세요. (원문 표기 COMS를 그대로 옮겼어요.)

이 문제에서 할 일
저항과 용량이 커질 때 출력 파형이 시간축에서 어떻게 늘어나는지 그림과 말로 설명해요.

이 문제를 봤을 때 떠올릴 개념과 공식
동작속도를 정하는 두 요소와 timing diagram이라는 단서에서는 켜진 경로의 저항 R과 부하 용량 CL을 떠올려요. R은 전하 이동을 제한하고 CL은 바꿔야 하는 전하량과 관련돼요.

단순 RC 모델의 τ=RCL에서 R은 Ω, CL은 F, τ는 s예요. 큰 τ이면 출력 50% 도달이 늦고 10–90% 변화도 길어져요. 전달 지연과 천이 시간은 측정 구간이 서로 달라요.

같은 입력 에지·같은 모델로 비교할 때 R이나 CL 증가가 두 시간을 늘려요. 특정 절대 시간이 없는 원문에서는 상대 곡선과 조건을 설명해요. 교안의 CMOS 동작속도·전달 지연·천이 용어를 연결하되 기존 정답 미확정은 유지해요.

첫 줄을 이렇게 시작해요
τ=RCL을 적고 같은 입력 에지에 대해 작은 τ, 큰 τ의 출력 곡선을 나란히 그려요.

필요한 개념: [전달 지연과 천이 시간을 구분해요](%EC%8B%A4%ED%97%9802_%EC%8B%A4%ED%97%98%EC%84%A4%EB%AA%85.md#t-delay)

왜 이렇게 푸는지 함께 따라가요
R은 전하가 이동하는 길의 저항, CL은 바꿔야 할 전하량과 관련된 용량이에요. 같은 조건에서 어느 하나가 두 배면 RC도 두 배라 지연과 천이가 길어져요. 절대 시간 수치가 없으므로 큰 τ 곡선이 더 늦게 50%에 도달하도록 상대 비교를 그려요.

#### 두 요소

켜진 트랜지스터의 저항 $R$($R_p$ 또는 $R_n$)과 출력에 매달린 부하 용량 $C_L$이에요.

#### 영향

출력은 시간 상수 $\tau=R\cdot C_L$로 서서히 변해요. 둘 중 하나라도 크면 $\tau$가 커져서 천이 시간과 전달 지연이 길어지고 동작속도가 느려요. 둘 중 하나라도 작으면 빨라요.

#### timing diagram

![같은 입력에서 R과 C_L의 곱이 작으면 출력이 빨리 올라가고 크면 천천히 올라가는 비교](%EC%9E%90%EB%A3%8C/figures/solutions/q-speed-solution-01.svg)

완성 답과 검산
요소 두 가지는 켜진 저항 $R$과 부하 용량 $C_L$이에요. 곱 $R\cdot C_L$이 클수록 출력이 천천히 변해 동작속도가 느려져요.

RC가 두 배일 때 단순 모델의 50% 지연 0.69RC와 10~90% 천이 2.2RC가 둘 다 두 배인지 확인해요.

간단한 RC 모델에서 50% 지연은 $0.69\,RC$, 10~90%는 약 $2.2\,RC$예요. $R$이나 $C_L$이 두 배면 시간도 두 배예요.

여기서 헷갈리기 쉬워요
정답 미확정: 제공 자료만으로 채점 의도나 답안 연결을 확정하지 못했어요. 아래는 명시한 이론·해석에 따른 설명이며 확정된 원문 정답이라는 뜻은 아니에요.

주파수나 전원 전압 같은 외부 조건만 쓰는 거예요. 문제는 회로 자체가 정하는 두 요소를 물었어요.

이제 설명을 닫고 다시 풀어요
- τ=RCL을 적고 같은 입력 에지에 대해 작은 τ, 큰 τ의 출력 곡선을 나란히 그려요.
- 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
- RC가 두 배일 때 단순 모델의 50% 지연 0.69RC와 10~90% 천이 2.2RC가 둘 다 두 배인지 확인해요.

같은 RC 모델에서 R 또는 CL이 크면 τ=RCL이 커져 지연·천이가 길어져요. 두 측정 기준을 구분해요.

**시작:** τ=RCL을 적고 같은 입력 에지에 대해 작은 τ, 큰 τ의 출력 곡선을 나란히 그려요.

**판단:** R은 전하가 이동하는 길의 저항, CL은 바꿔야 할 전하량과 관련된 용량이에요. 같은 조건에서 어느 하나가 두 배면 RC도 두 배라 지연과 천이가 길어져요. 절대 시간 수치가 없으므로 큰 τ 곡선이 더 늦게 50%에 도달하도록 상대 비교를 그려요.

**검산:** RC가 두 배일 때 단순 모델의 50% 지연 0.69RC와 10~90% 천이 2.2RC가 둘 다 두 배인지 확인해요.

이 문제에서 할 일

저항과 용량이 커질 때 출력 파형이 시간축에서 어떻게 늘어나는지 그림과 말로 설명해요.

이 문제를 봤을 때 떠올릴 개념과 공식

동작속도를 정하는 두 요소와 timing diagram이라는 단서에서는 켜진 경로의 저항 R과 부하 용량 CL을 떠올려요. R은 전하 이동을 제한하고 CL은 바꿔야 하는 전하량과 관련돼요.

단순 RC 모델의 τ=RCL에서 R은 Ω, CL은 F, τ는 s예요. 큰 τ이면 출력 50% 도달이 늦고 10–90% 변화도 길어져요. 전달 지연과 천이 시간은 측정 구간이 서로 달라요.

같은 입력 에지·같은 모델로 비교할 때 R이나 CL 증가가 두 시간을 늘려요. 특정 절대 시간이 없는 원문에서는 상대 곡선과 조건을 설명해요. 교안의 CMOS 동작속도·전달 지연·천이 용어를 연결하되 기존 정답 미확정은 유지해요.

첫 줄을 이렇게 시작해요

τ=RCL을 적고 같은 입력 에지에 대해 작은 τ, 큰 τ의 출력 곡선을 나란히 그려요.

필요한 개념: 전달 지연과 천이 시간을 구분해요

왜 이렇게 푸는지 함께 따라가요

R은 전하가 이동하는 길의 저항, CL은 바꿔야 할 전하량과 관련된 용량이에요. 같은 조건에서 어느 하나가 두 배면 RC도 두 배라 지연과 천이가 길어져요. 절대 시간 수치가 없으므로 큰 τ 곡선이 더 늦게 50%에 도달하도록 상대 비교를 그려요.

두 요소

켜진 트랜지스터의 저항 $R$($R_p$ 또는 $R_n$)과 출력에 매달린 부하 용량 $C_L$이에요.

영향

출력은 시간 상수 $\tau=R\cdot C_L$로 서서히 변해요. 둘 중 하나라도 크면 $\tau$가 커져서 천이 시간과 전달 지연이 길어지고 동작속도가 느려요. 둘 중 하나라도 작으면 빨라요.

완성 답과 검산

요소 두 가지는 켜진 저항 $R$과 부하 용량 $C_L$이에요. 곱 $R\cdot C_L$이 클수록 출력이 천천히 변해 동작속도가 느려져요.

RC가 두 배일 때 단순 모델의 50% 지연 0.69RC와 10~90% 천이 2.2RC가 둘 다 두 배인지 확인해요.

간단한 RC 모델에서 50% 지연은 $0.69\,RC$, 10~90%는 약 $2.2\,RC$예요. $R$이나 $C_L$이 두 배면 시간도 두 배예요.

여기서 헷갈리기 쉬워요

정답 미확정: 제공 자료만으로 채점 의도나 답안 연결을 확정하지 못했어요. 아래는 명시한 이론·해석에 따른 설명이며 확정된 원문 정답이라는 뜻은 아니에요.

주파수나 전원 전압 같은 외부 조건만 쓰는 거예요. 문제는 회로 자체가 정하는 두 요소를 물었어요.

이제 설명을 닫고 다시 풀어요
  1. τ=RCL을 적고 같은 입력 에지에 대해 작은 τ, 큰 τ의 출력 곡선을 나란히 그려요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. RC가 두 배일 때 단순 모델의 50% 지연 0.69RC와 10~90% 천이 2.2RC가 둘 다 두 배인지 확인해요.

같은 RC 모델에서 R 또는 CL이 크면 τ=RCL이 커져 지연·천이가 길어져요. 두 측정 기준을 구분해요.

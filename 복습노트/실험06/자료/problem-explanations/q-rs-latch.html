이 문제를 보면 떠올려요

C=0이면 유지, C=1이면 SR 래치 표

문제 회로에서 C가 앞단 NAND 두 개에 함께 들어가면 C를 Enable로 떠올려요. C=0이면 앞단이 모두 1을 내서 유지되고, C=1일 때만 S·R이 교차 NAND로 전달되기 때문이에요.

이 문제에서 할 일

주어진 R-S 래치 회로(앞단 NAND 2개 + 교차 NAND 2개)를 읽고 S·R·C 조합마다 Q(t)를 채우는 문제예요. C가 Enable 역할이에요.

첫 줄을 이렇게 시작해요

“C=0이면 앞단 NAND 두 개가 모두 1을 내서 Q(t)=Q(t−1)이에요.”라고 마지막 행부터 채워요.

필요한 개념: 실험 1: Enable이 있는 SR 래치

왜 이렇게 푸는지 함께 따라가요

C=1이면 앞단 NAND가 S와 R을 뒤집어 전달해요. 한 행씩 볼게요.

  • S=0, R=0: 앞단 출력이 모두 1 → 교차 NAND가 서로 붙잡아 Q(t−1) 유지.
  • S=0, R=1: 아래 앞단이 (1·1)′=0 → Q′=1 → 위 NAND가 (1·1)′=0 → Q=0, Reset.
  • S=1, R=0: 위 앞단이 0 → Q=1 → 아래 NAND (1·1)′=0 → Q′=0, Set.
  • S=1, R=1: 앞단 출력이 모두 0 → Q=1, Q′=1. 보수 관계가 깨져서 쓰지 않는 상태예요.

01101

완성 답과 검산

00(C=1)→Q(t−1), 01→0(Reset), 10→1(Set), 11→1(이때 Q′도 1, 사용 금지), C=0→Q(t−1)

검산: Set 행에서 Q=1을 되먹여 다시 계산하면 Q′=(1·1)′=0으로 Q′=Q̄가 맞아요. 11 행만 Q=Q′=1이라 금지예요.

여기서 헷갈리기 쉬워요

11 행에 “X”만 쓰면 회로가 실제로 내는 값을 놓쳐요. 자료마다 “1”, “1 (Invalid)”, “−”로 적었는데, 값은 1이고 Q′도 1이라 금지라는 뜻을 함께 써요.

이제 설명을 닫고 다시 풀어요
  1. C=0 행을 먼저 채워요.
  2. C=1에서 앞단 NAND 출력 → Q → Q′ 순서로 네 행을 따라가요.
  3. 11 행에 금지 이유를 덧붙여요.

떠올릴 것: C=0이면 유지, C=1이면 SR 래치 표

시작: “C=0이면 앞단 NAND 두 개가 모두 1을 내서 Q(t)=Q(t−1)이에요.”라고 마지막 행부터 채워요.

판단: C=0이면 유지, C=1이면 S=1→Set, R=1→Reset, 둘 다 0→유지, 둘 다 1→Q=Q′=1 금지예요.

검산: Set 행에서 Q=1을 되먹여 다시 계산하면 Q′=(1·1)′=0으로 Q′=Q̄가 맞아요. 11 행만 Q=Q′=1이라 금지예요.

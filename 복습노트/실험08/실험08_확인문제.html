Q1. 출력 파형의 주파수

카운터의 첫 단은 12 Hz 클럭의 하강 엣지마다 출력 Q를 반전해요. Q의 주파수는 몇 Hz인가요?

  1. 3 Hz
  2. 6 Hz
  3. 12 Hz
  4. 24 Hz
힌트 보기

Q가 같은 방향으로 두 번 연속 바뀌기까지 입력 클럭이 몇 주기 지나는지 세어 봐요.

풀이 보기
  1. "두 단계의 분주를 한 단계에 적용해요." — 출력 주기를 네 배로 늘린 값이에요. 여기서는 첫 단 Q만 봐요.
  2. Q가 한 번 오르고 한 번 내려오는 데 입력 클럭 두 주기가 걸려요.
  3. "반전 횟수를 출력 파형의 주기 수로 봐요." — 엣지마다 Q가 한 번 바뀌지만, 반전 한 번은 출력의 반 주기예요.
  4. "주기와 주파수에 같은 배율을 곱해요." — 반전 두 번이 Q의 한 주기라서 출력 주기는 길어지고 주파수는 낮아져요.

정답: B

  2. 10
  3. 11
  4. 00
힌트 보기

A에는 하강의 결과를, B에는 그 결과가 전달되기 전의 값을 써 봐요.

  3. "두 단의 전파 순서를 뒤집어요." — B만 먼저 반전됐다고 본 값이에요. 둘째 단은 A의 변화를 받은 뒤에 반응해요.

Q4. 디코더 선 하나 읽기

한 AND 게이트에 A와 B′가 들어가요. 카운터 출력이 A=1, B=1로 안정됐을 때 이 게이트의 두 입력과 출력은 각각 무엇인가요? 입력은 (A, B′) 순서예요.

  1. 입력 (1, 0), 출력 0
  2. 입력 (1, 1), 출력 1
  3. 입력 (1, 0), 출력 1
  4. 입력 (0, 1), 출력 0
힌트 보기

B′ 단자 값을 먼저 구한 뒤 두 입력에 AND를 적용해요.

풀이 보기
  1. B=1이면 B′=0이므로 AND 입력 중 하나가 0이에요.
  2. "정출력 B와 반전 출력 B′를 같은 신호로 봐요." — 게이트는 B 대신 B′를 받아요. 둘째 입력은 0이에요.
  3. "AND에 OR 규칙을 적용해요." — AND는 두 입력이 모두 1일 때만 출력이 1이에요.
  4. "반전 표시를 B에서 A로 옮겨 읽어요." — 출력은 우연히 맞지만, A는 정출력 1이고 B′는 반전 출력 0이에요.

정답: A

Q5. 엣지에서 읽는 입력

실험 2의 동기 카운터에서 두 플립플롭은 같은 CLK의 하강 엣지를 받아요. B를 만드는 플립플롭의 J에는 A를, K에는 1을 연결해요. 엣지 직전 A=B=0이고 이 엣지 뒤에 A가 1로 바뀌어요. 이 엣지에서 B는 어느 A 값을 사용하고, 엣지 뒤에 어떤 값으로 안정되나요?

  1. A=1을 사용해 B=0
  2. A=0을 사용해 B=1
  3. A=0을 사용해 B=0
  4. A=1을 사용해 B=1
힌트 보기

B가 J 입력을 읽는 순간과 A 출력이 실제로 바뀌는 순간을 구분해요.

풀이 보기
  1. "J=K=1에서도 B가 유지된다고 봐요." — A=1을 사용했다면 J=K=1로 B가 0에서 1로 반전돼요.
  2. "K=1만으로 반전 조건이 성립한다고 봐요." — 엣지 직전 A=0이라 J=0, K=1이므로 B의 다음 값은 0이에요.
  3. 두 단은 공통 엣지 직전의 입력을 사용해요. B는 J=0, K=1을 받아 0이 돼요.
  4. "같은 공통 엣지에서 앞 단의 새 출력을 읽는다고 봐요." — A=1은 엣지 뒤에 나온 새 값이라 이번 엣지에서 B가 사용한 값은 0이에요.

정답: C

Q6. 시작 상태가 11일 때

동기 3진 카운터가 A=B=1에서 시작해요. A 쪽 J에는 B′, B 쪽 J에는 A가 들어가고, K와 비동기 PR·CLR은 두 단 모두 1이에요. 두 단은 공통 CLK의 하강 엣지에서 동작해요. 두 번째 하강으로 이뤄지는 상태 전이가 끝나면 A가 왼쪽, B가 오른쪽인 두 자리로 답해요.

힌트 보기

각 엣지마다 엣지 직전 상태로 두 J 입력을 다시 정해요.

풀이 보기
  1. 첫 하강 직전에는 J_A=0이라 A가 0이 되고, J_B=1이라 B가 1에서 0으로 반전돼 AB=00이에요.
  2. 둘째 하강 직전에는 J_A=1이라 A가 0에서 1로 반전되고, J_B=0이라 B는 0으로 남아 AB=10이에요.

정답: 10

Q7. 7490의 두 단

7490의 리셋을 모두 해제하고 외부 클럭을 INPUT A에 넣어요. QA를 INPUT B에 잇는 대신 INPUT B를 0에 고정했어요. 정상 동작하는 칩에서 외부 클럭을 계속 넣으면 어떤 출력이 반복해서 바뀌나요?

  1. QB·QC·QD만 바뀌어요.
  2. QA만 바뀌어요.
  3. QA와 QB·QC·QD가 모두 바뀌어요.
  4. QA와 QB·QC·QD가 모두 고정돼요.
힌트 보기

각 부분의 클럭 입력에 엣지가 계속 들어오는지 확인해요.

풀이 보기
  1. "INPUT A와 INPUT B가 구동하는 단을 바꿔 읽어요." — 외부 클럭을 받은 QA가 반전돼요. QB·QC·QD 쪽 클럭은 0에 고정됐어요.
  2. INPUT A가 QA의 2진 단을 구동해요. INPUT B에 엣지가 없어 뒤 단은 진행하지 않아요.
  3. "QA의 엣지가 내부에서 INPUT B로 자동 전달된다고 봐요." — 뒤 단에 클럭을 전달하려면 QA와 INPUT B를 연결해야 해요.
  4. "INPUT B를 0에 고정하면 두 단 모두 정지한다고 봐요." — INPUT A에는 여전히 유효 엣지가 들어오므로 QA의 반전은 계속돼요.

정답: B

Q8. 초기화 입력이 겹칠 때

7490이 정상 세기 중 6을 출력하고 있어요. 외부 클럭을 멈춘 상태에서 R0의 두 입력과 R9의 두 입력을 모두 H로 올렸어요. 신호가 안정된 뒤 7490이 나타내는 십진 값은 무엇인가요?

  1. 0
  2. 6
  3. 7
  4. 9
힌트 보기

R0 쌍과 R9 쌍의 유효 조건을 각각 적용한 뒤 둘이 함께 유효한 행을 찾아봐요.

풀이 보기
  1. "두 요청이 겹칠 때 R0에 우선순위를 둬요." — R0만 유효하면 0이에요. 지금은 R9도 유효하므로 R9가 우선해요.
  2. "초기화도 카운트와 같은 클럭 엣지를 기다린다고 봐요." — 초기화 입력은 클럭 엣지가 없어도 반영돼요.
  3. "초기화 입력의 상승을 카운트 클럭으로 봐요." — 초기화 요청으로 강제 출력이 정해져요. 클럭을 멈춘 동안 카운트가 한 단계 진행하지 않아요.
  4. 두 쌍이 함께 유효하면 R9가 우선하므로 출력은 9로 고정돼요.

Q11. 제어 핀을 바꿨을 때

7447과 공통 애노드 표시기가 정상 연결돼 있어요. DCBA=1000으로 고정하고 LT와 RBI는 H로 유지한 채 BI/RBO 핀을 Blanking Input으로 사용해 L로 당겨요. 표시기의 a~g는 어떻게 되나요?

  1. 8이 그대로 표시돼요.
  2. 0이 표시돼요.
  3. a~g가 모두 꺼져요.
  4. 모두 잠깐 꺼졌다가 8이 다시 표시돼요.
힌트 보기

BCD 입력으로 정한 패턴에 BI의 유효 레벨이 어떤 영향을 주는지 봐요.

풀이 보기
  1. "제어 입력을 무시하고 BCD만 읽어요." — DCBA는 8이지만 BI가 L로 활성화되면 표시가 꺼져요.
  2. "표시를 끄는 기능을 BCD의 0 강제로 봐요." — BI는 카운터나 BCD 입력을 0으로 초기화하지 않아요.
  3. BI를 L로 당기면 입력 숫자와 관계없이 세그먼트 출력이 비활성화돼요.
  4. "BI를 유효 레벨이 유지되는 입력 대신 한 번만 작동하는 엣지 입력으로 봐요." — BI가 L인 동안에는 출력이 계속 비활성 상태예요.

Q12. 막대 두 곳의 배선

공통 애노드 FND에 7447을 연결하다가 d와 e로 가는 두 선만 서로 바꿔 꽂았어요. 각 선에는 330 Ω 저항이 있어요. 원래 7447의 d는 L, e는 비활성 H예요. 잘못 연결된 FND의 실제 d와 e 막대는 어떻게 되나요?

  1. d는 꺼지고 e는 켜져요.
  2. d는 켜지고 e는 꺼져요.
  3. d와 e 모두 켜져요.
  4. d와 e 모두 꺼져요.
힌트 보기

7447에서 나온 d와 e 신호가 각각 어느 막대의 캐소드에 도착하는지 따라가 봐요.

풀이 보기
  1. d 막대는 비활성 e 출력을 받고, e 막대는 L인 d 출력을 받아요.
  2. "신호 이름과 실제 막대 위치를 배선과 무관하게 같다고 봐요." — 정상 배선일 때의 결과예요. 선을 바꿨으므로 L은 e 막대에 도착해요.
  3. "공통 애노드 연결만으로 두 막대가 켜진다고 봐요." — 공통 애노드가 +5 V여도 비활성 H인 출력에 연결된 막대에는 켤 전류가 흐르지 않아요.
  4. "선이 뒤바뀐 상태를 연결이 끊긴 상태로 봐요." — 선이 교차해도 각 출력에서 저항을 거쳐 막대로 가는 경로는 있어요.

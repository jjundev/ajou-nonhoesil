동시 입력 시 일반 인코더의 엉뚱한 코드

문제에 “Priority Encoder”의 “사용이유”가 보이면 D1·D2가 동시에 켜질 때 일반 인코더가 011을 내는 예를 떠올려요. 우선순위 인코더는 순위가 높은 입력 하나만 골라 이 문제를 없애기 때문이에요.

이 문제에서 할 일

우선순위 인코더가 필요한 이유를 여러 요청이 동시에 들어오는 작은 예로 설명해요.

첫 줄을 이렇게 시작해요

D1과 D2를 동시에 켠다고 적고 일반 인코더에서는 코드 011이 나오는 예를 써요.

필요한 개념: 우선순위 인코더와 74HC148을 배워요 · 인코더는 켜진 줄의 번호를 코드로 바꿔요

왜 이렇게 푸는지 함께 따라가요

일반 인코더는 입력 하나만 활성이라고 가정하므로 다중 입력을 한 번호로 확실히 구분하지 못해요. 우선순위 인코더는 정해진 순위로 한 요청을 고른 뒤 그 번호를 내보내요. 나머지 요청 정보를 모두 출력한다는 뜻은 아니에요.

풀이

일반 인코더는 한 번에 하나의 입력만 켜진다고 가정해요. 8×3 일반 인코더에서 D1과 D2가 동시에 켜지면 출력이 011(=3)이 되어 1도 2도 아닌 값이 나와요. 우선순위 인코더는 동시에 켜진 입력 중 우선순위가 높은 입력의 코드만 내보내서 이 문제를 없애요.

완성 답과 검산

여러 입력이 동시에 활성일 때 우선순위가 높은 입력 하나를 선택해 올바른 코드를 내기 위해 써요.

번호 큰 쪽 우선이면 D2가 이겨 010이 나오고 동시에 켜진 입력의 코드를 OR로 합치지 않는지 확인해요.

검산: A1=D2+D3+D6+D7=1, A0=D1+D3+D5+D7=1, A2=0이라서 011이에요.

여기서 헷갈리기 쉬워요

흔한 실수: 우선순위 인코더가 입력 개수를 줄여 주는 회로라고 쓰면 안 돼요. 동시 입력의 충돌을 해결해요.

이제 설명을 닫고 다시 풀어요
  1. D1과 D2를 동시에 켠다고 적고 일반 인코더에서는 코드 011이 나오는 예를 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 번호 큰 쪽 우선이면 D2가 이겨 010이 나오고 동시에 켜진 입력의 코드를 OR로 합치지 않는지 확인해요.

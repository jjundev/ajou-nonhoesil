이 문제에서 할 일

one-hot 입력선 여덟 개에 대한 위치 코드의 대응표를 만들어요.

첫 줄을 이렇게 시작해요

표의 첫 행 D0만 1을 쓰고 출력 A2A1A0=000을 적어요.

필요한 개념: 인코더는 켜진 줄의 번호를 코드로 바꿔요

왜 이렇게 푸는지 함께 따라가요

번호가 4 이상인 D4~D7에서는 4의 자리 A2가 1이에요. 2의 자리 A1은 D2,D3,D6,D7에서, 1의 자리 A0는 홀수 번호에서 1이에요. 각 출력 비트의 1인 행을 모으면 해당 입력들의 OR식을 만들 수 있어요.

풀이

D0이 1이면 000, D1이 1이면 001, … D7이 1이면 111이에요.

완성한 표

D7D6D5D4D3D2D1D0A2A1A0
00000001000
00000010001
00000100010
00001000011
00010000100
00100000101
01000000110
10000000111

식

$$A_2=D_4+D_5+D_6+D_7,\ A_1=D_2+D_3+D_6+D_7,\ A_0=D_1+D_3+D_5+D_7$$

완성 답과 검산

Dk만 1이면 A2A1A0는 k의 3비트 이진수예요 (D0→000, …, D7→111).

D6만 1일 때 A2=1,A1=1,A0=0으로 110인지 확인하고 모든 행에 입력 1이 하나인지 확인해요.

검산: 각 출력 비트가 1인 행의 입력 번호들이 위 OR 식에 들어 있어요.

여기서 헷갈리기 쉬워요

흔한 실수: 한 줄만 켜진 여덟 행만 정해진 표예요. 두 줄 이상이 켜진 입력은 이 표가 정하지 않아요.

이제 설명을 닫고 다시 풀어요
  1. 표의 첫 행 D0만 1을 쓰고 출력 A2A1A0=000을 적어요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. D6만 1일 때 A2=1,A1=1,A0=0으로 110인지 확인하고 모든 행에 입력 1이 하나인지 확인해요.

시작: 표의 첫 행 D0만 1을 쓰고 출력 A2A1A0=000을 적어요.

판단: 번호가 4 이상인 D4~D7에서는 4의 자리 A2가 1이에요. 2의 자리 A1은 D2,D3,D6,D7에서, 1의 자리 A0는 홀수 번호에서 1이에요. 각 출력 비트의 1인 행을 모으면 해당 입력들의 OR식을 만들 수 있어요.

검산: D6만 1일 때 A2=1,A1=1,A0=0으로 110인지 확인하고 모든 행에 입력 1이 하나인지 확인해요.

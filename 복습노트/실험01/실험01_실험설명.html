실험 이해

왜 이 회로를 쓰는지 먼저 알아봐요

이해를 위한 예시 · 회로가 해결하는 문제

이해를 위한 예시로, 문이 닫혀 있고 시작 버튼도 눌렸을 때만 장치를 작동시키고 싶다고 해 봐요. 문 상태 A와 버튼 상태 B를 각각 0(조건을 만족하지 않음), 1(조건을 만족함)로 나타내면 두 조건을 함께 판단해야 해요.

스위치 상태를 따로 읽는 것만으로는 “둘 다 만족할 때만 작동”이라는 규칙이 만들어지지 않아요. 논리 게이트는 입력의 0과 1을 받아 정해진 규칙에 맞는 출력으로 바꿔요. AND는 모든 조건을 만족할 때, OR는 하나라도 만족할 때 1을 내보내요.

A=1, B=0이면 AND 출력은 0이라 작동 조건을 만족하지 않아요. B도 1로 바꾸면 출력이 1이 돼요. 이 예시는 논리 판단을 설명하는 것이며 실제 장치 구동 회로를 만드는 실험은 아니에요.

이번 실험에서는 5V와 GND로 입력을 바꾸고 LED로 출력 논리값을 확인해요. AND·OR·NAND·NOR를 비교한 뒤 여러 게이트를 이어 붙여, 원하는 조건을 부울식과 회로로 만드는 연습을 해요.

이번 실험에서 하는 일

교안은 신호 값을 이렇게 정해요. Low(L)는 논리값 0이고 물리값은 GND를 걸어 0V예요. High(H)는 논리값 1이고 물리값은 3~5V예요. 이번 실험에서는 5V 전압원과 GND를 입력에 번갈아 걸어요.

실험만드는 것쓰는 IC
1-13입력 AND (L1=A·B, L2=A·B·C)74HC08 두 개
1-23입력 OR (L1=A+B, L2=A+B+C)74HC32 두 개
2-13입력 NAND (L2=(A·B·C)′)74HC08, 74HC00
2-23입력 NOR (L2=(A+B+C)′)74HC32, 74HC02
3출력 X, Y, Z를 내는 회로74HC04, 74HC08, 74HC32

준비물은 5V 전압원, IC(74HC00, 02, 04, 08, 32, 86), LED 3개, 330Ω 저항 3개예요. 출력 선마다 LED와 330Ω 저항을 달아서 출력이 1인지 0인지 눈으로 확인해요.

이 팩이 다루는 범위

74HC86(XOR)은 준비물에 적혀 있지만 위 다섯 회로에는 쓰이지 않아요. 기출은 진리표, 부울식, 드모르간, NAND만으로 만들기, CMOS까지 나와서 교안에 없는 내용은 보충이라고 표시해 둘게요. LED가 켜지는 것은 출력이 1일 때로 읽지만, 실제로는 결선 방향에도 달려 있어요.

게이트는 여러 입력 조건을 함께 판단해 원하는 출력 규칙을 만들어요. H는 1(3~5V), L은 0(GND)이고 AND·OR·NAND·NOR와 X·Y·Z 회로를 확인해요. 74HC86은 준비물이지만 이번 다섯 회로에는 쓰이지 않아요. 교안 밖 기출 개념은 보충으로 구별하고, LED 켜짐과 논리값의 대응은 실제 결선 방향도 확인해요.

게이트 여섯 개와 진리표를 읽어요

게이트마다 말하는 규칙이 달라요

NOT은 뒤집어요. AND는 “전부 1이어야 1”이라고 말해요. OR는 “하나라도 1이면 1”이에요. XOR는 “서로 다를 때만 1”이에요. NAND와 NOR는 AND, OR의 결과를 한 번 뒤집은 게이트예요.

기호와 진리표를 읽어 봐요

A·B는 AND, A+B는 OR, A′나 윗줄은 NOT, A⊕B는 XOR예요. 여기의 +는 덧셈이 아니라서 1+1=1이에요. 진리표의 한 행은 입력을 동시에 정했을 때의 출력이에요. 예를 들어 A=1, B=0인 행에서 AND는 0, OR는 1이에요.

기호 모양도 읽을 수 있어야 해요. AND는 반원 모양이고, OR는 뾰족한 방패 모양이에요. XOR는 OR 모양에 입력 쪽 곡선이 하나 더 있어요. 출력에 작은 원이 붙으면 반전이라서 AND 모양에 원이 붙으면 NAND, OR 모양에 원이 붙으면 NOR예요.

교안은 0 대신 L, 1 대신 H로 적어요. 같은 표예요. 입력이 3개이면 2³=8가지 조합이 있고, 3입력 게이트는 이렇게 읽어요.

3입력 AND는 A·B·C, 3입력 OR는 A+B+C, 3입력 NAND는 (A·B·C)′, 3입력 NOR는 (A+B+C)′예요. 3입력 XOR는 1이 홀수 개일 때 1이에요.

XOR와 OR, NAND와 NOR를 섞지 않아요

XOR는 A=B=1일 때 0이지만 OR는 1이에요. 3입력 XOR에서 1이 두 개면 0이고, 셋이면 1이에요. NOR는 “전부 0일 때만 1”이고, NAND는 “전부 1일 때만 0”이에요.

한 단계만 풀어 봐요

A=1, B=1, C=0일 때 AND, OR, NOR, XOR의 출력을 구해 봐요.

힌트

1의 개수를 먼저 세요. XOR는 1의 개수가 홀수인지 봐요.

연습 답

AND는 0, OR는 1, NOR는 0, XOR는 0이에요. 1이 두 개라서 XOR는 짝수 개가 되어 0이에요.

NOT은 0과 1을 뒤집고, AND는 전부 1일 때·OR는 하나라도 1일 때 1이에요. NAND·NOR는 AND·OR의 반대예요. +는 산술 덧셈이 아닌 OR이고 출력의 작은 원은 반전이에요. 진리표 한 행은 같은 입력 조합의 출력을 뜻하며 3입력은 8행이에요. XOR는 1이 홀수 개일 때 1이므로 두 입력이 모두 1이면 OR는 1·XOR는 0이고, 3입력 111에서는 XOR가 1이에요.

부울대수와 드모르간 법칙을 익혀요

0과 1만 쓰는 계산 규칙이에요

부울대수는 식을 더 짧게 바꾸는 규칙 모음이에요. 규칙을 쓰면 게이트 수를 줄이거나 식을 다른 모양으로 바꿀 수 있어요. 드모르간은 “윗줄을 쪼갤 때 AND와 OR를 서로 바꾼다”는 규칙이에요.

자주 쓰는 규칙과 드모르간

X, Y, Z는 0 또는 1인 변수예요. 이 자리에 식 덩어리를 통째로 넣어도 돼요. 예를 들어 X·Y+X·Y′=X에서 Y 자리에 (W·Z)를 넣으면 X·(W·Z)+X·(W·Z)′=X예요. 윗줄과 ′는 NOT이에요.

이름합(OR) 꼴곱(AND) 꼴
항등X+0 = XX·1 = X
지배X+1 = 1X·0 = 0
멱등X+X = XX·X = X
보수X+X′ = 1X·X′ = 0
이중부정(X′)′ = X
분배X·Y+X·Z = X·(Y+Z)(X+Y)·(X+Z) = X+Y·Z
흡수X+X·Y = XX·(X+Y) = X
묶기(Combining)X·Y+X·Y′ = X(X+Y)·(X+Y′) = X

드모르간 법칙은 식 전체를 덮은 윗줄을 안으로 넣는 규칙이에요.

$$\overline{X_1\cdot X_2\cdots X_n}=\overline{X_1}+\overline{X_2}+\cdots+\overline{X_n}$$

$$\overline{X_1+X_2+\cdots+X_n}=\overline{X_1}\cdot\overline{X_2}\cdots\overline{X_n}$$

윗줄을 쪼개면 안에 있는 AND는 OR로, OR는 AND로 바뀌고 각 변수에는 윗줄이 붙어요. 교안은 NAND와 NOR를 이 법칙으로 소개해요. 예를 들어 (A·B)′ = A′+B′, (A+B)′ = A′·B′예요.

예제로 (A′·B + C)′를 전개해 볼게요. 먼저 전체 윗줄을 쪼개면 (A′·B)′ · C′이 돼요. 이어서 (A′·B)′ = A+B′이므로 결과는 (A+B′)·C′이에요. 값을 넣어 확인할게요. A=1, B=0, C=0이면 원래 식은 (0·0+0)′=1이고 결과는 (1+1)·1=1이에요. A=0, B=1, C=0이면 원래 식은 (1·1+0)′=0이고 결과는 (0+0)·1=0이에요. 두 경우 모두 같아요.

단순화 예제도 하나 볼게요. X·Y+X·Y′는 X로 묶으면 X·(Y+Y′)=X·1=X예요. 이때 Y가 0이든 1이든 X만 남아요.

윗줄이 어디까지 덮는지 확인해요

(A·B)′와 A′·B′는 달라요. A=1, B=0이면 (A·B)′=1이지만 A′·B′=0·1=0이에요. 윗줄이 식 전체를 덮는지 일부만 덮는지에 따라 답이 달라지니 괄호를 먼저 살펴요.

한 단계만 풀어 봐요

(A′+B)′를 드모르간으로 전개해 봐요.

힌트

윗줄을 쪼개면 +가 ·로 바뀌어요. A′에 윗줄이 이미 있으니 이중부정도 써요.

연습 답

(A′+B)′ = (A′)′·B′ = A·B′이에요. A=1, B=0일 때만 1이에요.

부울대수는 0/1 식의 구조를 바꾸는 규칙이며 변수 자리에 식 덩어리도 넣을 수 있어요. 드모르간은 묶음 전체의 보수를 쪼개면서 AND↔OR를 바꾸고 각 항도 보수해요. (AB)′=A′+B′, (A+B)′=A′B′이며 (A′)′=A예요. X·Y+X·Y′=X·(Y+Y′)=X로 줄여요. (AB)′와 A′B′는 다르므로 윗줄이 덮는 괄호 범위를 먼저 확인해요.

회로를 읽고 식을 회로로 그려요

회로를 읽는 건 길을 따라가는 일이에요

입력에서 출발해 게이트를 지날 때마다 이름을 붙이며 식을 써요. 반대로 식을 그릴 때는 가장 마지막에 일어나는 연산이 출력 쪽 게이트가 돼요.

회로를 읽는 순서와 그리는 순서

선이 만나는 곳에 점이 있으면 연결이고, 점 없이 교차하면 연결이 아니에요. 게이트 출력의 작은 원은 NOT이 붙어 있다는 뜻이에요. 같은 이름의 선은 같은 신호예요.

읽는 순서는 입력에 가까운 게이트부터예요. 각 게이트의 출력에 이름(D, E, Z 등)을 붙이고, 그 이름을 다음 게이트의 식에 넣어요. 실험 3 회로로 해 볼게요.

A를 NOT에 넣으면 A′, 그것과 B를 AND하면 A′·B예요. 이것을 한 번 더 NOT하면 Z=(A′·B)′예요. 드모르간을 쓰면 Z=A+B′예요. X는 A와 Z의 OR라서 X=A+Z=A+A+B′=A+B′이고, Y는 A와 B를 바로 OR해서 Y=A+B예요.

식에서 회로로 갈 때 “변형 없이 그리라”는 말은 식을 줄이지 않고 적힌 연산을 그대로 게이트로 만들라는 뜻이에요. 식의 바깥 연산이 출력 게이트이고, 괄호 안쪽 연산이 앞쪽 게이트예요. 윗줄이 괄호 하나만 덮었다면 그 괄호의 결과에만 NOT이나 반전 게이트가 붙어요.

교차와 분기를 구분해요

같은 입력이 여러 게이트로 갈 때는 분기점에 점이 있어요. 점이 없는 교차를 연결로 읽으면 식이 완전히 달라져요. 기출의 D, E, Q 문제에서도 B에서 갈라지는 점이 핵심이에요.

한 단계만 풀어 봐요

실험 3 회로에서 A=0, B=1일 때 Z, X, Y 값을 구해 봐요.

힌트

Z=A+B′부터 구하고, 그 값으로 X를 구해요.

연습 답

Z=0+0=0이에요. X=A+Z=0이고, Y=A+B=1이에요.

회로는 입력에서 출력으로 게이트마다 중간 신호 이름을 붙이며 읽어요. 실험 3은 Z=(A′B)′=A+B′, X=A+Z=A+B′, Y=A+B예요. 접속점이 있는 분기와 점 없는 교차를 구별해요. 식을 그릴 땐 바깥 연산이 출력 게이트이고, “변형 없이”는 식을 줄이지 않고 보수·괄호의 연산 구조를 그대로 옮기는 조건이에요.

NAND로 다른 게이트를 만들어요

NAND 하나로 다 만들 수 있어요

NAND만 잔뜩 있어도 NOT, AND, OR를 모두 만들 수 있어요. 그래서 NAND를 만능 게이트라고 불러요. 시험에서는 “NAND만으로 XOR를 구성하라”처럼 나와요.

NAND로 기본 게이트를 만들어요

NAND의 두 입력을 묶으면 (A·A)′=A′이라서 NOT이 돼요. NAND 뒤에 이 NOT을 붙이면 ((A·B)′)′=A·B라서 AND예요. OR는 A+B=(A′·B′)′이므로 입력마다 NOT을 붙인 뒤 NAND하면 돼요.

XOR는 A⊕B = A′B + AB′예요. NAND 네 개로 이렇게 만들 수 있어요. N1=(A·B)′, N2=(A·N1)′, N3=(B·N1)′, 출력 C=(N2·N3)′예요.

N2=(A·(AB)′)′=A′+AB=A′+B이고, N3=(B·(AB)′)′=B′+AB=A+B′예요. 출력은 C=(N2·N3)′=(A′+B)′+(A+B′)′=A·B′+A′·B예요. 행마다 확인하면 L L→L, L H→H, H L→H, H H→L이에요.

3입력 게이트도 2입력 부품으로 만들어요. 3입력 AND는 (A·B)·C라서 AND 두 개로 충분해요. 3입력 NAND는 (A·B·C)′이므로 먼저 A·B를 AND로 만들고 그 결과와 C를 NAND에 넣어요. 3입력 NOR는 (A+B+C)′이므로 OR 두 개로 A+B+C를 만든 뒤 NOT을 붙여요. 실험 2-1, 2-2가 바로 이 구성이에요.

NAND를 두 번 쓰는 실수를 조심해요

3입력 NAND를 NAND(NAND(A,B),C)로 만들면 안 돼요. ((A·B)′·C)′ = A·B+C′이라서 (A·B·C)′와 달라요. 첫 단계는 반드시 AND여야 해요. 2-1 회로가 74HC08(AND)과 74HC00(NAND)을 쓰는 이유예요.

한 단계만 풀어 봐요

NAND만으로 AND 한 개를 만들려면 NAND가 몇 개 필요한지 말해 봐요.

힌트

NAND 뒤에 NOT이 필요하고, NOT도 NAND로 만들어요.

연습 답

두 개예요. 첫 NAND가 (A·B)′를 만들고, 둘째 NAND는 입력을 묶어 NOT 역할을 해서 A·B를 만들어요.

NAND의 입력 둘을 묶으면 NOT, NAND 뒤에 NOT을 붙이면 AND, 두 입력을 각각 NOT한 뒤 NAND하면 OR가 돼요. XOR는 공유 N1=(AB)′를 A·B와 각각 NAND한 뒤 마지막 NAND로 합치는 4개 구성으로 만들어요. 3입력 NAND는 먼저 AND로 AB를 만들고 C와 NAND해요. NAND를 두 번 잇는 ((AB)′C)′는 AB+C′이므로 (ABC)′와 달라요.

CMOS NAND와 Pull-up을 살펴봐요 (보충)

스위치 두 줄이 번갈아 켜져요

CMOS 게이트는 출력을 위쪽 전원(VDD, 1) 또는 아래쪽 GND(0)에 연결하는 스위치로 만들어요. 위쪽 스위치가 켜지면 출력이 1이고, 아래쪽이 켜지면 0이에요. 둘이 동시에 켜지지 않게 설계해요.

PMOS와 NMOS 읽기 (보충)

이 내용은 현재 교안에는 없고 기출(CMOS 3-input NAND)에 필요한 보충이에요. NMOS는 게이트에 1을 주면 켜져서 도통하고, 게이트에 작은 원이 붙은 PMOS는 0을 주면 켜져요. PMOS는 VDD 쪽에, NMOS는 GND 쪽에 둬요.

3입력 NAND는 A, B, C가 모두 1일 때만 출력이 0이에요. “모두 1이어야 켜진다”는 직렬 연결이라서 NMOS 셋을 직렬로 놓아요. “하나라도 0이면 출력이 1”은 병렬이라서 PMOS 셋을 병렬로 놓아요.

입력트랜지스터 상태출력
ABC켜진 PMOSNMOS 경로Z
000P1 P2 P3끊김1
001P1 P2끊김1
010P1 P3끊김1
011P1끊김1
100P2 P3끊김1
101P2끊김1
110P3끊김1
111없음연결됨0

그리는 순서는 이래요. 먼저 VDD와 출력 사이에 PMOS 셋을 나란히 병렬로 놓고, 출력 노드에서 아래로 NMOS 셋을 직렬로 이어 GND에 연결해요. 그다음 A는 첫 PMOS와 첫 NMOS의 게이트에, B와 C도 각각 PMOS와 NMOS 한 쌍의 게이트에 같이 연결해요.

같은 방법으로 NOR는 PMOS를 직렬, NMOS를 병렬로 놓으면 돼요.

PMOS와 NMOS 위치를 바꾸지 않아요

작은 원이 있는 쪽이 PMOS이고 VDD에 붙어요. NMOS는 GND에 붙어요. 또 NAND에서는 NMOS가 직렬이고 PMOS가 병렬이라서 NOR와 반대예요.

보충: Pull-up 저항

입력이나 출력 선이 아무 데도 연결되지 않으면 값이 정해지지 않는 floating 상태가 돼요. Pull-up 저항은 그런 선을 저항으로 전원 쪽(Vcc)에 이어서 평소에는 High를 유지하게 하는 저항이에요. 서술형 한 줄짜리 개념이라서 문제 카드로는 따로 수록하지 않았어요.

교안 밖 기출을 위한 보충이에요. CMOS NAND3은 PMOS 3개를 병렬로 VDD와 출력 사이에, NMOS 3개를 직렬로 출력과 GND 사이에 놓아요. PMOS는 입력 0·NMOS는 1에서 켜지고, 각 입력은 위아래 한 쌍의 게이트에 연결해 모두 1일 때만 출력이 0이에요. NOR는 두 연결 방식이 반대예요. 별도 보충인 Pull-up 저항은 floating 선을 저항으로 Vcc에 이어 평소 High를 유지하게 해요.

실험 1-1부터 3까지 확인해요

예상 진리표를 먼저 쓰고 LED로 맞춰 봐요

교안은 “INPUT에 5V와 GND를 번갈아 인가하며 Output의 변화가 예상 결과 Truth Table과 일치하는지 확인한다”고 적어요. 그래서 실험 전에 예상 표를 써 두고, 8가지 입력을 하나씩 걸어 L1, L2의 LED와 비교해요. 아래는 이론에서 계산한 예상값이에요. 실제 측정값은 기록이 없어서 적지 않았어요.

실험 1-1) 3입력 AND (74HC08 두 개)

주어진 회로를 구성하고 L1, L2에 330Ω 저항과 LED를 달아요. 첫 AND는 A·B를 L1로 내고, 같은 선이 둘째 AND로 들어가 C와 만나 L2=A·B·C를 내요.

입력출력
ABCL1L2
00000
00100
01000
01100
10000
10100
11010
11111

L2가 1인 것은 A=B=C=1일 때뿐이에요.

실험 1-2) 3입력 OR (74HC32 두 개)

구성은 1-1과 같고 게이트만 OR로 바뀌어요. L1=A+B, L2=A+B+C예요.

입력출력
ABCL1L2
00000
00101
01011
01111
10011
10111
11011
11111

L2가 0인 것은 A=B=C=0일 때뿐이에요.

실험 2-1) 3입력 NAND (74HC08 + 74HC00)

첫 게이트는 AND라서 L1=A·B예요. 둘째 게이트가 NAND라서 L2=(A·B·C)′예요.

입력출력
ABCL1L2
00001
00101
01001
01101
10001
10101
11011
11110

L2는 A=B=C=1일 때만 0이에요.

실험 2-2) 3입력 NOR (74HC32 + 74HC02)

첫 게이트는 OR라서 L1=A+B이고, 둘째 게이트가 NOR라서 L2=(A+B+C)′예요.

입력출력
ABCL1L2
00001
00100
01010
01110
10010
10110
11010
11110

L2는 A=B=C=0일 때만 1이에요.

실험 3) X, Y, Z 회로

X, Y, Z에 330Ω 저항과 LED를 달고 A, B에 5V와 GND를 번갈아 걸어요. 회로 읽기에서 구한 대로 Z=A+B′, X=A+B′, Y=A+B예요.

입력출력
ABXYZ
00101
01010
10111
11111

X와 Z의 값이 같다는 것도 확인 포인트예요. 둘 다 A+B′라서 항상 같아야 해요.

다이오드(LED)에는 330Ω 저항이 꼭 필요해요

교안이 LED를 연결할 때 330Ω 저항이 필수라고 강조해요. 저항 없이 5V를 걸면 LED에 전류가 크게 흘러 손상될 수 있어서예요. 74HC IC의 전원 핀 연결은 교안 그림에 없어서 이 팩에서는 핀 번호를 적지 않았어요.

아래 표는 이론 예상값이며 실제 측정 기록이 아니에요. ABC 8가지마다 L1·L2를 비교해요. AND·NAND 회로의 L1=AB, OR·NOR 회로의 L1=A+B이고, L2는 각각 ABC·A+B+C·(ABC)′·(A+B+C)′예요. 실험 3은 AB 4가지에서 X=Z=A+B′와 Y=A+B를 확인해요. LED마다 330Ω 저항이 필요하고, 전원 핀 번호는 교안 그림에 없어 이 팩에서 제시하지 않아요.

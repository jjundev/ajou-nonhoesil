문제 1 · 3입력 게이트 진리표 (4행)

문제 읽기

문제

다음 3 Input Logic Gate의 진리표를 완성하시오.(0 = low, 1 = high)

주어진 조건

입력출력
ABCAND 출력OR 출력NOR 출력XOR 출력
000
001
101
111

구할 것

빈칸 네 열을 모두 채우세요. 원문은 입력 4행만 제시해요.

이 문제에서 할 일

세 입력의 상태를 보고 네 종류 게이트의 출력 칸을 채우는 문제예요. 행 하나를 독립적인 상황으로 읽어요.

이 문제를 봤을 때 떠올릴 개념과 공식

AND는 모두 1, OR는 하나라도 1, XOR는 1이 홀수 개

문제에 “3 Input Logic Gate의 진리표”가 보이면 세 게이트 규칙을 행마다 따로 떠올려요. 3입력 XOR는 1이 홀수 개일 때만 1이라서 1이 두 개인 101은 0이기 때문이에요.

“3 Input Logic Gate”와 A·B·C가 적힌 네 행은 진리표를 채우라는 단서예요. 진리표는 각 입력 조합에 대한 출력을 나란히 기록한 표이고, 여기서는 0=low, 1=high예요. A·B·C는 입력 세 개이며 AND·OR·NOR·XOR 열은 같은 입력을 받은 서로 다른 게이트의 출력이에요.

AND의 곱 ABC는 모두 1일 때만 1, OR의 합 A+B+C는 하나라도 1이면 1이에요. NOR는 (A+B+C)′로 OR 출력을 뒤집어요. ′는 0과 1을 바꾸는 보수이고 +는 산술 덧셈이 아니라 OR예요. 3입력 XOR A⊕B⊕C는 순서대로 XOR하여 1의 개수가 홀수일 때 1이에요.

이 규칙은 0/1 논리값을 계산하는 조건에서 써요. 원문에 주어진 ABC=000·001·101·111만 읽고 다른 행을 추가하지 않아요. 특히 101처럼 1이 두 개인 행을 XOR=0으로 구별하려고 홀짝 규칙을 떠올려요.

첫 줄을 이렇게 시작해요

첫 행 000에서 A=0, B=0, C=0을 적고, 1의 개수가 0개라고 표시해요.

필요한 개념: 게이트 여섯 개와 진리표를 읽어요

왜 이렇게 푸는지 함께 따라가요

AND는 모두 1이어야 하고, OR는 하나라도 1이면 돼요. NOR는 OR를 뒤집어요. XOR는 1이 홀수 개일 때 1이에요. 101은 1이 두 개여서 AND 0, OR 1, NOR 0, XOR 0이 돼요.

풀이

각 행을 따로 계산해요. 000은 1이 0개라서 AND 0, OR 0, NOR 1, XOR 0이에요. 001과 101은 각각 1이 1개, 2개예요.

표로 정리

입력출력
ABCAND 출력OR 출력NOR 출력XOR 출력
0000010
0010101
1010100
1111101
완성 답과 검산

표의 AND, OR, NOR, XOR 열은 000→0,0,1,0 / 001→0,1,0,1 / 101→0,1,0,0 / 111→1,1,0,1이에요.

111을 다시 넣어 AND·OR·NOR·XOR가 각각 1·1·0·1인지 확인해요.

검산: AND 열의 1은 A=B=C=1 행뿐이에요. OR 열의 0은 A=B=C=0 행뿐이에요. NOR 열은 OR 열을 뒤집은 값이에요. XOR 열은 각 행의 1 개수가 홀수인지로 다시 세요.

여기서 헷갈리기 쉬워요

흔한 실수: 3입력 XOR를 “둘 이상 다르면 1” 같은 2입력 규칙으로 읽는 거예요. 1이 두 개인 행(011, 101, 110)은 0이고, 셋인 행(111)은 1이에요.

이제 설명을 닫고 다시 풀어요
  1. 첫 행 000에서 A=0, B=0, C=0을 적고, 1의 개수가 0개라고 표시해요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 111을 다시 넣어 AND·OR·NOR·XOR가 각각 1·1·0·1인지 확인해요.

떠올릴 것: AND는 모두 1, OR는 하나라도 1, XOR는 1이 홀수 개

핵심 개념: ABC를 입력 순서로 읽어요. AND는 모두 1, OR는 하나라도 1, NOR는 OR의 보수, 3입력 XOR는 1이 홀수 개일 때 1이에요. 지정된 네 행만 채워요.

시작: 첫 행 000에서 A=0, B=0, C=0을 적고, 1의 개수가 0개라고 표시해요.

판단: AND는 모두 1이어야 하고, OR는 하나라도 1이면 돼요. NOR는 OR를 뒤집어요. XOR는 1이 홀수 개일 때 1이에요. 101은 1이 두 개여서 AND 0, OR 1, NOR 0, XOR 0이 돼요.

검산: 111을 다시 넣어 AND·OR·NOR·XOR가 각각 1·1·0·1인지 확인해요.

문제

다음 진리표를 완성하시오. (3 input, 0 = low, 1 = high)

주어진 조건

입력출력
ABCAND 출력OR 출력NOR 출력XOR 출력
000
001
010
011
100

구할 것

여덟 행의 AND, OR, NOR, XOR 출력을 모두 채우세요.

이 문제에서 할 일

000부터 111까지 여덟 상황을 빠짐없이 계산해 네 출력 열을 채워요.

이 문제를 봤을 때 떠올릴 개념과 공식

같은 입력 행을 각 게이트가 따로 받기, XOR는 1이 홀수 개

문제에 “3 input” 진리표의 AND·OR·NOR·XOR 열이 보이면 각 게이트가 같은 행을 따로 받는다는 걸 떠올려요. 앞 열 출력을 뒤 게이트에 넣는 표가 아니고, XOR는 1의 개수가 홀수인지로만 정해지기 때문이에요.

A·B·C와 000부터 111까지 빈 출력 칸이 보이면 모든 입력 조합의 진리표를 떠올려요. 입력마다 0과 1 두 선택이 있으므로 세 입력은 2³=8가지예요. ABC 순서에서 A를 왼쪽, C를 오른쪽에 두고 원문 행 순서를 유지해요.

곱 ABC는 AND, 합 A+B+C는 OR, (A+B+C)′는 NOR예요. 곱은 모두 1일 때, 합은 하나라도 1일 때 1이고 ′는 결과를 뒤집어요. A⊕B⊕C는 1의 개수가 홀수일 때 1인 XOR예요. 각 출력 열은 앞 열의 결과가 아니라 같은 A·B·C를 받아요.

논리값 0/1로 계산하며 여덟 조합을 빠짐없이 한 번씩 다룰 때 이 표가 완성돼요. 3입력 XOR에는 두 입력의 “서로 다름”만 적용하지 말고 홀짝을 세어요. 이 기준으로 네 열을 각 행마다 독립적으로 채워요.

첫 줄을 이렇게 시작해요

000 행에 AND=0, OR=0을 먼저 쓰고 NOR=1, XOR=0을 이어 써요.

필요한 개념: 게이트 여섯 개와 진리표를 읽어요

왜 이렇게 푸는지 함께 따라가요

각 게이트는 같은 입력 행을 서로 독립적으로 받아요. 앞 열의 출력을 뒤 게이트에 넣는 표가 아니에요. 011은 두 입력이 1이므로 AND=0, OR=1, NOR=0, XOR=0이에요. 이 규칙을 여덟 행에 적용해요.

풀이

AND는 111에서만 1이에요. OR는 000에서만 0이에요. NOR는 OR를 뒤집어 000에서만 1이에요. XOR는 1이 홀수 개인 001, 010, 100, 111에서 1이에요.

표로 정리

입력출력
ABCAND 출력OR 출력NOR 출력XOR 출력
0000010
0010101
0100101
0110100

1100100
1111101
완성 답과 검산

AND는 111만 1, OR는 000만 0, NOR는 000만 1, XOR는 001·010·100·111에서 1이에요.

AND 열의 1은 하나, OR 열의 0은 하나, XOR 열의 1은 네 개인지 확인해요.

검산: AND 열의 1은 A=B=C=1 행뿐이에요. OR 열의 0은 A=B=C=0 행뿐이에요. NOR 열은 OR 열을 뒤집은 값이에요. XOR 열은 각 행의 1 개수가 홀수인지로 다시 세요.

여기서 헷갈리기 쉬워요

흔한 실수: 3입력 XOR를 “둘 이상 다르면 1” 같은 2입력 규칙으로 읽는 거예요. 1이 두 개인 행(011, 101, 110)은 0이고, 셋인 행(111)은 1이에요.

이제 설명을 닫고 다시 풀어요
  1. 000 행에 AND=0, OR=0을 먼저 쓰고 NOR=1, XOR=0을 이어 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. AND 열의 1은 하나, OR 열의 0은 하나, XOR 열의 1은 네 개인지 확인해요.

떠올릴 것: 같은 입력 행을 각 게이트가 따로 받기, XOR는 1이 홀수 개

핵심 개념: ABC 순서를 유지한 2³=8행이에요. AND는 모두 1, OR는 하나라도 1, NOR는 OR 반전, XOR는 1의 개수가 홀수일 때 1이에요.

시작: 000 행에 AND=0, OR=0을 먼저 쓰고 NOR=1, XOR=0을 이어 써요.

판단: 각 게이트는 같은 입력 행을 서로 독립적으로 받아요. 앞 열의 출력을 뒤 게이트에 넣는 표가 아니에요. 011은 두 입력이 1이므로 AND=0, OR=1, NOR=0, XOR=0이에요. 이 규칙을 여덟 행에 적용해요.

검산: AND 열의 1은 하나, OR 열의 0은 하나, XOR 열의 1은 네 개인지 확인해요.

문제 3 · 2입력 XOR 진리표

문제 읽기

문제

아래 2-input XOR gate의 Truth table을 완성 하시오. (3점)

주어진 조건

입력출력
ABC
LL
LH
HL
HH

구할 것

출력 C를 L 또는 H로 채우세요. 그림 1은 XOR gate이고, 그림 2의 Truth Table은 위 표로 옮겼어요.

이 문제에서 할 일

L/H는 전압 상태를 나타내요. L=0, H=1로 바꾸어 두 입력이 다른지 판단해요.

이 문제를 봤을 때 떠올릴 개념과 공식

L=0·H=1로 읽고 두 입력이 다를 때만 H인 XOR

문제에 “2-input XOR gate”와 L·H 표가 보이면 두 입력이 다른지를 떠올려요. XOR는 OR와 달리 H,H에서 L이기 때문이에요.

“2-input XOR” 기호와 L/H 입력 표가 단서예요. XOR는 두 입력이 서로 다를 때만 출력이 1인 배타적 OR예요. A·B는 입력이고 C는 출력이며 L=0, H=1로 읽어요.

C=A⊕B=A′B+AB′예요. ′는 보수, 붙여 쓴 곱은 AND, +는 OR예요. A′B는 01, AB′는 10인 상황을 골라내므로 두 항 중 하나가 1일 때 출력이 1이에요.

이 “서로 다름” 기준은 여기처럼 두 입력의 XOR일 때 적용해요. 입력 00·01·10·11 네 조합을 확인한 뒤 원문이 요구하는 L/H로 되돌려요. 11을 1로 쓰는 OR와 구별하려고 이 기준을 써요.

첫 줄을 이렇게 시작해요

첫 행 L,L을 0,0으로 읽고 두 입력이 같으므로 C=L이라고 써요.

필요한 개념: 게이트 여섯 개와 진리표를 읽어요

왜 이렇게 푸는지 함께 따라가요

XOR는 OR와 달리 둘 다 1이면 0이에요. L,H와 H,L은 서로 다르므로 H, H,H는 같으므로 L이에요. 계산 뒤 표가 요구하는 L/H 표기로 되돌려요.

풀이

A와 B가 같은 행(L L, H H)은 출력이 L이에요. 다른 행(L H, H L)은 출력이 H예요.

표로 정리

입력출력
ABC
LLL
LHH
HLH
HHL
완성 답과 검산

C는 위에서부터 L, H, H, L이에요.

출력 위에서 아래가 L,H,H,L인지, 특히 H,H에서 L인지 확인해요.

검산: A⊕B = A′B + AB′에 대입해요. L은 0, H는 1로 읽으면 01과 10에서만 1이에요.

여기서 헷갈리기 쉬워요

흔한 실수: H H를 H로 쓰는 거예요. 그건 OR의 값이에요. XOR는 둘 다 H이면 L이에요.

이제 설명을 닫고 다시 풀어요
  1. 첫 행 L,L을 0,0으로 읽고 두 입력이 같으므로 C=L이라고 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 출력 위에서 아래가 L,H,H,L인지, 특히 H,H에서 L인지 확인해요.

떠올릴 것: L=0·H=1로 읽고 두 입력이 다를 때만 H인 XOR

핵심 개념: 두 입력 XOR는 다를 때만 1이에요. L=0·H=1로 읽으면 C=A′B+AB′이고, LL·LH·HL·HH 출력은 L·H·H·L이에요.

시작: 첫 행 L,L을 0,0으로 읽고 두 입력이 같으므로 C=L이라고 써요.

판단: XOR는 OR와 달리 둘 다 1이면 0이에요. L,H와 H,L은 서로 다르므로 H, H,H는 같으므로 L이에요. 계산 뒤 표가 요구하는 L/H 표기로 되돌려요.

검산: 출력 위에서 아래가 L,H,H,L인지, 특히 H,H에서 L인지 확인해요.

문제 4 · XOR 게이트 기호, 진리표, 논리식

문제 읽기

문제

1-1) 2 input 1 output XOR Gate의 Logic symbol (Gate)을 그리고 truth Table 을 작성하시오.

1-2) XOR Gate의 Logic function을 작성하시오. (빈칸 F = ____)

구할 것

입력을 A, B, 출력을 F라 하고 XOR 기호와 진리표를 그린 뒤, F의 논리식을 쓰세요.

이 문제에서 할 일

1-1은 그림과 표, 1-2는 그 표를 식으로 옮기는 문제예요. 두 요구를 따로 완성해요.

이 문제를 봤을 때 떠올릴 개념과 공식

출력 1인 행 01·10을 OR로 합친 F=A′B+AB′

문제에 “XOR Gate의 Logic function”이 보이면 진리표에서 출력이 1인 두 행을 떠올려요. 01행은 A′B, 10행은 AB′이고 둘 중 하나면 1이라 OR로 합치기 때문이에요.

1-1의 “Logic symbol·Truth Table”과 1-2의 “Logic function”은 같은 XOR를 그림·표·식으로 표현하라는 단서예요. 입력 A·B와 출력 F를 표시하고, OR 기호 앞의 추가 곡선으로 XOR를 구별해요.

두 입력 XOR는 서로 다를 때 1이라 표의 01과 10을 선택해요. F=A⊕B=A′B+AB′에서 ′는 보수, 곱은 AND, +는 OR예요. A′B는 A=0·B=1, AB′는 A=1·B=0을 뜻해요.

두 입력이 0/1인 조건에서 이 식과 네 행 표가 같아요. 기호만 그리거나 식만 쓰면 소문항이 빠지므로 1-1의 기호·표와 1-2의 식을 따로 완성하고 같은 출력인지 연결해요.

첫 줄을 이렇게 시작해요

입력 A,B와 출력 F를 표시한 XOR 기호를 그리고, 표의 첫 행 00→0을 써요.

필요한 개념: 게이트 여섯 개와 진리표를 읽어요

왜 이렇게 푸는지 함께 따라가요

Switching Algebra Axioms & Theorems (EECC341 - Shaaban). 원문 표를 글자로 옮겼어요.

이 문제에서 할 일

이 문제를 봤을 때 떠올릴 개념과 공식

같은 덩어리 Q와 그 반전, Combining XY+XY′=X

문제의 식에 같은 괄호 덩어리와 그 덩어리 전체에 걸친 윗줄이 함께 보이면 Combining 규칙을 떠올려요. 공통 P로 묶으면 P(Q+Q′)=P·1=P라서 전개할 필요가 없기 때문이에요.

“Switching Algebra로 간단히”와 두 항에 반복된 (V′+X)가 단서예요. 부울대수는 0/1 논리값을 다루며 +는 OR, ·는 AND, ′는 보수예요. 보수의 윗줄이 어디까지 덮는지 먼저 읽어요.

항등 X·1=X, 멱등 X+X=X·X=X, 흡수 X+XY=X는 같은 항의 구조에 맞춰 써요. 이 문항은 P=V′+X와 Q=W(Y′+Z)를 놓으면 PQ+PQ′여서 공통 P를 분배법칙으로 묶는 결합 규칙이 맞아요.

Q 전체에 보수가 걸려야 Q+Q′=1이에요. 그러면 P(Q+Q′)=P·1=P가 돼요. 어떤 부울값 Q든 0 또는 1이므로 성립해요. 여기서는 멱등이나 흡수를 무작정 적용하기보다 같은 덩어리 Q와 Q′를 찾으면 긴 내부 식을 전개하지 않아도 돼요.

첫 줄을 이렇게 시작해요

P=V′+X, Q=W(Y′+Z)라고 적고 원식을 PQ+PQ′로 다시 써요.

필요한 개념: 부울대수와 드모르간 법칙을 익혀요

왜 이렇게 푸는지 함께 따라가요

두 항의 공통 P를 묶으면 P(Q+Q′)예요. 어떤 Q도 자신과 반전 중 하나는 1이라 Q+Q′=1이에요. 따라서 P·1=P예요. NOT의 범위가 Q 전체인지 먼저 읽는 것이 핵심이에요.

덩어리 찾기

P = V′+X, Q = W·(Y′+Z)라고 두면 식은 P·Q + P·Q′ 꼴이에요. 둘째 항의 윗줄은 Q 전체에만 걸려 있어요.

규칙 적용

T10(Combining) X·Y+X·Y′=X를 쓰면 P·Q+P·Q′=P예요. 직접 풀면 P·(Q+Q′)=P·1=P이고 T8, T5, T1′을 차례로 쓴 거예요.

원래 문자로

$$(\overline{V}+X)\cdot Q+(\overline{V}+X)\cdot\overline{Q}=\overline{V}+X$$

완성 답과 검산

V′+X

Q가 0일 때와 1일 때 원식이 모두 P인지 확인하고, P를 V′+X로 되돌려요.

검산: V=1, X=0이면 V′+X=0이라 식 전체가 0이에요. V=0이면 V′+X=1이고 Q와 Q′ 중 하나만 1이라서 식이 1이에요. 둘 다 V′+X와 같아요.

여기서 헷갈리기 쉬워요

흔한 실수: Q를 전개해 W·Y′+W·Z로 바꾸다 길을 잃는 거예요. 전개할 필요 없이 Q를 한 덩어리로 보고 T10을 쓰면 돼요.

이제 설명을 닫고 다시 풀어요
  1. P=V′+X, Q=W(Y′+Z)라고 적고 원식을 PQ+PQ′로 다시 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. Q가 0일 때와 1일 때 원식이 모두 P인지 확인하고, P를 V′+X로 되돌려요.

핵심 개념: +는 OR·곱은 AND·′는 보수예요. 공통 P와 서로 보수인 Q·Q′를 찾아 PQ+PQ′=P(Q+Q′)=P로 줄여요. 보수 범위는 Q 전체예요.

문제 6 · 드모르간으로 식 전개

문제 읽기

문제

De Morgan 식을 사용하여 다음을 전개 하여라.

구할 것

$$\overline{(\overline{A}+\overline{B}+\overline{C})\cdot(\overline{D}\cdot\overline{E})}$$

윗줄 없이 전개한 식을 쓰세요.

이 문제에서 할 일

전체 반전을 바깥 괄호부터 한 겹씩 풀어 식을 전개해요.

이 문제를 봤을 때 떠올릴 개념과 공식

드모르간: 곱의 윗줄은 합으로, 합의 윗줄은 곱으로

문제에 “De Morgan 식을 사용하여 전개”가 보이면 윗줄을 한 겹씩 쪼개며 연산자를 바꾸는 걸 떠올려요. 곱 위의 윗줄은 합으로, 합 위의 윗줄은 곱으로 바뀌기 때문이에요.

“De Morgan으로 전개”와 여러 겹의 윗줄이 단서예요. 보수는 논리값을 뒤집는 연산이고, 드모르간은 묶음의 보수를 각 항의 보수로 옮길 때 AND와 OR를 교환하는 법칙이에요.

(XY)′=X′+Y′, (X+Y)′=X′Y′이고 (X′)′=X예요. +는 OR, 곱은 AND, ′는 보수예요. 원문은 P=A′+B′+C′와 R=D′E′의 곱 전체에 보수가 걸려 있으므로 바깥 (PR)′부터 읽어요.

이 법칙은 보수가 괄호 전체에 걸릴 때 적용해요. 바깥 곱을 합으로 바꾼 뒤 P′ 안의 합은 곱으로, R′ 안의 곱은 합으로 바꾸어요. 변수마다 이미 있는 보수까지 다시 뒤집어야 해서 윗줄 범위와 이중 보수를 함께 확인해요.

첫 줄을 이렇게 시작해요

P=A′+B′+C′, R=D′E′라고 두고 (PR)′=P′+R′를 먼저 써요.

필요한 개념: 부울대수와 드모르간 법칙을 익혀요

왜 이렇게 푸는지 함께 따라가요

곱을 뒤집으면 합으로, 합을 뒤집으면 곱으로 바뀌어요. P′=(A′+B′+C′)′=ABC이고 R′=(D′E′)′=D+E예요. 이중 부정은 원래 문자로 돌아가요.

바깥 윗줄 쪼개기

전체는 두 덩어리의 곱이에요. 곱의 윗줄은 각 덩어리의 윗줄을 OR로 합친 거예요.

$$\overline{(\overline{A}+\overline{B}+\overline{C})}+\overline{(\overline{D}\cdot\overline{E})}$$

안쪽 윗줄 처리

첫 덩어리는 NOR 꼴이라 (A′+B′+C′)′=A·B·C예요. 둘째 덩어리는 (D′·E′)′=D+E예요.

합치기

$$A\cdot B\cdot C+D+E$$

완성 답과 검산

A·B·C + D + E

A=B=C=1,D=E=0을 넣어 원식과 ABC+D+E가 둘 다 1인지 확인해요.

검산: A=B=C=1, D=E=0이면 원래 식은 (0·1)′=1이고 결과는 1+0+0=1이에요. A=0, D=E=0이면 원래 식은 (1·1)′=0이고 결과도 0이에요.

여기서 헷갈리기 쉬워요

흔한 실수: 윗줄을 쪼개고 연산자를 바꾸지 않는 거예요. 곱 위의 윗줄은 합으로, 합 위의 윗줄은 곱으로 바뀌어요.

이제 설명을 닫고 다시 풀어요
  1. P=A′+B′+C′, R=D′E′라고 두고 (PR)′=P′+R′를 먼저 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. A=B=C=1,D=E=0을 넣어 원식과 ABC+D+E가 둘 다 1인지 확인해요.

떠올릴 것: 드모르간: 곱의 윗줄은 합으로, 합의 윗줄은 곱으로

핵심 개념: 보수가 묶음 전체에 걸리면 곱↔합을 바꾸고 각 항을 보수해요. (XY)′=X′+Y′, (X+Y)′=X′Y′, 이중 보수는 원래 값이에요.

시작: P=A′+B′+C′, R=D′E′라고 두고 (PR)′=P′+R′를 먼저 써요.

판단: 곱을 뒤집으면 합으로, 합을 뒤집으면 곱으로 바뀌어요. P′=(A′+B′+C′)′=ABC이고 R′=(D′E′)′=D+E예요. 이중 부정은 원래 문자로 돌아가요.

검산: A=B=C=1,D=E=0을 넣어 원식과 ABC+D+E가 둘 다 1인지 확인해요.

문제 7 · 회로의 D, E, Q 부울식

문제 읽기

문제

아래 회로의 D, E, Q의 Boolean equation을 적으시오. (3점)

구할 것

D=, E=, Q=를 채우세요.

이 문제에서 할 일

그림을 입력에서 출력으로 따라가며 중간 출력 D,E를 먼저 이름 붙여요.

이 문제를 봤을 때 떠올릴 개념과 공식

출력의 작은 원은 반전, 중간 신호 D와 E부터 이름 붙이기

문제에 “D, E, Q의 Boolean equation”과 회로 그림이 보이면 입력에서 출력으로 따라가며 중간 신호부터 식을 쓰는 걸 떠올려요. 게이트 출력의 작은 원은 그 출력을 반전한다는 뜻이고, 분기점과 단순 교차를 구분해야 입력을 바꿔 읽지 않기 때문이에요.

그림에서 D·E·Q의 식을 각각 묻는 것이 단서예요. 회로의 중간 출력은 다음 게이트의 입력이므로 입력→중간 노드→최종 출력 순서로 부울식을 세워요. +는 OR, 곱은 AND, ′는 보수예요.

게이트 출력의 작은 원은 그 출력 전체를 뒤집는 버블이에요. D는 A·B를 받는 OR의 버블 때문에 (A+B)′, E는 B의 검은 접속점에서 갈라진 선과 C를 받는 AND라 BC예요. 마지막 버블 없는 OR는 D+E예요.

이 읽기는 원문 그림의 버블·접속점·연결선을 확인한 조건에 따른 것이에요. 단순히 선이 교차한다고 연결로 보지 않아요. D·E를 따로 이름 붙이면 보수 범위와 입력선을 섞지 않고 Q를 만들 수 있어요. 기존 답안 충돌 상태는 유지하고 제공 답안을 그대로 확정하지 않아요.

첫 줄을 이렇게 시작해요

D 게이트의 입력 A,B와 출력의 작은 원을 찾아 D=(A+B)′라고 써요.

필요한 개념: 회로를 읽고 식을 회로로 그려요

왜 이렇게 푸는지 함께 따라가요

작은 원은 그 게이트 출력의 반전을 뜻해요. E의 두 입력은 분기점이 있는 B와 C이므로 BC예요. 마지막 OR는 중간 신호 D,E를 받아 Q=D+E예요. 선의 교차와 접속점을 구분해야 입력을 바꿔 읽지 않아요.

D, E, Q

D는 A와 B를 받는 OR 게이트의 출력인데 출력에 작은 원이 있어서 D=(A+B)′예요. E는 AND 게이트의 출력이고 입력은 B에서 갈라진 선과 C라서 E=B·C예요. Q는 D와 E를 받는 OR 게이트의 출력이라서 Q=D+E=(A+B)′+B·C이고, 드모르간으로 Q=A′B′+BC로도 쓸 수 있어요.

완성 회로

검산과 흔한 실수

검산: A=0, B=0, C=0이면 D=1이므로 Q=1이에요. A=0, B=1, C=1이면 D=0, E=1이므로 Q=1이에요. A=1, B=1, C=0이면 D=0, E=0이므로 Q=0이에요.

흔한 실수: E의 입력을 A와 B로 읽는 거예요. 분기점은 B에만 있고 A는 OR로만 가요.

완성 답과 검산

D=(A+B)′, E=B·C, Q=(A+B)′+B·C (드모르간으로 Q=A′B′+BC로 써도 같은 답이에요)

A=0,B=1,C=1에서 D=0,E=1,Q=1이 되는지 실제 게이트 순서로 따라가요.

여기서 헷갈리기 쉬워요

답안 충돌: 원문·제공 답안의 조건이나 표기가 도출 결과와 달라요. 아래 풀이의 조건을 명시하고, 제공 답안을 그대로 정답으로 외우지 않아요.

출력 이름·비트 순서·성립 조건을 문제의 표와 맞춰요. 위의 검산도 함께 확인해요.

이제 설명을 닫고 다시 풀어요
  1. D 게이트의 입력 A,B와 출력의 작은 원을 찾아 D=(A+B)′라고 써요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. A=0,B=1,C=1에서 D=0,E=1,Q=1이 되는지 실제 게이트 순서로 따라가요.

떠올릴 것: 출력의 작은 원은 반전, 중간 신호 D와 E부터 이름 붙이기

핵심 개념: 출력 버블은 그 게이트 결과의 보수예요. 원문 접속점에 따라 D=(A+B)′와 E=BC를 따로 읽고 Q=D+E로 연결해요. 답안 충돌은 유지해요.

시작: D 게이트의 입력 A,B와 출력의 작은 원을 찾아 D=(A+B)′라고 써요.

판단: 작은 원은 그 게이트 출력의 반전을 뜻해요. E의 두 입력은 분기점이 있는 B와 C이므로 BC예요. 마지막 OR는 중간 신호 D,E를 받아 Q=D+E예요. 선의 교차와 접속점을 구분해야 입력을 바꿔 읽지 않아요.

검산: A=0,B=1,C=1에서 D=0,E=1,Q=1이 되는지 실제 게이트 순서로 따라가요.

문제 8 · 식의 논리 다이어그램 그리기

문제 읽기

문제

아래 식의 Logic Diagram을 변형 없이 그리시오.

구할 것

$$\overline{(A+\overline{B})}\cdot(C+\overline{D})$$

윗줄은 첫 괄호 (A+B′)에만 걸려 있어요. 식을 간단히 하지 말고 그대로 그리세요.

이 문제에서 할 일

식의 계산 순서를 그대로 게이트로 옮겨요. 이 문제는 식을 간단히 바꾸지 말라고 요구해요.

이 문제를 봤을 때 떠올릴 개념과 공식

가장 바깥 연산이 마지막 게이트, 윗줄은 첫 괄호에만

문제에 “Logic Diagram을 변형 없이”가 보이면 식의 가장 바깥 연산부터 찾는 걸 떠올려요. 두 괄호가 · 로 이어져 마지막 게이트는 AND이고, 윗줄은 (A+B′)에만 걸려 있기 때문이에요.

“변형 없이 Logic Diagram”과 두 괄호의 곱이 단서예요. 부울식의 각 연산을 게이트 하나의 기능으로 옮기며, 식을 단순화하지 않고 괄호별 중간 출력을 이어요.

+는 OR, ·는 AND, ′와 윗줄은 보수예요. 보수·괄호 안 연산을 먼저 만들고 두 덩어리를 연결해요. P=(A+B′)′에는 B의 NOT와 합 전체의 반전, R=C+D′에는 D의 NOT가 있어요. 가장 바깥 F=P·R은 AND예요.

원문 윗줄은 첫 괄호에만 걸리고 최종 곱 전체에는 걸리지 않아요. 그래서 첫 덩어리는 NOR, 둘째는 OR, 마지막은 AND를 골라요. “변형 없이” 조건 때문에 드모르간으로 다른 모양의 동치식을 그리는 대신 이 연산 구조를 보존해요.

첫 줄을 이렇게 시작해요

F=P·R, P=(A+B′)′, R=C+D′라고 쓰고 마지막 게이트를 AND로 정해요.

필요한 개념: 회로를 읽고 식을 회로로 그려요

왜 이렇게 푸는지 함께 따라가요

B′와 D′를 만들 NOT 두 개부터 그려요. A와 B′는 NOR에, C와 D′는 OR에 넣어요. 두 괄호의 결과를 마지막 AND에 연결해요. 바깥 연산을 먼저 찾으면 출력을 어디로 모을지 명확해져요.

가장 바깥 연산

두 괄호가 · 로 이어져 있어서 출력은 AND 게이트예요. 입력은 (A+B′)′와 (C+D′)예요.

안쪽 게이트

(A+B′)′는 B를 NOT한 뒤 A와 NOR해요. (C+D′)는 D를 NOT한 뒤 C와 OR해요. 변형하지 않으니 드모르간을 쓰지 않아요.

완성 회로

다른 표기

NOR 기호 대신 OR 게이트 뒤에 NOT을 붙여 그려도 같은 회로예요. 게이트 수는 하나 늘어요.

완성 답과 검산

NOT 2개, NOR 1개, OR 1개, AND 1개로 F=(A+B′)′·(C+D′)를 그려요.

게이트 출력이 P,R,F의 식과 일치하는지 확인하고, 반전 원은 첫 괄호에만 있는지 확인해요.

검산: A=0, B=1, C=0, D=0이면 (0+0)′=1, C+D′=0+1=1이라서 F=1이에요. A=1이면 첫 괄호가 0이라서 F=0이에요. 회로로 따라가도 같아요.

여기서 헷갈리기 쉬워요

흔한 실수: 윗줄이 식 전체를 덮는다고 읽어 마지막에 NAND를 쓰는 거예요. 윗줄은 첫 괄호에만 걸려 있어요.

이제 설명을 닫고 다시 풀어요
  1. F=P·R, P=(A+B′)′, R=C+D′라고 쓰고 마지막 게이트를 AND로 정해요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 게이트 출력이 P,R,F의 식과 일치하는지 확인하고, 반전 원은 첫 괄호에만 있는지 확인해요.

떠올릴 것: 가장 바깥 연산이 마지막 게이트, 윗줄은 첫 괄호에만

핵심 개념: 변형 없이 괄호별 중간 노드를 그려요. P=(A+B′)′와 R=C+D′를 만들고 마지막은 F=P·R인 AND예요. 윗줄은 첫 괄호에만 걸려요.

시작: F=P·R, P=(A+B′)′, R=C+D′라고 쓰고 마지막 게이트를 AND로 정해요.

판단: B′와 D′를 만들 NOT 두 개부터 그려요. A와 B′는 NOR에, C와 D′는 OR에 넣어요. 두 괄호의 결과를 마지막 AND에 연결해요. 바깥 연산을 먼저 찾으면 출력을 어디로 모을지 명확해져요.

검산: 게이트 출력이 P,R,F의 식과 일치하는지 확인하고, 반전 원은 첫 괄호에만 있는지 확인해요.

문제 9 · NAND만으로 XOR 구성

문제 읽기

문제

NAND gate만을 이용하여 XOR gate를 구성하여라.

구할 것

입력 A, B와 출력 C를 가진 회로를 그리세요.

이 문제에서 할 일

NAND만 사용한다는 제한 아래에서 XOR의 네 행을 만드는 회로를 구성해요.

이 문제를 봤을 때 떠올릴 개념과 공식

N1=(AB)′를 두 갈래로 보내는 NAND 네 개 XOR

문제에 “NAND gate만을 이용하여 XOR”가 보이면 첫 NAND 출력 N1=(AB)′를 공유하는 구성을 떠올려요. N1을 A, B와 각각 NAND한 뒤 마지막 NAND로 모아야 01·10에서만 1이 되기 때문이에요.

“NAND gate만”과 “XOR 구성”은 사용할 부품과 목표 기능을 함께 제한하는 단서예요. NAND는 AND 결과를 뒤집어 (XY)′를 내고, 두 입력 XOR는 서로 다를 때 1을 내요.

XOR의 A′B+AB′에서 ′는 보수, 곱은 AND, +는 OR예요. NAND는 입력 둘을 모두 1로 받았을 때만 0이므로 중간 신호도 각각 0/1로 따라가요. 공유 신호 N1=(AB)′를 두 갈래로 보내면 NAND만으로 필요한 두 경우를 만들 수 있어요.

여기서는 별도 AND·OR·NOT 기호를 쓰지 않고 모든 게이트를 NAND로 구성해야 해요. 중간 출력의 보수를 빠뜨리지 않으려고 N1·N2·N3를 이름 붙이고 마지막 NAND까지 계산해요. 네 입력 조합의 최종 출력이 0·1·1·0이면 XOR 조건을 만족해요.

첫 줄을 이렇게 시작해요

첫 NAND의 두 입력을 A,B로 두고 중간 출력 N1=(AB)′라고 이름 붙여요.

필요한 개념: NAND로 다른 게이트를 만들어요

왜 이렇게 푸는지 함께 따라가요

N1을 두 갈래로 보내 A와 NAND한 N2, B와 NAND한 N3를 만들어요. 마지막 NAND는 N2,N3를 받아요. A=0,B=1이면 N1=1,N2=1,N3=0이므로 마지막 출력은 1이에요. 중간 출력을 하나씩 계산하면 긴 식을 외울 필요가 없어요.

식으로 시작

$$A\oplus B=\overline{A}B+A\overline{B}=\overline{\overline{(A\cdot\overline{AB})}\cdot\overline{(B\cdot\overline{AB})}}$$

첫 등호는 XOR의 정의이고, 둘째 등호는 N1=(AB)′를 공유한 NAND 네 개 구성이에요.

완성 회로

표로 확인

입력중간 계산출력
ABN1N2N3C
001110
011101
101011
110110
완성 답과 검산

NAND 네 개: N1=(AB)′, N2=(A·N1)′, N3=(B·N1)′, C=(N2·N3)′. 다른 유효 설계도 인정해요.

00·01·10·11에 대한 마지막 출력이 0·1·1·0인지 네 행을 확인해요.

검산: 표의 C가 0, 1, 1, 0이라서 XOR 진리표와 같아요.

여기서 헷갈리기 쉬워요

흔한 실수: N1의 출력을 한 곳에만 연결하는 거예요. N1은 N2와 N3에 모두 들어가야 해요.

이제 설명을 닫고 다시 풀어요
  1. 첫 NAND의 두 입력을 A,B로 두고 중간 출력 N1=(AB)′라고 이름 붙여요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 00·01·10·11에 대한 마지막 출력이 0·1·1·0인지 네 행을 확인해요.

떠올릴 것: N1=(AB)′를 두 갈래로 보내는 NAND 네 개 XOR

핵심 개념: NAND는 (XY)′, XOR는 입력이 다를 때 1이에요. NAND만 써야 하므로 공유 N1=(AB)′를 두 분기로 보내고 네 입력 조합을 검산해요.

시작: 첫 NAND의 두 입력을 A,B로 두고 중간 출력 N1=(AB)′라고 이름 붙여요.

판단: N1을 두 갈래로 보내 A와 NAND한 N2, B와 NAND한 N3를 만들어요. 마지막 NAND는 N2,N3를 받아요. A=0,B=1이면 N1=1,N2=1,N3=0이므로 마지막 출력은 1이에요. 중간 출력을 하나씩 계산하면 긴 식을 외울 필요가 없어요.

검산: 00·01·10·11에 대한 마지막 출력이 0·1·1·0인지 네 행을 확인해요.

문제 10 · AND와 NAND로 3입력 NAND

문제 읽기

문제

2-input NAND gate와 AND gate를 활용하여 3-input NAND gate를 구성 하시오. (4점)

구할 것

재료는 그림 3의 2-input AND(74HC08)와 그림 4의 2-input NAND(74HC00)예요. A, B, C를 입력으로 하는 회로를 그리세요.

이 문제에서 할 일

2입력 게이트 두 개를 이어 세 입력의 NAND 기능을 만들어요.

이 문제를 봤을 때 떠올릴 개념과 공식

AND로 AB를 만든 뒤 C와 NAND, (ABC)′=((AB)C)′

문제에 “2-input NAND gate와 AND gate”로 “3-input NAND”가 보이면 첫 게이트는 AND, 마지막만 NAND라는 걸 떠올려요. 첫 게이트까지 NAND로 쓰면 반전이 두 번 들어가 (ABC)′와 달라지기 때문이에요.

“2-input NAND와 AND로 3-input NAND”는 게이트의 종류와 입력 수를 지정하는 단서예요. 3입력 NAND는 세 입력의 AND를 한 번 뒤집는 기능이고 F=(ABC)′예요.

곱은 AND, ′는 그 곱 전체의 보수예요. A·B·C가 모두 1인 111에서만 F=0이고 나머지는 1이에요. 곱의 결합법칙 ABC=(AB)C 때문에 먼저 두 입력 AND로 AB를 묶을 수 있어요.

첫 단계가 반전 없는 AND일 때 그 결과와 C를 마지막 NAND에 넣으면 전체 곱만 한 번 반전돼요. 첫 단계도 NAND로 바꾸면 내부 보수가 추가되어 목표와 달라져요. 지정된 두 종류를 잇는 순서를 정하려고 “마지막에 전체 반전”을 떠올려요.

첫 줄을 이렇게 시작해요

목표 F=(ABC)′를 적고 내부 곱 T=AB를 먼저 만들어요.

필요한 개념: NAND로 다른 게이트를 만들어요

왜 이렇게 푸는지 함께 따라가요

첫 AND가 AB를 만든 뒤 그 출력과 C를 NAND에 넣으면 (TC)′=(ABC)′가 돼요. 첫 게이트까지 반전하면 목표 식과 달라지므로 AND와 NAND의 순서를 구별해요.

식

$$\overline{A\cdot B\cdot C}=\overline{(A\cdot B)\cdot C}$$

완성 회로

첫 게이트는 AND로 A·B를 만들어요. 둘째 게이트는 NAND로 그 결과와 C를 받아요. 이것이 실험 2-1 회로예요.

표로 확인

A·B가 1인 행은 110과 111뿐이에요. 그중 C가 1인 111에서만 출력이 0이고, 나머지 7행은 모두 1이에요.

완성 답과 검산

AND(A,B)의 출력과 C를 NAND에 넣으면 출력은 (A·B·C)′예요.

111에서만 출력이 0이고 나머지 일곱 행이 1인지 확인해요.

검산: 출력이 0인 행은 111뿐이라서 3입력 NAND와 같아요.

여기서 헷갈리기 쉬워요

흔한 실수: 첫 게이트도 NAND로 쓰는 거예요. ((AB)′·C)′는 A·B+C′이라서 (ABC)′와 달라요.

이제 설명을 닫고 다시 풀어요
  1. 목표 F=(ABC)′를 적고 내부 곱 T=AB를 먼저 만들어요.
  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 111에서만 출력이 0이고 나머지 일곱 행이 1인지 확인해요.

떠올릴 것: AND로 AB를 만든 뒤 C와 NAND, (ABC)′=((AB)C)′

핵심 개념: 3입력 NAND F=(ABC)′는 111에서만 0이에요. 먼저 AND로 AB를 만들고 마지막 NAND에서 C와 묶어 전체 곱을 한 번 반전해요.

시작: 목표 F=(ABC)′를 적고 내부 곱 T=AB를 먼저 만들어요.

판단: 첫 AND가 AB를 만든 뒤 그 출력과 C를 NAND에 넣으면 (TC)′=(ABC)′가 돼요. 첫 게이트까지 반전하면 목표 식과 달라지므로 AND와 NAND의 순서를 구별해요.

검산: 111에서만 출력이 0이고 나머지 일곱 행이 1인지 확인해요.

문제 읽기

문제

2) OR Gate와 Inverter를 활용하여 3 input NOR Gate의 Logic Diagram을 그리시오.

입력 A, B, C로 3입력 NOR 회로를 그리세요.

OR로 세 입력을 합친 다음 마지막에 한 번만 뒤집어요.

이 문제를 봤을 때 떠올릴 개념과 공식

OR 두 개로 A+B+C를 만든 뒤 마지막에 한 번만 NOT

문제에 “OR Gate와 Inverter”로 “3 input NOR”가 보이면 합을 다 만든 뒤 한 번만 뒤집는 걸 떠올려요. 입력마다 인버터를 붙이면 A′+B′+C′가 되어 NOR가 아니기 때문이에요.

“OR Gate와 Inverter로 3 input NOR”는 사용할 게이트와 목표가 단서예요. NOR는 OR 결과를 반전해 F=(A+B+C)′를 내는 기능이에요. 인버터는 0과 1을 바꾸는 NOT예요.

+는 산술 합이 아니라 OR, ′는 합 전체의 보수예요. OR는 하나라도 1이면 1이므로 NOR는 000에서만 1이고 나머지 일곱 조합은 0이에요. OR의 결합법칙으로 (A+B)+C=A+B+C가 돼요.

원문처럼 OR와 인버터로 구성할 때 먼저 세 입력의 합을 만들고 마지막 출력에 인버터를 붙여요. 입력마다 반전하는 A′+B′+C′와는 달라요. 최종 합 전체를 뒤집는 위치를 정하려고 이 조건을 떠올려요.

첫 줄을 이렇게 시작해요

T=A+B, U=T+C, F=U′라는 세 줄을 먼저 써요.

필요한 개념: NAND로 다른 게이트를 만들어요

왜 이렇게 푸는지 함께 따라가요

2입력 OR는 한 번에 입력 둘만 받으므로 OR 두 개가 필요해요. 첫 OR의 출력을 둘째 OR의 입력 하나로 쓰고 나머지 입력에 C를 넣어요. 최종 합 전체를 NOT해야 NOR가 돼요.

식

$$\overline{A+B+C}=\overline{(A+B)+C}$$

완성 회로

첫 OR가 A+B를, 둘째 OR가 (A+B)+C를 만들고, 마지막 인버터가 뒤집어요.

문제 12 · CMOS 3입력 NAND 그리기

문제 읽기

문제

CMOS 3-input NAND gate를 그리시오.

구할 것

트랜지스터 수준으로 회로를 그리세요.

이 문제에서 할 일

게이트 기호가 아니라 전원에서 출력으로 이어지는 트랜지스터 길을 그려요.

이 문제를 봤을 때 떠올릴 개념과 공식

NAND는 NMOS 직렬, PMOS 병렬

문제에 “CMOS 3-input NAND gate”가 보이면 아래 NMOS 직렬·위 PMOS 병렬을 떠올려요. 세 입력이 모두 1일 때만 GND 길이 이어지고, 하나라도 0이면 VDD 길이 이어져야 하기 때문이에요.

“CMOS 3-input NAND를 그리시오”는 논리 기호 대신 PMOS·NMOS 전원 경로를 구성하라는 단서예요. CMOS는 출력과 VDD 사이의 pull-up, 출력과 GND 사이의 pull-down을 상보적으로 연결해요.

이상적인 정적 CMOS 논리에서는 입력 0일 때 PMOS가 켜지고 입력 1일 때 NMOS가 켜져요. 직렬은 모두 켜져야 길이 이어지고 병렬은 하나만 켜져도 이어져요. NAND F=(ABC)′는 모두 1일 때만 0이에요.

그래서 GND로 내리는 NMOS 세 개는 직렬, 하나라도 0이면 VDD로 올리는 PMOS 세 개는 병렬이에요. A·B·C를 위아래 각 쌍의 게이트에 연결해요. 입력이 0/1로 안정된 이상적 동작을 판단하는 조건에서 두 경로가 상보적이므로 NAND의 출력 조건을 전원 연결로 설명할 수 있어요.

첫 줄을 이렇게 시작해요

111에서 출력이 GND로 연결되어야 하므로 NMOS 세 개를 직렬로 먼저 그려요.

필요한 개념: CMOS NAND와 Pull-up을 살펴봐요 (보충)

왜 이렇게 푸는지 함께 따라가요

NMOS는 입력 1에서 켜져요. 세 입력이 모두 1이어야 아래 길이 이어지려면 직렬이어야 해요. PMOS는 입력 0에서 켜지므로 셋 중 하나만 0이어도 위 길이 이어지도록 병렬로 놓아요. A,B,C는 위아래 각 한 쌍의 게이트 단자로 연결해요.

아래쪽(NMOS)

출력이 0이 되려면 A, B, C가 모두 1이어야 해요. “모두”는 직렬이라서 NMOS 3개를 출력과 GND 사이에 직렬로 놓아요.

위쪽(PMOS)

출력이 1이 되려면 셋 중 하나라도 0이면 돼요. “하나라도”는 병렬이라서 PMOS 3개를 VDD와 출력 사이에 병렬로 놓아요.

완성 회로

완성 답과 검산

PMOS 3개는 병렬로 VDD와 출력 사이에, NMOS 3개는 직렬로 출력과 GND 사이에 놓고 A, B, C를 각 쌍의 게이트에 연결해요.

111에서는 아래 길만 이어져 0, 011에서는 A의 PMOS가 켜지고 NMOS가 끊겨 1인지 확인해요.

검산: 111이면 PMOS가 모두 꺼지고 NMOS 경로가 연결되어 Z=0이에요. 011이면 P1이 켜져 VDD와 연결되고 N1이 꺼져 GND 경로가 끊겨서 Z=1이에요.

여기서 헷갈리기 쉬워요

흔한 실수: PMOS를 직렬로 놓는 거예요. 그건 NOR 구조예요. NAND는 PMOS 병렬, NMOS 직렬이에요.

  2. 앞의 풀이를 보지 않고 문제에서 요구한 모든 표·식·회로·설명을 완성해요.
  3. 111에서는 아래 길만 이어져 0, 011에서는 A의 PMOS가 켜지고 NMOS가 끊겨 1인지 확인해요.

핵심 개념: 입력이 0/1로 안정된 이상적인 정적 CMOS에서 PMOS는 입력 0·NMOS는 1에 켜져요. NAND의 모두 1 조건은 NMOS 직렬, 하나라도 0 조건은 PMOS 병렬로 구현해요.

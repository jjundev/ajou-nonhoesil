이 문제에서 할 일

2bit RAM의 칸 B에만 1을 넣는 여섯 입력을 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

B의 Set 쪽 NAND = IN1과 WR1

“B part에 1”이 단서예요. B를 Set하려면 S′_B=0, R′_B=1이에요.

B의 Set 쪽 NAND(1·2번)는 IN1과 WR1, Reset 쪽(4·5번)은 IN1과 WR0을 받아요. WR 두 선은 A와 같이 써요.

A를 지키려면 IN0=0이에요. OE1=1이면 OUT1이 B를 바로 보여 주고, OE0=0이면 OUT0=0이에요.

첫 줄을 이렇게 시작해요

S′_B = (IN1·WR1)′ = 0을 적어요.

필요한 개념으로 돌아가요

이유를 따라 완성해요

B의 래치:

IN1=1, WR1=1, WR0=0이면 S′_B=0, R′_B=1이라 B가 Set돼요.

A 지키기:

IN0=0이면 A의 두 NAND가 1을 내서 A는 유지돼요.

OE0OE1IN0IN1WR0WR1
010101
답과 검산을 확인해요

최종 답: OE0=0, OE1=1, IN0=0, IN1=1, WR0=0, WR1=1

검산: 처음 값과 OE에 관계없이 S′_B=0, R′_B=1, S′_A=R′_A=1이라 B=1, A 유지예요. 제공 답안 두 개도 같은 값이에요(덧쓴 수기 두 장은 WR 값 판독 보류).

헷갈리기 쉬운 조건을 확인해요

WR은 A와 B가 같이 써요. 칸을 고르는 것은 IN뿐이에요. 범례대로 WR1만 B의 값이라고 생각해도 이 문항의 값은 같지만, B에 0을 쓸 때는 WR0=1도 필요해요.

설명을 닫고 다시 해 봐요
  1. B의 Set 쪽 NAND 입력을 찾아요.
  2. IN1, WR1, WR0을 정해요.
  3. IN0=0으로 A를 지켜요.

떠올릴 것: B의 Set 쪽 NAND = IN1과 WR1

“B part에 1”이 단서예요. B를 Set하려면 S′_B=0, R′_B=1이에요.

첫 실행: S′_B = (IN1·WR1)′ = 0을 적어요.

핵심: IN1=1, WR1=1, WR0=0, IN0=0이에요.

결론: OE0=0, OE1=1, IN0=0, IN1=1, WR0=0, WR1=1

검산: 처음 값과 OE에 관계없이 S′_B=0, R′_B=1, S′_A=R′_A=1이라 B=1, A 유지예요. 제공 답안 두 개도 같은 값이에요(덧쓴 수기 두 장은 WR 값 판독 보류).

주의: WR은 A와 B가 같이 써요. 칸을 고르는 것은 IN뿐이에요. 범례대로 WR1만 B의 값이라고 생각해도 이 문항의 값은 같지만, B에 0을 쓸 때는 WR0=1도 필요해요.

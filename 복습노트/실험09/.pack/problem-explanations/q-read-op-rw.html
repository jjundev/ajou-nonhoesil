이 문제에서 할 일

1 bit RAM에서 저장된 값을 Output으로 꺼낼 때 Read/Write 입력을 0과 1 중 무엇으로 둘지 묻는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

출력 AND에 그대로 들어가는 선은 1이어야

“Read operation”이 단서예요. 읽기는 Q를 Output으로 꺼내는 일이니 출력 AND의 문이 열려야 해요.

출력 AND는 Output = Sel·(R/W)·Q예요. Read/Write가 그대로 들어가니 1이어야 Q가 나가요.

Read/Write는 인버터를 거쳐 S, R 쪽 AND에도 들어가요. 1이면 그 문이 닫혀 읽는 동안 값이 바뀌지 않아요.

첫 줄을 이렇게 시작해요

Output = Sel·(R/W)·Q를 적고 R/W 자리에 1을 넣어 봐요.

필요한 개념으로 돌아가요

이유를 따라 완성해요

출력 문:

Output = Sel·(R/W)·Q예요. R/W=1, Sel=1이면 Output=Q예요.

쓰기 문 닫힘:

(R/W)′=0이라 S=R=0이에요. 래치는 유지돼요. 교안 표의 Read 줄(1, 1, X → Q(t-1), Q(t-1))과 같아요.

답과 검산을 확인해요

최종 답: 1

검산: R/W=0이면 출력 AND가 0을 내서 Q를 볼 수 없어요. 그래서 읽기는 1뿐이에요.

헷갈리기 쉬운 조건을 확인해요

제공 답안 일부는 “Read = 1, Write = 1”처럼 적혀 있어 값인지 규약인지 모호해요. 이 문제의 답은 입력 값 1이에요.

설명을 닫고 다시 해 봐요
  1. 출력 AND 식을 적어요.
  2. R/W에 1을 넣어 Output=Q를 확인해요.
  3. 쓰기 문이 닫히는지 확인해요.

떠올릴 것: 출력 AND에 그대로 들어가는 선은 1이어야

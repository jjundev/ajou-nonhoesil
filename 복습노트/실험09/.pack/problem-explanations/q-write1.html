이 문제에서 할 일

1 bit RAM의 Q에 1을 넣으려면 세 입력을 어떻게 둘지 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

Q=1 → S=1 → S 쪽 AND 세 입력 모두 1

“1의 데이터를 쓰려고”가 단서예요. RS 플립플롭 표에서 Q=1은 Set 줄(S=1, R=0)이에요.

S 쪽 AND는 S = Sel·(R/W)′·Input이에요. 세 입력이 모두 1이어야 S=1이에요. (R/W)′=1이려면 Read/Write=0이에요.

R 쪽 AND는 Input′를 받아요. Input=1이면 R=0이라 Set과 Reset이 부딪치지 않아요.

첫 줄을 이렇게 시작해요

S = Sel·(R/W)′·Input = 1을 적고 각 항을 1로 맞춰요.

필요한 개념으로 돌아가요

이유를 따라 완성해요

목표:

Q=1이려면 S=1, R=0이에요.

S 쪽 AND:

Sel=1, (R/W)′=1, Input=1이라야 S=1이에요. 그래서 Read/Write=0이에요.

R 쪽 확인:

R = Sel·(R/W)′·Input′ = 1·1·0 = 0이에요.

답과 검산을 확인해요

최종 답: Selection input=1, Input=1, Read/Write=0

검산: p4 표 셋째 줄(1, 0, 1 → Q=1, Output=0)과 같아요. 쓰는 동안 Output은 0이에요. 처음 Q가 0이든 1이든 Q=1이 돼요.

헷갈리기 쉬운 조건을 확인해요

Read/Write를 1로 두면 읽기라 써지지 않아요. 교안 p4 식은 S·R이 그림과 바뀌어 적혀 있으니 회로도로 판단해요. 수기 메모 한 장은 input을 0으로 적었지만 덧칠로 판독이 불확실해요.

설명을 닫고 다시 해 봐요
  1. Q=1에 필요한 S, R을 적어요.
  2. S 쪽 AND 세 입력을 1로 맞춰요.
  3. R=0인지 확인해요.

떠올릴 것: Q=1 → S=1 → S 쪽 AND 세 입력 모두 1

“1의 데이터를 쓰려고”가 단서예요. RS 플립플롭 표에서 Q=1은 Set 줄(S=1, R=0)이에요.

첫 실행: S = Sel·(R/W)′·Input = 1을 적고 각 항을 1로 맞춰요.

핵심: Sel=1, Input=1, R/W=0이면 S=1이라 Q=1이에요.

결론: Selection input=1, Input=1, Read/Write=0

검산: p4 표 셋째 줄(1, 0, 1 → Q=1, Output=0)과 같아요. 쓰는 동안 Output은 0이에요. 처음 Q가 0이든 1이든 Q=1이 돼요.

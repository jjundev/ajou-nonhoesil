이 문제에서 할 일

앞 문제와 반대로 Q에 0을 넣는 세 입력을 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

Q=0 → R=1 → R 쪽 AND는 Input′를 받음

“0의 데이터를 쓰려고”가 단서예요. RS 표의 Reset 줄(S=0, R=1)을 떠올려요.

R 쪽 AND는 R = Sel·(R/W)′·Input′예요. Input이 인버터를 거쳐 들어가니 Input=0이어야 그 항이 1이에요.

Selection=1, Read/Write=0은 1 쓰기와 같아요. 쓸 값만 Input으로 바뀌어요.

첫 줄을 이렇게 시작해요

R = Sel·(R/W)′·Input′ = 1을 적어요.

필요한 개념으로 돌아가요

이유를 따라 완성해요

목표:

Q=0이려면 R=1, S=0이에요.

R 쪽 AND:

Sel=1, (R/W)′=1, Input′=1이라야 R=1이에요. 그래서 Input=0, Read/Write=0이에요.

S 쪽 확인:

S = 1·1·0 = 0이에요.

답과 검산을 확인해요

최종 답: Selection input=1, Input=0, Read/Write=0

검산: p4 표 둘째 줄(1, 0, 0 → Q=0, Output=0)과 같아요. 제공 답안 일곱 개도 1, 0, 0이에요(덧쓴 수기 한 장은 판독 보류).

헷갈리기 쉬운 조건을 확인해요

Selection을 0으로 두면 아무것도 써지지 않아요. p4 표 첫 줄은 그때 Q=0이라 적었지만 회로대로면 Q는 유지예요.

설명을 닫고 다시 해 봐요
  1. Q=0에 필요한 S, R을 적어요.
  2. R 쪽 AND의 Input′를 1로 맞춰요.
  3. S=0인지 확인해요.

떠올릴 것: Q=0 → R=1 → R 쪽 AND는 Input′를 받음

“0의 데이터를 쓰려고”가 단서예요. RS 표의 Reset 줄(S=0, R=1)을 떠올려요.

첫 실행: R = Sel·(R/W)′·Input′ = 1을 적어요.

핵심: Sel=1, Input=0, R/W=0이면 R=1이라 Q=0이에요.

결론: Selection input=1, Input=0, Read/Write=0

검산: p4 표 둘째 줄(1, 0, 0 → Q=0, Output=0)과 같아요. 제공 답안 일곱 개도 1, 0, 0이에요(덧쓴 수기 한 장은 판독 보류).

주의: Selection을 0으로 두면 아무것도 써지지 않아요. p4 표 첫 줄은 그때 Q=0이라 적었지만 회로대로면 Q는 유지예요.

이 문제에서 할 일

2bit RAM의 칸 A에만 1을 넣으려면 여섯 입력을 어떻게 둘지 찾는 문제예요.

이 문제를 봤을 때 떠올릴 개념과 공식

A의 Set 쪽 NAND = IN0과 WR1

“A part에 1”이 단서예요. A의 래치를 Set(Q=1)하려면 S′_A=0, R′_A=1이어야 해요.

회로도에서 A의 Set 쪽 NAND(1·2번)는 IN0과 WR1을, Reset 쪽 NAND(4·5번)는 IN0과 WR0을 받아요. S′_A=(IN0·WR1)′이 0이려면 IN0=1, WR1=1이에요.

WR0, WR1은 B에도 함께 들어가요. B가 바뀌지 않으려면 IN1=0이어야 해요. OE는 출력 문이라 저장에는 영향이 없어요. 제공 답안은 OE0=1로 두어 쓰는 값이 OUT0에 바로 보이게 했어요.

첫 줄을 이렇게 시작해요

S′_A = (IN0·WR1)′ = 0을 적어요.

필요한 개념으로 돌아가요

이유를 따라 완성해요

A의 래치:

Set하려면 S′_A=0, R′_A=1이에요. IN0=1, WR1=1, WR0=0이면 S′_A=(1·1)′=0, R′_A=(1·0)′=1이에요.

B 지키기:

IN1=0이면 S′_B=R′_B=1이라 B는 유지돼요.

OE:

OE0=1이면 OUT0=OE0·Q로 쓰는 값 1이 바로 보이고, OE1=0이면 OUT1=0이에요. OE를 바꿔도 저장값은 같아요.

OE0OE1IN0IN1WR0WR1
101001
답과 검산을 확인해요

최종 답: OE0=1, OE1=0, IN0=1, IN1=0, WR0=0, WR1=1 (쓰기에 필요한 것은 IN0=1, IN1=0, WR1=1, WR0=0이고 OE는 저장에 영향을 주지 않아요)

검산: 처음 A, B가 0이든 1이든, OE를 어떻게 두든 S′_A=0, R′_A=1, S′_B=R′_B=1이라 A=1이 되고 B는 그대로예요. 제공 답안 일곱 개도 같은 값이에요.

헷갈리기 쉬운 조건을 확인해요

범례만 보고 “A의 값 = WR0”이라 여겨 WR0=1로 쓰면 A에 0이 써져요. 회로도대로 저장값은 WR1과 같아요. IN1까지 1로 두면 B에도 1이 써져요.

설명을 닫고 다시 해 봐요
  1. A의 Set 쪽 NAND 입력을 회로도에서 찾아요.
  2. S′=0, R′=1이 되게 IN0, WR1, WR0을 정해요.
  3. IN1=0으로 B를 지켜요.

떠올릴 것: A의 Set 쪽 NAND = IN0과 WR1

“A part에 1”이 단서예요. A의 래치를 Set(Q=1)하려면 S′_A=0, R′_A=1이어야 해요.

첫 실행: S′_A = (IN0·WR1)′ = 0을 적어요.

핵심: IN0=1, WR1=1, WR0=0, IN1=0이고 OE는 저장에 영향이 없어요.

결론: OE0=1, OE1=0, IN0=1, IN1=0, WR0=0, WR1=1 (쓰기에 필요한 것은 IN0=1, IN1=0, WR1=1, WR0=0이고 OE는 저장에 영향을 주지 않아요)

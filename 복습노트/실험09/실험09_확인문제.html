Q1. 멀리 떨어진 두 주소

어떤 RAM에서 주소 0을 읽었어요. 다음에 멀리 떨어진 주소 15를 읽으려면 어떤 동작이 필요한가요?

  1. 읽기 주소에 15를 주어 해당 칸을 바로 골라요.
  2. 주소 1부터 14까지 차례로 읽은 뒤 15를 읽어요.
  3. 주소 15의 데이터를 읽기 직전에 같은 칸에 다시 써요.
  4. 어떤 칸이 읽힐지는 매번 무작위로 결정돼요.
힌트 보기

주소 입력이 읽으려는 칸에 어떤 정보를 주는지 생각해요.

풀이 보기
  1. RAM에서 주소는 접근할 칸을 직접 골라요.
  2. "순서대로 밀어 읽는 회로와 같은 방식이라고 봐요" — 중간 칸을 통과하는 과정은 필요 없어요.
  3. "읽을 때도 값을 새로 써야 한다고 봐요" — 저장되어 있다면 읽기만 하면 돼요.
  4. "Random을 임의 선택으로 해석해요" — 어느 칸을 읽을지는 지정한 주소가 정해요.

정답: A

Q2. 1비트 RAM의 두 쓰기 경로

교안의 1비트 RAM 회로도에서 $\mathrm{Selection}=1$, $\mathrm{R/W}=0$, $\mathrm{Input}=1$이에요. 래치에 들어가는 S, R을 그 순서대로 붙여 두 자리로 쓰세요.

힌트 보기

Input이 인버터 없이 들어가는 쪽과 인버터를 지나가는 쪽을 각각 따라가요.

풀이 보기
  1. Selection이 1이고 R/W가 0이라 쓰기 쪽 AND 두 개가 열려요.
  2. S에는 Input=1이, R에는 반전된 0이 가요.
  3. S, R 순서로 10이에요.

정답: 10

Q3. 공용 쓰기 값이 닿는 칸

2비트 RAM의 A와 B에 각각 0과 0이 저장되어 있어요. WR1=1, WR0=0을 먼저 맞췄어요. 쓰기 동안 IN0=0, IN1=1로 뒀다가 두 IN을 0으로 내렸어요. A, B의 저장값을 그 순서로 붙여 두 자리로 쓰세요.

힌트 보기

두 칸에 같은 WR이 들어가도 각 칸의 쓰기 선택은 따로 봐요.

풀이 보기
  1. A는 IN0=0이어서 쓰기가 닫혀 있고 0을 유지해요.
  2. B는 IN1=1일 때 WR1의 1을 저장해요.
  3. IN을 모두 0으로 내리면 A=0, B=1이 유지돼요.

정답: 01

Q4. 보관한 값만 읽고 싶을 때

2비트 RAM 칸 A에 1을 썼어요. 쓰기 중이던 A를 저장 상태로 돌린 다음, WR 선에 새 값을 줘도 A는 그대로 두고 읽고 싶어요. A의 제어 신호를 어떻게 두나요?

  1. IN0=1, OE0=1
  2. IN0=0, OE0=1
  3. IN0=1, OE0=0
  4. IN0=0, OE0=0
힌트 보기

쓰기를 허용하는 선과 출력을 허용하는 선을 따로 골라요.

풀이 보기
  1. "읽기와 쓰기를 동시에 켜도 된다고 봐요" — 쓰기까지 켜져 있으면 WR이 A에 계속 반영돼요.
  2. IN0=0은 저장값을 붙잡고, OE0=1은 그 Q를 OUT0에 보여 줘요.
  3. "IN을 읽기 선택으로 봐요" — 쓰기만 열고 출력은 닫는 조합이에요.
  4. "쓰기만 끄면 읽기도 된다고 봐요" — A는 값을 유지하지만 읽기를 꺼서 OUT0에 보여 주지 않아요.

정답: B

Q5. 출력 핀에 저항이 빠졌을 때

74HC03의 한 출력에서 +5V로 이어지는 풀업 저항이 빠졌어요. 그 게이트의 두 입력은 모두 0이고, 핀에 붙은 다른 구동 회로는 없어요. 출력 핀은 어떻게 되나요?

  1. 칩이 핀을 +5V로 밀어 안정된 1을 만들어요.
  2. 칩이 핀을 GND로 당겨 안정된 0을 만들어요.
  3. 핀이 떠서 안정된 1이 보장되지 않아요.
  4. 직전에 핀에서 보였던 값을 회로가 계속 보관해요.
힌트 보기

NAND 결과를 구한 뒤, 그 결과에서 열린 드레인 내부가 핀을 당기는지 봐요.

풀이 보기
  1. "74HC00과 같은 방식으로 1을 구동한다고 봐요" — 열린 드레인은 이 상태에서 핀을 놓아요.
  2. "입력 0을 NAND의 출력 0으로 옮겨요" — 두 입력이 0이면 NAND 결과는 1이라 GND로 당기는 쪽이 꺼져요.
  3. NAND가 1이어야 할 때 칩은 핀을 놓고, 빠진 풀업이 1을 만들어 주지 못해요.
  4. "핀을 놓는 동작을 저장값 유지로 봐요" — 출력 핀을 놓는 동작에 저장 래치는 없어요.

정답: C

Q6. 쓰기 주소와 읽기 주소

74670의 00, 01, 10, 11번 칸에 차례로 1100, 0110, 1011, 0001이 들어 있어요. WE=0, WB WA=00으로 0011을 쓰면서, RE=0, RB RA=10을 유지해요. 신호가 안정된 뒤 Q4~Q1을 네 자리로 쓰세요.

힌트 보기

Q로 나오는 칸은 주소 두 쌍 중 어느 쪽이 고르는지 봐요.

풀이 보기
  1. 쓰기는 WB WA=00이 고른 칸에만 반영돼요.
  2. 읽기는 RB RA=10이 고른 칸을 봐요.
  3. 10번 칸은 바뀌지 않으므로 Q4~Q1은 1011이에요.

정답: 1011

Q7. 데이터 입력을 바꾼 뒤 읽기

74670의 01번 칸에 0101이 들어 있어요. WE=1인 동안 WB WA를 01로, D4~D1을 1110으로 바꿨어요. WE는 계속 1이에요. RE=0, RB RA=01에서 Q4~Q1을 네 자리로 쓰세요.

힌트 보기

쓰기 주소에 칸을 올려놓는 것과 쓰기가 켜지는 조건을 따로 확인해요.

풀이 보기
  1. WE=1이면 쓸 주소와 값을 바꿔도 저장값은 바뀌지 않아요.
  2. RE=0이고 읽기 주소가 01이므로 그 칸의 기존 값 0101이 나와요.

정답: 0101

Q8. 전원을 다시 켠 실험

74670에 1001을 쓴 뒤 전원을 충분히 끊었다가 다시 연결했어요. 새로 쓰기 전에 같은 주소를 읽었더니 우연히 1001이 보였어요. 어떤 결론을 내릴 수 있나요?

  1. 같은 값이 보였으니 전원이 없어도 그 저장값을 유지해요.
  2. 전원 재연결 뒤에는 반드시 모두 0이어야 해요.
  3. 같은 주소를 입력하면 이전 데이터도 자동 복구돼요.
  4. 전원을 다시 켠 뒤 같은 값이 보일 수 있지만, 이전 값을 보존했다는 근거는 되지 않아요.
힌트 보기

전원이 끊기는 동안 래치가 값을 유지할 수 있는지 먼저 생각해요.

풀이 보기
  1. "결과가 한 번 같으면 저장값이 이어졌다고 봐요" — 재인가 뒤 우연히 같은 값이 나올 수 있어요.
  2. "휘발성은 0으로 초기화된다는 뜻으로 봐요" — 교안은 재인가 뒤 초기값이 0이라고 정하지 않아요.
  3. "주소가 데이터를 함께 갖고 있다고 봐요" — 주소는 칸을 고르고 데이터는 별도로 써야 해요.
  4. 전원이 끊기면 래치가 값을 유지하지 못해 재인가 뒤의 값은 정해지지 않아요.

정답: D

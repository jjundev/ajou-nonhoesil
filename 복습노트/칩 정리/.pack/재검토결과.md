# 교안·데이터시트 재검토 — 2026-10-15

## 결론

13종의 전체 190핀에 대해 핀 번호·신호·입출력 역할을 대조했다. 기존 핀맵의 잘못된 번호나 역할은 발견하지 않았다. 문제 30개를 다시 읽고 기능·핀·논리·실험 범위와 비교했으며 틀린 정답은 발견하지 않았다. 10번 정답이 입출력 수를 명시하지 않은 점은 아래와 같이 보완했다.

- 기존: `BCD → Decimal · 1-of-10`
- 수정: `BCD → Decimal 디코더 · 입력 4개 · Active Low 출력 10개`

질문은 입출력 수까지 요구하므로 ‘1-of-10’이라는 기능명만으로 끝내지 않도록 했다. build.py와 questions.json 및 문제풀이·문제설명 HTML에 반영했다. 정리노트도 같은 빌드로 재생성했으며 내용상 정정은 필요하지 않았다.

교안은 `강의노트/실험1. Basic Gates.pdf`부터 실험5까지의 현재 배포 파일을 사용했다. 다음 9쪽을 새로 렌더해 회로와 글자를 확인했다.

- 실험01 p14: OR 32 뒤 NOR 02로 3입력 NOR 구성.
- 실험02 p9·11: 미사용 CMOS 입력 고정, 04→14 교체 및 첫 경로 1→2.
- 실험03 p5·7: 전가산기 86·08·32, 전감산기에는 04 추가.
- 실험04 p8·11: MUX 04·20, DMUX 04·11. 교안의 각 게이트 핀 배치와 일치.
- 실험05 p9·12: 42의 A=15, B=14, C=13, D=12와 Y0~Y9 핀, Active Low LED 배선, Excess-3의 04·20 조합.

수행 범위는 2026-09-14 `[필독] 논리회로실험 보고서 관련 공지`의 표와도 대조했다. 따라서 139·153·148을 교안 보충으로 구분하고 29·30번을 실제 수행 칩 조합으로 답한 내용은 유지했다. 교안 실험05 p9 제목의 ‘4×16’은 칩의 실제 출력 수와 다르므로, 노트와 28번에서 이 표기를 그대로 암기하지 않게 한 설명은 유지한다.

## 재현 검증

`audit_check.py`는 build.py의 핀 상수를 가져오지 않고 제조사 표에서 별도로 전사한 핀 그룹을 사용한다. chips.json뿐 아니라 최종 정리노트 HTML의 SVG 글자와 핀 역할 표도 190핀 전부 대조했다. 검증 기준은 audit-reference.json에 보존한다.

- `python "복습노트/칩 정리/.pack/audit_check.py"`: 13종·190핀, 최종 SVG·핀 표, 논리표·계산 PASS.
- AND·OR·NAND·NOR·XOR의 HTML 진리표를 정의로부터 계산해 비교.
- 전가산기와 전감산기 각각 8개 입력 조합 검산. BCD는 유효·무효를 포함한 16개 코드 확인.
- `python "복습노트/칩 정리/.pack/verify.py"`: 링크·문항 답안 반영·PC/모바일·테마·인쇄 표시 검사 PASS.

제조사 원문은 agent-reach의 Jina 웹 조회 경로와 웹 도구로 확인했다. TI PDF는 이번 재검토에서 직접 내려받아 p3·9를 시각 검사했다. 최초 제작 때 직접 다운로드에 실패한 기록과는 다른 이번 작업의 결과다.

다른 리뷰어가 수행한 독립 검토는 아니며, 동일 작성자가 원문을 다시 읽고 별도 기준값으로 대조한 재검토다. 실물 칩 제조사·접미사 및 실제 측정값은 검증 대상이 아니므로 기존 주의 문구를 유지했다.

학습 내용

칩 공부를 시작해요

실험실에서는 “AND가 무엇인가”에 더해 어느 칩을 골라 어느 다리에 연결하는가까지 판단해야 해요. 먼저 번호와 기능을 연결하고, 방향·전원·게이트 묶음을 확인해 보세요.

범위는 실험01~05예요. 실제 수행 중심 칩 10종을 먼저 익히고, 교안에만 등장하는 전용 칩 3종은 보충에서 구별해요. 새로 만든 연습문제이며 실제 기출이나 출제 예고는 아니에요.

번호 → 기능 → 방향 → 전원 → 신호 핀 순서로 확인해요.

방향·전원·입출력을 읽어요

노치부터 확인해요

칩을 위에서 보고 노치를 위로 놓아요. 왼쪽 위가 1번이고 왼쪽을 따라 아래로 센 다음, 오른쪽 아래에서 위로 올라가요. 14핀은 왼쪽 아래 7·오른쪽 아래 8·오른쪽 위 14번이에요. 16핀은 각각 8·9·16번이에요.

글자의 역할을 구분해요

74HC08에서 HC는 논리 계열, 08은 기능을 구별하는 번호예요. 제조사 접두사나 끝의 패키지 표기는 따로 확인해요. HC·HCT·LS를 전기적으로 같은 칩이라고 가정하지 않아요.

입력, 출력, NC는 서로 달라요

사용하지 않는 CMOS 입력은 VCC 또는 GND 등 회로에 맞는 확정값으로 고정해요. 사용 중인 게이트의 남는 입력은 원하는 논리를 보존하도록 고정해요. 미사용 출력과 NC는 연결하지 않아요. 여러 출력끼리 직접 묶지 않아요.

전원은 이 실험 교안의 +5V를 기준으로 해요. 신호원·측정기와 회로는 기준 접지를 공유해야 해요. LED는 극성과 직렬 저항을 확인해요. “LED 켜짐=논리 1”은 연결 방식에 따라 달라요.

노치 기준 위에서 보기. /는 Active Low. 실제 입력 고정·출력 미연결·NC 미연결을 구분해요.

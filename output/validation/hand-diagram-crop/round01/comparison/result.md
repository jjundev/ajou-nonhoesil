# Round 01 독립 이미지 비교

판정: 필수 내용 보존과 불필요한 주변 요소 제외는 두 쪽 모두 통과. 2% 여백은 plan 경계에서 정확히 적용되며, 실제 잉크 경계에서 약 2.21–3.21%이다. 따라서 “상하좌우가 실제 잉크로부터 정확히 2.00%”로 주장할 수는 없지만 보수적 보존 경계와 약 2% 여백이라는 설계에는 부합한다.

## 입력 고정 및 검증 범위

- `fresh/final-hashes.json`을 먼저 읽고 PNG 두 개의 SHA-256을 검증한 뒤 수동 JPEG를 열었다. 비교 이미지 생성 후에도 두 해시가 일치했다.
- 원본 PDF, fresh 출력 PNG, 수동 JPEG, 스킬, 코드를 수정하지 않았다. 비교 전용 Pillow 스크립트와 결과만 comparison 아래에 생성했다.
- 실제 자동 PNG 두 개와 수동 JPEG 두 개를 이미지 도구로 직접 열었다. 원본 전체 렌더 두 개와 생성한 나란히 비교 이미지 두 개도 열어 확인했다.
- 코드 실행 상태는 `crop-report.json`의 두 페이지 saved를 확인한 것이다. 실행 성공만으로 시각 합격을 대체하지 않았고, 아래 평가는 이미지 대조에 근거한다. 회로의 전기적 정확성은 평가하지 않았다.

## 시각 검증

| 검증 항목 | p1 | p2 |
|---|---|---|
| 전원 단자 3개·극성·연결선 | 모두 보존 | 모두 보존 |
| 보드 전체 외곽·홀·양쪽 행 번호 | 모두 보존 | 모두 보존 |
| 외부 신호 이름·핀 번호·연결 화살표 | D0, D2, E와 화살표 보존; 내부 D1/D3/S0/S1·IC 핀 필기 보존 | D와 화살표 보존; 내부 S0/S1·Y0–Y3·IC 핀 필기 보존 |
| 판형 구분선·하단 캡션 | 제외됨 | 제외됨 |

| 보드 내부의 삭제·덧칠 | 관찰되지 않음 | 관찰되지 않음 |

## 정렬 좌표와 경계 차이

좌표는 각 이미지의 원본 픽셀, 원점 좌상단이다. `[x0,y0,x1,y1]`는 보드 외곽선 중심이다. 네 모서리는 `(x0,y0),(x1,y0),(x0,y1),(x1,y1)`이다. 눈으로 보드 외곽을 찾은 뒤 주변 픽셀의 명암 투영으로 선 중심을 확인했다. JPEG의 흐림 때문에 수동 좌표 약 ±1.5 px, 자동 좌표 약 ±2 px 불확실성이 있다. 경계 차이 수치의 보수적 오차는 약 ±0.5 percentage points이다.

비교 이미지는 네 보드 모서리를 공통 850×1257 px 사각형에 맞춘다. x/y 축을 각각 선형 리샘플링하며 회전·국소 변형·내부 편집은 없다. 원본 이미지 전체를 보존한다. 청록 십자는 보드 모서리, 파란 테두리는 각 입력 이미지의 끝, 회색은 입력 밖이다. 미세한 가로세로 비율 차이까지 정규화하므로 이것은 픽셀 동일성 검사가 아니다. 변환 배율과 모서리 좌표는 `alignment-measurements.json`에 있다.

| 쪽 | 입력 | 이미지 크기 px | 보드 경계 px | 보드 밖 포함량 왼쪽 / 위 / 오른쪽 / 아래 (보드 너비 대비) |
|---|---|---|---|---|
| 1 | manual | [761, 1115] | [83.5, 189.5, 692, 1087.5] | 13.72% / 31.14% / 11.34% / 4.52% |
| 1 | auto | [1758, 2524] | [190.5, 416.5, 1592, 2489] | 13.59% / 29.72% / 11.84% / 2.50% |
| 2 | manual | [702, 1011] | [56, 152.5, 628, 998] | 9.79% / 26.66% / 12.94% / 2.27% |
| 2 | auto | [1696, 2444] | [123.5, 336.5, 1525, 2409] | 8.81% / 24.01% / 12.20% / 2.50% |

| 쪽 | 자동−수동 왼쪽 | 위 | 오른쪽 | 아래 |
|---|---:|---:|---:|---:|
| 1 | -0.13% | -1.42% | +0.51% | -2.02% |
| 2 | -0.98% | -2.65% | -0.74% | +0.22% |

양수는 자동이 수동보다 그 방향의 주변 공간을 더 많이 포함함을 뜻한다. p1은 수동보다 위·아래가 더 조밀하고 오른쪽은 약간 넓다. p2는 수동보다 위·좌·우가 더 조밀하고 아래는 거의 같다. 필수 요소 절단은 보이지 않는다.

## 새 출력 자체의 여백

계획에서 사용하는 보드 너비 338.6667 pt × 2% = 6.7733 pt = 300 DPI에서 28.2222 px이다. 각 페이지의 board/keep 합집합에 이 값이 상하좌우로 붙고, report의 `margin_clipped`는 두 페이지 모두 false다. 실제 보드 외곽선의 측정 너비는 약 1401.5 px이다. plan의 보존 경계가 실제 잉크를 보수적으로 감싸기 때문에 육안상 여백은 다음과 같이 더 크다.

| 쪽 | 왼쪽 | 위 | 오른쪽 | 아래 |
|---|---:|---:|---:|---:|
| 1 | 37px (2.64%) | 32px (2.28%) | 45px (3.21%) | 34px (2.43%) |
| 2 | 33px (2.35%) | 31px (2.21%) | 40px (2.85%) | 34px (2.43%) |

여백은 p1의 D0 왼쪽·빨간 + 위·E 오른쪽·보드 아래, p2의 왼쪽 행 번호·전원 단자 위·D 오른쪽·보드 아래에서 측정했다. 의미상 제외 가능한 p2 제목 조각은 오른쪽 여백 측정에서 제외했다. 색상 필기는 채도차 >60, 최저 채널 <200, 회색/검정은 최저 채널 <180을 기준으로 관련 ROI에서 검출하고 실제 이미지와 대조했다. 안티앨리어싱/선 두께로 약 ±3 px (±0.22 percentage points) 불확실성이 있다. 3.21%인 p1 오른쪽은 2%보다 보수적이지만 불필요한 넓은 주변 공간이나 제외 대상이 남은 사례는 아니다.

# 공통 규칙

- kind: common

교안 범위의 실험 1(p6·p7)과 실험 2(p8)를 만든다(조교 공지 `_350547_1`). C1을 맨바닥에서 만들고,
C2는 C1을 전부 뽑고 새로 짓는다(`rebuild: all`, M14). `U<n>`·슬롯 이름·노드 이름(`A-S'` 등)은 교안 원문이 아닌
이 문서의 식별자다.

전원은 p5의 5V 전압원이다. 전원핀은 칩마다 다르다. `74HC00`·`74HC03`은 pin 14 → VCC(+5V), pin 7 → GND다
(`74HC03`은 가정, M6). **`74670`은 pin 16 → VCC(+5V), pin 8 → GND**다(p8 핀맵). p6 회로도는 전원핀을 그리지 않는다.

다음은 교안 원문이 아닌 배선 운영 규칙이다. 칩을 꽂거나 배선을 바꿀 때 전원을 끄고 극성을 확인한다.
입력 점퍼를 +5V 레일과 GND 레일 사이로 옮기는 것은 교안의 스위치 조작에 해당하므로 전원을 켠 채 한다(M4).
사용하는 입력은 레일이나 구동 출력에 꽂아 플로팅을 막는다. 완성 회로는 `74HC00` 두 패키지와 `74HC03`의
네 게이트를 전부 쓰고 `74670`의 16핀도 전부 쓴다. 그래서 미사용 게이트 입력이 없다. **미사용 게이트 입력은
접지 생략**이 수업 공통 규칙이다(실험01 실측 2026-09-11). 부분 배선 단계에서 아직 배선하지 않은 게이트 입력
(C1의 U2·U3 전부, 배선 중인 게이트의 나머지 입력)과 C2의 아직 안 꽂은 D2~D4도 같은 규칙으로 비워 둔다.
그 게이트 출력과 그 데이터 비트는 그 단계에서 관측하지 않는다. C2에서 뜬 D 입력이 쓰는 비트 값은 정해지지
않으며, 그 비트는 자기 단계에서 다시 쓰고 읽는다.
각 칩의 첫 사용 회로에서 기록표 전 행을 돌린다. 칩 자리는 아래 칩 자리표를 따른다.

C1의 쓰기 규칙은 p7 주의사항이다. WR0과 WR1은 늘 반대로 둔다. WR을 바꾸는 것은 IN0·IN1이 둘 다 0일 때만
한다. IN0과 IN1을 동시에 1로 두지 않는다(M3). 쓴 뒤에는 IN을 GND로 내려 저장하고 OE를 올려 읽는다.
**회로도대로면 래치에 저장되는 값은 WR1과 같고 WR0과 반대다**(M2). C2는 주소·데이터를 바꾸기 전에 WE를 +5V로
올린다. WE·RE는 0일 때 켜진다(p8).

순차 출력은 `lab-netlist/v3`의 observed 노드와 저작한 확인 절차로 적는다. **모든 확인 절차는 교안 원문이 아니다.**
저작한 기대값은 측정 기록이 아니며 명세의 실제 결과 칸은 빈 상태로 둔다. 기본 경로에서 쓰지 않는 절차는
`checklist: diagnostic`을 달았다. 기본 경로의 조립 중 확인은 C1 5단계(A 한 비트 완성)와 C2 1단계(첫 데이터 비트)
두 번이고, 나머지는 교안이 지시한 확인의 기록표 T1, T4, T5다. 진단 절차의 중간 노드는 오실로스코프(p5 준비물)
DC 결합으로 0V·+5V를 본다. 멀티미터가 있으면 그것으로 대신한다.

이 실험에는 클록 입력이 없다. 교안은 신호발생기를 쓰지 않으며 C2의 WE도 레벨 입력이다(TI SDLS193 p2
Write Function Table). 그래서 확인 절차에 `RUN`이나 에지 조작을 두지 않는다.

# C1 · 실험 1) 2bit RAM (74HC00 ×2 + 74HC03)

- kind: circuit
- id: C1
- item: E9.P1
- tables: [T1]
- refs: [T2, T3]
- diagram: 실험09_1_결선도_2bitRAM.png

p6 회로를 짓는다. U1은 A의 NAND SR Latch, U2는 B의 래치, U3은 두 출력단이다. U3의 게이트와 핀 번호는
p6 회로도 그대로다. **U1·U2는 두 게이트의 자리를 맞바꿨다** — 래치 출력 Q는 pin 6, 리셋 쪽 입력 게이트는
pin 12·13→11이다(M13). p6의 스위치 여섯 개는 입력 점퍼로 대신한다. 점퍼 끝을 +5V 레일에 꽂으면 1, GND 레일에 꽂으면
0이다(M4). **WR1은 U1 pin 2와 U2 pin 2에, WR0은 U1 pin 12와 U2 pin 12에 함께 들어간다**(p6, M2, M13).
`74HC03` 출력 네 개에는 10kΩ 풀업을 단다(p6). A부터 다 짓고 OUT0을 확인한 뒤 B를 짓는다.
**이 순서와 단계 절차는 교안 원문이 아니다.** 단계마다 전원을 끄고 추가한다.

| M2 | **p6 범례와 회로도가 WR에서 어긋난다.** 범례는 `OE0, IN0, WR0: A part params`, `OE1, IN1, WR1: B part params`다. 그러나 회로도는 `WR 1`을 U1·U2의 pin 2(세트 쪽)에, `WR 0`을 U1·U2의 pin 5(리셋 쪽)에 함께 잇는다(p6 이미지를 3배로 키워 접속점 점 확인). 회로도대로 셈하면 IN=1일 때 WR1=1·WR0=0이면 Q=1, WR0=1·WR1=0이면 Q=0이라 저장값은 WR1과 같고 WR0과 반대다. p7 주의 2가 `WR0 = WR1'`을 요구하는 것은 이 공유 배선과 맞는다. 또 비트마다 WR 하나로 세트·리셋 양쪽을 주려면 인버터가 필요한데, 준비물에 인버터 칩이 없고 74HC00·74HC03의 게이트는 남는 것이 없다. 그래서 회로도의 공유 배선을 의도로 보고 범례는 입력을 A·B로 묶어 적은 것으로 읽는다. 이 문서는 회로도대로 배선하고 T1을 이 셈으로 채웠다. 이 판단과 셈은 교안 원문이 아니다 | 실험 전 조교 확인은 필수로 두지 않는다.

# 배치 탐색 — 보고서/실험09/결선도/배치.py

배선표가 바뀌면 다시 잰다 — 고른 layout 은 `배치.py` 의 `LAYOUT` 과 netlist `kind: layout` 표에 옮겨 적는다.

```json
{
 "hash": "3ae3c64fea73430d",
 "layout": {
  "bridge": [
   34,
   35
  ],
  "bridge_policy": "lower-clearance-v1",
  "leds": {
   "ram16": {
    "Q1": 16,
    "Q2": 21,
    "Q3": 26,
    "Q4": 31
   },
   "ram2": {
    "OUT0": 3,
    "OUT1": 8
   }
  },
  "slots": {
   "S1": 5,
   "S2": 15,
   "S3": 25,
   "S4": 8
  }
 }
}
```

실험08 과 같은 방식이다. `place_search --mode fixed` 는 어댑터당 회로 하나만 받아 C1·C2 를 함께 못 재므로, 손으로 만든 후보를 전 보드 `verify()` 로 쟀다. 256회 탐색이 아니므로 이 범위의 최선이다. 고르는 규칙은 고정 LED 탐색과 같다 — 통과한 최단 길이의 ×1.10 안에서 밀도 → 꺾임 → 길이 최소. 길이·꺾임·밀도는 superset 판(모든 단계의 선) 칸 단위다.

`verify()` 가 안 보는 두 가지를 먼저 걸렀다 — 입력 점퍼끼리 엇갈림, 신호 이름 배지가 번호 원·배선·홀을 가림(`tests/test_breadboard_readability.py` 의 `_badge_hits`).

## C2 (S4 · LED Q1~Q4)

- 74670 행 3~13 중 입력 점퍼가 엇갈리지 않는 것은 8·9행뿐이다(위쪽은 전원 잭 선이 레일 행을 먼저 쓴다).
- LED 를 3·8·13·18행에 두면 사슬 GND 행(6·11·16·21)이 f쪽 입력 다섯 행 안에 반드시 하나 들어와 배지를 가린다. 그래서 LED 윗행 시작 b 를 칩 옆·아래(13~17)로 내려 쟀다. 5행 간격, 위→아래 Q1→Q4 는 그대로다.

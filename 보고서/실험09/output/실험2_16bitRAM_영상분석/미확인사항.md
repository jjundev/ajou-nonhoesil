# 미확인 사항

발언·화면 관찰·사용자 설명을 구분한 기록이다. 입력값을 출력에서 역산해 확정하지 않는다.

- 촬영이 주소 00 쓰기 뒤('쓴 상태')에서 시작해 S1·W1 은 영상에 없음
- T5 휘발성 실험(전원 끊었다 다시 켜고 읽기)은 이 영상에 없음
- LED 위치와 Q1~Q4 핀 대응, 각 스위치 값은 화면으로 확인하지 못함
- 185~191초 4번째 LED 점등의 원인 미확인

## writes · p1 · 0~150초

화면 관찰: 쓰기 동안 LED 네 개 모두 소등. 손이 회로를 자주 가림

전사 근거: transcript_p1 0.7초 — 쓴 상태.

전사 근거: transcript_p1 39.1초 — 그럼 주소 01에 다가 쓰는 과정을 진행

전사 근거: transcript_p1 54.4초 — 주소를 10으로 바꾼다

전사 근거: transcript_p1 101초 — 다시 쓰기 모드로 해서 11로 바꾼다

전사 근거: transcript_p1 143.8초 — 다시 올리면 쓰기 끝.

- 미확인: 주소 00 쓰기(W1)는 촬영 시작 전에 끝났다는 발언뿐

- 미확인: WB·WA·D·WE 스위치 값은 화면으로 확인 못함

## read00 · p1 · 150~172초

화면 관찰: 156~170초 맨 위(1번째) LED만 점등

전사 근거: transcript_p1 148.4초 — 지금부터 읽어 보겠습니다.

전사 근거: transcript_p1 155.5초 — q1이 켜지고

- 미확인: LED 위치와 Q1~Q4 핀 대응은 배선 추적으로 확인 못함

## read01 · p1 · 172~185초

화면 관찰: 174~184초 위에서 2번째 LED만 점등

전사 근거: transcript_p1 167.3초 — 두 번째 거 q2만 켜지게

## addr_transition · p1 · 185~192초

화면 관찰: 185~191초 맨 아래(4번째) LED만 점등한 뒤 193초부터 3번째로 바뀜

전사 근거: transcript_p1 188초 — 옮겨서 지금 주소 10 그러니까 세 번째 거

- 미확인: RB·RA 를 바꾸는 순서 사이의 중간 상태(주소 11)로 보이나 스위치 조작을 화면으로 확인하지 못함

## read10_11 · p1 · 192~205.48초

화면 관찰: 193~199초 3번째 LED만 점등, 200~205초 4번째 LED만 점등

전사 근거: transcript_p1 188초 — r a를 5볼트로 옮기면 주소 11 그러니까 마지막 오케이.

- 오디오 직접 청취 확인 없음. 전사 대조와 수치상 동기 검증은 청감 자연스러움 검증과 다르다.

# 근거와 범위

2026-2 배포본 `강의노트/실험9. RAM.pdf`(8쪽)를 사용한다. **표지 표기는 `25-1 논리회로실험`이다.**
현 학기용으로 내용이 개정됐다고 가정하지 않는다. 과거 학기 아카이브 `from_the_past/정리/강의노트/실험9.pdf`는
근거로 쓰지 않았다.
실험 범위는 `config.EXPERIMENT_SCOPE[9]`의 `1`, `2`다(조교 공지 `_350547_1`). 교안의 실험 항목이 이 둘뿐이라
뺀 항목은 없다.

전 쪽을 텍스트 추출과 vision으로 함께 읽었다. p4·p6·p8의 그림은 래스터라 텍스트 층에 핀 번호·배선이 없다.
p6 회로도는 원본 이미지가 606×482 JPEG라 그 이미지를 뽑아 3배로 키워 vision으로 접속점을 읽었다.
p4의 부울식과 p7·p8의 오버바(`IN1`, `WR1`, `WE`, `RE` 위의 바)는 텍스트 추출에서 사라진다.

필요한 부품은 p5 준비물대로 5V 전압원, `74HC00` 2개, `74HC03` 1개, `74670` 1개, 발광 다이오드 4개,
330Ω 4개, 10kΩ 4개다. p5는 오실로스코프도 적었지만 p6~p8 절차는 오실로스코프 측정을 지시하지 않는다.
p6 회로도의 입력 스위치 여섯 개(`OE 0`·`In 0`·`WR 0`·`OE 1`·`In 1`·`WR 1`)는 준비물에 없다.
교안 표기와 회로가 갈리는 자리, 준비물에 없는 부품, 74670의 실물 계열은 `../결선도/netlist.md`의
`# 미확정 사항`에서 관리한다.

# E9.P1 · 실험 1) 2bit RAM

p6은 "아래 회로를 구성하고, A와 B 각각의 Output에 LED를 연결한다", "A 또는 B에 값을 쓰거나 읽어보고,
LED를 통해 결과를 확인한다"라고 지시한다. 회로는 `74HC00` 두 패키지와 `74HC03` 한 패키지다.
A와 B는 각각 `74HC00` 한 패키지(NAND 넷)로 NAND SR Latch를 만들고, `74HC03` 한 패키지의 네 게이트가
두 출력단을 맡는다. `74HC03` 출력마다 10kΩ 풀업이 달린다(p6 회로도의 `10K` 네 개).

p7 주의사항은 세 가지다. (1) "한 번에 하나의 Bit(A 또는 B)에만 데이터를 Write 한다." 괄호 식은 vision으로
`IN0 = IN1'`이다. (2) "Write Value는 반드시 반전 관계를 갖도록 한다." 괄호 식은 `WR0 = WR1'`이고, 이유는
"NAND SR Latch에 00이 입력되어 출력이 부정 상태가 되는 것을 방지하기 위함"이다. (3) "Write 후에는 Write
Select(IN)를 접지하여 값을 저장하고, Read Select(OE)에 전압을 가하여 저장된 값을 읽는다." 주의 3의 이유로
p7은 "Read, Write를 모두 켜게 되면, WR 값이 즉시 출력되며 기존 저장된 값을 Read 할 수 없음"이라고 적는다.

**p6 회로도에서 `WR 0`과 `WR 1`은 A와 B 양쪽 래치에 다 들어간다.** 범례는 `WR0`을 A의 값, `WR1`을 B의
값으로 적었지만, 회로도의 두 수직선은 `WR 1`을 두 래치의 세트 쪽 NAND(pin 1·2→3의 pin 2)에, `WR 0`을
두 래치의 리셋 쪽 NAND(pin 4·5→6의 pin 5)에 잇는다. 이 판독은 p6 이미지를 3배로 키워 접속점 점을 확인한 것이다.
회로도를 따라 셈하면 IN0=1, WR1=1, WR0=0일 때 pin 3이 0이 되어 A의 Q(pin 11)가 1이 되고, IN0=1, WR0=1,
WR1=0이면 pin 6이 0이 되어 Q가 0이 된다. **그래서 회로도대로면 저장되는 값은 WR1과 같고 WR0과 반대다.
이 셈은 교안 원문이 아니다.** 범례와 회로도의 어긋남은 미확정 표에 올렸다. 같은 셈으로 출력은 OE·Q다
(`74HC03` 첫 게이트가 (OE·Q)', 둘째 게이트가 그것을 다시 뒤집는다). p4의 `Output = (Selection Input)·
(Read or Write)·Q`와 같은 꼴이다. **이 셈과 대응도 교안 원문이 아니다.**

p7 주의 1의 `IN0 = IN1'`을 글자 그대로 지키면 IN0과 IN1 중 하나는 늘 1이라, 주의 3의 "IN을 접지하여 값을
저장"과 함께 지킬 수 없다. **이 문서는 주의 1을 "IN0과 IN1을 동시에 1로 두지 않는다"로 읽고, 쓰기 사이에는
둘 다 0으로 둔다. 이 해석은 교안 원문이 아니다.** WR0·WR1은 IN이 둘 다 0일 때만 바꾼다.

**T1은 교안에 원래 있던 표가 아니라 p6·p7 절차를 기록하기 위해 만든 양식이다. 교안 원문이 아니다.**
`source: manual:p6`은 절차의 출처이며 셀 표의 전사를 뜻하지 않는다. 쓰는 값과 순서(A←1, B←0, B←1, A←0)도
교안 원문이 아니다. A·B 각각에 0과 1을 한 번씩 쓰고, 한쪽을 쓰는 동안 다른 쪽이 유지되는지 보도록 골랐다.
전원을 켠 직후의 래치 값은 정해지지 않으므로, 아직 쓰지 않은 쪽의 OE는 0으로 둬서 출력이 0으로 정해진 행만
싣는다. OUT 칸은 회로도에서 셈한 예상값이다. 실제 결과 칸에 맞으면 ✓, 다르면 본 값을 적는다.

T2와 T3은 p4 이론의 1 bit RAM 표와 래치 표를 옮긴 참조표다. p4의 1 bit RAM은 AND 게이트와 인버터로
그린 회로이고 실험 1)의 2bit RAM과 회로가 다르다. T2의 행 머리 `Write`(2·3행)와 `Read`(4행)는 표 밖 괄호
표기라 셀에 넣지 않았다. T3은 p4 그림의 `RS-flip fop`(교안 오자) 블록의 표이고, S=R=1이 X인 Active High
표다. 실험 1)의 NAND SR Latch는 입력이 Active Low라 피해야 할 입력이 p7이 말한 `00`이다. **이 대응은 교안
원문이 아니다.** p4 안에서 부울식의 S·R과 그림·T2가 서로 어긋나고, T2 첫 행(Selection Input=0이면 Q=0)도
T3의 유지 행과 맞지 않는다. 셀은 교안 글리프 그대로 두고 어긋남은 미확정 표에 올렸다.

# E9.P2 · 실험 2) 16bit RAM (IC 74670)

p8은 세 가지를 지시한다. "Data sheet를 참고하여, Output에 LED를 연결한다." "4개 주소에 4bit 값을 쓰거나
읽어보고, LED를 통해 결과를 확인한다." "칩의 전원을 제거하였다가 다시 연결한 뒤, 저장해 두었던 값의 변화를
확인한다. (휘발성 실험)" p8 핀맵은 D2=1, D3=2, D4=3, RB=4, RA=5, Q4=6, Q3=7, GND=8, Q2=9, Q1=10,
RE=11, WE=12, WB=13, WA=14, D1=15, Vcc=16이다. RE·WE는 범례대로 0일 때 켜진다.
p8 핀맵은 TI SDLS193 p1의 SN74LS670 N 패키지 핀 배치와 같다(`GR`=11, `GW`=12).

**T4는 교안에 원래 있던 표가 아니라 p8 절차 2를 기록하기 위해 만든 양식이다. 교안 원문이 아니다.**
쓰는 값(주소 00←0001, 01←0010, 10←0100, 11←1000)은 교안에 없다. 주소마다 다른 LED 하나가 켜지도록 골라,
주소를 잘못 고르거나 데이터 선 하나가 붙어 있으면 다른 LED가 켜지게 했다. 쓰는 동안 RE=1로 두어 출력을
끈다(p7 주의 3과 같은 취지이며, 74670에 대해서는 교안 원문이 아니다). 주소를 바꾸기 전에 WE를 1로 올린다.
TI SDLS193 p2 Write Function Table은 WE(`GW`)가 L인 동안 선택한 주소가 `Q = D`, H면 유지(`Q0`)로
적는다. 그래서 WE가 0인 채 주소를 바꾸면 다른 주소에도 써진다. **이 순서와 근거 인용은 교안 원문이 아니다.**
Q 칸은 이 쓰기 순서에서 셈한 예상값이다.

**T5는 p8 절차 3(휘발성 실험)을 기록하기 위해 만든 양식이다. 교안 원문이 아니다.** 교안은 전원을 다시
연결한 뒤 "값의 변화를 확인"하라고만 하고 예상값을 주지 않는다. 그래서 Q 칸을 비워 두고 본 값을 적는다.
교안은 칩의 전원을 어떻게 제거할지 정하지 않는다. 이 문서는 전원 공급기 출력을 끄는 방법을 쓴다
(미확정 표 참고). 다시 켠 뒤에는 쓰기 없이 T4와 같은 순서로 네 주소를 읽는다.

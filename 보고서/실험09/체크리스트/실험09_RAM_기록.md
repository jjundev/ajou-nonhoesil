# 실험9 RAM 기록

진리표 — 확인 칸: `✓` 일치 / 값 = 불일치 시 실제 관찰값 / 공란 = 미확인.
스텝표 — 빈 칸에 읽은 값을 **단위와 함께** 적는다. 확인 칸이 없다.
파형 — 스케치에 그리고 판독 조건 줄을 채운다.
실제 결과 — 맞으면 ✓, 다르면 실제 값을 적어요. 안 본 행은 비워 둬요.
표를 통째로 진행하지 않았으면 그 표 아래에 `- 실험을 진행하지 않았음.` 을 적는다.

## E9.P1 · 실험 1) 2bit RAM
IC: 74HC00, 74HC03 · 판독: LED

### T1 · 2bit RAM 쓰기·읽기 기록

> A·B에 0과 1을 따로 쓰고 IN을 접지한 뒤 OE로 읽어, 쓴 값이 LED에 나오고 다른 쪽 값은 유지되는지 확인한다.

| 스텝 | 조작                                                                     | 입력 설정                                | 예상 켜지는 LED | 예상 꺼지는 LED | 실제 결과 |
|------|--------------------------------------------------------------------------|------------------------------------------|-----------------|-----------------|-----------|
| S1   | 모든 입력을 GND에 두고 WR1만 +5V에 둔 채 전원을 켠다                     | OE0=0; IN0=0; WR0=0; OE1=0; IN1=0; WR1=1 | 없음            | ①OUT0 · ②OUT1   |           |
| W1   | A에 1 쓰기: IN0을 +5V로 올린다                                           | OE0=0; IN0=1; WR0=0; OE1=0; IN1=0; WR1=1 | 없음            | ①OUT0 · ②OUT1   |           |
| R1   | IN0을 GND로 내려 저장한 뒤 OE0을 +5V로 올려 A를 읽는다                   | OE0=1; IN0=0; WR0=0; OE1=0; IN1=0; WR1=1 | ①OUT0           | ②OUT1           |           |
| W2   | B에 0 쓰기: OE0을 내리고 WR0을 +5V, WR1을 GND로 바꾼 뒤 IN1을 올린다     | OE0=0; IN0=0; WR0=1; OE1=0; IN1=1; WR1=0 | 없음            | ①OUT0 · ②OUT1   |           |
| R2   | IN1을 내려 저장한 뒤 OE0·OE1을 올려 A·B를 읽는다                         | OE0=1; IN0=0; WR0=1; OE1=1; IN1=0; WR1=0 | ①OUT0           | ②OUT1           |           |
| W3   | B에 1 쓰기: OE0·OE1을 내리고 WR0을 GND, WR1을 +5V로 바꾼 뒤 IN1을 올린다 | OE0=0; IN0=0; WR0=0; OE1=0; IN1=1; WR1=1 | 없음            | ①OUT0 · ②OUT1   |           |
| R3   | IN1을 내려 저장한 뒤 OE0·OE1을 올려 A·B를 읽는다                         | OE0=1; IN0=0; WR0=0; OE1=1; IN1=0; WR1=1 | ①OUT0 · ②OUT1   | 없음            |           |
| W4   | A에 0 쓰기: OE0·OE1을 내리고 WR0을 +5V, WR1을 GND로 바꾼 뒤 IN0을 올린다 | OE0=0; IN0=1; WR0=1; OE1=0; IN1=0; WR1=0 | 없음            | ①OUT0 · ②OUT1   |           |
| R4   | IN0을 내려 저장한 뒤 OE0·OE1을 올려 A·B를 읽는다                         | OE0=1; IN0=0; WR0=1; OE1=1; IN1=0; WR1=0 | ②OUT1           | ①OUT0           |           |

## E9.P2 · 실험 2) 16bit RAM (IC 74670)
IC: 74670 · 판독: LED

### T4 · 16bit RAM 쓰기·읽기 기록

> 네 주소에 서로 다른 4bit 값을 쓴 뒤 주소마다 읽어, 그 주소에 쓴 값이 LED에 나오는지 확인한다.

| 스텝 | 조작                                                                                  | 입력 설정                                                  | 예상 켜지는 LED | 예상 꺼지는 LED       | 실제 결과 |
|------|---------------------------------------------------------------------------------------|------------------------------------------------------------|-----------------|-----------------------|-----------|
| S1   | WE·RE를 +5V, 나머지를 GND에 둔 뒤 D1만 +5V로 옮기고 전원을 켠다(주소 00, 데이터 0001) | WB=0; WA=0; WE=1; D4=0; D3=0; D2=0; D1=1; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| W1   | WE를 GND로 내려 주소 00에 0001을 쓴다                                                 | WB=0; WA=0; WE=0; D4=0; D3=0; D2=0; D1=1; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| A2   | WE를 먼저 +5V로 올린 뒤 주소 01, 데이터 0010으로 바꾼다                               | WB=0; WA=1; WE=1; D4=0; D3=0; D2=1; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| W2   | WE를 GND로 내려 주소 01에 쓴다                                                        | WB=0; WA=1; WE=0; D4=0; D3=0; D2=1; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| A3   | WE를 먼저 올린 뒤 주소 10, 데이터 0100으로 바꾼다                                     | WB=1; WA=0; WE=1; D4=0; D3=1; D2=0; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| W3   | WE를 GND로 내려 주소 10에 쓴다                                                        | WB=1; WA=0; WE=0; D4=0; D3=1; D2=0; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| A4   | WE를 먼저 올린 뒤 주소 11, 데이터 1000으로 바꾼다                                     | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| W4   | WE를 GND로 내려 주소 11에 쓴다                                                        | WB=1; WA=1; WE=0; D4=1; D3=0; D2=0; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| H1   | WE를 +5V로 올려 쓰기를 끝낸다                                                         | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=0; RA=0; RE=1 | 없음            | ④Q4 · ③Q3 · ②Q2 · ①Q1 |           |
| R1   | RE를 GND로 내려 주소 00을 읽는다                                                      | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=0; RA=0; RE=0 | ①Q1             | ④Q4 · ③Q3 · ②Q2       |           |
| R2   | RA를 +5V로 옮겨 주소 01을 읽는다                                                      | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=0; RA=1; RE=0 | ②Q2             | ④Q4 · ③Q3 · ①Q1       |           |
| R3   | RB를 +5V, RA를 GND로 옮겨 주소 10을 읽는다                                            | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=1; RA=0; RE=0 | ③Q3             | ④Q4 · ②Q2 · ①Q1       |           |
| R4   | RA를 +5V로 옮겨 주소 11을 읽는다                                                      | WB=1; WA=1; WE=1; D4=1; D3=0; D2=0; D1=0; RB=1; RA=1; RE=0 | ④Q4             | ③Q3 · ②Q2 · ①Q1       |           |

### T5 · 16bit RAM 휘발성 기록

> 칩 전원을 끊었다 다시 넣은 뒤 네 주소를 읽어, T4에서 쓴 값이 남는지 본 대로 적는다.

| 스텝 | 조작                                                                                                                             | RB | RA | RE | Q4 | Q3 | Q2 | Q1 |
|------|----------------------------------------------------------------------------------------------------------------------------------|----|----|----|----|----|----|----|
| P1   | T4를 마친 상태에서 전원 공급기 출력을 끄고 몇 초 뒤 다시 켠다. WE는 +5V에 둔 채 쓰지 않는다. RB·RA를 GND로 옮겨 주소 00을 읽는다 | 0  | 0  | 0  |    |    |    |    |
| P2   | 주소 01을 읽는다                                                                                                                 | 0  | 1  | 0  |    |    |    |    |
| P3   | 주소 10을 읽는다                                                                                                                 | 1  | 0  | 0  |    |    |    |    |
| P4   | 주소 11을 읽는다                                                                                                                 | 1  | 1  | 0  |    |    |    |    |

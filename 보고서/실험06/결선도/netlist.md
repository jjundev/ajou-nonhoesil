# 공통 규칙

- kind: common

- 전원은 준비물 p6 의 `5V 전압원` 이다(교안 판본은 M1). `74HC00`·`74HC04` 는 계열 표준대로 pin 14 → VCC(+5V),
  pin 7 → GND 다. **`74HC76` 은 16핀이고 pin 5 → VCC(+5V), pin 13 → GND** 다 — 교안 p11 머리가 빨간
  글씨로 "GND와 Vcc 위치 유의" 라고 적는다. 칩 모서리(16·8)가 아니다
- 핀 번호는 **교안 회로도(p7·p8)와 핀 배치 그림(p11)이 적어 둔 번호 그대로**다. 교안 회로도는 U 번호를
  붙이지 않는다 — `U1` = `74HC00`, `U2` = `74HC04`, `U3` = `74HC76` 은 이 결선도가 붙였다(M8)
- **사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지). **미사용 게이트의 입력은 접지하지
  않는다** — 교안이 미사용 핀 처리를 말하지 않는 주차이고, 실험01 실측(2026-09-11)에서 접지 생략이
  결과에 영향이 없었다. 이 규칙은 교안 원문이 아니다(M7). 미사용 입력은 `74HC04` 의 인버터 다섯
  (pin 3·5·9·11·13)과 `74HC76` 2번 플립플롭(pin 6·7·8·9·12)이다
- **칩을 꽂거나 뽑을 때는 전원을 끈다.** 교안 원문이 아닌 안전 절차다(M15)
- **교안 실험 2-2(`74HC74`)·3-1(`74HC10`·`74HC00`)은 하지 않는다** — 조교 공지 `_350547_1`. 그래서
  C3 은 C2 위에 짓지 않고 새로 짓는다
- **C2(D 래치)는 C1(SR 래치) 위에 짓는다.** 교안 p8 회로가 p7 회로의 `S` 자리에 `D`, `R` 자리에
  `D'` 를 넣은 것이라, C1 의 `R` 입력 점퍼 한 가닥만 뽑고(`1걷기`) `74HC04` 와 두 가닥을 더한다.
  `S` 입력 점퍼는 그대로 두고 이제부터 `D` 라 부른다(M9)
- **C3(JK F/F)은 C2 를 전부 뽑고 새로 짓는다**(`rebuild: all`, M10). 칩이 전부 바뀌고(`74HC00`·
  `74HC04` → `74HC76`) 전원핀 자리가 달라서다. **LED 사슬도 다시 꽂는다** — `74HC00` 은 `Q'`(pin 11)가
  `Q`(pin 8)보다 위 행이고 `74HC76` 은 `Q`(pin 15)가 `Q'`(pin 14)보다 위 행이라, 사슬을 남기면 칩에서
  LED 로 건너는 두 선이 서로 엇갈린다(v2 렌더러 R10)
- **입력은 점퍼선으로 +5V(=1) 또는 GND(=0) 에 직접 물린다.** 띄워두지 않는다. 교안은 입력을 무엇으로
  주는지 말하지 않는다 — 스위치도 클럭 발생기도 준비물에 없다(M2). `CLK` 의 하강 에지(`1->0`)는 `CLK`
  점퍼의 레일 쪽 끝을 +5V 레일에서 GND 레일로 옮겨 꽂아 만든다
- **래치는 첫 입력으로 Set 또는 Reset 을 넣는다** — 교안 p7 원문 "초기 Feedback 값(Q, Q’) 설정을
  위해, 첫 입력은 Set 또는 Reset을 인가". 그래서 T1·T2 는 표 첫 행(`Q(t-1)`)부터 돌리지 않는다 — Reset·Set
  행을 먼저 넣고, 그 뒤 `Q(t-1)` 행으로 앞 행 값이 그대로 남는지 본다. 이 실행 순서와 "전원 직후 `Q` 는
  정해지지 않는다" 는 판단은 교안 원문이 아니다(M16)
- LED 는 준비물 p6 `발광 다이오드 (4개)`·`저항 330Ω (4개)` 중 둘을 쓴다 — 출력 `Q`·`Q'` 마다 하나,
  `출력 → 330Ω → LED → GND` 로 출력 1 에서 켜진다. 교안은 LED 배선을 그리지 않는다(M3). 기록 칸은
  교안 표대로 `Q(t)` 하나다 — `Q'` LED 에는 기록 칸이 없다(M4)
- **기반**은 단계마다 세지 않는 배선이다 — 칩 꽂기·전원선·레일 브리지(바깥 레일과 가운데 레일을
  잇는 선)·LED 사슬 부품. **배너**는 체크리스트가 회로 첫머리에 찍는 칩 교체·걷기 안내다.
  `R7`~`R10` 은 결선도 렌더러의 검사 규칙이다(`breadboard-diagram` SKILL — R7 칩 한쪽 리드 ≤ 8, R8 칩
  사이 선이 쪽을 안 바꿈, R9 칩은 좌 블록, R10 건너는 선 순서 = LED 순서)
- **칩 자리는 고정이다** (아래 `# 칩 자리표`). 그림의 **회색 선은 손대지 않는다** — 걷을 선은 걷기
  그림(빨간 점선), 새 선은 단계 그림(회색 기준선 위 번호)이 지시한다
- 한 신호가 여러 핀으로 가면(팬아웃) **목적지 스트립에서 다음 목적지로 이어 간다**(예: `E` 는 입력
  점퍼 → U1 pin 2 → U1 pin 4). 전기적으로는 한 노드다. 래치의 되먹임 두 가닥(pin 8 → pin 12, pin 11 →
  pin 10)도 칩 f쪽 안에서 잇는다. 교안 회로도는 가지로 그린다 — 이어 가는 순서는 배선 편의다(M15)
- 핀 줄의 `※` 뒤는 그 점의 신호 이름과 명세 표 대응을 적은 주석이다(배선 지시가 아니다)
- `## 노드` 표의 `'` 는 부울 보수다(`(S·E)'` = NAND 출력). 명세 셀의 `Q(t-1)'` 은 상태 토큰이라 뜻이 다르다
- **레일 빈 행**은 바깥 레일에 구멍이 없는 행(2·8·14·20·…, 6행마다)이다. `좌 GND레일7행` 은 왼쪽 블록
  바깥 GND 레일의 7행 구멍이다

# 꼭 읽을 것

- kind: must-read

- **`74HC76` 은 pin 5 가 +5V, pin 13 이 GND** 예요(16·8 이 아니에요). 교안 p11 도 "GND와 Vcc 위치
  유의" 라고 빨간 글씨로 적어요
- **래치(C1·C2)는 Set 이나 Reset 행부터 해요** — 표 첫 행(`Q(t-1)`)부터 하지 않아요. 그 뒤 `Q(t-1)`
  행에서 앞 행 값이 그대로 남는지 봐요
- `74HC76` 의 `SET`(pin 2)·`RESET`(pin 3)은 **0 일 때 작동해요**(Active Low). J·K 행을 볼 때는 둘 다
  +5V 에 꽂아요. **1~3행 동안 `CLK` 는 GND 에 둬요.** 하강 에지는 `CLK` 점퍼를 +5V 에 올렸다가 J·K 를
  꽂은 뒤 **GND 레일로** 옮겨 꽂아 만들어요
- **C2 는 C1 에서 `R` 점퍼 한 가닥만 뽑아요** — `S` 점퍼가 그대로 `D` 가 돼요. **C3 은 전부 뽑고 새로
  지어요** — 칩·전원선·LED 사슬까지 뽑고 레일 브리지만 남겨요

| 회로 | LED (위 → 아래) | 기록 칸 |
|---|---|---|
| C1·C2 (`74HC00`) | `Q'`(pin 11) · `Q`(pin 8) | `Q` 만 |
| C3 (`74HC76`) | `Q`(pin 15) · `Q'`(pin 14) | `Q` 만 |

# 핀아웃 출처

- kind: sources

**교안이 신호핀 번호를 직접 준다** — p7·p8 회로도가 `74HC00` 의 게이트 넷(1·2→3, 4·5→6, 9·10→8,
12·13→11)과 `74HC04` 의 인버터 하나(1→2)를, p11 핀 배치 그림이 `74HC76` 의 16핀 전부(전원 5·13 포함)를
적어 두었다. 셋 다 래스터라 렌더해 vision 으로 읽었다. 교안에 없는 `74HC00`·`74HC04` 전원핀은 제조사
1차 데이터시트의 저장소 기록으로 확인했고, `74HC76` 은 이번에 ST 데이터시트를 직접 열어 교안 그림과
맞댔다. 교안이 적은 신호핀도 전부 데이터시트와 일치한다.

- `74HC00` — Nexperia 74HC00; 74HCT00, Quad 2-input NAND gate, Rev. 11 (2025-04-29) §5.2 Pin description.
  저장소 기록 경유: `보고서/실험01/결선도/netlist.md` § 핀아웃 출처가 같은 판을 인용한다(`.claude/데이터시트_출처.md`
  Nexperia 표의 `74HC_HCT00` 행). 쿼드 2입력 게이트의 표준 배치 `1A=1, 1B=2, 1Y=3, 2A=4, 2B=5, 2Y=6, GND=7,
  3Y=8, 3A=9, 3B=10, 4Y=11, 4A=12, 4B=13, VCC=14` 이고 교안 p7 의 게이트 넷과 맞는다
- `74HC04` — Nexperia 74HC04; 74HCT04, Hex inverter, Rev. 10 (2024-02-16) §5.2 Table 2. 저장소 기록 경유:
  `보고서/실험05/결선도/netlist.md` § 핀아웃 출처가 입력 `1, 3, 5, 9, 11, 13`, 출력 `2, 4, 6, 8, 10, 12`,
  GND 7, VCC 14 로 옮겼다
- `74HC76` — STMicroelectronics M74HC76, Dual J-K flip flop with preset and clear (2001-08) p1 Pin connection
  and IEC logic symbols · p2 Pin description · Truth table.
  `https://media.digikey.com/pdf/data sheets/st microelectronics pdfs/m74hc76.pdf` 를 2026-10-11 에 직접 열어
  확인: IEC 기호 `1PR=2, 1J=4, 1CK=1, 1K=16, 1CLR=3, 1Q=15, 1Q'=14, 2PR=7, 2J=9, 2CK=6, 2K=12, 2CLR=8,
  2Q=11, 2Q'=10`, Pin description `GND=13, Vcc=5`, `CK` 는 "HIGH to LOW edge triggered", `PR`·`CLR` 은
  Active LOW. 교안 p11 그림의 빨간·파란 라벨(`SET` = `PR`, `RESET` = `CLR`)과 전부 같다. Pin description
  표는 `10, 14` 를 `1Q', 2Q'` 에 묶어 적어 짝 순서가 안 보인다 — IEC 기호 쪽 번호를 따랐다. **이 문서에는
  `Obsolete Product(s)` 워터마크가 찍혀 있다**(M8). 서지는 `.claude/데이터시트_출처.md` ST 표에 있다

교안 p11 진리표의 `CLK` 하강 에지 그림은 같은 쪽 기호의 `CLK` 버블, 본문 "Falling Edge", ST 진리표의 `CK`
계단과 셋 다 일치한다 — 교안 안에서 그림끼리 어긋나는 자리는 없다.

# C1 · 실험 1) SR Latch with Enable (74HC00)

- kind: circuit
- id: C1
- item: E6.P1
- tables: [T1]
- diagram: 실험06_1_결선도_SR래치.png

교안 p7 회로도 그대로. 이 주차 첫 회로라 맨바닥에서 시작한다. 칩이 하나라 단계 표를 두지 않는다 —
칩 전원·레일 브리지·LED 두 사슬·입력 점퍼 셋·칩 안 배선 다섯(E 이어 감 하나와 게이트 사이 넷)을 한
번에 꽂고 T1 을 돌린다. 첫 입력은 교안 원문대로 Set(T1 4행, `E=1, S=1, R=0`) 또는 Reset(3행, `E=1, S=0,
R=1`)이고, 그 뒤 1·2행(유지), 마지막에 5행(`S=R=1`) 순서로 본다(M16).

`## 노드` 표에는 입력만으로 값이 정해지는 앞단 NAND 두 출력만 싣는다. `Q`·`Q'` 는 앞 상태에 따라 값이
갈리는 되먹임 노드라 기록표 입력의 식으로 적을 수 없다(M13). T1 이 맞지 않으면 아래 두 노드부터 찍어
본다.

## 노드

| 노드 | 식 | 핀 |
|---|---|---|
| (S·E)' | (S·E)' | U1 pin 3 |
| (E·R)' | (E·R)' | U1 pin 6 |

- U1 = 74HC00 (quad 2-input NAND, DIP-14) — K1
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 S
  - pin 2  ← 입력 E          (E 점퍼, 거기서 pin 4 로 이어 감)
  - pin 2  → U1.pin4          (E 이어 감)
  - pin 4  ← U1.pin2          (E)
  - pin 5  ← 입력 R
  - pin 3  → U1.pin9          ((S·E)' → 뒷단 NAND)
  - pin 6  → U1.pin13         ((E·R)' → 뒷단 NAND)
  - pin 8  → U1.pin12         (Q 되먹임)
  - pin 11 → U1.pin10         (Q' 되먹임)
  - pin 8  → 330Ω → LED Q 애노드, LED 캐소드 → GND    ※ Q, T1 의 Q(t) 열
  - pin 11 → 330Ω → LED Q' 애노드, LED 캐소드 → GND   ※ Q' (기록 칸 없음 — M4)
  - 미사용 입력핀: 없음 (게이트 넷을 다 쓴다)

# C2 · 실험 2-1) D Latch with Enable (74HC00 + 74HC04)

- kind: circuit
- id: C2
- item: E6.P2-1
- tables: [T2]
- diagram: 실험06_2-1_결선도_D래치.png

교안 p8 회로도 그대로, **C1 위에 짓는다**(M9). `1걷기` 에서 C1 의 `R` 입력 점퍼 한 가닥을 뽑고, 1단계에서
`74HC04`(U2)를 K2 에 꽂아 전원을 잇고 두 가닥을 더한다. C1 의 `S` 점퍼(U1 pin 1)가 그대로 `D` 가 되고,
`E` 점퍼·칩 안 배선 다섯·LED 두 사슬은 손대지 않는다. 걷기 주소는 `배치.py` 가 뽑은 걷기 그림의 주소다(M11).

1단계의 관측 노드는 `D'` 다. `D'` 에는 LED 가 없다 — `E=1` 에서 `D` 를 0·1 로 바꿔 LED `Q`·`Q'` 가 따라
바뀌는지로 본다(`D=0` 에서 `Q` 를 0 으로 내리는 것이 `D'` 다). 멀티미터·로직프로브가 있으면 U2 pin 2 를
직접 찍는다. 이 관측 방법은 교안 원문이 아니다(M13). 1단계 뒤 T2 전 행을 돌린다.

# C3 · 실험 3-2) JK F/F – IC(74HC76) 활용 (74HC76)

- kind: circuit
- id: C3
- item: E6.P3-2
- tables: [T3]
- rebuild: all
- diagram: 실험06_3-2_결선도_JK플립플롭.png

교안 p11 핀 배치 그림대로, **C2 를 걷고 새로 짓는다**(M10). 전원을 끄고 C2 의 신호선·입력 점퍼를 전부
뽑고, `74HC00`·`74HC04` 와 그 전원선 네 가닥, **LED 사슬 두 개(LED·330Ω·GND 선)도 뽑는다.** 레일
브리지만 그대로 둔다. `74HC76`(U3)을 K1 에 꽂고 전원(**pin 5 → VCC, pin 13 → GND**), LED 두 사슬, 입력
점퍼 다섯을 꽂는다. 칩이 하나이고 칩 안 배선이 없어 단계 표를 두지 않는다. 플립플롭은 출력이 앞
상태에 따라 갈려 `## 노드` 표에 적을 조합 노드가 없다(M13).

교안 p11 표 순서대로 돌린다(회색 행도 돌린다 — M5). **1~3 행 동안 `CLK` 점퍼는 GND 에 둔다** — +5V 에 두었다가 3 행에서 GND 로
옮기면 그 자체가 하강 에지라 `Q` 가 그때의 `J`·`K` 대로 바뀐다(M2). 1·2 행은 `SET`·`RESET` 점퍼 하나만
GND 로 내려 클럭 없이 출력을 정한다. 3 행은 둘 다 +5V 에 두고(교안 "JK에 따른 결과 확인 시 HIGH"),
`CLK` 를 GND 에 둔 채 `J`·`K` 를 바꿔도 `Q` 가 그대로인지 본다. 4~7 행은 `CLK` 를 +5V 로 올리고 `J`·`K`
를 꽂은 뒤 `CLK` 를 GND 레일로 옮겨 하강 에지 하나를 낸다. 오르는 에지에서는 `Q` 가 바뀌지 않는다(ST
M74HC76 진리표 마지막 행 `NO CHANGE`). 이 순서는 교안 원문이 아니다(M16).

- U3 = 74HC76 (dual JK flip-flop with set/reset, DIP-16) — K1

  - pin 13 → GND
  - pin 1  ← 입력 CLK        (1번 F/F 의 CLK — 하강 에지에서 동작)
  - pin 2  ← 입력 Set        (SET, Active Low)
  - pin 3  ← 입력 Reset      (RESET, Active Low)
  - pin 4  ← 입력 J
  - pin 16 ← 입력 K

  - pin 14 → 330Ω → LED Q' 애노드, LED 캐소드 → GND   ※ Q(t)' (기록 칸 없음 — M4)
  - 미사용 입력핀: pin 6, 7, 8, 9, 12 (2번 F/F) → 접지하지 않는다 (M6·M7)
  - 미사용 출력핀: pin 10, 11 (2번 F/F) → 비워 둔다

| M16 | **실행 순서** — 교안 표는 `Q(t-1)` 행(T1 1·2행, T2 1행)으로 시작하지만 교안 p7 본문은 "첫 입력은 Set 또는 Reset을 인가" 라 한다. 그래서 C1·C2 는 Reset·Set 행을 먼저 넣고 `Q(t-1)` 행을 그 뒤에 보며, C1 의 `S=R=1` 행은 마지막에 본다. 전원 직후 `Q` 가 정해지지 않는다는 것은 이 교안 문장에서 끌어낸 판단이다.

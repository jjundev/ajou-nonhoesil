# 실험06 · 촬영명 실험1 · 확인 범위와 미확인 사항

이 파일은 사용자가 제공한 전사본 2개와 실제 원본 영상 프레임을 대조한 기록이다. 음성인식 라이브러리를 사용하지 않았으며, 오디오를 직접 청취한 것으로 간주하지 않는다. 전사 시간은 근사값이고 사진 시각은 원본 영상 프레임 PTS다.

파일명의 ‘실험1’은 촬영명이다. 영상 내용은 실험06 명세 E6.P3-2, JK 플립플롭(교안 74HC76), T3와 대응한다. 실물 IC 표면 글씨를 선명하게 읽어 부품명을 독립 확인한 것은 아니다.

## 직접 확인한 화면

- 1편 초반에는 LED가 꺼져 있고, 전원 투입 뒤 위 LED가 켜진다. 약21초 부근에 아래 LED가 켜지는 상태로 바뀐다.
- CLK=0 유지 설명 구간과 뒤의 클럭 조작 설명 구간에서는 전후 사진 모두 아래 LED가 켜져 있다.
- K=1 항목에서는 조작 전후 모두 아래 LED가 켜져 있다. 새롭게 Reset되는 전이가 있었음을 입증하는 사진으로 쓰면 안 된다.
- J=1, K=0 설명 구간에서는 아래 LED 점등에서 위 LED 점등으로 바뀐다. 약109.7~109.8초 표본 사이에서 변화가 보인다.
- 1편의 마지막 시도 뒤에도 위 LED가 켜져 있고, 2편은 처음부터 아래 LED가 켜진 상태다. 2편은 0.1초 간격으로 확인한 표본에서 전원 차단 전까지 그 상태를 유지한다.
- 2편의 LED 소등은 약8.1~8.3초 부근이다. 전사본의 00:06은 정확한 소등 프레임 시각으로 쓰지 않았다.

## T3 행별로 쓸 수 있는 근거

| 행 | 항목 | 확보한 근거 | 남은 한계 |
|---|---|---|---|
| 1 | 비동기 Set | Reset=1·위 Q 점등 발언과 위 LED 점등 사진 | Set=0은 문맥·명세 대응이며 실물 입력 전압 독립 확인 없음 |
| 2 | 비동기 Reset | Set=1 Reset=0 발언과 아래 LED 점등 사진 | 실물 입력 전압·클럭과의 독립성까지 계측한 증거 없음 |
| 3 | CLK=0 유지 | CLK=0·Reset=1 발언 및 전후 아래 LED 점등 | J/K를 실제로 바꾸어도 유지되는지 입증하지 못함 |
| 4 | J=K=0 유지 | 클럭을 1·0으로 바꾼다는 발언과 출력 유지 | ‘JK 유지’만 있고 J=K=0을 명시한 발언 없음. 해당 행의 확정 증거로 쓰지 말 것 |
| 5 | J=0 K=1 Reset | K=1·다섯째 행 발언, 아래 LED 점등 | J=0 독립 확인 없음. 이미 같은 출력이라 새로운 Reset 전이는 미확인 |
| 6 | J=1 K=0 Set | 두 입력값 발언 및 아래→위 LED 변화 | 어느 에지에서 변했는지는 확정 불가 |
| 7 | J=K=1 토글 | 조건 설명과 실패 시도, 수정 후 아래 LED 상태 | 촬영 중단 사이 배선 조정이 있으므로 연속 토글 성공을 증명하지 못함. 2편에서 입력·클럭 조작을 재진술하거나 연속 반전시키는 장면 없음 |

## 별도 확인이 필요한 부분

1. **클럭 에지 방향:** 명세는 1→0 하강 에지 기준이다. 전사에서는 ‘1로 바꾸면’이라는 설명도 있다. 입력핀 전압을 동시에 측정한 화면이 없어 실제 하강 에지 동작을 확정하지 않았다.
2. **LED와 출력핀 대응:** 위=Q, 아래=Q′는 발언과 기존 결선도에 따른 대응이다. 사진에서 실제 IC의 15·14번 핀까지 모든 배선을 추적해 확인한 것은 아니다. 사진의 직접 관찰은 ‘위/아래 LED 점등’으로 남겼다.
3. **오류 원인:** 선을 너무 깊게 꽂았다가 약간 뽑으니 해결됐다는 것은 사용자 설명이다. 영상만으로 내부 접촉·단락의 구체적인 원인이나 특정 선 번호는 확정하지 않았다.
4. **촬영 중단 전후:** 출력이 서로 다르다는 것과 동일한 입력에서 한 번의 클럭으로 반전됐다는 것은 다르다. 비교 시트 05는 ‘촬영 중단 전후 상태 비교’다.
5. **오디오 경계:** 실제 음성 트랙은 원본 영상과 같은 시각으로 잘라 유지했다. 새 음성을 합성하지 않았다. 청취 도구가 없어 절단점의 말끝·청감 자연스러움은 미확인이다. 수치상 동기와 전체 디코딩 검사는 별도로 기록한다.
6. **사진 해상도와 가림:** 전체 프레임은 1080×1920 PNG이며 재구성·보간·LED 색 보정이 없다. 일부 구간의 손 가림·촬영 초점 때문에 입력의 실제 결선을 확정하기 어렵다.

## 보고서 사진 설명 예시

- “비동기 Set 조건 설명 구간에서 위 LED의 점등을 관찰하였다(입력 조건은 실험 중 발언 기준).”
- “클럭 조작 전후 아래 LED의 점등 상태가 유지되었다. J=K=0 조건의 독립 확인에는 제한이 있다.”
- “J=1, K=0으로 설정했다는 설명 뒤, 아래 LED 점등에서 위 LED 점등으로 출력 상태가 변하였다. 에지 방향은 영상만으로 확정하지 못했다.”
- “배선을 조정한 뒤 재촬영한 영상에서는 아래 LED가 점등되었다. 촬영 중단 때문에 연속 토글 동작은 확인하지 못했다.”

# 미확인 사항

발언·화면 관찰·사용자 설명을 구분한 기록이다. 입력값을 출력에서 역산해 확정하지 않는다.

- 입력 E·D 값은 제공 전사본 기준이며 실제 전압·레일 접속을 독립 측정하지 않음.
- 위 LED=Q', 아래 LED=Q 대응은 전사 4초·14초 발언과 영상의 LED 위치 대조 기준이며 실물 출력 핀까지 배선을 추적하지 않음.
- 전사본의 시각은 근사값. 사진 이름·시각은 원본 실제 프레임 시각을 사용함.
- E=0에서 D를 다시 바꾸는 장면은 확인되지 않아 진리표의 모든 D 조건에 대한 유지 검증으로 일반화하지 않음.
- 네이티브 직접 청취 수단이 없어 오디오는 직접 확인하지 않았으며 제공 전사본을 사용함.

## reset · p1 · 0~9.5초

화면 관찰: 위 LED 점등·아래 LED 소등. 선택 사진은 손 가림 없이 보드와 두 LED가 보임. E=1,D=0과 Q' 대응은 전사 기준.

전사 근거: transcript_p1 0초 — 지금 상태가 E가 1이고

전사 근거: transcript_p1 4초 — D가 지금 0인 상태에서 맨 위에 있는 Q 프라임(Q')이 켜지고 있다.

- 미확인: 입력 E·D 값은 제공 전사본 기준이며 실제 전압·레일 접속을 독립 측정하지 않음.

- 미확인: 위 LED=Q', 아래 LED=Q 대응은 전사 4초·14초 발언과 영상의 LED 위치 대조 기준이며 실물 출력 핀까지 배선을 추적하지 않음.

## data_change · p1 · 9.5~18초

화면 관찰: 11.500878초 미리보기에서는 위 LED 점등, 11.600856초 미리보기에서는 위 LED 소등·아래 LED 점등. 이는 0.1초 간격 표본이며 정확한 전환 시각은 확정하지 않음. 이후 아래 LED 점등 상태. E=1은 앞 설명의 연속 맥락, D=1은 11초 전사 기준.

전사 근거: transcript_p1 11초 — 위에 있는 D도 입력을 1로 바꾸게 된다면

전사 근거: transcript_p1 14초 — 그럼 이번엔 Q가 켜지고

- 미확인: 입력 E·D 값은 제공 전사본 기준이며 실제 전압·레일 접속을 독립 측정하지 않음.

- 미확인: 위 LED=Q', 아래 LED=Q 대응은 전사 4초·14초 발언과 영상의 LED 위치 대조 기준이며 실물 출력 핀까지 배선을 추적하지 않음.

- 미확인: 조작 중 손이 입력 레일 일부를 가려 실제 D 전압 전환 시각은 확인하지 못함.

## disable_hold · p1 · 18~25.5976초

화면 관찰: E를 0으로 바꾼다는 설명 전후에 위 LED 소등·아래 LED 점등 상태가 이어짐. 후반 손이 물러난 24초 사진에서도 같은 상태. 새 출력 전이는 관찰하지 않음.

전사 근거: transcript_p1 18초 — 그럼 E를 다시 0으로 만들게 된다면

전사 근거: transcript_p1 21초 — 이전 상태를 유지하게 된다.

- 미확인: 입력 E·D 값은 제공 전사본 기준이며 실제 전압·레일 접속을 독립 측정하지 않음.

- 미확인: 위 LED=Q', 아래 LED=Q 대응은 전사 4초·14초 발언과 영상의 LED 위치 대조 기준이며 실물 출력 핀까지 배선을 추적하지 않음.

- 미확인: E=0에서 D를 반대 값으로 다시 바꾸는 장면은 확인되지 않음. 이 영상만으로 D 변화와 무관한 유지 동작 전체를 검증할 수 없음.

- 미확인: E 조작 중 손이 입력 접속을 가려 E=0 완료 시각은 발언만으로 특정하지 않음.

- 오디오 직접 청취 확인 없음. 전사 대조와 수치상 동기 검증은 청감 자연스러움 검증과 다르다.

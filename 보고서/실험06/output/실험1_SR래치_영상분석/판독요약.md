## 편집 선택

1편 0~57.8초 요청 구간을 실제 프레임 57.8184초까지 보존하고, 2초 중단 안내 다음에 2편 전체를 연결했다. 출력은 30fps이며 실제 출력 길이는 약 72.1초다. 원본 속도와 세로 표시 방향을 유지했다. 1편의 마지막 입력 설정·실패 시도·종료 부분은 편집본에서 제외하고 사진 05와 비교 시트 04에 별도로 보존했다.

촬영 사이의 조치가 보이지 않아 안내는 "촬영 중단 후 재촬영 / E=S=R=1 최종 상태 재확인"으로 적었다. 배선 수정이나 실패 원인은 확정하지 않았다.

## 판독 범위

- E=0에서 S·R을 바꾸는 시험은 없다. S=R=0인 채 직전 출력을 유지한 사례로만 기록했다.
- 두 LED가 함께 켜진 2편은 최종 상태 근거다. 촬영 사이의 연속 전이 성공 근거가 아니다.
- 27.526초 Set 사진은 카메라 초점이 다소 부드럽지만 LED 두 발광부는 가려지지 않고 점등 차이가 보인다.
- 음성을 직접 청취할 도구가 없어 전사본과 영상 프레임으로만 판단했다. 연결부의 청감 자연스러움은 확인하지 못했다.

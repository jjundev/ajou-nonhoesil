# E6.P1 · 실험 1) SR Latch with Enable

교안 p7. 교안 원문: "Enable이 1일 때 S와 R의 변화에 따른 출력의 변화를 관찰." 그리고 "초기 Feedback
값(Q, Q’) 설정을 위해, 첫 입력은 Set 또는 Reset을 인가". 회로도(vision, 교안 라벨 그대로) — `74HC00`
게이트 넷을 다 쓴다:

- `S` → pin 1, `E` → pin 2 와 pin 4 (한 노드), `R` → pin 5
- pin 3 → pin 9 ; pin 6 → pin 13
- pin 8 → 출력 `Q`, 그리고 pin 12 로 되먹임 ; pin 11 → 출력 `Q'`, 그리고 pin 10 으로 되먹임

`74HC00` 이 네 번 라벨돼 있지만 쿼드 패키지 하나의 게이트 넷이다. 관측점은 `Q`·`Q'` 두 출력이고,
기록 칸은 교안 표대로 `Q(t)` 하나다 — `Q'` 는 `S=R=1` 행에서 `Q` 와 함께 1 이 되는지 보는 데
쓴다(교안 p7 본문. `Q'` 에 기록 칸이 없다는 것은 결선도 미확정 표). 교안 원문대로 **첫 입력은 Set 또는
Reset 이다** — 그래서 표의 첫 두 행(`Q(t-1)`)부터 돌리지 않는다. 3·4 행(Reset·Set) 중 하나를 먼저 넣고, 그 뒤
1·2 행으로 앞 행의 값이 그대로 남는지 보고, 마지막에 5 행(`S=R=1`)을 본다. 전원을 넣은 직후의 `Q` 가
정해지지 않는다는 것과 이 실행 순서는 교안 원문이 아니다(결선도 미확정 표).

# E6.P2-1 · 실험 2-1) D Latch with Enable

교안 p8. 교안 원문: "Enable이 1일 때 D의 변화에 따른 출력의 변화를 관찰." 그리고 "SR 회로에 두
개의 개별 입력이 아닌 하나의 값(D)과 보수(D’)가 입력되도록 함으로써 SR 회로의 부정 상태를 구조적으로
방지". 회로도(vision, 교안 라벨 그대로)는 E6.P1 회로의 `S` 자리에 `D`, `R` 자리에 `D` 를 `74HC04`
로 뒤집은 것을 넣는다:

- `D` → `74HC00` pin 1, 그리고 `74HC04` pin 1 ; `74HC04` pin 2 → `74HC00` pin 5
- `E` → `74HC00` pin 2 와 pin 4
- 나머지(pin 3 → 9, pin 6 → 13, pin 8 → `Q`·pin 12, pin 11 → `Q'`·pin 10)는 E6.P1 과 같다

`74HC04` 는 인버터 여섯 중 하나(pin 1 → 2)만 쓴다. 관측점은 `Q`·`Q'` 이고 기록 칸은 `Q(t)` 하나다(E6.P1
과 같은 이유 — 결선도 미확정 표). 교안 표에는 `Q(t-1)` 행이 `E=0` 하나뿐이다 — 표의 `E=1` 두 행에서 `Q` 가 `D` 와 같다(표에서 읽은 것이다).
실행 순서는 E6.P1 과 같다 — 2·3 행 중 하나를 먼저 넣고 1 행을 그 뒤에 본다(결선도 미확정 표).

# E6.P3-2 · 실험 3-2) JK F/F – IC(74HC76) 활용

교안 p11. 교안 원문: "Falling Edge마다 J와 K의 변화에 따른 출력의 변화를 관찰" 그리고 "RESET, SET
(Active Low): 클럭과 무관하게 최우선 반영 => JK에 따른 결과 확인 시 HIGH". 같은 쪽 머리에 "GND와
Vcc 위치 유의" 가 빨간 글씨로 있다. 제목의 `–` 는 교안 그대로 옮긴 엔 대시다.

회로도는 없고 `74HC76` 핀 배치 그림이 있다(vision): 빨간 라벨 `CLK` 1·`SET` 2·`RESET` 3·`J` 4·`K` 16·
`Q(t)` 15·`Q(t)’` 14, 파란 라벨 `CLK` 6·`SET` 7·`RESET` 8·`J` 9·`K` 12·`Q(t)` 11·`Q(t)’` 10, 그리고
`Vcc` 5·`GND` 13. 플립플롭이 둘 든 패키지이고 교안은 어느 쪽을 쓸지 말하지 않는다 — 빨간 쪽(1번
플립플롭) 하나를 쓴다고 보았다(교안 원문이 아니다, 결선도 미확정 표). 관측점은 `Q(t)`·`Q(t)'` 이고
기록 칸은 `Q(t)` 하나다.

`Set`·`Reset`·`CLK`·`J`·`K` 다섯 입력을 표 행마다 정한다. 앞 두 행은 `SET`·`RESET` 중 **하나만** 0 으로
내려 클럭 없이 출력을 정하는 행이다(둘 다 0 인 조합은 교안 표에 없다 — 결선도 미확정 표). 3 행은 둘 다
1 로 두고 `CLK` 를 0 에 둔 채 `J`·`K` 를 바꿔도 `Q` 가 그대로인지 보는 행이고, 4~7 행은 `CLK` 를 1 에서
0 으로 떨어뜨려 본다. 1~3 행 동안 `CLK` 를 GND 에 둬야 3 행으로 넘어갈 때 에지가 생기지 않는다(교안
원문이 아니다, 결선도 미확정 표).
`CLK` 를 무엇으로 주는지는 교안에 없다 — 입력 점퍼를 +5V 에서 GND 로 옮겨 꽂는 것으로 가정했다(결선도
미확정 표). 토글 행(`J=K=1`)은 에지 하나에 한 번 뒤집히므로, 점퍼를 옮기는 순간 접점이 튀어 에지가
여러 번 생기면 그 수가 홀수일 때만 `Q(t-1)'` 가 된다 — 이 산술은 교안 원문이 아니다(결선도 미확정 표).

# 실험6 Latch & Flip-Flop 기록

진리표 — 확인 칸: `✓` 일치 / 값 = 불일치 시 실제 관찰값 / 공란 = 미확인.
스텝표 — 빈 칸에 읽은 값을 **단위와 함께** 적는다. 확인 칸이 없다.
파형 — 스케치에 그리고 판독 조건 줄을 채운다.
표를 통째로 진행하지 않았으면 그 표 아래에 `- 실험을 진행하지 않았음.` 을 적는다.

## E6.P1 · 실험 1) SR Latch with Enable
IC: 74HC00 · 판독: LED

### T1 · SR Latch with Enable Truth Table

| E | S | R | Q(t)예상 | 확인 |
|---|---|---|----------|------|
| 0 | X | X | Q(t-1)   |      |
| 1 | 0 | 0 | Q(t-1)   |      |
| 1 | 0 | 1 | 0: Reset |      |
| 1 | 1 | 0 | 1: Set   |      |
| 1 | 1 | 1 | X (부정) |      |

- 메모: 실험 시작 전에 실험01~05 범위의 퀴즈 시험을 40분 동안 치러 피곤한 상태로 실험을 시작했다.
  - 실험 시간을 줄이기 위해 실험 1과 실험 3-2를 병렬로 진행했다. 실험 2-1은 실험 1의 회로를 재사용할 수 있어 그 뒤에 진행했다.
  - 다른 조들은 무엇을 측정해야 하는지 애매해했지만, 우리 조는 측정 계획을 별도 파일로 미리 준비하여 바로 진행할 수 있었다.
  - '이전 상태를 유지했다'는 것을 정지 사진으로 어떻게 남길지 혼란이 있었다.
  - 실험 전체를 동영상으로 촬영하고, 채점하는 조교가 맥락을 이해할 수 있도록 유튜브에 업로드한 뒤 영상에서 스크린샷을 뽑아 사용하는 방법을 생각했다. 촬영·업로드 완료 여부는 미확인이다.
  - 보고서 작성 지시: 사전에 준비한 자료는 '측정 계획'으로 표현하고, '체크리스트'라는 단어는 보고서에 쓰지 않는다.

## E6.P3-2 · 실험 3-2) JK F/F – IC(74HC76) 활용
IC: 74HC76 · 판독: LED

### T3 · JK F/F (74HC76) Truth Table

| Set | Reset | CLK  | J | K | Q(t)예상 | 확인 |
|-----|-------|------|---|---|----------|------|
| 0   | 1     | X    | X | X | 1: Set   |      |
| 1   | 0     | X    | X | X | 0: Reset |      |
| 1   | 1     | 0    | X | X | Q(t-1)   |      |
| 1   | 1     | 1->0 | 0 | 0 | Q(t-1)   |      |
| 1   | 1     | 1->0 | 0 | 1 | 0: Reset |      |
| 1   | 1     | 1->0 | 1 | 0 | 1: Set   |      |
| 1   | 1     | 1->0 | 1 | 1 | Q(t-1)'  |      |

- 메모: 입력을 가해도 LED가 켜지지 않았으나, LED를 교체하자 바로 정상적으로 점등했다. 어느 입력 조건과 출력 LED에서 발생했는지는 이번 진술에 명시되지 않았다.
  - 배선 수가 적고 결선에 어느 정도 익숙해져 결선 실수가 거의 없다고 판단했으며, 선이 깊게 꽂히는 문제를 예방하려 자신이 꽂은 모든 선의 끝부분을 짧게 잘라 두었기 때문에 LED부터 의심했다.
  - 실험05에서 LED를 많이 사용했을 때 불량 LED가 하나 이상 있었던 경험도 LED를 먼저 의심한 근거였다. 이는 사용자의 경험에 따른 판단이며 일반적인 LED 불량률이 확인된 것은 아니다.
    - (추정 — LED 교체 직후 점등이 정상화되어 기존 LED 불량을 의심함; 미확인: 기존 LED 자체의 불량 여부를 별도로 검사했는지는 진술되지 않음.)
  - 실험 시간을 줄이기 위해 실험 1과 병렬로 진행했다.
  - 측정 계획을 별도 파일로 미리 준비하여 바로 진행할 수 있었다.
  - '이전 상태를 유지했다'는 것을 정지 사진으로 어떻게 남길지 혼란이 있었다.
  - 실험 전체를 동영상으로 촬영하고, 채점하는 조교가 맥락을 이해할 수 있도록 유튜브에 업로드한 뒤 영상에서 스크린샷을 뽑아 사용하는 방법을 생각했다. 촬영·업로드 완료 여부는 미확인이다.
  - 보고서 작성 지시: 사전에 준비한 자료는 '측정 계획'으로 표현하고, '체크리스트'라는 단어는 보고서에 쓰지 않는다.

# 실험 종료 메모

- 막혔던 것: (1·2-1·3-2) 실험01~05 범위의 퀴즈 시험을 40분 동안 치른 뒤 피곤한 상태로 실험을 시작했다. 래치와 JK 플립플롭의 '이전 상태 유지'를 정지 사진으로 어떻게 남길지 혼란이 있었다.
- 예상과 달랐던 것: (3-2) 입력을 가해도 LED가 점등하지 않았다.
- 뭘 바꿔서 해결했나: (1·3-2) 실험 시간을 줄이기 위해 두 실험을 병렬로 진행했다; (2-1) 실험 1의 회로를 재사용하여 진행했다; (3-2) 배선 수가 적고 결선에 익숙해졌다는 판단, 선 끝부분을 짧게 잘라 깊게 꽂히는 문제를 예방한 점, 실험05에서 불량 LED를 경험한 점 때문에 LED부터 의심했다. LED를 교체하자 바로 정상 점등했다(기존 LED 불량은 추정); (1·2-1·3-2) 다른 조들은 측정 대상을 애매해했지만 우리 조는 별도 측정 계획을 미리 준비하여 바로 진행했다. 상태 유지의 증빙을 위해 전체 동영상 촬영·유튜브 업로드·영상 캡처 활용 방식을 생각했다. 조교가 실험 맥락을 이해하도록 하려는 목적이며 촬영·업로드 완료 여부는 미확인이다. 보고서에서는 준비 자료를 '측정 계획'으로 표현하고 '체크리스트'라는 단어를 쓰지 않는다.

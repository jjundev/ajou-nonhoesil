# 실험6 Latch & Flip-Flop 기록

진리표 — 확인 칸: `✓` 일치 / 값 = 불일치 시 실제 관찰값 / 공란 = 미확인.
스텝표 — 빈 칸에 읽은 값을 **단위와 함께** 적는다. 확인 칸이 없다.
파형 — 스케치에 그리고 판독 조건 줄을 채운다.
표를 통째로 진행하지 않았으면 그 표 아래에 `- 실험을 진행하지 않았음.` 을 적는다.

## E6.P1 · 실험 1) SR Latch with Enable
IC: 74HC00 · 판독: LED

### T1 · SR Latch with Enable Truth Table

| E | S | R | Q(t)예상 | 확인 |
|---|---|---|----------|------|
| 0 | X | X | Q(t-1)   | ✓ |
| 1 | 0 | 0 | Q(t-1)   | ✓ |
| 1 | 0 | 1 | 0: Reset | ✓ |
| 1 | 1 | 0 | 1: Set   | ✓ |
| 1 | 1 | 1 | X (부정) | ✓ |

- 메모: 실험 시작 전에 실험01~05 범위의 퀴즈 시험을 40분 동안 치러 피곤한 상태로 실험을 시작했다.
  - 실험 시간을 줄이기 위해 실험 1과 실험 3-2를 병렬로 진행했다. 실험 2-1은 실험 1의 회로를 재사용할 수 있어 그 뒤에 진행했다.
  - 다른 조들은 무엇을 측정해야 하는지 애매해했지만, 우리 조는 측정 계획을 별도 파일로 미리 준비하여 바로 진행할 수 있었다.
  - '이전 상태를 유지했다'는 것을 정지 사진으로 어떻게 남길지 혼란이 있었다.
  - 실험 동영상과 추출 사진이 남아 있다. 2026-10-17 사용자 확인: 영상은 압축하여 보고서와 함께 제출할 계획이며 유튜브에는 업로드하지 않는다.
  - 보고서 작성 지시: 사전에 준비한 자료는 '측정 계획'으로 표현하고, '체크리스트'라는 단어는 보고서에 쓰지 않는다.
  - 2026-10-17 사용자 확인: T1의 5행을 수행했고 수정 후 모두 예상과 일치했다. E=0에서 S·R을 바꾸어도 상태가 유지됨을 확인했다. Q=0·1 양쪽 시작 상태의 세부 시험 목록은 진술하지 않았다.
  - E=S=R=1 첫 촬영에서는 위 LED만 켜졌고, 우측 선 몇 개가 너무 깊게 꽂혀 있어 살짝 빼자 정상 동작했다. 재촬영에서는 두 LED가 함께 켜졌다. 정확한 신호선·핀 및 브레드보드 내부의 접촉 상태는 특정하지 않았다.
  - 사용자 확인: 실제 배선은 예비보고서 손그림과 같았고, 위 LED=Q', 아래 LED=Q다.

## E6.P3-2 · 실험 3-2) JK F/F – IC(74HC76) 활용
IC: 74HC76 · 판독: LED

### T3 · JK F/F (74HC76) Truth Table

| Set | Reset | CLK  | J | K | Q(t)예상 | 확인 |
|-----|-------|------|---|---|----------|------|
| 0   | 1     | X    | X | X | 1: Set   | ✓ |
| 1   | 0     | X    | X | X | 0: Reset | ✓ |
| 1   | 1     | 0    | X | X | Q(t-1)   | ✓ |
| 1   | 1     | 1->0 | 0 | 0 | Q(t-1)   | ✓ |
| 1   | 1     | 1->0 | 0 | 1 | 0: Reset | ✓ |
| 1   | 1     | 1->0 | 1 | 0 | 1: Set   | ✓ |
| 1   | 1     | 1->0 | 1 | 1 | Q(t-1)'  | ✓ |

- 메모: 입력을 가해도 LED가 켜지지 않았으나, LED를 교체하자 바로 정상적으로 점등했다. 2026-10-17 재확인에서도 교체 직후 점등한 사실만 확인했으며, 정확한 입력 조건·LED 위치는 특정하지 않았다.
  - 배선 수가 적고 결선에 익숙해졌다고 판단했고, 선 끝을 짧게 잘라 깊게 꽂히는 문제를 예방하려 했으므로 처음에는 LED부터 의심했다. 다만 촬영 중에는 깊게 꽂힌 선을 조정하는 문제도 있었다.
  - 실험05에서 LED를 많이 사용했을 때 불량 LED가 하나 이상 있었던 경험도 LED를 먼저 의심한 근거였다. 이는 사용자의 경험에 따른 판단이며 일반적인 LED 불량률이 확인된 것은 아니다.
    - (추정 — LED 교체 직후 점등이 정상화되어 기존 LED 불량을 의심함; 기존 LED를 별도로 검사한 근거는 없으며 교체 후 점등만 확인함.)
  - 실험 시간을 줄이기 위해 실험 1과 병렬로 진행했다.
  - 측정 계획을 별도 파일로 미리 준비하여 바로 진행할 수 있었다.
  - '이전 상태를 유지했다'는 것을 정지 사진으로 어떻게 남길지 혼란이 있었다.
  - 실험 동영상과 추출 사진이 남아 있다. 2026-10-17 사용자 확인: 영상은 압축하여 보고서와 함께 제출할 계획이며 유튜브에는 업로드하지 않는다.
  - 보고서 작성 지시: 사전에 준비한 자료는 '측정 계획'으로 표현하고, '체크리스트'라는 단어는 보고서에 쓰지 않는다.
  - 2026-10-17 사용자 확인: T3의 7행을 측정 계획대로 수행했다. 유지 시험의 입력은 Set=Reset=1, J=K=0이었다. J=1,K=0에서 Set=Reset=1로 두고 CLK의 1->0에서 출력 변화를 확인했다. 수정 후 Set=Reset=1,J=K=1에서 클럭마다 반복 반전됨을 확인했다.
  - J=0,K=1 행도 계획대로 수행했다고 확인했다. 사진은 Q=0인 전후 상태만 보여 주므로 사진에 새로운 Reset 전이가 담겼다고 쓰지 않는다.
  - 마지막 촬영 전후의 조치 질문에는 앞선 우측 선을 살짝 뺐다는 답을 가리켰다. LED 교체 사건과 배선 조정 사건은 구분하며, 정확한 선·핀은 확인되지 않았다.
  - 사용자 확인: 실제 배선은 예비보고서 손그림과 같았고, 위 LED=Q, 아래 LED=Q'다. 하강 에지와 반복 토글은 사용자 확인 근거이며 정지 사진만으로 검증한 것은 아니다.

# 실험 종료 메모

- 막혔던 것: 실험01~05 범위의 퀴즈 시험을 40분 동안 치른 뒤 피곤한 상태로 시작했다. 래치와 JK 플립플롭의 이전 상태 유지를 정지 사진으로 어떻게 남길지 혼란이 있었다.
- 예상과 달랐던 것: JK 회로에서 입력을 가해도 LED가 켜지지 않았다. SR 래치의 E=S=R=1 첫 촬영에서는 LED 하나만 켜졌다. 촬영 중 깊게 꽂힌 선을 조정해야 했다.
- 뭘 바꿔서 해결했나: 실험 1과 3-2를 병렬로 진행했고 2-1은 실험 1의 회로를 재사용했다. JK 회로의 LED를 교체하자 바로 켜졌다(기존 LED 자체의 불량은 추정). 우측 선 몇 개가 너무 깊게 꽂혀 있어 살짝 빼자 정상 작동했다. 정확한 신호선과 내부 접촉 원인은 미확인이다. 별도 측정 계획을 미리 준비해 진행했고, 동영상에서 전후 사진을 뽑았다. 영상은 압축하여 보고서와 함께 제출할 계획이며 유튜브에는 업로드하지 않는다.
- 새로 안 것: (사용자 요청에 따른 작성 추천안; 본인 경험으로 확정한 진술은 아님) 상태 유지 여부는 한 장의 사진만으로 판단하기 어렵고, 먼저 Set 또는 Reset으로 값을 정한 뒤 입력을 바꾸기 전후의 출력과 동영상을 함께 비교해야 한다. 또한 SR 래치의 S=R=1과 JK 플립플롭의 J=K=1은 같은 두 입력 1이어도 각각 부정 상태와 토글로 동작한다.

## 2026-10-17 결과 확인의 범위

- 확인 칸 15개는 사용자 답변에 따라 수정·교체 후의 최종 결과를 ✓로 기록했다. 초기 실패를 없던 일로 처리한 것이 아니다.
- X 입력 행의 ✓는 계획한 상태 유지 시험을 수행했다는 사용자 확인이다. 가능한 입력 조합 전부와 Q=0·1 양쪽 초기 상태의 세부 목록까지 확보한 것은 아니다.
- 영상 분석의 과거 미확인 메모는 당시 영상만으로 확보한 범위다. 이 기록의 추가 사용자 확인과 출처를 구분한다.

# 미확인 사항

발언·화면 관찰·사용자 설명을 구분한 기록이다. 입력값을 출력에서 역산해 확정하지 않는다.

- 입력 조건은 제공된 편별 전사본 기준이다. 원본 음성을 직접 청취하지 못해 전사 정확도와 편집 연결부의 청감은 미확인이다.
- 위 LED=Q', 아래 LED=Q는 1편 1초의 Q' 발언과 명세·결선도 C1의 배치에 근거한다. 영상만으로 LED부터 IC 출력 핀까지 모든 결선을 추적하지 못했다.
- 전압 측정 자료가 없어 LED 발광을 관찰로 적고 입력·출력 전압 실측값으로 확정하지 않는다.
- E=0에서는 S·R을 바꾸지 않았다. 해당 조건의 유지 사례는 있으나 모든 S·R 조합 시험은 확인하지 못했다.
- 1편과 2편 사이에 무엇을 바꿨는지 확인되지 않는다. 배선 수정이나 접촉 불량을 원인으로 단정하지 않는다.
- 편집본은 1편 0~57.8초와 2편 전체를 연결한다. 실패 시도는 사진·중단 비교 시트에 별도로 보존했다.
- 2초 중단 안내에는 무음이 들어가며, 원본 영상 구간은 각 영상의 같은 시간대 음성 트랙을 사용한다.

## reset · p1 · 0~9초

화면 관찰: 위 LED 점등, 아래 LED 소등. 두 LED가 가려지지 않은 초기 안정 상태.

전사 근거: transcript_p1 1초 — E=1, S=0, R=1이며 위쪽 Q 프라임이 켜졌다는 설명

- 미확인: 입력값과 위 LED=Q' 대응은 전사본 기준. 실물 LED부터 IC 핀까지 전 구간을 독립 추적하지 못함.

## set · p1 · 26.9~31초

화면 관찰: 입력 조작 뒤 위 LED 소등, 아래 LED 점등. 손가락은 아래 LED 근처에 있지만 발광부는 보임.

전사 근거: transcript_p1 21초 — R을 0으로 만든다는 설명

전사 근거: transcript_p1 24초 — 아래쪽이 켜진다는 설명

- 미확인: E=1, S=1, R=0은 전사 설명의 연속 문맥 기준. 조작 순간은 손에 가려짐.

## hold_enabled · p1 · 38~44초

화면 관찰: S 조작 뒤 위 LED 소등, 아래 LED 점등 상태가 지속됨.

전사 근거: transcript_p1 31초 — E=1이고 나머지 S와 R은 0, S를 다시 0으로 바꾼다는 설명

전사 근거: transcript_p1 39초 — 직전 상태를 유지한다는 설명

- 미확인: S=0 입력은 전사본 기준. 정지 사진 두 장만으로 전체 구간의 연속 유지가 증명되지는 않으며 미리보기와 함께 판단.

## hold_disabled · p1 · 50~58초

화면 관찰: E 조작 이후에도 위 LED 소등, 아래 LED 점등 상태가 지속됨.

전사 근거: transcript_p1 44초 — E도 0으로 바꾼다는 설명

전사 근거: transcript_p1 48초 — 직전 상태를 유지한다는 설명

전사 근거: transcript_p1 52초 — S와 R은 don't care라 바꾸지 않겠다는 설명

- 미확인: E=0은 전사본 기준. S와 R의 네 조합을 각각 조작한 영상은 없음. 직전 S=R=0 조건을 유지한 사례만 관찰.

## failed_final_attempt · p1 · 69~84.3455초

화면 관찰: 최종 입력 설명 뒤 위 LED만 밝게 점등. 아래 LED는 재촬영본과 달리 밝은 발광이 보이지 않음.

전사 근거: transcript_p1 69초 — 세 입력이 모두 1이라는 설명

전사 근거: transcript_p1 81초 — 이게 안 켜진다는 발언

전사 근거: transcript_p1 83초 — 켜져야 된다는 발언

- 미확인: 실패 원인 미확인. 접촉 불량 또는 배선 수정으로 단정하지 않음.

## final_retaken · p2 · 0~12.2487초

화면 관찰: 재촬영 시작부터 위 LED와 아래 LED가 함께 점등. 7초와 11~12초에는 손 가림 없이 두 발광부가 보임.

전사 근거: transcript_p2 6초 — E, S, R이 전부 1인 경우라는 설명

전사 근거: transcript_p2 8초 — 아래쪽과 위쪽 모두 들어온다는 설명

전사 근거: transcript_p2 11초 — 두 개 다 들어왔다는 설명

- 미확인: 두 촬영 사이의 조치·원인은 영상과 전사에 없음. 연속 전이 성공이 아닌 재촬영 최종 상태의 근거.

- 오디오 직접 청취 확인 없음. 전사 대조와 수치상 동기 검증은 청감 자연스러움 검증과 다르다.

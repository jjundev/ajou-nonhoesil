예상 결과 그림 — 전가산기와 전감산기의 신호 격자

실험 1-2·2-2 소절의 진리표 바로 뒤에 넣을 그림 두 장이다. 여덟 입력 조합마다 입력, 입력 1의 개수, LED 가 없는 중간 노드, 출력 LED 를 한 격자에 놓아 진리표의 각 행이 왜 그 값인지 보이게 했다.

값의 출처

격자 값은 본문 부울식 S = A⊕B⊕Ci, Co = A·B + (A⊕B)·Ci 와 D = A⊕B⊕Bi, Bo = A'·B + (A⊕B)'·Bi 에서 계산했다. 출력 두 줄은 명세 T3·T7 진리표와 대조되며, 어긋나면 이 페이지 맨 위에 경고가 뜬다.

LED 가 켜지는 조건

넷리스트대로 출력 → 330Ω → LED 애노드, 캐소드 → GND 라서 출력이 1일 때 켜진다. 준비물에 LED 색이 적혀 있지 않아 특정 색으로 그리지 않았다.

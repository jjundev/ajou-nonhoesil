## 추가 조건 대조 — 강의노트 표기 그대로인가

강의노트 p4~p7 을 110dpi 로 렌더해 회로도 출력 꼬리표와 `Truth Table` 머리를 보고서 표와 맞댔다.

| 항목 | 강의노트 회로도 출력 | 강의노트 표 머리 | 보고서 표 머리 (줄) | 판정 |
|---|---|---|---|---|
| 1-1 반가산기 (p4) | `S`, `C` | 입력 `A B` / 출력 `S C` | `A B S C` (135) | ✓ |
| 1-2 전가산기 (p5) | `S`, `Co` | 입력 `A B Ci` / 출력 `S Co` | `A B Ci S Co` (148) | ✓ |
| 2-1 반감산기 (p6) | `D`, **`B`** | 입력 `A B` / 출력 `D` **`B`** | `A B D` **`Bo`** (165) | ✗ |
| 2-2 전감산기 (p7) | `D`, `Bo` | 입력 `A B Bi` / 출력 `D Bo` | `A B Bi D Bo` (178) | ✓ |

- 네 표 모두 열 수와 열 순서가 교안과 같고, 셀도 전부 같다(round1 에서 vision 으로 대조했다).
- 교안 회로도에는 중간 노드 이름(`A⊕B`, `A·B` 같은 자리)이 없고 LED 도 두 개뿐이다. 그래서 실험01 처럼
  빠뜨린 중간 출력 열은 없다.
- 불릿 제목의 부울식은 표 열 이름을 쓴다(§절대 규칙 22 형식). 반감산기만 `Bo = A'·B` 라 표와 같은
  이유로 교안과 어긋난다.

### ✗ 반감산기 내림 출력 `B` 를 `Bo` 로 바꿨다

교안 p6 은 회로도 AND 출력 꼬리표도 `B`, 진리표 넷째 열도 `B`, p9 절차 문장도 "출력 단(S와 C,
또는 **D와 B**)" 이다. 보고서 165줄은 이것을 `Bo` 로 적었다. 실험01 에서 `L2` 를 `Y` 로 바꿨다가
감점된 것과 같은 꼴이다. 회로도의 출력 이름이 표에 보이지 않는다.

바꾼 이유는 타당하다. 입력 `B` 와 글자가 같아 한 줄 머리로는 둘을 구분할 수 없다. 보고서도 이론
절 78줄에서 이를 밝혔다("강의노트는 내림 수를 B로 적는데 … Bo로 구분해 적는다"). 하지만 그
설명은 표에서 80줄 떨어진 이론 절에 있고, 표 앞 불릿과 과정 문단(162줄)에는 교안 표기가 한 번도
나오지 않는다. 결선도 PNG 는 제목에 `(교안 표기 B)` 를 달았는데 보고서 표에는 그런 표시가 없다.

**자동 검사가 이것을 못 잡는 이유.** `check_report_tables` 는 강의노트가 아니라 명세 머리와
대조한다. 그런데 `Bo` 로 바꾼 곳이 명세 T5·T6 자체다(명세 토큰 표, netlist M7). 파서가 한 표
안의 중복 열 이름을 거절해서 그렇게 했다. 명세 단계에서 이미 바뀌었으니 보고서가 명세를 충실히
따를수록 검사는 통과한다.

**교안대로 되돌리면 검사기가 틀린 이유로 error 를 낸다 (스크래치 실측).** 보고서 165줄 머리만
`| A | B | D | B |` 로 바꿔 `check_report_tables` 를 돌리면 아래가 나온다.

```
✗ pre_B.md — 166줄 표 4번째 행이 명세 T5 와 다르다: 보고서 ['1', '1', '0', '0'] · 명세 ['1', '1', '0', '1']
```

셀은 교안과 똑같은데 셀이 틀렸다고 한다. 머리의 두 `B` 가 이름 하나로 묶여 넷째 열이 입력 `B`
열과 비교되기 때문이다. 교안 표기를 그대로 쓰는 쪽을 고르면 명세·파서·검사기도 같이 고쳐야 한다
(테스트부터).

### 참고 — 걸지 않은 것

- **2단 머리(`입력` / `출력`).** 교안 표 네 개는 모두 2단 머리인데, 보고서 표는 한 줄 머리다. 조교
  감점 사유는 이름이었지 머리 단수가 아니었으므로 따로 걸지 않는다. 다만 반감산기에서 두 `B` 를
  가르는 것이 교안에서는 바로 이 2단 머리다. 아래 선택지 ①과 같이 본다.
- **기본 게이트 표의 `Y`**(26~51줄). 교안에 게이트 진리표가 없어 데이터시트 function table 을
  옮긴 것이고, 24줄에 출처를 밝혔다. 교안 회로도의 출력 이름이 아니므로 이번 조건과 무관하다.

# E3.P1-1 · 실험 1-1) 반가산기

교안 p4. 회로도(vision): `A`·`B` 가 `74HC86` XOR 한 개와 `74HC08` AND 한 개에
나란히 들어가고, XOR 출력이 `S`, AND 출력이 `C` 다. 게이트를 하나씩만 쓰므로
패키지도 종류당 하나다. 교안 본문 "2개 비트 A와 B를 입력 받아, 합 S와 올림 수
C를 출력".

관측점은 `S`·`C` 두 출력이고 각각 330Ω + LED 가 붙는다(p9). 부울식
`S = A⊕B`, `C = A·B` 는 회로도의 게이트 종류에서 읽은 것이고 교안이 글로 적지는
않았다 — 아래 T2(교안 원문)와 셀이 전부 일치한다.

# E3.P1-2 · 실험 1-2) 전가산기

교안 p5. 교안 본문 "반 가산기 2개와 OR Gate로 구성". 회로도(vision):

- `A`, `B` → `74HC86` XOR1 → `A⊕B`
- `A`, `B` → `74HC08` AND1 → `A·B`
- `A⊕B`, `Ci` → `74HC86` XOR2 → `S`
- `A⊕B`, `Ci` → `74HC08` AND2 → `(A⊕B)·Ci`
- `(A⊕B)·Ci`, `A·B` → `74HC32` OR → `Co`

회로도에 `74HC86` 라벨이 둘, `74HC08` 라벨이 둘 나오지만 **쿼드 패키지에서
게이트 둘을 뽑는 것이라 `ics` 는 종류당 하나다.** `A⊕B` 노드는 XOR2 와 AND2 로,
`Ci` 는 XOR2 와 AND2 로 팬아웃한다. 관측점은 `S`·`Co` 둘이다 — `A⊕B`·`A·B`
같은 중간단에는 LED 가 없다(준비물 LED 2개).

부울식 `S = A⊕B⊕Ci`, `Co = A·B + (A⊕B)·Ci` 는 회로도에서 읽은 것이다.
아래 T4(교안 원문) 8행과 전부 일치한다.

# E3.P2-1 · 실험 2-1) 반감산기

교안 p6. 회로도(vision): `A`·`B` 가 `74HC86` XOR 로 들어가 `D` 가 되고,
`A` 가 `74HC04` NOT 을 지나 `A'` 가 된 뒤 `B` 와 함께 `74HC08` AND 로 들어가
내림 수가 된다. NOT 의 입력이 `A` 쪽 탭이고 AND 의 다른 입력이 `B` 쪽 탭이라는
것은 300dpi 크롭에서 배선의 세로선 위치로 확인했다 — 내림 수 = `A'·B` 이고
교안 진리표 `0 1 → 1` 행과 맞는다. 이 판독이 `A'·B` 와 `A·B'` 를 가르는
자리라 결선도 미확정 표에 올렸다.

교안 본문 "2개 비트 A와 B를 입력 받아, 차 D와 내림 수 B를 출력" — **출력
내림 수의 이름이 입력 `B` 와 같은 `B` 다.** 교안 표기 그대로 적고 자리로 가른다 —
표의 둘째 열 `B` 가 입력, 넷째 열 `B` 가 출력이다(머리말 토큰 표). LED 는
`D`·`B` 두 출력에 붙는다(p9 "D와 B").

부울식 `D = A⊕B`, `B = A'·B` 는 회로도에서 읽은 것이다 — 식의 왼쪽 `B` 가 출력,
오른쪽 `B` 가 입력이다. 아래 T6(교안 원문)과 전부 일치한다.

# E3.P2-2 · 실험 2-2) 전감산기

교안 p7. 교안 본문 "반 감산기 2개와 OR Gate로 구성". 회로도(vision):

- `A`, `B` → `74HC86` XOR1 → `A⊕B`
- `A` → `74HC04` NOT1 → `A'` ; `A'`, `B` → `74HC08` AND1 → `A'·B`
- `A⊕B`, `Bi` → `74HC86` XOR2 → `D`
- `A⊕B` → `74HC04` NOT2 → `(A⊕B)'` ; `(A⊕B)'`, `Bi` → `74HC08` AND2 → `(A⊕B)'·Bi`
- `(A⊕B)'·Bi`, `A'·B` → `74HC32` OR → `Bo`

회로도에 `74HC86`·`74HC04`·`74HC08` 라벨이 각각 둘 나오지만 쿼드·헥스
패키지에서 게이트 둘씩을 뽑는 것이라 `ics` 는 종류당 하나다 — 이 항목은 네 종류
전부를 한 패키지씩 쓴다. `A⊕B` 노드는 XOR2 와 NOT2 로, `Bi` 는 XOR2 와 AND2 로
팬아웃한다. NOT2 의 입력이 `A⊕B` 노드(XOR1 출력의 아래쪽 세로선)이고 AND2 의
위쪽 입력이 `Bi` 탭이라는 것은 300dpi 크롭으로 확인했다. 관측점은 `D`·`Bo`
둘이다.

부울식 `D = A⊕B⊕Bi`, `Bo = A'·B + (A⊕B)'·Bi` 는 회로도에서 읽은 것이다.
아래 T8(교안 원문) 8행과 전부 일치한다.

# 공통 규칙

- kind: common

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND. 전원은 준비물 p8 의 `5V 전압원`,
  입력 레벨은 p9 "INPUT(A, B, Ci 또는 Bi)에 5V와 GND를 번갈아 인가"
- 네 칩(`74HC86`·`74HC08`·`74HC32`·`74HC04`) 모두 계열 표준 전원핀(14·7)이다.
  다른 전원핀을 가진 칩은 이 주차에 없다
- **사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지). **미사용 게이트의
  입력은 접지하지 않는다** — 교안이 미사용 핀 처리를 말하지 않는 주차이고,
  실험01 실측(2026-09-11)에서 접지 생략이 결과에 영향이 없었다. 이 규칙은 교안
  원문이 아니다(M12). 미사용 *출력*핀은 개방한다 (출력끼리 묶거나 GND 로 직결하면
  출력 정격을 넘는 전류가 흐른다 — 실험01 M3 이 인용한 74HC04 절대 최대 IO ±25 mA)
- **칩을 꽂거나 뽑을 때는 전원을 끈다.** 교안 원문이 아닌 안전 절차다 — 단계
  표의 "꽂는다/뽑는다" 줄은 전부 전원을 끈 상태를 전제한다
- **교안 실험 1-1(반가산기)·2-1(반감산기)는 하지 않는다** — 조교 공지 `_350547_1`.
  그래서 C2 는 맨바닥에서 시작하고, C4 는 C2 를 다 만든 상태에서 74HC04 를
  끼워 바꾼다
- **단계 하나는 관측 노드 하나를 세운다** — 그 단계에서 새로 꽂는 신호선은 셋
  이하이고, 확인은 `## 단계` 표의 `확인` 칸이 가리키는 노드 하나를 본다. LED 가
  둘뿐이라 중간 노드는 **그 시점에 비어 있는 LED 의 급전선을 그 핀으로 잠시 옮겨**
  본다(M10). 임시 급전선은 다음 단계 첫머리에서 걷는다. 각 칩을 처음 쓰는 단계는
  C2 1단계(74HC86)·C2 3단계(74HC08)·C2 5단계(74HC32)·C4 1단계(74HC04)이고, 두
  회로 모두 마지막 단계에서 진리표 8행 전부를 돌린다
- **칩 자리는 고정이다** (아래 `# 칩 자리표`). 회로에 있는 한 `74HC86` 은 좌측
  앞단, `74HC04` 는 그 아래, `74HC08` 과 `74HC32` 는 우측이다. 회로가 바뀌어도 전원·
  입력 A·B·LED 사슬은 그대로 두고, 그림의 **회색 선은 손대지 않는다** — 단계
  그림에서 앞 단계와 같은 배선은 회색으로 그려지고 번호를 받지 않는다
  (`breadboard-diagram` 의 기준선 규약). 걷을 선은 단계 표가 지시한다
- 단계 순서는 자기 LED 가 달린 출력을 가진 칩·경로부터다 — 결선도 관례이고
  교안 원문이 아니다
- 입력 A·B·Ci/Bi 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물린다. 띄워두지
  않는다(스위치는 교안에 없다 — M2)
- LED 는 **두 개뿐이다**(준비물 p8 `발광 다이오드 (2개)`·`저항 330Ω (2개)`).
  `LED1` 은 합/차(`S`·`D`), `LED2` 는 올림/내림(`Co`·`Bo`) 자리다. 애노드 쪽에
  330Ω 직렬, 캐소드 → GND (교안 p9 "출력 단(S와 C, 또는 D와 B)에 330Ω 저항과
  다이오드를 연결한다."). 어느 LED 가 어느 출력인지와 저항이 애노드 쪽이라는
  것은 배선 편의다(M11). 두 회로에서 급전선 자리도 같다 — LED1 은 U1 pin 6, LED2 는 U3
  pin 3 이다
- **물리 칩 재사용:** 준비물에 IC 수량 표기가 없다(M1). 아래 `U1`~`U4` 는
  **물리 칩 하나에 붙인 번호**라 두 회로에서 같은 이름이 같은 칩이다 — `U1` 은
  74HC86, `U2` 는 74HC08, `U3` 는 74HC32, `U4` 는 74HC04
- 핀 줄의 `※` 뒤는 그 점의 신호 이름과 명세 표 대응을 적은 주석이다(배선 지시가
  아니다)

# 칩 자리표

- kind: layout

두 회로가 같은 자리를 쓴다. 입력 A·B 는 S1 의 pin 1·2 와 S3 의 pin 1·2 로
가고(C4 에서 S3 pin 1 만 A' 로 바뀐다), 세 번째 입력 Ci/Bi 는 S1 pin 5 와 S3 pin 5
로 간다. 슬롯은 역할에 붙는다 — 앞단 XOR(S1)·인버터(S2)·앞단 AND(S3)·합류 OR(S4).
이 주차는 칩 종류가 회로마다 바뀌지 않으므로 슬롯의 칩도 바뀌지 않는다. `좌`·`우`
는 브레드보드 두 블록, 행은 그 블록 단자대의 행 번호(칩 pin 1 이 앉는 행)다.
행 번호는 실험01·02 결선도의 관례(S1 좌 7행·S2 좌 18행·S3 우 10행)를 따른 것이고
S4 우 21행은 이번에 새로 잡은 자리다 — 교안 근거가 없다(M4).

**AND 를 우측에, 인버터를 좌측에 둔 이유**(2026-09-14 렌더에서 확정, M4): 좌우를
건너는 선이 전부 입력 갈래(A·B·Ci/Bi 가 좌 7·8·11행 스트립에서 우측 AND 로 가는
것)와 인버터 출력 둘(A'·(A⊕B)')뿐이 된다. AND 를 좌측에 두면 감산기에서 좌우를
오가는 선이 여섯 가닥이다. AND→OR 은 우측 안에서 끝난다.

| 슬롯 | 자리 | 회로별 칩 |
|---|---|---|
| S1 | 좌 7행 | C2 74HC86 · C4 74HC86 (U1, 앞단 XOR) |
| S2 | 좌 18행 | C4 74HC04 (U4, 인버터) |
| S3 | 우 10행 | C2 74HC08 · C4 74HC08 (U2, 앞단 AND) |
| S4 | 우 21행 | C2 74HC32 · C4 74HC32 (U3, 합류 OR) |

- kind: sources

교안에는 핀 번호가 한 개도 없다 — 회로도(p4~p7)는 게이트 기호와 IC 라벨뿐이다.
네 칩 모두 **제조사 1차 데이터시트**로 확인된 핀 배치를 저장소 기록 경유로
쓴다. 서지는 `.claude/데이터시트_출처.md` 에 있다(2026-09-07 확인). 가정으로
남은 핀은 없다.

- `74HC86` — Nexperia 74HC86; 74HCT86 Rev. 7 (2024-04-02) §5.2.
  `.claude/데이터시트_출처.md` "이 표로 닫힌 미확정 항목" 표의 `7432`·`7486`
  핀아웃 행이 `1A=1, 1B=2, 1Y=3, 2A=4, 2B=5, 2Y=6, GND=7, 3Y=8, 3A=9, 3B=10,
  4Y=11, 4A=12, 4B=13, VCC=14` 가 "Nexperia 74HC32 Rev.10 / 74HC86 Rev.7 §5.2
  와도 일치" 한다고 적었다. 그 파일은 그 행을 `실험03 M4` 라 부르는데 **옛
  아카이브 기준 결선도의 번호이고 이 문서의 M4(칩 자리)와 무관하다** — 그 행의
  1차 대상은 아카이브 판 교안의 TTL `7432`·`7486` 이었다
- `74HC08` — Nexperia 74HC08; 74HCT08 Rev. 9 (2024-02-16) §5.2. 저장소 기록 경유:
  `보고서/실험01/결선도/netlist.md` § 핀아웃 출처가 같은 개정으로 확인했고, 참조
  핀아웃 표에 `1,2 → 3 / 4,5 → 6 / 9,10 → 8 / 12,13 → 11 / VCC 14 / GND 7` 로
  옮겨져 있다
- `74HC32` — Nexperia 74HC32; 74HCT32 Rev. 10 (2025-04-30) §5.2. 저장소 기록 경유:
  `.claude/데이터시트_출처.md` `실험01 M1` 행이 `1A~4A = 1,4,9,12 / 1B~4B =
  2,5,10,13 / 1Y~4Y = 3,6,8,11 / GND 7 / VCC 14` 를 적었다
- `74HC04` — Nexperia 74HC04; 74HCT04 Rev. 10 (2024-02-16) §5.2 Table 2. 저장소
  기록 경유: `보고서/실험02/결선도/netlist.md` § 핀아웃 출처가 입력 `1, 3, 5, 9,
  11, 13`, 출력 `2, 4, 6, 8, 10, 12`, GND 7, VCC 14 로 옮겼다

교안 표기가 `74HC` 계열이므로 실물이 TI `SN74HC..` 각인이어도 핀 배치는 같다
(TI SCLS081J·SCLS200F·SCLS100F·SCLS078H — 같은 파일의 TI 표). 각인이 `74HC` 가
아닌 계열(`74LS`·`74HCT` 등)이면 전기 특성이 달라 인용할 데이터시트를 바꾼다(M5).

# C2 · 실험 1-2) 전가산기 (74HC86 + 74HC08 + 74HC32)

- kind: circuit
- id: C2
- item: E3.P1-2
- tables: [T3]
- refs: [T4]
- diagram: 실험03_1-2_결선도_전가산기.png

교안 p5 회로도 그대로. 이 주차 첫 회로라 맨바닥에서 시작한다 — 교안이 앞에 두는
반가산기(실험 1-1)는 조교 공지 `_350547_1` 로 하지 않는다.
단계는 다섯이다 — **관측 노드 하나가 단계 하나**이고 한 단계에서 새로 꽂는 신호선은
셋 이하다. `A⊕B` → `S` → `A·B` → `(A⊕B)·Ci` → `Co` 순으로 신호가 흐르는 차례다.
LED 는 둘뿐이라 중간 노드는 **그 시점에 비어 있는 LED 의 급전선을 그 핀으로 잠시
옮겨** 본다 (LED1 은 1단계, LED2 는 3·4단계). 임시 급전선은 다음 단계 첫머리에서
걷고, 그 자리는 그림 아래 "앞 단계에서 걷는다" 표가 주소로 지시한다.

## 단계

| 단계 | 그림 | 이 단계에서 | 확인 |
|---|---|---|---|
| 1 | `실험03_1-2_결선도_전가산기_1단계_XOR1.png` | 74HC86 을 S1 에 꽂는다. 전원(14→VCC, 7→GND)·레일 브리지 셋·LED1 사슬·LED2 사슬(330Ω→GND)과 S3 전원 두 가닥을 미리 꽂는다. 신호선: A→pin 1, B→pin 2, **임시로** pin 3→LED1 급전 | 노드 `A⊕B` — LED1 을 A·B 네 조합으로 본다 (01·10 만 켜짐). 74HC86 첫 사용 |
| 2 | `실험03_1-2_결선도_전가산기_2단계_S.png` | **임시 급전선(U1 pin 3→LED1)을 걷는다.** 신호선: Ci→pin 5, U1 pin 3→U1 pin 4, pin 6→LED1 급전 | 노드 `S` — LED1 = A⊕B⊕Ci, T3 8행의 S 열 (입력에 1 이 홀수 개일 때만 켜짐) |
| 3 | `실험03_1-2_결선도_전가산기_3단계_AND1.png` | 74HC08 을 S3 에 꽂는다. 신호선: A 갈래→U2 pin 1, B 갈래→U2 pin 2 (둘 다 칩 위 4·5행을 건넌다), **임시로** U2 pin 3→LED2 급전 | 노드 `A·B` — LED2 를 A·B 네 조합으로 본다 (11 만 켜짐). 74HC08 첫 사용 |
| 4 | `실험03_1-2_결선도_전가산기_4단계_AND2.png` | **임시 급전선(U2 pin 3→LED2)을 걷는다.** 신호선: U1 pin 3→U2 pin 4, Ci 갈래→U2 pin 5, **임시로** U2 pin 6→LED2 급전 | 노드 `(A⊕B)·Ci` — LED2 를 T3 8행으로 본다 (A⊕B 와 Ci 가 둘 다 1 인 행만 켜짐) |
| 5 | `실험03_1-2_결선도_전가산기_5단계_Co.png` | **임시 급전선(U2 pin 6→LED2)을 걷는다.** 74HC32 를 S4 에 꽂고 전원 두 가닥을 잇는다. 신호선: U2 pin 3→U3 pin 2, U2 pin 6→U3 pin 1, U3 pin 3→LED2 급전 | 노드 `Co` — T3 8행 전부 (74HC32 첫 사용). LED1 = S 와 LED2 = Co 가 동시에 맞아야 한다 |

## 노드

| 노드 | 식 | 핀 |
|---|---|---|
| A⊕B | A⊕B | U1 pin 3 |
| S | A⊕B⊕Ci | U1 pin 6 |
| A·B | A·B | U2 pin 3 |
| (A⊕B)·Ci | (A⊕B)·Ci | U2 pin 6 |
| Co | A·B + (A⊕B)·Ci | U3 pin 3 |

- U1 = 74HC86 (quad 2-input XOR, DIP-14) — S1
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (XOR1)
  - pin 2  ← 입력 B
  - pin 3  → U1.pin4          (XOR1 출력 A⊕B → XOR2 입력)
  - pin 3  → U2.pin4          (A⊕B → AND2 입력, 팬아웃)
  - pin 4  ← U1.pin3          (XOR2)
  - pin 5  ← 입력 Ci
  - pin 6  → LED1 애노드 (330Ω 직렬) → GND    ※ S = A⊕B⊕Ci, T3 의 S 열
  - 미사용 입력핀: pin 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 8, 11 → 개방
- U2 = 74HC08 (quad 2-input AND, DIP-14) — S3
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (AND1)
  - pin 2  ← 입력 B
  - pin 3  → U3.pin2          (AND1 출력 A·B → OR)
  - pin 4  ← U1.pin3          (AND2, A⊕B)
  - pin 5  ← 입력 Ci
  - pin 6  → U3.pin1          (AND2 출력 (A⊕B)·Ci → OR)
  - 미사용 입력핀: pin 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 8, 11 → 개방
- U3 = 74HC32 (quad 2-input OR, DIP-14) — S4
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U2.pin6          ((A⊕B)·Ci)
  - pin 2  ← U2.pin3          (A·B)
  - pin 3  → LED2 애노드 (330Ω 직렬) → GND    ※ Co = A·B + (A⊕B)·Ci, T3 의 Co 열
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 6, 8, 11 → 개방

`Ci` 입력 점퍼는 U1 pin 5 와 U2 pin 5 두 곳으로 팬아웃한다. OR 의 두 입력은
교안 회로도에서 위가 AND2, 아래가 AND1 이지만 OR 은 교환 법칙이 성립하므로
pin 1·2 의 배정은 배선 편의다 — 교안 원문이 아니다(M11).

# C4 · 실험 2-2) 전감산기 (74HC86 + 74HC04 + 74HC08 + 74HC32)

- kind: circuit
- id: C4
- item: E3.P2-2
- tables: [T7]
- refs: [T8]
- diagram: 실험03_2-2_결선도_전감산기.png

교안 p7 회로도 그대로. C2(전가산기)를 다 만든 상태에서 바꾼다 — 교안이 앞에 두는
반감산기(실험 2-1)는 조교 공지 `_350547_1` 로 하지 않는다. 전가산기와 전감산기는
XOR 쪽이 같고 AND 입력 둘만 다르다: AND1 pin 1 이 `A` 대신 `A'` 를, AND2 pin 4 가
`A⊕B` 대신 `(A⊕B)'` 를 받는다. 그래서 새 칩은 `74HC04` 하나다.
0단계(걷기 보드)에서 **세 가닥**을 걷는다 — AND1 로 가던 `A` 갈래, AND2 로 가던
`A⊕B`, 그리고 LED2 의 최종 급전선이다. 마지막 것은 1단계에서 **프로브**가 된다:
Bo 는 아직 뜻이 없고(AND2 입력이 비었다) LED2 가 비므로, 급전선을 `A'·B` 핀에 잠시
꽂아 인버터가 들어온 것을 그 자리에서 본다. 2026-09-18 실험실에서는 이 중 두 가닥을
안 걷은 채 인버터 쪽을 꽂아 LED 가 어긋났고, 그 뒤로 걷기를 그림 한 장으로 뗐다.
`Ci` 점퍼는 그 자리 그대로 `Bi` 가 되고,
LED1 급전(U1 pin 6)·LED2 급전(U3 pin 3)도 그대로다 — `A⊕B⊕Ci` 와
`A⊕B⊕Bi` 는 같은 함수라 LED1 은 배선을 안 바꾸고 `S` 에서 `D` 가 된다.

## 노드

| 노드 | 식 | 핀 |
|---|---|---|
| A' | A' | U4 pin 2 |
| A⊕B | A⊕B | U1 pin 3 |
| (A⊕B)' | (A⊕B)' | U4 pin 4 |
| D | A⊕B⊕Bi | U1 pin 6 |
| A'·B | A'·B | U2 pin 3 |
| (A⊕B)'·Bi | (A⊕B)'·Bi | U2 pin 6 |
| Bo | A'·B + (A⊕B)'·Bi | U3 pin 3 |

- U1 = 74HC86 (quad 2-input XOR, DIP-14) — S1, C2 와 같은 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (XOR1)
  - pin 2  ← 입력 B
  - pin 3  → U1.pin4          (XOR1 출력 A⊕B → XOR2 입력)
  - pin 3  → U4.pin3          (A⊕B → NOT2 입력, 팬아웃)
  - pin 4  ← U1.pin3          (XOR2)
  - pin 5  ← 입력 Bi
  - pin 6  → LED1 애노드 (330Ω 직렬) → GND    ※ D = A⊕B⊕Bi, T7 의 D 열
  - 미사용 입력핀: pin 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 8, 11 → 개방
- U4 = 74HC04 (hex inverter, DIP-14) — S2
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (NOT1)
  - pin 2  → U2.pin1          (A')
  - pin 3  ← U1.pin3          (NOT2, A⊕B)
  - pin 4  → U2.pin4          ((A⊕B)')
  - 미사용 입력핀: pin 5, 9, 11, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 6, 8, 10, 12 → 개방
- U2 = 74HC08 (quad 2-input AND, DIP-14) — S3, C2 와 같은 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U4.pin2          (AND1, A')
  - pin 2  ← 입력 B
  - pin 3  → U3.pin2          (AND1 출력 A'·B → OR)
  - pin 4  ← U4.pin4          (AND2, (A⊕B)')
  - pin 5  ← 입력 Bi
  - pin 6  → U3.pin1          (AND2 출력 (A⊕B)'·Bi → OR)
  - 미사용 입력핀: pin 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 8, 11 → 개방
- U3 = 74HC32 (quad 2-input OR, DIP-14) — S4, C2 와 같은 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U2.pin6          ((A⊕B)'·Bi)
  - pin 2  ← U2.pin3          (A'·B)
  - pin 3  → LED2 애노드 (330Ω 직렬) → GND    ※ Bo = A'·B + (A⊕B)'·Bi, T7 의 Bo 열
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 6, 8, 11 → 개방

`A` 는 U1 pin 1·U4 pin 1 로, `Bi` 는 U1 pin 5·U2 pin 5 로, `A⊕B`(U1 pin 3) 는
U1 pin 4·U4 pin 3 으로 팬아웃한다. OR 의 pin 1·2 배정은 C2 와 같은 이유로
배선 편의다(M11).

# 미확정 사항

- kind: open-issues

교안 원문이 아닌 판단을 전부 모은다. 명세 쪽 미확정도 여기로 온다.

M7·M9 는 반감산기 몫이라 조교 공지 `_350547_1` 로 함께 뺐다.

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M1 | 준비물 p8 의 IC 목록 `74HC04, 74HC08, 74HC32, 74HC86` 에 **수량이 없다.** 종류당 한 패키지로 보고 두 회로를 순차 배선하도록 짰다 — 회로도의 라벨 중복은 전부 같은 패키지 안의 두 번째 게이트로 해석했다 | 실험실 키트에서 패키지 수 확인. 두 개씩이어도 C4 는 C2 에서 두 가닥만 바꾸면 되므로 이 결선도대로 한다 |
| M2 | 교안이 입력 스위치·딥스위치를 지정하지 않는다. 점퍼선 직결로 가정했다 | 실험실 키트 확인 |
| M3 | 74HC 출력으로 LED 를 직접 구동한다. 적색 LED 순방향 강하를 2V 로 보면 330Ω 에서 `(5−2)/330 ≈ 9.1 mA` 다 — 실험01 M3 과 같은 판단이고 교안 지시(p9)가 그러하므로 그대로 따른다 | LED 밝기가 눈에 띄게 낮으면 이 지점을 먼저 본다 |
| M4 | 칩 자리(S1 좌 7행·S2 좌 18행·S3 우 10행)는 실험01·02 결선도 관례를 따른 것이고 S4 우 21행은 이번에 새로 잡았다. 교안 근거가 없다. **2026-09-14 렌더로 확정** — 초안은 74HC08 을 S2(좌 18행)에 두었는데 교차 배선 수를 세어 AND 를 S3(우 10행), 인버터를 S2 로 바꿨다. 범위 축소 뒤의 5장(절차 3 + 완성본 2)도 렌더러의 물리 실현성 검사(R1~R6·넷)를 통과했다 | 실험실에서 슬롯을 바꾸면 그림과 어긋나므로 그대로 따른다. 우측 블록은 전원 레일이 좌우 뒤집혀 있어 U2·U3 의 pin 7 은 중앙 GND 레일, pin 14 는 우 바깥 VCC 레일로 간다(그림대로) |
| M5 | 교안 표기는 `74HC` 계열이다. 실물 각인이 다른 제조사(TI `SN74HC..`)여도 핀 배치는 같지만, `74HCT`·`74LS` 등 다른 계열이면 전기 특성(입력 문턱·미사용 입력 거동)이 달라 인용할 데이터시트를 바꾼다 | 수령한 칩의 각인 확인 |
| M6 | 교안 표지 머리글이 `25-1 논리회로실험` 이다. 2026-2 배포본이 지난 학기 슬라이드를 그대로 쓴 것인지, 다른 판이 따로 배포되는지 모른다 | 강의 사이트에서 배포 파일 갱신 여부 확인 |
| M8 | 회로도 두 장(p5·p7)의 위상은 래스터라 300dpi 렌더 후 vision 으로만 읽었다. 특히 전가산기 AND2 의 두 입력(`A⊕B`·`Ci`), 전감산기 NOT1 의 입력이 `A` 탭(`A'·B` 이지 `A·B'` 가 아니다), NOT2 의 입력(`A⊕B`)과 AND2 의 입력(`Bi`) 은 세로선 위치로 판독했다 | 교안 진리표와 부울식 역검산이 전부 일치한다(명세 T3·T7). 실험실에서 LED 가 T3·T7 과 어긋나면 이 배선부터 본다 |
| M10 | 준비물의 `발광 다이오드 (2개)` 가 출력 두 개에 배정되므로 `A⊕B`·`A·B`·`A'` 같은 중간단은 **완성본에** 관측점이 없다 | 중간 단계에서는 그 시점에 아직 급전되지 않은 LED 의 급전선을 관측 노드 핀으로 잠시 옮겨 본다 — 단계 표가 어느 핀인지 지시한다. 교안 부품 수를 넘기지 않고 완성본 결선도도 바뀌지 않는다. 멀티미터·로직프로브가 있으면 그것으로 대신해도 되고, 그때는 선을 옮기지 않는다 |
| M11 | 배선 편의로 정한 것: OR(U3) 의 pin 1·2 에 어느 AND 출력을 넣는지(교환 법칙), LED1 = 합/차·LED2 = 올림/내림 배정, 330Ω 을 애노드 쪽에 두는 직렬 순서. 교안 p9 는 "330Ω 저항과 다이오드를 연결" 까지만 쓴다 | 확인이 필요한 값은 아니다. 조교가 다른 배정을 지시하면 그쪽으로 — 함수는 바뀌지 않는다 |
| M12 | 미사용 게이트 입력을 개방하는 공통 규칙 자체가 교안 원문이 아니다. CMOS 는 플로팅 입력이 발진·소비 전류 증가를 부를 수 있는 계열이지만 실험01 실측(2026-09-11)에서 결과에 영향이 없었고, 이 주차 교안은 미사용 핀 처리를 말하지 않는다 | 조교가 접지·풀업을 지시하면 그대로 한다. LED 가 진리표와 다르면 이 자리를 본다 |

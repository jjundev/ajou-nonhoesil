교안은 2026-2 배포본 `강의노트/실험5. Decoder & Encoder.pdf`(13쪽)이다. 표지 머리글은
`25-1 논리회로실험` 이라 적혀 있다 — 실험04 배포본과 같은 모양이고, 이 명세는 그 파일
내용을 그대로 옮긴다(결선도 미확정 표). 과거 학기 아카이브 판(`from_the_past/정리/강의노트/실험5.pdf`)은
열지 않았다. 표 속성(`kind`·`encoding`·`source`·`role`·`outputs`)과 항목 필드의 뜻은
`docs/schema/lab-spec-v2.md` 가 정한다 — 이 문서는 그 계약의 인스턴스다.

교안 항목은 넷(실험 1-1 2X4 Decoder·1-2 BCD to Decimal Decoder·2-1 8x3 Priority Encoder·2-2
Decimal to Excess-3 Code Encoder)이지만 조교 공지 `_350547_1`(2026-09-14)로 이번 학기에는 실험
1-2·2-2 만 한다(`config.EXPERIMENT_SCOPE`). 1-1(`74HC04`·`74HC08`)과 2-1(`74HC148`)은 이 명세에
싣지 않는다. 항목 id·표 ID 는 교안 번호와 본문 순서다.

교안 본문과 p13 표는 `pypdf` 로 한글까지 읽힌다. `pdftotext -layout` 은 이 파일의 한글을 전부
떨어뜨리고, p13 표의 `BCD` 열을 한 행씩 밀어 낸다(7 행 `BCD` 가 `...`, 8 행이 `0111`, 끝에 `1001`
이 홀로 남는다) — p13 표 셀은 `pypdf` 추출과 110dpi 렌더 vision 판독이 셀 단위로 일치한 값을
옮겼다. **회로도 두 장(p9·p12)은 래스터라** 텍스트로는 신호 이름(p12 의 `D0`~`D5`·`A0`~`A3`)만
나오고 게이트 기호·IC 핀 번호·배선은 0 자다. p9 는 `Bit0`·`Y0`·`Y9` 가 머리말 문장 `Bit0-3`·`Y0-Y9`
안에만 있고 회로도 라벨은 텍스트 층에 하나도 없다. 두 쪽을 300dpi 로 렌더해 관심 영역을 잘라
vision 으로 읽었다 — 이 명세의 "회로도" 서술은 전부 그 판독이다.

교안은 두 항목 모두 **회로가 내는 진리표를 주지 않는다.** 1-2 는 표가 아예 없고, 2-2 는 p13 에
`INPUT (decimal) / BCD / OUTPUT (Excess-3)` 대응표를 주지만 그 표의 입력(10진수·BCD)은 회로의
입력선(`D0`~`D5`)이 아니다. 그래서 항목마다 기록표는 회로도에서 읽은 논리로 채운 `derived` 표
(`0/1`)이고, 2-2 는 교안 대응표를 원문 그대로 옮긴 참조표(`manual:p13`, `role: reference`)를 함께
싣는다. 교안 이론(p4 `8x3 Decoder`·p6 `8x3 Encoder` 의 `Truth Table`)은 싣지 않는다 — 두 항목 어느
회로와도 입출력이 다르고(p4 는 3입력 8출력 디코더, p6 은 OR 세 개 인코더), p4·p6 의 `D0`~`D7` 을
p4 는 출력으로, p6 은 입력으로 쓴다. 이 판단은 교안 원문이 아니다. 두 회로가 쓰는 게이트
(`74HC04` NOT·`74HC20` NAND)의 이론표는 이 교안에 없다.

준비물(p7 `실험 준비물`)은 `5V 전압원` · IC `74HC04, 74HC08, 74HC20(2개), 74HC42, 74HC148` ·
`발광 다이오드 (10개)` · `저항 330Ω (10개)` 다. 회로도의 입력은 전부 SPDT 스위치(위 접점 VCC, 아래
접점 GND, 공통 → 칩)인데 스위치는 준비물에 없다(결선도 미확정 표).

# E5.P1-2 · 실험 1-2) BCD to Decimal Decoder (4x16 Decoder)

교안 p9(회로도). 교안 원문: "주어진 회로를 구성하고, 입력신호의 변화에 따른 출력의 변화를
관찰한다." 그리고 "이때, IC가 Negative Logic이므로 선택 신호만 켜질 수 있도록 Output을 Negative
Logic으로 구축한다." 제목의 `(4x16 Decoder)` 는 교안 그대로 옮겼다 — `74HC42` 의 출력은 10 개다
(결선도 미확정 표). 회로도(vision, 교안 라벨 그대로):

- SW1(`Bit0`) → `74HC42` U1 pin 15 (`A`) ; SW2 → pin 14 (`B`) ; SW3 → pin 13 (`C`) ;
  SW4(`Bit3`) → pin 12 (`D`)
- U1 출력 `Y0`~`Y6` = pin 1~7, `Y7`~`Y9` = pin 9~11. 출력마다 버블이 있다
- 출력 연결은 대표 하나만 그린다: 출력 → `R1 330` → `D1`(LED) → `VCC`. 오른쪽 "출력 연결 예시"
  브레드보드 그림도 `Y0` → 저항 → LED `−` / LED `+` → `Vcc` 다

LED 열 개·330Ω 열 개는 준비물 수량이고, 출력마다 하나씩 다는 것은 예시 하나를 열 출력에
펼친 것이다 — 교안은 대표 하나만 그린다(결선도 미확정 표). 전원핀(16·8)은 회로도에 없다(결선도
`# 핀아웃 출처`). 관측점은 `Y0`~`Y9` 열이다.

부울식 `Yk = (입력 = k 인 최소항)'` 은 회로도가 아니라 칩의 기능이다 — 교안은 `74HC42` 의 기능표를
주지 않는다. Nexperia 74HC42 Rev. 4 Table 3 의 열여섯 행과 아래 T1 이 전부 일치한다(입력 10~15 는
출력이 모두 `1`). 교안이 "입력신호의 변화" 라고만 하므로 스위치 넷이 낼 수 있는 열여섯 조합을
전부 싣는다 — 10~15 행은 BCD 가 아닌 입력이라 교안 제목 밖이다(이 판단은 교안 원문이 아니다).

# E5.P2-2 · 실험 2-2) Decimal to Excess-3 Code Encoder

교안 p12(회로도)·p13(대응표). 교안 원문: "주어진 회로를 구성하고, IN0-7의 변화에 따른 출력의
변화를 관찰한다." 그리고 p13 "BCD코드에 3(0011)을 더한 값, Excess-3 코드가 제대로 출력되는지
확인한다." 회로도의 입력은 `IN0`~`IN7` 이 아니라 `D0`~`D5` 여섯이다(결선도 미확정 표). 회로도
(vision, 교안 라벨 그대로):

- `D5`→`74HC04` U1A(pin 1 → 2), `D4`→U1B(3 → 4), `D3`→U1C(5 → 6), `D2`→U1D(9 → 8),
  `D1`→U1E(11 → 10), `D0`→U1F(13 → 12)
- `D5'` → `74HC20` U2A pin 1. U2A pin 2·4·5 → `VCC`. 출력 pin 6 → `A3`
- `D4'`, `D3'`, `D2'`, `D1'` → `74HC20` U2B pin 9·10·12·13. 출력 pin 8 → `A2`
- `D4'`, `D3'`, `D0'` → `74HC20` U3A pin 1·2·4. pin 5 → `VCC`. 출력 pin 6 → `A1`
- `D4'`, `D2'`, `D0'` → `74HC20` U3B pin 9·10·12. pin 13 → `VCC`. 출력 pin 8 → `A0`
- 출력 연결은 대표 하나만 그린다: 출력 → `R1 330` → `D1`(LED) → 접지. 1-2 와 방향이 반대다

`74HC20`(4입력 NAND 둘이 든 패키지)이 회로도에 U2·U3 **두 패키지**로 나온다 — 준비물의
`74HC20(2개)` 와 같다. `ics` 는 패키지 이름 목록이라 `74HC20` 한 번만 적는다(수량은 이 산문이
말한다). `74HC04` 는 인버터 여섯을 다 쓴다. 핀 번호는 교안 회로도가 게이트마다 적어 둔 것이다
(`74HC20` 의 pin 3·11 은 회로도에 없다 — 데이터시트상 미연결이다, 결선도 `# 핀아웃 출처`).
U3 의 세로 버스 가운데 어느 선이 어느 핀으로 가는지는 접점 점과 꺾임 위치로 읽었다(결선도
미확정 표). 관측점은 `A3`~`A0` 넷이다. LED 넷은 준비물 열 개 중 넷을 쓴 것이고 출력마다 하나씩
다는 것은 교안 원문이 아니다(결선도 미확정 표).

부울식 `A3 = (D5')'` · `A2 = (D4'·D3'·D2'·D1')'` · `A1 = (D4'·D3'·D0')'` · `A0 = (D4'·D2'·D0')'` 은
회로도에서 읽은 것이다(VCC 에 묶인 입력은 1 이라 식에서 뺐다). 드모르간으로 펴면 `A3 = D5`,
`A2 = D4 + D3 + D2 + D1`, `A1 = D4 + D3 + D0`, `A0 = D4 + D2 + D0` 이다. 아래 T2 는 입력 하나만 `1`
인 여섯 행이다 — 교안 p13 이 10진수 하나씩을 넣어 보는 표라서다. 여섯 행 출력이 T3(교안 원문)의
10진수 0~5 행과 전부 일치한다(0·1·2 는 T3 에 그대로 있고, 3·4·5 는 T3 이 `…` 로 줄인 자리라
"BCD코드에 3(0011)을 더한 값" 으로 맞댔다). T3 의 6~9 행은 이 회로에 입력선이 없어 실험실에서
낼 수 없다(결선도 미확정 표). 입력이 둘 이상 `1` 이거나 모두 `0` 인 조합은 교안이 다루지 않아
싣지 않는다 — 이 판단은 교안 원문이 아니다.

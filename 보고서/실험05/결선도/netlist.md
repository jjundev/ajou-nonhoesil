# 공통 규칙

- kind: common

- 전원은 준비물 p7 의 `5V 전압원`, 회로도 p9·p12 의 `VCC` 다. **`74HC42` 는 16핀이라 pin 16 →
  VCC(+5V), pin 8 → GND** 다. `74HC04`·`74HC20` 은 계열 표준대로 pin 14 → VCC, pin 7 → GND 다.
  `74HC20` 의 pin 3·11 은 **미연결(n.c.)** 이다(`# 핀아웃 출처`) — 칩 안에서 아무 데도 이어지지 않아
  U2 pin 3 만 `D3'` 의 디딤돌(중계)로 쓰고 나머지 셋(U2 pin 11, U3 pin 3·11)은 비워 둔다(M18)
- 핀 번호는 **교안 회로도(p9·p12)가 적어 둔 번호 그대로**다. U 번호만 두 회로도를 한 체계로 다시
  붙였다(M7): `U1` = `74HC04`, `U2`·`U3` = `74HC20`(p12 와 같다), `U4` = `74HC42`(p9 의 U1).
  게이트 접미사(`U1A`~`U1F`, `U2A`·`U2B`)는 교안 회로도 표기다 — `A` 가 pin 1 쪽 첫 게이트다.
  준비물에 수량이 없는 `74HC04`·`74HC42` 는 하나로 본다(M15)
- **사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지). 교안이 VCC 에 묶은 `74HC20` 입력(U2
  pin 2·4·5, U3 pin 5·13)도 쓰는 입력이다 — +5V 레일에 꽂는다. 중간 단계에서 아직 세우지 않은
  게이트의 입력은 그 게이트를 세우는 단계까지 비어 있다 — 관측 노드의 상류가 아니므로 미사용
  게이트와 같이 다룬다(M12). **미사용 게이트의 입력은 접지하지 않는다** — 교안이 미사용 핀 처리를
  말하지 않는 주차이고, 실험01 실측(2026-09-11)에서 접지 생략이 결과에 영향이 없었다. 이 규칙은
  교안 원문이 아니다(M12). 이 주차는 두 회로 모두 칩의 입력을 전부 쓴다 — 미사용 입력핀이 없다
- **칩을 꽂거나 뽑을 때는 전원을 끈다.** 교안 원문이 아닌 안전 절차다
- **교안 실험 1-1(`74HC04`·`74HC08`)·2-1(`74HC148`)은 하지 않는다** — 조교 공지 `_350547_1`.
  그래서 C1 은 맨바닥에서 시작한다
- **C2(Excess-3)는 C1(BCD 디코더)의 신호선을 전부 뽑고 새로 짓는다**(M6, `rebuild: true`). 칩이
  전부 바뀐다(`74HC42` → `74HC04`·`74HC20` 둘). **LED 사슬도 남기지 않는다** — C1 은 `+5V → LED →
  330Ω → 출력`(출력 0 에서 켜짐), C2 는 `출력 → 330Ω → LED → GND`(출력 1 에서 켜짐)라 방향이
  반대다. C1 사슬 열 개를 뽑고 C2 1단계가 넷을 새로 꽂는다(M16)
- **단계 하나는 관측 노드 하나를 세운다.** 확인은 `## 단계` 표의 `확인` 칸이 가리키는 노드 하나를
  본다. 중간 노드는 그 시점에 비어 있는 LED 의 급전선을 그 핀으로 잠시 옮겨 보고, 뽑는 자리에
  `<k>걷기` 행과 걷기 그림을 둔다(C2 `3걷기`). 각 칩을 처음 쓰는 단계는 C1 1단계(74HC42 U4)·C2
  1단계(74HC04 U1·74HC20 U2)·C2 3단계(74HC20 U3)이고, 두 회로 모두 마지막 단계에서 기록 진리표 전
  행을 돌린다
- **이 주차의 새 신호선 예산은 5 다**(M8) — `74HC42` 출력 하나는 입력 넷이 다 있어야 정해지고
  (C1 1단계: 입력 넷 + LED 급전 하나), `74HC20` 출력 하나도 입력 넷을 받는다. 예산 = 게이트 입력
  수 + 1 이고 `배치.py` 에 `STAGE_WIRE_BUDGET = 5` 와 그 이유를 둔다
- **기반**은 단계마다 세지 않는 배선이다 — 칩 꽂기·전원선·레일 브리지(바깥 레일과 가운데 레일을
  잇는 선)·LED 사슬 부품. **급전**은 출력 핀에서 LED 사슬 첫 홀로 가는 신호선이다. **배너**는
  체크리스트가 회로 첫머리에 찍는 칩 교체·걷기 안내다. `R7`~`R10` 은 결선도 렌더러의 검사 규칙이다
  (`breadboard-diagram` SKILL — R7 칩 한쪽 리드 ≤ 8, R8 칩 사이 선이 쪽을 안 바꿈, R9 칩은 좌 블록,
  R10 건너는 선 순서 = LED 순서)
- **칩 자리는 고정이다** (아래 `# 칩 자리표`). 그림의 **회색 선은 손대지 않는다** — 걷을 선은
  걷기 그림(빨간 점선), 새 선은 단계 그림(회색 기준선 위 번호)이 지시한다
- 입력 `Bit0`~`Bit3`·`D0`~`D5` 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물린다. 띄워두지
  않는다. 교안 회로도는 입력마다 SPDT 스위치를 그리지만 스위치는 준비물에 없다(M2)
- LED 는 준비물 p7 `발광 다이오드 (10개)`·`저항 330Ω (10개)` 다. C1 은 열 개 전부(`Y0`~`Y9`),
  C2 는 넷(`A3`~`A0`)을 쓴다. 출력마다 LED 하나를 다는 것은 교안이 대표 하나만 그린 것을 펼친
  것이다(M3)
- 한 신호가 여러 핀으로 가면(팬아웃) **목적지 스트립에서 다음 목적지로 이어 간다** — 칩 안에서
  a쪽과 f쪽을 잇는 이어 가기도 쓴다. a쪽은 브레드보드 a~e 열에 앉는 다리(14핀 칩 pin 1~7, 16핀
  `74HC42` pin 1~8), f쪽은 f~j 열에 앉는 다리(pin 8~14 / pin 9~16)다(예: `D4'` 는 U1 pin 4 → U3 pin 1 → U3 pin 9
  → U2 pin 9). 전기적으로는 한 노드다(M11)
- 핀 줄의 `※` 뒤는 그 점의 신호 이름과 명세 표 대응을 적은 주석이다(배선 지시가 아니다)

# 꼭 읽을 것

- kind: must-read

- **`74HC42` 는 16핀이에요 — pin 16 이 +5V, pin 8 이 GND** 예요(14·7 이 아니에요). `74HC20` 의
  pin 3·11 은 빈 다리예요 — U2 pin 3 에만 `D3'` 를 잇는 선 두 가닥을 꽂아요
- **C1 LED 는 거꾸로 꽂아요** — `+5V → LED → 330Ω → 출력`, 출력이 0 일 때 켜져요(Negative Logic).
  **C2 LED 는 `출력 → 330Ω → LED → GND`** 로 1 일 때 켜져요
- 입력 `Bit0`~`Bit3`·`D0`~`D5` 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물려요. 스위치는
  없어요. `74HC20` 의 VCC 묶음 입력(U2 pin 2·4·5, U3 pin 5·13)도 반드시 +5V 에 꽂아요
- **C2 는 C1 을 전부 뽑고 새로 지어요** — 신호선, `74HC42` 와 그 전원선 두 가닥, **LED 사슬 열
  개까지** 뽑아요. 레일 브리지만 남겨요. C2 1단계에서 LED 사슬 넷을 반대 방향으로 다시 꽂아요
- C2 2단계의 U1 pin 12 → LED A2 선은 **임시**예요 — `3걷기` 그림대로 뽑고 나서 3단계를 해요

# 핀아웃 출처

- kind: sources

**교안이 신호핀 번호를 직접 준다** — p9 회로도가 `74HC42` 의 입력(15·14·13·12)과 출력(1~7·9~11)을,
p12 회로도가 `74HC04`(1→2·3→4·5→6·9→8·11→10·13→12)와 `74HC20`(1·2·4·5→6·9·10·12·13→8)을 적어
두었다. 회로도는 래스터라 300dpi 렌더를 잘라 vision 으로 읽었다. 교안에 없는 전원핀·미연결핀은
제조사 1차 데이터시트로 확인했고(`74HC42` 는 이번에 직접 열었고 `74HC20`·`74HC04` 는 저장소 기록
경유다 — 아래), 교안이 적은 신호핀도 전부 데이터시트와 일치한다. 남은 약한 자리는 하나다 —
`74HC42` 데이터시트가 SO16 판이라 **DIP-16 실물**의 배치는 출처 없는 저장소 그림으로만 맞댔다(M14).

- `74HC42` — Nexperia 74HC42, BCD to decimal decoder (1-of-10), Rev. 4 (2024-03-26) §5.2 Table 2
  Pin description · §6 Table 3 Function table.
  `https://assets.nexperia.com/documents/data-sheet/74HC42.pdf` 를 2026-10-05 에 직접 열어 확인:
  `0Y~6Y = 1~7, 7Y = 9, 8Y = 10, 9Y = 11, GND = 8, 0A = 15, 1A = 14, 2A = 13, 3A = 12, VCC = 16`.
  Table 3 은 입력 10~15 에서 출력이 전부 H 다. 이 판은 SO16(SOT109-1)만 싣는다 — 실험실 칩은 DIP
  일 것이고 핀 배치가 같다는 것은 저장소 그림
  `from_the_past/정리/소자_데이터시트_및_미디어/1_데이터시트_및_핀아웃/74hc42-bcd-todecimal.jpg`(Top
  view, 출처 표기 없음)가 같은 번호를 보이는 것으로만 맞댔다(M14). 서지는 `.claude/데이터시트_출처.md`
  Nexperia 표에 있다
- `74HC20` — Nexperia 74HC20, Dual 4-input NAND gate, Rev. 7 (2024-03-14) §5.2 Pin description. 저장소
  기록 경유: `보고서/실험04/결선도/netlist.md` § 핀아웃 출처가 2026-09-27 에 직접 열어 `1A=1, 1B=2,
  n.c.=3, 1C=4, 1D=5, 1Y=6, GND=7, 2Y=8, 2A=9, 2B=10, n.c.=11, 2C=12, 2D=13, VCC=14` 로 옮겼다
- `74HC04` — Nexperia 74HC04; 74HCT04 Rev. 10 (2024-02-16) §5.2 Table 2. 저장소 기록 경유:
  `보고서/실험02/결선도/netlist.md` § 핀아웃 출처가 입력 `1, 3, 5, 9, 11, 13`, 출력 `2, 4, 6, 8, 10,
  12`, GND 7, VCC 14 로 옮겼다

교안 표기가 `74HC` 계열이므로 실물이 TI `SN74HC..` 각인이어도 핀 배치는 같다. 각인이 `74HC` 가
아닌 계열(`74LS`·`74HCT` 등)이면 전기 특성이 달라 인용할 데이터시트를 바꾼다(M14).

교안 p9 회로도 그대로. 이 주차 첫 회로라 맨바닥에서 시작한다. 1단계에 `74HC42`(U4) 전원과 LED 열
사슬(`+5V → LED → 330Ω`, 출력 쪽이 급전 끝)을 한꺼번에 꽂는다(기반). 칩이 하나라 중간 노드가 없고
출력 열이 곧 노드 열이다. **관측 단계**는 넷이다 — 1단계가 입력 넷과 `Y0` 를, 2~4단계가 출력을 셋씩
LED 에 잇는다. 1단계 새 신호선은 다섯이다(예산 5, M8). LED 는 구동 핀의 행 순서로 붙는다 —
위에서부터 `Y0`~`Y5`, `Y9`, `Y6`, `Y8`, `Y7`(M17).

교안 p12 회로도 그대로, **C1 을 걷고 새로 짓는다**(M6). 전원을 끄고 C1 의 신호선(입력 점퍼·LED
급전선)을 전부 뽑고, `74HC42` 와 **그 전원선 두 가닥**을 빼고, **LED 사슬 열 개(LED·330Ω·+5V 선)도
뽑는다**(M16). 레일 브리지만 그대로 둔다. K1 의 전원선은 K3 의 `74HC20`(U2)과 행이 겹쳐 남겨 둘 수
없다(`# 칩 자리표`, 교안 원문이 아니다, M6). 1단계가 `74HC04`(U1)를 K2,
`74HC20`(U2·U3)을 K3·K4 에 꽂고 전원과 VCC 묶음, LED 네 사슬(`출력 → 330Ω → LED → GND`)을 꽂는다.

**관측 단계**는 다섯이다 — `A3`(1), 인버터 `D0'`(2, 임시 급전), `A1`(3), `A0`(4), `A2`(5). 인버터가
하나뿐인 `A3` 부터 세우고, 입력 넷이 모두 인버터를 거치는 `A2` 를 마지막에 둔다 — 앞 단계에 꽂은
인버터 출력에서 이어 가도록 짠 순서이고 교안 원문이 아니다(M11). 2단계는 인버터 셋에 입력을
물리고 그중 `D0'` 하나를 그 시점에 비어 있는 LED A2 로 본다. 그 임시 급전선을 `3걷기` 에서 뽑는다.
`D0'`(f쪽 pin 12)를 고른 것은 a쪽 `D4'`(pin 4)에서 LED 로 가는 길이 칩 몸통을 건널 자리가 없어서다
(교안 원문이 아니다, M18). 2단계는 입력 넷을 물리느라 다섯 가닥이 차서 `D1` 도 여기서 꽂아 둔다 —
5단계가 예산에 차서다. 각 단계의 새 신호선은 셋~다섯이다(예산 5, M8). 걷기 주소는 `배치.py` 가
뽑은 그림의 주소다(M10).

# 칩 자리표

- kind: layout

두 회로는 칩을 공유하지 않는다 — C1 은 `74HC42` 하나, C2 는 `74HC04`·`74HC20` 둘이다. 그래서 C2 는
C1 을 전부 뽑고(`rebuild`) 다른 슬롯에 새로 꽂는다. 슬롯은 역할에 붙는다: 디코더(K1), 인버터(K2),
앞 NAND(K3, `A3`·`A2`), 뒤 NAND(K4, `A1`·`A0`). v2 판형이라 칩은 전부 **좌 블록**에 두고(R9) LED 는
우 블록이다. `좌`·`우` 는 브레드보드 왼쪽·오른쪽 블록, 행은 칩 pin 1 이 앉는 행이다. 홀 주소
`좌 j19` 는 왼쪽 블록 j 열 19행이다(열 a~e 가 칩 a쪽, f~j 가 f쪽). 행은 `배치.py` 의 `LAYOUT` 이고
배치기(`python -m scripts.lab.place_search <배치.py>`) 결과 `배치탐색.md` 와 같다(M10). K1 과 K3 은
행이 겹친다 — 두 회로가 동시에 서지 않아서다. 그래서 C2 는 K1 의 전원선까지 뽑는다. U1 이 U2·U3
사이에 서는 것은 2단계 임시 급전이 LED A2 를 빌려서다(R10 — 건너는 선 순서 = LED 순서).

| K1 | 좌 3행 | C1 74HC42 (U4, BCD 디코더) · C2 비움 |
| K2 | 좌 17행 | C1 비움 · C2 74HC04 (U1, 인버터 여섯) |
| K3 | 좌 5행 | C1 비움 · C2 74HC20 (U2, NAND `A3`·`A2`) |

교안 원문이 아닌 판단을 전부 모은다. 명세 쪽 미확정도 여기로 온다.

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M1 | 교안 표지 머리글이 `25-1 논리회로실험` 이다(실험04 배포본과 같다). 2026-2 배포본이 지난 학기 슬라이드를 그대로 쓴 것인지 모른다 | 강의 사이트에서 배포 파일 갱신 여부 확인 |
| M2 | 교안 회로도(p9·p12)는 입력마다 SPDT 스위치(위 접점 VCC, 아래 접점 GND, 공통 → 칩)를 그리는데 스위치는 준비물 p7 에 없다. 점퍼선 직결로 가정했다 — 전기적으로는 같은 0/1 이다 | 실험실 키트에 딥스위치·토글스위치가 있으면 그것을 쓴다 |
| M3 | 교안은 LED 를 출력마다 그리지 않는다 — p9·p12 모두 출력은 포트 기호로 끝나고, 아래에 `R1 330`·`D1` 대표 하나만 있다. 준비물 `발광 다이오드 (10개)`·`저항 330Ω (10개)` 가 C1 출력 열과 맞으므로 출력마다 하나씩 달았다. 적색 LED 순방향 강하를 2V 로 보면 330Ω 에서 `(5−2)/330 ≈ 9.1 mA` 다(실험04 M3 과 같은 판단). C1 은 출력이 LOW 로 그 전류를 받아들이고, C2 는 HIGH 로 내보낸다. Nexperia 74HC42 Rev. 4 Table 6 은 VOH·VOL 을 VCC 4.5V 에서 `|IO| = 4.0 mA`(6.0V 에서 5.2 mA)까지 규정한다 — LED 를 구동하는 출력의 전압은 규정 밖이다(`74HC20`·`74HC04` 도 같은 조건이라 보았다 — 실험04 M3). C2 2단계의 임시 급전 중에는 U1 pin 4 가 LED 를 구동한다 | 조교가 다른 관측 방법을 지시하면 그쪽으로 — 함수는 바뀌지 않는다 |
| M4 | 명세 T1 의 10~15 행(BCD 가 아닌 입력)은 교안이 다루지 않는다 — 교안은 "입력신호의 변화" 라고만 한다. 출력이 모두 `1` 이라는 값은 Nexperia 74HC42 Rev. 4 Table 3 에서 왔다. 교안 제목의 `(4x16 Decoder)` 와 달리 `74HC42` 출력은 10 개다 | 실험실에서 10~15 를 넣어 LED 가 하나도 안 켜지는지 본다. 조교가 0~9 만 보라고 하면 그 행은 건너뛴다 |
| M5 | 교안 p12·p13 두 쪽 모두 머리말이 "D0-5: Input, A0-A2: Output" 이고 본문이 "IN0-7의 변화에 따른 출력의 변화를 관찰한다" 인데, p12 회로도의 입력은 `D0`~`D5` 여섯, 출력은 `A3`~`A0` 넷이다. `IN0-7` 은 앞 항목 2-1(8x3 Priority Encoder) 문장, `A0-A2` 는 2-1 의 출력 범위와 같다. 명세는 회로도 라벨(`D0`~`D5`·`A3`~`A0`)을 썼다. 또 p13 대응표는 10진수 0~9 를 싣지만 회로에 `D6`~`D9` 입력선이 없어 6~9 행은 실험실에서 낼 수 없다. 명세 T2 는 0~5 여섯 행이고 T3(참조)이 교안 표를 그대로 옮긴다 | 조교에게 6~9 를 다루는지 묻는다. 다루면 교안 밖 회로라 이 결선도를 다시 짠다 |
| M6 | **C2 는 C1 의 신호선을 전부 뽑고 새로 짓는다**(`rebuild: true`). 두 회로가 칩을 하나도 공유하지 않아 골라 뽑을 선이 없다. 걷기 그림·홀 주소 목록을 두지 않는다. K1(C1 `74HC42`)과 K3(C2 U2)은 행이 겹쳐 K1 전원선 두 가닥도 뽑는다 — 남는 것은 레일 브리지뿐이다 | 1단계 전에 보드에 레일 브리지 말고 아무것도 남지 않았는지 눈으로 본다 |
| M7 | U 번호 재부여: 교안 두 회로도의 U 번호는 서로 독립이다(p9 의 U1 = `74HC42`, p12 의 U1 = `74HC04`). p12 의 U1·U2·U3 은 그대로 두고 p9 의 U1(`74HC42`)을 U4 로 붙였다 — 칩이 셋인 C2 쪽 번호를 교안과 맞추려는 것이다. 핀 번호는 바꾸지 않았다 | 확인이 필요한 값은 아니다. 교안 p9 와 대조할 때 U4 = 교안 U1 이다 |

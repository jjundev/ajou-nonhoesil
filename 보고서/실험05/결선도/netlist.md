# 공통 규칙

- kind: common

## 1. 전원 핀이 IC 마다 다르다 — 이번 주의 1순위 사고

1~4주차는 전부 DIP-14 라 `pin 14 → VCC`, `pin 7 → GND` 하나로 끝났다.
이번 주는 **`74HC42` 와 `74HC148` 이 DIP-16** 이다.

| 패키지 | VCC | GND | 이 실험에서 |
|---|---|---|---|
| DIP-14 | pin 14 | pin 7 | `74HC04`, `74HC08`, `74HC20` |
| **DIP-16** | **pin 16** | **pin 8** | **`74HC42`, `74HC148`** |

**14핀 습관으로 16핀 칩에 `pin 14 → +5V`, `pin 7 → GND` 를 꽂으면 세 가지가
동시에 일어난다:**

1. **진짜 전원핀 pin 16 · pin 8 이 뜬다** → 칩에 전원이 아예 안 들어간다.
   아무 것도 동작하지 않는다.
2. **pin 7 이 GND 에 단락된다.** pin 7 은 `74HC42` 에서 `Y6`, `74HC148` 에서
   `A1` — **둘 다 출력**이다. 출력을 레일에 직결하는 것이다.
3. **pin 14 에 +5V 가 걸린다.** `74HC148` 의 pin 14 는 `GS` **출력**이라
   이것도 출력 직결이고, `74HC42` 의 pin 14 는 `B` 입력이지만 칩이 무전원인
   상태라 입력 보호 다이오드를 통해 전류가 떠 있는 VDD 로 흘러든다.

**즉 "안 켜지네" 로 끝나지 않고 칩이 상할 수 있다.** 전원을 넣기 전에 16핀 칩
두 개의 pin 8 · pin 16 을 반드시 손가락으로 짚어 확인한다. DIP-16 은 몸통이
길어 눈으로는 DIP-14 와 잘 구분되지 않으므로, **핀을 세어서** 확인한다.

## 2. 미사용 입력핀 — 규칙이 두 갈래로 갈린다

`docs/schema/lab-spec-v1.md` 가 말하는 "미사용 입력핀 처리"는 이번 주에
**두 가지 서로 다른 규칙**이 된다. 1주차의 "전부 GND" 를 그대로 적용하면
E5.P3 이 조용히 틀린다.

| 상황 | 처리 | 이유 |
|---|---|---|
| 게이트를 통째로 안 쓴다 (출력 개방) | 입력 → GND | 1주차 규칙 그대로. 플로팅 방지 |
| **쓰는 게이트의 남는 입력** — AND / NAND | **→ VCC** | 1 이 AND 의 항등원. GND 로 내리면 출력이 영구히 고정된다 |
| 쓰는 게이트의 남는 입력 — OR / NOR | → GND | 0 이 OR 의 항등원 |
| NC 핀 (`74HC20` pin 3 · pin 11) | **개방** | 내부 미연결. GND 도 VCC 도 물리지 않는다 |
| 미사용 **출력**핀 | 개방 | 출력끼리 묶거나 레일에 물리면 칩이 죽는다 |

교안 p14 회로도가 `74HC20` 의 남는 입력 **5개를 전부 VCC 레일**로 올려 둔 것이
이 규칙의 실물 근거다 (300 DPI 렌더 후 vision 으로 판독: U2A pin 2·4·5,
U3A pin 5, U3B pin 13). 이걸 습관대로 GND 로 내리면 그 NAND 출력이 항상 1 이
되어 `Bit3`·`Bit1`·`Bit0` LED 가 입력과 무관하게 계속 켜진다.

## 3. LED 방향이 항목마다 뒤집힌다 — 이번 주의 2순위 사고

교안이 `74HC42`(p13)와 `74HC148`(p22) 회로도에만 `Negative Logic` 이라고
형광펜을 칠해 두었고, 그 두 회로만 LED 심볼의 방향이 반대다 (p8·p13·p14·p22
하단 LED 를 각각 확대해 vision 으로 확인).

| 항목 | 배선 | 점등 조건 |
|---|---|---|
| E5.P1 `74HC08` | IC 출력 → 330Ω → **LED 애노드**, LED 캐소드 → GND | 출력 HIGH (source) |
| E5.P2 `74HC42` | VCC → **LED 애노드**, LED 캐소드 → 330Ω → IC 출력 | 출력 LOW (sink) |
| E5.P3 `74HC20` | IC 출력 → 330Ω → **LED 애노드**, LED 캐소드 → GND | 출력 HIGH (source) |
| E5.P4 `74HC148` | VCC → **LED 애노드**, LED 캐소드 → 330Ω → IC 출력 | 출력 LOW (sink) |

- LED 애노드는 **긴 다리**, 캐소드는 짧은 다리(패키지의 깎인 면)다.
- E5.P2·E5.P4 를 P1 방식(애노드가 IC 쪽)으로 꽂으면 **아무 것도 안 켜진다.**
  출력이 LOW 여도 전류가 흐를 경로가 없다. 고장이 아니라 방향 오류다.
- 반대로 저항을 빼고 꽂으면 LED 와 IC 출력단이 함께 죽는다. **330Ω 은 어느
  방향이든 필수다** (교안이 네 회로 모두에 `R 330` 을 그려 두었다).

## 4. 입력 스위치

교안 회로도의 입력 소자는 전부 `SW SPDT` 다. 공통(가운데) 단자 → IC 입력,
한쪽 고정단자 → VCC(= 1), 다른 쪽 → GND(= 0). p8·p13·p22 모두 **위쪽 접점이
VCC, 아래쪽이 GND** 로 그려져 있다 (vision 확인).

실험실 키트에 SPDT 가 없으면 점퍼선을 VCC 또는 GND 에 **직결**한다. 어느
경우에도 입력을 띄워 두지 않는다.

## 5. 물리 칩·부품 재사용 — 네 회로를 동시에 올릴 수 없다

교안 p2 준비물은 `74HC04` 1개 / `74HC08` 1개 / `74HC20` **2개** / `74HC42` 1개 /
`74HC148` 1개, LED 10개, 330Ω 10개다.

- **`74HC04` 는 한 개뿐인데** E5.P1 이 인버터 2개, E5.P3 이 6개를 쓴다. 합이 8 >
  6 이므로 두 회로는 **동시에 올릴 수 없다.** 아래에서 `U1`(P1)과 `U4`(P3)는
  같은 물리 칩을 다시 배선한 것이다.
- LED·저항도 E5.P2 가 10개를 전부 쓴다. 항목을 하나씩 세우고 헐고 다음으로 간다.
- `74HC20` 만 2패키지를 동시에 쓴다 (게이트 4개가 필요한데 패키지당 2개다).

# E5.P1 · 2X4 Decoder (74HC04 + 74HC08)

- kind: circuit
- id: C1
- item: E5.P1
- tables: [T2]
- refs: [T1]

교안 p8. `Bit0`·`Bit1` 두 입력과 그 보수 네 개를 `74HC08` 네 게이트로 짝지어
최소항 4개를 만든다. 배선 위상은 p8 을 300 DPI 로 렌더해 vision 으로 추적했고,
p9~p12 의 "이 입력에서 이 LED 가 켜진다" 빨간 박스 네 장과 **교차 확인**했다.

- SW1 (SPDT) — 교안 라벨 `Bit0`
  - 공통 단자 → `Bit0` 노드
  - 위쪽 접점 → VCC(+5V) = 1 / 아래쪽 접점 → GND = 0
- SW2 (SPDT) — 교안 라벨 `Bit1`
  - 공통 단자 → `Bit1` 노드
  - 위쪽 접점 → VCC(+5V) = 1 / 아래쪽 접점 → GND = 0
- U1 = `74HC04` (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← `Bit0` 노드            (인버터1 입력)
  - pin 2  → `Bit0'` 노드           (인버터1 출력)
  - pin 3  ← `Bit1` 노드            (인버터2 입력)
  - pin 4  → `Bit1'` 노드           (인버터2 출력)
  - 미사용 입력핀: pin 5, 9, 11, 13 → GND   ※ 게이트 전체 미사용이라 GND
  - 미사용 출력핀: pin 6, 8, 10, 12 → 개방
- U2 = `74HC08` (quad 2-input AND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← `Bit0`                 (게이트 A)
  - pin 2  ← `Bit1`
  - pin 3  → 330Ω → D1 애노드, D1 캐소드 → GND    ※ D1 = Bit1·Bit0 (십진 3)
  - pin 4  ← `Bit0'`                (게이트 B)
  - pin 5  ← `Bit1`
  - pin 6  → 330Ω → D2 애노드, D2 캐소드 → GND    ※ D2 = Bit1·Bit0' (십진 2)
  - pin 9  ← `Bit0`                 (게이트 C)
  - pin 10 ← `Bit1'`
  - pin 8  → 330Ω → D3 애노드, D3 캐소드 → GND    ※ D3 = Bit1'·Bit0 (십진 1)
  - pin 12 ← `Bit0'`                (게이트 D)
  - pin 13 ← `Bit1'`
  - pin 11 → 330Ω → D4 애노드, D4 캐소드 → GND    ※ D4 = Bit1'·Bit0' (십진 0)
  - 미사용 입력핀 없음 / 미사용 출력핀 없음 (게이트 4개 전부 사용)

노드 팬아웃: `Bit0` → U1.pin1, U2.pin1, U2.pin9 (3곳) · `Bit1` → U1.pin3,
U2.pin2, U2.pin5 (3곳) · `Bit0'` → U2.pin4, U2.pin12 (2곳) · `Bit1'` →
U2.pin10, U2.pin13 (2곳).

**LED 번호에 속지 말 것.** 교안이 위에서부터 D1, D2, D3, D4 라고 붙였지만
디코딩 값은 **3, 2, 1, 0** 이다. `D1` 이 십진 1 이라고 믿고 기록하면 T2 가
통째로 뒤집힌다.

**자체 검산:** 어떤 입력에서도 LED 는 정확히 한 개만 켜진다. 두 개가 켜지면
같은 노드를 두 게이트에 잘못 물린 것이고, 하나도 안 켜지면 `74HC04` 전원이나
스위치 공통 단자를 먼저 본다.

# E5.P2 · BCD to Decimal Decoder (74HC42)

- kind: circuit
- id: C2
- item: E5.P2
- tables: [T3]

교안 p13. **DIP-16 이고 LED 가 뒤집혀 있다** — 위 공통 규칙 1·3 을 먼저 읽을 것.

- SW1~SW4 (SPDT 4개) — 교안 라벨 `Bit0`(SW1) ~ `Bit3`(SW4)
  - 각 공통 단자 → 아래 U3 의 대응 입력핀
  - 각 위쪽 접점 → VCC(+5V) = 1 / 아래쪽 접점 → GND = 0
- U3 = `74HC42` (BCD-to-decimal decoder, **DIP-16**)
  - **pin 16 → VCC(+5V)**            ※ pin 14 가 아니다
  - **pin 8  → GND**                 ※ pin 7 이 아니다
  - pin 15 ← SW1 공통 (`A`, LSB, 교안 `Bit0`)
  - pin 14 ← SW2 공통 (`B`, 교안 `Bit1`)
  - pin 13 ← SW3 공통 (`C`, 교안 `Bit2`)
  - pin 12 ← SW4 공통 (`D`, MSB, 교안 `Bit3`)
  - pin 1  → `Y0` (Active Low) → 330Ω → LED0 캐소드, LED0 애노드 → VCC(+5V)
  - pin 2  → `Y1` → 330Ω → LED1 캐소드, LED1 애노드 → VCC(+5V)
  - pin 3  → `Y2` → 330Ω → LED2 캐소드, LED2 애노드 → VCC(+5V)
  - pin 4  → `Y3` → 330Ω → LED3 캐소드, LED3 애노드 → VCC(+5V)
  - pin 5  → `Y4` → 330Ω → LED4 캐소드, LED4 애노드 → VCC(+5V)
  - pin 6  → `Y5` → 330Ω → LED5 캐소드, LED5 애노드 → VCC(+5V)
  - pin 7  → `Y6` → 330Ω → LED6 캐소드, LED6 애노드 → VCC(+5V)
  - pin 9  → `Y7` → 330Ω → LED7 캐소드, LED7 애노드 → VCC(+5V)   ※ pin 8 아님
  - pin 10 → `Y8` → 330Ω → LED8 캐소드, LED8 애노드 → VCC(+5V)
  - pin 11 → `Y9` → 330Ω → LED9 캐소드, LED9 애노드 → VCC(+5V)
  - 미사용 입력핀 없음 (`A`~`D` 4개 전부 스위치에 물린다)
  - 미사용 출력핀 없음 (`Y0`~`Y9` 10개 전부 LED 로 나간다)

**7-segment 가 아니다.** 교안 p13 은 `Y0`~`Y9` 를 **낱개 LED 10개**로 받는다.
7-segment FND 도, `74HC47`·`74HC48` 세그먼트 드라이버도 이 주차 준비물(p2)에
없다. common anode / common cathode 를 따질 대상 자체가 없다 — 다만 LED 배선
방식은 common anode 방식과 같은 **전류 흡수(sinking)** 구조다: 애노드가 다 같이
VCC 에 붙고 IC 가 캐소드 쪽에서 전류를 빨아들인다.

**전원을 넣자마자 10개가 다 꺼져 있어도 정상일 수 있다.** BCD 아닌 입력
(십진 10~15)에서는 출력 10개가 전부 HIGH 다. 회로가 살아 있는지부터 보려면
`D C B A = 0 0 0 0` 을 먼저 넣어 `Y0` LED 가 켜지는지 확인한다.

# E5.P3 · 10진 / Excess-3 코드 인코더 (74HC04 + 74HC20 ×2)

- kind: circuit
- id: C3
- item: E5.P3
- tables: [T4]

교안 p14. 배선 위상은 p14 를 300 DPI 로 렌더해 vision 으로 추적했고,
p16~p21 여섯 장(스위치 하나씩 올렸을 때 켜지는 출력의 빨간 박스)과 **교차
확인**했다 — 여섯 장 전부 아래 배선이 만드는 값과 일치한다.

- SW0~SW5 (SPDT 6개) — 교안 라벨 `SW0 (Decimal 0)` ~ `SW5 (Decimal 5)`.
  회로도에서 위에서부터 SW5, SW4, SW3, SW2, SW1, SW0 순으로 배치돼 있다
  - 각 공통 단자 → U4 의 대응 인버터 입력
  - 각 위쪽 접점 → VCC(+5V) = 1 / 아래쪽 접점 → GND = 0
  - **한 번에 하나만 올린다.** 우선순위 회로가 아니라서 두 개를 동시에 올리면
    출력이 두 코드의 OR 가 되고 Excess-3 코드가 아닌 값이 나온다
- U4 = `74HC04` (hex inverter, DIP-14) — E5.P1 의 U1 과 **같은 물리 칩**
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← SW5 공통 → pin 2  → `S5'` 노드
  - pin 3  ← SW4 공통 → pin 4  → `S4'` 노드
  - pin 5  ← SW3 공통 → pin 6  → `S3'` 노드
  - pin 9  ← SW2 공통 → pin 8  → `S2'` 노드
  - pin 11 ← SW1 공통 → pin 10 → `S1'` 노드
  - pin 13 ← SW0 공통 → pin 12 → `S0'` 노드
  - 미사용 핀 없음 (인버터 6개 전부 사용)
- U5 = `74HC20` #1 (dual 4-input NAND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - **게이트 A → `Bit3`**
    - pin 1  ← `S5'`
    - pin 2  → **VCC(+5V)**          ※ 남는 입력. GND 로 내리면 Bit3 이 항상 1
    - pin 4  → **VCC(+5V)**          ※ 남는 입력
    - pin 5  → **VCC(+5V)**          ※ 남는 입력
    - pin 6  → 330Ω → Bit3 LED 애노드, 캐소드 → GND
  - **게이트 B → `Bit2`**
    - pin 9  ← `S4'`
    - pin 10 ← `S3'`
    - pin 12 ← `S2'`
    - pin 13 ← `S1'`
    - pin 8  → 330Ω → Bit2 LED 애노드, 캐소드 → GND
  - **pin 3, pin 11 = NC → 개방** (GND 도 VCC 도 물리지 않는다)
- U6 = `74HC20` #2 (dual 4-input NAND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - **게이트 A → `Bit1`**
    - pin 1  ← `S4'`
    - pin 2  ← `S3'`
    - pin 4  ← `S0'`
    - pin 5  → **VCC(+5V)**          ※ 남는 입력
    - pin 6  → 330Ω → Bit1 LED 애노드, 캐소드 → GND
  - **게이트 B → `Bit0`**
    - pin 9  ← `S4'`
    - pin 10 ← `S2'`
    - pin 12 ← `S0'`
    - pin 13 → **VCC(+5V)**          ※ 남는 입력
    - pin 8  → 330Ω → Bit0 LED 애노드, 캐소드 → GND
  - **pin 3, pin 11 = NC → 개방**

노드 팬아웃 (한 인버터 출력이 여러 NAND 로 갈라진다):

| 노드 | 가는 곳 | 만드는 항 |
|---|---|---|
| `S5'` | U5.pin1 | `Bit3` |
| `S4'` | U5.pin9, U6.pin1, U6.pin9 | `Bit2`, `Bit1`, `Bit0` |
| `S3'` | U5.pin10, U6.pin2 | `Bit2`, `Bit1` |
| `S2'` | U5.pin12, U6.pin10 | `Bit2`, `Bit0` |
| `S1'` | U5.pin13 | `Bit2` |
| `S0'` | U6.pin4, U6.pin12 | `Bit1`, `Bit0` |

**왜 NAND 가 OR 가 되나:** `NAND(S_a', S_b', S_c', S_d') = S_a + S_b + S_c + S_d`
다. 인버터가 이미 반전을 해 두었으므로 NAND 한 단이 곧 OR 다. 그래서 남는
입력을 **VCC(=1)** 로 올려야 한다 — 1 은 반전하면 0 이고, OR 의 항등원이다.
GND 로 내리면 NAND 출력이 영구히 1 이 되어 그 비트 LED 가 계속 켜진다.

**자체 검산 (교안 p15 대조):** `SW0` 만 올리면 `0011`, `SW5` 만 올리면 `1000` 이
나와야 한다. Excess-3 는 BCD + 3 이므로 십진 0 이 `0011` 이고 십진 5 가 `1000`
이다. `SW0` 에서 `0000` 이 나오면 `S0'` 이 어디에도 안 물렸거나 `74HC20` 의
남는 입력을 GND 로 내린 것이다.

# E5.P4 · 8X3 Priority Encoder (74HC148)

- kind: circuit
- id: C4
- item: E5.P4
- tables: [T6]
- refs: [T5]

교안 p22. **DIP-16 이고, 입력도 출력도 active-low 이고, LED 가 뒤집혀 있다.**

교안 회로도에는 `IN0`·`IN7` 두 개의 스위치만 그려져 있지만, 슬라이드 하단에
*"★ IN1~IN6도 IN0과 IN7과 같이 연결하여야 함"* 이라고 적혀 있다 → **스위치 8개
전부 단다.**

- SW0~SW7 (SPDT 8개) — **이 이름은 이 문서가 붙인 것**이다. 교안 p22 회로도는
  스위치를 `IN0`·`IN7` 두 개만 그리고 이름을 붙이지 않았다
  - 각 공통 단자 → U7 의 대응 `IN` 핀
  - 각 위쪽 접점 → VCC(+5V) = **1 = 비활성** / 아래쪽 접점 → GND = **0 = 활성**
  - **active-low 라 "누른다 = 0" 이다.** 위로 올린 스위치가 눌리지 않은 것이다
- U7 = `74HC148` (8-to-3 priority encoder, **DIP-16**)
  - **pin 16 → VCC(+5V)**            ※ pin 14 가 아니다 — pin 14 는 `GS` 출력이다 (M1)
  - **pin 8  → GND**                 ※ pin 7 이 아니다 — pin 7 은 `A1` 출력이다 (M1)
  - **pin 5  → GND**                 ※ `EI` (Active Low). 아래 경고를 볼 것
  - pin 10 ← SW0 공통 (`IN0` (Active Low), 우선순위 최하)
  - pin 11 ← SW1 공통 (`IN1`)
  - pin 12 ← SW2 공통 (`IN2`)
  - pin 13 ← SW3 공통 (`IN3`)
  - pin 1  ← SW4 공통 (`IN4`)
  - pin 2  ← SW5 공통 (`IN5`)
  - pin 3  ← SW6 공통 (`IN6`)
  - pin 4  ← SW7 공통 (`IN7`, 우선순위 최상)
  - pin 9  → `A0` (Active Low) → 330Ω → LED_A0 캐소드, 애노드 → VCC(+5V)
  - pin 7  → `A1` → 330Ω → LED_A1 캐소드, 애노드 → VCC(+5V)
  - pin 6  → `A2` → 330Ω → LED_A2 캐소드, 애노드 → VCC(+5V)
  - pin 14 → `GS` (Active Low) → 330Ω → LED_GS 캐소드, 애노드 → VCC(+5V)
  - pin 15 → `EO` (Active Low) → 330Ω → LED_EO 캐소드, 애노드 → VCC(+5V)
  - 미사용 입력핀 없음 (`IN0`~`IN7` 8개 + `EI` 전부 결선)
  - 미사용 출력핀 없음 (`A0`·`A1`·`A2`·`GS`·`EO` 5개 전부 LED 로 나간다)

## `EI` 를 띄우면 칩이 통째로 죽은 것처럼 보인다 — 이 주의 3순위 사고

`EI` (pin 5) 는 active-low 인에이블이다. **GND 에 물려야 칩이 동작한다.**

- 띄워 두면 CMOS 입력이 부정 전위라 동작이 **불확정**해진다. HIGH 쪽으로 뜨면
  칩이 비활성돼 `A2 A1 A0` = 111, `GS` = 1, `EO` = 1 로 **다섯 개 출력이 전부
  HIGH** 가 되고, LED 가 캐소드 쪽에 붙어 있으니 **다섯 개가 전부 꺼진다.**
  더 나쁜 경우는 문턱 근처에서 떨려 결과가 눌렀다 안 눌렀다 하는 것이다.
- 즉 "전원이 안 들어온 것"과 "인에이블이 안 걸린 것"이 눈으로 **똑같이 보인다.**
  스위치를 아무리 내려도 반응이 없으면 IC 를 의심하기 전에 pin 5 를 먼저 짚는다.
- 살아 있는지 판별하는 법: `EI` 가 제대로 GND 면 **아무 스위치도 안 내려도
  `EO` LED 하나는 켜져 있다** (`EO` = 0). 이 LED 가 이 회로의 전원 표시등인
  셈이다. 단 이 판별법은 아래 **M2**(표준 규약으로 적은 T6)에 기대고 있다

이것이 2주차 netlist 가 `74HC02` 의 핀 순서를 따로 경고한 것과 같은 급의
지점이다 — 회로는 멀쩡한데 결과가 전부 죽어 보이는 종류의 실수다.

## 우선순위 확인 절차 (교안 지시)

교안 p22 는 *"입력을 이론에서처럼 하나씩 넣지 않고 다양하게 넣을 것"* 이라고
한다. `IN3` 과 `IN7` 을 동시에 GND 로 내려 보고, 출력이 **7 쪽**
(`A2 A1 A0` = `000`) 으로 나오는지 확인한다. 3 쪽(`100`)이 나오면 우선순위
방향을 반대로 배선한 것이다 — `IN` 번호와 핀 번호가 **연속이 아니라는 점**
(`IN3`=13 다음이 `IN4`=1) 이 그 실수를 부른다.

`GS` 와 `EO` 는 반드시 같이 본다: `GS` = 0 은 "칩 켜짐 + 활성 입력 있음"(출력
유효), `EO` = 0 은 "칩 켜짐 + 활성 입력 없음". 둘 다 1 이면 칩이 꺼진 것이다.

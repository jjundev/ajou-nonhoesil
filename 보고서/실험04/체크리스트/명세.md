교안은 2026-2 배포본 `강의노트/실험4. Multiplexer & Demultiplexer.pdf`(14쪽)이다.
표지 머리글은 `25-1 논리회로실험` 이라 적혀 있다 — 배포본 파일이 지난 학기
슬라이드를 그대로 쓴 것으로 보이나, 이 명세는 그 파일 내용을 그대로 옮긴다(결선도
미확정 표). 과거 학기 아카이브 판(`from_the_past/정리/강의노트/실험4.pdf`)은 열지
않았다. 표 속성(`kind`·`encoding`·`source`·`role`·`outputs`)과 항목 필드의 뜻은
`docs/schema/lab-spec-v2.md` 가 정한다 — 이 문서는 그 계약의 인스턴스다.

교안 항목은 넷(실험 1-1 MUX 회로 구현·1-2 MUX IC 활용·2-1 DMUX 회로 구현·2-2 DMUX IC
활용)이지만 조교 공지 `_350547_1`(2026-09-14)로 이번 학기에는 실험 1-1·2-1 만 한다
(`config.EXPERIMENT_SCOPE`). IC 활용 두 항목(`74HC153`·`74HC139`)은 이 명세에 싣지
않는다. 항목 id 는 교안 번호 그대로다.

교안 본문과 진리표는 `pypdf` 로 한글까지 읽힌다. `pdftotext -layout` 은 이 파일의
한글을 전부 떨어뜨리고(실험3 배포본과 같은 증상), p9 진리표의 `E` 열을 다른 열
사이로 흩뜨린다 — 표 셀은 `pypdf` 추출과 150dpi 렌더 vision 판독이 셀 단위로
일치한 값을 옮겼다. 진리표 머리의 `S1`·`D0`·`Y0` 은 교안에서 아래첨자 글리프
(S₁·D₀·Y₀)이고 텍스트 추출은 `S1`·`D0`·`Y0` 을 낸다 — 텍스트 쪽 표기를 쓴다.
**회로도 두 장(p8·p11)은 래스터라** 텍스트로는 신호 이름(`E`·`S1`·`D0 (= I0)`·`Y`
등)만 나오고 게이트 기호·핀 번호·배선은 0 자다 — 교안에 박힌 원본 이미지
(2007×1159·1523×1029 px)를 뽑아 확대해 vision 으로만 읽었다. 이 명세의 "회로도"
서술은 전부 그 판독이다.

교안은 항목마다 진리표를 **직접** 준다(p9·p12). 그래서 항목마다 표가 둘이다 —
실험실에서 LED 로 채우는 기록표(`derived`, `0/1`)와, 교안 `Truth Table` 을 원문
그대로 옮긴 참조표(`manual:pN`, `role: reference`). 기록표의 `derived` 식은
회로도에서 읽은 게이트 논리라 역검산기가 표와 회로를 서로 검산하고, 참조표는
교안 쪽 번호를 `source` 로 지닌다. 두 표는 **첫 행 출력 칸 하나만 다르다** — 아래
토큰 표의 `X` 행. 교안 진리표가 `0/1` 표기라 이 명세에는 `H/L` 표가 없다.

실험 이론의 두 `Truth Table`(p4 MUX `S1 S0 Y` 에 셀 `I0`~`I3`, p6 DMUX
`S1 S0 D0 D1 D2 D3` 에 셀 `I`)은 싣지 않는다. Enable 이 없는 기능표이고, p6 은 같은
글자 `D0`~`D3` 을 **출력**으로 쓰는데 실험 1-1 표는 그 글자를 **입력**으로 쓴다 —
참조표로 얹으면 열 이름 하나가 표마다 뜻이 갈린다. 두 항목 표가 그 기능표에 Enable
열을 더한 것이라는 대응은 아래 항목 산문에 교안 문장으로 남긴다. 이 판단은 교안
원문이 아니다.

준비물(p7)은 `5V 전압원` · IC `74HC04, 74HC11(2개), 74HC20(3개), 74HC139, 74HC153` ·
`발광 다이오드 (4개)` · `저항 330Ω (4개)` 다. 교안 실험 방법 쪽(p8·p11)은 "주어진 회로를
구성하고" 관찰하라고만 하고 **LED 를 어디에 다는지 말하지 않는다** — 회로도에도 LED 가
없다. 출력마다 LED 하나와 330Ω 하나를 다는 것은 준비물 수량(4개)이 실험 2-1 의 출력
넷(`Y0`~`Y3`)과 맞는 데서 따른 것이고 교안 원문이 아니다(결선도 미확정 표). 회로도의
입력은 전부 SPDT 스위치(1번 → +5V, 3번 → GND, 2번 → 게이트)인데 스위치는 준비물에
없다(결선도 미확정 표).

# E4.P1-1 · 실험 1-1) Enable을 갖는 4x1 MUX - 회로 구현

교안 p8(회로도)·p9(진리표). 교안 원문: "주어진 회로를 구성하고, 입력/선택신호 변화에
따른 Y의 변화를 관찰한다." 이론(p4)은 MUX 를 "2ⁿ개의 입력, n개의 선택 신호, 1개의
출력으로 구성" 이라 하고 `Y = S1'·S0'·I0 + S1'·S0·I1 + S1·S0'·I2 + S1·S0·I3` 을 준다
(교안의 오버바 표기를 `'` 로 옮겼다). 회로도는 그 식에 Enable 을 곱한 것을 NAND-NAND
두 단으로 짓는다. 회로도(vision, 교안 라벨 그대로):

- `E` → `74HC04` U4A(pin 1 → 2) → `E'` ; `S1` → U4B(pin 3 → 4) → `S1'` ;
  `S0` → U4C(pin 5 → 6) → `S0'`
- `S0'`, `S1'`, `E'`, `D0` → `74HC20` U1A(pin 1·2·4·5 → 6)
- `S0`, `S1'`, `E'`, `D1` → `74HC20` U1B(pin 9·10·12·13 → 8)
- `S0'`, `S1`, `E'`, `D2` → `74HC20` U2A(pin 1·2·4·5 → 6)
- `S0`, `S1`, `E'`, `D3` → `74HC20` U2B(pin 9·10·12·13 → 8)
- 네 NAND 출력 → `74HC20` U3A(pin 1·2·4·5 → 6) → `Y`

`74HC20`(4입력 NAND 둘이 든 패키지)이 회로도에 U1·U2·U3 **세 패키지**로 나온다 —
U3 은 게이트 A 하나만 쓴다. 준비물의 `74HC20(3개)` 와 같다. `ics` 는 패키지 이름
목록이라 `74HC20` 한 번만 적는다(수량은 이 산문이 말한다). `74HC04` 는 인버터 셋을
한 패키지에서 뽑는다. 핀 번호는 교안 회로도가 게이트마다 적어 둔 것이다(`74HC20`
의 pin 3·11 은 회로도에 없다 — 데이터시트상 미연결이다, 결선도 `# 핀아웃 출처`).
관측점은 `Y` 하나다.

부울식 `Y = E'·(S1'·S0'·D0 + S1'·S0·D1 + S1·S0'·D2 + S1·S0·D3)` 은 회로도에서 읽은
것이다(드모르간으로 NAND-NAND 를 AND-OR 로 폈다). 아래 T2(교안 원문) 9행 중 입력에
`X` 가 없는 8행과 전부 일치한다. 교안 표는 선택 조합마다 **선택된 데이터 입력만
0·1 로 바꾸고 나머지 셋은 그 반대 값으로** 둔 두 행씩이다 — 선택되지 않은 입력이
`Y` 에 새어 나오지 않는지를 함께 보는 배치다(이 해석은 교안 원문이 아니다).

# E4.P2-1 · 실험 2-1) Enable을 갖는 1x4 DMUX - 회로 구현

교안 p11(회로도)·p12(진리표). 교안 원문: "주어진 회로를 구성하고, 선택신호 변화에
따른 Y0-Y3의 변화를 관찰한다." 이론(p6)은 DMUX 를 "1개의 입력, n개의 선택 신호,
2ⁿ개의 출력으로 구성" 이라 하고 `D0 = S1'·S0'·I` ~ `D3 = S1·S0·I` 를 준다. 실험 쪽은
그 입력 `I` 를 `D` 로, 출력 `D0`~`D3` 을 `Y0`~`Y3` 으로 부르고, `D` 가 Enable 을
겸한다(p11 "D: Enable & Data Input"). 회로도(vision, 교안 라벨 그대로):

- `S0` → `74HC04` U3A(pin 1 → 2) → `S0'` ; `S1` → U3B(pin 3 → 4) → `S1'`
- `S1'`, `S0'`, `D` → `74HC11` U1A(pin 1·2·13 → 12) → `Y0`
- `S0`, `S1'`, `D` → `74HC11` U1B(pin 3·4·5 → 6) → `Y1`
- `S1`, `S0'`, `D` → `74HC11` U1C(pin 9·10·11 → 8) → `Y2`
- `S0`, `S1`, `D` → `74HC11` U2A(pin 1·2·13 → 12) → `Y3`

`74HC11`(3입력 AND 셋이 든 패키지)이 회로도에 U1·U2 **두 패키지**로 나온다 — U2 는
게이트 A 하나만 쓴다. 준비물의 `74HC11(2개)` 와 같다. `ics` 는 이름 목록이라
`74HC11` 한 번만 적는다. 회로도는 `74HC04` 를 U3 으로 그리고 인버터 둘을 뽑는다.
결선도는 실험 1-1 의 신호선을 전부 뽑은 뒤 같은 `74HC04` 패키지를 이 핀대로 다시
배선한다 — 준비물에 `74HC04` 수량 표기가 없어 한 패키지로 본 것이고 교안 원문이 아니다
(결선도 미확정 표). 교안 두 회로도의
U 번호는 서로 독립이다(실험 1-1 의 U1 은 `74HC20`, 실험 2-1 의 U1 은 `74HC11`) —
결선도는 이 둘을 한 번호 체계로 다시 붙인다. 관측점은 `Y0`~`Y3` 넷이다.

부울식 `Y0 = D·S1'·S0'` · `Y1 = D·S1'·S0` · `Y2 = D·S1·S0'` · `Y3 = D·S1·S0` 은
회로도에서 읽은 것이다. 아래 T4(교안 원문) 5행 중 입력에 `X` 가 없는 4행과 전부
일치한다.

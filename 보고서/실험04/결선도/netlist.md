# 꼭 읽을 것

- kind: must-read

- **`74HC20` 의 pin 3·11 은 미연결(n.c.)이에요** — 아무것도 꽂지 않아요
- **쓰는 게이트의 입력은 반드시 물려요** (플로팅 금지). 아직 세우지 않은 게이트의
  입력은 그 단계까지 비어 있어도 괜찮아요. 미사용 입력은 비워 두고, 미사용 출력은 아무 데도
  잇지 않아요
- 입력 `E`·`S1`·`S0`·`D0`~`D3`·`D` 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물어요.
  스위치는 없어요
- LED 는 네 개예요 — 급전 홀 우 c42·c46·c51·c57. 중간 노드는 비어 있는 LED 의 급전선을
  그 핀으로 **잠시** 옮겨 보고, 걷기 그림에서 뽑아요. **8단계 전 걷기에서는 LED2~4 사슬
  (LED·330Ω·GND 선)까지 뽑아요** — C1 완성은 Y LED 하나고, C2 1단계에서 다시 꽂아요
- **C2(DMUX)는 C1 의 신호선을 전부 뽑고 새로 지어요.** 전원선·레일 브리지·LED1 사슬·
  K1 의 `74HC04` 는 남겨요

# 공통 규칙

- kind: common

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND. 전원은 준비물 p7 의 `5V 전압원`, 회로도
  p8·p11 의 `+5V`
- 세 칩(`74HC04`·`74HC20`·`74HC11`) 모두 계열 표준 전원핀(14·7)이다. 다른 전원핀을 가진
  칩은 이 주차에 없다. `74HC20` 의 pin 3·11 은 **미연결(n.c.)** 이다 — 아무것도 꽂지
  않는다(`# 핀아웃 출처`)
- 핀 번호는 **교안 회로도(p8·p11)가 게이트마다 적어 둔 번호 그대로**다. U 번호만 두
  회로도를 한 체계로 다시 붙였다(M7): `U1`·`U2`·`U3` = `74HC20`(p8 과 같다), `U4` =
  `74HC04`(p8 의 U4 이자 p11 의 U3 — 같은 물리 칩이고 회로마다 배선을 새로 한다),
  `U5`·`U6` = `74HC11`(p11 의 U1·U2)
- **완성본에서 사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지). 중간 단계에서
  아직 세우지 않은 게이트(C1 1~3단계의 U1·U2·U3, C2 1~3단계의 U6 등)의 입력은 그 게이트를
  세우는 단계까지 비어 있다 — 관측 노드의 상류가 아니므로 미사용 게이트와 같이 다룬다(M12).
  관측 노드 상류의 입력은 단계마다 전부 물려 있다. **미사용 게이트의 입력은 접지하지
  않는다** — 교안이 미사용 핀 처리를 말하지 않는 주차이고, 실험01 실측(2026-09-11)에서
  접지 생략이 결과에 영향이 없었다. 이 규칙은 교안 원문이 아니다(M12). 미사용 *출력*핀은
  개방한다 (출력끼리 묶거나 GND 로 직결하면 출력 정격을 넘는 전류가 흐를 수 있다 — 교안 원문이 아니다, M12)
- **칩을 꽂거나 뽑을 때는 전원을 끈다.** 교안 원문이 아닌 안전 절차다
- **교안 실험 1-2·2-2(IC 활용, `74HC153`·`74HC139`)는 하지 않는다** — 조교 공지
  `_350547_1`. 그래서 C1 은 맨바닥에서 시작한다
- **C2(DMUX)는 C1(MUX)의 신호선을 전부 뽑고 새로 짓는다**(M6, `rebuild: true`).
  전원선·레일 브리지·LED1 사슬과 K1 의 `74HC04` 는 남긴다(LED2~4 사슬은 C1 8걷기에서
  이미 뽑았고 C2 1단계가 다시 꽂는다). 전부 뽑으므로 놓칠 선이
  없어 걷기 그림을 두지 않는다 — 체크리스트 배너가 지시한다
- **단계 하나는 관측 노드 하나를 세운다.** 확인은 `## 단계` 표의 `확인` 칸이 가리키는
  노드 하나를 본다. 중간 노드는 **그 시점에 비어 있는 LED 의 급전선을 그 핀으로 잠시
  옮겨** 본다(M15). 임시 급전선을 **뽑는 자리마다 `<k>걷기` 행과 걷기 그림이 한 장씩**
  있다. 각 칩을 처음 쓰는 단계는 C1 1단계(74HC04)·C1 4단계(74HC20 U1)·C1 6단계
  (74HC20 U2)·C1 8단계(74HC20 U3)·C2 1단계(74HC11 U6)·C2 2단계(74HC11 U5)이고, 두 회로
  모두 마지막 단계에서 기록 진리표 전 행을 돌린다
- **이 주차의 새 신호선 예산은 5 다**(M8, 2026-09-27 결정) — 4입력 NAND 하나의 출력을
  보려면 입력 넷과 관측선 하나가 한꺼번에 있어야 한다. 예산 = 게이트 입력 수 + 1 이고
  `배치.py` 에 `STAGE_WIRE_BUDGET = 5` 와 그 이유를 둔다. 단계는 여전히 관측 노드 하나씩이다
- **칩 자리는 고정이다** (아래 `# 칩 자리표`). 그림의 **회색 선은 손대지 않는다** —
  걷을 선은 걷기 그림(빨간 점선), 새 선은 단계 그림(회색 기준선 위 번호)이 지시한다
- 입력 `E`·`S1`·`S0`·`D0`~`D3`·`D` 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접**
  물린다. 띄워두지 않는다. 교안 회로도는 입력마다 SPDT 스위치를 그리지만 스위치는
  준비물에 없다(M2)
- LED 는 **네 개**다(준비물 p7 `발광 다이오드 (4개)`·`저항 330Ω (4개)`). 네 사슬을 C1
  첫 단계에 한꺼번에 꽂는다 — 우 c42·c46·c51·c57 이 급전 홀이다. C1 의 LED2~4 는 중간
  노드를 보는 자리라 **8걷기에서 사슬째 뽑고**(C1 완성 보드 = 완성본 그림, LED1 하나),
  C2 1단계가 같은 자리에 다시 꽂는다(2026-09-29 사용자, M15).
  C1 완성본은 LED1 = `Y`, C2 완성본은 LED1~LED4 = `Y0`~`Y3` 다. 애노드 쪽에 330Ω 직렬, 캐소드 → GND.
  교안은 LED 를 어디에 다는지 말하지 않는다 — 이 배정은 교안 원문이 아니다(M3)
- 한 신호가 여러 핀으로 가면(팬아웃) **목적지 스트립에서 다음 목적지로 이어 간다**
  (예: `E'` 는 U4 pin 12 → U1 pin 4 → U1 pin 12, U4 pin 12 → U2 pin 4 → U2 pin 12). 전기적으로는
  한 노드이고, 출력 스트립 한 줄에 선이 몰리지 않게 한 배선 편의다(M11)
- 핀 줄의 `※` 뒤는 그 점의 신호 이름과 명세 표 대응을 적은 주석이다(배선 지시가
  아니다)

# 칩 자리표

- kind: layout

두 회로가 같은 자리를 쓴다 — C2 는 C1 신호선을 전부 뽑은 뒤 K2·K4 의
`74HC20` 을 `74HC11` 로 바꿔 꽂는다. 두 칩 모두 pin 14·7 전원이라 그 자리 전원선을 그대로
쓴다. 슬롯은 역할에 붙는다: 인버터(K1), 앞단 게이트 둘(K2·K3), 합류 NAND(K4). 슬롯 이름을 실험01~03 의 `S<n>` 대신 `K<n>` 으로 쓴다 — 이 주차는 선택 입력
이름이 `S1`·`S0` 이라 "S1 에 꽂는다" 가 칩 자리인지 입력인지 갈리지 않는다. `좌`·`우` 는 브레드보드 두 블록, 행은 그 블록 단자대의 행 번호(칩 pin 1 이
앉는 행)다. 열은 칩 다리 한쪽이 `a`~`e`(pin 1~7 쪽), 다른 쪽이 `f`~`j`(pin 8~14 쪽)이고 칩
다리가 `e`·`f` 에 앉는다. U4·U3(U6) 은 우 블록, U1·U2(U5) 는 좌 블록이다 — 같은 블록이면 `S0`·`S0'` 중 하나가, 또 U1·U2 출력 pin 8 이
칩 사이에서 쪽(a~d / g~j)을 바꿔 건너야 해서 렌더러 R8 에 걸린다(M10). 자리는 교안
근거가 없다(M10). pin 14·pin 7 행(7·13, 18·24, 30·36)은 전원 레일 빈 행(렌더러 `RAIL_GAP_ROWS`:
8·14·20·26·32·38·44·50·56 …)을 피한다(M10).

| 슬롯 | 자리 | 회로별 칩 |
|---|---|---|
| K1 | 우 7행 | C1 74HC04 · C2 74HC04 (U4, 인버터 — 같은 칩, 배선은 새로) |
| K2 | 좌 18행 | C1 74HC20 (U1, 앞단 NAND `D0`·`D1`) · C2 74HC11 (U5, AND `Y0`·`Y1`·`Y2`) |
| K3 | 좌 30행 | C1 74HC20 (U2, 앞단 NAND `D2`·`D3`) · C2 비움 |
| K4 | 우 30행 | C1 74HC20 (U3, 합류 NAND → `Y`) · C2 74HC11 (U6, AND `Y3`) |

# 핀아웃 출처

- kind: sources

**교안이 신호핀 번호를 직접 준다** — p8·p11 회로도가 게이트마다 핀 번호를 적어 두었다
(`74HC04` 1→2·3→4·5→6, `74HC20` 1·2·4·5→6·9·10·12·13→8, `74HC11` 1·2·13→12·3·4·5→6·
9·10·11→8). 회로도는 래스터라 원본 이미지를 확대해 vision 으로 읽었다. 교안에 없는
전원핀·미연결핀은 제조사 1차 데이터시트로 확인했고(`74HC20`·`74HC11` 은 이번에 직접 열었고
`74HC04` 는 저장소 기록 경유다 — 아래), 교안이 적은 신호핀도 전부 데이터시트와 일치한다. 가정으로 남은 핀은 없다.

- `74HC20` — Nexperia 74HC20, Dual 4-input NAND gate, Rev. 7 (2024-03-14) §5.2 Pin
  description. `https://assets.nexperia.com/documents/data-sheet/74HC20.pdf` 를 2026-09-27
  에 직접 열어 확인: `1A=1, 1B=2, n.c.=3, 1C=4, 1D=5, 1Y=6, GND=7, 2Y=8, 2A=9, 2B=10,
  n.c.=11, 2C=12, 2D=13, VCC=14`. 서지는 `.claude/데이터시트_출처.md` Nexperia 표에 있다
- `74HC11` — Nexperia 74HC11; 74HCT11, Triple 3-input AND gate, Rev. 9 (2024-02-21) §5.2
  Table 2. `https://assets.nexperia.com/documents/data-sheet/74HC_HCT11.pdf` 를 2026-09-27
  에 직접 열어 확인: `1A, 2A, 3A = 1, 3, 9` / `1B, 2B, 3B = 2, 4, 10` / `1C, 2C, 3C =
  13, 5, 11` / `1Y, 2Y, 3Y = 12, 6, 8` / GND 7 / VCC 14. 서지는 `.claude/데이터시트_출처.md` Nexperia 표에
  이 주차 저작 때 더했다
- `74HC04` — Nexperia 74HC04; 74HCT04 Rev. 10 (2024-02-16) §5.2 Table 2. 저장소 기록
  경유: `보고서/실험02/결선도/netlist.md` § 핀아웃 출처가 입력 `1, 3, 5, 9, 11, 13`,
  출력 `2, 4, 6, 8, 10, 12`, GND 7, VCC 14 로 옮겼다

교안 표기가 `74HC` 계열이므로 실물이 TI `SN74HC..` 각인이어도 핀 배치는 같다. 각인이
`74HC` 가 아닌 계열(`74LS`·`74HCT` 등)이면 전기 특성이 달라 인용할 데이터시트를
바꾼다(M14).

# C1 · 실험 1-1) Enable을 갖는 4x1 MUX - 회로 구현 (74HC04 + 74HC20 ×3)

- kind: circuit
- id: C1
- item: E4.P1-1
- tables: [T1]
- refs: [T2]
- diagram: 실험04_1-1_결선도_4x1MUX.png

교안 p8 회로도 그대로. 이 주차 첫 회로라 맨바닥에서 시작한다. 1단계에 네 칩(U4·U1·U2·
U3)의 전원과 LED 네 사슬을 한꺼번에 꽂는다(기반). **관측 단계**는 여덟이다 — 인버터
출력 셋(1~3), 앞단 NAND 출력 넷(4~7), `Y`(8) 순으로 신호가 흐르는 차례다. `Y` 가
설 때까지 LED 넷이 전부 비어 있으므로 중간 노드는 LED 로 본다: 인버터 출력은
LED4·LED3·LED2, NAND 출력은 LED1~LED4. 임시 급전선을 **뽑는 자리마다 걷기 행과 걷기
그림이 한 장씩** 있어 단계 표는 열 줄이다. 8걷기는 LED2~4 사슬도 뽑아 8단계 보드가
완성본과 같은 모양(LED1 하나)이 된다(M15). 4~8단계는 새 신호선이 다섯이다 — 이 주차 예산이 5 다(M8). E 인버터는 교안의 게이트 1 대신 게이트 6(pin 13→12)이다(M9). 네 NAND 의
입력 배정은 래스터 회로도의 vision 판독이다(M13).

# C2 · 실험 2-1) Enable을 갖는 1x4 DMUX - 회로 구현 (74HC04 + 74HC11 ×2)

- kind: circuit
- id: C2
- item: E4.P2-1
- tables: [T3]
- refs: [T4]
- rebuild: true
- diagram: 실험04_2-1_결선도_1x4DMUX.png

교안 p11 회로도 그대로, **C1 을 걷고 새로 짓는다**(M6, 2026-09-27 결정). 전원을 끄고 C1 의
신호선(입력 점퍼·칩 사이 선·LED 급전선)을 **전부** 뽑는다. 전원선·레일 브리지·LED1
사슬은 그대로 두고(LED2~4 사슬은 C1 8걷기에서 뽑았다 — 1단계가 다시 꽂는다), `74HC20` 셋을 빼고 `74HC11` 둘을 K2·K4 에 꽂는다 — 두 칩 모두 pin 14·7
전원이라 K2·K4 전원선을 그대로 쓴다. K3 의 전원선은 칩 없이 남아도 된다. `74HC04`(U4)는
K1 에 두되 **배선은 교안 p11 대로 다시 한다**(pin 1 → 2 = `S0'`, pin 3 → 4 = `S1'`). 전부
뽑으므로 걷기 그림이 없다 — 체크리스트 배너가 지시하고, 확인은 "보드에 전원선·브리지·LED1
사슬 말고 점퍼가 하나도 없다" 로 눈으로 한다.

**관측 단계**는 넷이고 AND 하나가 단계 하나다. 출력 넷이 곧 LED 넷이라 임시 급전선이
없다(걷기 행도 없다). 인버터가 필요 없는 `Y3` 부터 세우고, `S1'` 이 들어오는 `Y1`, `S0'` 이
들어오는 `Y2`, 둘 다 쓰는 `Y0` 순이다 — 앞 단계에 꽂은 입력 스트립에서 이어 가도록 짠
순서이고 교안 원문이 아니다(M11). 각 단계의 새 신호선은 넷~다섯이다(예산 5, M8).

LED1 = `Y`(C1)·`Y0`(C2), LED2~4 = `Y1`~`Y3` 배정, 330Ω 을 애노드 쪽에 두는 순서는 배선 편의다. 적색 LED 순방향 강하를 2V 로 보면 330Ω 에서 `(5−2)/330 ≈ 9.1 mA` 다(실험03 M3 과 같은 판단). 74HC 데이터시트의 VOH 는 `IO = -4.0 mA`(VCC 4.5V) 조건까지만 규정되어 있어 LED 를 구동하는 출력의 전압은 규정 밖이다 — C1 1~7단계의 임시 급전 중에는 그 출력이 NAND 입력도 함께 구동한다(Nexperia 74HC20 Rev. 7 Table 6) | 조교가 다른 관측 방법을 지시하면 그쪽으로 — 함수는 바뀌지 않는다 |
| M4 | 명세 T1·T3 첫 행(막힌 상태 `E = 1` / `D = 0`)의 출력은 `0` 으로 적었다. 교안 진리표 p9·p12 는 같은 칸에 `X` 를 적는다(명세 T2·T4 가 원문 그대로 옮겼다). `0` 은 회로도 게이트 논리(C1: `E' = 0` 이면 앞단 NAND 가 전부 1 이고 U3 이 0, C2: `D = 0` 이면 AND 가 전부 0)에서 온 것이고 교안 원문이 아니다 | 실험실에서 그 행의 나머지 입력을 몇 가지로 바꿔 LED 가 계속 꺼져 있는지 본다. 켜지면 교안이 `X` 로 둔 이유(막힌 출력의 뜻)를 조교에게 묻는다 |
| M5 | 준비물 p7 은 `74HC04` 에만 수량이 없다(`74HC11(2개)`·`74HC20(3개)` 와 달리). 한 패키지로 보고 C1·C2 가 같은 칩을 K1 에 둔 채 배선만 새로 하도록 짰다 | 실험실 키트에서 `74HC04` 수량 확인. 둘이어도 이 결선도대로 한다 |
| M6 | **C2 는 C1 의 신호선을 전부 뽑고 새로 짓는다**(2026-09-27 사용자 결정, `rebuild: true`). 교안 p11 핀 번호를 인버터까지 그대로 쓰고, C2 완성본 그림에 MUX 가 섞이지 않는다. 남기는 것(전원선·레일 브리지·LED1 사슬·K1 의 `74HC04`)과 바꾸는 칩(`74HC20` 셋 → `74HC11` 둘)은 체크리스트 배너가 말한다. 전부 뽑으므로 걷기 그림·홀 주소 목록을 두지 않는다 — 골라 뽑을 때 놓치는 사고(2026-09-18 실험03)가 전부 뽑을 때는 생기지 않는다는 판단이다 | 1단계 전에 보드에 전원선·브리지·LED1 사슬 말고 점퍼가 하나도 남지 않았는지 눈으로 본다 |

| M8 | **새 신호선 예산을 이 주차만 5 로 둔다**(2026-09-27 사용자 결정). 기본 예산 셋으로는 4입력 NAND 출력 하나를 관측할 수 없다 — 입력 넷과 관측 급전선 하나가 모두 있어야 한다(C1 4~8단계: 다섯 가닥). 3입력 AND 는 넷이다(C2). 입력 일부만 물리면 나머지가 떠서 관측 노드 상류 플로팅 금지에 걸린다. 예산 = 게이트 입력 수 + 1 (`docs/schema/lab-netlist-v2.md` 주차 예외) | `breadboard-diagram` 이 `배치.py` 에 `STAGE_WIRE_BUDGET = 5` 와 `STAGE_WIRE_BUDGET_REASON` 을 둔다 — 없으면 `StageBudget` 테스트가 4~8단계를 막는다 |
| M9 | 렌더러 R7(칩 한쪽 리드 ≤ 8)을 교안 핀 번호 그대로의 **C1 U4 a쪽(pin 1~7)이 넘는다** — 입력 셋(E·S1·S0 점퍼), 출력 셋, 갈래 둘, GND 가 몰려 9 가닥이다. 그래서 **`E` 인버터를 게이트 6(pin 13 → 12)으로 옮겼다**(2026-09-28 `breadboard-diagram`). 논리는 같고 나머지 핀 번호는 교안 그대로다. | M10 | 칩 자리·LED 사슬 자리(우 c42·c46·c51·c57)·걷기 주소는 `배치.py` 렌더 검사(R1~R8·넷)를 통과한 자리다(2026-09-28). 교안 근거가 없다.

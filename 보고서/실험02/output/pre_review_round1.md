## 사람이 확인한 것 — 어긋난 곳

코드가 못 보는 자리를 교안 p2~p12 렌더, Nexperia PDF 두 장(pypdf), 결선도 PNG 3장으로 직접 대조했다. 아래 세 곳이 어긋난다.

- [ ] **✗ 본문 58행 — "강의노트에는 핀 번호도 전압 규격도 실려 있지 않아"는 교안과 어긋나고 같은 보고서 101행과 모순이다.** 교안 p9·p12 회로도는 74HC04 14핀 전부에 번호(1~14)와 `1A`~`6Y` 라벨을 찍어 두었고, p11 도 74HC14 의 1·2·7·14 를 적는다. 101행은 그 사실을 정확히 서술한다("강의노트 회로도는 74HC04의 14핀 전부에 1A~6Y 이름과 번호를 적어 두었고"). 채점자가 두 문장을 나란히 읽으면 한쪽이 틀렸다고 본다. 전압 규격이 교안에 없다는 것은 맞으므로 "핀 번호도" 를 빼고 "전압 규격은 강의노트에 없어 데이터시트에서 옮겼다" 류로 좁혀야 한다. 이것이 이번 라운드의 유일한 수정 필수 항목이다.
- [ ] **! 본문 134행 — "규격 행은 CL 50pF 부하에서 VCC 4.5V와 6.0V 두 줄이고"** — 데이터시트 Table 7 의 CL 50pF 규격 행은 2.0V·4.5V·6.0V **세 줄**이다(pypdf 로 확인: `VCC = 2.0 V - 25 85 105 130 ns`). 58행이 "VCC 2.0V·4.5V·6.0V 세 지점에서 규정" 이라 적은 것과도 안 맞는다. 표에 2.0V 행을 싣지 않은 것 자체는 선택이지만 문장은 "이 표에 옮긴 규격 행은" 처럼 범위를 밝혀야 한다. warn 수준.
- [ ] **! 본문 40행 — "VH = VT+ - VT- 가 히스테리시스 폭이다"** — 기호 뒤 조사 띄어쓰기(③ §절대 규칙 21). `check_body_style` 은 `-` 로 끝나는 토큰을 안 잡아서 통과했다. `VT-가` 로 붙이면 마이너스와 조사가 붙어 읽기 나쁘므로 "두 문턱의 차가 히스테리시스 폭 VH다" 처럼 어순을 바꾸는 편이 낫다. warn 수준.

# 공통 규칙

- kind: common

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND. 전원은 준비물 p8 의 `5V 전압원`,
  전압은 p10·p12 의 `Vcc=5V`
- **이번 주차는 교안이 미사용 입력 처리를 명시한다** — p9 "74HC04, 74HC14에
  대해 사용하지 않는 핀의 입력 값은 Vcc 또는 GND에 연결 (Pull up/Pull down)".
  p9 그림과 p12 의 U2 가 같은 배치를 쓴다: **pin 3(2A)·pin 5(3A) → GND, pin 9(4A)·
  pin 11(5A)·pin 13(6A) → VCC.** 어느 핀을 위로·아래로 묶을지는 교안이 글로
  정하지 않았고 그림이 그렇게 그려져 있어 그대로 따른다(M6). 미사용 *출력*핀은
  개방한다(그림의 ×)
- **사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지)
- **GND 는 한 점이다.** 전원 장치 -, 함수발생기 -, CH1 -, CH2 -, IC pin 7 을 모두
  같은 GND 레일에 묶는다. 회로도(p10~p12)에 접지 기호가 여러 개 그려져 있지만
  전부 같은 GND 다
- **칩 자리는 고정이다** (아래 `# 칩 자리표`, 자리 자체는 관례다 — M9). C1→C2 는
  칩만 갈아 끼우고, C2→C3 은 U1 을 갈아 끼운 뒤 체인 점퍼를 더한다. 걷을 선은
  단계 표가 지시한다
- 핀 줄의 `※` 뒤는 그 점의 신호 이름과 명세 표 대응을 적은 주석이다(배선 지시가
  아니다)
- 계측: 오실로스코프 CH1·CH2 프로브. 실험 1-1·1-2 는 **X-Y 모드**(교안 머리글
  "X-Y 모드 설정 : Horiz > 좌측 아래 버튼"), 실험 2 는 시간축(Y-T)으로 되돌려
  두 채널 에지 사이 시간을 잰다 — 되돌린다는 지시는 교안 원문이 아니다. 교안은
  실험 2 에서 X-Y 를 말하지 않는다
- 신호원 설정은 항목마다 다르다: 실험 1 은 **사인파 Vpp 5V, offset 2.5V**(p10),
  실험 2 는 **사각파 Vpp 5V, 1MHz**(p12, offset 표기 없음 — 미확정 M2)

# 핀아웃 출처

- kind: sources

두 칩 모두 **교안 안의 핀 라벨**과 **제조사 1차 데이터시트**로 확인됐다. 가정으로
남은 핀은 없다.

- `74HC04` — 교안 p9·p12 회로도가 14 핀 전부에 `1A`~`6Y`·`VCC`·`GND` 라벨과 핀
  번호를 함께 찍어 두었다(래스터라 vision 판독). Nexperia 74HC04; 74HCT04 Rev. 10
  (2024-02-16) §5.2 Table 2 가 같은 값을 준다: 입력 `1, 3, 5, 9, 11, 13`, 출력
  `2, 4, 6, 8, 10, 12`, GND 7, VCC 14. 저장소 기록 경유로도 확인된 칩이다
  (`보고서/실험01/결선도/netlist.md` § 핀아웃 출처, 같은 개정)
- `74HC14` — 교안에는 핀 번호가 p11 회로도의 `1`·`2`·`14`·`7` 네 개만 있다.
  Nexperia 74HC14; 74HCT14 Rev. 10 (2024-02-29) §6.2 Table 2: 입력 `1, 3, 5, 9,
  11, 13`, 출력 `2, 4, 6, 8, 10, 12`, GND 7, VCC 14 — `74HC04` 와 같다. 이번
  저작에서 데이터시트 원문을 열어 확인했다(2026-09-13). 서지는
  `.claude/데이터시트_출처.md` 에 있다

데이터시트 참고값(명세 T4 와 미확정 M4·M5 의 근거):

- `74HC04` Rev. 10 Table 7 (Tamb 25 °C): `t_pd` VCC 4.5 V·C_L 50 pF typ 9 ns /
  max 17 ns; VCC 5.0 V·C_L 15 pF typ 7 ns; VCC 6.0 V·C_L 50 pF typ 7 ns / max
  14 ns. 각주 [1] "tpd is the same as tPHL and tPLH". 명세 T4 의 세 행이 이것이다
- `74HC14` Rev. 10 Table 10 (Tamb 25 °C, VCC 4.5 V): `VT+` 1.7 / 2.38 / 3.15 V,
  `VT-` 0.9 / 1.4 / 2.0 V, `VH` 0.4 / 0.98 / 1.4 V (min / typ / max). 교안이 이
  값과의 비교를 지시하지 않으므로 명세에는 싣지 않았다 — 예비보고서 이론 절
  재료다

# C1 · 실험 1-1) Inverter의 입출력 특성 확인 (74HC04)

- kind: circuit
- id: C1
- item: E2.P1-1
- tables: [T1]
- diagram: 실험02_1-1_결선도_인버터_입출력특성.png

교안 p10 회로도 그대로. 게이트 1(pin 1 → pin 2)만 쓰고 나머지 다섯 게이트의
입력은 p9 그림대로 묶는다.

- U1 = 74HC04 (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 함수발생기 + (사인파 Vpp 5V, offset 2.5V) — CH1 + 프로브도 이 점에 문다 ※ Vin
  - pin 2  → CH2 + 프로브 ※ Vout, T1 의 세로축
  - 미사용 입력핀: pin 3, 5 → GND (교안 p9 그림 — Pull down)
  - 미사용 입력핀: pin 9, 11, 13 → VCC (교안 p9 그림 — Pull up)
  - 미사용 출력핀: pin 4, 6, 8, 10, 12 → 개방
- 함수발생기 -, CH1 -, CH2 - → GND (회로도의 접지 기호 셋)

## 계측

- 오실로스코프를 X-Y 모드로 놓는다: "Horiz > 좌측 아래 버튼"(교안 p10 머리글 —
  기종은 M8). CH1(Vin) 이 가로축, CH2(Vout) 이 세로축 — 축 배정은 X-Y 모드의 통상
  정의이고 교안 원문이 아니다(M8 에서 함께 확인)
- T1 캡션에 눈금(V/div)과 전이가 보이는 Vin 구간을 적는다 — 교안 원문이 아닌
  기록 지시다(명세 T1 expected 와 같다)

교안 p12 회로도 그대로. 칩 이름은 교안대로 `U1`(체인)·`U2`(부하)다 — 교안 본문이
"U1의 4번 핀", "U1의 8번 핀" 으로 부르므로 번호를 바꾸지 않는다. `U1` 의 여섯
게이트가 전부 직렬이라 U1 에는 미사용 입력이 없고, `U2` 는 게이트 1 입력만 쓴다.
`U2` 를 "부하" 라 부르는 것은 회로도 해석이지 교안 원문이 아니다(명세 E2.P2).
두 칩이 같은 `74HC04` 지만 **패키지 두 개**다(준비물 p8 `74HC04(2개)`).

## 계측

- 두 채널 모두 커서를 Vcc 의 50%(2.5V) 에 놓고 CH1 에지 → CH2 같은 방향 에지 사이
  시간을 읽는다(교안 p7 "Vcc 의 50% 기준"). 상승·하강 각각 T3 에 적는다
- `1단 환산` 은 측정값을 단 수로 나눈 값이다. 단 수는 1 단계에서 센 점퍼로
  확정한다 — 측정값에서 거꾸로 정하지 않는다
- 비교 대상 T4 는 규격 조건(C_L 50 pF, VCC 4.5 V)의 값이다. 이 회로의 부하와
  전원이 그것과 다르므로(M5) 보고서에 조건을 나란히 적는다

| M1 | 준비물 p8 은 `5V 전압원`·`오실로스코프`·`IC` 뿐이다. 사인파·사각파를 낼 **함수발생기**, 브레드보드, 점퍼, 프로브가 목록에 없다. 함수발생기의 출력 설정(출력 임피던스 50Ω/High-Z 등)도 교안에 없다 | 실험실 장비 확인. 설정과 무관하게 CH1 로 Vin 이 Vpp 5V 인지 먼저 본다 |

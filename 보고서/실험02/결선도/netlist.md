# 공통 규칙

- kind: common

이 주차의 결선도는 **논리 배선이 아니라 계측 셋업**이다. 게이트 하나짜리 회로가
대부분이라 "어느 핀을 어디에 꽂나" 는 몇 줄로 끝나고, 실제로 실험을 망치는 것은
**프로브를 어디에 무엇을 기준으로 대는가**, **함수발생기가 무엇을 내보내는가**,
**미사용 입력핀을 어떻게 처리했는가** 셋이다. 그래서 항목마다 배선 다음에
계측 접점을 반드시 적는다.

## 전원

- 모든 IC: **pin 14 → VCC(+5V), pin 7 → GND.** `74HC04`·`74HC14` 둘 다 같다.
- 이 주차에 별도 전원 레일은 없다. 명세 프론트매터도 `{VCC: "+5V", GND: "GND"}`
  둘뿐이다.
- **함수발생기 접지 · 오실로스코프 프로브 접지 클립 · DMM 접지 · 브레드보드 GND 를
  한 점으로 묶는다.** 이 주차에서 가장 조용히 틀어지는 지점이다. X-Y 모드는 두
  채널의 전압을 **같은 기준**으로 놓고 그리는데, CH1 접지 클립을 함수발생기 쪽
  접지에, CH2 를 브레드보드 GND 에 물리면 둘 사이의 몇십 mV 차가 VTC 를 통째로
  기울이거나 평행이동시킨다. 곡선 모양이 그럴듯해서 눈치채지 못한다.

## 미사용 입력핀 — 이 주차는 "전부 GND" 가 아니다

교안 p8 원문: "74HC04N, SN74HC14의 사용하지 않는 입력 핀의 입력 값은 VCC 또는
GND에 연결한다 (Pull up/Pull down)".

**`실험01/결선도/netlist.md` 의 "미사용 입력핀은 전부 GND" 규칙을 복사해 오면
교안과 어긋난다.** 인버터는 입력이 VCC 든 GND 든 출력이 확정되므로 둘 다 정답이고,
교안 도면은 실제로 둘을 섞는다.

교안 p8 도면은 손글씨로 "실험에서 사용하는 인버터 1개"(pin 1·2 를 가리킴)라고
적혀 있다 — 즉 **이 도면이 곧 E2.P1·E2.P2·E2.P3-1·E2.P3-2 의 미사용핀 처리 지시다**
(그 네 항목 모두 인버터를 한 개만 쓴다). 도면을 vision 으로 판독한 결과:

| 핀 | 신호 | p8 도면의 처리 |
|---|---|---|
| 3 | 2A (입력) | **GND** |
| 5 | 3A (입력) | **GND** |
| 9 | 4A (입력) | **VCC** |
| 11 | 5A (입력) | **VCC** |
| 13 | 6A (입력) | **VCC** |
| 4, 6, 8, 10, 12 | 2Y·3Y·4Y·5Y·6Y (출력) | **개방** (도면에 X 표) |

- 왜 띄워 두면 안 되는가: 플로팅 입력은 CMOS 에서 0 도 1 도 아닌 중간 전압에 떠서
  NMOS·PMOS 가 동시에 도통한다. 관통전류로 칩이 데워지고 전원 레일이 흔들려
  **옆 게이트의 파형이 오염된다.** 이 주차가 재는 것이 바로 그 파형이라, 다른
  주차에서라면 "LED 가 가끔 이상하다" 로 끝날 결함이 여기서는 측정값 자체로 들어온다.
- **미사용 출력핀은 절대 GND·VCC 에 물리지 않는다.** 출력 트랜지스터가 전원을
  단락시켜 칩이 죽는다. 개방이 정답이다.
- p8 이 "VCC 또는 GND" 라고 열어 뒀지만, 실험실에서 임의로 바꾸면 사진 대조가
  안 맞는다. 위 표대로 통일한다.

## 프로브·계측 공통

- 오실로스코프는 저장소 강의노트 폴더에 함께 들어 있는
  `from_the_past/정리/강의노트/오실로스코프 메뉴얼.pdf`
  (Agilent InfiniiVision 2000 X 시리즈) 를 이 과목 장비로 본다.
- **X-Y 모드에서 CH1 이 X 축, CH2 가 Y 축이다.** 매뉴얼 p47 · p49 에 명시돼 있다
  ("XY 모드를 선택하면 ... 타임 베이스는 꺼집니다. 채널 1 진폭은 X 축에 표시되며
  채널 2 진폭은 Y 축에 표시됩니다"). 설정 경로는 `[Horiz]` → `시간 모드` → `XY`.
- 그래서 **CH1 은 반드시 `V_IN`(인버터 입력), CH2 는 `V_OUT`(인버터 출력)** 이다.
  바꿔 꽂으면 VTC 가 90도 돌아간 그림이 되어 "출력 전압 대 입력 전압" 이 아니라
  그 역함수를 보게 된다. 곡선이 여전히 그럴듯해 보이기 때문에 알아차리기 어렵다.
- 교안이 프로브 감쇠비(1:1 / 10:1)를 지정하지 않는다. E2.P4 에서는 프로브 용량이
  지연에 직접 들어가므로(74HC04 데이터시트 p13: `C_L = Load capacitance including
  jig and probe capacitance`) 10:1 쪽이 유리하지만, 교안 지시가 아니다.
- (교안에 없는 파생 권고) 각 IC 의 pin 14–pin 7 사이에 0.1μF 세라믹 바이패스
  커패시터를 칩 가까이 붙이면 E2.P4 의 1MHz 스위칭 노이즈가 줄어든다. 교안 준비물에
  없는 부품이므로 필수로 적지 않는다.

# 핀아웃 출처

- kind: sources

**두 칩 다 제조사 1차 데이터시트로 확인됐다** (2026-09-07). 서지는
`.claude/데이터시트_출처.md` 에 있다.

- **`74HC04` — Nexperia Rev. 10 (2024-02-16) §5.2.** 교안 p8·p13 회로도의 핀
  라벨(`1A/1Y/2A/2Y/…`)과 일치한다 — 이중 확인.
- **`74HC14` — Nexperia Rev. 10 (2024-02-29) §6.2 Pin description:**
  `1A~6A = 1,3,5,9,11,13` / `1Y~6Y = 2,4,6,8,10,12` / GND 7 / VCC 14.
  **74HC04 와 완전히 같은 배치임이 확인됐다** — 교안이 `pin 1`·`pin 2`·`pin 14`·
  `pin 7` 네 개만 라벨해서 나머지 5개 게이트를 가정했던 자리다(이전 미확정 M1).
  가정값과 일치했다.
- **`74HC14` 의 문턱전압이 같은 데이터시트 §9 Static characteristics 에 있다**
  (`VCC = 4.5 V`, `Tamb = -40~+85 °C` 기준):

  | 기호 | 뜻 | min | typ | max |
  |---|---|---|---|---|
  | `VT+` | positive-going threshold | 1.2 | 1.41 | 1.9 V |
  | `VT-` | negative-going threshold | 0.5 | 0.85 | 1.2 V |
  | `VH` | hysteresis voltage | 0.4 | 0.56 | — V |

  이전 미확정 M2 가 "교안에도 저장소에도 값이 없다"였던 자리다. **실측값을
  이 규격 범위와 대조할 수 있다** — 범위 밖이면 배선·프로브·전원을 먼저 본다.
  단 실험실 `VCC` 가 5.0 V 면 규격 조건(4.5 V)보다 높아 문턱이 조금 위로 밀린다.
- 회로 연결(어느 핀이 어디로 가는가)은 교안 **p8·p9·p10·p11·p12·p13** 회로도를
  400~900 dpi 로 렌더해 vision 으로 읽었다. 특히 p13 은 접합점(자홍색 점)과
  단순 교차를 900 dpi 에서 구분해 확정했다 — `pin 1` 로 가는 함수발생기 배선과
  `pin 6 → pin 13` 세로 배선이 교차하지만 **접합점이 없어 연결되지 않는다.**
- 아래 어느 항목도 "표준 74 시리즈 관례" 같은 약한 근거만으로 적지 않았다.
  확인되지 않은 것은 전부 `미확정 사항` 표로 내렸다.

# E2.P1 · Inverter 의 입출력 특성 확인 (교안 p9)

- U1 = `74HC04` (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 함수발생기 출력 (= `VIN` 노드)
  - pin 2  → `VOUT` 노드 (부하 없음. 프로브만 문다)
  - 미사용 입력핀: pin 3, 5 → GND / pin 9, 11, 13 → VCC (교안 p8 도면대로)
  - 미사용 출력핀: pin 4, 6, 8, 10, 12 → 개방

## 함수발생기가 내보내는 것

| 항목 | 값 | 출처 |
|---|---|---|
| 파형 | 사인파 | 교안 p9 |
| 진폭 | `Vpp 5V` | 교안 p9 |
| 오프셋 | `Voffset 2.5V` (→ 0V ~ +5V 스윙) | 교안 p9 |
| 주파수 | **교안에 없음** | → `M3` |
| 접지 | 공통 GND | |

오프셋 2.5V 가 필수인 이유: 오프셋을 0 으로 두면 `-2.5V ~ +2.5V` 가 되어 입력이
`-0.5V` 아래로 내려간다. 74HC04 데이터시트 p5 `LIMITING VALUES` 는 `V_I < -0.5V`
에서 입력 보호 다이오드에 전류(`I_IK`, 절대최대 ±20mA)가 흐른다고 규정한다.
함수발생기가 전류를 제한하지 않으면 입력단이 상한다.

## 계측 — 어디에 대는가

| 채널 | 프로브 팁 | 접지 클립 | 역할 |
|---|---|---|---|
| CH1 | **U1 pin 1** (= 함수발생기 출력 노드) | 공통 GND | X 축 = `V_IN` |
| CH2 | **U1 pin 2** | 공통 GND | Y 축 = `V_OUT` |

- 오실로스코프: `[Horiz]` → `시간 모드` → `XY` (매뉴얼 p46~p47).
- CH1/CH2 를 바꿔 물면 곡선이 90도 돌아간다. **X 축이 입력**이라는 것을 화면에서
  확인하는 방법: 함수발생기 오프셋을 잠깐 올렸다 내리면 곡선이 **좌우로** 움직여야
  한다. 위아래로 움직이면 채널이 바뀐 것이다.
- 프로브를 pin 1 이 아니라 함수발생기 단자에서 직접 따도 되지만, 그러면 브레드보드
  접촉 불량이 화면에 안 나타난다. **pin 1 에 직접 무는 편이 안전하다.**

**E2.P1 과 배선이 글자 그대로 같고 칩만 바뀐다.** 통제 실험이므로 함수발생기
설정·프로브 위치·미사용핀 처리를 하나도 바꾸지 않는다 — 바꾸면 그림 차이가 칩
때문인지 설정 때문인지 갈리지 않는다.

- U1 = `74HC14` (Schmitt-trigger hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 함수발생기 출력 (= `VIN` 노드)
  - pin 2  → `VOUT` 노드
  - 미사용 입력핀: pin 3, 5 → GND / pin 9, 11, 13 → VCC
  - 미사용 출력핀: pin 4, 6, 8, 10, 12 → 개방
  - ※ 열네 핀 전부 Nexperia 74HC14 Rev. 10 §6.2 로 확인됐다 — 74HC04 와 같은

함수발생기 설정·계측 접점은 E2.P1 과 동일하다 (사인파 `Vpp 5V`, `Voffset 2.5V`,

**칩을 바꿔 꽂을 때 전원을 내린다.** 전원이 살아 있는 상태로 DIP 를 뽑으면 핀이
순서대로 빠지면서 입력에만 전원이 걸린 순간이 생긴다.

# E2.P3-1 · CMOS 의 DC 특성 확인 — Rn (교안 p11)

- kind: circuit
- id: C3
- item: E2.P3-1
- tables: [T4]
- diagram: 실험02_결선도_DC특성_Rn.png

- U1 = `74HC04` (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - **pin 1  → VCC(+5V) 직결** (입력 HIGH → 출력 LOW 고정)
  - pin 2  → `R1` 의 한쪽
  - 미사용 입력핀: pin 3, 5 → GND / pin 9, 11, 13 → VCC
  - 미사용 출력핀: pin 4, 6, 8, 10, 12 → 개방
- `R1` = **1kΩ**. 한쪽 → **VCC(+5V)**, 다른 쪽 → **U1 pin 2**

부하 저항의 **위치가 이 항목의 전부**다. `R1` 이 VCC 와 출력 사이에 있으므로
전류가 VCC → R1 → pin 2 → (도통한 NMOS) → GND 로 흐른다. 출력이 전류를 빨아들이는
**sinking** 상태이고, 그때 NMOS 도통 저항에 걸리는 전압이 `V_OL` 이다.

- **`pin 1` 을 VCC 에 직결하는 것은 정상이다** — CMOS 입력은 전류를 거의 안 먹는다.
  저항을 끼울 필요가 없다.
- **`pin 2`(출력)를 VCC 에 직결하면 안 된다.** 반드시 `R1` 을 거친다. 직결하면
  도통한 NMOS 를 통해 VCC 가 GND 로 단락된다.
- `1kΩ` 을 고른 이유(해석): `(5V - V_OL)/1kΩ` 이 약 4.7mA 로 데이터시트가 `V_OL` 을
  규정하는 시험 조건 `I_O = 4.0mA` 와 거의 같은 동작점이라, 명세 `T8` 값과 곧바로
  비교된다.

## 계측 — 어디에 대는가

| 계측 | DMM(+) | DMM(-) | 모드 | 무엇을 |
|---|---|---|---|---|
| S1 | R1 한쪽 | R1 다른 쪽 | 저항(Ω) | **회로에 꽂기 전** R1 실저항 |
| S2 | U1 pin 2 | 공통 GND | DCV | `V_out` (= `V_OL`) |
| S3 | VCC 레일 | U1 pin 2 | DCV | R1 양단 전압 → `I_OL` 계산용 |

- **전류계를 쓸 거라면 반드시 직렬로** — VCC 와 R1 사이(또는 R1 과 pin 2 사이)를
  끊고 그 자리에 넣는다. 저항이나 전원에 **병렬로 대면 전류계가 VCC 를 단락시켜
  퓨즈가 나간다.** 교안 도면에는 전류계 기호가 없고 `IOL` 화살표만 있어서, 위 표는
  전압을 재서 나누는 방식을 기본으로 적었다 → `M7`.
- `S1` 을 회로 연결 전에 재는 이유: 회로에 꽂은 채로 저항을 재면 IC 를 통한
  우회 경로가 병렬로 붙어 값이 틀린다. 그리고 ±5% 오차가 `Rn` 에 그대로 들어간다.

# E2.P3-2 · CMOS 의 DC 특성 확인 — Rp (교안 p12)

- kind: circuit
- id: C4
- item: E2.P3-2
- tables: [T5]
- diagram: 실험02_결선도_DC특성_Rp.png

E2.P3-1 을 위아래로 뒤집는다. **바뀌는 것은 두 곳뿐이다.**

- U1 = `74HC04` (hex inverter, DIP-14) — E2.P3-1 과 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - **pin 1  → GND 직결** (입력 LOW → 출력 HIGH 고정) ← E2.P3-1 에서 VCC 였던 곳
  - pin 2  → `R1` 의 한쪽
  - 미사용 입력핀: pin 3, 5 → GND / pin 9, 11, 13 → VCC
  - 미사용 출력핀: pin 4, 6, 8, 10, 12 → 개방
- `R1` = **1kΩ**. 한쪽 → **U1 pin 2**, 다른 쪽 → **GND** ← E2.P3-1 에서 VCC 였던 곳

전류가 VCC → (도통한 PMOS) → pin 2 → R1 → GND 로 흐른다. 출력이 전류를 내보내는
**sourcing** 상태이고, PMOS 도통 저항에서 잃은 전압만큼 `V_OH` 가 VCC 보다 낮아진다.

**두 항목을 다 해야 하는 이유:** CMOS 는 위아래가 대칭이 아니어서 보통 `Rp > Rn`
이고, 그것이 상승 천이가 하강 천이보다 느린 원인이다(교안 p5 의
`t_r = 2.2 Rp C_L`, `t_f = 2.2 Rn C_L`). E2.P4 에서 재는 지연의 비대칭이 여기서 잰
두 저항의 비대칭이다.

## 계측 — 어디에 대는가

| 계측 | DMM(+) | DMM(-) | 모드 | 무엇을 |
|---|---|---|---|---|
| S1 | R1 한쪽 | R1 다른 쪽 | 저항(Ω) | **회로에 꽂기 전** R1 실저항 |
| S2 | U1 pin 2 | 공통 GND | DCV | `V_out` (= `V_OH`). R1 양단 전압이기도 하다 |
| S3 | VCC 레일 | 공통 GND | DCV | VCC 실측 — `Rp` 의 분자가 `VCC - V_OH` 라 필수 |

`R1` 이 pin 2 와 GND 사이에 있으므로 **R1 양단 전압 = `V_out` 이다.** 따라서
`I_OH = V_out / R1` 이고 DMM 접점이 E2.P3-1 보다 하나 줄어든다. 대신 `VCC` 실측
(`S3`)이 새로 필요하다 — 분자가 두 큰 수의 차라 공칭 5.00V 를 쓰면 오차가 크다.

# E2.P4 · CMOS 의 AC 특성 확인 — tpd (교안 p13~p14)

- kind: circuit
- id: C5
- item: E2.P4
- tables: [T6, T7]
- refs: [T8]
- diagram: 실험02_결선도_전파지연_tpd.png

## 소자 배치

| 지정자 | 소자 | 역할 |
|---|---|---|
| U1 | `74HC04` #1 | 인버터 **6개 전부**를 직렬로 이은 지연 체인 |
| U2 | `74HC04` #2 | U1 최종단(pin 8)에 게이트 입력 부하 1개를 더하는 용도 |

`74HC04` 가 **두 패키지 필요하다.** E2.P1~E2.P3 에서 쓰던 칩 하나로는 안 된다.

## U1 = `74HC04` #1 — 지연 체인

**핀 번호 순서로 흐르지 않는다.** `pin 6` 에서 `pin 13` 으로 건너뛴 뒤 번호를
거슬러 내려온다. 교안 p13 회로도를 900dpi 로 렌더해 확정했다.

| 단 | 게이트 | 입력핀 | 출력핀 | 출력이 가는 곳 |
|---|---|---|---|---|
| 1 | 1A/1Y | **1** ← 함수발생기 | 2 | → U1 pin 3 |
| 2 | 2A/2Y | 3 | **4** | → U1 pin 5, **그리고 CH1 프로브** |
| 3 | 3A/3Y | 5 | 6 | → **U1 pin 13** (여기서 건너뛴다) |
| 4 | 6A/6Y | 13 | 12 | → U1 pin 11 |
| 5 | 5A/5Y | 11 | 10 | → U1 pin 9 |
| 6 | 4A/4Y | 9 | **8** | → U2 pin 1, **그리고 CH2 프로브** |

- pin 14 → VCC(+5V), pin 7 → GND.
- **U1 에는 미사용 입력핀이 없다.** 인버터 6개를 전부 쓰므로 14핀이 모두 물린다.
  다른 항목의 미사용핀 처리 습관대로 pin 3·5 를 GND 로 내리면 **체인이 끊긴다.**
- 짧은 점퍼 4개(`2→3`, `4→5`, `12→11`, `10→9`)는 인접 핀끼리라 짧게 꽂히고,
  `6→13` 하나만 칩을 가로지르는 긴 배선이다. **이 긴 점퍼가 빠지면** 뒤 4단이
  전부 죽고 `pin 8` 이 플로팅된다 — 화면에는 CH2 가 노이즈처럼 흔들리는 모습으로
  나타나지 지연이 이상한 모습으로 나타나지 않는다.

### 왜 pin 4 와 pin 8 인가 — 단 수가 4다

교안 p14 는 `CH1` → `U1 pin 4`, `CH2` → `U1 pin 8` 이라고만 쓴다. 위 체인 표를
따라가면 그 사이에 인버터가 **4단**(3단 5→6, 4단 13→12, 5단 11→10, 6단 9→8) 있다.

**핀 번호만 보고 `1→2, 3→4, 5→6, 9→8` 이라고 짐작하면 2단으로 세게 되고,
게이트당 `t_pd` 가 정확히 2배로 나온다.** 이 주차에서 가장 비싼 실수다 —
배선이 아니라 계산에서 틀리므로 실험실에서는 아무 이상이 없어 보인다.

짝수 단이므로 두 파형은 **동상**이다. 또 4단은 상승·하강 천이를 두 번씩 거치므로
어느 에지로 재든 `Δt = 2·t_PHL + 2·t_PLH` 이고, 이 회로로는 `t_PHL` 과 `t_PLH` 를
**분리할 수 없다 — 둘의 평균만 얻는다.**

## U2 = `74HC04` #2 — 부하

교안 p13 회로도를 vision 으로 판독한 결과:

| 핀 | 연결 | 비고 |
|---|---|---|
| 14 | VCC(+5V) | |
| 7 | GND | |
| 1 (1A) | ← **U1 pin 8** | 유일하게 신호를 받는 핀 |
| 2 (1Y) | **개방** | 도면에 X 표. 이 인버터의 출력은 아무 데도 안 간다 |
| 3 (2A) | **GND** | 미사용 입력 |
| 5 (3A) | **GND** | 미사용 입력 |
| 9 (4A) | **VCC** | 미사용 입력 |
| 11 (5A) | **VCC** | 미사용 입력 |
| 13 (6A) | **VCC** | 미사용 입력 |
| 4, 6, 8, 10, 12 | **개방** | 미사용 출력 (도면에 X 표) |

**교안은 U2 의 역할을 설명하지 않는다.** 배선상 U2 는 논리에 관여하지 않고
`pin 8` 노드에 게이트 입력 부하 하나를 얹을 뿐이다. 그렇게 해야 `pin 4`(U1 pin 5 라는
게이트 입력을 밀고 있다)와 `pin 8` 의 부하 조건이 같아져 지연 비교가 공정해진다 —
이것은 도면에서 읽은 **해석**이지 교안 문면이 아니다.

`U2 pin 2` 가 개방인 것에 주의: 이 인버터는 **쓰는 인버터인데 출력이 개방**이다.
"입력이 물렸으니 출력도 어디론가 가야 한다" 는 습관으로 아무 데나 연결하면 안 된다.

## 함수발생기가 내보내는 것

| 항목 | 값 | 출처 |
|---|---|---|
| 파형 | 사각파 | 교안 p13 |
| 주파수 | `1MHz` | 교안 p13 |
| 진폭 | `5V amplitude` | 교안 p13 |
| 오프셋 | **교안에 없음** | → **`M4` (위험)** |
| 접점 | U1 pin 1, 접지는 공통 GND | 교안 p13 |

**`M4` 는 부품이 상할 수 있는 항목이라 여기서 다시 적는다.** 실험 1·2 는
`Voffset 2.5` 를 명시했지만 실험 4 는 오프셋을 말하지 않는다. 함수발생기를 기본값
(오프셋 0)으로 두면 `-2.5V ~ +2.5V` 가 나가고, 입력이 `-0.5V` 아래로 내려가 74HC04
데이터시트 p5 `LIMITING VALUES` 의 입력 보호 다이오드 전류 조건(`I_IK`, 절대최대
±20mA)에 걸린다. **0V ~ +5V 로 나오도록 오프셋 +2.5V 를 걸고, 출력을 켜기 전에
오실로스코프로 파형을 먼저 확인한다.**

## 계측 — 어디에 대는가

| 채널 | 프로브 팁 | 접지 클립 | 무엇을 |
|---|---|---|---|
| CH1 | **U1 pin 4** (2단 출력) | 공통 GND | 기준 파형 |
| CH2 | **U1 pin 8** (6단 출력) | 공통 GND | 4단 뒤 파형 |

- 시간축은 `ns/div` 대까지 내린다. 데이터시트 typ 로 환산하면 `Δt` 가
  `4 x 9ns = 약 36ns` 수준이라, `μs`·`ms` 대에서는 두 파형이 완전히 겹쳐
  **지연이 0 인 것처럼 보인다.** 겹쳐 보인다고 배선을 뜯기 전에 시간축부터 줄인다.
- 두 파형의 **2.5V(= VCC 의 50%) 교차점** 사이를 잰다. 기준을 50% 로 두는 것은
  교안 p7 이 지정한다.
- **두 프로브의 접지 클립을 모두 짧게, 같은 GND 점에** 문다. 클립 리드가 길면
  수십 ns 대에서 링잉이 생겨 50% 교차점을 읽을 수 없다.
- 트리거는 CH1 로 잡는다. CH2 로 잡으면 기준이 지연된 쪽이 되어 `Δt` 의 부호를
  거꾸로 읽기 쉽다.

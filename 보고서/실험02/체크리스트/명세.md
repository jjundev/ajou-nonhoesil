# E2.P1-1 · 실험 1-1) Inverter의 입출력 특성 확인

교안 p10. `74HC04` 게이트 1 개(회로도 라벨 `U1A`, pin 1 → pin 2)를 쓴다.
교안 지시는 세 줄이다 — "주어진 회로를 구성한다", "Vcc=5V, Vin=(사인파 Vpp 5V,
offset 2.5V) 를 인가한다", "오실로스코프 출력 모드를 X-Y 모드로 설정한 뒤 결과를
확인한다".

회로도(p10, vision): 신호원 `VIN` 의 + 가 CH1 의 + 와 U1 pin 1 에 함께 물리고,
`VIN` 의 - 와 CH1 의 - 는 GND 다. U1 pin 2 가 CH2 의 + 로 가고 CH2 의 - 는 GND 다.
pin 14 는 VCC, pin 7 은 GND. **회로도에는 미사용 게이트 처리가 그려져 있지 않다** —
그것은 p9 "실험 주의사항" 이 따로 시킨다: "74HC04, 74HC14에 대해 사용하지 않는 핀의
입력 값은 Vcc 또는 GND에 연결 (Pull up/Pull down)". p9 그림은 게이트 1 만 쓰는
U1 에서 `2A`·`3A`(pin 3·5) 를 GND 로, `4A`·`5A`·`6A`(pin 9·11·13) 를 VCC 로
묶고 출력 여섯 중 미사용 다섯을 개방(×)한다. 결선도는 이 그림을 그대로 따른다.

교안은 준비물(p8)에 `5V 전압원`·`오실로스코프`·`IC` 만 적고 **사인파를 낼
신호원을 적지 않는다.** 함수발생기가 실험실에 있는지는 결선도 미확정 표에 올렸다.

## T1 · 74HC04 Inverter 입출력 특성 (X-Y)

- kind: capture
- source: manual:p10
- expected: 가로축 CH1 = Vin(0~5V 사인파), 세로축 CH2 = Vout. 교안 p3 의 논리
  레벨 정의대로 Vin 이 낮은 쪽에서는 Vout 이 VCC 근처(OUTPUT HIGH), Vin 이 높은
  쪽에서는 GND 근처(OUTPUT LOW)에 있고, 그 사이에서 한 번 전이한다. 전이가
  일어나는 Vin 구간을 p3 의 `V_ILmax`~`V_IHmin`(ABNORMAL 영역) 과 대응해 본다.
  Vin 이 올라갈 때와 내려갈 때 전이 위치가 같은지(단일 곡선인지)를 T2 와 비교하기
  위해 봐 둔다. 이 대응·비교 지시는 교안 원문이 아니다 — 교안은 "결과를
  확인한다" 까지만 쓴다. 전이 전압 숫자는 교안에 없으므로 예상값을 적지 않는다.

# E2.P1-2 · 실험 1-2) Schmitt-trigger의 입출력 특성 확인

교안 p11. 지시는 두 줄이다 — "앞선 회로 구성 및 설정을 유지하고, IC를 74HC14로
교체한다", "결과를 비교한다". 회로도(p11, vision)는 p10 과 같은 배선에 게이트
심볼만 히스테리시스 기호가 든 `74HC14` `U1A` 로 바뀐 것이다. 신호원 설정(사인파
Vpp 5V, offset 2.5V)과 X-Y 모드도 그대로다. p9 주의사항이 `74HC14` 도 같이
지목하므로 미사용 입력 pull up/down 배선도 그대로 둔다.

`74HC14` 의 핀 배치는 `74HC04` 와 같다(Nexperia 74HC14 Rev.10 §6.2 — 결선도
`# 핀아웃 출처`). 그래서 **칩만 뽑아 갈아 끼우면** 된다는 교안 지시가 성립한다.

## T2 · 74HC14 Schmitt-trigger 입출력 특성 (X-Y)

- kind: capture
- source: manual:p11
- expected: T1 과 같은 축. 교안 p4 의 이론대로 Vin 이 올라갈 때의 전이 전압(`VT+`)과
  내려갈 때의 전이 전압(`VT-`)이 달라 곡선이 닫힌 고리(hysteresis)를 그린다.
  고리의 오른쪽 세로 에지가 `VT+`, 왼쪽이 `VT-`, 가로 폭이 `VH = VT+ - VT-` 다
  (p4 그림). 캡션에 두 에지의 Vin 눈금값을 적어 두면 비교가 된다 — 이 기록
  지시와 T1 의 단일 전이를 나란히 놓고 보라는 지시는 교안 원문이 아니다. 교안은
  "결과를 비교한다" 까지만 쓴다. 문턱 전압의 예상 숫자는 교안에 없으므로 적지
  않는다.

# E2.P2 · 실험 2) CMOS의 AC 특성 확인

교안 p12. 지시는 네 줄이다 — "주어진 회로를 구성한다", "Vcc=5V, Vin=(사각파 Vpp
5V, 1MHz) 를 인가한다", "오실로스코프 CH1에 U1의 4번 핀을, CH2에 U1의 8번 핀을
연결한다", "t_pd를 측정하고, Datasheet 값과 비교한다".

**`74HC04` 두 패키지를 쓴다** — 준비물 p8 이 `74HC04(2개)` 라 적었고 p12 회로도에
`U1`·`U2` 가 둘 다 `74HC04` 다. `ics` 는 패키지 이름 목록이라 하나만 적는다.

회로도(p12, 600dpi vision) 배선 — 텍스트 추출이 못 보는 자리라 판독 방식을 적는다:

- `U1`: `VIN` → pin 1(1A). pin 2(1Y) → pin 3(2A). pin 4(2Y) → pin 5(3A).
  pin 6(3Y) → 위쪽 우회선 → pin 13(6A). pin 12(6Y) → pin 11(5A). pin 10(5Y) →
  pin 9(4A). pin 8(4Y) → `U2` pin 1. pin 14 VCC, pin 7 GND. `VIN` 의 - 는 GND.
  **여섯 게이트가 전부 직렬로 쓰인다** — 미사용 입력이 없다. 위쪽 우회선이 pin 1
  행을 가로지르지만 접점(분홍 점)이 없어 VIN 과는 연결되지 않는다 — 회로도의 다른
  접속점은 전부 분홍 점으로 찍혀 있고, 만약 연결돼 있다면 신호원 출력과 게이트
  출력 pin 6 이 직결되는 회로라 성립하지 않는다. 이 판독은 확정으로 둔다.
- `U2`: pin 1(1A) ← `U1` pin 8. pin 2(1Y) 는 개방(×). pin 3(2A)·pin 5(3A) → GND,
  pin 9(4A)·pin 11(5A)·pin 13(6A) → VCC (p9 그림과 같은 배치 — 결선도 M6). 출력
  4·6·8·10·12 개방.
  pin 14 VCC, pin 7 GND. `U2` 는 게이트 1 의 입력만 쓰고 그 출력을 아무 데도
  보내지 않는다 — `U1` 체인 끝의 **부하** 로 쓰인다는 해석은 교안 원문이 아니다.

CH1(pin 4) 과 CH2(pin 8) 사이에는 pin 5→6, 13→12, 11→10, 9→8 의 **인버터 4 단**이
놓인다. 이 단 수는 교안이 글로 적지 않았고 회로도에서 센 것이다 — 교안 원문이
아니다. 짝수 단이라 CH2 는 CH1 과 같은 방향으로 움직이고, CH1 의 한 에지에서 CH2 의
같은 방향 에지까지가 4 단 지연의 합이다. 각 단은 `t_PHL` 과 `t_PLH` 를 번갈아
겪으므로 두 행 모두 `2·t_PHL + 2·t_PLH` 를 재는 셈이고, `1단 환산` 은 그 4 분의 1
이다(교안 원문이 아닌 산술). T3 의 상승·하강 두 행은 같은 양을 두 에지에서 따로 잰
것이지 `t_PHL` 과 `t_PLH` 를 갈라 주는 것이 아니다. **단 수는 측정 결과로 역산하지
않고 브레드보드에서 센다** — 체인 점퍼는 모두 5 가닥(2→3, 4→5, 6→13, 12→11,
10→9)이고, 그중 pin 4 와 pin 8 사이에 놓인 것은 뒤의 4 가닥이라 인버터 4 단이다.

교안 p12 는 사각파의 `offset` 을 적지 않는다(p10 의 사인파는 `offset 2.5V` 를
적었다). Vpp 5V 사각파를 0~5V 로 놓으려면 offset 2.5V 가 필요한데 이것은 교안
문자가 아니다 — 결선도 미확정 표에 올렸다.

## T3 · 74HC04 전달 지연 t_pd 측정

- kind: stepped
- encoding: 0/1
- source: manual:p12

`측정값` 과 `1단 환산` 이 실험실에서 채우는 칸이다. `단 수` 의 `4` 는 위 산문대로
회로도에서 센 값이고 브레드보드에서 다시 센다. 기준선은 두 채널 모두 Vcc 의 50%
(교안 p7).

| 구간 | CH1 에지 (U1 pin 4) | CH2 에지 (U1 pin 8) | 측정값 (ns) | 단 수 | 1단 환산 (ns) |
|---|---|---|---|---|---|
| 상승 | 50% 상승 | 50% 상승 | | 4 | |
| 하강 | 50% 하강 | 50% 하강 | | 4 | |

교안이 "Datasheet 값과 비교한다" 라고 지시하므로 비교 대상을 아래 참조표로 둔다.
값은 교안이 아니라 Nexperia 데이터시트에서 왔다. 규격 행(`C_L = 50 pF`)은 VCC
4.5 V 와 6.0 V 두 줄이고 5.0 V 줄은 `C_L = 15 pF` 참고값이다 — 어느 줄도 이 회로의
실제 부하·전원(U2 게이트 입력 하나 + 프로브, 5V)과 같지 않다는 것을 결선도 미확정
표(M5)에 올렸다. 측정값이 규격보다 어느 쪽에 놓일지는 여기서 예단하지 않는다.

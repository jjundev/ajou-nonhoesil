특성, 교안 p12)는 이 명세에 싣지 않는다(`config.EXPERIMENT_SCOPE`). 두 항목 모두

`pdftotext` 로 읽히지만 **회로도 네 장(p9·p10·p11 과 p4 의 심볼)은 래스터라 텍스트
추출이 0 자를 낸다** — 전부 300dpi 렌더 후 vision 으로 읽고, p9·p10 은 600dpi 로
다시 렌더해 크롭·판독했다.

# E2.P1-1 · 실험 1-1) Inverter의 입출력 특성 확인

교안 p10. `74HC04` 게이트 1 개(회로도 라벨 `U1A`, pin 1 → pin 2)를 쓴다.
교안 지시는 세 줄이다 — "주어진 회로를 구성한다", "Vcc=5V, Vin=(사인파 Vpp 5V,
offset 2.5V) 를 인가한다", "오실로스코프 출력 모드를 X-Y 모드로 설정한 뒤 결과를
확인한다".

회로도(p10, vision): 신호원 `VIN` 의 + 가 CH1 의 + 와 U1 pin 1 에 함께 물리고,
`VIN` 의 - 와 CH1 의 - 는 GND 다. U1 pin 2 가 CH2 의 + 로 가고 CH2 의 - 는 GND 다.
pin 14 는 VCC, pin 7 은 GND. **회로도에는 미사용 게이트 처리가 그려져 있지 않다** —
그것은 p9 "실험 주의사항" 이 따로 시킨다: "74HC04, 74HC14에 대해 사용하지 않는 핀의
입력 값은 Vcc 또는 GND에 연결 (Pull up/Pull down)". p9 그림은 게이트 1 만 쓰는
U1 에서 `2A`·`3A`(pin 3·5) 를 GND 로, `4A`·`5A`·`6A`(pin 9·11·13) 를 VCC 로
묶고 출력 여섯 중 미사용 다섯을 개방(×)한다. 결선도는 이 그림을 그대로 따른다.

교안은 준비물(p8)에 `5V 전압원`·`오실로스코프`·`IC` 만 적고 **사인파를 낼
신호원을 적지 않는다.** 함수발생기가 실험실에 있는지는 결선도 미확정 표에 올렸다.

- expected: 가로축 CH1 = Vin(0~5V 사인파), 세로축 CH2 = Vout. 교안 p3 의 논리

  확인한다" 까지만 쓴다. 전이 전압 숫자는 교안에 없으므로 예상값을 적지 않는다.

# E2.P1-2 · 실험 1-2) Schmitt-trigger의 입출력 특성 확인

교안 p11. 지시는 두 줄이다 — "앞선 회로 구성 및 설정을 유지하고, IC를 74HC14로
교체한다", "결과를 비교한다". 회로도(p11, vision)는 p10 과 같은 배선에 게이트
심볼만 히스테리시스 기호가 든 `74HC14` `U1A` 로 바뀐 것이다. 신호원 설정(사인파
Vpp 5V, offset 2.5V)과 X-Y 모드도 그대로다. p9 주의사항이 `74HC14` 도 같이
지목하므로 미사용 입력 pull up/down 배선도 그대로 둔다.

`74HC14` 의 핀 배치는 `74HC04` 와 같다(Nexperia 74HC14 Rev.10 §6.2 — 결선도
`# 핀아웃 출처`). 그래서 **칩만 뽑아 갈아 끼우면** 된다는 교안 지시가 성립한다.

- expected: T1 과 같은 축. 교안 p4 의 이론대로 Vin 이 올라갈 때의 전이 전압(`VT+`)과

  고리의 오른쪽 세로 에지가 `VT+`, 왼쪽이 `VT-`, 가로 폭이 `VH = VT+ - VT-` 다
  (p4 그림). 캡션에 두 에지의 Vin 눈금값을 적어 두면 비교가 된다 — 이 기록
  지시와 T1 의 단일 전이를 나란히 놓고 보라는 지시는 교안 원문이 아니다. 교안은
  "결과를 비교한다" 까지만 쓴다. 문턱 전압의 예상 숫자는 교안에 없으므로 적지
  않는다.

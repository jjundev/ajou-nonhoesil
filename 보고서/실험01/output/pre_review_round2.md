## 교안 회로도 대조

- 교안 `실험1. Basic Gates.pdf` p.11~p.15를 렌더해 회로 위상을 직접 대조했다.
- 3입력 AND·OR: 1단 출력(L1)을 2단 입력과 LED로 팬아웃하고 C를 2단의 다른 입력으로 넣는 구조가 일치한다.
- 3입력 NAND·NOR: 각각 `74HC08 → 74HC00`, `74HC32 → 74HC02` 순서와 L1/L2 위치가 일치한다. NOR의 `74HC02` 게이트1은 입력 2·3번, 출력 1번으로 기록·도면 모두 일치한다.
- 복합 논리회로: `A → NOT → AND(A',B) → NOT = Z`, `A,Z → OR = X`, `A,B → OR = Y`가 교안 p.15와 일치한다. Z는 LED와 X 게이트 입력에 모두 연결돼 있다.
- PNG 결선도 7장은 위 netlist와 동일한 핀 연결, LED 330Ω 직렬, VCC 14번·GND 7번, 미사용 입력 GND 처리를 보인다.

## 실험 전 현물 확인

- 실제 브레드보드·IC 각인·전원장치 연결은 파일 검토만으로 증명할 수 없다. 전원을 넣기 전 각 IC의 14번이 +5V, 7번이 GND인지 도통으로 확인한다.
- 복합회로는 `X ≡ Z`이므로 네 입력 조합 모두에서 LED_X와 LED_Z가 같은 상태여야 한다. 다르면 전원을 끄고 Z 팬아웃부터 재확인한다.

# 공통 규칙

- kind: common

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND
- **미사용 입력핀은 전부 GND 로 내린다.** 플로팅 금지. 미사용 *출력*핀은 개방한다
  (출력끼리 묶거나 GND 로 내리면 칩이 죽는다)
- 입력 A·B·C 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물린다. 띄워두지 않는다
- LED 는 애노드 쪽에 330Ω 직렬, 캐소드 → GND (교안 p11~p15 의 "다이오드 연결 시,
  330Ω 저항 필수" 박스)
- **물리 칩 재사용:** 교안 p10 준비물은 `74HC00 / 74HC02 / 74HC04 / 74HC08 /
  74HC32 / 74HC86` 이고 **수량 표기가 없다.** 아래에서 `U1`·`U3`·`U8` 은 **같은
  74HC08 한 개**를, `U2`·`U5`·`U9` 는 **같은 74HC32 한 개**를 항목마다 재배선해
  쓰는 것이다
- **`74HC02` 는 나머지 셋과 핀 배치가 다르다.** 출력 핀 기준으로 `74HC00/08/32` 는
  핀 3·6·8·11 이 출력이지만 `74HC02` 는 **핀 1·4·10·13** 이 출력이다. 이 실험에서
  가장 흔한 배선 실수다

# 핀아웃 출처

- kind: sources

칩마다 근거의 등급이 다르다. **가정인 것은 미확정 표에 올린다.**

- `74HC04` — 저장소 실물 데이터시트
  `from_the_past/정리/소자_데이터시트_및_미디어/1_데이터시트_및_핀아웃/datasheet.pdf`
  (Philips 74HC04 Hex inverter, 2003-07-23, PINNING 절) 로 확인함
- `74HC00` — **저장소 안에서 확인된다.** 실험6 교안
  (`from_the_past/정리/강의노트/실험6.pdf`) p7·p8 회로도가 같은 물리 칩(74HC00 쿼드
  NAND)의 게이트 핀을 `(1,2→3)`·`(4,5→6)`·`(9,10→8)`·`(12,13→11)` 로 라벨한 것을
  vision 으로 대조했다 — 아래 참조 핀아웃 표와 일치한다
- `74HC08`·`74HC02` — TI 데이터시트(74HC08: SCLS081J/SN74HC08, 74HC02:
  SCLS076G/SN74HC02)로 대조해 확인됐다
- `74HC32` — **저장소에 데이터시트가 없고, 저장소 회로도로도 대조되지 않는다**
  (실험6 은 OR/NOR 게이트를 쓰지 않는다). 표준 74HC 시리즈 DIP-14 쿼드 2입력
  배치(74HC00·74HC08 과 동일 패턴)를 근거로 적었다. 실물 칩 각인과 1주차에 대조할 것
  (아래 미확정 사항 표 M1 참조)

# C5 · 복합 논리회로 (74HC04 + 74HC08 + 74HC32)

- kind: circuit
- id: C5
- item: E1.P3
- tables: [T5]
- diagram: 실험01_결선도_복합논리회로.png

교안 p15. **입력 2개(A, B), 출력 3개(X, Y, Z), LED 3개.** C 입력은 없다.

- U7 = 74HC04 (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (인버터1 입력)
  - pin 2  → U8.pin1          (인버터1 출력 A')
  - pin 3  ← U8.pin3          (인버터2 입력 A'·B)
  - pin 4  → U9.pin2          (인버터2 출력 Z = (A'·B)')
  - pin 4  → LED_Z 애노드 (330Ω 직렬) → GND
  - 미사용 입력핀: pin 5, 9, 11, 13 → GND
  - 미사용 출력핀: pin 6, 8, 10, 12 → 개방
- U8 = 74HC08 (quad 2-input AND, DIP-14) — U1 과 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U7.pin2          (A')
  - pin 2  ← 입력 B
  - pin 3  → U7.pin3          (A'·B)
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 6, 8, 11 → 개방
- U9 = 74HC32 (quad 2-input OR, DIP-14) — U2 와 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (게이트1)
  - pin 2  ← U7.pin4          (Z)
  - pin 3  → LED_X 애노드 (330Ω 직렬) → GND    ※ X = A + Z
  - pin 4  ← 입력 A           (게이트2)
  - pin 5  ← 입력 B
  - pin 6  → LED_Y 애노드 (330Ω 직렬) → GND    ※ Y = A + B
  - 미사용 입력핀: pin 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 8, 11 → 개방

`Z` 노드(U7.pin4)는 LED_Z 와 U9.pin2 로 팬아웃한다. 부울대수상 `X ≡ Z` 이므로
**LED_X 와 LED_Z 가 언제나 같이 켜져야 한다.** 다르면 배선 오류다.

# 미확정 사항

- kind: open-issues

교안 원문이 아닌 판단을 전부 모은다. 명세 쪽 미확정도 여기로 온다.

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M1 | `74HC32` 핀아웃이 저장소 데이터시트로도 저장소 회로도로도 확인되지 않는다(표준 DIP-14 쿼드 2입력 배치를 가정). `74HC04` 는 저장소 데이터시트로, `74HC00` 은 실험6 교안 p7·p8 회로도로, `74HC08`·`74HC02` 는 TI 데이터시트로 각각 확인됐다 — `# 핀아웃 출처` 참조 | 실물 칩 각인 확인 후 벤더 데이터시트 대조 |
| M2 | 교안이 입력 스위치·딥스위치를 지정하지 않는다. 점퍼선 직결로 가정했다 | 실험실 키트 확인 |
| M3 | 74HC 출력으로 LED 를 직접 구동한다. 적색 LED 순방향 강하를 2V 로 보면 330Ω 에서 `(5−2)/330 ≈ 9.1 mA` 다. 저장소 74HC04 데이터시트는 `VOH`·`VOL` 을 `IO = ±4.0 mA`(VCC 4.5V) 조건에서 규정하므로 **규격 조건의 두 배가 넘고**, 절대 최대 `IO = ±25 mA` 보다는 작다 | 교안 지시가 그러하므로 그대로 따른다. 규격 조건을 넘겨 쓰면 `VOH` 가 규정 최소 3.98V 아래로 내려가므로, LED 밝기가 눈에 띄게 낮으면 이 지점을 먼저 본다 |
| M7 | 교안은 "5V 전압원"(p10)·"전압원 5V"(p11~p13) 만 적고 접지를 문자로 적지 않는다. 명세 `power` 의 `GND` 는 관례값이다 | 전원장치 GND 단자를 접지 레일에 물리고 IC 7번 핀과 도통을 본다 |
| M8 | `74HC86`(XOR) 이 p10 준비물에 있으나 어느 항목도 XOR 회로를 구성하지 않는다. 예비용인지 다른 연도 잔재인지 알 수 없다 | 조교에게 이번 주차에 쓰는지 확인한다 |
| M10 | 항목마다 `74HC08`·`74HC32` 를 한 패키지씩 요구하는데 준비물은 종류당 하나다. 세 회로를 동시에 브레드보드에 올릴 수 없다(`# 공통 규칙` 의 물리 칩 재사용 참조) | 순차로 배선한다 — 앞 회로를 다 기록한 뒤 칩을 빼고 다음 회로를 꽂는다 |

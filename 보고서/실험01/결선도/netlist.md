# 꼭 읽을 것

- kind: must-read

- **`74HC02` 는 나머지 셋과 핀 배치가 다르다.** `74HC00/08/32` 는 핀 3·6·8·11 이
  출력이지만 `74HC02` 는 **핀 1·4·10·13** 이 출력이다. 이 실험에서 가장 흔한 배선 실수다
- 미사용 입력은 비워 둔다. **미사용 출력은 아무 데도 잇지 않는다** — 묶거나 GND 로 내리면 칩이 상한다
- 입력 A·B·C 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 문다. 띄워두지 않는다
- **각 칩을 처음 쓰는 회로에서는 진리표 전 행을 돌린다** — 조교가 일부 행만 지시해도 그렇다
- 칩 자리는 고정이다. 그림의 **회색 선은 손대지 않는다**

# 공통 규칙

- kind: common

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND
- **사용하는 게이트의 입력은 반드시 물린다** (플로팅 금지). **미사용 게이트의
  입력은 접지하지 않는다** — 2026-09-11 실험실 실측에서 결과에 영향이 없었고,
  접지선이 NAND 순서표 20줄 중 12줄이라 결선만 복잡하게 했다. 미사용 *출력*핀은
  개방한다 (출력끼리 묶거나 GND 로 내리면 칩이 죽는다). 교안이 미사용 핀 처리를
  명시한 주차(실험02 p9)만 교안대로 한다
- **각 칩을 처음 쓰는 회로에서는 진리표 전 행을 돌린다.** 조교가 일부 행만
  지시해도 그렇다 — 74HC08 결함(2026-09-11)은 11 조합을 건너뛰어 마지막
  회로에서야 드러났다. C1 8행이 74HC08 게이트1·2 의 네 조합을 모두 덮고, C2 가
  74HC32, C3 2단계가 74HC00, C4 2단계가 74HC02 를 처음 쓴다
- **칩 자리는 고정이다** (아래 `# 칩 자리표`). 회로가 바뀌어도 전원·입력·LED
  사슬은 그대로 두고, 그림의 **회색 선은 손대지 않는다.** 걷을 선은 그림 아래
  "앞 단계에서 걷는다" 표에 있다
- 입력 A·B·C 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물린다. 띄워두지 않는다
- LED 는 애노드 쪽에 330Ω 직렬, 캐소드 → GND (교안 p11~p15 의 "다이오드 연결 시,
  330Ω 저항 필수" 박스)
- **물리 칩 재사용:** 교안 p10 준비물은 `74HC00 / 74HC02 / 74HC04 / 74HC08 /
  74HC32 / 74HC86` 이고 **수량 표기가 없다.** 아래에서 `U1`·`U3`·`U8` 은 **같은
  74HC08 한 개**를, `U2`·`U5`·`U9` 는 **같은 74HC32 한 개**를 항목마다 재배선해
  쓰는 것이다
- **`74HC02` 는 나머지 셋과 핀 배치가 다르다.** 출력 핀 기준으로 `74HC00/08/32` 는
  핀 3·6·8·11 이 출력이지만 `74HC02` 는 **핀 1·4·10·13** 이 출력이다. 이 실험에서
  가장 흔한 배선 실수다

## 단계

| 단계 | 그림 | 이 단계에서 | 확인 |

| 3 | `실험01_3_결선도_복합논리회로_3단계_OR.png` | 74HC32 를 우 10행에 꽂고 A·B 갈래, Z→pin 2, X·Y LED 를 잇는다 | T5 4행 · X 와 Z 가 항상 같다 |

교안 p15. **입력 2개(A, B), 출력 3개(X, Y, Z), LED 3개.** C 입력은 없다.

- U7 = 74HC04 (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (인버터1 입력)
  - pin 2  → U8.pin1          (인버터1 출력 A')
  - pin 3  ← U8.pin3          (인버터2 입력 A'·B)
  - pin 4  → U9.pin2          (인버터2 출력 Z = (A'·B)')
  - pin 4  → LED_Z 애노드 (330Ω 직렬) → GND
  - 미사용 입력핀: pin 5, 9, 11, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 6, 8, 10, 12 → 개방
- U8 = 74HC08 (quad 2-input AND, DIP-14) — U1 과 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U7.pin2          (A')
  - pin 2  ← 입력 B
  - pin 3  → U7.pin3          (A'·B)
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 6, 8, 11 → 개방
- U9 = 74HC32 (quad 2-input OR, DIP-14) — U2 와 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (게이트1)
  - pin 2  ← U7.pin4          (Z)
  - pin 3  → LED_X 애노드 (330Ω 직렬) → GND    ※ X = A + Z
  - pin 4  ← 입력 A           (게이트2)
  - pin 5  ← 입력 B
  - pin 6  → LED_Y 애노드 (330Ω 직렬) → GND    ※ Y = A + B
  - 미사용 입력핀: pin 9, 10, 12, 13 → 개방 (접지 생략 — 공통 규칙)
  - 미사용 출력핀: pin 8, 11 → 개방

`Z` 노드(U7.pin4)는 LED_Z 와 U9.pin2 로 팬아웃한다. 부울대수상 `X ≡ Z` 이므로
**LED_X 와 LED_Z 가 언제나 같이 켜져야 한다.** 다르면 배선 오류다.

# 미확정 사항

- kind: open-issues

교안 원문이 아닌 판단을 전부 모은다. 명세 쪽 미확정도 여기로 온다.

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M2 | 교안이 입력 스위치·딥스위치를 지정하지 않는다. 점퍼선 직결로 가정했다 | 실험실 키트 확인 |
| M3 | 74HC 출력으로 LED 를 직접 구동한다. 적색 LED 순방향 강하를 2V 로 보면 330Ω 에서 `(5−2)/330 ≈ 9.1 mA` 다. 저장소 74HC04 데이터시트는 `VOH`·`VOL` 을 `IO = ±4.0 mA`(VCC 4.5V) 조건에서 규정하므로 **규격 조건의 두 배가 넘고**, 절대 최대 `IO = ±25 mA` 보다는 작다 | 교안 지시가 그러하므로 그대로 따른다. 규격 조건을 넘겨 쓰면 `VOH` 가 규정 최소 3.98V 아래로 내려가므로, LED 밝기가 눈에 띄게 낮으면 이 지점을 먼저 본다 |
| M7 | 명세 `power` 의 `GND` 는 교안 문자다 — p3 "0 Volt (GND 인가)", p11~p15 "5V와 GND를 번갈아 인가". 이전 판은 "교안이 접지를 문자로 적지 않는다" 고 적었는데 텍스트 추출로 실재가 확인돼 2026-09-08 정정했다. 남는 것은 전원장치의 어느 단자가 그 GND 인가뿐이다 | 전원장치 GND 단자를 접지 레일에 물리고 IC 7번 핀과 도통을 본다 |

전원: VCC = +5V · V15 = +15V · GND = GND · 미사용 입력핀을 띄워 두지 않는다 (플로팅 금지) — GND 로 내릴지 VCC 로 올릴지는 아래 공통 규칙을 본다

진리표 — 확인 칸: ✓ 일치 / 값 = 불일치 시 실제로 관찰한 값 / 공란 = 미확인. 표를 통째로 진행하지 않았으면 그 표 아래에 진행하지 않았음 이라고 적는다.

스텝표 — 회색 칸에 읽은 값을 단위와 함께 적는다 (예: 3.2 V, 47 Ω). 확인 칸이 없다: 대조할 예상값이 없는 표다.

파형 — 격자에 직접 그리고 판독 조건 줄(V/div·time/div·프로브·모드)을 채운다. 조건이 없으면 결과보고서에서 화면의 칸을 볼트로 환산할 수 없다.

공통 규칙

이 주차는 이 과목에서 유일하게 아날로그와 디지털이 한 브레드보드에 섞이는 회로다. 전원 레일이 셋이고, 오픈 컬렉터 인버터가 있고, 카운터의 전원핀이 다른 칩과 다르다. 아래 세 문단이 이 주차 배선 사고의 거의 전부를 차지한다.

전원 레일 — 레일마다 어디로 가는지 명시한다

명세 프론트매터는 {VCC: "+5V", V15: "+15V", GND: "GND"} 세 레일을 선언한다. 음전원(−15V) 레일은 없다. 교안 실험10 어디에도 -15V 나 ±15V 라벨이 없고, p7 의 U4·p15 의 U5 두 741 모두 pin 4 가 접지 기호에 직접 물려 있다 — vision 으로 확인했다. 즉 741 은 +15V 단일 전원으로 돌린다.

레일값어느 핀으로 가는가
VCC+5V7490 pin 5, 7404 pin 14, 7405 pin 14, 풀업 저항 R1~R4 상단
V15+15V741 OP amp U4 pin 7, U5 pin 7, 기준전압 분압기 R10 상단, ADC 가변저항 R13 상단
GND0V7490 pin 10, 7404 pin 7, 7405 pin 7, 741 U4·U5 pin 4, R11 하단, R13 하단, 7490 리셋핀 4개, 미사용 입력핀 전부, 계측기 프로브 접지 클립
  • +5V 전원과 +15V 전원의 GND 를 반드시 같은 노드로 묶는다. 실험실 파워서플라이의 두 채널을 쓸 때 각 채널의 COM 을 따로 두면 DAC 출력이 741 입장에서 기준 없는 전압이 되어 계단이 아예 안 나오거나 레일에 붙는다. 이 주차에서 가장 조용히 망가지는 지점이다.
  • 741 pin 4 는 데이터시트상 V− 다. 여기서 V− = 0V 이므로 출력은 0V 아래로 내려갈 수 없다. 그래서 교안이 R10–R9–R11 분압기로 pin 3(+) 에 양의 기준전압을 걸어 두는 것이다. 이 분압기를 빼먹으면 반전 가산 증폭기의 출력이 0V 에 붙어 계단이 보이지 않는다 — 분압기는 장식이 아니라 단일 전원 동작의 필수 부품이다.
  • 741 pin 4 를 −15V 로 착각해 물리지 않는다. 명세가 선언하지 않은 레일이고 교안에도 없다. 실험실 파워서플라이에 −15V 단자가 있어도 이 회로에는 쓰지 않는다.

7405 는 오픈 컬렉터다 — 풀업이 없으면 회로가 아예 안 돈다

7405 는 7404 와 논리는 같지만 출력단에 상단 트랜지스터가 없다. 출력은 LOW 로 끌어내리기만 하고 HIGH 를 못 만든다. 그래서 교안 p7 은 출력 4개마다 +5V 로 가는 1.5kΩ 풀업(R1~R4) 을 달아 둔다.

  • 풀업을 빠뜨리면 7405 출력은 HIGH 일 때 플로팅이 되고, 가중 저항망에 전류가 들어가지 않아 계단이 전혀 안 나온다. "IC 를 잘못 꽂았나" 하고 IC 부터 의심하기 쉬운데, 실제 원인은 저항 4개다.
  • 풀업이 가중 저항망의 일부라는 점이 이 회로의 핵심이다. 7405 출력이 HIGH 면 그 비트의 브랜치는 풀업 + 브랜치저항 을 통해 +5V 에 물리고, LOW 면 포화된 트랜지스터를 통해 거의 0V 에 물린다. 즉 풀업 저항값은 가중치 비율에 직접 들어간다 — R1~R4 를 다른 값으로 바꾸면 계단 높이가 어긋난다.
  • 7404 → 7405 로 두 번 반전하므로 7405 출력 노드의 논리는 카운터 출력과 같다(QA=1 → 7405 출력 HIGH). 7404 는 카운터 출력을 버퍼링하고, 7405 는 그것을 +5V/0V 로 딱 떨어지게 스위칭하는 역할이다.

7490 은 전원핀이 14/7 이 아니다

7490 은 pin 5 가 VCC, pin 10 이 GND 다. 이 과목의 다른 모든 74 시리즈 칩이 14 → VCC, 7 → GND 라서 손이 자동으로 그리로 간다. 7490 에 그렇게 물리면 pin 5(VCC) 가 R9(1) 옆의 신호핀이 아니라… 실제로는 pin 14 가 INPUT A, pin 7 이 R9(2) 이므로 클럭 입력에 5V 를 직결하고 R9(2) 를 접지로 끌어내리는 꼴이 되어 칩이 세지 않는다. 배선 전에 pin 5·10 을 먼저 꽂는 습관이 안전하다.

리셋핀은 넷 다 GND 로 내린다: R0(1)=pin 2, R0(2)=pin 3, R9(1)=pin 6, R9(2)=pin 7. 교안 p9 의 Reset Inputs 표에서 이 넷이 모두 L 일 때만 COUNT 다. 하나라도 뜨면(플로팅은 TTL 에서 HIGH 로 읽힌다) 카운터가 0 또는 9 에 고정된다.

미사용핀 처리

  • 7404·7405 는 hex 인버터인데 이 회로는 게이트 4개만 쓴다. 미사용 입력핀 pin 11, pin 13 → GND. 미사용 출력핀 pin 10, pin 12 → 개방. (7405 의 미사용 출력은 오픈 컬렉터라 풀업이 없으면 어차피 플로팅이다 — 그대로 개방해 두고 아무것도 물리지 않는다.)
  • 7490 pin 4, pin 13 은 NC 다 → 개방.
  • 741 pin 1·pin 5 는 OFFSET NULL, pin 8 은 NC 다 → 세 핀 모두 개방. 오프셋 널은 이 실험에서 조정하지 않는다.

확인항목내용확인 방법
M1교안 p14 가 요구하는 68kΩ 이 p6 준비물 목록에 없다. p6 은 330Ω 가변저항·1k·1.5k·2.7k·4.5k·10.5k·22.6k 만 싣는다. p14 원문은 "10.5KΩ 저항에 68KΩ을 병렬로 연결하고" 이므로 대상은 R6 이다실험실에서 68kΩ 조달 가능한지 조교에게 확인. 없으면 p14 관찰만 생략
M2카운터를 0 으로 리셋하는 구체적 방법을 교안이 지정하지 않는다. p16 은 "counter 를 0으로 reset한다"로만 쓴다. 위 표의 "R0(1)·R0(2) 를 잠시 +5V 로" 는 교안 p9 의 Reset Inputs 진리표에서 파생한 절차다실험실 키트에 리셋 스위치가 따로 있는지 확인. 없으면 점퍼선으로 위 절차 수행
M3single pulse 의 물리적 형태가 지정되지 않았다. 함수발생기의 single/burst 버튼인지, 디바운스된 푸시버튼인지 교안에 없다. 디바운스가 안 된 생 스위치를 쓰면 한 번 눌러 여러 칸이 올라간다실험실 장비 확인. 카운트가 한 번에 2 이상 뛰면 이걸 의심
M4오실로스코프 Ch2 가 어느 노드인지 교안이 라벨하지 않는다. p11 사진의 계단 파형은 Ch3(분홍)이 확실하고, Ch2(청록)는 2 ms/div 에서 점선처럼 보이는 1 kHz 구형파라 클럭으로 판단했다. 위 계측 표의 Ch2 지정은 이 추론이다파형이 안 맞으면 Ch2 를 클럭 대신 U3 출력 한 비트에 대 볼 것
M5R13(330Ω) 이 +15V–GND 사이에 단독으로 걸려 약 0.68 W 를 소비한다. 교안 p15 회로도 그대로이지만 소형 가변저항 정격을 넘을 수 있다. 회로도에 정격 표기가 없다실물 가변저항의 정격(W) 확인. 넘으면 조교에게 문의 — 임의로 저항을 키우지 말 것(전이점 범위가 바뀐다)
M6교안 p7 회로도의 아래쪽 일부가 슬라이드 경계에서 잘려 렌더되지 않는다. U4 pin 7 아래 전원 라벨과 R11 하단 접지 기호가 그 영역에 있다. pin 7 → +15V 와 R11 하단 → GND 는 ①PDF 내부 텍스트 객체의 좌표(U4 pin 7 바로 아래 +15V, R11 바로 아래 0) ②잘린 글자의 윗부분 형태 ③U4 pin 4 가 접지 기호에 직결된 것이 눈으로 확인되므로 pin 7 이 양전원일 수밖에 없다는 점 ④p15 의 U5 가 동일 패턴(pin 4→GND, pin 7→+15V)으로 잘리지 않고 그려진 점 — 이 넷으로 판단했다배선 전 조교에게 "741 은 단일 +15V 인가"를 한 번 확인. −15V 는 물리지 않는다
M7p6 준비물의 "저항 : 330Ω 가변저항 (2개)" 표기가 "330Ω 저항 + 가변저항 2개" 인지 "330Ω 가변저항 2개" 인지 문면상 갈린다. 회로도의 R9·R13 둘 다 값 330 에 와이퍼 화살표가 붙은 가변저항이므로 후자로 읽었다부품 수령 시 330Ω 가변저항이 2개인지 확인

준비 — 꽂는다: 7490, 7404, 7405, 741 OP amp

교안 p7 회로. 7490 이 0→9 를 세고, 각 비트가 7404→7405 를 거쳐 가중 저항망(weighted resistor) 으로 들어가고, 741 반전 가산 증폭기가 아날로그 전압을 만든다.

저항망은 R-2R 사다리가 아니라 가중 저항망이다. 교안 p4 는 두 방식을 나란히 설명하지만, p7 이 실제로 그린 것은 비트마다 다른 값의 저항 하나를 공통 가산 노드로 모으는 가중 저항 방식이다 — R-2R 처럼 저항이 두 값만 반복하는 구조가 아니다. 배선 순서를 R-2R 로 착각하면 저항 위치가 전부 어긋난다.

교안이 요구하는 배선 변형 (p12~p14)

기본 회로를 세운 뒤 아래 변형을 차례로 가한다. 명세의 T1(capture) 은 파형을 그리라고만 하므로 표 칸은 없지만, 배선은 실제로 바뀐다.

교안변형되돌릴 것
p12R12(Rf) 를 4.5kΩ → 2.7kΩ 으로 교체다음 단계에서 4.5kΩ 으로 복귀
p13R12 = 4.5kΩ 로 되돌린 뒤, ①7404 pin 2 ↔ 7405 pin 1 ②7404 pin 4 ↔ 7405 pin 3 ③7404 pin 6 ↔ 7405 pin 5 를 하나씩 개방각 관찰 후 다시 연결

p13 에서 링크를 끊으면 7405 입력이 플로팅된다. TTL 플로팅 입력은 HIGH 로 읽히므로 해당 비트의 7405 출력이 LOW 로 고정되고, 그 비트만 계단에서 빠진다 — 그것이 이 관찰의 목적이다. (다른 실험에서라면 플로팅 입력은 금지지만 여기서는 교안이 의도한 조작이다.)

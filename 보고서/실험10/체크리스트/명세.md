**신호발생기.** 교안은 이 설정을 `오실로스코프 설정`이라는 머리 아래 적는다. 절차 1(p15)은 사각파·주기 1s·
진폭 5V·오프셋 2.5V, 절차 2~3(p16·p17)은 사각파·주파수 1.0kHz·진폭 5V·오프셋 2.5V다. p18~p21에는 설정이
따로 없다. **절차 4~6을 1.0kHz로 이어 하는 것은 교안 원문이 아니다.** 교안은 진폭이 Vpp인지 피크인지 적지
않는다. 5Vpp면 0V~+5V이고 5V 피크면 -2.5V~+7.5V라, 둘 중 어느 쪽인지 교안만으로 정할 수 없다. **다음 두 문장은 교안 원문이 아니다.** 회로에 잇기
전에 오실로스코프로 실제 최소·최대 전압과 주기를 보고 0V~+5V인지 확인한다. 발생기·오실로스코프·회로의 GND는
공통으로 잇는다.

# E10.P1 · 실험 1) DAC

교안 p15~p21은 실험 1)을 여섯 절차로 나눈다. p15는 "7490(Counter) 출력에 LED를 연결하여 0-9 모두 정상
출력되는지 확인"이다. p16은 "Op-Amp V+에 GND를 연결하여 결과 확인", p17은 "Op-Amp V+에 전압분배기를
연결하여 결과 확인"이고 둘 다 `(전압 최소, 최대, 피크-피크 확인)`을 붙인다. p18은 예상 결과를 "내림차순 계단
형태로 출력"이라고 적는다. p19는 "다음의 핀을 개방하였을 때 출력 파형 확인", p20은 "저항 Rf를 2.7k로 바꾼 뒤,
출력 파형 확인", p21은 "10.5k 저항에 68k를 병렬 연결한 뒤, 출력 파형 비교"다. p15 머리에는 "실험에 앞서,
오실로스코프 고장 여부를 반드시 확인할 것"이 있다.

회로(p8~p12, p16·p17 회로도)는 다음과 같다. `7490`(U1)은 `clk`를 CLKA(pin 14)로 받고 QA(pin 12)를 CLKB(pin 1)로
되돌린다. R01·R02·R91·R92(pin 2·3·6·7)는 전부 GND(`0`)다. QA·QB·QC·QD는 각각 `7404` 인버터 하나(U2A~U2D, 핀
1→2, 3→4, 5→6, 9→8)와 `7405` 인버터 하나(U3A~U3D, 같은 핀 번호)를 거친다. `7405` 출력마다 +5V로 가는 1.5k
풀업(R1~R4)이 있고, 그 출력이 가중 저항 R5 22.6k(QA), R6 10.5k(QB), R7 4.5k(QC), R8 1.5k(QD)를 지나 한 노드로
모여 `LM741`(U4)의 pin 2로 들어간다. 그 노드와 pin 6(DAC OUTPUT) 사이에 R12 4.5k가 있다. pin 3은 +15V-R10 1k-
R9 330(가변)-R11 1k-GND 분배기의 가운데 단자에 물리고, pin 4는 GND다. **pin 7은 회로도에서 라벨 없는 단자로
끝난다.** p16·p17의 `LM741 Datasheet` 그림은 pin 7을 `V+`, pin 4를 `V-`로 적는다. 같은 교안 p22의 ADC 비교기
(U5)는 pin 7을 `+15V`에 잇는다. 이 문서는 U4 pin 7을 +15V로 잇는다. **이 결정은 교안 원문이 아니다** — 미확정
표에 올렸다.

p9는 "출력을 정확히 GND 또는 Vcc로 만들기 위해, Open-collector IC 05와 Pull up 저항 활용"하고 "IC 05에 의한
결과 반전을 피하기 위해 IC 04를 함께 활용"한다고 적는다. p10은 각 비트가 2^0~2^3의 비중을 갖도록 저항을
정하고 "비율은 약간의 오차가 있어도 됨"이라고 적는다. 풀업과 가중 저항을 직렬로 더하면 QA 24.1k, QB 12k,
QC 6k, QD 3k다. **이 합산은 V+가 GND일 때(p11의 조건)의 셈이며 교안 원문이 아니다.** V+가 분배기에 물린
절차 3에서는 가산 노드가 V+ 전위를 따라가므로 같은 합산이 그대로 성립한다고 가정하지 않는다. 그 셈은 미확정
표에 올렸다.

**T1~T2는 교안에 원래 있던 표가 아니라 p15~p17 절차를 기록하기 위해 만든 양식이다. 교안 원문이 아니다.**
T1의 예상 칸은 p8의 `(0000, 0001, … , 1000, 1001, 0000, …)`을 옮긴 것이다. R01·R02·R91·R92가 전부 GND라
이 회로에는 초기화 입력이 없다. **그래서 전원 직후 어느 카운트부터 시작하는지는 정해지지 않는다. 이 판단은
교안 원문이 아니다.** T1은 시작 값이 아니라 순환 순서를 기록한다. 네 LED가 모두 꺼진 구간을 COUNT 0으로 잡고
그 뒤 순서를 대조한다. 발생기를 멈추지 않고 LED만 보므로 특정 에지의 값을 실측으로 적지 않는다. 이 기록 방식도
교안 원문이 아니다.

T2의 스텝 2·3은 p16·p17이 지시한 최소·최대·피크-피크다. 오실로스코프 프로브는 DAC OUTPUT(U4 pin 6)과 GND에
물리고 DC 결합으로 본다. **프로브 자리와 DC 결합은 교안 원문이 아니다** — 최소·최대를 전압으로 읽으려면 DC
결합이어야 한다. T3~T9는 각 절차의 파형을 그리는 칸이다. 화면의 수직·수평 눈금(V/div, s/div)을 그림 옆에
적는다. **이 기록 지시는 교안 원문이 아니다.**

절차 4~6의 회로 변경은 서로 독립으로 한다. 절차 4는 한 번에 한 자리만 열고 다음 자리로 가기 전에 다시 잇는다.
절차 5가 끝나면 Rf를 4.5k로 되돌린 뒤 절차 6을 한다. **이 순서는 교안 원문이 아니다** — 교안은 되돌리라는
말을 하지 않는다. 미확정 표에 올렸다.

## T1 · 7490 BCD 카운터 출력 기록

- kind: stepped
- purpose: 1Hz 반복 클록에서 QD~QA LED가 COUNT 0부터 9까지 순서대로 바뀌고 0으로 돌아오는지 확인한다.
- encoding: 0/1
- source: manual:p15
- comparison: led
- outputs: [QD, QC, QB, QA]

| 스텝 | 조작 | CLK | QD | QC | QB | QA |

| S1 | 전원과 발생기를 켠다. 네 LED가 모두 꺼진 구간을 COUNT 0으로 잡는다 | RUN | 0 | 0 | 0 | 0 |
| S2 | COUNT 1 구간 | RUN | 0 | 0 | 0 | 1 |
| S3 | COUNT 2 구간 | RUN | 0 | 0 | 1 | 0 |
| S4 | COUNT 3 구간 | RUN | 0 | 0 | 1 | 1 |
| S5 | COUNT 4 구간 | RUN | 0 | 1 | 0 | 0 |
| S6 | COUNT 5 구간 | RUN | 0 | 1 | 0 | 1 |
| S7 | COUNT 6 구간 | RUN | 0 | 1 | 1 | 0 |
| S8 | COUNT 7 구간 | RUN | 0 | 1 | 1 | 1 |
| S9 | COUNT 8 구간 | RUN | 1 | 0 | 0 | 0 |
| S10 | COUNT 9 구간 | RUN | 1 | 0 | 0 | 1 |

## T3 · DAC 출력 파형 (V+ = GND)

- kind: capture
- source: manual:p16
- expected: p11은 "V+를 GND에 연결하면" 출력이 Vout = -(Rf/R1·V1 + Rf/R2·V2 + Rf/R3·V3 + Rf/R4·V4)라고
  적는다. 식의 V1~V4는 0 이상이므로 식이 주는 값은 모든 카운트에서 0 이하다. 그런데 U4의 음전원 핀(pin 4)은
  GND이고, p5는 소자가 공급 전압 이상을 출력할 수 없다고 적는다. p12는 "DAC Output이 음의 값(0V 이하)을 갖지
  않도록" 전압 분배기를 둔다고 적는다. 그래서 식이 주는 계단이 화면에 그대로 나온다고 예상하지 않는다. 이 셈은
  교안 원문이 아니다. 단일 +15V로 LM741을 쓰는 문제는 미확정 표에 올렸다. 교안은 이 절차의 결과 화면을 따로
  적지 않는다. p18 왼쪽 사진은 평평한 선이고 오른쪽은 계단인데, 어느 사진이 어느 절차인지 교안이 밝히지
  않는다(vision 판독, 미확정 표). 보이는 개형을 그대로 그리고 T2 스텝 2에 최소·최대·피크-피크를 적는다. 예상
  전압 숫자는 교안에 없어 적지 않는다.

## T4 · DAC 출력 파형 (V+ = 전압 분배기)

- kind: capture
- source: manual:p17
- expected: p18의 예상 결과는 "내림차순 계단 형태로 출력"이다. p8대로 카운트가 0000부터 1001까지 열 값을
  돌므로 한 주기의 계단은 열 단이다. 1.0kHz 클록이면 한 단이 1ms, 한 주기가 10ms다. 단 수와 시간은 p8·p16에서
  굴린 셈이며 교안 원문이 아니다. p18 오른쪽 사진의 수평 눈금은 `M 2.00ms`다(vision 판독). **교안 소자값으로
  반전 가산기 식을 이상 소자로 굴리면 분배기 전 범위·모든 카운트에서 출력이 U4 전원 +15V를 넘어, p18의 계단
  사진과 어긋난다.** 셈은 미확정 표에 있고 교안 원문이 아니다. 어느 쪽이 맞는지는 실측으로 가른다. 보이는
  개형과 단 수를 그대로 그리고 T2 스텝 3에 최소·최대·피크-피크를 적는다. 예상 전압 숫자는 적지 않는다.

## T5 · 7404 핀 2와 7405 핀 1 사이 개방 출력 파형

- kind: capture
- source: manual:p19
- expected: QA(LSB) 비트의 7404 출력(U2 pin 2)과 7405 입력(U3 pin 1) 사이 선을 뽑은 상태의 DAC OUTPUT이다.

## T8 · Rf 2.7k 출력 파형

- kind: capture
- source: manual:p20
- expected: R12(4.5k)를 2.7k로 바꾼 상태의 DAC OUTPUT이다. 반전 가산기에서 비트 하나가 바뀔 때 출력이 움직이는
  양은 그 비트 가지의 전류 변화에 Rf를 곱한 것이다. 그래서 계단 한 단의 높이는 Rf에 비례하고, Rf가 4.5k에서
  2.7k로 바뀌면 2.7/4.5 = 0.6배가 된다. V+가 0이 아니면 출력 식에 V+ × (1 + Rf × Σ1/Ri) 항이 있어 계단 전체의
  위치도 Rf에 따라 바뀐다. 이 셈들은 교안 원문이 아니며 출력이 공급 전압 안에 있을 때만 맞는다 — 미확정 표의
  이상 셈대로면 Rf 2.7k에서도 +15V 아래로 셈되는 것은 COUNT 8·9뿐이고 나머지 카운트는 +15V를 넘는다. 교안 p20은 사진 두 장만 싣는다. T4와 나란히 그리고 단
  높이를 비교한다.

## T9 · 10.5k ∥ 68k 출력 파형

- kind: capture
- source: manual:p21
- expected: Rf를 4.5k로 되돌린 뒤 R6(10.5k, QB 가지)에 68k를 병렬로 단 상태의 DAC OUTPUT이다. 병렬 합성은
  10.5 × 68 / 78.5 ≈ 9.1k라 QB 가지의 저항이 줄어 QB 비트의 비중이 커진다. 그래서 QB가 바뀌는 단(COUNT 1→2,
  3→4, 5→6, 7→8)의 높이가 다른 단과 달라질 수 있다. 이 셈과 단 목록은 교안 원문이 아니며 출력이 공급 전압
  안에 있을 때만 맞는다(미확정 표의 이상 셈). 교안 p21은 "출력 파형 비교"만 지시하고, 사진 두 장의 차이는 이
  해상도에서 단정할 수 없다(vision 판독, 미확정 표). T4와 나란히 그리고 단 높이가 고른지 비교한다.

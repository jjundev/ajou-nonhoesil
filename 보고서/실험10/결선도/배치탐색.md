# 배치 탐색 — 보고서/실험10/결선도/배치.py

배선표가 바뀌면 다시 잰다 — 고른 layout 은 `배치.py` 의 `LAYOUT` 과 netlist `kind: layout` 표에 옮겨 적는다.

```json
{
 "hash": "ccd03de691dee8b2",
 "layout": {
  "bridge": [
   48,
   49
  ],
  "bridge_policy": "lower-clearance-v1",
  "leds": {
   "dac": {
    "QA": 18,
    "QB": 13,
    "QC": 8,
    "QD": 3
   }
  },
  "slots": {
   "S1": 4,
   "S2": 15,
   "S3": 25,
   "S4": 36
  }
 }
}
```

실험08·09 와 같은 방식이다. `place_search --mode fixed` 는 어댑터당 회로 하나만 받고 배선기 끝 `NODE`(저항 스트립)·둘째 전원을 모른다. 그래서 손으로 만든 후보를 전 보드 `verify()` 로 쟀다. 256회 탐색이 아니므로 이 범위의 최선이다. 고르는 규칙은 고정 LED 탐색과 같다 — 통과한 최단 길이의 ×1.10 안에서 밀도 → 꺾임 → 길이 최소. 길이·꺾임·밀도는 superset 판(모든 단계의 선) 칸 단위다.

- LED 윗행 3·8·13·18(QD→QA), S4(LM741) 36행은 고정이다 — pin 6 이 레일 빈 행 38에 와야 Rf 가 가운데 레일 홀 위를 지나지 않는다. 저항 구역(우 36~45행)·+15V 착지·브리지 48·49행도 고정이다.
- 후보 여덟: S1 4·5·6 × S2 = S1 + 10·11 × S3 = S2 + 10·11 중 S3 이 S4 앞에 세 행 이상 남는 것.
- 띠 431.5(최단 392.3 ×1.10).

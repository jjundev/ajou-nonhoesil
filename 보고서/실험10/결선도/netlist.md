# 공통 규칙

- kind: common

교안 범위의 실험 1) DAC(p15~p21)만 만든다. 실험 2) ADC(p22~p24)는 하지 않는다(조교 공지 `_350547_1`).
C1을 맨바닥에서 만들고, C2는 C1 위에 이어 짓고, C3은 C2의 선·부품 일부를 잠시 바꾼다. `U<n>`은 교안 회로도의
`U1`~`U4`를 그대로 쓴다. 슬롯 이름과 `OA`~`OD` 같은 노드 이름은 교안 원문이 아닌 이 문서의 식별자다.

전원은 p14의 5V·15V 전압원이다. **두 전원을 섞지 않는다.** +15V는 `LM741`(U4) pin 7과 분배기 R10 위쪽 끝에만
간다. 로직 칩 셋(`7490`·`74HC04`·`74HC05`)과 풀업 R1~R4는 +5V다. 74HC05의 절대 최대 전원은 7V다(TI SCLS080F §6.1) — +15V가 로직 칩에 닿으면 안 되는 근거다. 두 전원의 GND는 공통이다(p8·p16 회로도의 `0` 기호가
전부 같은 넷이다). 전원핀은 칩마다 다르다. **`7490`은 pin 5 → VCC(+5V), pin 10 → GND**, `74HC04`·`74HC05`는
pin 14 → VCC(+5V), pin 7 → GND, **`LM741`은 pin 7 → +15V, pin 4 → GND**다. 교안 회로도는 7490·7404·7405의
전원핀을 그리지 않고, LM741 pin 7은 라벨 없는 단자로 끝난다(M3).

다음은 교안 원문이 아닌 배선 운영 규칙이다. 칩을 꽂거나 배선을 바꿀 때 전원과 발생기 출력을 끄고 극성을
확인한다. 사용하는 입력은 확정된 레벨이나 구동 출력에 연결해 플로팅을 막는다. **미사용 게이트 입력은 접지
생략**이 수업 공통 규칙이다(실험01 실측 2026-09-11, `draft-lab-spec` 결선도 골격의 공통 규칙). `74HC04`·`74HC05`는 여섯 게이트 중 넷만 쓴다 — 남는 입력 pin 11·13은 비워 둔다. 부분 배선 단계에서 아직 안 쓰는 게이트 입력(C2 1단계의 U2 pin 9, 2단계의 U3 pin 5·9)도 같은 규칙으로 비워 둔다. 그 게이트 출력은 그 단계의 관측에 들어가지 않는다.
`7490`의 pin 4·13은 No Connect라 비워 둔다(TI SDLS940A p1). `LM741`의 pin 1·5(OFFSET NULL)·pin 8(NC)은
비워 둔다(p16 `LM741 Datasheet` 그림). C3의 절차 4가 7405 입력을 잠시 띄우는 것은 교안 지시다(p19, M8).

V+ 선택은 점퍼 한 가닥(`VP`)으로 한다. 한 끝은 U4 pin 3에 고정하고, 다른 끝을 GND 레일(절차 2) 또는 R9 가운데
단자 행(절차 3)에 꽂는다. 이 점퍼를 옮기는 것은 교안의 "V+에 GND를 연결"·"V+에 전압분배기를 연결" 조작에
해당한다. **이 점퍼 방식은 교안 원문이 아니다.** 옮길 때는 발생기와 전원을 끈다. 결선도에서는 GND 쪽 점퍼
(C2 5단계, 좌 a38 → 좌 GND레일37행)를 6걷기에서 뽑고 R9 쪽 점퍼(6단계, 좌 d38 → 우 f44)를 새로 꽂는 두 가닥으로 그린다.

+15V는 노랑 잭에서 **우 바깥 VCC 레일**로만 간다(사용자 결정 2026-11-16). 그 레일은 +15V 전용이고 U4 pin 7과 R10만
닿는다. 우 바깥 GND 레일은 회색 잭의 둘째 선이 먹인다. 결선도 엔진은 +15V 레일 넷에 LM741 pin 7 밖의 칩 핀이 닿으면
그림을 내지 않는다. 저항망(R5~R12)은 우 블록 LED 아래 36~45행에 둔다(같은 날 사용자 결정, 배치.py
`LED_BLOCK_PARTS_REASON`). **이 자리 배치는 교안 원문이 아니다.**

LED 사슬은 `7490 출력 → LED → 330Ω → GND`로 적어 출력 1에서 켜지게 한다. **LED·330Ω은 준비물에 없고, 극성과
직렬 순서는 교안 원문이 아니다**(M5). C1에서 단 LED는 C2·C3에서도 그대로 둔다. 교안은 LED를 떼라고 하지 않는다.
LED 부하가 7490 출력 레벨에 주는 영향은 M6에 적었다.

신호발생기 설정은 명세 머리말을 따른다. C1과 C2 1~3단계는 사각파·주기 1s, C2 4단계부터와 C3은 사각파·1.0kHz다
(p15~p17. C2 1~3단계의 1s는 조립 확인용 선택이다). **다음 문장들은 교안 원문이 아니다.** 회로에 잇기
전에 오실로스코프로 실제 최소 0V·최대 +5V를 확인한다. 진폭의 단위(Vpp·피크)는 교안에 없다(M4). 발생기·
오실로스코프·회로 GND를 공통으로 잇는다. 전원을 끌 때는 발생기 출력도 끈다. 출력 OFF가 0V를 보장한다고
가정하지 않는다.

표기: `IN:CLK`는 신호발생기 출력을 그 핀에 잇는다는 뜻이다. `RUN`은 발생기가 반복 클록을 내는 상태, `미정`은 그 행에서 값을 예측할 수 없다는 뜻이다(전원 직후 카운트가 정해지지 않아서다). 핀 표의 `QA'` 등은 7404 출력 신호이고, 노드 이름은 같은 신호를 `QA_N`처럼 적는다(`_N` = 반전). 이 표기는 교안 원문이 아니다.

순차 출력은 `lab-netlist/v3`의 observed 노드와 저작한 확인 절차로 적는다. **모든 확인 절차는 교안 원문이
아니다.** 저작한 기대값은 측정 기록이 아니며 명세의 실제 결과 칸은 빈 상태로 둔다. C2의 조립 중 확인(V1~V3)은
교안 필수 측정이 아니지만 현장판에 관측표로 인쇄한다(사용자 결정 2026-11-20). 교안이 지시한 기록표는 T1~T9다.

# 꼭 읽을 것

- kind: must-read

- **+15V는 노랑 잭 → 맨 오른쪽 바깥 VCC 레일 하나에만 있어요. 그 레일에는 LM741 pin 7과 R10만 꽂아요.** 74HC04·74HC05·7490에 닿으면 칩이 망가져요. 꽂기 전에 레일 두 개를 손으로 짚어 확인해요.
- **전원핀이 칩마다 달라요.** 7490은 5·10, 74HC04·74HC05는 14·7, LM741은 7(+15V)·4(GND)예요.
- **발생기는 회로에 잇기 전에 확인해요.** 오실로스코프로 0~+5V를 보고 GND를 공통으로 이어요. C1·C2 1~3단계는 주기 1s, C2 4단계부터와 C3은 1.0kHz예요.
- **V+ 점퍼(U4 pin 3)는 T2 스텝 2·T3에서 GND, T2 스텝 3·T4~T9에서 R9 가운데 단자예요.**
- **절차 4는 한 번에 한 선만 빼고, 그리고 나면 다시 꽂아요. 절차 5가 끝나면 Rf를 4.5k로 되돌린 뒤 절차 6을 해요.**

|---|---|---|
| R1~R4 | +5V → U3 pin 2·4·6·8 (풀업) | 1.5k |
| R5 | U3 pin 2 → 가산 노드 (QA, LSB) | 22.6k |
| R6 | U3 pin 4 → 가산 노드 (QB) | 10.5k |
| R7 | U3 pin 6 → 가산 노드 (QC) | 4.5k |

| R12 (Rf) | 가산 노드(U4 pin 2) → U4 pin 6 | 4.5k (절차 5에서 2.7k) |
| R10 / R9 / R11 | +15V → R10 → R9 → R11 → GND 분배기, R9 가운데 단자가 V+ 후보 | 1k / 330 가변 / 1k |

# C1 · 실험 1) DAC — 1. 7490 카운터 확인 (7490)

원문이 아니다**(M5).

# C2 · 실험 1) DAC — 2~3. DAC 전체 회로 (74HC04 + 74HC05 + LM741)

- kind: circuit
- id: C2
- item: E10.P1
- tables: [T2, T3, T4]
- continues: C1
- diagram: 실험10_1_결선도_DAC.png

p16·p17 회로를 C1 위에 이어 짓는다. C1의 7490과 LED 사슬은 그대로 둔다. 각 비트는 `74HC04`(U2) 하나와 `74HC05`(U3)
하나를 거쳐 1.5k 풀업과 가중 저항으로 가고, 가중 저항 넷은 한 노드에서 만나 U4 pin 2로 들어간다. R12가 그 노드와
U4 pin 6 사이에 있다. 분배기 R10·R9·R11은 +15V와 GND 사이에 있다. 1~3단계는 1Hz에서 LED로 카운트 구간을 보며 각
단계에서 꽂은 선을 확인하고, 4단계부터 발생기를 1.0kHz로 바꾼다. **이 단계 절차와 1Hz 조립 확인은 교안 원문이
아니다.** 단계 1~3의 확인은 저항망을 잇기 전의 조립 상태에서만 맞는다. 4단계에서 R5~R8이 들어오면 U3 출력은
가산 노드 전위의 영향을 받는다(M7).

# 칩 자리표

- kind: layout

교안 원문이 아니다. 슬롯은 역할에 붙는다. S1은 클럭을 받는 카운터, S2는 그 출력을 받는 첫 인버터, S3은 풀업이 달린
오픈 드레인 인버터, S4는 가산 증폭기다. 세 회로 모두 칩이 바뀌지 않는다. LED 윗행은 위에서부터 3·8·13·18행
(QD·QC·QB·QA, T1 열 순서)이고 우 a열에서 받는다. S4는 pin 6이 레일 빈 행 38에 오게 36행에 둔다 — Rf가 그 행에서
가운데 레일 홀 위를 지나지 않고 건넌다. 행 비교는 `배치탐색.md`에 있다. 저항 구역은 우 36~45행, +15V는 우 바깥 VCC 레일, 브리지는 48·49행이다.

| 슬롯 | 자리 | 회로별 칩 |
|---|---|---|
| S1 | 좌 4행 | C1~C3: U1 = 7490 |
| S2 | 좌 15행 | C2~C3: U2 = 74HC04 |
| S3 | 좌 25행 | C2~C3: U3 = 74HC05 |
| S4 | 좌 36행 | C2~C3: U4 = LM741 |

# 미확정 사항

- kind: open-issues

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M1 | 표지 표기가 `25-1 논리회로실험`이다. 2026-2 개정 여부는 알 수 없다. 저장소 아카이브 `from_the_past/정리/강의노트/실험10.pdf`는 근거로 쓰지 않았다. `.claude/데이터시트_출처.md`의 옛 실험10 문단("교안 p9 가 7490·7404·7405·741 핀아웃 도해를 싣는다")은 아카이브 교안 기준이라 배포본과 맞지 않았다. 2026-11-16 고쳤다 | 조교 공지·실험 당일 교안 대조 |
| M2 | IC 표기가 갈린다. 준비물(p14)과 명세 `ics`는 `74HC04`·`74HC05`·`7490`·`LM741`, 회로도(p8~p12·p15~p17)는 `7404`·`7405`, p9 본문은 `IC 05`·`IC 04`다. 핀 번호는 두 계열이 같다. `7490`이 TTL이고 `74HC04` 입력이 CMOS 레벨(TI SCLS080F·Nexperia 74HC04: VCC 4.5V에서 VIH 최소 3.15V)이라 7490 High 출력이 그 문턱을 넘는지는 수령 실물 계열에 달렸다. 7490의 VOH 값은 이번에 데이터시트를 열어 확인하지 않았다 | 수령 시 각인 확인. T1과 V1이 맞지 않으면 7490 출력과 U2 출력을 오실로스코프로 함께 본다 |
| M3 | **LM741 pin 7의 전원 라벨이 회로도에 없다.** p8~p12·p16·p17 회로도는 U4 pin 7을 라벨 없는 단자로 끝낸다. p16 `LM741 Datasheet` 그림은 pin 7을 `V+`로, 같은 교안 p22의 ADC 비교기 U5는 pin 7을 `+15V`로 적는다. 이 문서는 +15V로 잇는다. 교안 원문이 아니다 | 실험 당일 조교에게 확인 |
| M4 | 교안은 신호발생기 설정을 `오실로스코프 설정` 머리 아래 적는다(p15~p17). 실험실 오실로스코프에 발생기가 내장됐는지, 별도 발생기인지는 교안에 없다. 진폭 `5V`가 Vpp인지 피크인지도 없다 — 5Vpp면 0~+5V, 5V 피크면 -2.5~+7.5V다. 절차 4~6(p19~p21)은 설정을 다시 적지 않아 1.0kHz를 이어 쓴다. 교안 원문이 아니다 | 회로에 잇기 전 오실로스코프로 실제 최소·최대를 확인. 0~+5V가 아니면 진폭을 맞춘다 |
| M5 | 절차 1(p15)은 LED를 쓰지만 p14 준비물에 LED와 LED용 저항이 없다. 330Ω 사슬, 사슬 방향(`출력 → LED → 330Ω → GND`), LED를 C2·C3에 남기는 것은 이 문서의 선택이다. 교안 원문이 아니다 | 실험 전 키트 확인. 없으면 조교에게 요청 |
| M6 | C2·C3에서 7490 출력 하나가 LED 사슬과 74HC04 입력(QA는 CLKB까지)을 함께 구동한다. LED 부하가 7490 High 레벨을 M2의 VIH 문턱 아래로 낮추는지는 측정 전이라 모른다 | T2·T3·T4가 이상하면 LED 급전선 넷을 뽑고 다시 본다. 뽑으면 그 사실을 기록에 적는다 |
| M7 | **교안 소자값으로 이상 소자 셈을 하면 절차 3(V+ = 분배기)의 출력이 R9 전 범위·모든 카운트에서 U4 전원 +15V를 넘어, p18의 계단 사진과 어긋난다.** 분배기 가운데 단자 전압은 15V × 1000/2330 ≈ 6.4V ~ 15V × 1330/2330 ≈ 8.6V다(R10 1k, R9 330, R11 1k, 이상 저항 셈). U4가 선형으로 동작하면 가산 노드도 이 전위가 되어 +5V 로직 레일보다 높다. 이때 High 비트 가지의 U3 출력은 VCC보다 높아질 수 있고, TI SCLS080F는 VO > VCC 쪽 출력 클램프 전류(±20mA)를 정격에 둔다. 같은 이상 셈으로 V+ ≈ 6.4V(분배기 하한), COUNT 9(가지 전류가 가장 작은 카운트)에서 출력은 V+ + Rf × Σ(V+ − Vi)/Ri ≈ 6.4V + 4.5k × 2.6mA ≈ 18V로, U4 전원 +15V를 넘는다. Low 비트 가지는 Vi ≈ 0V·Ri = 가중 저항, High 비트 가지는 Vi = 5V·Ri = 풀업 + 가중 저항(5V 풀업과 가중 저항의 테브난 모형)으로 셌다. 이 모형은 비트 비중이 2의 거듭제곱이 된다는 뜻이 아니다. 출력은 V+에 대해 증가하므로 분배기 하한이 전 범위의 최솟값이다. COUNT 0(모든 비트 Low)이 +13.5V 안에 들려면 V+ ≲ 13.5V / (1 + 4.5k × Σ1/Ri) ≈ 2.4V여야 하는데, 분배기 범위(6.4~8.6V)와 멀다. Rf 2.7k(T8)로 바꿔도 V+ ≈ 6.4V에서 COUNT 9만 ≈ 13.4V이고 COUNT 8은 ≈ 14.0V, COUNT 0~7은 ≈ 19~24V라 +15V를 넘는다. U3 High 출력을 5.5V 클램프로 바꿔 세도 같은 쪽이다. 이 셈은 7490·74HC05 출력 저항과 LM741 실제 출력 한계를 무시했고 교안 원문이 아니다. 교안 회로도의 R10·R9·R11 판독(p8~p12·p16·p17 vision)이 틀렸을 가능성도 이 셈과 함께 남는다. p10은 "비율은 약간의 오차가 있어도 됨"만 적는다 | T2 스텝 3과 T4를 실측으로 판정한다. 출력이 한 값에 붙어 계단이 안 보이면 R9 양 끝 두 자리의 최소·최대를 적고, 분배기 값을 조교에게 확인한다 |
| M8 | 절차 4(p19)는 7404 출력과 7405 입력 사이를 연다. 연 동안 74HC05 입력은 떠 있다. TI SCLS080F는 떠 있는 CMOS 입력의 출력 값을 정하지 않는다. p19 사진(2003년 촬영 표기)이 어떤 계열 칩으로 찍혔는지는 교안에 없다. 교안은 QD 비트(U2 pin 8–U3 pin 9)는 열지 않는다 | T5~T7을 보이는 대로 그린다. 연 시간은 화면을 그리는 동안으로 짧게 둔다 |
| M9 | 절차 5(Rf 2.7k)와 절차 6(10.5k ∥ 68k)이 누적인지 교안은 적지 않는다. p20·p21 사진의 트리거 설정이 달라(p21 `-900mV`, vision 판독) 사진으로도 가를 수 없다. 이 문서는 절차 5 뒤 Rf를 4.5k로 되돌려 T9를 T4와 비교한다. 교안 원문이 아니다 | 실험 당일 조교에게 확인. 누적으로 하라면 T9 옆에 "Rf 2.7k 상태"라고 적는다 |
| M10 | 결선도 엔진이 DIP-8(LM741)·가변저항·저항망·+15V 레일을 그릴 수 있는지 이 단계에서 확인하지 않았다. 칩 자리표의 행, 그림 파일, 단계별 신호선 셈은 결선도 단계에서 정한다. 단계 4는 저항 여덟 개(R5~R8·R12·R10·R9·R11)와 칩 하나를 함께 더하므로 조립 순서 표로 나눌 후보다 | **해소(2026-11-16 결선도):** 엔진에 DIP-8 LM741(`DIP_PINS`·`DIP_POWER`), +15V 레일(`connect_jacks_15v`, `DIP_SUPPLY`), 두 홀 사이 저항(`resistor`)·가변저항(`potentiometer`)을 더했다. 저항은 준비 그림 셋에서 꽂고 4단계 신호선은 다섯이다(`STAGE_WIRE_BUDGET` 5). 74HC05 a쪽 리드 10은 `SIDE_LEAD_MAX` 10이다. 256회 고정 LED 탐색은 NODE 끝점을 탐색 어댑터가 모르므로 돌리지 않았다 |
| M11 | LM741 데이터시트(TI SNOSC25D §6.3)의 권장 동작 전원은 ±10V~±22V(LM741)다. 교안은 단일 +15V와 GND로 구동한다. T2 2행(V+ = GND)은 입력이 음전원과 같은 0V라 p12의 "Op-Amp가 정상적인 출력을 하기 어려움" 문장과 함께 읽는다. 데이터시트의 출력 스윙은 ±15V 공급 기준값이라 단일 15V의 출력 한계를 이 문서는 정하지 않는다 | T2의 최소·최대를 실측으로 적는다 |
| M12 (구조 결정) | 실험 1)은 교안이 항목을 하나로 두어 명세 항목 `E10.P1` 하나에 절차 1~6을 담았다. 결선도는 C1(절차 1), C2(절차 2~3), C3(절차 4~6)으로 나눴다. 회로 제목의 `1.`·`2~3.`·`4~6.` 구분과 V+ 점퍼 `VP`, 노드 이름 `OA`~`OD`는 교안 원문이 아니다 | 해당 없음 |
| M13 | 교안 사진의 대응이 정해지지 않았다. p18은 예상 결과 사진 두 장(왼쪽 평평한 선, 오른쪽 내림차순 계단)을 싣지만 어느 사진이 절차 2·3 중 어느 것인지 적지 않는다. p21의 두 사진은 이 해상도에서 차이를 단정할 수 없다(300dpi vision). p18~p21 사진은 모두 `21 Aug 2003` 표기다(vision) | T3·T4·T9를 실측대로 그린다. 사진과의 비교는 결과보고서에서 이 미확정을 밝히고 한다 |

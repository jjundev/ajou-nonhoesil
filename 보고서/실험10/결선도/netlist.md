# 공통 규칙

- kind: common

이 주차는 이 과목에서 **유일하게 아날로그와 디지털이 한 브레드보드에 섞이는** 회로다.
전원 레일이 셋이고, 오픈 컬렉터 인버터가 있고, 카운터의 전원핀이 다른 칩과 다르다.
아래 세 문단이 이 주차 배선 사고의 거의 전부를 차지한다.

## 전원 레일 — 레일마다 어디로 가는지 명시한다

명세 프론트매터는 `{VCC: "+5V", V15: "+15V", GND: "GND"}` 세 레일을 선언한다.
**음전원(−15V) 레일은 없다.** 교안 실험10 어디에도 `-15V` 나 `±15V` 라벨이 없고,
p7 의 `U4`·p15 의 `U5` 두 741 모두 **pin 4 가 접지 기호에 직접 물려 있다** —
vision 으로 확인했다. 즉 741 은 **+15V 단일 전원**으로 돌린다.

| 레일 | 값 | 어느 핀으로 가는가 |
|---|---|---|
| `VCC` | +5V | `7490` **pin 5**, `7404` pin 14, `7405` pin 14, 풀업 저항 R1~R4 상단 |
| `V15` | +15V | `741 OP amp` U4 **pin 7**, U5 **pin 7**, 기준전압 분압기 R10 상단, ADC 가변저항 R13 상단 |
| `GND` | 0V | `7490` **pin 10**, `7404` pin 7, `7405` pin 7, 741 U4·U5 **pin 4**, R11 하단, R13 하단, 7490 리셋핀 4개, 미사용 입력핀 전부, 계측기 프로브 접지 클립 |

- **+5V 전원과 +15V 전원의 GND 를 반드시 같은 노드로 묶는다.** 실험실 파워서플라이의
  두 채널을 쓸 때 각 채널의 COM 을 따로 두면 DAC 출력이 741 입장에서 기준 없는
  전압이 되어 계단이 아예 안 나오거나 레일에 붙는다. 이 주차에서 가장 조용히
  망가지는 지점이다.
- **`741` pin 4 는 데이터시트상 `V−` 다.** 여기서 `V− = 0V` 이므로 출력은 0V 아래로
  내려갈 수 없다. 그래서 교안이 R10–R9–R11 분압기로 `pin 3(+)` 에 **양의 기준전압**을
  걸어 두는 것이다. 이 분압기를 빼먹으면 반전 가산 증폭기의 출력이 0V 에 붙어
  계단이 보이지 않는다 — 분압기는 장식이 아니라 단일 전원 동작의 필수 부품이다.
- **`741` pin 4 를 −15V 로 착각해 물리지 않는다.** 명세가 선언하지 않은 레일이고
  교안에도 없다. 실험실 파워서플라이에 −15V 단자가 있어도 이 회로에는 쓰지 않는다.

## `7405` 는 오픈 컬렉터다 — 풀업이 없으면 회로가 아예 안 돈다

`7405` 는 `7404` 와 논리는 같지만 출력단에 상단 트랜지스터가 없다. 출력은 LOW 로
끌어내리기만 하고 HIGH 를 **못 만든다**. 그래서 교안 p7 은 출력 4개마다 +5V 로
가는 **1.5kΩ 풀업(R1~R4)** 을 달아 둔다.

- 풀업을 빠뜨리면 7405 출력은 HIGH 일 때 플로팅이 되고, 가중 저항망에 전류가
  들어가지 않아 **계단이 전혀 안 나온다.** "IC 를 잘못 꽂았나" 하고 IC 부터
  의심하기 쉬운데, 실제 원인은 저항 4개다.
- 풀업이 **가중 저항망의 일부**라는 점이 이 회로의 핵심이다. 7405 출력이 HIGH 면
  그 비트의 브랜치는 `풀업 + 브랜치저항` 을 통해 +5V 에 물리고, LOW 면 포화된
  트랜지스터를 통해 거의 0V 에 물린다. 즉 풀업 저항값은 가중치 비율에 직접
  들어간다 — R1~R4 를 다른 값으로 바꾸면 계단 높이가 어긋난다.
- `7404 → 7405` 로 **두 번 반전**하므로 7405 출력 노드의 논리는 카운터 출력과
  같다(QA=1 → 7405 출력 HIGH). 7404 는 카운터 출력을 버퍼링하고, 7405 는 그것을
  +5V/0V 로 딱 떨어지게 스위칭하는 역할이다.

## `7490` 은 전원핀이 14/7 이 아니다

**`7490` 은 pin 5 가 VCC, pin 10 이 GND 다.** 이 과목의 다른 모든 74 시리즈 칩이
`14 → VCC, 7 → GND` 라서 손이 자동으로 그리로 간다. 7490 에 그렇게 물리면
pin 5(VCC) 가 R9(1) 옆의 신호핀이 아니라… 실제로는 pin 14 가 `INPUT A`, pin 7 이
`R9(2)` 이므로 **클럭 입력에 5V 를 직결하고 R9(2) 를 접지로 끌어내리는 꼴**이 되어
칩이 세지 않는다. 배선 전에 pin 5·10 을 먼저 꽂는 습관이 안전하다.

리셋핀은 넷 다 GND 로 내린다: `R0(1)=pin 2`, `R0(2)=pin 3`, `R9(1)=pin 6`,
`R9(2)=pin 7`. 교안 p9 의 Reset Inputs 표에서 이 넷이 모두 L 일 때만 `COUNT` 다.
하나라도 뜨면(플로팅은 TTL 에서 HIGH 로 읽힌다) 카운터가 0 또는 9 에 고정된다.

## 미사용핀 처리

- `7404`·`7405` 는 hex 인버터인데 이 회로는 게이트 4개만 쓴다.
  **미사용 입력핀 pin 11, pin 13 → GND.** 미사용 출력핀 pin 10, pin 12 → 개방.
  (`7405` 의 미사용 출력은 오픈 컬렉터라 풀업이 없으면 어차피 플로팅이다 —
  그대로 개방해 두고 아무것도 물리지 않는다.)
- `7490` pin 4, pin 13 은 `NC` 다 → 개방.
- `741` pin 1·pin 5 는 `OFFSET NULL`, pin 8 은 `NC` 다 → 세 핀 모두 개방.
  오프셋 널은 이 실험에서 조정하지 않는다.

# E10.P1 · DAC — 계단 파형 관찰

- kind: circuit
- id: C1
- item: E10.P1
- tables: [T1]

교안 p7 회로. `7490` 이 0→9 를 세고, 각 비트가 `7404`→`7405` 를 거쳐
**가중 저항망(weighted resistor)** 으로 들어가고, `741` 반전 가산 증폭기가
아날로그 전압을 만든다.

**저항망은 R-2R 사다리가 아니라 가중 저항망이다.** 교안 p4 는 두 방식을 나란히
설명하지만, p7 이 실제로 그린 것은 비트마다 다른 값의 저항 하나를 공통 가산
노드로 모으는 가중 저항 방식이다 — R-2R 처럼 저항이 두 값만 반복하는 구조가
아니다. 배선 순서를 R-2R 로 착각하면 저항 위치가 전부 어긋난다.

## 가중 저항망 — 저항값과 위치

| 저항 | 값 | 한쪽 | 다른 쪽 | 브랜치 합성 | 가중치 |
|---|---|---|---|---|---|
| R1 | 1.5kΩ | VCC(+5V) | U3 pin 2 | R1+R5 = **24.1kΩ** | QA (LSB), ×1 |
| R5 | 22.6kΩ | U3 pin 2 | 가산 노드 | | |
| R2 | 1.5kΩ | VCC(+5V) | U3 pin 4 | R2+R6 = **12kΩ** | QB, ×2 |
| R6 | 10.5kΩ | U3 pin 4 | 가산 노드 | | |
| R3 | 1.5kΩ | VCC(+5V) | U3 pin 6 | R3+R7 = **6kΩ** | QC, ×4 |
| R7 | 4.5kΩ | U3 pin 6 | 가산 노드 | | |
| R4 | 1.5kΩ | VCC(+5V) | U3 pin 8 | R4+R8 = **3kΩ** | QD (MSB), ×8 |
| R8 | 1.5kΩ | U3 pin 8 | 가산 노드 | | |

- **가산 노드** = R5·R6·R7·R8 의 오른쪽 끝이 전부 모이는 한 점 = U4 pin 2 = R12 의 한쪽.
- 합성 저항이 `24.1 : 12 : 6 : 3` 이므로 전류 가중치는 `1 : 2 : 4 : 8` 이다.
  MSB(QD) 가 **가장 작은** 저항을 갖는다 — 직관과 반대라 자리를 바꿔 꽂기 쉽다.
  **22.6kΩ 은 QA(LSB) 쪽, 1.5kΩ 두 개가 QD(MSB) 쪽**이라고 외우는 편이 안전하다.
- 계단 높이가 불균등하면 IC 보다 이 여덟 개 저항의 자리를 먼저 의심한다.

## 계측 — 오실로스코프를 어디에 대는가

| 채널 | 프로브 팁 | 프로브 접지 클립 |
|---|---|---|
| Ch3 | **U4 pin 6 (`DAC OUTPUT`)** — 계단 파형이 보이는 곳 | 공통 GND |
| Ch2 | 클럭 노드(함수발생기 출력 = U1 pin 14) | 공통 GND |

- **두 프로브의 접지 클립은 반드시 같은 공통 GND 로.** +15V 전원 쪽 COM 에만 물리고
  로직 GND 를 안 묶으면 계단이 엉뚱한 오프셋으로 뜬다.
- 교안 p11 사진의 설정: `Ch2 5.00 V/div`, `Ch3 5.00 V/div`, `M 2.00 ms/div`,
  트리거 `A: Ch3, 상승 에지, 0.00 V`(p14 사진은 −900 mV). 1 kHz 클럭이면 계단
  10개의 한 주기가 10 ms 이므로 2 ms/div 화면에서 약 5칸에 한 주기가 들어온다 —
  이게 맞으면 카운터가 제대로 10진으로 돌고 있다는 뜻이다.
- 계단은 **내려간다.** 반전 증폭기이므로 카운트가 올라갈수록 출력이 기준전압에서
  아래로 내려가고, 9→0 리셋에서 위로 튄다. 톱니의 방향이 반대로 보인다고
  배선을 의심할 필요는 없다.

## 교안이 요구하는 배선 변형 (p12~p14)

기본 회로를 세운 뒤 아래 변형을 차례로 가한다. 명세의 `T1`(capture) 은 파형을
그리라고만 하므로 표 칸은 없지만, **배선은 실제로 바뀐다.**

| 교안 | 변형 | 되돌릴 것 |
|---|---|---|
| p12 | R12(`Rf`) 를 4.5kΩ → **2.7kΩ** 으로 교체 | 다음 단계에서 4.5kΩ 으로 복귀 |
| p13 | R12 = 4.5kΩ 로 되돌린 뒤, ①`7404` pin 2 ↔ `7405` pin 1 ②`7404` pin 4 ↔ `7405` pin 3 ③`7404` pin 6 ↔ `7405` pin 5 를 **하나씩 개방** | 각 관찰 후 다시 연결 |
| p14 | R6(10.5kΩ) 에 **68kΩ** 을 병렬 연결 → 파형 관찰 → 68kΩ 제거 후 비교 | 68kΩ 제거 |

p13 에서 링크를 끊으면 `7405` 입력이 플로팅된다. TTL 플로팅 입력은 HIGH 로 읽히므로
해당 비트의 7405 출력이 LOW 로 고정되고, 그 비트만 계단에서 빠진다 — 그것이 이
관찰의 목적이다. (다른 실험에서라면 플로팅 입력은 금지지만 여기서는 교안이
의도한 조작이다.)

## U5 = `741 OP amp` (비교기)

| 핀/소자 | 연결 | 왜 |
|---|---|---|
| U5 pin 7 | **V15(+15V)** | 교안 p15 U5 pin 7 라벨 |
| U5 pin 4 | **GND** | 교안 p15 에서 접지 기호에 직결. U4 와 같은 단일 전원 |
| U5 pin 2 (−) | **U4 pin 6 (`DAC OUTPUT`)** | 비교 대상. U4 의 출력을 그대로 받는다 |
| U5 pin 3 (+) | R13 와이퍼 | 5~15V 로 돌려 가며 전이점을 찾는 쪽 |
| U5 pin 6 | `OUTPUT` — DMM 및 오실로스코프 | |
| U5 pin 1, 5, 8 | 개방 | |
| R13 상단 | **V15(+15V)** | |
| R13 하단 | **GND** | |

- **귀환 저항이 없다.** 교안 p15 는 U5 에 `Rf` 를 달지 않는다 — 개루프 비교기이므로
  출력은 두 입력의 대소에 따라 거의 레일까지 튄다. U4 처럼 R12 를 달면 비교기가
  아니라 증폭기가 되어 전이점이 안 나온다.
- **R13 발열 주의.** R13(330Ω) 은 +15V 와 GND 사이에 다른 저항 없이 홀로 걸린다
  (U4 쪽 R9 는 R10·R11 과 직렬이라 사정이 다르다). 약 45 mA, **0.68 W** 가
  소비되는데 소형 가변저항의 정격은 보통 0.25~0.5 W 다. 교안 p15 회로도 그대로지만,
  꽂자마자 뜨거워지면 정상이 아니라 정격 초과를 의심하고 조교에게 확인할 것.
  (아래 미확정 사항 `M5`)

## 클럭 변경과 카운터 리셋

| 조작 | 배선 | 왜 |
|---|---|---|
| 클럭 교체 | U1 pin 14 ← 1 kHz 구형파 대신 **single pulse** 출처 | 교안 p16: "1KHz pulse 를 single pulse 로 바꾸고" |
| 카운터 리셋 | U1 pin 2·pin 3(R0(1)·R0(2)) 을 잠시 VCC(+5V) 로 올렸다가 **다시 GND 로 되돌린다** | 교안 p9 표에서 R0(1)=H, R0(2)=H, R9 중 하나 L 이면 출력이 전부 L. GND 로 되돌리지 않으면 그 뒤로 세지 않는다 (`M2`) |

## 계측 — 어디를 재는가

| 계측기 | 접점 | 기준 | 무엇을 |
|---|---|---|---|
| DMM (전압) | **U5 pin 6 (`OUTPUT`)** | 공통 GND | 명세 T2 의 "출력 전압" |
| DMM (전압) | **U5 pin 3** | 공통 GND | 명세 T2 의 "3번 핀 전압". R13 을 돌리며 읽는다 |
| 오실로스코프 Ch3 | U5 pin 6 (`OUTPUT`) | 공통 GND | 전이 순간을 눈으로 확인 |
| 오실로스코프 Ch2 | U4 pin 6 (`DAC OUTPUT`) | 공통 GND | 교안 p17: 반전 입력이 구형파인지 확인 |

디지털 워드는 **`7405` 의 pin 8 · pin 6 · pin 4 · pin 2** 에서 읽는다 (교안 p16 명시).
명세 T2 의 열 순서와 같고, 비트 순서는 **pin 8 = QD(MSB) → pin 2 = QA(LSB)** 다.
DMM 이나 로직 프로브를 이 네 핀에 차례로 대고 GND 기준으로 읽는다.
7405 출력은 오픈 컬렉터라 **풀업 R1~R4 가 붙어 있어야만** HIGH 가 읽힌다 —
여기서 전부 0V 로 읽히면 비트가 아니라 풀업을 의심한다.

# 미확인 사항

발언·화면 관찰·사용자 설명을 구분한 기록이다. 입력값을 출력에서 역산해 확정하지 않는다.

- 자동 전사 미확인 (p1): 실패 상태를 확인하고 transcribe 명령으로 재개하세요.
- API 키 부재로 발언 전사 실패. 입력 조건과 클럭 에지 및 실제 LED와 BIT 대응을 확정할 수 없음.

## lights · p1 · 15~21.5초

화면 관찰: 세로로 배열된 LED의 점등 위치가 시간에 따라 변한다.

- 미확인: 입력 상태와 클럭 파형, LED와 각 BIT의 실물 대응 미확인

## after_adjust · p1 · 25~31.017초

화면 관찰: 손으로 조작한 뒤 LED 점등 위치가 변한다.

- 미확인: 조작한 신호와 입력값, 클럭 에지 미확인

- 오디오 직접 청취 확인 없음. 전사 대조와 수치상 동기 검증은 청감 자연스러움 검증과 다르다.

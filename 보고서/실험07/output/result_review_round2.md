# 실험07 결과보고서 검토 — round2

## 자동 검사

- 오류 0건, 경고 6건, 정보 1건. 강의노트 판본 일치, 26쪽.
- 경고 6건은 단계 1~6의 프로브 관측 노드에 LED가 없다는 내용이다. netlist.md:250–260은 해당 단계들을 프로브로 확인하도록 지정하므로 유지한다.
- 정보: 그림 3장. 보고서·HTML 자동 검사에서 오류가 없다.

## 내용 대조

- round1의 출력 연결 오류는 수정됐다. 보고서 140행은 BIT1~BIT5만 다음 단의 J와 LED를 함께 구동하고 BIT6은 LED에 연결된다고 구분한다. netlist.md:166–173, 187–193, 210–215와 일치한다.
- U2가 제대로 꽂히지 않았다는 사용자의 설명에 맞춰 보고서 120·128·135행을 기록.md:51, 72–74와 대조했다. 개별 핀의 확인 여부를 추측한 문장은 삭제했다.
- HD74HC76 참고문헌은 [Renesas 원본 데이터시트](https://www.renesas.com/en/document/dst/hd74hc76-datasheet)의 문서 첫 쪽(전체 PDF 3쪽)에서 REJ03D0551-0200, Rev.2.00, 2005-10-06과 일치함을 확인했다.
- 이미지 세 경로는 실재한다. 사진의 입력 설정은 제공 전사에 근거하며 실제 전압·에지·LED-BIT 배선은 영상만으로 독립 확인되지 않았다.

| 확인 필요 | 근거 | 판정 |
|---|---|---|
| 기록표 확인 당시의 LED 물리 번호와 BIT의 대응 | 기록.md:24–31, 41–49, 59–66은 ②·①·④·③·⑥·⑤ 순서, netlist.md:135–140은 ①~⑥ 순서 | 근거 간 불일치. BIT 이름에 따른 표는 기록과 명세에 맞지만 실제 확인 기준을 사용자에게 질문했다. 응답 전 실제 결과의 대응은 확정하지 않는다. |

## 사용자 확인 및 후속 조치

- 사용자는 실제 실험에서 결선도와 같이 ①~⑥을 BIT1~BIT6 순서로 읽었다고 확인했다.
- 기록표 25개 행에서 BIT 이름은 유지하고 원형 LED 번호만 결선도 순서로 수정했다. 확인 표시를 바꾸지 않았다.
- 수정된 기록의 점등 BIT와 명세의 예상 출력을 25행 대조한 결과 불일치 0건이다. 보고서 출력값은 변경할 필요가 없다.
- 보고서 자동 검사 오류 0건. 위 6개 프로브 단계 경고는 그대로다.
- LED 번호 대응에 관한 확인 대기는 해소됐다. 고찰의 본인 경험, 회로도 위상 및 표기 등 사람 확인 사항은 그대로 남는다.

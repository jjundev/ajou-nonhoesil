# 배치 탐색 — 보고서/실험07/결선도/배치.py

`python -m scripts.lab.place_search <배치.py>` 가 쓴다. 배선표가 바뀌면 다시 돌린다 — 고른 layout 은 `배치.py` 의 `LAYOUT` 과 netlist `kind: layout` 표에 옮겨 적는다.

```json
{
 "hash": "206d20a7ba8823e8",
 "layout": {
  "bridge": [
   51,
   52
  ],
  "leds": {
   "shift": {
    "BIT1": 22,
    "BIT2": 18,
    "BIT3": 33,
    "BIT4": 28,
    "BIT5": 44,
    "BIT6": 40
   }
  },
  "slots": {
   "S1": 7,
   "S2": 17,
   "S3": 28,
   "S4": 39
  }
 }
}
```

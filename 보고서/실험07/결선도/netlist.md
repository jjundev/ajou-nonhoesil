# 공통 규칙

- kind: common

교안 p8~11의 실험 1 회로 하나를 맨바닥에서 만든다. `74HC00` 1개와 `74HC76` 3개를
동시에 올리고, 여섯 Q 출력에 LED 6개를 연결한다(p7~8). 범위 밖 7496 회로는 만들지 않는다.
`U1`~`U4`와 슬롯 이름은 교안 원문이 아닌 이 문서의 식별자다.

전원은 p7의 5V 전압원이다. `74HC00`은 pin 14 → VCC(+5V), pin 7 → GND다(아래 핀아웃 출처).
**`74HC76` 세 패키지는 모두 pin 5 → VCC(+5V), pin 13 → GND**다. 보통 DIP-16의 모서리
16·8을 전원으로 쓰는 배치를 적용하지 않는다. 신호 배선의 근거는 p8 300dpi·900dpi vision이다.

다음은 교안 원문이 아닌 배선 운영 규칙이다. 칩·점퍼를 바꿀 때 전원을 끄고 전원 극성을
확인한다. 사용하는 입력은 확정된 논리 레벨 또는 구동 출력에 연결해 플로팅을 막는다.
미사용 게이트 입력은 `draft-lab-spec`의 결선도 골격 공통 규칙이 지정한
접지 생략으로 적었다. 이는 이 수업의 운영 선택이며 CMOS 입력의 일반 권장사항이라는 뜻은 아니다. 실물 확인 전의 미확정은
아래 대장의 M3·M4·M5에서 관리한다. **여섯 F/F는 전부 사용**하므로 그 J·K·CLK·PR·CLR 중
남겨 두는 입력은 없다.

클럭은 교안 p10 본문을 따라 오실로스코프에서 보며 **주기 5s 이상(0.2Hz 이하)**을 우선
설정한다. 회로도에 인쇄된 1Hz와는 구분한다(M2). 0~+5V 클럭·회로·오실로스코프의 GND를
공통으로 잇는 것은 교안 p8 발생기 접지선에서 구체화한 절차이며 교안 원문이 아니다(M3).
스위치 접점의 1·2·3은 외부 스위치 단자 번호이며 IC 핀 번호가 아니다. 준비물에 스위치
수량은 없으므로 입력은 레벨을 확정할 수 있는 장비나 점퍼로 구성하고 실제 수단을 확인한다(M3).

CLR·PR1·PR2는 Active Low다. 명세 T1~T3은 CLR=0인 동안 PR1=PR2=1로 두고, CLR을 1로
해제한 다음 한 PR만 0으로 내린다. **CLR과 PR을 동시에 0으로 만들지 않는 순서는 교안 원문이
아닌 확인 절차다.** 교안은 두 비동기 입력의 동시 활성 상태를 실험하라고 지시하지 않는다.
PR을 0으로 유지하면 해당 단은 계속 강제 SET되므로, 한 비트를 이동시키는 관찰에서는
PR을 1로 해제하고 CLK을 재개한다. 이 관찰 순서는 교안 원문이 아니며 p11의 강제 SET 기능과
p10의 시프트 기능을 나눠 보기 위한 것이다.

각 Q에서 `출력 → LED → 330Ω → GND`로 연결해 출력 1에서 점등하는 후보를 쓴다.
**LED 극성과 이 직렬 연결 순서는 교안 원문이 아니다**(M4). p8은 Q마다 LED를 연결하라고만
하며 p7은 330Ω 6개를 준다. Q 출력은 다음 J도 구동하므로 LED 부하를 포함한 동작 여부는
실물에서 확인한다. 예상 LED 전류·실측 전압을 지어 넣지 않는다.

순차 출력은 `lab-netlist/v3`의 observed 노드와 저작한 확인 절차로 적는다.
모든 확인 절차는 교안 원문이 아니다. 조합식으로 상태를 계산하지 않으며, 초기화부터
실행하는 입력·기대 관측열을 명시한다. 명세 T1~T3의 실제 측정 칸은 빈 상태로 둔다.

배치 규칙을 지키기 위해 각 HC76 안의 BIT 역할을 바꿨다(교안 원문이 아니다, M6).
BIT1·3·5는 둘째 F/F, BIT2·4·6은 첫째 F/F다. 따라서 PR1은 U2 pin7,
PR2는 U2 pin2다. 관측 편의를 위해 LED는 위→아래 BIT1·BIT2·BIT3·BIT4·BIT5·BIT6다. R10 중 선의 순서 역전만 사용자 승인 예외이며 다른 블록 건너기 규칙은 유지한다.
새 신호선은 단계마다 최대 셋이다. R7의 실험07 한도 12와 산술 근거는 M7에 남겼다.

# 꼭 읽을 것

- kind: must-read

- **74HC76 세 개 모두 +5V는 pin 5, GND는 pin 13입니다.** 16·8이 아닙니다.
- **CLR은 0으로 초기화하고 다시 1로 올립니다.** 초기화할 때 PR1·PR2는 1에 둡니다.
- **PR1·PR2는 0일 때 SET입니다.** 한 비트의 이동을 볼 때는 해당 PR을 다시 1로 올립니다.
- **CLK 하강 에지를 보며 입력합니다.** 본문 권장 주기는 5s 이상입니다. 발생기 실제 레벨·공통 GND를 확인합니다.
- **임시 고정선은 걷기 그림대로 뽑아요.** 다시 켜기 전 CLK=0·CLR=0·PR1=PR2=1을 맞춰요.

| 관찰 | 기록표 | 기록 출력 순서 |
|---|---|---|
| 초기화·직렬 데이터 입력 | T1 | BIT1, BIT2, BIT3, BIT4, BIT5, BIT6 |
| PR1 강제 SET 후 이동 | T2 | BIT1, BIT2, BIT3, BIT4, BIT5, BIT6 |
| PR2 강제 SET 후 이동 | T3 | BIT1, BIT2, BIT3, BIT4, BIT5, BIT6 |

# C1 · 실험 1) 6bit Shift Right Register

- kind: circuit
- id: C1
- item: E7.P1
- tables: [T1, T2, T3]
- diagram: 실험07_1_결선도_6bit시프트레지스터.png

p8 회로의 논리 넷을 유지하고 패키지 안 두 F/F의 역할만 교환했다.
**이 핀 재배정과 단계 절차는 교안 원문이 아니다.** NAND는 9·10→8을 쓴다.
D는 교안의 SERIAL DATA와 같은 입력이다. CLK·CLR은 여섯 단 공통이다.
PR1은 BIT1(U2 둘째 F/F), PR2는 BIT2(U2 첫째 F/F)만 제어한다.
전원은 모든 HC76에서 5·13이며 HC00에서 14·7이다.

1단계에서 HC76의 미배선 J·K·CLK·CLR은 임시 GND선으로 0, PR1·PR2는 임시 +5V선으로
1에 고정한다. U3·U4 PR은 완성본에서도 +5V 고정이다. 임시 고정선은 미사용 핀이 아니며,
해당 입력을 연결하기 직전 걷기 그림에서 뽑는다. **이 운영 절차는 교안 원문이 아니다.**
걷기·새 배선 중에는 전원을 끈다. 매번 켜기 전에 D=0·CLK=0·CLR=0·PR1=PR2=1을
맞춰 초기화한 뒤 해당 절차의 첫 행부터 수행한다. 아직 점퍼가 없는 입력은 임시 고정선이
그 값을 준다. 전원을 끈 상태에서 발생기 출력도 정지·분리해 입력을 통해 역급전하지 않는다.

1~6단계에서는 J·K가 아직 데이터 사슬에 연결되지 않았지만 0으로 고정돼 있다.
Q 값은 확인하지 않고 해당 입력 넷만
오실로스코프/전압 프로브로 본다. 프로브 GND는 회로 GND에 연결한다(교안 원문이 아닌
부분 배선 확인 절차). 7단계부터 확인하는 BIT의 모든 J·K·CLK·CLR·PR은 확정된 넷에
연결된다. 각 단계마다 CLK을 정지하고 전원을 끈 뒤 다음 배선을 추가한다.
CLK 입력 그림은 점퍼의 0 자리다. 자동 클럭을 쓸 때는 그 점퍼의 레일 쪽 끝을 검증한
0~+5V 발생기 출력으로 옮기고 발생기 GND를 회로 GND에 잇는다. 두 구동원을 함께 물리지 않는다.

## LED 사슬과 계측

이 연결 순서는 교안 원문이 아니다. 엔진 판형의 출력 → LED 애노드 → LED 캐소드 → 330Ω → GND를
쓴다. 각 출력 1에서 점등한다. 직렬 저항은 항상 포함하며 LED·저항은 각 6개다.
Q는 다음 J도 구동한다. 부하 상태에서 레벨·점등을 실물로 확인한다(M4).
오실로스코프로 발생기의 공통 GND 기준 0~+5V와 주기 5s 이상을 확인한다(M2·M3).
전압·지연·듀티비의 측정값은 미리 채우지 않는다. 명세 T1~T3은 실제 결과 기록이다.

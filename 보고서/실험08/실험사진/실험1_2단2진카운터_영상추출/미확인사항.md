# 미확인 사항

발언·화면 관찰·사용자 설명을 구분한 기록이다. 입력값을 출력에서 역산해 확정하지 않는다.

- LED 보드 번호(①~④)와 화면상 위→아래 순서의 대응은 영상에서 배선을 따라가 독립 확인하지 못함. 위에서 1번째=Y0 은 결선도 배치 기준 추정
- CLK 파형·주기·AB 값은 화면에 보이지 않음. 약 1초 간격 전이는 프레임 관찰값
- 자동 전사(Gemini)는 2.7s 부근 '예.' 한 마디만 반환. 직접 청취 아님, 실험 내용 설명 발언 없음

## cycle · p1 · 0~9.75초

화면 관찰: LED 4개 중 하나씩만 켜짐. 화면 위에서부터 1→2→3→4→1 순서로 약 1초마다 바뀜(0.25s 미리보기: 전이는 각 정수초 직후 1.0~1.25s 사이 등). 0~0.1s 부근 4번째, 이후 1번째부터 두 바퀴 넘게 반복

전사 근거: transcript_p1 2.7초 — 예.

- 미확인: LED 보드 번호(①~④)와 화면상 위→아래 순서의 대응은 영상에서 배선을 따라가 독립 확인하지 못함. 위에서 1번째=Y0 은 결선도 배치 기준 추정

- 미확인: CLK 파형·주기·AB 값은 화면에 보이지 않음. 약 1초 간격 전이는 프레임 관찰값

- 미확인: 자동 전사(Gemini)는 2.7s 부근 '예.' 한 마디만 반환. 직접 청취 아님, 실험 내용 설명 발언 없음

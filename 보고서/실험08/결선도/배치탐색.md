# 배치 탐색 — 보고서/실험08/결선도/배치.py

`python -m scripts.lab.place_search <배치.py>` 가 쓴다. 배선표가 바뀌면 다시 돌린다 — 고른 layout 은 `배치.py` 의 `LAYOUT` 과 netlist `kind: layout` 표에 옮겨 적는다.

```json
{
 "hash": "1eed7f4ab3bb88e6",
 "layout": {
  "bridge": [
   39,
   40
  ],
  "bridge_policy": "lower-clearance-v1",
  "fnd": 29,
  "leds": {
   "bcd": {
    "A": 3,
    "B": 8,
    "C": 13,
    "D": 18
   },
   "counter": {
    "Y0": 3,
    "Y1": 8,
    "Y2": 13,
    "Y3": 18
   }
  },
  "slots": {
   "S1": 5,
   "S2": 16
  }
 }
}
```

길이·밀도는 superset 판(모든 단계의 선) 칸 단위, 회로 합이다. 기준 = 탐색 시점 `LAYOUT`.

순위: 기준보다 짧고 밀도가 기준 이하인 후보를 모두 verify 하고, 통과한 것 중 최단 길이의 ×1.02 안에서 밀도가 가장 낮은 것(동률은 꺾임·길이).

실험08 은 이 표를 `place_search` 대신 손으로 고른 칩·FND 행 후보로 쟀다. `place_plan` 의 슬롯 근사가 표시기 행을 탐색 변수로 안 보고, `--mode fixed` 는 어댑터당 회로 하나만 받아 C1·C2~C5 공유 슬롯을 못 푼다. 후보마다 `route_plan` 과 전 보드 `verify()` 를 돌렸다. 고르는 규칙은 고정 LED 탐색과 같다 — 최단 길이의 ×1.10 안에서 밀도가 가장 낮은 것. 예산 256회 탐색이 아니므로 이 범위의 최선이다.

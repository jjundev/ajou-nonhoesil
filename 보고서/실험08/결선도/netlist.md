# 공통 규칙

- kind: common

교안 범위의 실험 1(p9)과 실험 3(p11~13)만 만든다. 실험 2(p10)는 하지 않는다(조교 공지 `_350547_1`).
C1을 맨바닥에서 만들고, C2는 C1을 전부 뽑고 새로 짓는다(`rebuild: all`, M16). C3·C4는 C2 위에 이어 붙이고,
C5는 C4의 입력 고정선을 7490 출력으로 바꾼다. `U<n>`과 슬롯 이름은 교안 원문이 아닌 이 문서의 식별자다.

전원은 p8의 5V 전압원이다. 전원핀은 칩마다 다르다. **`74HC76`은 pin 5 → VCC(+5V), pin 13 → GND**,
**`7490`은 pin 5 → VCC(+5V), pin 10 → GND**(p6), `7447`은 pin 16 → VCC(+5V), pin 8 → GND(p12, p14),
`74HC08`은 pin 14 → VCC(+5V), pin 7 → GND다. p9·p11 회로도는 전원핀을 그리지 않는다.

다음은 교안 원문이 아닌 배선 운영 규칙이다. 칩을 꽂거나 배선을 바꿀 때 전원을 끄고 극성을 확인한다. T2·T6·T7에서 R0 점퍼와 7447 입력 점퍼를 레일 사이로 옮기는 것은 교안의 스위치·입력 조작에 해당하므로 전원을 켠 채 한다. 사용하는 입력은
확정된 논리 레벨이나 구동 출력에 연결해 플로팅을 막는다. **미사용 게이트 입력은 접지 생략**이 수업 공통 규칙인데,
완성 회로는 `74HC08` 네 게이트와 `74HC76` 두 F/F를 전부 써서 해당 입력이 없다. 부분 배선 단계의 아직 안 쓰는 게이트 입력도 같은 규칙으로 비워 둔다. 그 게이트 출력은 LED에 잇기 전이라 관측에 들어가지 않는다. `7490`의 pin 4·13은 교안 핀맵의
No Connect라 비워 둔다. 각 칩의 첫 사용 회로에서 교안 표의 전 행을 돌린다. T4의 R9 행은 p11이 R9를 GND에 고정해 돌리지 않는다. 칩 자리는 아래 칩 자리표를 따른다.

**`7490`의 pin 6·7은 GND에 꽂는다.** p6 핀맵은 No Connect라고 적었지만 p6 내부 회로·p11 회로·TI 데이터시트는
R9로 쓴다(M4). 입력을 공중에 두면 안 되므로 p11을 따른다.

**FND는 p16 핀표대로 잇는다.** p12·p13 그림의 FND 핀 번호는 p16 핀표와 다르다(M2). p12 머리의 "Pin map은
Appendix 참고" 지시와 준비물의 FND 507 표기에 따라 p16을 택했다. 이 선택은 교안 원문이 아니다.

클럭은 p9·p11의 Clock Generator(+5V, 1Hz)다. 설정 예는 사각파, 오프셋 +2.5V, 진폭 5Vpp이고 **교안 원문이 아니다**(M11).
CLK 선을 발생기에 잇기 전에 오실로스코프로 실제 최소 0V·최대 +5V·주기 1s를 확인하고, 발생기·오실로스코프·회로
GND를 공통으로 잇는다. 전원을 끌 때는 발생기 출력도 끈다. 출력 OFF가 0V를 보장한다고 가정하지 않는다.
스위치 `D0`는 준비물에 없어 입력 `R0` 점퍼를 +5V 또는 GND 레일에 옮겨 꽂는 것으로 대신한다(M7).
p11의 접점 번호 1·2·3은 스위치 단자 번호이고 IC 핀 번호가 아니다.

LED 사슬은 `출력 → LED → 330Ω → GND`로 적어 출력 1에서 켜지게 한다. **LED 극성과 직렬 순서는 교안 원문이 아니다**(M12).
7447 출력은 Active Low 오픈 컬렉터다(p16 Pin map `0: On, 1: Off`, TI SDLS111 p1). FND는 `7447 출력 → 330Ω → FND 세그먼트 핀`이다(p12).

순차 출력은 `lab-netlist/v3`의 observed 노드와 저작한 확인 절차로 적는다. **모든 확인 절차는 교안 원문이 아니다.**
저작한 기대값은 측정 기록이 아니며 명세의 실제 결과 칸은 빈 상태로 둔다. 기본 경로에서 쓰지 않는 절차는
`checklist: diagnostic`을 달았다. 기본 경로의 조립 중 확인은 C1 3단계 한 번이고, 나머지는 교안이 지시한 확인의 기록표 T1, T2, T5, T6, T7이다.

# 꼭 읽을 것

- kind: must-read

- **전원핀이 칩마다 달라요.** 74HC76은 5·13, 7490은 5·10, 7447은 16·8, 74HC08은 14·7이에요.
- **7490 pin 6·7(R9)은 GND에 꽂아요.** 교안 p6 핀맵의 No Connect 표기대로 비워 두지 않아요.

# C1 · 실험 1) 2단 2진 카운터 (비동기) (74HC76 + 74HC08)

- id: C1
- item: E8.P1
- tables: [T1]
- diagram: 실험08_1_결선도_2단2진카운터.png

p9 회로의 논리 넷을 유지하고, 네 AND를 74HC08 한 패키지의 네 게이트로 나눴다. p9는 네 게이트 모두 핀 1·2→3으로
적었으므로 **게이트 배정과 단계 절차는 교안 원문이 아니다**(M13). 두 F/F의 입력 J·K·PR·CL은 p9대로 VCC 고정이다.
회로에 초기화 입력이 없어 전원 직후 AB는 정해지지 않는다. 이 판단도 교안 원문이 아니다.
단계마다 전원을 끄고 추가하며, 켜기 전에 발생기를 확인한 값으로 맞춘다.

## 확인 절차 V1 · A·B 토글 확인

- checklist: diagnostic
- purpose: A가 CLK 하강 에지마다, B가 A 하강 에지마다 바뀌어 AB가 00, 10, 01, 11 순서로 도는지 확인한다.
- source: manual:p5
- layout: inline
- provenance: derived
- rationale: p5의 Falling Edge Trigger 설명과 AB 순서, p9의 회로를 부분 배선 확인으로 구체화했다. 교안 원문이 아니다.
- setup: 전원과 발생기 출력을 끈 상태에서 CLK 선을 발생기에 잇기 전에 오실로스코프로 사각파 0~+5V·주기 1s를 확인한다. 설정 예는 오프셋 +2.5V, 진폭 5Vpp이고 장비의 Vpp·피크 표시와 부하 설정은 현장에서 확인한다. 발생기·오실로스코프·회로 GND를 공통으로 잇고 CLK 선을 발생기에 잇는다. 전원을 켠 뒤 발생기를 0V로 두고 시작한다. 초기화 입력이 없어 첫 행의 A·B는 정해지지 않는다.
- encoding: 0/1
- inputs: [CLK]
- clocks: [CLK]
- observe: [A, B]

# C5 · 실험 3) 7-Segment 표시기를 갖는 BCD 카운터 — 3. 최종 BCD 카운터 (7490 + 7447 + FND 507)

- kind: circuit
- id: C5
- item: E8.P3
- tables: [T7]
- diagram: 실험08_3_결선도_BCD표시기.png

p13대로 1의 Output(ABCD)을 2의 Input(ABCD)에 잇는다. 7447 입력 고정선을 뽑고 7490 출력을 연결하는 것 말고는 바꾸지 않는다.
아래 U2 표는 바뀌는 네 핀만 적는다. 7490·FND와 7447의 나머지 핀은 C2~C4 그대로다.
A·B·C를 먼저 잇고 D 고정선은 남겨 입력이 뜨지 않게 한다. 이 순서는 교안 원문이 아니다.

p13 그림에는 A~D LED가 없다. p11의 LED는 "임의로" 단 확인용이므로 이 문서는 LED를 뽑지 않고 함께 둔다.
7490 출력이 7447과 LED를 같이 구동한다(M12). **이 유지 결정은 교안 원문이 아니다.**

7490 출력은 전부 f쪽이고 7447 입력은 전부 a쪽이라 두 칩 사이를 바로 이을 수 없다(R8). 그래서 신호선은 같은 넷인 LED 사슬 신호 스트립에서 7447 입력으로 간다(M14). **이 경로는 교안 원문이 아니다.**

| M11 | 교안은 발생기를 `+5V, 1Hz`로만 적는다. 파형 종류, 최소 전압, 오프셋, 진폭 단위가 없다. 사각파 0~+5V, 오프셋 +2.5V, 5Vpp는 교안 원문이 아니다. p8의 오실로스코프에 밑줄이 있지만 범위 안 절차는 파형 기록을 지시하지 않아 capture 표를 만들지 않았다. 발생기 제공 여부와 부하 설정도 교안에 없다. 0V 구동이 어려운 장비면 절차 첫 행을 건너뛰고 반복 클록부터 시작한다 | 실험실 장비 확인. 발생기가 없으면 조교에게 묻는다. 파형 제출 요구 여부도 확인 |
| M12 | LED 극성·직렬 순서는 교안에 없다. `출력 → LED → 330Ω → GND`는 이 문서의 선택이다. 7490이 TTL 품목이면 High 출력으로 LED와 INPUT B·7447 입력을 함께 구동한다. 부하 상태의 레벨은 교안에 없고 측정 전이라 값을 적지 않는다. C5에서 LED를 유지한 것도 이 문서의 선택이다 | C2·C5에서 A~D 레벨을 오실로스코프로 볼 수 있다. T2나 T7이 표와 다르면 LED만 뽑고 출력을 다시 본다. C5의 LED 급전선은 7447 입력까지 이어지므로 뽑지 않는다 |
| M13 | p9는 네 AND를 모두 핀 1·2→3으로 적었다. 74HC08 한 패키지의 네 게이트로 나눠 Y0=게이트4(12,13→11), Y1=게이트1(1,2→3), Y2=게이트2(4,5→6), Y3=게이트3(9,10→8)로 배정했다. 74HC76 출력이 전부 f쪽이라 칩 사이 선은 U2 f쪽 핀(9·10·12·13)으로 받고 a쪽 게이트 입력은 칩 안에서 건넌다(R8). Y0·Y3을 f쪽에 두어 네 신호가 모두 f쪽에 내린다. 교안 원문이 아니다 | 렌더러 검증 통과. 배정이 바뀌면 U2 표·단계·이 항목을 함께 고친다 |
| M14 | **FND 다리 간격은 교안에 없다.** 지난 학기 사진(`from_the_past/정리/결과보고서/실험8/`, 같은 WISH 보드)에서 FND는 골을 걸치고 몸통이 c~h 열을 덮어 a·b·i·j 열만 남는다. 그림은 이 전제로 c~h에 꽂지 않고, 숨은 다리는 d·h 열로 가정해 그렸다. 다리가 c~e·f~h 어디든 같은 스트립이라 결선은 같다. pin 1은 왼쪽 위(우 d29)이고 숫자는 옆으로 눕는다. C5의 7490→7447 네 선은 LED 사슬 신호 스트립을 거친다(R8). 7490과 7447에는 쪽을 바꿀 빈 핀이 넷이 없고 7447을 180° 돌리는 그림은 엔진에 없다. 교안 원문이 아니다 | 실물 FND를 우 29~33행에 꽂아 a·b·i·j 열이 비는지 본다. 다르면 조교·사용자에게 알리고 `DISPLAYS` 표를 고친다 |
| M15 (구조 결정) | 실험 3은 교안에 소번호가 없어 항목 `E8.P3` 하나로 두고 절차 1·2·3과 FND 테스트를 회로 넷(C2~C5)으로 나눴다. `실험 3)` 제목 뒤 구분은 교안 원문이 아니다 | 해당 없음 |
| M16 | C1→C2는 `rebuild: all`이다. 칩 전부가 바뀌고 74HC76 GND(pin 13)와 7490 GND(pin 10)의 행이 달라 전원선을 남길 수 없다. LED 사슬도 함께 뽑는다 | 결선도 단계에서 슬롯별로 재검토 |

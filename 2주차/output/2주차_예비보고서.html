1. 실험 목적

교안(실험1.pdf) p.2 "1. 목적"에 따르면 이번 실험의 목적은 다음과 같다.

  1. Logic gates(논리 게이트)의 동작 원리를 이해한다.
  2. Logic 회로 구성 법칙을 이해한다 — 부울대수(Boolean equation)와 드모르간(De Morgan)의 법칙을 이해하는 것을 포함한다.

이를 이번 주차의 세 실험 항목에 구체적으로 적용하면 다음과 같다.

  1. 2-input 게이트 IC(74HC08, 74HC32, 74HC00, 74HC02)를 두 단으로 캐스케이드 연결하여 3-input AND·OR·NAND·NOR 게이트를 구성하고, LED로 읽은 출력을 진리표와 대조해 검증한다(E1.P1-1, E1.P1-2).
  2. 인버터(74HC04)·AND(74HC08)·OR(74HC32)를 조합한 복합 논리회로를 구성하여, 여러 게이트가 만드는 부울식을 실제 회로로 확인하고 드모르간 정리가 회로 수준에서 어떻게 성립하는지 관찰한다(E1.P2).

출처: from_the_past/정리/강의노트/실험1.pdf p.2.

2. 실험 이론

2.1 논리 레벨 — H/L과 0/1

교안 p.3은 논리값을 두 단계로 정의한다: L(Low) = 논리값 0 = 물리적으로 0V, H(High) = 논리값 1 = 물리적으로 3~5V. 이 보고서의 §2.2 이론표(T6~T9)는 교안 원문 그대로 H/L 인코딩을 쓰고, §4의 3-input 진리표(T1~T5)는 실험실에서 LED 점등 여부로 직접 읽는 0/1 인코딩을 쓴다. 두 표기는 같은 논리값을 가리키는 서로 다른 표기일 뿐이며, 교안과 대조할 때 혼동하지 않도록 이 보고서에서도 서로 바꿔 쓰지 않는다.

2.2 기본 게이트 — 2-input 이론표

교안 p.4~p.8은 AND·OR·NOT·NAND·NOR 각 게이트의 기호와 부울식, 2-input 진리표를 차례로 제시한다. 아래 T6~T9는 명세(2주차/체크리스트/명세.md)에 role: reference로 등록된 참조표로, 학생이 배선·기록하는 대상이 아니라 교안 원문을 그대로 옮긴 이론 자료다. H/L 인코딩을 0/1로 바꾸지 않고 교안 그대로 둔다.

2.3 드모르간 정리와 3-input으로의 확장

일반화된(n변수) 드모르간 정리는 다음과 같다(논회 강의노트/Chap3-part1.pdf p.13, "DeMorgan's Laws for n variables"):

(X1 + X2 + ... + Xn)' = X1'·X2'· ... ·Xn'
(X1·X2· ... ·Xn)'     = X1' + X2' + ... + Xn'

같은 자료 p.14는 이를 게이트 수준에서 "AND-Invert ≡ Invert-OR"·"OR-Invert ≡ Invert-AND"로 그림과 함께 보여준다 — 즉 NAND 게이트 하나는 각 입력을 반전한 뒤 OR로 묶은 것과 논리적으로 같고, NOR 게이트 하나는 각 입력을 반전한 뒤 AND로 묶은 것과 같다.

이번 실험의 3-input AND(T1)·OR(T2)·NAND(T3)·NOR(T4)는 위 2-input 이론표를 이 정리로 확장한 것이다. 예를 들어 3-input NAND는 A·B·C = A+B+C이고, 회로 구성은(교안 p.12) 단일 3-input NAND 게이트가 아니라 74HC08로 A·B를 먼저 만들고 그 결과를 74HC00(NAND)에 C와 함께 넣어 A·B·C를 얻는 2단 구조다 — "AND 뒤에 인버터를 붙이는" 방식이 아니라는 점에 주의한다(netlist.md).

2.4 복합 논리회로(E1.P2)의 부울대수 해석

교안 p.13 회로(netlist.md가 vision 판독으로 확정)는 입력 A, B 두 개로 출력 X, Y, Z 세 개를 만든다. 배선을 부울식으로 옮기면:

Z = (A'·B)'
X = A + Z
Y = A + B

§2.3의 드모르간 정리를 Z에 적용하면 Z = A·B = A + B = A + B이고, 이를 X에 대입하면 X = A + Z = A + (A + B) = A + B(멱등법칙)이므로 X와 Z는 항등식으로 같다. 따라서 올바르게 배선했다면 모든 입력 조합에서 LED_X와 LED_Z는 항상 같이 켜지거나 같이 꺼져야 한다 — §4·§5에서 이 성질을 배선 자체 검증 수단으로 다시 쓴다.

출처: 부울식 전개는 위 §2.3의 드모르간 정리(Chap3-part1.pdf p.13)를 배선 판독 결과(2주차/결선도/netlist.md)에 적용해 이 보고서가 직접 도출했다.

3.3 LED와 전류 제한 저항

발광다이오드(LED) 3개가 준비물에 포함되며(교안 p.10), 각 LED는 애노드 쪽에 330Ω 저항을 반드시 직렬로 연결한 뒤 캐소드를 GND로 내린다(교안 p.11·p.12·p.13 공통 박스: "다이오드 연결 시, 330Ω 저항 필수"). 저항이 없으면 LED가 과전류로 손상되거나 74HC 출력단에 과부하가 걸릴 수 있다.

다만 netlist.md의 미확정 사항 M3이 지적하듯, 330Ω에서 흐르는 전류는 약 9mA로 74HC 시리즈 데이터시트가 권장하는 출력 구동 전류를 넘는 값이다. 이 보고서는 교안의 지시를 그대로 따르되, 실험 중 LED 밝기가 유난히 낮거나 조합마다 밝기 차이가 크면 이 저항값을 먼저 의심할 것을 메모해 둔다.

3.4 미사용 핀 처리

CMOS(74HC) 입력 핀을 아무 데도 연결하지 않고 띄워 두면(floating) 입력단이 고임피던스 상태가 되어 중간 전압(약 1.5~3.5V) 사이를 떠돌고, 그 결과 게이트 내부의 PMOS·NMOS가 동시에 켜지는 관통 전류(shoot-through current)가 흘러 소자가 과열되거나 영구 손상될 수 있다(docs/study/01_기본게이트_CMOS특성(실험1-2).md "절대 금기 (플로팅 입력 방지)" 절). 이 때문에 netlist.md의 공통 규칙은 미사용 입력핀을 예외 없이 GND로 내리고, 반대로 미사용 출력핀은 개방(open)해 둘 것을 요구한다 — 미사용 출력끼리 서로 묶거나 GND로 내리면 칩이 손상되기 때문이다.

이번 실험에서 미사용 입력핀이 많이 남는 이유는 쿼드(4-게이트) IC 한 개에서 게이트를 1~2개만 쓰기 때문이다. 예를 들어 74HC08은 항목마다 게이트 1개만 쓰므로, 나머지 3개 게이트의 입력 6핀이 매번 GND로 내려간다. 항목별 정확한 핀 번호는 §5 회로 결선도의 표를 따른다.

4. 실험 과정 및 예상 결과

세 항목은 공통적으로 다음 절차를 따른다: ① §5 회로 결선도의 표대로 배선하고 전원을 인가하기 전에 결선을 재확인한다. ② 입력 A(·B·C)를 점퍼선으로 +5V(=1) 또는 GND(=0)에 직접 연결해(띄워두지 않고) 가능한 모든 조합을 순서대로 인가한다. ③ 각 조합에서 LED 점등 여부를 읽어 진리표를 완성한다. ④ 완성한 표를 아래 예상값과 대조한다(교안 각 슬라이드의 공통 지시: "위 회로를 구성하고, 출력 결과를 토대로 Truth table을 작성하라. 다이오드를 통해 Truth Table 검증.").

4.1 E1.P1-1 · 3-input AND / OR gate 구성

교안 p.11 회로("3-input AND gate의 logic diagram")를 구성한다. 74HC08 한 개의 게이트1에 입력 A, B를 넣어 A·B를 만들고, 그 출력을 같은 칩의 게이트2 입력 한 쪽과 연결해 입력 C와 함께 A·B·C를 얻는다. 게이트1 출력에는 중간단 확인용 LED(L1), 게이트2(최종) 출력에는 LED(L2)를 각각 330Ω 저항과 함께 단다. OR는 같은 회로를 74HC08 대신 74HC32로 바꿔 반복한다 — 교안이 "OR gate에 대한 IC 찾아서 수행"이라고만 지시하므로, 이 보고서(그리고 netlist.md)는 OR을 만드는 IC로 74HC32를 채택했다.

4.2 E1.P1-2 · 3-input NAND / NOR gate 구성

4.3 E1.P2 · 복합 논리회로 구성

교안 p.13 회로. 입력은 A, B 두 개이고 출력은 X, Y, Z 세 개(LED 3개)로, C 입력은 없다. 74HC04 인버터로 A를 만들고, 74HC08로 A·B를 만든 뒤 다시 74HC04로 반전해 Z=A·B를 얻는다. 74HC32 게이트1은 A와 Z를 더해 X를, 게이트2는 A와 B를 더해 Y를 만든다. 세 출력 각각에 LED(330Ω 직렬)를 달아 관찰한다.

§2.4에서 정리했듯 Z=A·B=A+B이고 X=A+Z=A+B이므로 X와 Z는 항등이다. 따라서 배선이 올바르면 LED_X와 LED_Z는 모든 입력 조합에서 항상 같이 켜지거나 같이 꺼져야 하며, 이는 배선 오류를 스스로 점검할 수 있는 별도 비용 없는 검산 수단이다 — 아래 표에서도 X열과 Z열이 모든 행에서 일치한다.

5. 회로 결선도

5.1 공통 규칙

  • 모든 IC 공통: pin 14 → VCC(+5V), pin 7 → GND.
  • 미사용 입력핀은 전부 GND로 내린다. 플로팅 금지(§3.4). 미사용 출력핀은 개방한다 — 출력끼리 묶거나 GND로 내리면 칩이 손상된다.
  • 입력 A·B·C는 점퍼선으로 +5V(=1) 또는 GND(=0)에 직접 연결한다. 띄워두지 않는다.
  • LED는 애노드 쪽에 330Ω 직렬, 캐소드는 GND로(§3.3).
  • 물리 칩 재사용: 교안 p.10 준비물은 74HC00/74HC02/74HC04(2개)/74HC08/ 74HC32/74HC86 각 1개(74HC04만 2개)뿐이다. 아래 표의 U1·U3·U8은 같은 74HC08 한 개를, U2·U5·U9는 같은 74HC32 한 개를 항목마다 재배선해 쓰는 것이다 — 세 회로를 동시에 올릴 수는 없다.
  • 핀아웃 근거는 §3.2와 같다.

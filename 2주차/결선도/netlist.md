# 공통 규칙

- 모든 IC: pin 14 → VCC(+5V), pin 7 → GND
- **미사용 입력핀은 전부 GND 로 내린다.** 플로팅 금지. 미사용 *출력*핀은 개방한다
  (출력끼리 묶거나 GND 로 내리면 칩이 죽는다)
- 입력 A·B·C 는 점퍼선으로 +5V(=1) 또는 GND(=0) 에 **직접** 물린다. 띄워두지 않는다
- LED 는 애노드 쪽에 330Ω 직렬, 캐소드 → GND (교안 p11·p12·p13 의 "다이오드 연결 시,
  330Ω 저항 필수" 박스)
- **물리 칩 재사용:** 교안 p10 준비물은 `74HC00 / 74HC02 / 74HC04(2개) / 74HC08 /
  74HC32 / 74HC86` 각 1개(74HC04 만 2개)다. 아래에서 `U1`·`U3`·`U8` 은 **같은 74HC08
  한 개**를, `U2`·`U5`·`U9` 는 **같은 74HC32 한 개**를 항목마다 재배선해 쓰는 것이다.
  동시에 세 회로를 올릴 수는 없다
- 핀아웃 출처:
  - `74HC04` — 저장소 실물 데이터시트
    `from_the_past/정리/소자_데이터시트_및_미디어/1_데이터시트_및_핀아웃/datasheet.pdf`
    (Philips 74HC04 Hex inverter, 2003-07-23, PINNING 절) 로 확인함
  - `74HC00` — **저장소 안에서 확인된다.** 실험6 교안
    (`from_the_past/정리/강의노트/실험6.pdf`) p7·p8 회로도가 같은 물리 칩(74HC00 쿼드
    NAND)의 게이트 핀을 `(1,2→3)`·`(4,5→6)`·`(9,10→8)`·`(12,13→11)` 로 라벨한 것을
    vision 으로 대조했다 — 아래 참조 핀아웃 표와 일치한다
  - `74HC08`·`74HC02` — 리뷰에서 TI 데이터시트로 대조해 확인됐다
  - `74HC32` — **저장소에 데이터시트가 없고, 저장소 회로도로도 대조되지 않는다**
    (실험6 은 OR/NOR 게이트를 쓰지 않는다). 표준 74HC 시리즈 DIP-14 쿼드 2입력
    배치(74HC00·74HC08 과 동일 패턴)를 근거로 적었다. 실물 칩 각인과 1주차에 대조할 것
    (아래 미확정 사항 표 M1 참조)
- **`74HC02` 는 나머지 셋과 핀 배치가 다르다.** `74HC00/08/32` 는 게이트마다
  `입력·입력·출력` 순이지만 `74HC02` 는 `출력·입력·입력` 순이다. 이 실험에서 가장
  흔한 배선 실수다

## 참조 핀아웃

| IC | 게이트1 | 게이트2 | 게이트3 | 게이트4 | VCC | GND |
|---|---|---|---|---|---|---|
| 74HC00 (quad NAND) | 1,2 → 3 | 4,5 → 6 | 9,10 → 8 | 12,13 → 11 | 14 | 7 |
| 74HC08 (quad AND) | 1,2 → 3 | 4,5 → 6 | 9,10 → 8 | 12,13 → 11 | 14 | 7 |
| 74HC32 (quad OR) | 1,2 → 3 | 4,5 → 6 | 9,10 → 8 | 12,13 → 11 | 14 | 7 |

`74HC04` (hex inverter): 1→2, 3→4, 5→6, 9→8, 11→10, 13→12. VCC 14, GND 7.

# E1.P1-1 · 3-input AND (74HC08)

- U1 = 74HC08 (quad 2-input AND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A
  - pin 2  ← 입력 B
  - pin 3  → U1.pin4          (게이트1 출력 A·B → 게이트2 입력)
  - pin 3  → L1 애노드 (330Ω 직렬) → GND    ※ 교안 p11 의 중간단 LED
  - pin 5  ← 입력 C
  - pin 6  → L2 애노드 (330Ω 직렬) → GND    ※ 최종 출력 Y = A·B·C, T1 의 검증 대상
  - 미사용 입력핀: pin 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 8, 11 → 개방

# E1.P1-1 · 3-input OR (74HC32)

- U2 = 74HC32 (quad 2-input OR, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A
  - pin 2  ← 입력 B
  - pin 3  → U2.pin4          (게이트1 출력 A+B → 게이트2 입력)
  - pin 3  → L1 애노드 (330Ω 직렬) → GND
  - pin 5  ← 입력 C
  - pin 6  → L2 애노드 (330Ω 직렬) → GND    ※ 최종 출력 Y = A+B+C, T2 의 검증 대상
  - 미사용 입력핀: pin 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 8, 11 → 개방

# E1.P1-2 · 3-input NAND (74HC08 + 74HC00)

교안 p12 회로도 그대로. AND 로 `A·B` 를 만들고 NAND 로 `C` 와 합쳐 `(A·B·C)'` 를 낸다.

- U3 = 74HC08 (quad 2-input AND, DIP-14) — U1 과 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A
  - pin 2  ← 입력 B
  - pin 3  → U4.pin1          (게이트1 출력 A·B)
  - pin 3  → L1 애노드 (330Ω 직렬) → GND
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 6, 8, 11 → 개방
- U4 = 74HC00 (quad 2-input NAND, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U3.pin3
  - pin 2  ← 입력 C
  - pin 3  → L2 애노드 (330Ω 직렬) → GND    ※ 최종 출력 Y = (A·B·C)', T3 의 검증 대상
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 6, 8, 11 → 개방

# E1.P1-2 · 3-input NOR (74HC32 + 74HC02)

같은 구조를 OR → NOR 로 바꾼 것. **`74HC02` 의 핀 순서에 주의** (출력이 pin 1).

- U5 = 74HC32 (quad 2-input OR, DIP-14) — U2 와 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A
  - pin 2  ← 입력 B
  - pin 3  → U6.pin2          (게이트1 출력 A+B)
  - pin 3  → L1 애노드 (330Ω 직렬) → GND
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 6, 8, 11 → 개방
- U6 = 74HC02 (quad 2-input NOR, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 2  ← U5.pin3          (게이트1 입력 A — **pin 1 이 아니다**)
  - pin 3  ← 입력 C           (게이트1 입력 B)
  - pin 1  → L2 애노드 (330Ω 직렬) → GND    ※ 게이트1 **출력**. Y = (A+B+C)', T4 의 검증 대상
  - 미사용 입력핀: pin 5, 6, 8, 9, 11, 12 → GND
  - 미사용 출력핀: pin 4, 10, 13 → 개방

# E1.P2 · 복합 논리회로 (74HC04 + 74HC08 + 74HC32)

교안 p13. **입력 2개(A, B), 출력 3개(X, Y, Z), LED 3개.** C 입력은 없다.

- U7 = 74HC04 (hex inverter, DIP-14)
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (인버터1 입력)
  - pin 2  → U8.pin1          (인버터1 출력 A')
  - pin 3  ← U8.pin3          (인버터2 입력 A'·B)
  - pin 4  → U9.pin2          (인버터2 출력 Z = (A'·B)')
  - pin 4  → LED_Z 애노드 (330Ω 직렬) → GND
  - 미사용 입력핀: pin 5, 9, 11, 13 → GND
  - 미사용 출력핀: pin 6, 8, 10, 12 → 개방
- U8 = 74HC08 (quad 2-input AND, DIP-14) — U1 과 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← U7.pin2          (A')
  - pin 2  ← 입력 B
  - pin 3  → U7.pin3          (A'·B)
  - 미사용 입력핀: pin 4, 5, 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 6, 8, 11 → 개방
- U9 = 74HC32 (quad 2-input OR, DIP-14) — U2 와 같은 물리 칩
  - pin 14 → VCC(+5V)
  - pin 7  → GND
  - pin 1  ← 입력 A           (게이트1)
  - pin 2  ← U7.pin4          (Z)
  - pin 3  → LED_X 애노드 (330Ω 직렬) → GND    ※ X = A + Z
  - pin 4  ← 입력 A           (게이트2)
  - pin 5  ← 입력 B
  - pin 6  → LED_Y 애노드 (330Ω 직렬) → GND    ※ Y = A + B
  - 미사용 입력핀: pin 9, 10, 12, 13 → GND
  - 미사용 출력핀: pin 8, 11 → 개방

`Z` 노드(U7.pin4)는 LED_Z 와 U9.pin2 로 팬아웃한다. 부울대수상 `X ≡ Z` 이므로
**LED_X 와 LED_Z 가 언제나 같이 켜져야 한다.** 다르면 배선 오류다.

# 미확정 사항

| 항목 | 내용 | 확인 방법 |
|---|---|---|
| M1 | `74HC32` 핀아웃이 저장소 데이터시트로도 저장소 회로도로도 확인되지 않음(표준 DIP-14 쿼드 2입력 배치를 가정). `74HC00` 은 실험6 교안 회로도(p7·p8)로, `74HC08`·`74HC02` 는 TI 데이터시트로 각각 확인됐다 | 실물 칩 각인 확인 후 벤더 데이터시트 대조 |
| M2 | 교안이 입력 스위치/딥스위치를 지정하지 않음. 점퍼선 직결로 가정 | 실험실 키트 확인 |
| M3 | 74HC 출력으로 LED 를 직접 구동한다. 330Ω 에서 약 9 mA 로 데이터시트 권장 구동 전류를 넘는다 | 교안 지시가 그러하므로 그대로 따르되, LED 가 어두우면 이를 먼저 의심 |
